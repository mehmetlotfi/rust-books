    کتاب ناپایدار

    به «کتاب ناپایدار» (The Unstable Book) خوش آمدید! این کتاب از چندین فصل تشکیل شده است که هر کدام بر اساس یک «پرچم قابلیت» (feature flag) سازمان‌دهی شده‌اند. یعنی هنگام استفاده از یک قابلیت ناپایدار Rust باید از یک پرچم استفاده کنید، مانند این:

    #![feature(coroutines, coroutine_trait, stmt_expr_attributes)]

use std::ops::{Coroutine, CoroutineState};
use std::pin::Pin;

fn main() {
    let mut coroutine = #[coroutine] || {
        yield 1;
        return "foo"
    };

    match Pin::new(&mut coroutine).resume(()) {
        CoroutineState::Yielded(1) => {}
        _ => panic!("unexpected value from resume"),
    }
    match Pin::new(&mut coroutine).resume(()) {
        CoroutineState::Complete("foo") => {}
        _ => panic!("unexpected value from resume"),
    }
}

    قابلیت coroutines یک فصل اختصاصی دارد که نحوهٔ استفاده از آن را شرح می‌دهد.

    از آنجا که این مستندات به قابلیت‌های ناپایدار مربوط است، هیچ تضمینی نمی‌دهیم که مطالب آن دقیق یا به‌روز باشد. این مستندات با بهترین تلاش ممکن تهیه می‌شود. هر صفحه پیوندی به مسئلهٔ ردیابی (tracking issue) خود دارد که آخرین پیشرفت‌ها در آن آمده است؛ بهتر است آن‌ها را نیز بررسی کنید.
