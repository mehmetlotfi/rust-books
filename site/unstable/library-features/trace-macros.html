    trace_macros

    مسئلهٔ پیگیری (tracking issue) این ویژگی: #29598.

    با trace_macros می‌توانید گسترش (expansion) ماکروها را در کد خود ردیابی کنید.

    مثال‌ها

    #![feature(trace_macros)]

fn main() {
    trace_macros!(true);
    println!("Hello, Rust!");
    trace_macros!(false);
}
