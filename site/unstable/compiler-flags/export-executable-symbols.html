    export-executable-symbols

    مسئله‌ی پیگیری (tracking issue) این قابلیت: #84161.

    پرچم کامپایلر -Zexport-executable-symbols باعث می‌شود rustc نمادها (symbols) را از فایل‌های اجرایی صادر (export) کند. فایل دودویی حاصل قابل اجراست، اما می‌توان از آن به‌عنوان کتابخانه‌ی پویا هم استفاده کرد. این برای تعامل با برنامه‌های نوشته‌شده به زبان‌های دیگر، به‌ویژه زبان‌هایی با محیط اجرا (runtime) مانند Java یا Lua، مفید است.

    برای مثال در ویندوز:

    #[no_mangle]
fn my_function() -> usize {
    return 42;
}

fn main() {
    println!("Hello, world!");
}

    یک cargo build استاندارد یک فایل .exe بدون دایرکتوری صادرات (export directory) تولید می‌کند. وقتی پرچم export-executable-symbols اضافه شود

    export RUSTFLAGS="-Zexport-executable-symbols"
cargo build

    فایل دودویی یک دایرکتوری صادرات با این توابع خواهد داشت:

    The Export Tables (interpreted .edata section contents)

...

[Ordinal/Name Pointer] Table
    [   0] my_function
    [   1] main

    (خروجی objdump -x روی فایل دودویی)

    توجه کنید که ویژگی #[no_mangle] الزامی است. بدون آن، نماد صادر نمی‌شود.

    معادل این پرچم در کامپایلرهای C و C++ حاشیه‌نویسی __declspec(dllexport) یا پرچم لینکر -rdynamic است.
