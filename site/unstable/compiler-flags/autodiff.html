    autodiff

    issue ردیابی این قابلیت #124509 است.

    این قابلیت به شما اجازه می‌دهد توابع را با مشتق‌گیری خودکار (automatic differentiation) مشتق بگیرید. برای تنظیم رفتار قابلیت autodiff، پرچم کامپایلر -Zautodiff=<options> را به کار ببرید. چند گزینه را می‌توان با کاما از هم جدا کرد.

    نحو

    rustc -Z autodiff=Enable[,options]

    که در آن options می‌تواند یکی از این‌ها باشد:

    • Enable - پرچم لازم برای فعال‌سازی autodiff
    • PrintTA - چاپ اطلاعات تحلیل نوع (Type Analysis)
    • PrintTAFn=<fn_name> - چاپ اطلاعات تحلیل نوع برای یک تابع مشخص (ترکیب آن با no_mangle را در نظر بگیرید)
    • PrintAA - چاپ اطلاعات تحلیل فعالیت (Activity Analysis)
    • PrintPerf - چاپ هشدارهای کارایی از Enzyme
    • PrintSteps - چاپ همهٔ تبدیل‌های میانی
    • PrintModBefore - چاپ کل ماژول، پیش از اجرای بهینه‌سازی‌ها
    • PrintModAfter - چاپ ماژول پس از آن‌که Enzyme همه‌چیز را مشتق گرفت
    • LooseTypes - ابزار کمکی اشکال‌زدایی Enzyme برای نوع‌های سهل‌گیرانه (می‌تواند گرادیان نادرست تولید کند)
    • Inline - اجرای inlining مخصوص Enzyme
    • RuntimeActivity - امکان تعیین فعالیت در زمان اجرا

    مثال‌ها

    # Enable autodiff via cargo, assuming `enzyme` being a toolchain that supports autodiff
"RUSTFLAGS=-Zautodiff=Enable" cargo +enzyme build

# Enable autodiff directly via rustc
rustc -Z autodiff=Enable

# Print TypeAnalysis updates for the function `foo`, as well as Activity Analysis for all differentiated code.
rustc -Z autodiff=Enable,PrintTAFn=foo,PrintAA
