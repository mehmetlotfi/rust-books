    self-profile-events

    پرچم کامپایلر -Zself-profile-events مشخص می‌کند وقتی self-profiler از طریق پرچم -Zself-profile فعال شده است، چه رویدادهایی ثبت شوند.

    این پرچم فهرستی از انواع رویداد را می‌گیرد که با ویرگول از هم جدا شده‌اند.

    برای مثال:

    $ rustc -Zself-profile -Zself-profile-events=default,args

    انواع رویداد

    • query-provider

      • هر query‌ای را که کامپایلر به‌صورت داخلی استفاده می‌کند ردیابی می‌کند.

    • generic-activity

      • بخش‌های دیگری از کامپایلر را که سیستم query پوشش نمی‌دهد ردیابی می‌کند.

    • query-cache-hit

      • اطلاعات ردیابی‌ای اضافه می‌کند که ثبت می‌کند چه زمانی کش query در حافظه «پیدا» (hit) شده و لازم نبوده queryِ کش‌شده دوباره اجرا شود.
      • به‌طور پیش‌فرض غیرفعال است، چون حجم فایل ردیابی را به‌طور چشمگیری افزایش می‌دهد.

    • query-blocked

      • زمانی را ردیابی می‌کند که یک query می‌خواهد اجرا شود، اما منتظر می‌ماند تا نخ دیگری که همان query را اجرا می‌کند کارش تمام شود.
      • مسدود شدن query فقط زمانی رخ می‌دهد که کامپایلر با پشتیبانی از حالت موازی ساخته شده باشد.

    • incr-cache-load

      • زمانی را ردیابی می‌کند که صرف بارگذاری و deserialize کردن نتایج query از کش روی دیسک در کامپایل افزایشی (incremental) می‌شود.

    • query-keys

      • نمایشی سریال‌شده از کلید هر query را به داده‌های ردیابی اضافه می‌کند.
      • به‌طور پیش‌فرض غیرفعال است، چون حجم فایل ردیابی را به‌طور چشمگیری افزایش می‌دهد.

    • function-args

      • داده‌های ردیابی بیشتری به برخی رویدادهای generic-activity اضافه می‌کند.
      • برای همسانی با query-keys به‌طور پیش‌فرض غیرفعال است.

    • llvm

      • اطلاعات ردیابی دربارهٔ passهای LLVM و تولید کد را اضافه می‌کند.
      • به‌طور پیش‌فرض غیرفعال است، چون حجم فایل ردیابی را به‌طور چشمگیری افزایش می‌دهد.

    مترادف‌های رویداد

    • none

      • همهٔ رویدادها را غیرفعال می‌کند. معادل غیرفعال بودن self-profiler است.

    • default

      • مجموعهٔ پیش‌فرض رویدادها که میان ارائهٔ داده‌های ردیابی دقیق و سربار اضافی روی کامپایل توازن برقرار می‌کند.

    • args

      • معادل query-keys و function-args است.

    • all

      • همهٔ رویدادها را فعال می‌کند.

    مثال‌ها

    پروفایلر را فعال کنید و مجموعهٔ پیش‌فرض رویدادها را ثبت کنید (هر دو دستور معادل‌اند):

    $ rustc -Zself-profile
$ rustc -Zself-profile -Zself-profile-events=default

    پروفایلر را فعال کنید و رویدادهای پیش‌فرض را همراه با آرگومان‌هایشان ثبت کنید:

    $ rustc -Zself-profile -Zself-profile-events=default,args
