    min-function-alignment

    issue پیگیری این قابلیت: https://github.com/rust-lang/rust/issues/82232.

    پرچم -Zmin-function-alignment=<align> کمینه‌ی تراز (alignment) توابعی را که برایشان کد تولید می‌شود مشخص می‌کند. مقدار align باید توانی از 2 باشد و مقادیر دیگر رد می‌شوند.

    توجه کنید که برای اعمال این کمینه‌ی تراز بر توابع کتابخانه‌ی استاندارد، -Zbuild-std (یا مشابه آن) لازم است. به‌طور پیش‌فرض این توابع از پیش کامپایل‌شده عرضه می‌شوند و ترازشان پرچم min-function-alignment را رعایت نمی‌کند.

    این پرچم معادل موارد زیر است:

    • -fmin-function-alignment برای GCC
    • -falign-functions برای Clang

    تراز مشخص‌شده یک کمینه است. با استفاده از قابلیت align(...) و حاشیه‌نویسی تابع با attribute به‌صورت #[align(<align>)] می‌توان برای توابع خاص تراز بالاتری تعیین کرد. اگر مقدار attribute از مقداری که به min-function-alignment داده شده کمتر باشد، نادیده گرفته می‌شود.

    دو حالت مرزی دیگر برای این پرچم وجود دارد:

    • هدف‌ها برای توابع کمینه‌ی ترازی دارند (مثلاً روی x86_64 کمترین مقداری که LLVM تولید می‌کند ۱۶ بایت است). مقدار min-function-alignment کمتر از کمینه‌ی هدف هیچ اثری ندارد.
    • بیشینه‌ی ترازی که Rust (و LLVM) پشتیبانی می‌کند 2^29 است. تلاش برای تنظیم مقدار بالاتر به خطا می‌انجامد.
