    گزینه‌های --extern

    • مسئله‌ی پیگیری برای اصلاح‌کننده‌های crate در --extern: #98405
    • مسئله‌ی پیگیری برای noprelude: #98398
    • مسئله‌ی پیگیری برای priv: #98399
    • مسئله‌ی پیگیری برای nounused: #98400
    • مسئله‌ی پیگیری برای force: #111302

    رفتار پرچم --extern را می‌توان با گزینه‌های noprelude، priv یا nounused تغییر داد.

    این یک قابلیت ناپایدار است، بنابراین برای فعال‌کردن آن باید -Zunstable-options را بدهید.

    مثال‌ها

    از نسخه‌ی ساخت خودتان از crate با نام core استفاده کنید.

    rustc main.rs -Z unstable-options --extern noprelude:core=libcore.rlib

    برای استفاده از چند گزینه، آن‌ها را با کاما جدا کنید:

    rustc main.rs -Z unstable-options --extern noprelude,priv,nounused:mydep=mydep.rlib

    گزینه‌ها

    • noprelude: crate را به prelude خارجی اضافه نکن. در صورت استفاده، باید با extern crate وارد (import) شود. پروژه‌ی build-std از این گزینه برای شبیه‌سازی سازگاری با crateهایی که فقط در sysroot هستند استفاده می‌کند.
    • priv: crate را به‌عنوان وابستگی خصوصی برای lint با نام exported_private_dependencies علامت‌گذاری کن.
    • nounused: هشدارهای unused-crate-dependencies را برای این crate خاموش کن.
    • force: crate را طوری حل (resolve) کن که گویی استفاده شده است، حتی اگر استفاده نشده باشد. این را می‌توان برای برآوردن الزامات نشست کامپایل مانند وجود یک تخصیص‌دهنده (allocator) یا کنترل‌کننده‌ی panic به کار برد.
