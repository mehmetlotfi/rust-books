    annotate-moves

    issue ردیابی این قابلیت #148197 است.

    پرچم -Z annotate-moves حاشیه‌نویسی (annotation) عملیات move و copy تولیدشده توسط کامپایلر را فعال می‌کند و آن‌ها را برای اشکال‌زدایی کارایی، در profilerها و stack traceها قابل مشاهده می‌سازد.

    وقتی این پرچم فعال باشد، کامپایلر اطلاعات debug را طوری دستکاری می‌کند که عملیات move و copy حجیم مثل فراخوانی‌های inline‌شدهٔ core::profiling::compiler_move و core::profiling::compiler_copy به نظر برسند. هیچ فراخوانی تابع واقعی تولید نمی‌شود؛ این صرفاً یک تبدیل روی اطلاعات debug است که عملیات پرهزینهٔ حافظه را در profilerها و stack traceها نمایان می‌کند.

    نحو

    rustc -Z annotate-moves[=<value>]

    که در آن <value> می‌تواند یکی از این‌ها باشد:

    • یک مقدار بولی: true، false، yes، no، on، off
    • یک عدد: آستانهٔ اندازه بر حسب بایت (مثلاً 128)
    • حذف‌شده: با آستانهٔ پیش‌فرض (۶۵ بایت) فعال می‌شود

    گزینه‌ها

    • -Z annotate-moves یا -Z annotate-moves=true: فعال‌سازی با حد اندازهٔ پیش‌فرض
    • -Z annotate-moves=false: غیرفعال‌سازی حاشیه‌نویسی
    • -Z annotate-moves=N: فعال‌سازی با حد اندازهٔ دلخواه N بایت

    مثال‌ها

    # Enable annotation with default threshold (65 bytes)
rustc -Z annotate-moves main.rs

# Enable with custom 128-byte threshold
rustc -Z annotate-moves=128 main.rs

# Only annotate very large moves (1KB+)
rustc -Z annotate-moves=1024 main.rs

# Explicitly disable
rustc -Z annotate-moves=false main.rs

    رفتار

    حاشیه‌نویسی فقط برای موارد زیر اعمال می‌شود:

    • نوع‌هایی که اندازه‌شان برابر یا بزرگ‌تر از آستانهٔ مشخص‌شده است
    • نوع‌های غیرفوری (non-immediate)، یعنی آن‌هایی که memcpy تولید می‌کنند
    • عملیاتی که واقعاً داده را move یا copy می‌کنند (نه نوع‌های ZST)

    stack traceها این عملیات را به این شکل نشان می‌دهند:

    0: memcpy
1: core::profiling::compiler_move::<MyLargeStruct, 148>
2: my_function

    توابع compiler_move و compiler_copy دو پارامتر جنریک دارند: نوعی که move/copy می‌شود و اندازهٔ آن بر حسب بایت. این اندازه با size_of::<T>() یکسان است و فقط برای این آمده که بتوان فوراً فهمید copy چقدر بزرگ است.

    توجه کنید که این کار به کدگذاری درست v0 mangling نیاز دارد؛ legacy mangling این توابع را با نوع و اندازهٔ مشخص جایگزین نمی‌کند.

    مثال

    #[derive(Clone)]
struct LargeData {
    buffer: [u8; 1000],
}

fn example() {
    let data = LargeData { buffer: [0; 1000] };
    let copy = data.clone(); // Shows as compiler_copy in profiler
    let moved = data;        // Shows as compiler_move in profiler
}

    سربار

    این پرچم بر کد تولیدشده تأثیری ندارد و فقط debuginfo اضافه می‌کند. سربار آن معمولاً بسیار کم است؛ روی خود rustc، حد پیش‌فرض ۶۵ بایت حدود ۰٫۰۵۵٪ به اندازهٔ باینری می‌افزاید.
