    function-return

    مسئله‌ی پیگیری (tracking issue) این قابلیت: https://github.com/rust-lang/rust/issues/116853.

    گزینه‌ی -Zfunction-return نحوه‌ی تبدیل بازگشت از تابع‌ها را کنترل می‌کند.

    این گزینه معادل -mfunction-return در Clang و GCC است. هسته‌ی لینوکس از آن برای ساخت‌های RETHUNK استفاده می‌کند. برای جزئیات، به LLVM commit 2240d72f15f3 (“[X86] initial -mfunction-return=thunk-extern support”) مراجعه کنید که این قابلیت را معرفی کرد.

    مقادیر پشتیبانی‌شده برای این گزینه:

    • keep: بازگشت از تابع‌ها را تبدیل نکن.
    • thunk-extern: بازگشت از تابع‌ها (ret) را به پرش‌هایی (jmp) به یک نماد خارجی به نام __x86_return_thunk تبدیل کن.

    مانند Clang، مقادیر thunk و thunk-inline در GCC پشتیبانی نمی‌شوند.

    فقط x86 و مدل‌های کد غیربزرگ پشتیبانی می‌شوند.
