    report-time

    issue ردیابی این قابلیت: #64888

    قابلیت report-time امکان گزارش زمان اجرای آزمون‌های تولیدشده از طریق libtest را اضافه می‌کند.

    این یک قابلیت ناپایدار است، بنابراین برای کار کردن آن باید -Zunstable-options را بدهید.

    نمونهٔ دستور استفاده:

    ./test_executable -Zunstable-options --report-time

    گزینه‌های موجود:

    --report-time
                Show execution time of each test.
                Threshold values for colorized output can be
                configured via
                `RUST_TEST_TIME_UNIT`, `RUST_TEST_TIME_INTEGRATION`
                and
                `RUST_TEST_TIME_DOCTEST` environment variables.
                Expected format of environment variable is
                `VARIABLE=WARN_TIME,CRITICAL_TIME`.
                Not available for --format=terse
--ensure-time
                Treat excess of the test execution time limit as
                error.
                Threshold values for this option can be configured via
                `RUST_TEST_TIME_UNIT`, `RUST_TEST_TIME_INTEGRATION`
                and
                `RUST_TEST_TIME_DOCTEST` environment variables.
                Expected format of environment variable is
                `VARIABLE=WARN_TIME,CRITICAL_TIME`.
                `CRITICAL_TIME` here means the limit that should not be
                exceeded by test.

    نمونهٔ قالب متغیر محیطی:

    RUST_TEST_TIME_UNIT=100,200

    که در آن 100 نمایانگر زمان هشدار و 200 نمایانگر زمان بحرانی است.
