    hint-mostly-unused

    این پرچم به کامپایلر القا می‌کند که بیشتر بخش‌های crate احتمالاً استفاده نخواهد شد. کامپایلر می‌تواند عملکرد خود را بر پایه‌ی این فرض بهینه کند تا سریع‌تر کامپایل کند. این فقط یک راهنمایی (hint) است و رفتار خاصی را تضمین نمی‌کند.

    اگر این گزینه روی یک وابستگی بزرگ اعمال شود که بیشتر بخش‌های آن استفاده نمی‌شود، می‌تواند کامپایل را به‌طور قابل‌توجهی سریع‌تر کند. در موارد دیگر ممکن است این پرچم کامپایل را کند کند.

    در حال حاضر، این گزینه باعث می‌شود کامپایلر تولید کد را تا حد ممکن برای تابع‌های crate به تعویق بیندازد، تا زمانی که crateهای بعدی آن تابع‌ها را فراخوانی کنند. برای تابع‌هایی که هرگز فراخوانی نشوند، هرگز کدی تولید نمی‌شود. برای مثال، اگر یک crate هزاران تابع ارائه کند، اما فقط چند تا از آن‌ها فراخوانی شوند، این پرچم باعث می‌شود کامپایلر فقط برای تابع‌های فراخوانی‌شده کد تولید کند. (این از همان سازوکارهای درون‌خطی‌سازی (inlining) تابع‌ها میان crateها استفاده می‌کند.) این گزینه روی تابع‌های extern یا تابع‌های علامت‌گذاری‌شده با #[inline(never)] اثری ندارد.

    برای امتحان‌کردن این پرچم روی یکی از وابستگی‌های درخت وابستگی‌ها، از قابلیت profile-rustflags در cargo نایتلی (nightly) استفاده کنید:

    cargo-features = ["profile-rustflags"]

# ...
[dependencies]
mostly-unused-dependency = "1.2.3"

[profile.release.package.mostly-unused-dependency]
rustflags = ["-Zhint-mostly-unused"]
