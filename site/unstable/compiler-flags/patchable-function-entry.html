    patchable-function-entry

    پرچم کامپایلر -Z patchable-function-entry=total_nops,prefix_nops,record_section، -Z patchable-function-entry=total_nops,prefix_nops یا -Z patchable-function-entry=total_nops ورودی توابع را با ‘total_nops’ دستور nop پر می‌کند، به‌طوری که نقطهٔ ورود تابع به اندازهٔ ‘prefix_nops’ دستور nop جابه‌جا می‌شود. در شکل سوم، مقدار پیش‌فرض ‘prefix_nops’ برابر 0 است. record_section می‌تواند بخش مشخصی از لینکر را برای قرار دادن رکورد ورودی تعیین کند؛ مقدار پیش‌فرض __patchable_function_entries است.

    برای مثال، -Z patchable-function-entry=3,2 این خروجی را تولید می‌کند:

    nop
nop
function_label:
nop
//Actual function code begins here

    این پرچم برای hotpatching، به‌ویژه در هستهٔ لینوکس، به کار می‌رود. آرگومان‌های پرچم بر اساس پرچم -fpatchable-function-entry طراحی شده‌اند که برای هر دو Clang و gcc تعریف شده است و هدف آن ایجاد همان اثر است.
