    rustc_attrs

    این ویژگی issue ردیابی ندارد و بنابراین داخلی کامپایلر است و برای استفادهٔ عمومی در نظر گرفته نشده است.

    توجه: rustc_attrs بسیاری از attributeهای داخلی rustc را فعال می‌کند و این صفحه فقط به چند مورد از آن‌ها می‌پردازد.

    ویژگی rustc_attrs امکان اشکال‌زدایی چیدمان نوع‌ها (type layout) در rustc را با استفاده از #[rustc_dump_layout(...)] فراهم می‌کند تا چیدمان در زمان کامپایل بررسی شود (حتی با cargo check هم کار می‌کند)؛ این روشی جایگزین برای rustc -Z print-type-sizes است که خروجی بسیار پرحجم‌تری دارد.

    گزینه‌هایی که #[rustc_dump_layout(...)] ارائه می‌دهد عبارت‌اند از backend_repr، align، debug، homogeneous_aggregate و size. توجه کنید که این فقط روی نوع‌های دارای اندازهٔ مشخص و بدون جنریک کار می‌کند.

    مثال‌ها

    #![feature(rustc_attrs)]

#[rustc_dump_layout(backend_repr, size)]
pub enum X {
    Y(u8, u8, u8),
    Z(isize),
}
