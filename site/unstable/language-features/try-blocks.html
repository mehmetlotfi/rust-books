    try_blocks

    issue ردیابی این ویژگی: #154391

    ویژگی try_blocks از بلوک‌های try پشتیبانی می‌کند. یک بلوک try حوزهٔ جدیدی ایجاد می‌کند که می‌توان در آن از عملگر ? استفاده کرد.

    #![feature(try_blocks)]

use std::num::ParseIntError;

let result = try {
    "1".parse::<i32>()?
        + "2".parse::<i32>()?
        + "3".parse::<i32>()?
};
assert_eq!(result, Ok(6));

let result = try {
    "1".parse::<i32>()?
        + "foo".parse::<i32>()?
        + "3".parse::<i32>()?
};
assert!(result.is_err());
