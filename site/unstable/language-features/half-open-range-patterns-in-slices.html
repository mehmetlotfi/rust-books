    half_open_range_patterns_in_slices

    مسئلهٔ پیگیری (tracking issue) این ویژگی: #67264 این ویژگی بخشی از آیندهٔ ویژگی exclusive_range_pattern است که در #37854 پیگیری می‌شود.

    این ویژگی امکان استفاده از الگوهای بازهٔ نیمه‌باز سطح بالا را در slice‌ها فراهم می‌کند.

    #![feature(half_open_range_patterns_in_slices)]

fn main() {
    let xs = [13, 1, 5, 2, 3, 1, 21, 8];
    let [a @ 3.., b @ ..3, c @ 4..6, ..] = xs else { return; };
}

    توجه کنید که اگر الگوها میان پرانتز قرار بگیرند، به این ویژگی نیازی نیست.

    fn main() {
    let xs = [13, 1];
    let [(a @ 3..), c] = xs else { return; };
}
