    unboxed_closures

    issue ردیابی این ویژگی #29625 است

    همچنین ببینید: fn_traits

    ویژگی unboxed_closures به شما اجازه می‌دهد تابع‌هایی با ABI به نام "rust-call" بنویسید که برای پیاده‌سازی خانوادهٔ traitهای Fn* لازم است. تابع‌های "rust-call" باید دقیقاً یک آرگومان (غیر از self) داشته باشند، که تاپلی است که فهرست آرگومان‌ها را نشان می‌دهد.

    #![feature(unboxed_closures)]

extern "rust-call" fn add_args(args: (u32, u32)) -> u32 {
    args.0 + args.1
}

fn main() {}
