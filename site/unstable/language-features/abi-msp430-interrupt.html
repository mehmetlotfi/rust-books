    abi_msp430_interrupt

    issue ردیابی این قابلیت: #38487

    در معماری MSP430، کنترل‌کننده‌های وقفه (interrupt handler) قرارداد فراخوانی ویژه‌ای دارند. می‌توانید از ABI با نام "msp430-interrupt" استفاده کنید تا کامپایلر قرارداد فراخوانی درست را روی کنترل‌کننده‌های وقفه‌ای که تعریف می‌کنید اعمال کند.

    #![feature(abi_msp430_interrupt)]
#![no_std]

// Place the interrupt handler at the appropriate memory address
// (Alternatively, you can use `#[used]` and remove `pub` and `#[no_mangle]`)
#[link_section = "__interrupt_vector_10"]
#[no_mangle]
pub static TIM0_VECTOR: extern "msp430-interrupt" fn() = tim0;

// The interrupt handler
extern "msp430-interrupt" fn tim0() {
    // ..
}
    $ msp430-elf-objdump -CD ./target/msp430/release/app
