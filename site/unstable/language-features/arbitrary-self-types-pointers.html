    arbitrary_self_types_pointers

    issue ردیابی این قابلیت: [#44874]

    این قابلیت، قابلیت arbitrary self types را گسترش می‌دهد تا متدها بتوانند self را به‌صورت اشاره‌گر دریافت کنند. برای مثال:

    #![feature(arbitrary_self_types_pointers)]

struct A;

impl A {
    fn m(self: *const Self) {}
}

fn main() {
    let a = A;
    let a_ptr: *const A = &a as *const A;
    a_ptr.m();
}

    به‌طور کلی این کار توصیه نمی‌شود: به‌نظر می‌رسد روش بهتر این است که اشاره‌گرهای خام را در یک wrapper از نوع newtype قرار دهید که صفت core::ops::Receiver را پیاده‌سازی می‌کند؛ آن‌وقت «فقط» به قابلیت arbitrary_self_types نیاز دارید. برای مثال:

    #![feature(arbitrary_self_types)]
#![allow(dead_code)]

struct A;

impl A {
    fn m(self: Wrapper<Self>) {} // can extract the pointer and do
        // what it needs
}

struct Wrapper<T>(*const T);

impl<T> core::ops::Receiver for Wrapper<T> {
    type Target = T;
}

fn main() {
    let a = A;
    let a_ptr: *const A = &a as *const A;
    let a_wrapper = Wrapper(a_ptr);
    a_wrapper.m();
}
