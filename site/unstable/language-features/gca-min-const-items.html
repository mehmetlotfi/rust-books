    gca_min_const_items

    MVP آرگومان‌های const جنریک (مسیرها به آیتم‌های const مستقیم و نوع‌های اولیه) را فعال می‌کند.

    issue ردیابی این قابلیت: #132980

    هشدار: این قابلیت ناقص است؛ طراحی و نحو آن ممکن است تغییر کند.

    این قابلیت به‌عنوان جایگزینی حداقلی برای generic_const_exprs عمل می‌کند که زیرمجموعهٔ کوچک‌تری از امکانات را مجاز می‌کند و رویکرد پیاده‌سازی متفاوتی دارد. این قابلیت عمداً محدودکننده‌تر است، که به پرهیز از موارد مرزی‌ای کمک می‌کند که پیاده‌سازی درست generic_const_exprs را دشوار می‌کنند. برای جزئیات بیشتر پیشینهٔ قابلیت را ببینید.

    قابلیت‌های مرتبط: gca_macroless_args، gca_const_items، generic_const_items.

    ماکروی gca!

    این قابلیت یک ماکروی جدید معرفی می‌کند: gca!.

    وقتی یک عبارت به‌عنوان آرگومان generic به کار می‌رود، معمولاً به‌صورت یک «anon const» پایین‌آورده (lower) می‌شود، یعنی عبارتی که برای سیستم نوع مات (opaque) است و نمی‌تواند generic داشته باشد. استفاده از gca! به‌جای آن، عبارت را «به‌طور مستقیم» نمایش می‌دهد، یعنی بدون anon const، به شکلی که برای سیستم نوع قابل مشاهده است.

    (توجه کنید که مسیرهای ساده به پارامترهای generic همیشه بدون gca! به‌طور مستقیم نمایش داده می‌شوند، زیرا این کار هم‌اکنون روی stable کار می‌کند)

    برای غیرفعال کردن لزوم نوشتن gca!، gca_macroless_args را ببینید.

    آیتم‌های const مستقیم

    این قابلیت نوع جدیدی از آیتم را معرفی می‌کند: constهایی با سمت راست gca!. constهایی که سمت راست مستقیم دارند می‌توانند در بافت‌های نوع به کار روند، مثلاً:

    #![allow(incomplete_features)]
#![feature(gca_min_const_items)]

const X: usize = core::gca!(1);
const Y: usize = 1;

struct Foo {
    good_arr: [(); core::gca!(X)], // Allowed
    bad_arr: [(); core::gca!(Y)], // Will not compile
}

    نمونه‌ها

    #![allow(incomplete_features)]
#![feature(gca_min_const_items)]

trait Bar {
    #[rustc_always_gca]
    const VAL: usize;
    #[rustc_always_gca]
    const VAL2: usize;
}

struct Baz;

impl Bar for Baz {
    const VAL: usize = core::gca!(2);
    const VAL2: usize = core::gca!(const { Self::VAL * 2 });
}

struct Foo<B: Bar> {
    arr1: [usize; core::gca!(B::VAL)],
    arr2: [usize; core::gca!(B::VAL2)],
}

    توجه کنید که با generic_const_exprs همین نمونه به شکل زیر خواهد بود:

    #![allow(incomplete_features)]
#![feature(generic_const_exprs)]

trait Bar {
    const VAL: usize;
    const VAL2: usize;
}

struct Baz;

impl Bar for Baz {
    const VAL: usize = 2;
    const VAL2: usize = const { Self::VAL * 2 };
}

struct Foo<B: Bar>
where
    [(); B::VAL]:,
    [(); B::VAL2]:,
{
    arr1: [usize; B::VAL],
    arr2: [usize; B::VAL2],
}

    استفاده از تابع‌های const مجاز است:

    #![allow(incomplete_features)]
#![feature(gca_min_const_items)]

const VAL: usize = 1;

const fn inc(val: usize) -> usize {
    val + 1
}

const INC: usize = core::gca!(const { inc(VAL) });

const ARR: [usize; INC] = [0; INC];
