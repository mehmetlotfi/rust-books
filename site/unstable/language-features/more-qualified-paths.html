    more_qualified_paths

    ویژگی more_qualified_paths برای فعال کردن استفاده از مسیرهای مشخص‌شده (qualified paths) در الگوها به کار می‌رود.

    issue ردیابی این ویژگی: #86935.

    مثال

    #![feature(more_qualified_paths)]

fn main() {
    // destructure through a qualified path
    let <Foo as A>::Assoc { br } = StructStruct { br: 2 };
}

struct StructStruct {
    br: i8,
}

struct Foo;

trait A {
    type Assoc;
}

impl A for Foo {
    type Assoc = StructStruct;
}
