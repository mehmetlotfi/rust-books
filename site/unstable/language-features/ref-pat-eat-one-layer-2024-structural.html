    ref_pat_eat_one_layer_2024_structural

    issue ردیابی این ویژگی: #123076

    این ویژگی ناقص است و هنوز برای استفادهٔ عمومی در نظر گرفته نشده است.

    این ویژگی، ارگونومی match آزمایشی و وابسته به edition را پیاده‌سازی می‌کند که برای گنجاندن در Rust در دست بررسی است و اجازه می‌دهد الگوهای & در جاهای بیشتری به کار روند. برای مثال:

    #![feature(ref_pat_eat_one_layer_2024_structural)]
#![allow(incomplete_features)]

// Tests type equality in a way that avoids coercing `&&T` or `&mut T` to `&T`.
trait Eq<T> {}
impl<T> Eq<T> for T {}
fn has_type<T>(_: impl Eq<T>) {}

// `&` can match against a `ref` binding mode instead of a reference type:
let (x, &y) = &(0, 1);
has_type::<&u8>(x);
has_type::<u8>(y);

// `&` can match against `&mut` references:
let &z = &mut 2;
has_type::<u8>(z);

    برای جزئیات، به قواعد نوع‌دهی متناظر برای editionهای 2021 و قبل‌تر و برای editionهای 2024 و بعدتر مراجعه کنید. برای اطلاعات بیشتر دربارهٔ حالت‌های اتصال (binding mode)، به مرجع Rust مراجعه کنید.

    برای ارگونومی match آزمایشی جایگزین، به ویژگی ref_pat_eat_one_layer_2024 مراجعه کنید.
