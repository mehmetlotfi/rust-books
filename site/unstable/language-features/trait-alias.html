    trait_alias

    issue ردیابی این ویژگی: #41517

    ویژگی trait_alias پشتیبانی از نام مستعار صفت (trait alias) را اضافه می‌کند. این نام‌های مستعار امکان می‌دهند برای یک یا چند صفت یک نام مستعار ساخته شود (در حال حاضر فقط یک صفت معمولی به‌علاوهٔ هر تعداد auto-trait)، و در هر جایی که صفت‌ها معمولاً به عنوان قید (bound) یا شیء صفت به کار می‌روند استفاده شود.

    #![feature(trait_alias)]

trait Foo = std::fmt::Debug + Send;
trait Bar = Foo + Sync;

// Use trait alias as bound on type parameter.
fn foo<T: Foo>(v: &T) {
    println!("{:?}", v);
}

pub fn main() {
    foo(&1);

    // Use trait alias for trait objects.
    let a: &dyn Bar = &123;
    println!("{:?}", a);
    let b = Box::new(456) as Box<dyn Foo>;
    println!("{:?}", b);
}
