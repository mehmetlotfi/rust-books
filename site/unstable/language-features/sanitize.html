    sanitize

    issue ردیابی این ویژگی: #39699

    attribute به نام sanitize را می‌توان برای غیرفعال یا فعال کردن گزینشی ابزارسازی (instrumentation) sanitizer در تابعی که به آن افزوده شده است به کار برد. این کار می‌تواند برای موارد زیر مفید باشد: پرهیز از سربار ابزارسازی در تابعی که عملکرد در آن حیاتی است، یا پرهیز از ابزارسازی کدی که ساختارهایی دارد که sanitizer مورد نظر از آن‌ها پشتیبانی نمی‌کند.

    اثر دقیق این حاشیه‌نویسی به sanitizer مورد استفاده بستگی دارد. برای مثال، با sanitize(thread = "off")، thread sanitizer دیگر عملیات ذخیره / بارگذاری غیراتمی را ابزارسازی نمی‌کند، اما عملیات اتمی را ابزارسازی می‌کند تا از گزارش‌های مثبت کاذب جلوگیری شود و ردهای پشته (stack trace) معنادار ارائه گردد.

    این attribute پیش‌تر no_sanitize نام داشت.

    مثال‌ها

    #![feature(sanitize)]

#[sanitize(address = "off")]
fn foo() {
  // ...
}

    همچنین می‌توان sanitizerها را برای ماژول‌های کامل غیرفعال کرد و برای آیتم‌ها یا تابع‌های منفرد فعال کرد.

    #![feature(sanitize)]

#[sanitize(address = "off")]
mod foo {
  fn unsanitized() {
    // ...
  }

  #[sanitize(address = "on")]
  fn sanitized() {
    // ...
  }
}

    این attribute برای بلوک‌های impl هم قابل استفاده است.

    #![feature(sanitize)]

trait MyTrait {
  fn foo(&self);
  fn bar(&self);
}

#[sanitize(address = "off")]
impl MyTrait for () {
  fn foo(&self) {
    // ...
  }

  #[sanitize(address = "on")]
  fn bar(&self) {
    // ...
  }
}
