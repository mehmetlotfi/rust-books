    asm_goto_with_outputs

    issue ردیابی این قابلیت: #119364

    این قابلیت اجازه می‌دهد عملوندهای برچسب (label) همراه با عملوندهای خروجی (output) به کار روند.

    مثال:

    
unsafe {
    let a: usize;
    asm!(
        "mov {}, 1"
        "jmp {}",
        out(reg) a,
        label {
            println!("Jumped from asm {}!", a);
        }
    );
}

    عملوندهای خروجی پیش از اجرای بلوک‌های برچسب مقداردهی می‌شوند.

    → asm-experimental-regasm-unwind ←
