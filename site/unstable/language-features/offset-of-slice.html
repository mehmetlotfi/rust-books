    offset_of_slice

    issue ردیابی این ویژگی: #126151

    وقتی ویژگی offset_of_slice فعال باشد، ماکروی offset_of! را می‌توان برای تعیین آفست فیلدهایی به کار برد که نوعشان [T] است، یعنی یک slice با اندازهٔ پویا.

    به طور کلی، فیلدهایی که نوعشان اندازهٔ پویا دارد آفست معلوم در زمان کامپایل ندارند، چون تراز (alignment) معلوم در زمان کامپایل ندارند. اما [T] همان تراز T را دارد، بنابراین می‌توان به طور خاص اجازهٔ آن را داد.

    #![feature(offset_of_slice)]

#[repr(C)]
pub struct Struct {
    head: u32,
    tail: [u8],
}

fn main() {
    assert_eq!(std::mem::offset_of!(Struct, tail), 4);
}
