    import_trait_associated_functions

    مسئلهٔ پیگیری (tracking issue) این ویژگی: #134691

    این ویژگی امکان import کردن توابع و ثابت‌های وابسته (associated) از صفت‌ها (trait) و سپس استفاده از آن‌ها مانند آیتم‌های معمولی را فراهم می‌کند.

    #![feature(import_trait_associated_functions)]

use std::ops::Add::add;

fn main() {
    let numbers = vec![1, 2, 3, 4, 5, 6];
    let sum = numbers.into_iter().reduce(add); // instead of `.reduce(Add:add)`

    assert_eq!(sum, Some(21));
}
