    diagnostic_on_unmatched_args

    مسئلهٔ پیگیری (tracking issue) این ویژگی: #155642

    ویژگی diagnostic_on_unmatched_args attribute به نام #[diagnostic::on_unmatched_args(...)] را برای ماکروهای اعلانی (declarative) اضافه می‌کند. این attribute به تعریف ماکرو اجازه می‌دهد پس از آنکه همهٔ شاخه‌ها (arm) امتحان شدند، پیام‌های تشخیصی مربوط به شکست تطبیق را شخصی‌سازی کند؛ مانند فراخوانی‌های ناقص یا آرگومان‌های اضافیِ انتهایی.

    این attribute در حال حاضر برای ماکروهای اعلانی مانند macro_rules! و pub macro به کار می‌رود. فعلاً برای خطاهایی استفاده می‌شود که خودِ فرایند تطبیق ماکروی اعلانی تولید می‌کند؛ خطاهای تجزیه‌گر fragment همچنان از پیام‌های تشخیصی موجود خود استفاده می‌کنند.

    #![feature(diagnostic_on_unmatched_args)]

#[diagnostic::on_unmatched_args(
    message = "invalid arguments to {this} macro invocation",
    label = "expected a type and value here",
    note = "this macro expects a type and a value, like `pair!(u8, 0)`",
    note = "see <link/to/docs>",
)]
macro_rules! pair {
    ($ty:ty, $value:expr) => {};
}

pair!(u8);
