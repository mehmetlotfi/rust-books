    register_tool

    issue ردیابی این ویژگی: #66079

    ویژگی زبانی register_tool به کامپایلر اطلاع می‌دهد که attributeهای موجود در کد شما برای استفاده با ابزارهایی غیر از خود کامپایلر در نظر گرفته شده‌اند. این کار زمانی مفید است که کد شما بدون ابزار خارجی هم معنای مشخصی داشته باشد، اما با حضور آن ابزار قابلیت‌های اضافی فعال شوند.

    register_tool همچنین امکان پیکربندی سطح lintها را برای ابزارهای خارجی فراهم می‌کند.

    attributeهای ابزار فقط برای attributeهایی در نظر گرفته شده‌اند که می‌توان نادیده‌شان گرفت. اگر معنای کد شما با حضور attribute تغییر می‌کند، نباید از attribute ابزار استفاده کند (چون با هیچ چیز جز آن ابزار خارجی قابل کامپایل نیست و به نوعی یک fork از زبان به شمار می‌آید).

    #![register_tool(tool)] یک attribute است و فقط در ریشهٔ crate معتبر است. attributeهایی که از ابزار ثبت‌شده استفاده می‌کنند از نظر نحو معتبر بودن بررسی می‌شوند، و attributeهای lint نیز از نظر داشتن قالب معتبر بررسی می‌شوند. با این حال، کامپایلر نمی‌تواند معناشناسی (semantics) attribute را اعتبارسنجی کند و نمی‌تواند تشخیص دهد که lint پیکربندی‌شده در ابزار خارجی وجود دارد یا نه.

    از نظر معنایی، lintها و attributeهای clippy::*، rustdoc::* و rustfmt::* همگی طوری رفتار می‌کنند که گویی #![register_tool(clippy, rustdoc, rustfmt)] در ریشهٔ crate تزریق شده است، با این تفاوت که فضای نام rustdoc فقط برای lintها قابل استفاده است، نه برای attributeها. هنگام کامپایل با -Z unstable-features، lintهای rustc::* را نیز می‌توان استفاده کرد. مانند rustdoc، فضای نام rustc فقط با lintها قابل استفاده است، نه attributeها.

    اگر کامپایلر به lint/attributeای برخورد کند که فضای نامش یک ابزار ثبت‌شده نیست، خطا صادر می‌کند.

    فضای نام ابزارها نمی‌تواند تودرتو باشد؛ register_tool(main_tool::subtool) خطا است.

    مثال‌ها

    attributeهای ابزار:

    #![feature(register_tool)]
#![register_tool(c2rust)]

// Mark which C header file this module was generated from.
#[c2rust::header_src = "operations.h"]
pub mod operations_h {
    use std::ffi::c_int;

    // Mark which source line this struct was generated from.
    #[c2rust::src_loc = "11:0"]
    pub struct Point {
        pub x: c_int,
        pub y: c_int,
    }
}

    lintهای ابزار:

    #![feature(register_tool)]
#![register_tool(bevy)]
#![deny(bevy::duplicate_bevy_dependencies)]
