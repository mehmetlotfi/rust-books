    loop_match

    issue ردیابی این قابلیت: #132306

    attributeهای #[loop_match] و #[const_continue] را می‌توان برای بهبود تولید کد منطقی که با این شکل جور است به کار برد:

    loop {
    state = 'blk: {
        match state {
            State::A => {
                break 'blk State::B
            }
            State::B => { /* ... */ }
            /* ... */
        }
    }
}

    در اینجا خود حلقه را می‌توان با #[loop_match] علامت‌گذاری کرد، و هر break 'blk را با #[const_continue]، اگر مقدار در زمان کامپایل مشخص باشد:

    #[loop_match]
loop {
    state = 'blk: {
        match state {
            State::A => {
                #[const_continue]
                break 'blk State::B
            }
            State::B => { /* ... */ }
            /* ... */
        }
    }
}

    رفتار قابل‌مشاهده‌ی این حلقه دقیقاً همان رفتار بدون attributeهای اضافی است. تفاوت در خروجی تولیدشده است: به‌طور معمول، وقتی حالت A است، جریان کنترل از شاخه‌ی A به بالای حلقه برمی‌گردد و سپس به شاخه‌ی B می‌رود. با این attributeها، شاخه‌ی A بلافاصله به شاخه‌ی B می‌پرد.

    حذف این واسطه می‌تواند برای مصرف پشته و پیش‌بینی شاخه (branch prediction) مفید باشد، و با جداکردن آشکار مسیرهای جریان کنترلی که برنامه‌ی شما واقعاً از آن‌ها استفاده می‌کند، بهینه‌سازی‌های دیگر را ممکن می‌سازد.
