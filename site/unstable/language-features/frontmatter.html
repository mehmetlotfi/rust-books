    frontmatter

    مسئلهٔ پیگیری (tracking issue) این ویژگی: #136889

    ویژگی frontmatter اجازه می‌دهد یک بلوک فراداده (metadata) اضافی در بالای فایل‌ها قرار بگیرد تا ابزارهای خارجی از آن استفاده کنند. برای مثال، فایل‌های cargo-script می‌توانند از آن برای تعیین وابستگی‌ها استفاده کنند.

    #!/usr/bin/env -S cargo -Zscript
---
[dependencies]
libc = "0.2.172"
---
#![feature(frontmatter)]
mod libc { pub type c_int = i32; }

fn main() {
    let x: libc::c_int = 1i32;
}
