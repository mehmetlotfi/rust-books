    diagnostic_on_move

    مسئلهٔ پیگیری (tracking issue) این ویژگی: #154181

    ویژگی diagnostic_on_move استفاده از attribute به نام #[diagnostic::on_move] را ممکن می‌کند. این attribute باید روی تعریف struct، enum و union قرار بگیرد، هرچند قرار دادن آن در جاهای دیگر خطا محسوب نمی‌شود. این attribute یک راهنمایی برای کامپایلر است تا هرگاه نوع حاشیه‌نویسی‌شده در یک خطای borrowcheck دخیل باشد، پیام خطا را تکمیل کند.

    برای مثال، File به این شکل حاشیه‌نویسی شده است:

    #![feature(diagnostic_on_move)]

#[diagnostic::on_move(note = "you can use `File::try_clone` \
                             to duplicate a `File` instance")]
pub struct File {
    // ...
}

    وقتی سعی کنید از یک File پس از آنکه move شده استفاده کنید، کامپایلر مفیدانه دربارهٔ try_clone به شما اطلاع می‌دهد.

    پیام اصلی و برچسب (label) نیز قابل شخصی‌سازی هستند:

    #![feature(diagnostic_on_move)]

use std::marker::PhantomData;

#[diagnostic::on_move(
    message = "`{Self}` cannot be used multiple times",
    label = "this token may only be used once",
    note = "you can create a new `Token` with `Token::conjure()`"
)]
pub struct Token<'brand> {
    spooky: PhantomData<&'brand ()>,
}

impl Token<'_> {
    pub fn conjure<'u>() -> Token<'u> {
        Token {
            spooky: PhantomData,
        }
    }
}

    کاربر ممکن است سعی کند آن را این‌گونه استفاده کند:

    #![feature(diagnostic_on_move)]

use std::marker::PhantomData;

#[diagnostic::on_move(
    message = "`{Self}` cannot be used multiple times",
    label = "this token may only be used once",
    note = "you can create a new `Token` with `Token::conjure()`"
)]
pub struct Token<'brand> {
    spooky: PhantomData<&'brand ()>,
}

impl Token<'_> {
    pub fn conjure<'u>() -> Token<'u> {
        Token {
            spooky: PhantomData,
        }
    }
}
fn main() {
let token = Token::conjure();
let _ = (token, token);
}

    این کار به خطای زیر منجر می‌شود:
