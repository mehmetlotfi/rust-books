    custom_test_frameworks

    issue ردیابی این قابلیت: #50297

    قابلیت custom_test_frameworks امکان استفاده از #[test_case] و #![test_runner] را فراهم می‌کند. هر تابع، const یا static را می‌توان با #[test_case] حاشیه‌نویسی کرد تا (مانند #[test]) جمع‌آوری شود و به اجراکننده‌ی آزمون (test runner) که با attribute سطح crate به نام #![test_runner] تعیین شده داده شود.

    #![feature(custom_test_frameworks)]
#![test_runner(my_runner)]

fn my_runner(tests: &[&i32]) {
    for t in tests {
        if **t == 0 {
            println!("PASSED");
        } else {
            println!("FAILED");
        }
    }
}

#[test_case]
const WILL_PASS: i32 = 0;

#[test_case]
const WILL_FAIL: i32 = 4;
