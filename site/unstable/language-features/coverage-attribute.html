    coverage_attribute

    issue ردیابی این قابلیت: #84605

    attribute به نام coverage را می‌توان برای غیرفعال‌کردن انتخابی ابزارگذاری پوشش (coverage instrumentation) در یک تابع حاشیه‌نویسی‌شده به کار برد. این می‌تواند برای موارد زیر مفید باشد:

    • پرهیز از سربار ابزارگذاری در تابعی که از نظر کارایی حساس است
    • پرهیز از تولید پوشش برای تابعی که قرار نیست اجرا شود، اما همچنان هدف پوشش 100٪ برای بقیه‌ی برنامه حفظ شود.

    مثال

    #![feature(coverage_attribute)]

// `foo()` will get coverage instrumentation (by default)
fn foo() {
  // ...
}

#[coverage(off)]
fn bar() {
  // ...
}
