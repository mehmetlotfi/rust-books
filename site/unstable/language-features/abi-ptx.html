    abi_ptx

    issue ردیابی این قابلیت: #38788

    هنگام تولید کد PTX، همهٔ تابع‌های (fn) معمولی Rust به تابع‌های «device» ترجمه می‌شوند. این تابع‌ها از طریق API CUDA از سمت میزبان (host) قابل فراخوانی نیستند، بنابراین crateای که فقط تابع‌های device داشته باشد چندان مفید نیست!

    در مقابل، تابع‌های «global» را میزبان می‌تواند فراخوانی کند؛ می‌توانید آن‌ها را API عمومیِ واقعی crate خود بدانید. برای تولید یک تابع global از ABI با نام "ptx-kernel" استفاده کنید.

    #![feature(abi_ptx)]
#![no_std]

pub unsafe extern "ptx-kernel" fn global_function() {
    device_function();
}

pub fn device_function() {
    // ..
}
