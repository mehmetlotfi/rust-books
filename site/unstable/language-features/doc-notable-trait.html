    doc_notable_trait

    مسئلهٔ پیگیری (tracking issue) این ویژگی: #45040

    ویژگی doc_notable_trait استفاده از attribute به نام #[doc(notable_trait)] را ممکن می‌کند؛ این attribute باعث می‌شود صفت (trait) در یک پنجرهٔ «Notable traits» برای توابعی نمایش داده شود که نوعی را برمی‌گردانند که آن صفت را پیاده‌سازی می‌کند. برای مثال، این attribute روی صفت‌های Iterator، Future، io::Read و io::Write در کتابخانهٔ استاندارد اعمال شده است.

    شما می‌توانید همین کار را روی صفت‌های خودتان این‌گونه انجام دهید:

    #![feature(doc_notable_trait)]

#[doc(notable_trait)]
pub trait MyTrait {}

pub struct MyStruct;
impl MyTrait for MyStruct {}

/// The docs for this function will have a button that displays a dialog about
/// `MyStruct` implementing `MyTrait`.
pub fn my_fn() -> MyStruct { MyStruct }

    این ویژگی ابتدا در PR با شمارهٔ #45039 پیاده‌سازی شد.
