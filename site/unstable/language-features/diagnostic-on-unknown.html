    diagnostic_on_unknown

    مسئلهٔ پیگیری (tracking issue) این ویژگی: #152900

    ویژگی diagnostic_on_unknown استفاده از attribute به نام #[diagnostic::on_unknown] را ممکن می‌کند. این attribute باید روی تعریف‌های use و ماژول و نیز روی ریشهٔ crate قرار بگیرد، هرچند قرار دادن آن در جاهای دیگر خطا محسوب نمی‌شود. این attribute یک راهنمایی برای کامپایلر است تا هرگاه تعریف حاشیه‌نویسی‌شده در یک خطای تعیین نام (name resolution) دخیل باشد، پیام خطا را تکمیل کند.

    پارامترهای قالب‌بندی که نام مشخصی دارند با متن زیر جایگزین می‌شوند:

    • {Unresolved} — همان SimplePathSegment مسیر import که قابل تعیین نبوده است.
    • {this} — نام آیتم حاشیه‌نویسی‌شده. روی دستورهای use این مقدار با {unresolved} یکسان است.

    پیام خطای اصلی حذف نمی‌شود، بلکه به‌جای آن به‌صورت یک note نمایش داده می‌شود.

    روی تعریف‌های use

    #![feature(diagnostic_on_unknown)]

#[diagnostic::on_unknown(
    message = "`{Unresolved}` doesn't exist",
    label = "you did something silly here"
)]
use doesnt_exist;

    این کد به خطای زیر منجر می‌شود:

    error[E0432]: `doesnt_exist` doesn't exist
 --> src/lib.rs:7:5
  |
7 | use doesnt_exist;
  |     ^^^^^^^^^^^^ you did something silly here
  |
  = note: unresolved import `doesnt_exist`

For more information about this error, try `rustc --explain E0432`.

    روی تعریف‌های ماژول

    #![feature(diagnostic_on_unknown)]

#[diagnostic::on_unknown(
    message = "module `{this}` is empty, there is no `{unresolved}` here",
    label = "can't import something from an empty module"
)]
mod empty {}

use empty::what;

    این کد به خطای زیر منجر می‌شود:

    error[E0432]: module `empty` is empty, there is no `what` here
 --> src/lib.rs:9:5
  |
9 | use empty::what;
  |     ^^^^^^^----
  |            |
  |            can't import something from an empty module
  |
  = note: unresolved import `empty::what`

    روی ریشهٔ crate

    این حالت علاوه بر آن به ویژگی #![feature(custom_inner_attributes)] نیز نیاز دارد:

    #![feature(diagnostic_on_unknown)]
#![feature(custom_inner_attributes)]
#![diagnostic::on_unknown(message = "Say `{Unresolved}` again!")]

use self::what;

    مثال

    این جفت ماکرو را در نظر بگیرید: یکی ماژولی پنهان با یک ثابت می‌سازد و دیگری آن را می‌خواند.

    #![feature(macro_metavar_expr, macro_attr)]

macro_rules! instrument {
    attr() { $vis:vis fn $fn_name:ident ($($arg_name:ident : $arg_ty:ty),*) $(-> $ret:ty)? $body:block } => {
        $vis fn $fn_name ($($arg_name:$arg_ty),*) $(-> $ret)? $body
        #[doc(hidden)]
        $vis mod $fn_name {
            pub const LEN: usize = ${ count($arg_name) };
        }
    }
}

macro_rules! count_args {
    ($name:ident) => {{
        $name::LEN
    }}
}

#[instrument]
fn add(a: u8, b: u8) -> u8 {
    a + b
}

fn main() {
    let n = count_args!(add);
    println!("`add` has {n} arguments");
}

    اگر ماکروی #[instrument] حذف شود، این خطای گیج‌کننده نمایش داده می‌شود:

    error[E0433]: cannot find module or crate `add` in this scope
  --> src/main.rs:25:25
   |
25 |     let n = count_args!(add);
   |                         ^^^ function `add` is not a crate or module

    می‌توان از #[diagnostic::on_unknown] برای شخصی‌سازی این پیام خطا استفاده کرد:

    #![feature(diagnostic_on_unknown)]
#![feature(macro_metavar_expr, macro_attr)]

#[allow(unused_macros)]
macro_rules! instrument {
    attr() { $vis:vis fn $fn_name:ident ($($arg_name:ident : $arg_ty:ty),*) $(-> $ret:ty)? $body:block } => {
        $vis fn $fn_name ($($arg_name:$arg_ty),*) $(-> $ret)? $body
        #[doc(hidden)]
        $vis  mod $fn_name {
            pub const LEN: usize = ${ count($arg_name) };
        }
    }
}

macro_rules! count_args {
    ($name:ident) => {{
        #[diagnostic::on_unknown(
            message = "cannot count arguments of `{Unresolved}`",
            label = "`{Unresolved}` is not a function decorated \
                    with the `#[instrument]` macro"
        )]
        use $name::LEN as length;
        length
    }}
}

// #[instrument]
fn add(a: u8, b: u8) -> u8 {
  a + b
}

fn main() {
    let n = count_args!(add);
    println!("`add` has {n} arguments");
}

    این کد خروجی زیر را تولید می‌کند:

    error[E0432]: cannot count arguments of `add`
  --> src/main.rs:33:25
   |
33 |     let n = count_args!(add);
   |                         ^^^ `add` is not a function decorated with
   |                              the `#[instrument]` macro
   |
   = note: unresolved import `add`

    تفاوت‌های edition

    در edition 2015، مسیرهای use نسبت به ریشهٔ crate سنجیده می‌شوند. برای مثال، use empty نسبت به ریشهٔ crate تعیین می‌شود و در این فرایند به تعریف mod empty {} برخورد نخواهد کرد.

    #![feature(diagnostic_on_unknown)]

mod foo {
   #[diagnostic::on_unknown(message = "oh oh")]
   mod empty {}

   use empty::what;
}
