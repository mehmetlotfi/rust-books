    deref_patterns

    مسئلهٔ پیگیری (tracking issue) این ویژگی: #87121

    نکته: این ویژگی جایگزین box_patterns می‌شود.

    این ویژگی امکان تطبیق الگو روی اشاره‌گرهای هوشمند کتابخانهٔ استاندارد را از طریق نوع‌های هدف Deref آن‌ها فراهم می‌کند؛ چه به‌صورت ضمنی و چه با الگوهای صریح deref!(_) (که نحو آن‌ها فعلاً موقتی است).

    #![feature(deref_patterns)]

let mut v = vec![Box::new(Some(0))];

// Implicit dereferences are inserted when a pattern can match against the
// result of repeatedly dereferencing but can't match against a smart
// pointer itself. This works alongside match ergonomics for references.
if let [Some(x)] = &mut v {
    *x += 1;
}

// Explicit `deref!(_)` patterns may instead be used when finer control is
// needed, e.g. to dereference only a single smart pointer, or to bind the
// the result of dereferencing to a variable.
if let deref!([deref!(opt_x @ Some(1))]) = &mut v {
    opt_x.as_mut().map(|x| *x += 1);
}

assert_eq!(v, [Box::new(Some(2))]);

    بدون این ویژگی، هنگام تطبیق روی ساختارهای تو در تو ممکن است لازم شود برای نمایش مکان‌های dereference‌شده، متغیرهای موقت تعریف کنیم:

    let mut v = vec![Box::new(Some(0))];
if let [b] = &mut *v {
    if let Some(x) = &mut **b {
        *x += 1;
    }
}
if let [b] = &mut *v {
    if let opt_x @ Some(1) = &mut **b {
        opt_x.as_mut().map(|x| *x += 1);
    }
}
assert_eq!(v, [Box::new(Some(2))]);

    الگوهای deref می‌توانند مقدار را از داخل Box بیرون بکشند (move کنند):

    #![feature(deref_patterns)]
struct NoCopy;
let deref!(x) = Box::new(NoCopy);
drop::<NoCopy>(x);

    علاوه بر این، deref_patterns تغییراتی در الگوهای literal رشته و رشتهٔ بایتی اعمال می‌کند تا بتوان از آن‌ها در الگوهای deref استفاده کرد:

    #![feature(deref_patterns)]
match ("test".to_string(), Box::from("test"), b"test".to_vec()) {
    ("test", "test", b"test") => {}
    _ => panic!(),
}

// This works through multiple layers of reference and smart pointer:
match (&Box::new(&"test".to_string()), &&&"test") {
    ("test", "test") => {}
    _ => panic!(),
}

// `deref!("...")` syntax may also be used:
match "test".to_string() {
    deref!("test") => {}
    _ => panic!(),
}

// Matching on slices and arrays using literals is possible elsewhere as well:
match *"test" {
    "test" => {}
    _ => panic!(),
}
match *b"test" {
    b"test" => {}
    _ => panic!(),
}
match *(b"test" as &[u8]) {
    b"test" => {}
    _ => panic!(),
}
