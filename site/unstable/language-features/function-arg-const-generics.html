    function_arg_const_generics

    issue ردیابی این قابلیت: #163261

    #![feature(function_arg_const_generics)] اجازه می‌دهد پارامترهای const generic در فهرست پارامترهای مقداری (value parameter) یک تابع تعریف شوند و مانند آرگومان‌های معمولی فراخوانی ارائه شوند، نه از طریق آرگومان‌های generic (نحو turbofish).

    هشدار: این قابلیت ناقص است؛ طراحی و نحو آن ممکن است تغییر کند.

    این قابلیت به #![feature(gca_min_const_items)] یا #![feature(gca_adts)] نیاز دارد.

    نمونه‌ها

    به‌طور معمول، پارامترهای const generic در فهرست پارامترهای generic تعریف می‌شوند و با نحو turbofish ارائه می‌گردند:

    fn foo<const N: usize>(value: u8) {
    let _ = N;
}

fn main() {
    foo::<42>(10);
}

    با function_arg_const_generics، پارامتر const generic را می‌توان به‌جای آن در فهرست پارامترهای مقداری تابع تعریف کرد:

    #![allow(incomplete_features)]
#![feature(function_arg_const_generics, gca_min_const_items)]

fn foo(const N: usize, value: u8) {
    let _ = (N, value);
}

fn main() {
    foo(42, 10);
}

    در اینجا N همچنان یک پارامتر const generic است، اما مقدار آن به‌عنوان اولین آرگومان فراخوانی تابع ارائه می‌شود.

    متدها و تابع‌های trait

    پارامترهای const generic در موقعیت آرگومان در تابع‌های آزاد (free function)، متدهای ذاتی (inherent)، متدهای trait و پیاده‌سازی‌های trait پشتیبانی می‌شوند.

    #![allow(incomplete_features)]
#![feature(function_arg_const_generics, gca_min_const_items)]

struct Foo;

impl Foo {
    fn bar(&self, const N: usize) {
        let _ = N;
    }
}

trait Trait {
    fn baz(const N: usize);
}

impl Trait for Foo {
    fn baz(const N: usize) {
        let _ = N;
    }
}

fn main() {
    Foo.bar(10);
    Foo::baz(20);
}

    آرگومان‌های const پشتیبانی‌شده

    در حال حاضر فقط شکل‌های زیر از آرگومان‌های const پشتیبانی می‌شوند:

    • literalها.
    • مسیرها (path) به پارامترهای const generic.
    • مسیرها به آیتم‌های const، به شرطی که آیتم const برای استفاده در سیستم نوع علامت‌گذاری شده باشد، برای مثال با استفاده از gca!.
    #![allow(incomplete_features)]
#![feature(function_arg_const_generics, gca_min_const_items)]

fn foo(const N: usize) {
    let _ = N;
}

const VALUE: usize = core::gca!(42);

fn bar<const K: usize>() {
    foo(K);
}

fn main() {
    foo(10);    // OK: integer literal
    foo(VALUE); // OK: const item marked with gca!
    bar::<20>();
}

    محدودیت‌ها

    پارامترهای const generic در موقعیت آرگومان محدودیت‌های زیر را دارند:

    • باید با یک شناسهٔ ساده تعریف شوند، مانند const N: usize.
    • نمی‌توان آن‌ها را به‌صراحت با نحو turbofish ارائه کرد.
    • آرگومان‌ها باید از یکی از شکل‌های پشتیبانی‌شدهٔ آرگومان const که در بالا شرح داده شد استفاده کنند.

    برای مثال، یک متغیر محلی زمان اجرا (runtime) را نمی‌توان به‌عنوان آرگومان const به کار برد:

    #![allow(incomplete_features)]
#![feature(function_arg_const_generics, gca_min_const_items)]

fn foo(const N: usize) {}

fn main() {
    let n = 10;
    foo(n); // ERROR: runtime local variable
}

    به همین ترتیب، پارامترهای const generic در موقعیت آرگومان را نمی‌توان با نحو turbofish مشخص کرد:

    #![allow(incomplete_features)]
#![feature(function_arg_const_generics, gca_min_const_items)]

fn foo(const N: usize) {}

fn main() {
    foo::<10>(10); // ERROR: N cannot be specified using turbofish
}

    پارامترهای const generic در موقعیت آرگومان در حال حاضر در نوع‌های اشاره‌گر تابع (function pointer)، نحو trait Fn() یا اعلان‌های تابع خارجی (foreign function) پشتیبانی نمی‌شوند.
