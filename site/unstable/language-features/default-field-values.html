    default_field_values

    issue ردیابی این قابلیت: #132162

    RFC مربوط به این قابلیت: #3681

    قابلیت default_field_values به کاربران اجازه می‌دهد برای فیلدهای منفرد در تعریف ساختارها یک مقدار const مشخص کنند، به‌طوری که بتوان آن‌ها را از مقداردهی‌های اولیه حذف کرد.

    مثال‌ها

    #![feature(default_field_values)]

#[derive(Default)]
struct Pet {
    name: Option<String>, // impl Default for Pet will use Default::default() for name
    age: i128 = 42, // impl Default for Pet will use the literal 42 for age
}

fn main() {
    let a = Pet { name: Some(String::new()), .. }; // Pet { name: Some(""), age: 42 }
    let b = Pet::default(); // Pet { name: None, age: 42 }
    assert_eq!(a.age, b.age);
    // The following would be a compilation error: `name` needs to be specified
    // let _ = Pet { .. };
}

    #[derive(Default)]

    هنگام derive کردن Default، مقادیر ارائه‌شده به کار می‌روند. روی واریانت‌های شمارش، واریانت همچنان باید با #[default] علامت‌گذاری شود و همه‌ی فیلدهایش مقدار پیش‌فرض داشته باشند.

    #![feature(default_field_values)]

#[derive(Default)]
enum A {
    #[default]
    B {
        x: i32 = 0,
        y: i32 = 0,
    },
    C,
}

    واریانت‌های شمارش

    این قابلیت از واریانت‌های شمارش (enum) نیز پشتیبانی می‌کند، هم برای تعیین مقادیر پیش‌فرض و هم برای #[derive(Default)].

    تعامل با #[non_exhaustive]

    ساختار یا واریانت شمارشی که با #[non_exhaustive] علامت‌گذاری شده باشد اجازه ندارد مقادیر پیش‌فرض فیلد داشته باشد.

    لینت‌ها

    هنگام پیاده‌سازی دستی صفت Default برای نوعی که مقادیر پیش‌فرض فیلد دارد، اگر هر یک از این مقادیر در impl بازنویسی شود، lint به نام default_overrides_default_fields فعال می‌شود. این lint برای جلوگیری از رفتار متفاوتِ غافلگیرکننده میان S { .. } و S::default() وجود دارد، چون استفاده از یک نوع به هر دو روش ممکن است به مقادیر متفاوت بینجامد. شیوه‌ی درست نوشتن پیاده‌سازی دستی Default استفاده از نحو به‌روزرسانی تابعی (functional update) است:

    #![feature(default_field_values)]

struct Pet {
    name: String,
    age: i128 = 42, // impl Default for Pet will use the literal 42 for age
}

impl Default for Pet {
    fn default() -> Pet {
        Pet {
            name: "no-name".to_string(),
            ..
        }
    }
}
