کتاب قابلیت‌های ناپایدارThe Unstable Book

    macro_metavar_expr_concat

    issue ردیابی این قابلیت: #124225

    در Rust پایدار (stable)، بدون استفاده از ماکروهای رویه‌ای مانند paste هیچ راهی برای ساختن شناسه‌های (identifier) جدید از پیوند دادن شناسه‌ها به literalها یا شناسه‌های دیگر وجود ندارد. #![feature(macro_metavar_expr_concat)] راهی برای این کار فراهم می‌کند که از عبارت فرامتغیر (metavariable) به نام concat استفاده می‌کند.

    این ویژگی از نحوی (syntax) استفاده می‌کند که در macro_metavar_expr آمده است، اما در غیر این صورت مستقل از آن است. این ویژگی جایگزین ویژگی ناپایدار concat_idents است که از آن زمان حذف شده است.

    این یک ویژگی آزمایشی است؛ پیش از پایدارسازی، خود ویژگی و نحو آن به یک RFC نیاز خواهد داشت.

    نمای کلی

    #![feature(macro_metavar_expr_concat)] عبارت فرامتغیر concat را برای ساختن شناسه‌های جدید در اختیار می‌گذارد:

    #![feature(macro_metavar_expr_concat)]

macro_rules! create_some_structs {
    ($name:ident) => {
        pub struct ${ concat(First, $name) };
        pub struct ${ concat(Second, $name) };
        pub struct ${ concat(Third, $name) };
    }
}

create_some_structs!(Thing);

    این فراخوانی ماکرو به کد زیر گسترش می‌یابد:

    pub struct FirstThing;
pub struct SecondThing;
pub struct ThirdThing;

    نحو

    این ویژگی بر پایهٔ نحو عبارت فرامتغیر ${ .. } ساخته شده است که در RFC 3086 (macro_metavar_expr) مشخص شده است. concat به شکل ${ concat(items) } در دسترس است، که در آن items دنباله‌ای از شناسه‌ها و/یا literalها است که با ویرگول از هم جدا شده‌اند.

    مثال‌ها

    ساخت تابع یا متد با نام الحاقی

    #![feature(macro_metavar_expr_concat)]

macro_rules! make_getter {
    ($name:ident, $field: ident, $ret:ty) => {
        impl $name {
            pub fn ${ concat(get_, $field) }(&self) -> &$ret {
                &self.$field
            }
        }
    }
}

pub struct Thing {
    description: String,
}

make_getter!(Thing, description, String);

    این کد به شکل زیر گسترش می‌یابد:

    pub struct Thing {
    description: String,
}

impl Thing {
    pub fn get_description(&self) -> &String {
        &self.description
    }
}

    ساخت نام برای آزمون‌هایی که ماکرو تولید می‌کند

    #![feature(macro_metavar_expr_concat)]

macro_rules! test_math {
    ($integer:ident) => {
        #[test]
        fn ${ concat(test_, $integer, _, addition) } () {
            let a: $integer = 73;
            let b: $integer = 42;
            assert_eq!(a + b, 115)
        }

        #[test]
        fn ${ concat(test_, $integer, _, subtraction) } () {
            let a: $integer = 73;
            let b: $integer = 42;
            assert_eq!(a - b, 31)
        }
    }
}

test_math!(i32);
test_math!(u64);
test_math!(u128);
