    cfi_encoding

    issue ردیابی این قابلیت: #89653

    قابلیت cfi_encoding به کاربر اجازه می‌دهد برای یک نوع، کدگذاری CFI تعریف کند. این قابلیت اجازه می‌دهد برای نوع‌هایی که در غیر این صورت باید همان نامی را داشته باشند که در توابع C تعریف‌شده‌ی بیرونی به کار رفته، نام‌های متفاوتی استفاده شود.

    مثال‌ها

    #![feature(cfi_encoding, extern_types)]

#[cfi_encoding = "3Foo"]
pub struct Type1(i32);

extern {
    #[cfi_encoding = "3Bar"]
    type Type2;
}
