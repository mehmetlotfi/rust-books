    abi_cmse_nonsecure_call

    issue ردیابی این قابلیت: #81391

    قابلیت TrustZone-M برای هدف‌هایی در دسترس است که پروفایل معماری Armv8-M دارند (در نام هدفشان thumbv8m آمده است). LLVM، کامپایلر Rust و لینکر از قابلیت TrustZone-M پشتیبانی می‌کنند.

    یکی از چیزهایی که این قابلیت ناپایدار فراهم می‌کند، ABI تابع با نام “cmse-nonsecure-call” است. این ABI روی اشاره‌گرهای تابع به کد non-secure به کار می‌رود تا یک فراخوانی تابع non-secure را مشخص کند (برای جزئیات بخش ۵٫۵ را ببینید).

    با این ABI، کامپایلر برای انجام فراخوانی کارهای زیر را انجام می‌دهد:

    • ثبات‌هایی را که پس از فراخوانی لازم‌اند در حافظهٔ Secure ذخیره می‌کند
    • همهٔ ثبات‌هایی را که ممکن است اطلاعات محرمانه داشته باشند پاک می‌کند
    • کم‌ارزش‌ترین بیت (Least Significant Bit) آدرس تابع را پاک می‌کند
    • با دستور BLXNS پرش می‌کند

    برای پرهیز از استفاده از پشتهٔ non-secure، کامپایلر تعداد و نوع پارامترها/مقدار بازگشتی را محدود می‌کند.

    #![no_std]
#![feature(abi_cmse_nonsecure_call)]

#[no_mangle]
pub fn call_nonsecure_function(addr: usize) -> u32 {
    let non_secure_function =
        unsafe { core::mem::transmute::<usize, extern "cmse-nonsecure-call" fn() -> u32>(addr) };
    non_secure_function()
}
