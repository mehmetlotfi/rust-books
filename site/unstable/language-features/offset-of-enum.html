    offset_of_enum

    issue ردیابی این ویژگی: #120141

    وقتی ویژگی offset_of_enum فعال باشد، ماکروی offset_of! را می‌توان برای به‌دست آوردن آفست فیلدهای enumها به کار برد؛ برای بیان این کار، می‌توان از واریانت‌های enum مانند فیلد عبور کرد. خود واریانت‌ها آفست ندارند، بنابراین نمی‌توانند به عنوان آخرین جزء مسیر ظاهر شوند.

    #![feature(offset_of_enum)]
use std::mem;

#[repr(u8)]
enum Enum {
    A(u8, u16),
    B { one: u8, two: u16 },
}

assert_eq!(mem::offset_of!(Enum, A.0), 1);
assert_eq!(mem::offset_of!(Enum, B.two), 2);

assert_eq!(mem::offset_of!(Option<&u8>, Some.0), 0);
