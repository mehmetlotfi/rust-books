    مدل حافظه (Memory model)

    [memory.intro]

    Warning

    هشدار مدل حافظهٔ Rust هنوز کامل نیست و همهٔ جنبه‌های آن به‌طور نهایی تصمیم‌گیری نشده‌اند.

    [memory.bytes]

    بایت‌ها

    [memory.bytes.intro]

    بنیادی‌ترین واحد حافظه در Rust یک بایت است.

    Note

    نکته هرچند بایت‌ها معمولاً در سطح پایین به بایت‌های سخت‌افزاری تبدیل می‌شوند، Rust مفهومی «انتزاعی» از بایت دارد که می‌تواند تمایزهایی را نمایش دهد که در سخت‌افزار وجود ندارند؛ مانند مقداردهی‌اولیه‌نشده بودن یا نگهداری بخشی از یک اشاره‌گر. این تمایزها می‌توانند بر تعریف‌نشده بودن رفتار برنامه اثر بگذارند و بنابراین همچنان اثری ملموس بر رفتار برنامه‌های کامپایل‌شدهٔ Rust دارند.

    [memory.bytes.contents]

    هر بایت می‌تواند یکی از مقادیر زیر را داشته باشد:

    [memory.bytes.init]
    • یک بایت مقداردهی اولیه‌شده که مقداری از نوع u8 و در صورت وجود منشأ را در خود دارد؛
    [memory.bytes.uninit]
    • یک بایت مقداردهی اولیه‌نشده.

    Note

    نکته هنوز تضمین نشده است که فهرست بالا جامع باشد.
