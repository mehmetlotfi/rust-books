مرجع زبان RustThe Rust Reference

    [variable]

    متغیرها (Variables)

    [variable.intro]

    متغیر جزئی از یک قاب پشته است: پارامتر نام‌دار تابع، مقدار موقت بی‌نام یا متغیر محلی نام‌دار.

    [variable.local]

    متغیر محلی (یا تخصیص محلی پشته) مقداری را مستقیماً در حافظهٔ پشته نگه می‌دارد. این مقدار بخشی از قاب پشته است.

    [variable.local-mut]

    متغیرهای محلی تغییرناپذیرند، مگر آنکه خلافش اعلان شود؛ برای نمونه: let mut x = ....

    [variable.param-mut]

    پارامترهای تابع تغییرناپذیرند، مگر آنکه با mut اعلان شوند. واژهٔ کلیدی mut فقط به پارامتر پس از خود اعمال می‌شود. برای نمونه، |mut x, y| و fn f(mut x: Box<i32>, y: Box<i32>) یک متغیر تغییرپذیر x و یک متغیر تغییرناپذیر y اعلان می‌کنند.

    [variable.init]

    متغیرهای محلی هنگام تخصیص مقداردهی اولیه نمی‌شوند. در عوض، هنگام ورود به قاب، فضای همهٔ متغیرهای محلی قاب در حالتی مقداردهی‌اولیه‌نشده تخصیص می‌یابد. دستورهای بعدی تابع ممکن است متغیرهای محلی را مقداردهی اولیه کنند یا نکنند. یک متغیر محلی تنها پس از آن قابل استفاده است که در تمام مسیرهای قابل دسترس جریان کنترل مقداردهی اولیه شده باشد.

    در نمونهٔ بعد، init_after_if پس از عبارت if مقداردهی اولیه شده است، اما uninit_after_if چنین نیست؛ زیرا در حالت else مقداردهی نمی‌شود.

    fn random_bool() -> bool { true }
fn initialization_example() {
    let init_after_if: ();
    let uninit_after_if: ();

    if random_bool() {
        init_after_if = ();
        uninit_after_if = ();
    } else {
        init_after_if = ();
    }

    init_after_if; // ok
    // uninit_after_if; // err: use of possibly uninitialized `uninit_after_if`
}
