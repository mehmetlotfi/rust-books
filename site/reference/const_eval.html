    [const-eval]

    ارزیابی ثابت

    [const-eval.intro]

    ارزیابی ثابت فرایند محاسبهٔ نتیجهٔ عبارت‌ها هنگام کامپایل است. فقط زیرمجموعه‌ای از عبارت‌ها در زمان کامپایل قابل ارزیابی‌اند.

    [const-eval.const-expr]

    عبارت‌های ثابت

    [const-eval.const-expr.intro]

    شکل‌های مشخصی از عبارت که عبارت ثابت نام دارند، در زمان کامپایل قابل ارزیابی‌اند.

    [const-eval.const-expr.const-context]

    عبارت‌های درون بافت const باید عبارت ثابت باشند.

    [const-eval.const-expr.evaluation]

    عبارت‌های بافت const همیشه هنگام کامپایل ارزیابی می‌شوند.

    [const-eval.const-expr.runtime-context]

    بیرون بافت const، عبارت‌های ثابت ممکن است هنگام کامپایل ارزیابی شوند، اما تضمینی نیست.

    [const-eval.const-expr.error]

    رفتارهایی مانند نمایه‌گذاری آرایه خارج از محدوده یا سرریز، اگر مقدار مجبور باشد هنگام کامپایل ارزیابی شود—یعنی در بافت const—خطای کامپایلر هستند. در غیر این صورت هشدارند، اما احتمالاً هنگام اجرا panic می‌کنند.

    [const-eval.const-expr.list]

    عبارت‌های زیر به‌شرط ثابت‌بودن همهٔ عملوندها و اجرا نشدن فراخوانی Drop::drop، عبارت ثابت هستند.

    [const-eval.const-expr.path-static]

    • مسیرهای منتهی به staticها با محدودیت‌های زیر:

      • نوشتن در آیتم static در هیچ بافت ارزیابی ثابت مجاز نیست.
      • خواندن از staticهای extern در هیچ بافت ارزیابی ثابت مجاز نیست.
      • اگر ارزیابی در مقداردهندهٔ اولیهٔ یک آیتم static انجام نشود، خواندن از هر static تغییرپذیر مجاز نیست. یک static تغییرپذیر، آیتم static mut یا آیتم static با نوعی دارای تغییرپذیری درونی (interior mutability) است.

      این الزامات فقط هنگام ارزیابی ثابت بررسی می‌شوند. یعنی وجود نحوی چنین دسترسی‌هایی در بافت const تا زمانی که هرگز اجرا نشوند مجاز است.

    [const-eval.const-expr.borrows]

    • همهٔ شکل‌های قرض، شامل قرض خام، به‌جز قرض عبارت‌هایی که حوزهٔ موقتشان تا پایان برنامه گسترش طول‌عمر موقت می‌یابد و یکی از موارد زیرند:

      • قرض تغییرپذیر؛
      • قرض اشتراکی عبارتی که مقداری با تغییرپذیری درونی تولید می‌کند.
      // Due to being in tail position, this borrow extends the scope of the
// temporary to the end of the program. Since the borrow is mutable,
// this is not allowed in a const expression.
const C: &u8 = &mut 0; // ERROR not allowed
      // Const blocks are similar to initializers of `const` items.
let _: &u8 = const { &mut 0 }; // ERROR not allowed
      use core::sync::atomic::AtomicU8;
// This is not allowed as 1) the temporary scope is extended to the
// end of the program and 2) the temporary has interior mutability.
const C: &AtomicU8 = &AtomicU8::new(0); // ERROR not allowed
      use core::sync::atomic::AtomicU8;
// As above.
let _: &_ = const { &AtomicU8::new(0) }; // ERROR not allowed
      #![allow(static_mut_refs)]
// Even though this borrow is mutable, it's not of a temporary, so
// this is allowed.
const C: &u8 = unsafe { static mut S: u8 = 0; &mut S }; // OK
      use core::sync::atomic::AtomicU8;
// Even though this borrow is of a value with interior mutability,
// it's not of a temporary, so this is allowed.
const C: &AtomicU8 = {
    static S: AtomicU8 = AtomicU8::new(0); &S // OK
};
      use core::sync::atomic::AtomicU8;
// This shared borrow of an interior mutable temporary is allowed
// because its scope is not extended.
const C: () = { _ = &AtomicU8::new(0); }; // OK
      // Even though the borrow is mutable and the temporary lives to the
// end of the program due to promotion, this is allowed because the
// borrow is not in tail position and so the scope of the temporary
// is not extended via temporary lifetime extension.
const C: () = { let _: &'static mut [u8] = &mut []; }; // OK
//                                              ~~
//                                     Promoted temporary.

      Note

      نکته به‌عبارت دیگر و با تمرکز بر موارد مجاز، قرض اشتراکی دادهٔ دارای تغییرپذیری درونی و قرض تغییرپذیر فقط زمانی در بافت const مجازند که عبارت مکان قرض‌گرفته‌شده گذرا، غیرمستقیم یا ایستا باشد.

      عبارت مکان زمانی گذرا است که متغیری محلی در بافت const جاری یا عبارتی باشد که حوزهٔ موقتش در همان بافت قرار دارد.

      // The borrow is of a variable local to the initializer, therefore
// this place expression is transient.
const C: () = { let mut x = 0; _ = &mut x; };
      // The borrow is of a temporary whose scope has not been extended,
// therefore this place expression is transient.
const C: () = { _ = &mut 0u8; };
      // When a temporary is promoted but not lifetime extended, its
// place expression is still treated as transient.
const C: () = { let _: &'static mut [u8] = &mut []; };

      عبارت مکان زمانی غیرمستقیم است که عبارت ارجاع‌زدایی باشد.

      const C: () = { _ = &mut *(&mut 0); };

      عبارت مکان زمانی ایستا است که آیتم static باشد.

      #![allow(static_mut_refs)]
const C: &u8 = unsafe { static mut S: u8 = 0; &mut S };

      Note

      نکته پیامد شگفت‌آور این قواعد آن است که کد زیر مجاز است:

      const C: &[u8] = { let x: &mut [u8] = &mut []; x }; // OK
//                                    ~~~~~~~
// Empty arrays are promoted even behind mutable borrows.

      اما کد مشابه زیر مجاز نیست:

      const C: &[u8] = &mut []; // ERROR
//               ~~~~~~~
//           Tail expression.

      تفاوت این است که در اولی آرایهٔ خالی ارتقا می‌یابد اما حوزه‌اش مشمول گسترش طول‌عمر موقت نمی‌شود؛ بنابراین عبارت مکان گذرا در نظر گرفته می‌شود، هرچند پس از ارتقا تا پایان برنامه زنده است. در دومی حوزهٔ آرایهٔ موقت گسترش می‌یابد و چون قرض تغییرپذیر از مقدار موقت با طول‌عمر گسترش‌یافته و در نتیجه مکان غیرگذراست، رد می‌شود.

      نتیجه شگفت‌آور است، زیرا گسترش طول‌عمر موقت در این مورد باعث می‌شود کد کمتری کامپایل شود.

      برای جزئیات issue #143129 را ببینید.

      use core::cell::UnsafeCell;
const _: u8 = unsafe {
    let x: *mut u8 = &raw mut *&mut 0;
    //                        ^^^^^^^
    //             Dereference of mutable reference.
    *x = 1; // Dereference of mutable pointer.
    *(x as *const u8) // Dereference of constant pointer.
};
const _: u8 = unsafe {
    let x = &UnsafeCell::new(0);
    *x.get() = 1; // Mutation of interior mutable value.
    *x.get()
};

    [const-eval.const-fn]

    تابع‌های Const

    [const-eval.const-fn.intro]

    تابع const تابعی است که در بافت const قابل فراخوانی است. با مشخص‌کنندهٔ const تعریف می‌شود و سازنده‌های ساختار تاپل و گونهٔ تاپل enum را نیز شامل می‌شود.

    مثال

    const fn square(x: i32) -> i32 { x * x }

const VALUE: i32 = square(12);
    [const-eval.const-fn.const-context]

    هنگامی که یک تابع const از یک بافت const فراخوانی شود، کامپایلر آن را در زمان کامپایل تفسیر می‌کند. این تفسیر در محیط هدف کامپایل انجام می‌شود، نه میزبان. بنابراین اگر برای یک سیستم 32 بیتی کامپایل کنید، usize برابر 32 بیت است، صرف‌نظر از اینکه ساخت را روی یک سیستم 64 بیتی انجام دهید یا 32 بیتی.

    [const-eval.const-fn.outside-context]

    فراخوانی تابع const بیرون بافت const درست مانند حالتی رفتار می‌کند که مشخص‌کنندهٔ const نداشته باشد.

    [const-eval.const-fn.body-restriction]

    بدنهٔ تابع const فقط می‌تواند از عبارت‌های ثابت استفاده کند.

    [const-eval.const-fn.async]

    تابع const نمی‌تواند async باشد.

    [const-eval.const-fn.type-restrictions]

    نوع پارامترها و نوع بازگشت تابع const به نوع‌های سازگار با بافت const محدود است.
