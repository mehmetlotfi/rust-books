    [items.struct.intro]

    ساختار یک نوع ساختار اسمی است که با واژهٔ کلیدی struct تعریف می‌شود.

    [items.struct.namespace]

    اعلان ساختار، نام داده‌شده را در فضای نام نوع ماژول یا بلوکی که در آن قرار دارد تعریف می‌کند.

    نمونه‌ای از آیتم struct و کاربرد آن:

    struct Point {x: i32, y: i32}
let p = Point {x: 10, y: 11};
let px: i32 = p.x;
    [items.struct.tuple]

    ساختار تاپلی یک نوع تاپل اسمی است و آن هم با واژهٔ کلیدی struct تعریف می‌شود. افزون بر تعریف نوع، سازنده‌ای هم‌نام در فضای نام مقدار نیز تعریف می‌کند. سازنده تابعی است که می‌توان آن را برای ساخت نمونهٔ جدید ساختار فراخواند. برای نمونه:

    struct Point(i32, i32);
let p = Point(10, 11);
let px: i32 = match p { Point(x, _) => x };
    [items.struct.unit]

    ساختار واحدمانند ساختاری بدون فیلد است که با حذف کامل فهرست فیلدها تعریف می‌شود. چنین ساختاری به‌طور ضمنی یک ثابت هم‌نام از نوع خودش تعریف می‌کند. برای نمونه:

    struct Cookie;
let c = [Cookie, Cookie {}, Cookie, Cookie {}];

    با کد زیر معادل است:

    struct Cookie {}
const Cookie: Cookie = Cookie {};
let c = [Cookie, Cookie {}, Cookie, Cookie {}];
    [items.struct.layout]

    چیدمان دقیق حافظهٔ یک ساختار مشخص نشده است. می‌توان با ویژگی repr چیدمان خاصی تعیین کرد.
