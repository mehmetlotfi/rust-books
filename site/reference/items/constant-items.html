    آیتم‌های ثابت

    [items.const.syntax]

    Syntax
    ConstantItem →
        const ( IDENTIFIER | _ ) : Type ( = Expression )? ;

    [items.const.intro]

    یک آیتم ثابت، یک مقدار ثابت با نام اختیاری است که به محل مشخصی از حافظهٔ برنامه وابسته نیست.

    [items.const.behavior]

    ثابت‌ها اساساً در هر محل استفاده به‌صورت درون‌خطی قرار می‌گیرند؛ یعنی هنگام استفاده مستقیماً در بافت مربوط کپی می‌شوند. این رفتار شامل ثابت‌های crateهای خارجی و نوع‌های غیر-Copy نیز می‌شود. تضمینی نیست که ارجاع‌های مختلف به یک ثابت، همگی به یک نشانی حافظه اشاره کنند.

    [items.const.namespace]

    اعلان ثابت، مقدار ثابت را در فضای نام مقدار ماژول یا بلوکی که در آن قرار دارد تعریف می‌کند.

    [items.const.static]

    نوع ثابت‌ها باید به‌صراحت مشخص شود. نوع باید طول‌عمر 'static داشته باشد؛ هر ارجاعی در مقداردهندهٔ اولیه باید طول‌عمر 'static داشته باشد. طول‌عمر پیش‌فرض ارجاع‌ها در نوع یک ثابت، 'static است؛ حذف طول‌عمر static را ببینید.

    [items.const.static-temporary]

    اگر مقدار ثابت واجد شرایط ارتقا باشد، ارجاع به آن طول‌عمر 'static خواهد داشت؛ در غیر این صورت، یک مقدار موقت ساخته می‌شود.

    const BIT1: u32 = 1 << 0;
const BIT2: u32 = 1 << 1;

const BITS: [u32; 2] = [BIT1, BIT2];
const STRING: &'static str = "bitstring";

struct BitsNStrings<'a> {
    mybits: [u32; 2],
    mystring: &'a str,
}

const BITS_N_STRINGS: BitsNStrings<'static> = BitsNStrings {
    mybits: BITS,
    mystring: STRING,
};
    [items.const.expr-omission]

    عبارت ثابت را تنها می‌توان در یک تعریف صفت حذف کرد.

    [items.const.destructor]

    ثابت‌های دارای ویرانگر

    ثابت‌ها می‌توانند ویرانگر داشته باشند. وقتی مقدار از حوزه خارج می‌شود، ویرانگر اجرا خواهد شد.

    struct TypeWithDestructor(i32);

impl Drop for TypeWithDestructor {
    fn drop(&mut self) {
        println!("Dropped. Held {}.", self.0);
    }
}

const ZERO_WITH_DESTRUCTOR: TypeWithDestructor = TypeWithDestructor(0);

fn create_and_drop_zero_with_destructor() {
    let x = ZERO_WITH_DESTRUCTOR;
    // x gets dropped at end of function, calling drop.
    // prints "Dropped. Held 0.".
}
    [items.const.unnamed]

    ثابت بی‌نام

    [items.const.unnamed.intro]

    برخلاف یک ثابت وابسته، یک ثابت آزاد می‌تواند با استفاده از زیرخط به‌جای نام، بی‌نام باشد. برای مثال:

    const _: () =  { struct _SameNameTwice; };

// OK although it is the same name as above:
const _: () =  { struct _SameNameTwice; };
    [items.const.unnamed.repetition]

    همانند واردکردن با زیرخط، ماکروها می‌توانند یک ثابت بی‌نام یکسان را بیش از یک بار و با خیال آسوده در یک حوزه تولید کنند. برای مثال، کد زیر نباید خطایی ایجاد کند:

    macro_rules! m {
    ($item: item) => { $item $item }
}

m!(const _: () = (););
// This expands to:
// const _: () = ();
// const _: () = ();
    [items.const.eval]

    ارزیابی

    ثابت‌های آزاد همیشه در زمان کامپایل ارزیابی می‌شوند تا panicها آشکار شوند. این کار حتی درون تابعی بدون استفاده نیز رخ می‌دهد:

    // Compile-time panic
const PANIC: () = std::unimplemented!();

fn unused_generic_function<T>() {
    // A failing compile-time assertion
    const _: () = assert!(usize::BITS == 0);
}
