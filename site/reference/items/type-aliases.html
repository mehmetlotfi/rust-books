    [items.type.intro]

    نام مستعار نوع نامی تازه برای یک نوع موجود در فضای نام نوع ماژول یا بلوکی تعریف می‌کند که در آن قرار دارد. نام‌های مستعار نوع با واژهٔ کلیدی type اعلان می‌شوند. هر مقدار یک نوع مشخص و یگانه دارد، اما می‌تواند چندین صفت متفاوت را پیاده‌سازی کند و با چندین محدودیت نوع متفاوت سازگار باشد.

    برای نمونه، کد زیر نوع Point را مترادف نوع (u8, u8)، یعنی نوع جفتی از اعداد صحیح بدون علامت ۸ بیتی، تعریف می‌کند:

    type Point = (u8, u8);
let p: Point = (41, 68);
    [items.type.constructor-alias]

    نام مستعار نوع برای یک ساختار تاپلی یا ساختار واحد را نمی‌توان برای واجدشرایط‌کردن سازندهٔ آن نوع به کار برد:

    struct MyStruct(u32);

use MyStruct as UseAlias;
type TypeAlias = MyStruct;

let _ = UseAlias(5); // OK
let _ = TypeAlias(5); // Doesn't work
    [items.type.associated-type]

    نام مستعار نوع، وقتی به‌عنوان نوع وابسته به کار نرود، باید شامل یک Type باشد و نمی‌تواند شامل Bounds باشد.

    [items.type.associated-trait]

    نام مستعار نوع، وقتی به‌عنوان نوع وابسته در یک trait به کار رود، نباید مشخصهٔ Type داشته باشد، اما می‌تواند شامل Bounds باشد.

    [items.type.associated-impl]

    نام مستعار نوع، وقتی به‌عنوان نوع وابسته در یک trait impl به کار رود، باید مشخصهٔ Type داشته باشد و نمی‌تواند شامل Bounds باشد.

    [items.type.deprecated]

    بندهای where پیش از علامت مساوی در نام مستعار نوع درون یک پیاده‌سازی صفت (مانند type TypeAlias<T> where T: Foo = Bar<T>) منسوخ شده‌اند. بندهای where پس از علامت مساوی (مانند type TypeAlias<T> = Bar<T> where T: Foo) ترجیح داده می‌شوند.
