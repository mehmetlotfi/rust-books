    [items.extern-crate]

    اعلان‌های Extern crate

    [items.extern-crate.syntax]

    Syntax
    ExternCrate → extern crate CrateRef AsClause? ;

    CrateRef → IDENTIFIER | self

    AsClause → as ( IDENTIFIER | _ )

    [items.extern-crate.intro]

    یک اعلان extern crate وابستگی به یک crate خارجی را مشخص می‌کند.

    [items.extern-crate.namespace]

    سپس crate خارجی با شناسهٔ داده‌شده در فضای نام نوع به حوزهٔ اعلان‌کننده متصل می‌شود.

    [items.extern-crate.extern-prelude]

    افزون بر این، اگر extern crate در ریشهٔ crate ظاهر شود، نام crate به پیش‌درآمد extern نیز افزوده می‌شود و در نتیجه به‌طور خودکار در حوزهٔ همهٔ ماژول‌ها قرار می‌گیرد.

    [items.extern-crate.as]

    از بند as می‌توان برای متصل‌کردن crate واردشده به نامی متفاوت استفاده کرد.

    [items.extern-crate.lookup]

    crate خارجی هنگام کامپایل به یک soname مشخص تفکیک می‌شود و نیازمندی پیوند زمان اجرا به آن soname برای بارگذاری در زمان اجرا به پیونددهنده فرستاده می‌شود. soname هنگام کامپایل، با پیمایش مسیر کتابخانهٔ کامپایلر و تطبیق crate_name اختیاری با ویژگی‌های crate_name اعلان‌شده روی crate خارجی در زمان کامپایل آن، تفکیک می‌شود. اگر crate_name ارائه نشده باشد، ویژگی پیش‌فرض name برابر با شناسهٔ داده‌شده در اعلان extern crate فرض می‌شود.

    [items.extern-crate.self]

    می‌توان crate مربوط به self را وارد کرد تا اتصالی به crate جاری ساخته شود. در این حالت باید با بند as نامی را که اتصال به آن انجام می‌شود مشخص کرد.

    سه نمونه از اعلان‌های extern crate:

    extern crate pcre;

extern crate std; // equivalent to: extern crate std as std;

extern crate std as ruststd; // linking to 'std' under another name
    [items.extern-crate.name-restrictions]

    در نام‌گذاری crateهای Rust، خط تیره مجاز نیست؛ اما بسته‌های Cargo می‌توانند از آن استفاده کنند. در چنین حالتی، اگر Cargo.toml نام crate را مشخص نکرده باشد، Cargo به‌طور شفاف - را با _ جایگزین می‌کند (برای جزئیات بیشتر RFC 940 را ببینید).

    در اینجا یک نمونه آمده است:

    // Importing the Cargo package hello-world
extern crate hello_world; // hyphen replaced with an underscore
    [items.extern-crate.underscore]

    واردکردن با زیرخط

    [items.extern-crate.underscore.intro]

    با استفاده از زیرخط به‌شکل extern crate foo as _ می‌توان وابستگی به یک crate خارجی را بدون متصل‌کردن نام آن در حوزه اعلان کرد. این روش برای crateهایی مفید است که تنها باید پیوند داده شوند اما هرگز به آن‌ها ارجاع نمی‌شود، و مانع گزارش‌شدنشان به‌عنوان مورد بدون استفاده خواهد شد.

    [items.extern-crate.underscore.macro_use]

    [ویژگی macro_use] به‌شکل معمول عمل می‌کند و نام ماکروها را به پیش‌درآمد macro_use وارد می‌کند.

    [items.extern-crate.no_link]

    ویژگی no_link

    [items.extern-crate.no_link.intro]

    ویژگی no_link را می‌توان روی یک آیتم extern crate اعمال کرد تا از پیوند crate جلوگیری شود.

    Note

    نکته این کار برای نمونه زمانی سودمند است که تنها ماکروهای یک crate موردنیاز باشند.

    مثال

    #[no_link]
extern crate other_crate;

other_crate::some_macro!();
    [items.extern-crate.no_link.syntax]

    ویژگی no_link از نحو MetaWord استفاده می‌کند.

    [items.extern-crate.no_link.allowed-positions]

    ویژگی no_link را تنها می‌توان روی یک اعلان extern crate اعمال کرد.

    Note

    نکته rustc استفاده از آن را در موقعیت‌های دیگر نادیده می‌گیرد، اما درباره‌اش lint صادر می‌کند. ممکن است این رفتار در آینده به خطا تبدیل شود.

    [items.extern-crate.no_link.duplicates]

    تنها نخستین استفاده از no_link روی یک اعلان extern crate اثر دارد.

    Note

    نکته rustc دربارهٔ هر استفاده پس از مورد نخست lint صادر می‌کند. ممکن است این رفتار در آینده به خطا تبدیل شود.
