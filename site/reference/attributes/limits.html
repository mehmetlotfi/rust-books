    [attributes.limits]

    محدودیت‌ها

    [attributes.limits.intro]

    Attributeهای زیر بر محدودیت‌های هنگام کامپایل اثر می‌گذارند.

    [attributes.limits.recursion_limit]

    Attributeِ recursion_limit

    [attributes.limits.recursion_limit.intro]

    Attributeِ recursion_limit را می‌توان در سطح crate اعمال کرد تا بیشینهٔ عمق عملیات بالقوه بی‌نهایت بازگشتی زمان کامپایل، مانند بسط ماکرو یا اشاره‌زدایی خودکار، تعیین شود.

    [attributes.limits.recursion_limit.syntax]

    این ویژگی برای تعیین عمق بازگشت از نحو MetaNameValueStr استفاده می‌کند.

    Note

    نکته مقدار پیش‌فرض در rustc برابر ۱۲۸ است.

    #![recursion_limit = "4"]

macro_rules! a {
    () => { a!(1); };
    (1) => { a!(2); };
    (2) => { a!(3); };
    (3) => { a!(4); };
    (4) => { };
}

// This fails to expand because it requires a recursion depth greater than 4.
a!{}
    #![recursion_limit = "1"]

// This fails because it requires two recursive steps to auto-dereference.
(|_: &u8| {})(&&&1);
    [attributes.limits.type_length_limit]

    Attributeِ type_length_limit

    [attributes.limits.type_length_limit.intro]

    AttributeAttributeِ type_length_limit بیشینهٔ تعداد جایگزینی‌های نوع هنگام ساخت یک نوع concrete در monomorphization را تعیین می‌کند.

    Note

    نکته rustc فقط هنگامی این محدودیت را اعمال می‌کند که پرچم nightly با نام -Zenforce-type-length-limit فعال باشد.

    برای اطلاعات بیشتر Rust PR #127670 را ببینید.

    مثال

    #![type_length_limit = "4"]

fn f<T>(x: T) {}

// This fails to compile because monomorphizing to
// `f::<((((i32,), i32), i32), i32)>` requires more
// than 4 type elements.
f(((((1,), 2), 3), 4));

    Note

    نکته مقدار پیش‌فرض در rustc برابر 1048576 است.

    [attributes.limits.type_length_limit.syntax]

    Attributeِ type_length_limit از نحو MetaNameValueStr استفاده می‌کند. مقدار رشته باید عددی نامنفی باشد.

    [attributes.limits.type_length_limit.allowed-positions]

    Attributeِ type_length_limit فقط روی ریشهٔ crate قابل اعمال است.

    Note

    نکته rustc استفاده در موقعیت‌های دیگر را نادیده می‌گیرد، اما برای آن lint گزارش می‌کند. ممکن است این وضعیت در آینده به خطا تبدیل شود.

    [attributes.limits.type_length_limit.duplicates]

    فقط نخستین استفاده از type_length_limit روی یک آیتم اثر دارد.

    Note

    نکته rustc برای هر استفاده پس از مورد نخست lint گزارش می‌کند. ممکن است این وضعیت در آینده به خطا تبدیل شود.
