    [attributes.derive]

    Derive

    [attributes.derive.intro]

    ویژگی derive یک یا چند ماکروی derive را فراخوانی می‌کند و اجازه می‌دهد آیتم‌های جدید به‌طور خودکار برای ساختارهای داده تولید شوند. می‌توانید با ماکروهای رویه‌ای ماکروهای derive بسازید.

    مثال ماکروی derive مربوط به PartialEq یک پیاده‌سازی از PartialEq برای Foo<T> where T: PartialEq تولید می‌کند. ماکروی derive مربوط به Clone نیز همین کار را برای Clone انجام می‌دهد.

    #[derive(PartialEq, Clone)]
struct Foo<T> {
    a: i32,
    b: T,
}

    آیتم‌های impl تولیدشده معادل موارد زیر هستند:

    struct Foo<T> { a: i32, b: T }
impl<T: PartialEq> PartialEq for Foo<T> {
    fn eq(&self, other: &Foo<T>) -> bool {
        self.a == other.a && self.b == other.b
    }
}

impl<T: Clone> Clone for Foo<T> {
    fn clone(&self) -> Self {
        Foo { a: self.a.clone(), b: self.b.clone() }
    }
}
    [attributes.derive.syntax]

    ویژگی derive برای مشخص‌کردن فهرستی از مسیرهای ماکروهای derive که باید فراخوانی شوند، از نحو MetaListPaths استفاده می‌کند.

    [attributes.derive.allowed-positions]

    ویژگی derive را تنها می‌توان روی ساختارها، شمارش‌ها و unionها اعمال کرد.

    [attributes.derive.duplicates]

    ویژگی derive را می‌توان هر تعداد بار روی یک آیتم به‌کار برد. همهٔ ماکروهای derive فهرست‌شده در تمام ویژگی‌ها فراخوانی می‌شوند.

    [attributes.derive.stdlib]

    ویژگی derive در کتابخانهٔ استاندارد به‌شکل‌های زیر صادر می‌شود:

    • core::derive
    • std::derive
    • core::prelude::v1::derive
    • std::prelude::v1::derive
    [attributes.derive.built-in]

    deriveهای داخلی در پیش‌درآمد زبان تعریف شده‌اند. فهرست آن‌ها چنین است:

    • Clone
    • Copy
    • Debug
    • Default
    • Eq
    • Hash
    • Ord
    • PartialEq
    • PartialOrd
    [attributes.derive.built-in-automatically_derived]

    deriveهای داخلی، ویژگی automatically_derived را در پیاده‌سازی‌هایی که تولید می‌کنند قرار می‌دهند.

    [attributes.derive.behavior]

    هنگام گسترش ماکرو، ماکروی derive متناظر با هر عنصر فهرست deriveها به صفر یا چند آیتم گسترش می‌یابد.

    [attributes.derive.automatically_derived]

    ویژگی automatically_derived

    [attributes.derive.automatically_derived.intro]

    ویژگی automatically_derived برای حاشیه‌نویسی یک پیاده‌سازی به‌کار می‌رود تا نشان دهد آن پیاده‌سازی به‌طور خودکار توسط یک ماکروی derive ساخته شده است. این ویژگی اثر مستقیمی ندارد، اما ابزارها و lintهای تشخیصی می‌توانند برای شناسایی این پیاده‌سازی‌های خودکار از آن استفاده کنند.

    مثال با قرارگرفتن #[derive(Clone)] روی struct Example، ماکروی derive ممکن است کد زیر را تولید کند:

    struct Example;
#[automatically_derived]
impl ::core::clone::Clone for Example {
    #[inline]
    fn clone(&self) -> Self {
        Example
    }
}
    [attributes.derive.automatically_derived.syntax]

    ویژگی automatically_derived از نحو MetaWord استفاده می‌کند.

    [attributes.derive.automatically_derived.allowed-positions]

    ویژگی automatically_derived را تنها می‌توان روی یک پیاده‌سازی اعمال کرد.

    Note

    نکته rustc استفاده از آن را در موقعیت‌های دیگر نادیده می‌گیرد، اما درباره‌اش lint صادر می‌کند. ممکن است این رفتار در آینده به خطا تبدیل شود.

    [attributes.derive.automatically_derived.duplicates]

    استفادهٔ چندباره از automatically_derived روی یک پیاده‌سازی، همان اثر استفادهٔ یک‌باره را دارد.

    Note

    نکته rustc دربارهٔ هر استفاده پس از مورد نخست lint صادر می‌کند.

    [attributes.derive.automatically_derived.behavior]

    ویژگی automatically_derived هیچ رفتاری ندارد.
