    [type.slice]

    نوع‌های برش (Slice types)

    [type.slice.syntax]

    Syntax
    SliceType → [ Type ]

    [type.slice.intro]

    برش یک نوع با اندازهٔ پویا است که «نمایی» از دنباله‌ای از عناصر نوع T را ارائه می‌کند. نوع برش به‌شکل [T] نوشته می‌شود.

    [type.slice.unsized]

    نوع‌های برش عموماً از طریق نوع‌های اشاره‌گر استفاده می‌شوند. برای نمونه:

    • &[T]: یک «برش اشتراکی» که اغلب فقط «برش» نامیده می‌شود. مالک داده‌ای که به آن اشاره می‌کند نیست، بلکه آن را قرض می‌گیرد.
    • &mut [T]: یک «برش تغییرپذیر» که دادهٔ مورد اشاره را به‌صورت تغییرپذیر قرض می‌گیرد.
    • Box<[T]>: یک «برش باکس‌شده».

    نمونه‌ها:

    // A heap-allocated array, coerced to a slice
let boxed_array: Box<[i32]> = Box::new([1, 2, 3]);

// A (shared) slice into an array
let slice: &[i32] = &boxed_array[..];
    [type.slice.safe]

    تمام عناصر برش‌ها همیشه مقداردهی اولیه شده‌اند و دسترسی به برش در متدها و عملگرهای امن همواره از نظر محدوده بررسی می‌شود.
