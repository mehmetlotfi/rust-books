    [type.array]

    نوع‌های آرایه

    [type.array.syntax]

    Syntax
    ArrayType → [ Type ; Expression ]

    [type.array.intro]

    آرایه دنباله‌ای با اندازهٔ ثابت از N عنصر نوع T است. نوع آرایه به‌شکل [T; N] نوشته می‌شود.

    [type.array.constraint]

    اندازه یک عبارت ثابت است که به یک usize ارزیابی می‌شود.

    نمونه‌ها:

    // A stack-allocated array
let array: [i32; 3] = [1, 2, 3];

// A heap-allocated array, coerced to a slice
let boxed_array: Box<[i32]> = Box::new([1, 2, 3]);
    [type.array.index]

    تمام عناصر آرایه‌ها همیشه مقداردهی اولیه شده‌اند و دسترسی به آرایه در متدها و عملگرهای امن همواره از نظر محدوده بررسی می‌شود.

    Note

    نکته نوع Vec<T> در کتابخانهٔ استاندارد، نوع آرایه‌ای تغییراندازه‌پذیر و تخصیص‌یافته روی هیپ را فراهم می‌کند.
