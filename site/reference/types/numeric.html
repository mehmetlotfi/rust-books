    [type.numeric.int.size]

    نوع‌های صحیح وابسته به ماشین

    [type.numeric.int.size.usize]

    نوع usize یک عدد صحیح بدون علامت با تعداد بیت برابر با نوع اشاره‌گر پلتفرم است. این نوع می‌تواند همهٔ نشانی‌های حافظهٔ فرایند را نمایش دهد.

    Note

    نکته هرچند usize می‌تواند هر نشانی را نمایش دهد، تبدیل یک اشاره‌گر به usize الزاماً برگشت‌پذیر نیست. برای اطلاعات بیشتر مستندات عبارت‌های تبدیل نوع، ‏std::ptr و به‌ویژه خاستگاه را ببینید.

    [type.numeric.int.size.isize]

    نوع isize یک عدد صحیح علامت‌دار مکمل دو با تعداد بیت برابر نوع اشاره‌گر پلتفرم است. کران بالای نظری اندازهٔ object و آرایه، بیشینهٔ مقدار isize است. این ویژگی تضمین می‌کند isize بتواند اختلاف میان اشاره‌گرهای داخل یک object یا آرایه را محاسبه کند و هر بایت داخل object، به‌اضافهٔ یک بایت پس از پایان آن، را نشانی‌دهی کند.

    [type.numeric.int.size.minimum]

    پهنای usize و isize دست‌کم ۱۶ بیت است.

    Note

    نکته بخش‌های زیادی از کد Rust ممکن است فرض کنند اشاره‌گرها، usize و isize یا ۳۲ بیتی‌اند یا ۶۴ بیتی. در نتیجه پشتیبانی از اشاره‌گر ۱۶ بیتی محدود است و ممکن است کتابخانه برای پشتیبانی از آن به مراقبت و اعلام صریح نیاز داشته باشد.

    [type.numeric.validity]

    اعتبار بیت‌ها

    برای هر نوع عددی T، اعتبار بیت‌های T معادل اعتبار بیت‌های [u8; size_of::<T>()] است. یک بایت مقداردهی‌نشده u8 معتبر نیست.
