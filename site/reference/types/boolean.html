    [type.bool]

    نوع بولی

    [type.bool.intro] 
    let b: bool = true;

    نوع بولی یا bool یک نوع دادهٔ ابتدایی است که می‌تواند یکی از دو مقدار درست و نادرست را بگیرد.

    [type.bool.literal]

    مقادیر این نوع را می‌توان با یک عبارت لفظی و کلیدواژه‌های true و false ساخت که هرکدام با مقدار هم‌نام خود متناظرند.

    [type.bool.namespace]

    این نوع با نام bool بخشی از پیش‌درآمد زبان است.

    [type.bool.layout]

    یک شیء از نوع بولی، هم اندازه و هم‌ترازی برابر با ۱ دارد.

    [type.bool.repr]

    مقدار false الگوی بیتی 0x00 و مقدار true الگوی بیتی 0x01 دارد. داشتن هر الگوی بیتی دیگری برای شیئی از نوع بولی، رفتار تعریف‌نشده است.

    [type.bool.use]

    نوع بولی، نوع بسیاری از عملوندها در عبارت‌های گوناگون است:

    [type.bool.use-in-condition]
    • عملوند شرط در عبارت‌های if و عبارت‌های while
    [type.bool.use-in-lazy-operator]
    • عملوندهای عبارت‌های عملگر بولی تنبل

    Note

    نکته نوع بولی رفتاری شبیه یک نوع شمارشی دارد، اما نوع شمارشی نیست. در عمل، مهم‌ترین نتیجه این است که سازنده‌ها به این نوع وابسته نیستند (برای نمونه bool::true وجود ندارد).

    [type.bool.traits]

    مانند همهٔ نوع‌های ابتدایی، نوع بولی traitهای Clone، Copy، Sized، Send و Sync را پیاده‌سازی می‌کند.

    Note

    نکته برای عملیات کتابخانه‌ای، مستندات کتابخانهٔ استاندارد را ببینید.

    [type.bool.expr]

    عملیات روی مقادیر بولی

    [type.bool.expr.intro]

    وقتی از برخی عبارت‌های عملگر با عملوندهایی از نوع بولی استفاده می‌شود، این عبارت‌ها طبق قواعد منطق بولی ارزیابی می‌شوند.

    [type.bool.expr.not]

    نقیض منطقی

    b!b
    truefalse
    falsetrue
    [type.bool.expr.or]

    یای منطقی

    aba | b
    truetruetrue
    truefalsetrue
    falsetruetrue
    falsefalsefalse
    [type.bool.expr.and]

    و منطقی

    aba & b
    truetruetrue
    truefalsefalse
    falsetruefalse
    falsefalsefalse
    [type.bool.expr.xor]

    یای انحصاری منطقی

    aba ^ b
    truetruefalse
    truefalsetrue
    falsetruetrue
    falsefalsefalse
    [type.bool.expr.cmp]

    مقایسه‌ها

    [type.bool.expr.cmp.eq]
    aba == b
    truetruetrue
    truefalsefalse
    falsetruefalse
    falsefalsetrue
    [type.bool.expr.cmp.greater]
    aba > b
    truetruefalse
    truefalsetrue
    falsetruefalse
    falsefalsefalse
    [type.bool.expr.cmp.not-eq]
    • a != b همان !(a == b) است.
    [type.bool.expr.cmp.greater-eq]
    • a >= b همان a == b | a > b است.
    [type.bool.expr.cmp.less]
    • a < b با !(a >= b) یکسان است
    [type.bool.expr.cmp.less-eq]
    • a <= b همان a == b | a < b است.
    [type.bool.validity]

    اعتبار بیت‌ها

    تضمین می‌شود که تک‌بایت یک bool مقداردهی اولیه شده باشد (به‌عبارت دیگر، transmute::<bool, u8>(...) همیشه صحیح است؛ اما چون بعضی الگوهای بیتی bool معتبر نیستند، عکس آن همیشه صحیح نیست).
