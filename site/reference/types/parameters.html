    [type.generic]

    پارامترهای نوع (Type parameters)

    در بدنهٔ آیتمی که اعلان پارامتر نوع دارد، نام پارامترهای نوع آن، خودشان نوع هستند:

    fn to_vec<A: Clone>(xs: &[A]) -> Vec<A> {
    if xs.is_empty() {
        return vec![];
    }
    let first: A = xs[0].clone();
    let mut rest: Vec<A> = to_vec(&xs[1..]);
    rest.insert(0, first);
    rest
}

    در اینجا، first نوع A دارد که به پارامتر نوع A در to_vec اشاره می‌کند؛ همچنین rest از نوع Vec<A>، یعنی برداری با عنصرهای نوع A، است.
