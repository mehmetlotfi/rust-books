    [names.preludes]

    پیش‌درآمدها

    [names.preludes.intro]

    پیش‌درآمد مجموعه‌ای از نام‌هاست که به‌طور خودکار وارد حوزهٔ هر ماژول یک crate می‌شوند.

    این نام‌ها بخشی از خود ماژول نیستند و هنگام تفکیک نام به‌طور ضمنی جست‌وجو می‌شوند. برای مثال، با اینکه Box در حوزهٔ همهٔ ماژول‌هاست، نمی‌توانید با self::Box به آن اشاره کنید، زیرا عضو ماژول جاری نیست.

    [names.preludes.kinds]

    چند نوع پیش‌درآمد وجود دارد:

    • پیش‌درآمد Extern
    • پیش‌درآمد extern
    • پیش‌درآمد زبان
    • [پیش‌درآمد macro_use]
    • پیش‌درآمد ابزار
    [names.preludes.std]

    پیش‌درآمد کتابخانهٔ استاندارد

    [names.preludes.std.intro]

    هر crate یک پیش‌درآمد کتابخانهٔ استاندارد دارد که از نام‌های یک ماژول واحد کتابخانهٔ استاندارد تشکیل می‌شود.

    [names.preludes.std.module]

    ماژول مورد استفاده به ویرایش crate و اعمال‌شدن یا نشدن ویژگی no_std روی crate بستگی دارد:

    ویرایشبدون no_stdبا no_std
    2015std::prelude::rust_2015core::prelude::rust_2015
    2018std::prelude::rust_2018core::prelude::rust_2018
    2021std::prelude::rust_2021core::prelude::rust_2021
    2024std::prelude::rust_2024core::prelude::rust_2024

    Note

    نکته محتوای std::prelude::rust_2015 و std::prelude::rust_2018 با std::prelude::v1 یکسان است.

    محتوای core::prelude::rust_2015 و core::prelude::rust_2018 نیز با core::prelude::v1 یکسان است.

    Note

    نکته وقتی یکی از core::panic! یا std::panic! به‌دلیل پیش‌درآمد کتابخانهٔ استاندارد وارد حوزه شود و یک واردکردن سراسری نوشته‌شده توسط کاربر دیگری را وارد کند، rustc اکنون استفاده از panic! را با وجود ابهام مجاز می‌داند. برای رفع این ابهام، واردکردن سراسری کاربر اولویت دارد.

    برای جزئیات، names.resolution.expansion.imports.ambiguity.panic-hack را ببینید.

    [names.preludes.extern]

    پیش‌درآمد Extern

    [names.preludes.extern.intro]

    crateهای خارجی که با extern crate در ماژول ریشه وارد یا به کامپایلر داده شده‌اند—مانند پرچم --extern در rustc—به پیش‌درآمد extern افزوده می‌شوند. اگر با نام مستعار مانند extern crate orig_name as new_name وارد شوند، نماد new_name به پیش‌درآمد افزوده می‌شود.

    [names.preludes.extern.core]

    crate مربوط به core همیشه به پیش‌درآمد extern افزوده می‌شود.

    [names.preludes.extern.std]

    تا زمانی که ویژگی no_std در ریشهٔ crate مشخص نشده باشد، crate مربوط به std افزوده می‌شود.

    [names.preludes.extern.edition2018]

    تفاوت‌های ویرایش 2018 در ویرایش ۲۰۱۵، نمی‌توان از طریق اعلان‌های use به crateهای پیش‌درآمد extern ارجاع داد؛ بنابراین معمولاً اعلان‌های extern crate برای آوردن آن‌ها به حوزه نوشته می‌شدند.

    از ویرایش ۲۰۱۸، اعلان‌های use می‌توانند به crateهای پیش‌درآمد extern ارجاع دهند؛ پس استفاده از extern crate غیراصطلاحی محسوب می‌شود.

    Note

    نکته crateهای اضافی همراه rustc مانند alloc و test، هنگام استفاده از Cargo به‌طور خودکار با پرچم --extern گنجانده نمی‌شوند. حتی در ویرایش ۲۰۱۸ باید با اعلان extern crate وارد حوزه شوند.

    extern crate alloc;
use alloc::rc::Rc;

    Cargo فقط برای crateهای proc-macro، ‏proc_macro را به پیش‌درآمد extern می‌آورد.

    [names.preludes.extern.no_std]

    ویژگی no_std

    [names.preludes.extern.no_std.intro]

    ویژگی no_std باعث می‌شود crate مربوط به std خودکار پیوند نخورد و پیش‌درآمد کتابخانهٔ استاندارد به‌جای آن از پیش‌درآمد core استفاده کند.

    مثال

    #![no_std]

    Note

    نکته no_std زمانی سودمند است که crate سکویی بدون پشتیبانی کتابخانهٔ استاندارد را هدف می‌گیرد یا عمداً از قابلیت‌های آن استفاده نمی‌کند. این قابلیت‌ها عمدتاً تخصیص پویای حافظه مانند Box و Vec و امکانات فایل و شبکه مانند std::fs و std::io هستند.

    Warning

    هشدار استفاده از no_std مانع پیوند کتابخانهٔ استاندارد نمی‌شود. نوشتن extern crate std در خود crate یا یکی از وابستگی‌هایش همچنان معتبر است و باعث می‌شود کامپایلر crate مربوط به std را به برنامه پیوند دهد.

    [names.preludes.extern.no_std.syntax]

    ویژگی no_std از نحو MetaWord استفاده می‌کند.

    [names.preludes.extern.no_std.allowed-positions]

    ویژگی no_std را تنها می‌توان روی ریشهٔ crate اعمال کرد.

    [names.preludes.extern.no_std.duplicates]

    ویژگی no_std را می‌توان هر تعداد بار روی یک فرم به‌کار برد.

    Note

    نکته rustc دربارهٔ استفاده‌های پس از مورد نخست lint صادر می‌کند.

    [names.preludes.extern.no_std.module]

    ویژگی no_std باعث می‌شود پیش‌درآمد کتابخانهٔ استاندارد به‌جای پیش‌درآمد std از core استفاده کند.

    [names.preludes.extern.no_std.edition2018]

    تفاوت‌های ویرایش 2018 پیش از ویرایش ۲۰۱۸، ‏std به‌طور پیش‌فرض در ریشهٔ crate تزریق می‌شد و با مشخص‌شدن no_std، ‏core جای آن را می‌گرفت. از ویرایش ۲۰۱۸، مستقل از وجود no_std، هیچ‌کدام به ریشهٔ crate تزریق نمی‌شوند.

    پیش‌درآمد macro_use

    [names.preludes.macro_use.intro]

    پیش‌درآمد macro_use شامل ماکروهایی از crateهای خارجی است که ویژگی macro_use اعمال‌شده روی یک extern crate آن‌ها را وارد کرده است.

    [names.preludes.tool]

    پیش‌درآمد ابزار

    [names.preludes.tool.intro]

    پیش‌درآمد ابزار نام ابزارهای خارجی را در فضای نام نوع دربرمی‌گیرد. برای جزئیات بخش ویژگی‌های ابزار را ببینید.

    [names.preludes.no_implicit_prelude]

    ویژگی no_implicit_prelude

    [names.preludes.no_implicit_prelude.intro]

    ویژگی no_implicit_prelude مانع واردشدن پیش‌درآمدهای ضمنی به حوزه می‌شود.

    مثال

    // The attribute can be applied to the crate root to affect
// all modules.
#![no_implicit_prelude]

// Or it can be applied to a module to only affect that module
// and its descendants.
#[no_implicit_prelude]
mod example {
    // ...
}
    [names.preludes.no_implicit_prelude.syntax]

    ویژگی no_implicit_prelude از نحو MetaWord استفاده می‌کند.

    [names.preludes.no_implicit_prelude.allowed-positions]

    ویژگی no_implicit_prelude را تنها می‌توان روی crate یا ماژول اعمال کرد.

    Note

    نکته rustc استفاده در موقعیت‌های دیگر را نادیده می‌گیرد، اما درباره‌اش lint صادر می‌کند. ممکن است در آینده به خطا تبدیل شود.

    [names.preludes.no_implicit_prelude.duplicates]

    ویژگی no_implicit_prelude را می‌توان هر تعداد بار روی یک فرم به‌کار برد.

    Note

    نکته rustc دربارهٔ استفاده‌های پس از مورد نخست lint صادر می‌کند.

    [names.preludes.no_implicit_prelude.excluded-preludes]

    ویژگی no_implicit_prelude مانع واردشدن پیش‌درآمد کتابخانهٔ استاندارد، پیش‌درآمد extern، پیش‌درآمد macro_use و پیش‌درآمد ابزار به حوزهٔ ماژول و فرزندانش می‌شود.

    [names.preludes.no_implicit_prelude.implicitly-imported-macros]

    Note

    نکته با وجود #![no_implicit_prelude]، ‏rustc اکنون برخی ماکروها را به‌طور ضمنی وارد حوزه می‌کند:

    • assert!
    • cfg!
    • cfg_select!
    • column!
    • compile_error!
    • concat!
    • concat_bytes!
    • env!
    • file!
    • format_args!
    • include!
    • include_bytes!
    • include_str!
    • line!
    • module_path!
    • option_env!
    • panic!
    • stringify!
    • unreachable!

    برای مثال، این کد کار می‌کند:

    #![no_implicit_prelude]
fn main() { assert!(true); }

    به این رفتار تکیه نکنید؛ ممکن است در آینده حذف شود. هنگام استفاده از #![no_implicit_prelude] همیشه آیتم‌های لازم را صریحاً وارد حوزه کنید.

    برای جزئیات Rust PR #62086 و Rust PR #139493 را ببینید.

    [names.preludes.no_implicit_prelude.lang]

    ویژگی no_implicit_prelude بر پیش‌درآمد زبان اثر نمی‌گذارد.

    [names.preludes.no_implicit_prelude.edition2018]

    [!EDITION-2018] در ویرایش ۲۰۱۵، ویژگی no_implicit_prelude بر پیش‌درآمد macro_use اثر نمی‌گذارد و همهٔ ماکروهای صادرشده از کتابخانهٔ استاندارد همچنان در پیش‌درآمد macro_use گنجانده می‌شوند. از ویرایش ۲۰۱۸ به بعد، این ویژگی پیش‌درآمد macro_use را حذف می‌کند.
