    [names.namespaces]

    فضاهای نام

    [names.namespaces.intro]

    فضای نام گروه‌بندی منطقی نام‌های اعلان‌شده است. نام‌ها بر پایهٔ نوع موجودیتی که به آن اشاره می‌کنند در فضاهای نام جداگانه قرار می‌گیرند. فضاهای نام اجازه می‌دهند وجود یک نام در یک فضای نام، با همان نام در فضای نامی دیگر تعارض نداشته باشد.

    چند فضای نام متفاوت وجود دارد که هرکدام نوع‌های متفاوتی از موجودیت‌ها را در خود دارند. استفاده از یک نام بر پایهٔ بافت، اعلان آن نام را در فضاهای نام مختلف جست‌وجو می‌کند؛ همان‌گونه که در فصل تفکیک نام توضیح داده شده است.

    برچسب‌های بلوک

    // Foo introduces a type in the type namespace and a constructor in the value
// namespace.
struct Foo(u32);

// The `Foo` macro is declared in the macro namespace.
macro_rules! Foo {
    () => {};
}

// `Foo` in the `f` parameter type refers to `Foo` in the type namespace.
// `'Foo` introduces a new lifetime in the lifetime namespace.
fn example<'Foo>(f: Foo) {
    // `Foo` refers to the `Foo` constructor in the value namespace.
    let ctor = Foo;
    // `Foo` refers to the `Foo` macro in the macro namespace.
    Foo!{}
    // `'Foo` introduces a label in the label namespace.
    'Foo: loop {
        // `'Foo` refers to the `'Foo` lifetime parameter, and `Foo`
        // refers to the type namespace.
        let x: &'Foo Foo;
        // `'Foo` refers to the label.
        break 'Foo;
    }
}
    [names.namespaces.without]

    موجودیت‌های نام‌دار بدون فضای نام

    [names.namespaces.without.intro]

    موجودیت‌های زیر نام صریح دارند، اما نامشان بخشی از فضای نام مشخصی نیست.

    فیلدها

    [names.namespaces.without.fields]

    با اینکه فیلدهای struct، ‏enum و union نام دارند، فیلدهای نام‌دار در فضای نام صریحی زندگی نمی‌کنند. تنها از طریق یک عبارت فیلد می‌توان به آن‌ها دسترسی یافت؛ این عبارت فقط نام فیلدهای همان نوع مشخصی را بررسی می‌کند که به آن دسترسی صورت می‌گیرد.

    اعلان‌های use

    [names.namespaces.without.use]

    یک اعلان use نام‌های مستعاری دارد که به حوزه وارد می‌کند، اما خود آیتم use به فضای نام مشخصی تعلق ندارد. در عوض، بسته به نوع آیتم واردشده می‌تواند نام‌های مستعار را به چند فضای نام معرفی کند.

    [names.namespaces.sub-namespaces]

    زیرفضای نام‌ها

    [names.namespaces.sub-namespaces.intro]

    فضای نام ماکرو به دو زیرفضای نام تقسیم می‌شود: یکی برای ماکروهای سبک علامت تعجب و دیگری برای ویژگی‌ها. هنگام تفکیک یک ویژگی، همهٔ ماکروهای سبک علامت تعجب موجود در حوزه نادیده گرفته می‌شوند. برعکس، تفکیک ماکروی سبک علامت تعجب نیز ماکروهای ویژگی موجود در حوزه را نادیده می‌گیرد. این کار مانع سایه‌انداختن یک سبک روی سبک دیگر می‌شود.

    برای مثال، ویژگی cfg و ماکروی cfg دو موجودیت متفاوت با نامی یکسان در فضای نام ماکرو هستند، اما همچنان می‌توان هرکدام را در بافت مربوط به خودش به‌کار برد.

    Note

    نکته واردکردن با use همچنان نمی‌تواند اتصال‌های تکراری هم‌نام را در یک ماژول یا بلوک ایجاد کند؛ زیرفضای نام تفاوتی در این قاعده ندارد.

    #[macro_export]
macro_rules! mymac {
    () => {};
}

use myattr::mymac; // error[E0252]: the name `mymac` is defined multiple times.
