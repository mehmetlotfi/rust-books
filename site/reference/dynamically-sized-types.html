    [dynamic-sized]

    نوع‌های با اندازهٔ پویا

    [dynamic-sized.intro]

    اندازهٔ بیشتر نوع‌ها ثابت است، هنگام کامپایل شناخته می‌شود و Traitِ Sized را پیاده‌سازی می‌کنند. نوعی که اندازه‌اش فقط هنگام اجرا معلوم می‌شود، نوع با اندازهٔ پویا (DST) یا به‌طور غیررسمی نوع بدون اندازه نام دارد. Sliceها، trait objectها و str نمونه‌هایی از DST هستند.

    [dynamic-sized.restriction]

    این نوع‌ها فقط در حالت‌های مشخصی قابل استفاده‌اند:

    [dynamic-sized.pointer-types]
    • نوع‌های اشاره‌گر به DST خودشان اندازه‌دارند، اما اندازه‌شان دو برابر اشاره‌گر به نوع اندازه‌دار است؛ زیرا فراداده نیز ذخیره می‌کنند:
      • اشاره‌گرهای slice تعداد عنصرها و اشاره‌گرهای str طول را بر حسب بایت ذخیره می‌کنند.
      • اشاره‌گرهای trait object یک اشاره‌گر به vtable ذخیره می‌کنند.
      • اشاره‌گر به struct یا tuple دارای دنبالهٔ بدون اندازه، همان فرادادهٔ اشاره‌گر به آن دنباله را ذخیره می‌کند.
    [dynamic-sized.question-sized]
    • می‌توان DSTها را به‌عنوان آرگومان نوع به پارامترهای نوع عمومی دارای قید ویژهٔ ?Sized داد. همچنین اگر اعلان نوع وابستهٔ متناظر قید ?Sized داشته باشد، می‌توان از آن‌ها در تعریف نوع وابسته استفاده کرد. هر پارامتر نوع یا نوع وابسته به‌طور پیش‌فرض قید Sized دارد، مگر آنکه این قید با ?Sized آسان‌گیرانه شود.
    [dynamic-sized.trait-impl]
    • Traitها را می‌توان برای DSTها پیاده‌سازی کرد. برخلاف پارامترهای نوع عمومی، در تعریف Trait مقدار پیش‌فرض Self: ?Sized است.
    [dynamic-sized.struct-field]
    • یک struct می‌تواند یک DST را به‌عنوان آخرین فیلد داشته باشد؛ این کار خود struct را نیز یک DST می‌کند.

    Note

    نکته متغیرها، پارامترهای تابع، آیتم‌های const و آیتم‌های static باید Sized باشند.

    [dynamic-sized.tail]

    دنبالهٔ بدون اندازه یک نوع، جزء با اندازهٔ پویایی است که فراداده اشاره‌گر به آن نوع توصیفش می‌کند. یک slice ‏([T]) و یک str هرکدام دنبالهٔ بدون اندازهٔ خودشان هستند که طول آن‌ها را توصیف می‌کند؛ یک trait object ‏(dyn Trait) نیز دنبالهٔ بدون اندازهٔ خودش است که اشاره‌گری به vtable آن را توصیف می‌کند. اگر یک struct—مطابق dynamic-sized.struct-field—یا tuple فیلد آخر بدون اندازه داشته باشد، دنبالهٔ بدون اندازهٔ آن همان دنبالهٔ بدون اندازهٔ آن فیلد است. نوع اندازه‌دار دنبالهٔ بدون اندازه ندارد.
