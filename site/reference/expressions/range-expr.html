    [expr.range]

    عبارت‌های بازه (Range expressions)

    [expr.range.syntax]

    Syntax
    RangeExpression →
          RangeExpr
        | RangeFromExpr
        | RangeToExpr
        | RangeFullExpr
        | RangeInclusiveExpr
        | RangeToInclusiveExpr

    RangeExpr → Expression .. Expression

    RangeFromExpr → Expression ..

    RangeToExpr → .. Expression

    RangeFullExpr → ..

    RangeInclusiveExpr → Expression ..= Expression

    RangeToInclusiveExpr → ..= Expression

    [expr.range.behavior]

    عملگرهای .. و ..= مطابق جدول زیر شیئی از یکی از گونه‌های std::ops::Range (یا core::ops::Range) می‌سازند:

    تولیدنحونوعبازه
    RangeExprstart..endstd::ops::Rangestart ≤ x < end
    RangeFromExprstart..std::ops::RangeFromstart ≤ x
    RangeToExpr..endstd::ops::RangeTox < end
    RangeFullExpr..std::ops::RangeFull-
    RangeInclusiveExprstart..=endstd::ops::RangeInclusivestart ≤ x ≤ end
    RangeToInclusiveExpr..=endstd::ops::RangeToInclusivex ≤ end

    نمونه‌ها:

    1..2;   // std::ops::Range
3..;    // std::ops::RangeFrom
..4;    // std::ops::RangeTo
..;     // std::ops::RangeFull
5..=6;  // std::ops::RangeInclusive
..=7;   // std::ops::RangeToInclusive
    [expr.range.equivalence]

    عبارت‌های زیر با یکدیگر معادل‌اند.

    let x = std::ops::Range {start: 0, end: 10};
let y = 0..10;

assert_eq!(x, y);
    [expr.range.for]

    می‌توان از بازه‌ها در حلقه‌های for استفاده کرد:

    for i in 1..11 {
    println!("{}", i);
}
