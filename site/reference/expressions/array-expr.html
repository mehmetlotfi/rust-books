    [expr.array]

    عبارت‌های آرایه و نمایه‌گذاری آرایه

    عبارت‌های آرایه

    [expr.array.syntax]

    Syntax
    ArrayExpression → [ ArrayElements? ]

    ArrayElements →
          Expression ( , Expression )* ,?
        | Expression ; Expression

    [expr.array.constructor]

    عبارت‌های آرایه آرایه‌ها را می‌سازند و دو شکل دارند.

    [expr.array.array]

    شکل نخست، همهٔ مقادیر آرایه را فهرست می‌کند.

    [expr.array.array-syntax]

    نحو این شکل، فهرستی از عبارت‌های هم‌نوع و جداشده با ویرگول است که میان براکت قرار می‌گیرند.

    [expr.array.array-behavior]

    این شکل آرایه‌ای می‌سازد که مقادیر را به همان ترتیب نوشته‌شدن در خود دارد.

    [expr.array.repeat]

    نحو شکل دوم، دو عبارت جداشده با نقطه‌ویرگول (;) و محصور در براکت است.

    [expr.array.repeat-operand]

    عبارت پیش از ;، عملوند تکرار نام دارد.

    [expr.array.length-operand]

    عبارت پس از ;، عملوند طول نام دارد.

    [expr.array.length-restriction]

    عملوند طول باید یک ثابت استنتاج‌شده یا یک عبارت ثابت از نوع usize باشد (برای نمونه، یک لفظ یا آیتم ثابت).

    const C: usize = 1;
let _: [u8; C] = [0; 1]; // Literal.
let _: [u8; C] = [0; C]; // Constant item.
let _: [u8; C] = [0; _]; // Inferred const.
let _: [u8; C] = [0; (((_)))]; // Inferred const.

    Note

    در یک عبارت آرایه، یک const استنتاج‌شده به‌عنوان عبارت تجزیه می‌شود، اما از نظر معنایی به‌عنوان نوعی جداگانه از آرگومان const generic در نظر گرفته می‌شود.

    [expr.array.repeat-behavior]

    عبارت آرایه‌ای به این شکل، آرایه‌ای با طولِ مقدار عملوند طول می‌سازد که هر عنصر آن کپی‌ای از عملوند تکرار است؛ یعنی [a; b] آرایه‌ای شامل b کپی از مقدار a می‌سازد.

    [expr.array.repeat-copy]

    اگر مقدار عملوند طول بزرگ‌تر از ۱ باشد، عملوند تکرار باید نوعی داشته باشد که Copy را پیاده‌سازی کند، یک عبارت بلوک const باشد یا مسیری به یک آیتم ثابت باشد.

    [expr.array.repeat-const-item]

    اگر عملوند تکرار یک بلوک const یا مسیری به یک آیتم ثابت باشد، به تعداد مشخص‌شده در عملوند طول ارزیابی می‌شود.

    [expr.array.repeat-evaluation-zero]

    اگر آن مقدار 0 باشد، بلوک const یا آیتم ثابت اصلاً ارزیابی نمی‌شود.

    [expr.array.repeat-non-const]

    عبارت‌هایی که نه بلوک const و نه مسیری به آیتم ثابت هستند، دقیقاً یک بار ارزیابی می‌شوند و سپس نتیجه به تعداد مقدار عملوند طول کپی می‌شود.

    [1, 2, 3, 4];
["a", "b", "c", "d"];
[0; 128];              // array with 128 zeros
[0u8, 0u8, 0u8, 0u8,];
[[1, 0, 0], [0, 1, 0], [0, 0, 1]]; // 2D array
const EMPTY: Vec<i32> = Vec::new();
[EMPTY; 2];
    [expr.array.index]

    عبارت‌های نمایه‌گذاری آرایه و برش

    [expr.array.index.syntax]

    Syntax
    IndexExpression → Expression [ Expression ]

    [expr.array.index.array]

    مقادیر دارای نوع آرایه و برش را می‌توان با نوشتن عبارتی از نوع usize (نمایه) درون براکت پس از آن‌ها نمایه‌گذاری کرد. اگر آرایه تغییرپذیر باشد، می‌توان به محل حافظهٔ حاصل مقداری نسبت داد.

    [expr.array.index.trait]

    برای نوع‌های دیگر، عبارت نمایه‌گذاری a[b] معادل *std::ops::Index::index(&a, b) است؛ یا در بافت یک عبارت مکان تغییرپذیر، معادل *std::ops::IndexMut::index_mut(&mut a, b) است. یک استثنا وجود دارد: وقتی عبارت نمایه‌گذاری مشمول گسترش طول‌عمر موقت شود، حوزهٔ موقت عبارت نمایه‌گذاری‌شدهٔ a نیز گسترش می‌یابد. همانند متدها، Rust عملیات ارجاع‌زدایی را نیز به‌طور پیاپی روی a درج می‌کند تا یک پیاده‌سازی پیدا شود.

    // The temporary holding the result of `vec![()]` is extended to
// live to the end of the block, so `x` may be used in subsequent
// statements.
let x = &vec![()][0];
x;
    // The temporary holding the result of `vec![()]` is dropped at the
// end of the statement, so it's an error to use `y` after.
let y = &*std::ops::Index::index(&vec![()], 0); // ERROR
y;
    [expr.array.index.zero-index]

    نمایهٔ آرایه‌ها و برش‌ها از صفر آغاز می‌شود.

    [expr.array.index.const]

    دسترسی به آرایه یک عبارت ثابت است؛ بنابراین با مقدار ثابت نمایه می‌توان کران‌ها را در زمان کامپایل بررسی کرد. در غیر این صورت، بررسی در زمان اجرا انجام می‌شود و در صورت شکست، نخ را وارد وضعیت panic می‌کند.

    // lint is deny by default.
#![warn(unconditional_panic)]

([1, 2, 3, 4])[2];        // Evaluates to 3

let b = [[1, 0, 0], [0, 1, 0], [0, 0, 1]];
b[1][2];                  // multidimensional array indexing

let x = (["a", "b"])[10]; // warning: index out of bounds

let n = 10;
let y = (["a", "b"])[n];  // panics

let arr = ["a", "b"];
arr[10];                  // warning: index out of bounds
    [expr.array.index.trait-impl]

    با پیاده‌سازی صفت‌های Index و IndexMut می‌توان عبارت نمایه‌گذاری آرایه را برای نوع‌هایی غیر از آرایه و برش نیز پیاده‌سازی کرد.
