    [expr.literal]

    عبارت‌های لفظی

    [expr.literal.syntax]

    Syntax
    LiteralExpression →
          CHAR_LITERAL
        | STRING_LITERAL
        | RAW_STRING_LITERAL
        | BYTE_LITERAL
        | BYTE_STRING_LITERAL
        | RAW_BYTE_STRING_LITERAL
        | C_STRING_LITERAL
        | RAW_C_STRING_LITERAL
        | INTEGER_LITERAL
        | FLOAT_LITERAL
        | true
        | false

    [expr.literal.intro]

    عبارت لفظی عبارتی است که به‌جای دنباله‌ای از توکن‌ها، از یک توکن واحد تشکیل می‌شود و به‌جای ارجاع به مقدار از راه نام یا قاعدهٔ ارزیابی دیگر، بی‌درنگ و مستقیماً مقداری را نشان می‌دهد که به آن ارزیابی می‌شود.

    [expr.literal.const-expr]

    لفظ گونه‌ای عبارت ثابت است و بنابراین عمدتاً در زمان کامپایل ارزیابی می‌شود.

    [expr.literal.literal-token]

    هر یک از شکل‌های واژگانی لفظ که پیش‌تر شرح داده شد می‌تواند یک عبارت لفظی بسازد؛ کلیدواژه‌های true و false نیز چنین‌اند.

    "hello";   // string type
'5';       // character type
5;         // integer type
    [expr.literal.string-representation]

    در توضیح‌های زیر، بازنمایی رشته‌ای یک توکن دنباله‌ای از نویسه‌های ورودی است که با تولید آن توکن در قطعهٔ دستور زبان Lexer تطبیق یافته‌اند.

    Note

    نکته این بازنمایی رشته‌ای هرگز شامل نویسهٔ U+000D (CR) نیست که بلافاصله U+000A (LF) پس از آن آمده باشد؛ این جفت پیش‌تر به یک U+000A (LF) تبدیل شده است.

    [expr.literal.escape]

    گریزها

    [expr.literal.escape.intro]

    توضیح عبارت‌های لفظی متنی در ادامه از چند شکل گریز استفاده می‌کند.

    [expr.literal.escape.sequence]

    هر شکل گریز با این موارد مشخص می‌شود:

    • یک دنبالهٔ گریز: دنباله‌ای از نویسه‌ها که همیشه با U+005C (\) آغاز می‌شود
    • یک مقدار گریخته: یا یک نویسهٔ واحد یا دنباله‌ای خالی از نویسه‌ها

    در تعریف گریزها در ادامه:

    • رقم هشت‌هشتی هر نویسه‌ای در بازهٔ [0-7] است.
    • رقم شانزده‌شانزدهی هر نویسه‌ای در بازه‌های [0-9]، [a-f] یا [A-F] است.
    [expr.literal.escape.simple]

    گریزهای ساده

    هر دنباله از نویسه‌ها که در ستون نخست جدول زیر ظاهر شود، یک دنبالهٔ گریز (escape sequence) است.

    در هر مورد، مقدار گریخته نویسه‌ای است که در خانهٔ متناظر ستون دوم آمده است.

    دنبالهٔ گریزمقدار گریخته
    \0U+0000 (NUL)
    \tU+0009 (HT)
    \nU+000A (LF)
    \rU+000D (CR)
    \"U+0022 (علامت نقل‌قول)
    \'U+0027 (آپوستروف)
    \\U+005C (بک‌اسلش)
    [expr.literal.escape.hex-octet]

    گریزهای ۸بیتی

    دنبالهٔ گریز از \x و سپس دو رقم شانزده‌شانزدهی تشکیل می‌شود.

    مقدار گریخته نویسه‌ای است که مقدار نرده‌ای یونی‌کد آن از تفسیر دو نویسهٔ پایانی دنبالهٔ گریز به‌عنوان یک عدد صحیح شانزده‌شانزدهی به دست می‌آید؛ گویی u8::from_str_radix با مبنای ۱۶ به کار رفته است.

    Note

    نکته بنابراین مقدار گریخته، مقدار نرده‌ای یونی‌کدی در بازهٔ u8 دارد.

    [expr.literal.escape.hex-ascii]

    گریزهای ۷بیتی

    دنبالهٔ گریز از \x، سپس یک رقم هشت‌هشتی و پس از آن یک رقم شانزده‌شانزدهی تشکیل می‌شود.

    مقدار گریخته نویسه‌ای است که مقدار نرده‌ای یونی‌کد آن از تفسیر دو نویسهٔ پایانی دنبالهٔ گریز به‌عنوان یک عدد صحیح شانزده‌شانزدهی به دست می‌آید؛ گویی u8::from_str_radix با مبنای ۱۶ به کار رفته است.

    [expr.literal.escape.unicode]

    گریزهای یونی‌کد

    دنبالهٔ گریز از \u{، سپس دنباله‌ای از نویسه‌ها که هر یک رقم شانزده‌شانزدهی یا _ هستند، و در پایان } تشکیل می‌شود.

    مقدار گریخته نویسه‌ای است که مقدار نرده‌ای یونی‌کد آن از تفسیر رقم‌های شانزده‌شانزدهی درون دنبالهٔ گریز به‌عنوان عددی صحیح با مبنای شانزده به دست می‌آید؛ گویی u32::from_str_radix با مبنای ۱۶ به کار رفته است.

    Note

    نکته شکل‌های مجاز توکن CHAR_LITERAL یا STRING_LITERAL وجود چنین نویسه‌ای را تضمین می‌کنند.

    [expr.literal.continuation]

    گریزهای ادامهٔ رشته

    دنبالهٔ گریز از \ که بلافاصله U+000A (LF) پس از آن می‌آید و همهٔ نویسه‌های فاصلهٔ بعدی تا نخستین نویسهٔ غیرفاصله تشکیل می‌شود. برای این منظور، نویسه‌های فاصله عبارت‌اند از U+0009 (HT)، U+000A (LF)، U+000D (CR) و U+0020 (SPACE).

    مقدار گریخته دنباله‌ای خالی از نویسه‌ها است.

    Note

    نکته اثر این شکل گریز آن است که ادامهٔ رشته، فاصله‌های پس از خود از جمله خط‌های جدید اضافی را نادیده می‌گیرد. بنابراین a، b و c برابرند:

    let a = "foobar";
let b = "foo\
         bar";
let c = "foo\

     bar";

assert_eq!(a, b);
assert_eq!(b, c);

    نادیده گرفتن خط‌های جدید اضافی، مانند مثال c، ممکن است گیج‌کننده و دور از انتظار باشد. این رفتار شاید در آینده تغییر کند. تا زمان تصمیم‌گیری، توصیه می‌شود به نادیده گرفتن چند خط جدید با ادامهٔ خط تکیه نکنید. برای اطلاعات بیشتر این مسئله را ببینید.

    [expr.literal.char]

    عبارت‌های لفظ نویسه‌ای

    [expr.literal.char.intro]

    عبارت لفظ نویسه‌ای از یک توکن CHAR_LITERAL واحد تشکیل می‌شود.

    [expr.literal.char.type]

    نوع عبارت، نوع ابتدایی char است.

    [expr.literal.char.no-suffix]

    توکن نباید پسوند داشته باشد.

    [expr.literal.char.literal-content]

    محتوای لفظی توکن دنبالهٔ نویسه‌هایی است که در بازنمایی رشته‌ای توکن پس از نخستین U+0027 (') و پیش از آخرین U+0027 (') قرار دارند.

    [expr.literal.char.represented]

    نویسهٔ بازنمایی‌شده در عبارت لفظی از محتوای لفظی به شکل زیر به دست می‌آید:

    [expr.literal.char.escape]
    • اگر محتوای لفظی یکی از شکل‌های زیر از دنبالهٔ گریز باشد، نویسهٔ بازنمایی‌شده مقدار گریختهٔ آن دنباله است:
      • گریزهای ساده
      • گریزهای ۷بیتی
      • گریزهای یونی‌کد
    [expr.literal.char.single]
    • در غیر این صورت، نویسهٔ بازنمایی‌شده همان نویسهٔ واحد تشکیل‌دهندهٔ محتوای لفظی است.
    [expr.literal.char.result]

    مقدار عبارت char متناظر با مقدار نرده‌ای یونی‌کد نویسهٔ بازنمایی‌شده است.

    Note

    نکته شکل‌های مجاز توکن CHAR_LITERAL تضمین می‌کنند این قواعد همیشه یک نویسهٔ واحد تولید کنند.

    نمونه‌هایی از عبارت‌های لفظ نویسه‌ای:

    'R';                               // R
'\'';                              // '
'\x52';                            // R
'\u{00E6}';                        // LATIN SMALL LETTER AE (U+00E6)
    [expr.literal.string]

    عبارت‌های لفظ رشته‌ای

    [expr.literal.string.intro]

    عبارت لفظ رشته‌ای از یک توکن STRING_LITERAL یا RAW_STRING_LITERAL واحد تشکیل می‌شود.

    [expr.literal.string.type]

    نوع عبارت یک ارجاع اشتراکی با طول‌عمر static به نوع ابتدایی str است؛ یعنی نوع آن &'static str است.

    [expr.literal.string.no-suffix]

    توکن نباید پسوند داشته باشد.

    [expr.literal.string.literal-content]

    محتوای لفظی توکن دنبالهٔ نویسه‌هایی است که در بازنمایی رشته‌ای توکن پس از نخستین U+0022 (") و پیش از آخرین U+0022 (") قرار دارند.

    [expr.literal.string.represented]

    رشتهٔ بازنمایی‌شده در عبارت لفظی دنباله‌ای از نویسه‌ها است که از محتوای لفظی به شکل زیر به دست می‌آید:

    [expr.literal.string.escape]

    • اگر توکن یک STRING_LITERAL باشد، هر دنبالهٔ گریز با یکی از شکل‌های زیر در محتوای لفظی با مقدار گریختهٔ همان دنباله جایگزین می‌شود.

      • گریزهای ساده
      • گریزهای ۷بیتی
      • گریزهای یونی‌کد
      • گریزهای ادامهٔ رشته

      این جایگزینی‌ها از چپ به راست انجام می‌شوند. برای نمونه، توکن "\\x41" به نویسه‌های \، x، 4 و 1 تبدیل می‌شود.

    [expr.literal.string.raw]
    • اگر توکن یک RAW_STRING_LITERAL باشد، رشتهٔ بازنمایی‌شده با محتوای لفظی یکسان است.
    [expr.literal.string.result]

    مقدار عبارت ارجاعی به یک str ایستا تخصیص‌یافته است که رمزگذاری UTF-8 رشتهٔ بازنمایی‌شده را در خود دارد.

    نمونه‌هایی از عبارت‌های لفظ رشته‌ای:

    "foo"; r"foo";                     // foo
"\"foo\""; r#""foo""#;             // "foo"

"foo #\"# bar";
r##"foo #"# bar"##;                // foo #"# bar

"\x52"; "R"; r"R";                 // R
"\\x52"; r"\x52";                  // \x52
    [expr.literal.byte-char]

    [expr.literal.byte-char.intro]

    [expr.literal.byte-char.literal]

    نوع عبارت، نوع ابتدایی u8 است.

    [expr.literal.byte-char.no-suffix]

    توکن نباید پسوند داشته باشد.

    [expr.literal.byte-char.literal-content]

    محتوای لفظی توکن دنبالهٔ نویسه‌هایی است که در بازنمایی رشته‌ای توکن پس از نخستین U+0027 (') و پیش از آخرین U+0027 (') قرار دارند.

    [expr.literal.byte-char.represented]

    نویسهٔ بازنمایی‌شده در عبارت لفظی از محتوای لفظی به شکل زیر به دست می‌آید:

    [expr.literal.byte-char.escape]
    • اگر محتوای لفظی یکی از شکل‌های زیر از دنبالهٔ گریز باشد، نویسهٔ بازنمایی‌شده مقدار گریختهٔ آن دنباله است:
      • گریزهای ساده
      • گریزهای ۸بیتی
    [expr.literal.byte-char.single]
    • در غیر این صورت، نویسهٔ بازنمایی‌شده همان نویسهٔ واحد تشکیل‌دهندهٔ محتوای لفظی است.
    [expr.literal.byte-char.result]

    مقدار عبارت، مقدار اسکالر یونی‌کد نویسهٔ نمایش‌داده‌شده است.

    Note

    نکته شکل‌های مجاز توکن BYTE_LITERAL تضمین می‌کنند این قواعد همیشه یک نویسهٔ واحد با مقدار نرده‌ای یونی‌کد در بازهٔ u8 تولید کنند.

    نمونه‌هایی از عبارت‌های لفظ بایتی:

    b'R';                              // 82
b'\'';                             // 39
b'\x52';                           // 82
b'\xA0';                           // 160
    [expr.literal.byte-string]

    عبارت‌های لفظ رشتهٔ بایتی

    [expr.literal.byte-string.intro]

    عبارت لفظ رشتهٔ بایتی از یک توکن BYTE_STRING_LITERAL یا RAW_BYTE_STRING_LITERAL واحد تشکیل می‌شود.

    [expr.literal.byte-string.type]

    نوع عبارت یک ارجاع اشتراکی با طول‌عمر static به آرایه‌ای است که نوع عنصر آن u8 است؛ یعنی نوع آن &'static [u8; N] است که در آن N شمار بایت‌های رشتهٔ بازنمایی‌شدهٔ شرح‌داده‌شده در ادامه است.

    [expr.literal.byte-string.no-suffix]

    توکن نباید پسوند داشته باشد.

    [expr.literal.byte-string.literal-content]

    محتوای لفظی توکن دنبالهٔ نویسه‌هایی است که در بازنمایی رشته‌ای توکن پس از نخستین U+0022 (") و پیش از آخرین U+0022 (") قرار دارند.

    [expr.literal.byte-string.represented]

    رشتهٔ بازنمایی‌شده در عبارت لفظی دنباله‌ای از نویسه‌ها است که از محتوای لفظی به شکل زیر به دست می‌آید:

    [expr.literal.byte-string.escape]

    • اگر توکن یک BYTE_STRING_LITERAL باشد، هر دنبالهٔ گریز با یکی از شکل‌های زیر در محتوای لفظی با مقدار گریختهٔ همان دنباله جایگزین می‌شود.

      • گریزهای ساده
      • گریزهای ۸بیتی
      • گریزهای ادامهٔ رشته

      این جایگزینی‌ها از چپ به راست انجام می‌شوند. برای نمونه، توکن b"\\x41" به نویسه‌های \، x، 4 و 1 تبدیل می‌شود.

    [expr.literal.byte-string.raw]
    • اگر توکن یک RAW_BYTE_STRING_LITERAL باشد، رشتهٔ بازنمایی‌شده با محتوای لفظی یکسان است.
    [expr.literal.byte-string.result]

    مقدار این عبارت، ارجاعی به یک آرایهٔ تخصیص‌یافته به‌صورت ایستا است که مقادیر اسکالر یونیکد نویسه‌های رشتهٔ نمایش‌داده‌شده را به همان ترتیب در خود دارد.

    Note

    نکته شکل‌های مجاز توکن‌های BYTE_STRING_LITERAL و RAW_BYTE_STRING_LITERAL تضمین می‌کنند این قواعد همیشه مقادیر عنصر آرایه را در بازهٔ u8 تولید کنند.

    نمونه‌هایی از عبارت‌های لفظ رشتهٔ بایتی:

    b"foo"; br"foo";                     // foo
b"\"foo\""; br#""foo""#;             // "foo"

b"foo #\"# bar";
br##"foo #"# bar"##;                 // foo #"# bar

b"\x52"; b"R"; br"R";                // R
b"\\x52"; br"\x52";                  // \x52
    [expr.literal.c-string]

    عبارت‌های لفظ رشتهٔ C

    [expr.literal.c-string.intro]

    عبارت لفظ رشتهٔ C از یک توکن C_STRING_LITERAL یا RAW_C_STRING_LITERAL واحد تشکیل می‌شود.

    [expr.literal.c-string.type]

    نوع عبارت یک ارجاع اشتراکی با طول‌عمر static به نوع CStr کتابخانهٔ استاندارد است؛ یعنی نوع آن &'static core::ffi::CStr است.

    [expr.literal.c-string.no-suffix]

    توکن نباید پسوند داشته باشد.

    [expr.literal.c-string.literal-content]

    محتوای لفظی توکن دنبالهٔ نویسه‌هایی است که در بازنمایی رشته‌ای توکن پس از نخستین " و پیش از آخرین " قرار دارند.

    [expr.literal.c-string.represented]

    بایت‌های بازنمایی‌شده در عبارت لفظی دنباله‌ای از بایت‌ها هستند که از محتوای لفظی به شکل زیر به دست می‌آیند:

    [expr.literal.c-string.escape]
    • اگر توکن یک C_STRING_LITERAL باشد، محتوای لفظی به‌صورت دنباله‌ای از اقلام در نظر گرفته می‌شود که هر یک یا یک نویسهٔ یونی‌کد به‌جز \ است یا یک گریز. دنبالهٔ اقلام به شکل زیر به دنباله‌ای از بایت‌ها تبدیل می‌شود:
      • هر نویسهٔ یونی‌کد واحد، بازنمایی UTF-8 خود را می‌افزاید.
      • هر گریز ساده، مقدار اسکالر یونیکدِ مقدار گریخته‌شدهٔ خود را فراهم می‌کند.
      • هر گریز ۸بیتی، یک بایت دارای مقدار نرده‌ای یونی‌کد مقدار گریختهٔ خود را می‌افزاید.
      • هر گریز یونی‌کد، بازنمایی UTF-8 مقدار گریختهٔ خود را می‌افزاید.
      • هر گریز ادامهٔ رشته هیچ بایتی نمی‌افزاید.
    [expr.literal.c-string.raw]
    • اگر توکن یک RAW_C_STRING_LITERAL باشد، بایت‌های بازنمایی‌شده همان رمزگذاری UTF-8 محتوای لفظی هستند.

    Note

    نکته شکل‌های مجاز توکن‌های C_STRING_LITERAL و RAW_C_STRING_LITERAL تضمین می‌کنند بایت‌های بازنمایی‌شده هرگز شامل بایت تهی نباشند.

    [expr.literal.c-string.result]

    مقدار عبارت ارجاعی به یک CStr ایستا تخصیص‌یافته است که آرایهٔ بایت‌هایش شامل بایت‌های بازنمایی‌شده و پس از آن یک بایت تهی است.

    نمونه‌هایی از عبارت‌های لفظ رشتهٔ C:

    c"foo"; cr"foo";                     // foo
c"\"foo\""; cr#""foo""#;             // "foo"

c"foo #\"# bar";
cr##"foo #"# bar"##;                 // foo #"# bar

c"\x52"; c"R"; cr"R";                // R
c"\\x52"; cr"\x52";                  // \x52

c"æ";                                // LATIN SMALL LETTER AE (U+00E6)
c"\u{00E6}";                         // LATIN SMALL LETTER AE (U+00E6)
c"\xC3\xA6";                         // LATIN SMALL LETTER AE (U+00E6)

c"\xE6".to_bytes();                  // [230]
c"\u{00E6}".to_bytes();              // [195, 166]
    [expr.literal.int]

    عبارت‌های لفظ عدد صحیح

    [expr.literal.int.intro]

    عبارت لفظ عدد صحیح از یک توکن INTEGER_LITERAL واحد تشکیل می‌شود.

    [expr.literal.int.suffix]

    اگر توکن پسوند داشته باشد، پسوند باید نام یکی از نوع‌های ابتدایی عدد صحیح باشد: u8، i8، u16، i16، u32، i32، u64، i64، u128، i128، usize یا isize؛ و عبارت همان نوع را خواهد داشت.

    [expr.literal.int.infer]

    اگر توکن پسوند نداشته باشد، نوع عبارت با استنباط نوع تعیین می‌شود:

    [expr.literal.int.inference-unique-type]
    • اگر بتوان یک نوع عدد صحیح را از بافت پیرامون برنامه به‌شکل یکتا تعیین کرد، عبارت همان نوع را دارد.
    [expr.literal.int.inference-default]
    • اگر بافت برنامه نوع را کمتر از اندازه مقید کند، نوع پیش‌فرض عدد صحیح علامت‌دار ۳۲بیتی i32 است.
    [expr.literal.int.inference-error]
    • اگر بافت برنامه نوع را بیش از اندازه مقید کند، خطای ایستای نوع رخ می‌دهد.

    نمونه‌هایی از عبارت‌های لفظ عدد صحیح:

    123;                               // type i32
123i32;                            // type i32
123u32;                            // type u32
123_u32;                           // type u32
let a: u64 = 123;                  // type u64

0xff;                              // type i32
0xff_u8;                           // type u8

0o70;                              // type i32
0o70_i16;                          // type i16

0b1111_1111_1001_0000;             // type i32
0b1111_1111_1001_0000i64;          // type i64

0usize;                            // type usize
    [expr.literal.int.representation]

    مقدار عبارت از بازنمایی رشته‌ای توکن به شکل زیر تعیین می‌شود:

    [expr.literal.int.radix]

    • مبنای عدد صحیح با بررسی دو نویسهٔ نخست رشته به شکل زیر انتخاب می‌شود:

      • 0b مبنای ۲ را نشان می‌دهد
      • 0o مبنای ۸ را نشان می‌دهد
      • 0x مبنای ۱۶ را نشان می‌دهد
      • در غیر این صورت مبنا ۱۰ است.
    [expr.literal.int.radix-prefix-stripped]
    • اگر مبنا ۱۰ نباشد، دو نویسهٔ نخست از رشته حذف می‌شوند.
    [expr.literal.int.type-suffix-stripped]
    • هر پسوندی از رشته حذف می‌شود.
    [expr.literal.int.separators-stripped]
    • همهٔ زیرخط‌ها از رشته حذف می‌شوند.
    [expr.literal.int.u128-value]
    • رشته به مقداری از نوع u128 تبدیل می‌شود؛ گویی u128::from_str_radix با مبنای انتخاب‌شده به کار رفته است. اگر مقدار در u128 نگنجد، خطای کامپایلر رخ می‌دهد.
    [expr.literal.int.cast]
    • مقدار u128 از راه یک تبدیل عددی به نوع عبارت تبدیل می‌شود.

    Note

    نکته اگر مقدار لفظ در نوع عبارت نگنجد، تبدیل نهایی آن را کوتاه می‌کند. rustc بررسی لینتی با نام overflowing_literals دارد که مقدار پیش‌فرض آن deny است و عبارت‌هایی را که این اتفاق در آن‌ها رخ می‌دهد رد می‌کند.

    Note

    نکته برای نمونه، -1i8 اعمال عملگر منفی‌سازی روی عبارت لفظی 1i8 است، نه یک عبارت لفظ عدد صحیح واحد. برای نکته‌های مربوط به بازنمایی منفی‌ترین مقدار یک نوع علامت‌دار، بخش سرریز را ببینید.

    [expr.literal.float]

    عبارت‌های لفظ ممیزشناور

    [expr.literal.float.intro]

    عبارت لفظ ممیزشناور یکی از دو شکل زیر را دارد:

    • یک توکن FLOAT_LITERAL واحد
    • یک توکن INTEGER_LITERAL واحد که پسوند دارد و نشانگر مبنا ندارد
    [expr.literal.float.suffix]

    اگر توکن پسوند داشته باشد، پسوند باید نام یکی از نوع‌های ابتدایی ممیزشناور، یعنی f32 یا f64، باشد و عبارت همان نوع را خواهد داشت.

    [expr.literal.float.infer]

    اگر توکن پسوند نداشته باشد، نوع عبارت با استنباط نوع تعیین می‌شود:

    [expr.literal.float.inference-unique-type]
    • اگر بتوان یک نوع ممیزشناور را از بافت پیرامون برنامه به‌شکل یکتا تعیین کرد، عبارت همان نوع را دارد.
    [expr.literal.float.inference-default]
    • اگر بافت برنامه نوع را کمتر از اندازه مقید کند، نوع پیش‌فرض f64 است.
    [expr.literal.float.inference-error]
    • اگر بافت برنامه نوع را بیش از اندازه مقید کند، خطای ایستای نوع رخ می‌دهد.

    نمونه‌هایی از عبارت‌های لفظ ممیزشناور:

    123.0f64;        // type f64
0.1f64;          // type f64
0.1f32;          // type f32
12E+99_f64;      // type f64
5f32;            // type f32
let x: f64 = 2.; // type f64
    [expr.literal.float.result]

    مقدار عبارت از بازنمایی رشته‌ای توکن به شکل زیر تعیین می‌شود:

    [expr.literal.float.type-suffix-stripped]
    • هر پسوندی از رشته حذف می‌شود.
    [expr.literal.float.separators-stripped]
    • همهٔ زیرخط‌ها از رشته حذف می‌شوند.
    [expr.literal.float.value]
    • رشته به نوع عبارت تبدیل می‌شود؛ گویی f32::from_str یا f64::from_str به کار رفته است.

    Note

    نکته برای نمونه، -1.0 اعمال عملگر منفی‌سازی روی عبارت لفظی 1.0 است، نه یک عبارت لفظ ممیزشناور واحد.

    Note

    نکته inf و NaN توکن لفظی نیستند. به‌جای عبارت لفظی می‌توان از ثابت‌های f32::INFINITY، f64::INFINITY، f32::NAN و f64::NAN استفاده کرد. در rustc، لفظی که آن‌قدر بزرگ باشد که به بی‌نهایت ارزیابی شود، بررسی لینت overflowing_literals را فعال می‌کند.

    [expr.literal.bool]

    عبارت‌های لفظ بولی

    [expr.literal.bool.intro]

    عبارت لفظ بولی از یکی از کلیدواژه‌های true یا false تشکیل می‌شود.

    [expr.literal.bool.result]

    نوع عبارت نوع بولی ابتدایی است و مقدار آن چنین است:

    • اگر کلیدواژه true باشد، درست
    • اگر کلیدواژه false باشد، نادرست
