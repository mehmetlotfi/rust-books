    [expr.tuple]

    عبارت‌های تاپل و نمایه‌گذاری تاپل

    عبارت‌های تاپل

    [expr.tuple.syntax]

    Syntax
    TupleExpression → ( TupleElements? )

    TupleElements → ( Expression , )+ Expression?

    [expr.tuple.result]

    یک عبارت تاپل مقادیر تاپل را می‌سازد.

    [expr.tuple.intro]

    نحو عبارت تاپل، فهرستی از عبارت‌های جداشده با ویرگول درون پرانتز است که عملوندهای مقداردهی اولیهٔ تاپل نامیده می‌شوند.

    [expr.tuple.unary-tuple-restriction]

    عبارت‌های تاپل تک‌عضوی (1-ary) برای اینکه از عبارت پرانتزی تمیز داده شوند، پس از عملوند مقداردهی اولیهٔ تاپل به یک ویرگول نیاز دارند.

    [expr.tuple.value]

    عبارت‌های تاپل عبارت مقدار هستند و به مقداری تازه‌ساخته‌شده از یک نوع تاپل ارزیابی می‌شوند.

    [expr.tuple.type]

    تعداد عملوندهای مقداردهی اولیهٔ تاپل، تعداد اعضای تاپل ساخته‌شده است.

    [expr.tuple.unit]

    عبارت تاپل بدون هیچ عملوند مقداردهی اولیه، تاپل واحد را تولید می‌کند.

    [expr.tuple.fields]

    در دیگر عبارت‌های تاپل، نخستین عملوند نوشته‌شده فیلد 0 را مقداردهی می‌کند و هر عملوند بعدی فیلد با شمارهٔ بعدی را مقدار می‌دهد. برای مثال، در عبارت تاپل ('a', 'b', 'c')، مقدار 'a' فیلد 0، مقدار 'b' فیلد 1 و مقدار 'c' فیلد 2 را مقداردهی می‌کند.

    نمونه‌هایی از عبارت‌های تاپل و نوع آن‌ها:

    عبارتنوع
    ()() (واحد)
    (0.0, 4.5)(f64, f64)
    ("x".to_string(), )(String, )
    ("a", 4usize, true)(&'static str, usize, bool)
    [expr.tuple-index]

    عبارت‌های نمایه‌گذاری تاپل

    [expr.tuple-index.syntax]

    Syntax
    TupleIndexingExpression → Expression . TUPLE_INDEX

    [expr.tuple-index.intro]

    یک عبارت نمایه‌گذاری تاپل به فیلدهای تاپل‌ها و ساختارهای تاپل دسترسی پیدا می‌کند.

    نحو عبارت نمایه‌گذاری تاپل از یک عبارت به‌نام عملوند تاپل، سپس یک . و در پایان نمایهٔ تاپل تشکیل می‌شود.

    [expr.tuple-index.index-syntax]

    نحو نمایهٔ تاپل یک لفظ ده‌دهی بدون صفر آغازین، زیرخط یا پسوند است. برای مثال، 0 و 2 نمایه‌های معتبر تاپل هستند، اما 01، ‏0_ و 0i32 معتبر نیستند.

    [expr.tuple-index.required-type]

    نوع عملوند تاپل باید یک نوع تاپل یا ساختار تاپل باشد.

    [expr.tuple-index.index-name-operand]

    نمایهٔ تاپل باید نام یکی از فیلدهای نوع عملوند تاپل باشد.

    [expr.tuple-index.result]

    ارزیابی عبارت نمایه‌گذاری تاپل، به‌جز ارزیابی عملوند تاپل، اثر جانبی دیگری ندارد. این عبارت به‌عنوان یک عبارت مکان به محل فیلدی از عملوند تاپل ارزیابی می‌شود که نامش با نمایهٔ تاپل یکسان است.

    نمونه‌هایی از عبارت‌های نمایه‌گذاری تاپل:

    // Indexing a tuple
let pair = ("a string", 2);
assert_eq!(pair.1, 2);

// Indexing a tuple struct
struct Point(f32, f32);
let point = Point(1.0, 0.0);
assert_eq!(point.0, 1.0);
assert_eq!(point.1, 0.0);

    Note

    نکته برخلاف عبارت‌های دسترسی به فیلد، عبارت نمایه‌گذاری تاپل می‌تواند عملوند تابع یک عبارت فراخوانی باشد، زیرا نام متد نمی‌تواند عدد باشد و در نتیجه با فراخوانی متد اشتباه نمی‌شود.

    Note

    نکته با اینکه آرایه‌ها و برش‌ها نیز عنصر دارند، برای دسترسی به عناصرشان باید از یک عبارت نمایه‌گذاری آرایه یا برش یا یک الگوی برش استفاده کنید.
