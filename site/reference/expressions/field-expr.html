مرجع زبان RustThe Rust Reference

    [expr.field]

    عبارت‌های دسترسی به فیلد

    [expr.field.syntax]

    Syntax
    FieldExpression → Expression . IDENTIFIER

    [expr.field.intro]

    عبارت فیلد یک عبارت مکان است که به مکان فیلدی از یک struct یا union ارزیابی می‌شود.

    [expr.field.mut]

    اگر عملوند تغییرپذیر باشد، عبارت فیلد نیز تغییرپذیر است.

    [expr.field.form]

    نحو عبارت فیلد شامل یک عبارت به نام عملوند ظرف، سپس . و در پایان یک شناسه است.

    [expr.field.not-method-call]

    پس از عبارت فیلد نمی‌توان فهرستی پرانتزی از عبارت‌های جداشده با ویرگول آورد، زیرا چنین نحوی به‌عنوان عبارت فراخوانی متد تجزیه می‌شود. به بیان دیگر، عبارت فیلد نمی‌تواند عملوند تابع در یک عبارت فراخوانی باشد.

    Note

    نکته برای استفاده از عبارت فیلد در عبارت فراخوانی، آن را در یک عبارت پرانتزی قرار دهید.

    struct HoldsCallable<F: Fn()> { callable: F }
let holds_callable = HoldsCallable { callable: || () };

// Invalid: Parsed as calling the method "callable"
// holds_callable.callable();

// Valid
(holds_callable.callable)();

    نمونه‌ها:

    mystruct.myfield;
foo().x;
(Struct {a: 10, b: 20}).a;
(mystruct.function_field)() // Call expression containing a field expression
    [expr.field.autoref-deref]

    اشاره‌زدایی خودکار

    اگر نوع عملوند ظرف—بسته به تغییرپذیر بودن عملوند—Deref یا DerefMut را پیاده‌سازی کند، به تعداد لازم خودکار اشاره‌زدایی می‌شود تا دسترسی به فیلد ممکن شود. این فرایند به‌اختصار autoderef نیز نامیده می‌شود.

    [expr.field.borrow]

    قرض‌گیری

    هنگام قرض‌گیری، فیلدهای یک struct یا ارجاع به struct موجودیت‌هایی جداگانه در نظر گرفته می‌شوند. اگر struct در متغیری محلی ذخیره شده باشد و Drop را پیاده‌سازی نکند، همین قاعده دربارهٔ بیرون‌کشیدن هر فیلد نیز برقرار است. اگر اشاره‌زدایی خودکار از میان نوع‌های تعریف‌شده به‌دست کاربر—غیر از Box—انجام شود، این قاعده کاربرد ندارد.

    struct A { f1: String, f2: String, f3: String }
let mut x: A;
x = A {
    f1: "f1".to_string(),
    f2: "f2".to_string(),
    f3: "f3".to_string()
};
let a: &mut String = &mut x.f1; // x.f1 borrowed mutably
let b: &String = &x.f2;         // x.f2 borrowed immutably
let c: &String = &x.f2;         // Can borrow again
let d: String = x.f3;           // Move out of x.f3
