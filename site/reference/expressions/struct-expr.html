    [expr.struct.intro]

    یک عبارت ساختار مقداری از نوع struct، ‏enum یا union می‌سازد. این عبارت از مسیری به یک آیتم ساختار، گونهٔ enum یا union و سپس مقادیر فیلدهای آن آیتم تشکیل می‌شود.

    موارد زیر نمونه‌هایی از عبارت ساختار هستند:

    struct Point { x: f64, y: f64 }
struct NothingInMe { }
mod game { pub struct User<'a> { pub name: &'a str, pub age: u32, pub score: usize } }
enum Enum { Variant {} }
Point {x: 10.0, y: 20.0};
NothingInMe {};
let u = game::User {name: "Joe", age: 35, score: 100_000};
Enum::Variant {};

    Note

    نکته ساختارهای تاپل و گونه‌های تاپل enum معمولاً با یک عبارت فراخوانی ساخته می‌شوند که به سازنده در فضای نام مقدار اشاره می‌کند. این روش با عبارت ساختاری که از آکولاد استفاده می‌کند و به سازنده در فضای نام نوع اشاره دارد متفاوت است.

    struct Position(i32, i32, i32);
Position(0, 0, 0);  // Typical way of creating a tuple struct.
let c = Position;  // `c` is a function that takes 3 arguments.
let pos = c(8, 6, 7);  // Creates a `Position` value.

enum Version { Triple(i32, i32, i32) };
Version::Triple(0, 0, 0);
let f = Version::Triple;
let ver = f(8, 6, 7);

    آخرین قطعهٔ مسیر فراخوانی نمی‌تواند به یک نام مستعار نوع اشاره کند:

    trait Tr { type T; }
impl<T> Tr for T { type T = T; }

struct Tuple();
enum Enum { Tuple() }

// <Unit as Tr>::T(); // causes an error -- `::T` is a type, not a value
<Enum as Tr>::T::Tuple(); // OK

    ساختارهای واحد و گونه‌های واحد enum معمولاً با یک عبارت مسیر ساخته می‌شوند که به ثابت در فضای نام مقدار اشاره می‌کند.

    struct Gamma;
// Gamma unit value, referring to the const in the value namespace.
let a = Gamma;
// Exact same value as `a`, but constructed using a struct expression
// referring to the type namespace.
let b = Gamma {};

enum ColorSpace { Oklch }
let c = ColorSpace::Oklch;
let d = ColorSpace::Oklch {};
    [expr.struct.field]

    عبارت ساختار فیلدی

    [expr.struct.field.intro]

    عبارت ساختاری با فیلدهای محصور در آکولاد اجازه می‌دهد مقدار هر فیلد را با هر ترتیبی مشخص کنید. نام فیلد با دونقطه از مقدار آن جدا می‌شود.

    [expr.struct.field.union-constraint]

    مقداری از نوع union تنها با این نحو ساخته می‌شود و باید دقیقاً یک فیلد را مشخص کند.

    [expr.struct.update]

    نحو به‌روزرسانی تابعی

    [expr.struct.update.intro]

    عبارت ساختاری که مقداری از یک نوع struct می‌سازد، می‌تواند برای نمایش به‌روزرسانی تابعی با نحو .. و سپس یک عبارت پایان یابد.

    [expr.struct.update.base-same-type]

    عبارت پس از .. (پایه) باید با نوع ساختار جدیدی که ساخته می‌شود یکسان باشد.

    [expr.struct.update.fields]

    کل عبارت برای فیلدهای مشخص‌شده از مقادیر داده‌شده استفاده می‌کند و فیلدهای باقی‌مانده را از عبارت پایه جابه‌جا یا کپی می‌کند.

    [expr.struct.update.visibility-constraint]

    همانند همهٔ عبارت‌های ساختار، تمام فیلدهای ساختار باید قابل مشاهده باشند؛ حتی فیلدهایی که صریحاً نام برده نشده‌اند.

    struct Point3d { x: i32, y: i32, z: i32 }
let mut base = Point3d {x: 1, y: 2, z: 3};
let y_ref = &mut base.y;
Point3d {y: 0, z: 10, .. base}; // OK, only base.x is accessed
drop(y_ref);
    [expr.struct.brace-restricted-positions]

    عبارت ساختار را نمی‌توان مستقیماً در سر یک عبارت loop یا if، یا در بررسی‌شوندهٔ یک عبارت if let یا match به‌کار برد. بااین‌حال، اگر عبارت ساختار درون عبارت دیگری—برای نمونه داخل پرانتز—قرار گیرد، استفاده از آن در این موقعیت‌ها مجاز است.

    [expr.struct.tuple-field]

    نام فیلدها می‌تواند مقدار صحیح ده‌دهی باشد تا نمایه‌های مورد استفاده در ساخت ساختارهای تاپل را مشخص کند. این قابلیت را می‌توان همراه ساختار پایه به‌کار برد تا نمایه‌های مشخص‌نشدهٔ باقی‌مانده پر شوند:

    struct Color(u8, u8, u8);
let c1 = Color(0, 0, 0);  // Typical way of creating a tuple struct.
let c2 = Color{0: 255, 1: 127, 2: 0};  // Specifying fields by index.
let c3 = Color{1: 0, ..c2};  // Fill out all other fields using a base struct.
    [expr.struct.field.named]

    شکل کوتاه مقداردهی فیلد ساختار

    هنگام مقداردهی اولیهٔ یک ساختار داده (struct، ‏enum یا union) با فیلدهای نام‌دار (نه شماره‌دار)، می‌توان fieldname را به‌عنوان شکل کوتاه fieldname: fieldname نوشت. این کار نحوی فشرده‌تر با تکرار کمتر فراهم می‌کند. برای مثال:

    struct Point3d { x: i32, y: i32, z: i32 }
let x = 0;
let y_value = 0;
let z = 0;
Point3d { x: x, y: y_value, z: z };
Point3d { x, y: y_value, z };
