    [expr.method]

    عبارت‌های فراخوانی متد

    [expr.method.syntax]

    Syntax
    MethodCallExpression → Expression . PathExprSegment ( CallParams? )

    [expr.method.intro]

    یک فراخوانی متد از یک عبارت (گیرنده)، سپس یک نقطه، یک قطعه از مسیر عبارت و فهرستی از عبارت‌ها درون پرانتز تشکیل می‌شود.

    [expr.method.target]

    فراخوانی‌های متد به متدهای وابسته در صفت‌های مشخص تفکیک می‌شوند: اگر نوع دقیق self در سمت چپ معلوم باشد، اعزام به متد به‌صورت ایستا انجام می‌شود؛ و اگر عبارت سمت چپ یک شیء صفت غیرمستقیم باشد، اعزام پویا خواهد بود.

    let pi: Result<f32, _> = "3.14".parse();
let log_pi = pi.unwrap_or(1.0).log(2.72);
assert!(1.14 < log_pi && log_pi < 1.15)
    [expr.method.autoref-deref]

    هنگام جست‌وجوی یک فراخوانی متد، ممکن است گیرنده برای فراخوانی متد به‌طور خودکار ارجاع‌زدایی یا قرض گرفته شود. از آنجا که ممکن است چند متد قابل فراخوانی وجود داشته باشد، این کار به فرایند جست‌وجوی پیچیده‌تری نسبت به تابع‌های دیگر نیاز دارد. روال زیر به‌کار می‌رود:

    [expr.method.candidate-receivers]

    گام نخست، ساختن فهرستی از نوع‌های گیرندهٔ نامزد است. برای به‌دست‌آوردن آن‌ها، نوع عبارت گیرنده را به‌طور پیاپی ارجاع‌زدایی کنید و هر نوعی را که دیده می‌شود به فهرست بیفزایید؛ سپس در پایان، یک وادارسازی بدون اندازه برای آرایه امتحان کنید و اگر موفق بود، نوع حاصل را نیز به فهرست اضافه کنید.

    [expr.method.candidate-receivers-refs]

    سپس برای هر نامزد T، نوع‌های &T و &mut T را بلافاصله پس از T به فهرست اضافه کنید.

    برای نمونه، اگر گیرنده نوع Box<[i32;2]> داشته باشد، نوع‌های نامزد به‌ترتیب عبارت‌اند از: Box<[i32;2]>، ‏&Box<[i32;2]>، ‏&mut Box<[i32;2]>، ‏[i32; 2] (از راه ارجاع‌زدایی)، ‏&[i32; 2]، ‏&mut [i32; 2]، ‏[i32] (از راه وادارسازی بدون اندازه)، ‏&[i32] و در پایان &mut [i32].

    [expr.method.candidate-search]

    پس از آن، برای هر نوع نامزد T، در محل‌های زیر به‌دنبال متدی قابل مشاهده با گیرنده‌ای از همان نوع بگردید:

    1. متدهای ذاتی T (متدهایی که مستقیماً روی T پیاده‌سازی شده‌اند).
    2. هر متدی که یک صفت قابل مشاهده و پیاده‌سازی‌شده توسط T فراهم می‌کند. اگر T یک پارامتر نوع باشد، ابتدا متدهایی جست‌وجو می‌شوند که کران‌های صفت روی T فراهم کرده‌اند؛ سپس همهٔ متدهای باقی‌مانده در حوزه جست‌وجو می‌شوند.

    Note

    نکته جست‌وجو برای هر نوع و به‌ترتیب انجام می‌شود و گاهی می‌تواند نتیجه‌ای غافلگیرکننده داشته باشد. کد زیر In trait impl! را چاپ می‌کند، زیرا متدهای &self زودتر جست‌وجو می‌شوند و متد صفت پیش از متد &mut self ساختار پیدا می‌شود.

    struct Foo {}

trait Bar {
  fn bar(&self);
}

impl Foo {
  fn bar(&mut self) {
    println!("In struct impl!")
  }
}

impl Bar for Foo {
  fn bar(&self) {
    println!("In trait impl!")
  }
}

fn main() {
  let mut f = Foo{};
  f.bar();
}
    [expr.method.ambiguous-target]

    اگر این فرایند چند نامزد ممکن به‌دست دهد، خطا رخ می‌دهد و برای ممکن‌شدن فراخوانی متد باید گیرنده به یک نوع گیرندهٔ مناسب تبدیل شود.

    [expr.method.receiver-constraints]

    این فرایند تغییرپذیری یا طول‌عمر گیرنده و نیز unsafe بودن متد را در نظر نمی‌گیرد. پس از یافتن متد، اگر به یک یا چند مورد از این دلایل نتوان آن را فراخوانی کرد، نتیجه خطای کامپایلر خواهد بود.

    [expr.method.ambiguous-search]

    اگر در یکی از گام‌ها بیش از یک متد ممکن وجود داشته باشد—برای نمونه، هنگامی که متدهای عمومی یا صفت‌ها یکسان تلقی شوند—خطای کامپایلر رخ می‌دهد. در این موارد برای فراخوانی متد یا تابع باید از نحو رفع ابهام فراخوانی تابع استفاده کرد.

    [expr.method.edition2021]

    تفاوت‌های ویرایش 2021 پیش از ویرایش ۲۰۲۱، هنگام جست‌وجوی متدهای قابل مشاهده، اگر نوع گیرندهٔ نامزد یک نوع آرایه بود، متدهایی که صفت IntoIterator کتابخانهٔ استاندارد فراهم می‌کرد نادیده گرفته می‌شدند.

    ویرایشی که برای این منظور استفاده می‌شود، با توکنی تعیین می‌شود که نام متد را نمایش می‌دهد.

    ممکن است این حالت ویژه در آینده حذف شود.

    Warning

    هشدار در شیءهای صفت، اگر متدی ذاتی هم‌نام با یک متد صفت وجود داشته باشد، تلاش برای فراخوانی آن در یک عبارت فراخوانی متد به خطای کامپایلر منجر می‌شود. در عوض می‌توانید متد را با نحو رفع ابهام فراخوانی تابع فراخوانی کنید؛ در این حالت متد صفت فراخوانی می‌شود، نه متد ذاتی. راهی برای فراخوانی متد ذاتی وجود ندارد. بنابراین کافی است روی شیءهای صفت، متد ذاتی هم‌نام با متد صفت تعریف نکنید.
