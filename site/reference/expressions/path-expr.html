    [expr.path]

    عبارت‌های مسیر (Path expressions)

    [expr.path.syntax]

    Syntax
    PathExpression →
          PathInExpression
        | QualifiedPathInExpression

    [expr.path.intro]

    یک مسیر که در بافت عبارت به کار رود، یا یک متغیر محلی را مشخص می‌کند یا یک آیتم را.

    [expr.path.place]

    عبارت‌های مسیری که به متغیرهای محلی یا ایستا حل (resolve) شوند، عبارت‌های مکان هستند؛ مسیرهای دیگر عبارت‌های مقدار به شمار می‌روند.

    [expr.path.safety]

    استفاده از متغیر static mut به یک بلوک unsafe نیاز دارد.

    mod globals {
    pub static STATIC_VAR: i32 = 5;
    pub static mut STATIC_MUT_VAR: i32 = 7;
}
let local_var = 3;
local_var;
globals::STATIC_VAR;
unsafe { globals::STATIC_MUT_VAR };
let some_constructor = Some::<i32>;
let push_integer = Vec::<i32>::push;
let slice_reverse = <[i32]>::reverse;
    [expr.path.const]

    ارزیابی ثابت‌های وابسته همانند بلوک‌های const انجام می‌شود.
