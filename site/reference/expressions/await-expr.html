    [expr.await]

    عبارت‌های Await

    [expr.await.syntax]

    Syntax
    AwaitExpression → Expression . await

    [expr.await.intro]

    عبارت await سازه‌ای نحوی برای تعلیق محاسبه‌ای است که پیاده‌سازی std::future::IntoFuture فراهم می‌کند؛ تعلیق تا زمانی ادامه دارد که Future آمادهٔ تولید مقدار شود.

    [expr.await.construct]

    نحو عبارت await از یک عبارت با نوع پیاده‌کنندهٔ Traitِ IntoFuture—به نام عملوند Future—سپس tokenِ . و پس از آن کلیدواژهٔ await تشکیل می‌شود.

    [expr.await.allowed-positions]

    عبارت await فقط در یک زمینهٔ async مانند async fn، ‏closureِ async یا بلوک async مجاز است.

    [expr.await.effects]

    به‌طور دقیق‌تر، عبارت await اثرهای زیر را دارد:

    1. با فراخوانی IntoFuture::into_future روی عملوند Future، یک Future می‌سازد.
    2. Future را در مقدار Future با نام tmp ارزیابی می‌کند.
    3. مقدار tmp را با Pin::new_unchecked پین می‌کند.
    4. Future پین‌شده با فراخوانی متد Future::poll و دادن زمینهٔ Task جاری به آن poll می‌شود.
    5. اگر poll مقدار Poll::Pending بازگرداند، Future نیز Poll::Pending می‌دهد و وضعیتش تعلیق می‌شود؛ هنگامی که زمینهٔ async دربرگیرنده دوباره poll شود، اجرا به مرحلهٔ ۳ بازمی‌گردد.
    6. در غیر این صورت poll باید Poll::Ready بازگردانده باشد؛ مقدار درون واریانت Poll::Ready نتیجهٔ خود عبارت await می‌شود.
    [expr.await.edition2018]

    تفاوت‌های ویرایش 2018 عبارت‌های await از Rust 2018 به بعد در دسترس‌اند.

    [expr.await.task]

    زمینهٔ Task

    زمینهٔ Task همان Contextی است که هنگام poll شدن زمینهٔ async جاری به آن داده شده است. چون عبارت‌های await فقط در زمینهٔ async مجازند، باید یک زمینهٔ Task در دسترس باشد.

    [expr.await.desugar]

    تبدیل تقریبی نحو

    در عمل، عبارت await تقریباً با تبدیل نحوی غیرهنجاری زیر برابر است:

    match operand.into_future() {
    mut pinned => loop {
        let mut pin = unsafe { Pin::new_unchecked(&mut pinned) };
        match Pin::future::poll(Pin::borrow(&mut pin), &mut current_context) {
            Poll::Ready(r) => break r,
            Poll::Pending => yield Poll::Pending,
        }
    }
}

    در این شبه‌کد، yield مقدار Poll::Pending را بازمی‌گرداند و هنگام فراخوانی دوباره، اجرا را از همان نقطه ادامه می‌دهد. متغیر current_context به context گرفته‌شده از محیط async اشاره دارد.
