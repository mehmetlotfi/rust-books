    [expr.loop]

    حلقه‌ها و دیگر عبارت‌های شکست‌پذیر

    [expr.loop.syntax]

    Syntax
    LoopExpression →
        LoopLabel? (
            InfiniteLoopExpression
          | PredicateLoopExpression
          | IteratorLoopExpression
          | LabelBlockExpression
        )

    [expr.loop.intro]

    Rust از چهار عبارت حلقه پشتیبانی می‌کند:

    • یک عبارت loop حلقه‌ای بی‌پایان را نشان می‌دهد.
    • یک عبارت while تا زمانی تکرار می‌شود که یک گزاره نادرست شود.
    • یک عبارت for مقادیر را از یک تکرارگر بیرون می‌کشد و تا خالی شدن تکرارگر تکرار می‌شود.
    • یک عبارت بلوک برچسب‌دار حلقه را دقیقاً یک بار اجرا می‌کند، اما امکان خروج زودهنگام با break را می‌دهد.
    [expr.loop.break-label]

    هر چهار گونهٔ حلقه از عبارت‌های break و برچسب‌ها پشتیبانی می‌کنند.

    [expr.loop.continue-label]

    همهٔ آن‌ها به‌جز عبارت‌های بلوک برچسب‌دار از عبارت‌های continue پشتیبانی می‌کنند.

    [expr.loop.explicit-result]

    تنها loop و عبارت‌های بلوک برچسب‌دار از ارزیابی به مقادیر غیرساده پشتیبانی می‌کنند.

    [expr.loop.infinite]

    حلقه‌های بی‌پایان

    [expr.loop.infinite.syntax]

    Syntax
    InfiniteLoopExpression → loop BlockExpression

    [expr.loop.infinite.intro]

    عبارت loop اجرای بدنهٔ خود را پیوسته تکرار می‌کند: loop { println!("I live."); }.

    [expr.loop.infinite.diverging]

    عبارت loop بدون عبارت break وابسته، واگرا است و نوع ! دارد.

    [expr.loop.infinite.break]

    عبارت loop دارای عبارت یا عبارت‌های break وابسته ممکن است پایان یابد و باید نوعی سازگار با مقدار عبارت یا عبارت‌های break داشته باشد.

    [expr.loop.while]

    حلقه‌های گزاره‌ای

    [expr.loop.while.syntax]

    Syntax
    PredicateLoopExpression → while Conditions BlockExpression

    [expr.loop.while.intro]

    عبارت حلقهٔ while اجازه می‌دهد ارزیابی یک بلوک تا زمانی تکرار شود که مجموعه‌ای از شرط‌ها درست باقی بمانند.

    [expr.loop.while.condition]

    عملوندهای شرط باید یا یک Expression با نوع بولی باشند یا یک تطبیق شرطی let. اگر همهٔ عملوندهای شرط به true ارزیابی شوند و همهٔ الگوهای let با عبارت بررسی‌شوندهٔ خود با موفقیت تطبیق یابند، بلوک بدنهٔ حلقه اجرا می‌شود.

    [expr.loop.while.repeat]

    پس از اجرای موفق بدنهٔ حلقه، عملوندهای شرط دوباره ارزیابی می‌شوند تا مشخص شود آیا بدنه باید بار دیگر اجرا شود یا نه.

    [expr.loop.while.exit]

    اگر یکی از عملوندهای شرط به false ارزیابی شود یا الگویی از let با عبارت بررسی‌شوندهٔ خود تطبیق نیابد، بدنه اجرا نمی‌شود و اجرا پس از عبارت while ادامه پیدا می‌کند.

    [expr.loop.while.eval]

    عبارت while به () ارزیابی می‌شود.

    یک نمونه:

    let mut i = 0;

while i < 10 {
    println!("hello");
    i = i + 1;
}
    [expr.loop.while.let]

    الگوهای while let

    [expr.loop.while.let.intro]

    الگوهای let در شرط while اجازه می‌دهند هنگام تطبیق موفق الگو، متغیرهای جدیدی وارد دامنه شوند. مثال‌های زیر مقیدسازی با الگوهای let را نشان می‌دهند:

    let mut x = vec![1, 2, 3];

while let Some(y) = x.pop() {
    println!("y = {}", y);
}

while let _ = 5 {
    println!("Irrefutable patterns are always true");
    break;
}
    [expr.loop.while.let.desugar]

    یک حلقهٔ while let معادل عبارت loop دارای یک عبارت match به شکل زیر است.

    'label: while let PATS = EXPR {
    /* loop body */
}

    معادل است با

    'label: loop {
    match EXPR {
        PATS => { /* loop body */ },
        _ => break,
    }
}
    [expr.loop.while.let.or-pattern]

    با عملگر | می‌توان چند الگو مشخص کرد. معنای آن همانند | در عبارت‌های match است:

    let mut vals = vec![2, 3, 1, 2, 2];
while let Some(v @ 1) | Some(v @ 2) = vals.pop() {
    // Prints 2, 2, then 1
    println!("{}", v);
}
    [expr.loop.while.chains]

    زنجیره‌های شرط while

    [expr.loop.while.chains.intro]

    چند عملوند شرط را می‌توان با && جدا کرد. معنا و محدودیت‌های این زنجیره‌ها همانند زنجیره‌های شرط if است.

    مثال زیر زنجیر کردن چند عبارت، ترکیب مقیدسازی‌های let با عبارت‌های بولی و امکان ارجاع عبارت‌ها به مقیدسازی‌های الگوی عبارت‌های پیشین را نشان می‌دهد:

    fn main() {
    let outer_opt = Some(Some(1i32));

    while let Some(inner_opt) = outer_opt
        && let Some(number) = inner_opt
        && number == 1
    {
        println!("Peek a boo");
        break;
    }
}
    [expr.loop.for]

    حلقه‌های تکرارگر

    [expr.loop.for.syntax]

    Syntax
    IteratorLoopExpression →
        for Pattern in Expressionexcept StructExpression BlockExpression

    [expr.loop.for.intro]

    عبارت for سازه‌ای نحوی برای پیمایش عنصرهایی است که یک پیاده‌سازی std::iter::IntoIterator فراهم می‌کند.

    [expr.loop.for.condition]

    اگر تکرارگر مقداری تولید کند، آن مقدار با الگوی انکارناپذیر تطبیق داده می‌شود، بدنهٔ حلقه اجرا می‌شود و سپس کنترل به ابتدای حلقهٔ for بازمی‌گردد. اگر تکرارگر خالی باشد، عبارت for پایان می‌یابد.

    نمونه‌ای از حلقهٔ for روی محتوای یک آرایه:

    let v = &["apples", "cake", "coffee"];

for text in v {
    println!("I like {}.", text);
}

    نمونه‌ای از حلقهٔ for روی دنباله‌ای از اعداد صحیح:

    let mut sum = 0;
for n in 1..11 {
    sum += n;
}
assert_eq!(sum, 55);
    [expr.loop.for.desugar]

    یک حلقهٔ for معادل عبارت loop دارای یک عبارت match به شکل زیر است:

    'label: for PATTERN in iter_expr {
    /* loop body */
}

    معادل است با

    {
    let result = match IntoIterator::into_iter(iter_expr) {
        mut iter => 'label: loop {
            let mut next;
            match Iterator::next(&mut iter) {
                Option::Some(val) => next = val,
                Option::None => break,
            };
            let PATTERN = next;
            let () = { /* loop body */ };
        },
    };
    result
}
    [expr.loop.for.lang-items]

    در اینجا IntoIterator، Iterator و Option همیشه اقلام کتابخانهٔ استاندارد هستند، نه هر چیزی که این نام‌ها در دامنهٔ جاری به آن تفکیک شوند.

    نام متغیرهای next، iter و val فقط برای توضیح است؛ این متغیرها در واقع نامی ندارند که کاربر بتواند تایپ کند.

    Note

    نکته از match بیرونی برای اطمینان از این استفاده می‌شود که مقادیر موقت در iter_expr پیش از پایان حلقه حذف نشوند. next پیش از انتساب اعلان می‌شود، زیرا این کار در موارد بیشتری به استنباط درست نوع‌ها منجر می‌شود.

    [expr.loop.label]

    برچسب‌های حلقه

    [expr.loop.label.syntax]

    Syntax
    LoopLabel → LIFETIME_OR_LABEL :

    [expr.loop.label.intro]

    یک عبارت حلقه می‌تواند به‌صورت اختیاری برچسب داشته باشد. برچسب به‌شکل یک طول‌عمر پیش از عبارت حلقه نوشته می‌شود؛ مانند 'foo: loop { break 'foo; }، 'bar: while false {} و 'humbug: for _ in 0..0 {}.

    [expr.loop.label.control-flow]

    اگر برچسبی وجود داشته باشد، عبارت‌های برچسب‌دار break و continue که درون این حلقه تودرتو شده‌اند می‌توانند از حلقه خارج شوند یا کنترل را به ابتدای آن بازگردانند. عبارت‌های break و عبارت‌های continue را ببینید.

    [expr.loop.label.ref]

    برچسب‌ها از قواعد بهداشت و سایه‌اندازی متغیرهای محلی پیروی می‌کنند. برای نمونه، این کد «outer loop» را چاپ می‌کند:

    'a: loop {
    'a: loop {
        break 'a;
    }
    print!("outer loop");
    break 'a;
}

    '_ برچسب حلقهٔ معتبری نیست.

    [expr.loop.break]

    عبارت‌های break

    [expr.loop.break.syntax]

    Syntax
    BreakExpression → break LIFETIME_OR_LABEL? Expression?

    [expr.loop.break.intro]

    هنگام روبه‌رو شدن با break، اجرای بدنهٔ حلقهٔ وابسته بلافاصله پایان می‌یابد؛ برای نمونه:

    let mut last = 0;
for x in 1..100 {
    if x > 12 {
        break;
    }
    last = x;
}
assert_eq!(last, 12);
    [expr.loop.break.diverging]

    عبارت break واگرا است و نوع ! دارد.

    [expr.loop.break.label]

    عبارت break معمولاً به درونی‌ترین حلقهٔ loop، for یا while که عبارت break را در بر گرفته است مرتبط می‌شود، اما می‌توان با یک برچسب مشخص کرد کدام حلقهٔ دربرگیرنده تحت تأثیر قرار گیرد. برای نمونه:

    'outer: loop {
    while true {
        break 'outer;
    }
}
    [expr.loop.break.value]

    عبارت break تنها در بدنهٔ یک حلقه مجاز است و یکی از شکل‌های break، break 'label یا (پایین را ببینید) break EXPR یا break 'label EXPR را دارد.

    [expr.loop.break-value.implicit-value]

    در یک loop دارای عبارت‌های break یا یک عبارت بلوک برچسب‌دار، break بدون عبارت معادل break () است.

    [expr.loop.block-labels]

    عبارت‌های بلوک برچسب‌دار

    [expr.loop.block-labels.syntax]

    Syntax
    LabelBlockExpression → BlockExpression

    [expr.loop.block-labels.intro]

    عبارت‌های بلوک برچسب‌دار دقیقاً مانند عبارت‌های بلوک هستند، جز اینکه اجازه می‌دهند درون بلوک از عبارت‌های break استفاده شود.

    [expr.loop.block-labels.break]

    برخلاف حلقه‌ها، عبارت‌های break درون یک عبارت بلوک برچسب‌دار باید برچسب داشته باشند؛ یعنی برچسب اختیاری نیست.

    [expr.loop.block-labels.label-required]

    به همین ترتیب، عبارت‌های بلوک برچسب‌دار باید با یک برچسب آغاز شوند.

    fn do_thing() {}
fn condition_not_met() -> bool { true }
fn do_next_thing() {}
fn do_last_thing() {}
let result = 'block: {
    do_thing();
    if condition_not_met() {
        break 'block 1;
    }
    do_next_thing();
    if condition_not_met() {
        break 'block 2;
    }
    do_last_thing();
    3
};
    [expr.loop.block-labels.type]

    نوع یک عبارت بلوک برچسب‌دار برابر است با کمترین کران بالای همهٔ عملوندهای break و عملوند نهایی. اگر عملوند نهایی حذف شود، نوع آن به‌طور پیش‌فرض نوع unit است، مگر اینکه بلوک واگرا باشد که در این صورت نوع آن نوع never است.

    مثال

    fn example(condition: bool) {
    let s = String::from("owned");

    let _: &str = 'block: {
        if condition {
            break 'block &s;  // &String coerced to &str via Deref
        }
        break 'block "literal";  // &'static str coerced to &str
    };
}
    [expr.loop.continue]

    عبارت‌های continue

    [expr.loop.continue.syntax]

    Syntax
    ContinueExpression → continue LIFETIME_OR_LABEL?

    [expr.loop.continue.intro]

    هنگام روبه‌رو شدن با continue، تکرار جاری بدنهٔ حلقهٔ وابسته بلافاصله پایان می‌یابد و کنترل به ابتدای حلقه بازمی‌گردد.

    [expr.loop.continue.diverging]

    عبارت continue واگرا است و نوع ! دارد.

    [expr.loop.continue.while]

    در حلقهٔ while، ابتدا همان عملوندهای شرطی کنترل‌کنندهٔ حلقه است.

    [expr.loop.continue.for]

    در حلقهٔ for، ابتدا همان عبارت فراخوانی کنترل‌کنندهٔ حلقه است.

    [expr.loop.continue.label]

    همانند break، continue نیز معمولاً به درونی‌ترین حلقهٔ دربرگیرنده وابسته است، اما با continue 'label می‌توان حلقهٔ تحت تأثیر را مشخص کرد.

    [expr.loop.continue.in-loop-only]

    عبارت continue تنها در بدنهٔ یک حلقه مجاز است.

    [expr.loop.break-value]

    مقادیر break و حلقه

    [expr.loop.break-value.intro]

    هنگامی که عبارت break به یک loop وابسته باشد، می‌توان با یکی از شکل‌های break EXPR یا break 'label EXPR مقداری از حلقه بازگرداند؛ در این شکل‌ها EXPR عبارتی است که نتیجه‌اش از loop بازگردانده می‌شود. برای نمونه:

    let (mut a, mut b) = (1, 1);
let result = loop {
    if b > 10 {
        break b;
    }
    let c = a + b;
    a = b;
    b = c;
};
// first number in Fibonacci sequence over 10:
assert_eq!(result, 13);
    [expr.loop.break-value.type]

    نوع یک loop دارای عبارت‌های break وابسته، کمترین کران بالای همهٔ عملوندهای break است.

    مثال

    fn example(condition: bool) {
    let s = String::from("owned");

    let _: &str = loop {
        if condition {
            break &s; // &String coerced to &str via Deref
        }
        break "literal"; // &'static str coerced to &str
    };
}
    [expr.loop.break-value.diverging]

    یک loop دارای عبارت‌های break وابسته، اگر دست‌کم یکی از عملوندهای break واگرا نباشد، واگرا نمی‌شود. اگر همهٔ عملوندهای break واگرا باشند، عبارت loop نیز واگرا است.

    مثال

    fn diverging_loop_with_break(condition: bool) -> ! {
    // This loop is diverging because all `break` operands are diverging.
    loop {
        if condition {
            break loop {};
        } else {
            break panic!();
        }
    }
}
    fn loop_with_non_diverging_break(condition: bool) -> ! {
    // The type of this loop is i32 even though one of the breaks is
    // diverging.
    loop {
        if condition {
            break loop {};
        } else {
            break 123i32;
        }
    } // ERROR: expected `!`, found `i32`
}
