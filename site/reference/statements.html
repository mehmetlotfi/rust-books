    [statement]

    دستورها

    [statement.syntax]

    Syntax
    Statement →
          ;
        | Item
        | LetStatement
        | ExpressionStatement
        | OuterAttribute* MacroInvocationSemi

    [statement.intro]

    یک دستور جزئی از یک بلوک است و خود بلوک نیز جزئی از یک عبارت یا تابع بیرونی است.

    [statement.kind]

    Rust دو نوع دستور دارد: دستورهای اعلان و دستورهای عبارت.

    [statement.decl]

    دستورهای اعلان

    دستور اعلان دستوری است که یک یا چند نام را به بلوک دستورهای پیرامون معرفی می‌کند. نام‌های اعلان‌شده می‌توانند متغیرهای جدید یا آیتم‌های جدید را نشان دهند.

    دو نوع دستور اعلان وجود دارد: اعلان آیتم و دستور let.

    [statement.item]

    اعلان‌های آیتم

    [statement.item.intro]

    دستور اعلان آیتم از نظر نحوی شکلی یکسان با اعلان آیتم درون یک ماژول دارد.

    [statement.item.scope]

    اعلان یک آیتم درون بلوک دستور، حوزهٔ آن را به بلوک دربردارندهٔ دستور محدود می‌کند. نه خود آیتم و نه زیرآیتم‌هایی که ممکن است اعلان کند، مسیر متعارف دریافت نمی‌کنند.

    [statement.item.associated-scope]

    استثنا این است که آیتم‌های وابستهٔ تعریف‌شده توسط پیاده‌سازی‌ها، تا زمانی که خود آیتم و در صورت لزوم صفت دسترس‌پذیر باشند، همچنان از حوزه‌های بیرونی قابل دسترسی‌اند. از دیگر جنبه‌ها، معنای آن با اعلان آیتم درون یک ماژول یکسان است.

    [statement.item.outer-generics]

    پارامترهای عمومی، پارامترها و متغیرهای محلی تابع دربردارنده به‌طور ضمنی تسخیر نمی‌شوند. برای مثال، inner نمی‌تواند به outer_var دسترسی داشته باشد.

    fn outer() {
  let outer_var = true;

  fn inner() { /* outer_var is not in scope here */ }

  inner();
}
    [statement.let]

    دستورهای let

    [statement.let.syntax]

    Syntax
    LetStatement →
        OuterAttribute* let PatternNoTopAlt ( : Type )?
        (
              = Expression
            | = Expressionexcept LazyBooleanExpression or end with a }
                  else BlockExpressionNoInnerAttributes
        )? ;

    [statement.let.intro]

    یک دستور let مجموعه‌ای تازه از متغیرها را که یک الگو تعیین می‌کند معرفی می‌کند. پس از الگو می‌تواند حاشیه‌نویسی نوع بیاید؛ سپس دستور پایان می‌یابد یا عبارت مقداردهندهٔ اولیه و یک بلوک اختیاری else پس از آن قرار می‌گیرند.

    [statement.let.inference]

    اگر حاشیه‌نویسی نوع ارائه نشود، کامپایلر نوع را استنتاج می‌کند؛ و اگر اطلاعات نوع برای استنتاج قطعی کافی نباشد، خطا گزارش می‌دهد.

    [statement.let.scope]

    هر متغیری که یک اعلان متغیر معرفی کند، از نقطهٔ اعلان تا پایان حوزهٔ بلوک پیرامون قابل مشاهده است؛ مگر اینکه اعلان متغیر دیگری روی آن سایه بیندازد.

    [statement.let.constraint]

    اگر بلوک else وجود نداشته باشد، الگو باید ردناپذیر باشد. با وجود بلوک else، الگو می‌تواند ردپذیر باشد.

    [statement.let.behavior]

    اگر الگو مطابقت نکند—که مستلزم ردپذیربودن آن است—بلوک else اجرا می‌شود. بلوک else باید همیشه واگرا باشد (به نوع هرگز ارزیابی شود).

    let (mut v, w) = (vec![1, 2, 3], 42); // The bindings may be mut or const
let Some(t) = v.pop() else { // Refutable patterns require an else block
    panic!(); // The else block must diverge
};
let [u, v] = [v[0], v[1]] else { // This pattern is irrefutable, so the compiler
                                 // will lint as the else block is redundant.
    panic!();
};
    [statement.expr]

    دستورهای عبارت

    [statement.expr.syntax]

    Syntax
    ExpressionStatement →
          ExpressionWithoutBlock ;
        | ExpressionWithBlock ;?

    [statement.expr.intro]

    دستور عبارت یک عبارت را ارزیابی می‌کند و نتیجهٔ آن را نادیده می‌گیرد. به‌طور معمول هدف دستور عبارت، فعال‌کردن اثرهای ارزیابی عبارت است.

    [statement.expr.restriction-semicolon]

    عبارتی که تنها از یک عبارت بلوکی یا عبارت کنترل جریان تشکیل شده باشد، اگر در بافتی استفاده شود که دستور در آن مجاز است، می‌تواند نقطه‌ویرگول پایانی را حذف کند. این امر ممکن است میان تجزیهٔ آن به‌عنوان دستوری مستقل و بخشی از عبارت دیگر ابهام ایجاد کند؛ در این حالت به‌عنوان دستور تجزیه می‌شود.

    [statement.expr.constraint-block]

    نوع عبارت‌های ExpressionWithBlock هنگام استفاده به‌عنوان دستور باید نوع واحد باشد.

    let mut v = vec![1, 2, 3];
v.pop();          // Ignore the element returned from pop
if v.is_empty() {
    v.push(5);
} else {
    v.remove(0);
}                 // Semicolon can be omitted.
[1];              // Separate expression statement, not an indexing expression.

    وقتی نقطه‌ویرگول پایانی حذف می‌شود، نتیجه باید از نوع () باشد.

    // bad: the block's type is i32, not ()
// Error: expected `()` because of default return type
// if true {
//   1
// }

// good: the block's type is i32
if true {
  1
} else {
  2
};
