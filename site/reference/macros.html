    [macro]

    ماکروها

    [macro.intro]

    قابلیت‌ها و نحو Rust را می‌توان با تعریف‌های سفارشی‌ای به نام ماکرو گسترش داد. هر ماکرو نامی دارد و با نحوی یکدست مانند some_extension!(...) فراخوانی می‌شود.

    برای تعریف ماکروهای تازه دو راه وجود دارد:

    • ماکروهای نمونه‌محور نحو تازه را به‌شکلی اعلانی و سطح‌بالا تعریف می‌کنند.
    • ماکروهای رویه‌ای با تابع‌هایی که روی tokenهای ورودی کار می‌کنند، ماکروهای تابع‌مانند، deriveهای سفارشی و attributeهای سفارشی را تعریف می‌کنند.
    [macro.invocation]

    فراخوانی ماکرو

    [macro.invocation.syntax]

    Syntax
    MacroInvocation →
        SimplePath ! DelimTokenTree

    DelimTokenTree →
          ( TokenTree* )
        | [ TokenTree* ]
        | { TokenTree* }

    TokenTree →
        Tokenexcept delimiters | DelimTokenTree

    MacroInvocationSemi →
          SimplePath ! ( TokenTree* ) ;
        | SimplePath ! [ TokenTree* ] ;
        | SimplePath ! { TokenTree* }

    [macro.invocation.intro]

    فراخوانی ماکرو، ماکرو را هنگام کامپایل بسط می‌دهد و خود فراخوانی را با نتیجهٔ ماکرو جایگزین می‌کند. ماکروها را می‌توان در موقعیت‌های زیر فراخواند:

    [macro.invocation.expr]
    • الگوها
    [macro.invocation.pattern]
    • نوع‌ها
    [macro.invocation.type]
    • نوع‌ها
    [macro.invocation.item]
    • آیتم‌ها از جمله آیتم‌های وابسته

    • رونویس‌های macro_rules
    [macro.invocation.extern]
    • بلوک‌های خارجی

    هنگامی که ماکرو به‌عنوان آیتم یا دستور استفاده می‌شود، فرم MacroInvocationSemi به کار می‌رود؛ اگر از آکولاد استفاده نشده باشد، در پایان این فرم نقطه‌ویرگول لازم است. پیش از فراخوانی ماکرو یا تعریف macro_rules هرگز نمی‌توان مشخص‌کنندهٔ دیدپذیری آورد.

    // Used as an expression.
let x = vec![1,2,3];

// Used as a statement.
println!("Hello!");

// Used in a pattern.
macro_rules! pat {
    ($i:ident) => (Some($i))
}

if let pat!(x) = Some(1) {
    assert_eq!(x, 1);
}

// Used in a type.
macro_rules! Tuple {
    { $A:ty, $B:ty } => { ($A, $B) };
}

type N2 = Tuple!(i32, i32);

// Used as an item.
use std::cell::RefCell;
thread_local!(static FOO: RefCell<u32> = RefCell::new(1));

// Used as an associated item.
macro_rules! const_maker {
    ($t:ty, $v:tt) => { const CONST: $t = $v; };
}
trait T {
    const_maker!{i32, 7}
}

// Macro calls within macros.
macro_rules! example {
    () => { println!("Macro call in a macro!") };
}
// Outer macro `example` is expanded, then inner macro `println` is expanded.
example!();
