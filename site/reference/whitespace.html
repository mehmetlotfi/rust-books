    [lex.whitespace]

    فضای خالی (Whitespace)

    [whitespace.syntax]

    Lexer
    WHITESPACE →
          U+0009 // Horizontal tab, '\t'
        | U+000A // Line feed, '\n'
        | U+000B // Vertical tab
        | U+000C // Form feed
        | U+000D // Carriage return, '\r'
        | U+0020 // Space, ' '
        | U+0085 // Next line
        | U+200E // Left-to-right mark
        | U+200F // Right-to-left mark
        | U+2028 // Line separator
        | U+2029 // Paragraph separator

    TAB → U+0009 // Horizontal tab, '\t'

    LF → U+000A // Line feed, '\n'

    CR → U+000D // Carriage return, '\r'

    SP → U+0020 // Space, ' '

    [lex.whitespace.intro]

    فضای خالی هر رشتهٔ ناتهی‌ای است که فقط از نویسه‌های دارای ویژگی یونیکد Pattern_White_Space تشکیل شده باشد.

    [lex.whitespace.token-sep]

    Rust زبانی با «قالب آزاد» است؛ یعنی همهٔ شکل‌های فضای خالی در دستور زبان تنها برای جداکردن توکن‌ها به کار می‌روند و هیچ معنای مستقلی ندارند.

    [lex.whitespace.replacement]

    اگر هر عنصر فضای خالی در یک برنامهٔ Rust با هر عنصر فضای خالی مجاز دیگری، مانند یک نویسهٔ فاصله، جایگزین شود، معنای برنامه یکسان می‌ماند.
