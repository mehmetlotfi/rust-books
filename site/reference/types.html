    [type]

    نوع‌ها

    [type.intro]

    هر متغیر، آیتم و مقدار در برنامهٔ Rust یک نوع دارد. نوع یک مقدار، تفسیر حافظه‌ای را که مقدار در آن نگهداری می‌شود و عملیاتی را که می‌توان روی آن انجام داد تعریف می‌کند.

    [type.builtin]

    نوع‌های داخلی به‌شکلی عمیق و غیرساده با زبان یکپارچه شده‌اند که تقلید آن در نوع‌های تعریف‌شده توسط کاربر ممکن نیست.

    [type.user-defined]

    نوع‌های تعریف‌شده توسط کاربر قابلیت‌های محدودتری دارند.

    [type.kinds]

    فهرست نوع‌ها چنین است:

    • نوع‌های ابتدایی:
      • بولی — bool
      • عددی — عدد صحیح و ممیز شناور
      • char
      • str
      • هرگز — ! — نوعی بدون مقدار
    • نوع‌های دنباله‌ای:
      • چندتایی
      • آرایه
      • برش
    • تاپل
      • struct
      • enum
      • union
    • آرایه
      • توابع
      • بستارها
    • نوع‌های اشاره‌گر:
      • ارجاع‌ها
      • اشاره‌گرهای خام
      • اشاره‌گرهای تابع
    • نوع‌های تابع:
      • شیءهای trait
      • نوع‌های اشاره‌گر:

    نوع‌های پرانتزی

    [type.name.parenthesized.syntax]

    Syntax
    ParenthesizedType → ( Type )

    [type.name.parenthesized.intro]

    در برخی وضعیت‌ها ترکیب نوع‌ها ممکن است مبهم باشد. برای جلوگیری از ابهام، نوع را درون پرانتز قرار دهید. برای مثال، در عملگر + مربوط به کران‌های نوع درون یک نوع ارجاع معلوم نیست کران بر کدام بخش اعمال می‌شود؛ بنابراین استفاده از پرانتز الزامی است. قواعد دستور زبانی که به این رفع ابهام نیاز دارند به‌جای قاعدهٔ Type از TypeNoBounds استفاده می‌کنند.

    use std::any::Any;
type T<'a> = &'a (dyn Any + Send);
    [type.recursive]

    نوع‌های بازگشتی

    [type.recursive.intro]

    نوع‌های اسمی—ساختارها، شمارش‌ها و unionها—می‌توانند بازگشتی باشند؛ یعنی هر گونهٔ enum یا فیلد struct یا union می‌تواند مستقیم یا غیرمستقیم به خود نوع enum یا struct دربرگیرنده ارجاع دهد.

    [type.recursive.constraint]

    چنین بازگشتی محدودیت‌هایی دارد:

    • نوع‌های بازگشتی باید در چرخهٔ بازگشت شامل یک نوع اسمی باشند، نه فقط نام‌های مستعار نوع یا نوع‌های ساختاری دیگری مانند آرایه‌ها یا تاپل‌ها. بنابراین type Rec = &'static [Rec] مجاز نیست.
    • اندازهٔ نوع بازگشتی باید متناهی باشد؛ به‌عبارت دیگر فیلدهای بازگشتی نوع باید نوع‌های اشاره‌گر باشند.

    نمونه‌ای از یک نوع بازگشتی و کاربرد آن:

    enum List<T> {
    Nil,
    Cons(T, Box<List<T>>)
}

let a: List<i32> = List::Cons(7, Box::new(List::Cons(13, Box::new(List::Nil))));
