    [subtype]

    زیرنوع‌سازی و واریانس

    [subtype.intro]

    زیرنوع‌سازی ضمنی است و می‌تواند در هر مرحله‌ای از بررسی یا استنتاج نوع رخ دهد.

    [subtype.kinds]

    زیرنوع‌سازی به دو حالت محدود می‌شود: واریانس نسبت به طول‌عمرها، و رابطهٔ میان نوع‌هایی با طول‌عمرهای رتبه‌بالاتر. اگر طول‌عمرها را از نوع‌ها حذف کنیم، تنها زیرنوع‌سازی باقی‌مانده از برابری نوع‌ها ناشی خواهد شد.

    مثال زیر را در نظر بگیرید: لفظ‌های رشته‌ای همیشه طول‌عمر 'static دارند. بااین‌حال می‌توانیم s را به t نسبت دهیم:

    fn bar<'a>() {
    let s: &'static str = "hi";
    let t: &'a str = s;
}

    چون 'static بیشتر از پارامتر طول‌عمر 'a عمر می‌کند، &'static str زیرنوع &'a str است.

    [subtype.higher-ranked]

    اشاره‌گرهای تابع و شیءهای trait رتبه‌بالاتر رابطهٔ زیرنوع دیگری نیز دارند. آن‌ها زیرنوعِ نوع‌هایی هستند که با جایگزینی طول عمرهای رتبه‌بالاتر به‌دست می‌آیند. چند نمونه:

    // Here 'a is substituted for 'static
let subtype: &(for<'a> fn(&'a i32) -> &'a i32) = &((|x| x) as fn(&_) -> &_);
let supertype: &(fn(&'static i32) -> &'static i32) = subtype;

// This works similarly for trait objects
let subtype: &(dyn for<'a> Fn(&'a i32) -> &'a i32) = &|x| x;
let supertype: &(dyn Fn(&'static i32) -> &'static i32) = subtype;

// We can also substitute one higher-ranked lifetime for another
let subtype: &(for<'a, 'b> fn(&'a i32, &'b i32)) = &((|x, y| {}) as fn(&_, &_));
let supertype: &for<'c> fn(&'c i32, &'c i32) = subtype;
    [subtyping.variance]

    واریانس

    [subtyping.variance.intro]

    واریانس ویژگی نوع‌های عمومی نسبت به آرگومان‌هایشان است. واریانس یک نوع عمومی در یک پارامتر نشان می‌دهد زیرنوع‌سازی آن پارامتر چگونه بر زیرنوع‌سازی خود نوع اثر می‌گذارد.

    [subtyping.variance.covariant]
    • F<T> نسبت به T هم‌وردا است اگر زیرنوع U بودن T به این معنا باشد که F<T> نیز زیرنوع F<U> است (زیرنوع‌سازی «عبور می‌کند»).
    [subtyping.variance.contravariant]
    • F<T> نسبت به T پادوردا است اگر زیرنوع U بودن T به این معنا باشد که F<U> زیرنوع F<T> است.
    [subtyping.variance.invariant]
    • در غیر این صورت F<T> نسبت به T ناوردا است (هیچ رابطهٔ زیرنوعی نمی‌توان نتیجه گرفت).
    [subtyping.variance.builtin-types]

    واریانس نوع‌ها به‌طور خودکار به‌شکل زیر تعیین می‌شود:

    [subtyping.variance.user-composite-types]

    واریانس دیگر نوع‌های struct، ‏enum و union با بررسی واریانس نوع فیلدهایشان تعیین می‌شود. اگر پارامتر در موقعیت‌هایی با واریانس متفاوت به‌کار رود، آن پارامتر ناورداست. برای مثال، ساختار زیر در 'a و T هم‌وردا و در 'b، ‏'c و U ناورداست.

    use std::cell::UnsafeCell;
struct Variance<'a, 'b, 'c, T, U: 'a> {
    x: &'a U,               // This makes `Variance` covariant in 'a, and would
                            // make it covariant in U, but U is used later
    y: *const T,            // Covariant in T
    z: UnsafeCell<&'b f64>, // Invariant in 'b
    w: *mut U,              // Invariant in U, makes the whole struct invariant

    f: fn(&'c ()) -> &'c () // Both co- and contravariant, makes 'c invariant
                            // in the struct.
}
    [subtyping.variance.builtin-composite-types]

    هنگامی که پارامترها بیرون از یک struct، ‏enum یا union به‌کار می‌روند، واریانس آن‌ها در هر محل به‌طور جداگانه بررسی می‌شود.

    use std::cell::UnsafeCell;
fn generic_tuple<'short, 'long: 'short>(
    // 'long is used inside of a tuple in both a co- and invariant position.
    x: (&'long u32, UnsafeCell<&'long u32>),
) {
    // As the variance at these positions is computed separately,
    // we can freely shrink 'long in the covariant position.
    let _: (&'short u32, UnsafeCell<&'long u32>) = x;
}

fn takes_fn_ptr<'short, 'middle: 'short>(
    // 'middle is used in both a co- and contravariant position.
    f: fn(&'middle ()) -> &'middle (),
) {
    // As the variance at these positions is computed separately,
    // we can freely shrink 'middle in the covariant position
    // and extend it in the contravariant position.
    let _: fn(&'static ()) -> &'short () = f;
}
