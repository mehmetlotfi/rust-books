    [runtime]

    زمان اجرای Rust

    [runtime.intro]

    این بخش قابلیت‌هایی را مستند می‌کند که برخی جنبه‌های runtimeِ Rust را تعریف می‌کنند.

    [runtime.global_allocator]

    Attributeِ global_allocator

    [runtime.global_allocator.intro]

    Attributeِ global_allocator یک تخصیص‌دهندهٔ حافظه را انتخاب می‌کند.

    مثال

    use core::alloc::{GlobalAlloc, Layout};
use std::alloc::System;

struct MyAllocator;

unsafe impl GlobalAlloc for MyAllocator {
    unsafe fn alloc(&self, layout: Layout) -> *mut u8 {
        unsafe { System.alloc(layout) }
    }
    unsafe fn dealloc(&self, ptr: *mut u8, layout: Layout) {
        unsafe { System.dealloc(ptr, layout) }
    }
}

#[global_allocator]
static GLOBAL: MyAllocator = MyAllocator;
    [runtime.global_allocator.syntax]

    Attributeِ global_allocator از نحو MetaWord استفاده می‌کند.

    [runtime.global_allocator.allowed-positions]

    Attributeِ global_allocator فقط روی یک آیتم static قابل اعمال است که نوع آن Traitِ GlobalAlloc را پیاده‌سازی کند.

    [runtime.global_allocator.duplicates]

    Attributeِ global_allocator فقط یک بار می‌تواند روی یک آیتم استفاده شود.

    [runtime.global_allocator.single]

    Attributeِ global_allocator فقط یک بار در گراف crate قابل استفاده است.

    [runtime.global_allocator.stdlib]

    Attributeِ global_allocator از prelude کتابخانهٔ استاندارد صادر می‌شود.

    [runtime.windows_subsystem]

    Attributeِ windows_subsystem

    [runtime.windows_subsystem.intro]

    Attributeِ windows_subsystem هنگام پیوند برای مقصد Windows، زیرسامانه را تنظیم می‌کند.

    مثال

    #![windows_subsystem = "windows"]
    [runtime.windows_subsystem.syntax]

    Attributeِ windows_subsystem از نحو MetaNameValueStr استفاده می‌کند. مقدارهای پذیرفته‌شده عبارت‌اند از "console" و "windows".

    [runtime.windows_subsystem.allowed-positions]

    Attributeِ windows_subsystem فقط روی ریشهٔ crate قابل اعمال است.

    [runtime.windows_subsystem.duplicates]

    فقط نخستین استفاده از windows_subsystem اثر دارد.

    Note

    نکته rustc برای هر استفاده پس از مورد نخست lint گزارش می‌کند. ممکن است این وضعیت در آینده به خطا تبدیل شود.

    [runtime.windows_subsystem.ignored]

    Attributeِ windows_subsystem برای مقصدهای غیر Windows و نوع‌های crate غیر bin نادیده گرفته می‌شود.

    [runtime.windows_subsystem.console]

    زیرسامانهٔ "console" پیش‌فرض است. اگر یک فرایند console از console موجود اجرا شود، به همان متصل خواهد شد؛ در غیر این صورت پنجرهٔ console تازه‌ای ساخته می‌شود.

    [runtime.windows_subsystem.windows]

    زیرسامانهٔ "windows" جدا از هر console موجود اجرا می‌شود.

    Note

    نکته زیرسامانهٔ "windows" معمولاً در برنامه‌های GUI به کار می‌رود که نمی‌خواهند هنگام آغاز پنجرهٔ console نمایش دهند.
