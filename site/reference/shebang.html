    [shebang]

    شِبَنگ (Shebang)

    [shebang.intro]

    شِبَنگ خطی اختیاری است که معمولاً در سامانه‌های شبه‌یونیکس برای مشخص‌کردن مفسری جهت اجرای فایل به‌کار می‌رود.

    مثال

    #!/usr/bin/env rustx

fn main() {
    println!("Hello!");
}
    [shebang.syntax]

    Lexer
    SHEBANG →
        #! !( ( WHITESPACE | LINE_COMMENT | SHEBANG_BLOCK_COMMENT )* [ )
        ~LF* ( LF | EOF )

    SHEBANG_BLOCK_COMMENT →
        /* !( ! | * ![* /] )
          ( SHEBANG_NESTED_BLOCK_COMMENT | ( !( */ | /* ) CHAR ) )*
        */

    SHEBANG_NESTED_BLOCK_COMMENT →
        /*
          ( SHEBANG_NESTED_BLOCK_COMMENT | ( !( */ | /* ) CHAR ) )*
        */

    [shebang.syntax-description]

    شِبَنگ با نویسه‌های #! آغاز می‌شود و تا نخستین U+000A (LF)، یا اگر LF وجود نداشته باشد تا EOF، ادامه می‌یابد. اگر پس از نویسه‌های #!، با نادیده‌گرفتن فضای خالی یا توضیحات غیرمستند میان آن‌ها، نویسهٔ [ بیاید، آن خط شِبَنگ محسوب نمی‌شود؛ این قاعده از ابهام با یک ویژگی درونی جلوگیری می‌کند.

    Note

    نکته هنگام تشخیص اینکه آیا پس از نویسه‌های #! یک [ آمده است، توضیحات مستند نادیده گرفته نمی‌شوند. برای نمونه، #! /*! */ [allow(unused)] در ابتدای فایل یک شِبَنگ است، نه یک ویژگی درونی؛ زیرا /*! */ توضیح مستند است. به همین ترتیب، متنی پس از #! که شبیه توضیح بلوکی پایان‌نیافته باشد، مانند #!/*، خطا ایجاد نمی‌کند؛ آن خط یک شِبَنگ است.

    [shebang.position]

    شِبَنگ می‌تواند بلافاصله در ابتدای فایل یا پس از نشانهٔ ترتیب بایت اختیاری ظاهر شود.
