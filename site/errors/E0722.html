راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود

    دلیل این است که این خطا بیش از حد مختص attribute به نام optimize بود. برای attributeهای دیگر نیز تشخیص‌های مشابهی وجود دارد. مثال این‌جا اکنون خطای E0539 را صادر می‌کند.

    attribute به نام optimize به‌درستی نوشته نشده بود.

    نمونه کد خطادار:

    #![feature(optimize_attribute)]

#[optimize(something)] // error: invalid argument
pub fn something() {}

    attribute به نام #[optimize] باید به این صورت استفاده شود:

    • #[optimize(size)] – به خط لوله بهینه‌سازی دستور می‌دهد کدی تولید کند که به‌جای سریع‌تر بودن، کوچک‌تر باشد

    • #[optimize(speed)] – به خط لوله بهینه‌سازی دستور می‌دهد کدی تولید کند که به‌جای کوچک‌تر بودن، سریع‌تر باشد

    برای مثال:

    #![feature(optimize_attribute)]

#[optimize(size)]
pub fn something() {}

    برای جزئیات بیشتر، RFC 2412 را ببینید.
