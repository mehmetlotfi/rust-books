راهنمای خطاهای کامپایلرCompiler Error Index

    این خطا نشان می‌دهد که ساختار، شمارش یا واریانت شمارش باید به‌صورت غیرجامع (non-exhaustive) تطبیق داده شود، زیرا با non_exhaustive علامت‌گذاری شده است.

    وقتی این ویژگی درون یک crate به کار می‌رود، کاربران پایین‌دستی crate هنگام تطبیق شمارش‌ها باید از الگوی _ و هنگام تطبیق ساختارها از الگوی .. استفاده کنند. crateهای پایین‌دستی نمی‌توانند واریانت‌های غیرجامع شمارش را تطبیق دهند.

    برای مثال، در نمونهٔ زیر، چون شمارش با non_exhaustive علامت‌گذاری شده است، لازم است crateهای پایین‌دستی آن را به‌صورت غیرجامع تطبیق دهند.

    #[non_exhaustive]
pub enum Error {
    Message(String),
    Other,
}

impl Display for Error {
    fn fmt(&self, formatter: &mut fmt::Formatter) -> fmt::Result {
        // This will not error, despite being marked as non_exhaustive, as this
        // enum is defined within the current crate, it can be matched
        // exhaustively.
        let display = match self {
            Message(s) => s,
            Other => "other or unknown error",
        };
        formatter.write_str(display)
    }
}

    نمونه‌ای از تطبیق غیرجامع روی شمارش بالا در ادامه آمده است:

    use mycrate::Error;

// This will not error as the non_exhaustive Error enum has been matched with a
// wildcard.
match error {
    Message(s) => ...,
    Other => ...,
    _ => ...,
}

    به‌طور مشابه، برای ساختارها نیز برای پرهیز از این خطا با .. تطبیق دهید.
