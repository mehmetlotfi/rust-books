راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود.

    این کد خطا با تشخیص attribute cannot be used on... که کد خطا ندارد جایگزین شده است.

    یک attribute از نوع #[repr(..)] روی یک آیتم پشتیبانی‌نشده قرار داده شده است.

    نمونه‌های کد خطادار:

    #[repr(C)]
type Foo = u8;

#[repr(packed)]
enum Foo {Bar, Baz}

#[repr(u8)]
struct Foo {bar: bool, baz: bool}

#[repr(C)]
impl Foo {
    // ...
}
    • attribute با نام #[repr(C)] را فقط می‌توان روی ساختارها و شمارش‌ها قرار داد.
    • attributeهای #[repr(packed)] و #[repr(simd)] فقط روی ساختارها کار می‌کنند.
    • attributeهای #[repr(u8)]، #[repr(i16)] و مانند آن‌ها فقط روی شمارش‌ها کار می‌کنند.

    این attributeها روی typedefها کار نمی‌کنند، زیرا typedefها فقط نام مستعار هستند.

    بازنمایی‌هایی مانند #[repr(u8)] و #[repr(i64)] برای انتخاب اندازهٔ discriminant در شمارش‌ها به کار می‌روند. برای شمارش‌هایی که هیچ‌یک از variantهایشان فیلد داده ندارد، مانند enum Color {Red, Blue, Green}، این کار عملاً اندازهٔ شمارش را برابر با اندازهٔ نوع داده‌شده قرار می‌دهد. چنین شمارشی را می‌توان به مقداری از همان نوع نیز cast کرد. به طور خلاصه، #[repr(u8)] باعث می‌شود یک شمارش بدون فیلد مانند یک عدد صحیح با مجموعه‌ای محدود از مقادیر مجاز رفتار کند.

    برای توضیح اینکه #[repr(C)] و بازنمایی‌هایی مانند #[repr(u8)] چگونه روی چیدمان (layout) شمارش‌های دارای فیلد داده اثر می‌گذارند، به RFC 2195 مراجعه کنید.

    فقط شمارش‌های بدون فیلد را می‌توان به انواع عددی اولیه cast کرد. بازنمایی‌هایی مانند #[repr(u8)] روی ساختارها اعمال نمی‌شوند.

    #[repr(packed)] فاصله‌گذاری (padding) را کاهش می‌دهد تا اندازهٔ ساختار کوچک‌تر شود. بازنمایی شمارش‌ها در Rust به‌طور دقیق تعریف نشده است و این attribute روی شمارش‌ها کار نمی‌کند.

    #[repr(simd)] به ساختاری که از یک رشتهٔ همگن از انواع ماشین (مانند u8، i32 و غیره) تشکیل شده، بازنمایی‌ای می‌دهد که برداری‌سازی (vectorization) از طریق SIMD را ممکن می‌کند. این برای شمارش‌ها چندان معنا ندارد، زیرا آن‌ها از یک فهرست واحد از داده‌ها تشکیل نشده‌اند.
