راهنمای خطاهای کامپایلرCompiler Error Index

    یک عملیات دودویی روی نوعی انجام شده است که از آن پشتیبانی نمی‌کند.

    نمونه کد خطادار:

    let x = 12f32; // error: binary operation `<<` cannot be applied to
               //        type `f32`

x << 2;

    برای رفع این خطا، بررسی کنید که آن نوع این عملیات دودویی را پیاده‌سازی کرده باشد. مثال:

    let x = 12u32; // the `u32` type does implement it:
               // https://doc.rust-lang.org/stable/std/ops/trait.Shl.html

x << 2; // ok!

    همچنین می‌توان بیشتر عملگرها را برای نوع خودتان با پیاده‌سازی صفت‌های std::ops سربار کرد (overload).

    الحاق رشته‌ها (string concatenation)، رشته سمت راست را به رشته سمت چپ اضافه می‌کند و ممکن است به تخصیص مجدد حافظه نیاز داشته باشد. این کار به مالکیت رشته سمت چپ نیاز دارد. اگر قرار است چیزی به یک literal رشته‌ای اضافه شود، literal را با to_owned() به heap منتقل کنید، مانند "Your text".to_owned().
