راهنمای خطاهای کامپایلرCompiler Error Index

    یک متغیر تغییرپذیر استفاده شده است در حالی که پیش‌تر توسط یک closure capture شده است.

    نمونه کد خطادار:

    fn inside_closure(x: &mut i32) {
    // Actions which require unique access
}

fn outside_closure(x: &mut i32) {
    // Actions which require unique access
}

fn foo(a: &mut i32) {
    let mut bar = || {
        inside_closure(a)
    };
    outside_closure(a); // error: cannot borrow `*a` as mutable because previous
                        //        closure requires unique access.
    bar();
}

    این خطا نشان می‌دهد که یک متغیر تغییرپذیر در حالی استفاده شده که هنوز توسط یک closure capture شده است. چون closure متغیر را قرض گرفته است، تا زمانی که closure از محدوده خارج نشود، آن متغیر در دسترس نیست.

    توجه کنید که یک capture یا متغیر را منتقل می‌کند یا آن را قرض می‌گیرد، اما در این وضعیت closure در حال قرض گرفتن متغیر است. برای اطلاعات بیشتر به فصل Capturing در Rust By Example نگاه کنید.

    برای رفع این خطا می‌توانید استفاده از closure را پیش از استفاده از متغیر capture‌شده به پایان برسانید:

    fn inside_closure(x: &mut i32) {}
fn outside_closure(x: &mut i32) {}

fn foo(a: &mut i32) {
    let mut bar = || {
        inside_closure(a)
    };
    bar();
    // borrow on `a` ends.
    outside_closure(a); // ok!
}

    یا می‌توانید متغیر را به‌عنوان پارامتر به closure بدهید:

    fn inside_closure(x: &mut i32) {}
fn outside_closure(x: &mut i32) {}

fn foo(a: &mut i32) {
    let mut bar = |s: &mut i32| {
        inside_closure(s)
    };
    outside_closure(a);
    bar(a);
}

    شاید بتوان closure را بعداً تعریف کرد:

    fn inside_closure(x: &mut i32) {}
fn outside_closure(x: &mut i32) {}

fn foo(a: &mut i32) {
    outside_closure(a);
    let mut bar = || {
        inside_closure(a)
    };
    bar();
}
