راهنمای خطاهای کامپایلرCompiler Error Index

    یک الگوی آرایه یا slice به عناصر بیشتری نسبت به آنچه در آرایهٔ مورد تطبیق وجود داشت نیاز داشت.

    نمونه کد خطادار:

    let r = &[1, 2];
match r {
    &[a, b, c, rest @ ..] => { // error: pattern requires at least 3
                               //        elements but array has 2
        println!("a={}, b={}, c={} rest={:?}", a, b, c, rest);
    }
}

    مطمئن شوید که آرایهٔ مورد تطبیق دست‌کم به اندازهٔ عناصری که الگو نیاز دارد عنصر دارد. می‌توانید تعداد دلخواهی از عناصر باقی‌مانده را با .. تطبیق دهید:

    let r = &[1, 2, 3, 4, 5];
match r {
    &[a, b, c, rest @ ..] => { // ok!
        // prints `a=1, b=2, c=3 rest=[4, 5]`
        println!("a={}, b={}, c={} rest={:?}", a, b, c, rest);
    }
}
