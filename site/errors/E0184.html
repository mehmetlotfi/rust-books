    صفت Copy روی نوعی پیاده‌سازی شده است که پیاده‌سازی Drop دارد.

    نمونه کدی که خطا می‌دهد:

    #[derive(Copy)]
struct Foo; // error!

impl Drop for Foo {
    fn drop(&mut self) {
    }
}

    پیاده‌سازی صریح هر دو صفت Drop و Copy روی یک نوع در حال حاضر ممنوع است. این قابلیت از نظر تئوری می‌تواند تا حدی معنا داشته باشد، اما پیاده‌سازی فعلی نادرست است و می‌تواند به ناامنی حافظه منجر شود (به issue شماره‌ی 20126 نگاه کنید)، به همین دلیل فعلاً غیرفعال شده است.
