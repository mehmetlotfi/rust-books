راهنمای خطاهای کامپایلرCompiler Error Index

    یک عبارت if فاقد بلوک else است.

    نمونه کد خطادار:

    let x = 5;
let a = if x == 5 {
    1
};

    این خطا زمانی رخ می‌دهد که عبارت if بدون بلوک else در بافتی به کار رود که نوعی غیر از () انتظار می‌رود. در مثال کد قبلی، عبارت let انتظار یک مقدار داشت، اما چون else وجود نداشت، مقداری بازگردانده نشد.

    عبارت if بدون بلوک else نوع () دارد، بنابراین این یک خطای نوع است. برای رفع آن، یک بلوک else با همان نوعِ بلوک if اضافه کنید.

    پس برای رفع مثال کد قبلی:

    let x = 5;
let a = if x == 5 {
    1
} else {
    2
};
