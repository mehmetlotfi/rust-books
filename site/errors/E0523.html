راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود.

    کامپایلر چندین فایل کتابخانه با نام crate درخواستی پیدا کرد.

    // aux-build:crateresolve-1.rs
// aux-build:crateresolve-2.rs
// aux-build:crateresolve-3.rs

extern crate crateresolve;
//~^ ERROR multiple candidates for `rlib` dependency `crateresolve` found

fn main() {}

    این خطا می‌تواند در چند حالت مختلف رخ دهد؛ برای مثال هنگام استفاده از extern crate یا ارسال گزینه‌های --extern بدون مسیر crate. همچنین می‌تواند به‌دلیل مشکلات کش در پوشهٔ ساخت رخ دهد که در این صورت cargo clean ممکن است کمک کند.

    در مثال بالا، سه فایل کتابخانهٔ متفاوت وجود دارد که همگی نام crate یکسانی را تعریف می‌کنند. بدون ارائهٔ مسیر کامل، کامپایلر راهی برای دانستن اینکه کدام crate را باید استفاده کند ندارد.

    توجه کنید که E0523 در E0464 ادغام شده است.
