راهنمای خطاهای کامپایلرCompiler Error Index

    وابستگی با نسخهٔ متفاوتی از rustc کامپایل شده است.

    نمونه کد خطادار:

    a.rs

    // compiled with stable `rustc`

#[crate_type = "lib"]

    b.rs

    // compiled with nightly `rustc`

#[crate_type = "lib"]

extern crate a; // error: found crate `a` compiled by an incompatible version
                //        of rustc

    این خطا زمانی رخ می‌دهد که نسخهٔ rustc مورد استفاده برای کامپایل یک crate، که در فراداده (metadata) فایل باینری ذخیره می‌شود، با نسخهٔ یکی از وابستگی‌های آن متفاوت باشد. بسیاری از بخش‌های باینری‌های Rust ناپایدار در نظر گرفته می‌شوند. برای مثال، ABI زبان Rust بین نسخه‌های مختلف کامپایلر پایدار نیست. این یعنی کامپایلر نمی‌تواند مطمئن باشد که یک تابع را بین نسخه‌های مختلف کامپایلر چگونه باید فراخوانی کند، و به همین دلیل این خطا رخ می‌دهد.

    این خطا را می‌توان به این صورت برطرف کرد:

    • استفاده از Cargo، مدیر بسته‌های Rust، و Rustup، نصب‌کنندهٔ toolchain زبان Rust، که این مشکل را به‌طور خودکار برطرف می‌کنند.
    • کامپایل مجدد crateها با یک نسخهٔ یکسان از rustc.
