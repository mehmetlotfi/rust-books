راهنمای خطاهای کامپایلرCompiler Error Index

    یک نوع با repr(transparent) علاوه بر آن با راهنماهای بازنمایی دیگری که ناسازگار هستند نیز حاشیه‌نویسی شده است.

    نمونه کد خطادار:

    #[repr(transparent, C)] // error: incompatible representation hints
struct Grams(f32);

    نوعی که با repr(transparent) حاشیه‌نویسی شده، تمام مسائل مربوط به بازنمایی را به نوع دیگری واگذار می‌کند، بنابراین افزودن راهنماهای بازنمایی بیشتر متناقض است. یا راهنمای transparent را حذف کنید یا راهنماهای دیگر را، مانند این:

    #[repr(transparent)]
struct Grams(f32);

    به‌طور جایگزین، attributeهای دیگر را به نوعِ درون‌گرفته‌شده منتقل کنید:

    #[repr(C)]
struct Foo {
    x: i32,
    // ...
}

#[repr(transparent)]
struct FooWrapper(Foo);

    توجه کنید که ایجاد یک struct دیگر فقط برای داشتن جایی برای attributeهای دیگر ممکن است اثرات جانبی ناخواسته‌ای روی بازنمایی داشته باشد:

    #[repr(transparent)]
struct Grams(f32);

#[repr(C)]
struct Float(f32);

#[repr(transparent)]
struct Grams2(Float); // this is not equivalent to `Grams` above

    در اینجا Grams2 با Grams معادل نیست؛ اولی به‌صورت transparent یک ساختار (غیر transparent) را که یک عدد اعشاری دارد در بر می‌گیرد، در حالی که Grams یک پوشش transparent پیرامون یک عدد اعشاری است. این موضوع می‌تواند روی ABI تفاوت ایجاد کند.
