    یک binding چیزی را که نباید، پنهان (shadow) کرده است.

    یک شاخه‌ی match یا یک متغیر نامی دارد که پیش‌تر برای چیز دیگری استفاده شده است، مثلاً:

    • نام یک ساختار
    • یک واریانت شمارش
    • یک static
    • یک ثابت وابسته (associated constant)

    این خطا همچنین زمانی رخ می‌دهد که یک واریانت شمارش دارای فیلد در یک الگو و بدون فیلدهایش به کار رود.

    enum Enum {
    WithField(i32)
}

use Enum::*;
match WithField(1) {
    WithField => {} // error: missing (_)
}

    bindingهای match نمی‌توانند staticها را پنهان کنند:

    static TEST: i32 = 0;

let r = 123;
match r {
    TEST => {} // error: name of a static
}

    نمونه‌های اصلاح‌شده:

    static TEST: i32 = 0;

let r = 123;
match r {
    some_value => {} // ok!
}

    یا

    const TEST: i32 = 0; // const, not static

let r = 123;
match r {
    TEST => {} // const is ok!
    other_values => {}
}
