راهنمای خطاهای کامپایلرCompiler Error Index

    کلیدواژه Self بیرون از یک impl، صفت (trait) یا تعریف نوع به‌کار رفته است.

    نمونه کد خطادار:

    <Self>::foo; // error: use of `Self` outside of an impl, trait, or type
             // definition

    کلیدواژه Self نمایانگر نوع فعلی است، و به همین دلیل فقط درون یک impl، صفت یا تعریف نوع قابل استفاده است. این کلیدواژه امکان دسترسی به آیتم‌های وابسته (associated item) یک نوع را فراهم می‌کند:

    trait Foo {
    type Bar;
}

trait Baz : Foo {
    fn bar() -> Self::Bar; // like this
}

    با این حال، وقتی دو نوع یک نوع وابسته مشترک دارند، باید مراقب باشید:

    trait Foo {
    type Bar;
}

trait Foo2 {
    type Bar;
}

trait Baz : Foo + Foo2 {
    fn bar() -> Self::Bar;
    // error: ambiguous associated type `Bar` in bounds of `Self`
}

    این مشکل با مشخص کردن اینکه می‌خواهیم نوع Bar را از کدام صفت استفاده کنیم حل می‌شود:

    trait Foo {
    type Bar;
}

trait Foo2 {
    type Bar;
}

trait Baz : Foo + Foo2 {
    fn bar() -> <Self as Foo>::Bar; // ok!
}
