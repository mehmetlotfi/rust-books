راهنمای خطاهای کامپایلرCompiler Error Index

    نوع مورد انتظار با نوع دریافتی مطابقت نداشت.

    نمونه‌های کد خطادار:

    fn plus_one(x: i32) -> i32 {
    x + 1
}

plus_one("Not a number");
//       ^^^^^^^^^^^^^^ expected `i32`, found `&str`

if "Not a bool" {
// ^^^^^^^^^^^^ expected `bool`, found `&str`
}

let x: f32 = "Not a float";
//     ---   ^^^^^^^^^^^^^ expected `f32`, found `&str`
//     |
//     expected due to this

    این خطا زمانی رخ می‌دهد که عبارتی در جایی به کار رفته باشد که کامپایلر عبارتی با نوع متفاوت انتظار داشته است. این خطا می‌تواند در موارد مختلفی رخ دهد که رایج‌ترین آن فراخوانی تابع و ارسال آرگومانی است که نوعش با نوع متناظر در اعلان تابع متفاوت است.
