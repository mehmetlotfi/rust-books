راهنمای خطاهای کامپایلرCompiler Error Index

    یک ساختار/واریانت چندتایی (tuple) ناشناخته به کار رفته است.

    نمونه‌ی کد خطادار:

    let Type(x) = Type(12); // error!
match Bar(12) {
    Bar(x) => {} // error!
    _ => {}
}

    در بیشتر موارد، علت یا فراموش‌کردن import است یا غلط تایپی. با این حال، ببینیم چگونه می‌توان چنین نوعی داشت:

    struct Type(u32); // this is a tuple struct

enum Foo {
    Bar(u32), // this is a tuple variant
}

use Foo::*; // To use Foo's variant directly, we need to import them in
            // the scope.

    در هر صورت، کد قبلی ما باید با آن درست کار کند:

    struct Type(u32);

enum Foo {
    Bar(u32),
}
use Foo::*;

let Type(x) = Type(12); // ok!
match Type(12) {
    Type(x) => {} // ok!
    _ => {}
}
