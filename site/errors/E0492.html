راهنمای خطاهای کامپایلرCompiler Error Index

    تلاش شده است ثابتی که دارای تغییرپذیری درونی (interior mutability) است قرض گرفته شود.

    نمونه کد دارای خطا:

    use std::sync::atomic::AtomicUsize;

const A: AtomicUsize = AtomicUsize::new(0);
const B: &'static AtomicUsize = &A;
// error: cannot borrow a constant which may contain interior mutability,
//        create a static instead

    یک const نشان‌دهندهٔ مقداری ثابت است که هرگز نباید تغییر کند. اگر از ثابت یک ارجاع & گرفته شود، در واقع اشاره‌گری به یک مکان حافظه که مقدار را نگه می‌دارد گرفته شده است. معمولاً این کار کاملاً مشکلی ندارد: بیشتر مقادیر را نمی‌توان از طریق اشاره‌گر مشترک & تغییر داد، اما تغییرپذیری درونی این امکان را فراهم می‌کند. یعنی ممکن است یک مقدار ثابت تغییر کند. از سوی دیگر، static صراحتاً یک مکان حافظهٔ واحد است که می‌توان آن را به دلخواه تغییر داد.

    بنابراین برای رفع این خطا، از staticهایی که Sync هستند استفاده کنید:

    use std::sync::atomic::AtomicUsize;

static A: AtomicUsize = AtomicUsize::new(0);
static B: &'static AtomicUsize = &A; // ok!

    این خطا را هنگام استفاده از نوع‌های سلولی (cell) نیز ممکن است ببینید:

    use std::cell::Cell;

const A: Cell<usize> = Cell::new(1);
const B: &Cell<usize> = &A;
// error: cannot borrow a constant which may contain interior mutability,
//        create a static instead

// or:
struct C { a: Cell<usize> }

const D: C = C { a: Cell::new(1) };
const E: &Cell<usize> = &D.a; // error

// or:
const F: &C = &D; // error

    دلیل این است که نوع‌های سلولی عملیاتی انجام می‌دهند که ایمن در برابر نخ‌ها (thread-safe) نیست. به همین دلیل، آن‌ها Sync را پیاده‌سازی نمی‌کنند و در نتیجه نمی‌توان آن‌ها را در staticها قرار داد.

    با این حال، اگر باز هم می‌خواهید از این نوع‌ها استفاده کنید، می‌توانید این کار را با یک wrapper ناایمن (unsafe) انجام دهید:

    use std::cell::Cell;

struct NotThreadSafe<T> {
    value: Cell<T>,
}

unsafe impl<T> Sync for NotThreadSafe<T> {}

static A: NotThreadSafe<usize> = NotThreadSafe { value : Cell::new(1) };
static B: &'static NotThreadSafe<usize> = &A; // ok!

    به یاد داشته باشید که این راه‌حل unsafe است! باید خودتان مطمئن شوید که دسترسی‌ها به سلول همگام‌سازی شده‌اند.
