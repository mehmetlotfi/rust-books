راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود.

    عملوند اسمبلی درون‌خطی را نمی‌توان به یک مقدار واحد LLVM تبدیل کرد.

    نمونهٔ کد خطادار:

    #![feature(llvm_asm)]

fn main() {
    unsafe {
        llvm_asm!("" :: "r"("")); // error!
    }
}

    این خطا معمولاً زمانی رخ می‌دهد که تلاش می‌کنید مقداری را به یک عملوند ورودی اسمبلی درون‌خطی بدهید که در واقع یک جفت مقدار است. به‌طور خاص، این مورد ممکن است هنگام تلاش برای دادن یک slice، مثلاً یک &str، رخ دهد. در Rust این مقادیر به‌صورت داخلی با یک جفت مقدار، یعنی اشاره‌گر و طولش، نمایش داده می‌شوند. وقتی این جفت مقدار به‌عنوان عملوند ورودی داده شود، نمی‌توان آن را به یک ثبات تبدیل (coerce) کرد و بنابراین باید با خطا شکست بخوریم.
