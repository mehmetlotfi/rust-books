راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود.

    کلیدواژه pub درون یک شمارش (enum) عمومی به کار رفته بود.

    نمونه کد دارای خطا:

    pub enum Foo {
    pub Bar, // error: unnecessary `pub` visibility
}

    از آنجا که شمارش از پیش عمومی است، افزودن pub به یکی از عناصر آن غیرضروری است. مثال:

    enum Foo {
    pub Bar, // not ok!
}

    این نحو درست است:

    pub enum Foo {
    Bar, // ok!
}
