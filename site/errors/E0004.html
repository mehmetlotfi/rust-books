راهنمای خطاهای کامپایلرCompiler Error Index

    این خطا نشان می‌دهد که کامپایلر نمی‌تواند برای یک یا چند ورودی ممکن به عبارت match یک الگوی منطبق را تضمین کند. تطبیق‌های تضمین‌شده برای انتساب مقادیر به عبارت‌های match یا به‌طور جایگزین برای تعیین جریان اجرا لازم هستند.

    نمونه کد اشتباه:

    enum Terminator {
    HastaLaVistaBaby,
    TalkToMyHand,
}

let x = Terminator::HastaLaVistaBaby;

match x { // error: non-exhaustive patterns: `HastaLaVistaBaby` not covered
    Terminator::TalkToMyHand => {}
}

    اگر با این خطا روبه‌رو شدید، باید الگوهای خود را طوری تغییر دهید که هر مقدار ممکنِ نوع ورودی پوشش داده شود. برای نوع‌هایی با تعداد کمی واریانت (مانند enumها) احتمالاً باید همهٔ حالت‌ها را صریحاً پوشش دهید. به‌طور جایگزین، می‌توان الگوی wildcard یعنی زیرخط _ را پس از همهٔ الگوهای دیگر افزود تا «هر چیز دیگری» را تطبیق دهد. مثال:

    enum Terminator {
    HastaLaVistaBaby,
    TalkToMyHand,
}

let x = Terminator::HastaLaVistaBaby;

match x {
    Terminator::TalkToMyHand => {}
    Terminator::HastaLaVistaBaby => {}
}

// or:

match x {
    Terminator::TalkToMyHand => {}
    _ => {}
}
