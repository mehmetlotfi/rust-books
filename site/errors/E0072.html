راهنمای خطاهای کامپایلرCompiler Error Index

    یک نوع بازگشتی اندازهٔ نامتناهی دارد، چون هیچ سطح غیرمستقیمی (indirection) در آن وجود ندارد.

    نمونه کد دارای خطا:

    struct ListNode {
    head: u8,
    tail: Option<ListNode>, // error: no indirection here so impossible to
                            //        compute the type's size
}

    هنگام تعریف یک ساختار یا شمارش بازگشتی، هر استفاده از نوعی که در حال تعریف است، از داخل خود تعریف، باید پشت یک اشاره‌گر (مانند Box، & یا Rc) انجام شود. دلیلش این است که ساختارها و شمارش‌ها باید اندازه‌ای کاملاً مشخص داشته باشند، و بدون اشاره‌گر، اندازهٔ نوع باید بی‌کران باشد.

    در این مثال، نوع نمی‌تواند اندازه‌ای مشخص داشته باشد، زیرا باید به‌صورت دلخواه بزرگ باشد (چون می‌توانیم ListNodeها را تا هر عمقی تو در تو کنیم). به‌طور دقیق‌تر،

    size of `ListNode` = 1 byte for `head`
                   + 1 byte for the discriminant of the `Option`
                   + size of `ListNode`

    یک راه برای رفع این مشکل این است که ListNode را درون یک Box قرار دهیم، مانند زیر:

    struct ListNode {
    head: u8,
    tail: Option<Box<ListNode>>,
}

    این کار جواب می‌دهد، چون Box یک اشاره‌گر است و بنابراین اندازهٔ آن مشخص است.
