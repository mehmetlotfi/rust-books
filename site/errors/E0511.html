راهنمای خطاهای کامپایلرCompiler Error Index

    از یک monomorphization نامعتبر برای یک تابع intrinsic استفاده شده است.

    نمونه کد خطادار:

    #![feature(intrinsics)]

#[rustc_intrinsic]
unsafe fn simd_add<T>(a: T, b: T) -> T;

fn main() {
    unsafe { simd_add(0, 1); }
    // error: invalid monomorphization of `simd_add` intrinsic
}

    نوع جنریک باید یک نوع SIMD باشد. نمونه:

    #![feature(repr_simd)]
#![feature(intrinsics)]

#[repr(simd)]
#[derive(Copy, Clone)]
struct i32x2([i32; 2]);

#[rustc_intrinsic]
unsafe fn simd_add<T>(a: T, b: T) -> T;

unsafe { simd_add(i32x2([0, 0]), i32x2([1, 2])); } // ok!
