راهنمای خطاهای کامپایلرCompiler Error Index

    برای یک بازه، چیزی غیر از عدد و نویسه به کار رفته است.

    نمونه کد نادرست:

    let string = "salutations !";

// The ordering relation for strings cannot be evaluated at compile time,
// so this doesn't work:
match string {
    "hello" ..= "world" => {}
    _ => {}
}

// This is a more general version, using a guard:
match string {
    s if s >= "hello" && s <= "world" => {}
    _ => {}
}

    در یک عبارت match فقط اعداد و نویسه‌ها را می‌توان با یک بازه تطبیق داد. دلیل این است که کامپایلر در زمان کامپایل بررسی می‌کند که بازه تهی نباشد و نمی‌تواند توابع مقایسه دلخواه را ارزیابی کند. اگر می‌خواهید مقادیر یک نوع قابل‌ترتیب را که بین دو نقطه انتهایی قرار دارند بگیرید، می‌توانید از guard استفاده کنید.
