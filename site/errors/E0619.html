راهنمای خطاهای کامپایلرCompiler Error Index

    نکته: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود.

    type-checker برای یک عبارت به دانستن نوع آن نیاز داشت، اما آن نوع هنوز استنتاج نشده بود.

    نمونهٔ کد دارای خطا:

    let mut x = vec![];
match x.pop() {
    Some(v) => {
        // Here, the type of `v` is not (yet) known, so we
        // cannot resolve this method call:
        v.to_uppercase(); // error: the type of this value must be known in
                          //        this context
    }
    None => {}
}

    استنتاج نوع معمولاً از بالای تابع به پایین پیش می‌رود و در طول مسیر نوع‌ها را مشخص می‌کند. در برخی موارد – به‌ویژه فراخوانی متدها و عملگرهای قابل overload مانند * – ممکن است type checker هنوز اطلاعات کافی برای ادامه نداشته باشد. این می‌تواند حتی زمانی رخ دهد که بقیهٔ تابع زمینهٔ کافی را فراهم می‌کند (چون type-checker هنوز آن‌قدر جلو را نگاه نکرده است). در این حالت می‌توان از annotationهای نوع برای کمک به آن استفاده کرد.

    برای رفع این خطا، کافی است نوع متغیر را مشخص کنید. مثال:

    let mut x: Vec<String> = vec![]; // We precise the type of the vec elements.
match x.pop() {
    Some(v) => {
        v.to_uppercase(); // Since rustc now knows the type of the vec elements,
                          // we can use `v`'s methods.
    }
    None => {}
}
