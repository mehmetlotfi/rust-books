راهنمای خطاهای کامپایلرCompiler Error Index

    یک کلیدواژه حلقه (break یا continue) بیرون از یک حلقه به کار رفته است.

    کد دارای خطا:

    fn some_func() {
    break; // error: `break` outside of a loop
}

    بدون حلقه‌ای که بتوان از آن خارج شد یا در آن ادامه داد، هیچ کار معناداری نمی‌توان انجام داد. لطفاً بررسی کنید که break و continue را فقط درون حلقه‌ها به کار می‌برید. مثال:

    fn some_func() {
    for _ in 0..10 {
        break; // ok!
    }
}
