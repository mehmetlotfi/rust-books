راهنمای خطاهای کامپایلرCompiler Error Index

    هنگام ایجاد قواعد drop-check به حد بازگشت (recursion limit) رسیدیم.

    نمونه کد خطادار:

    enum A<T> {
    B,
    C(T, Box<A<(T, T)>>)
}

fn foo<T>() {
    A::<T>::B; // error: overflow while adding drop-check rules for A<T>
}

    کامپایلر Rust باید بتواند درباره‌ی چگونگی Drop شدن یک نوع و در نتیجه انواع فیلدهای آن استدلال کند تا بتواند کدِ چسب (glue) لازم برای آزادسازی صحیح یک مقدار را تولید کند. مثال کد بالا نوعی را نشان می‌دهد که چنین استنتاجی برای آن ناممکن است، چون بازگشتی است. توجه کنید که این با E0072 که در آن نوع اندازه‌ی نامتناهی دارد یکسان نیست؛ نوع اینجا اندازه‌ی متناهی دارد اما هر تلاشی برای Drop کردن آن بی‌نهایت بازگشت می‌کند. برای اطلاعات بیشتر مستندات Drop را بخوانید.

    تعریف نوعی با قواعد drop-check بازگشتی ممکن نیست. تمام چنین بازگشت‌هایی باید حذف شوند.
