راهنمای خطاهای کامپایلرCompiler Error Index

    یک شناسه غیر ASCII در جایی نامعتبر استفاده شده است.

    مثال‌های کدی که خطا می‌دهند:

    
mod řųśť; // error!

#[no_mangle]
fn řųśť() {} // error!

fn main() {}

    نام‌های غیر ASCII را می‌توان برای ماژول‌ها به کار برد، به شرطی که ماژول درون‌خطی (inline) باشد یا attribute با نام #[path] مشخص شده باشد. برای مثال:

    mod řųśť { // ok!
    const IS_GREAT: bool = true;
}

fn main() {}
