راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود.

    ثابت‌ها را فقط می‌توان با یک مقدار ثابت یا، در نسخه‌ای آینده از Rust، با فراخوانی یک تابع const مقداردهی اولیه کرد. این خطا نشان می‌دهد که از یک مسیر (مانند a::b یا x) استفاده شده که چیزی غیر از این آیتم‌های مجاز را مشخص می‌کند.

    نمونه کد اشتباه:

    const FOO: i32 = { let x = 0; x }; // 'x' isn't a constant nor a function!

    برای پرهیز از آن، باید مقدار غیر ثابت را جایگزین کنید:

    const FOO: i32 = { const X : i32 = 0; X };
// or even:
const FOO2: i32 = { 0 }; // but brackets are useless here
