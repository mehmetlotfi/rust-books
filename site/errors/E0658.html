راهنمای خطاهای کامپایلرCompiler Error Index

    از یک feature ناپایدار استفاده شده است.

    نمونهٔ کد خطادار:

    use std::intrinsics; // error: use of unstable library feature `core_intrinsics`

    اگر از نسخهٔ stable یا beta ابزار rustc استفاده می‌کنید، نمی‌توانید از هیچ قابلیت ناپایداری (unstable) استفاده کنید. برای این کار لطفاً (با استفاده از rustup) به نسخهٔ nightly ابزار rustc بروید.

    اگر از نسخهٔ nightly ابزار rustc استفاده می‌کنید، برای استفاده از feature مورد نظر کافی است آن را اضافه کنید:

    #![feature(core_intrinsics)]

use std::intrinsics; // ok!
