راهنمای خطاهای کامپایلرCompiler Error Index

    تلاش شده است متغیری با نوع نامعتبر به یک تابع variadic پاس داده شود.

    نمونهٔ کد دارای خطا:

    # use std::os::raw::{c_char, c_int};
extern "C" {
    fn printf(format: *const c_char, ...) -> c_int;
}

unsafe {
    printf("%f\n\0".as_ptr() as _, 0f32);
    // error: cannot pass an `f32` to variadic function, cast to `c_double`
}

    برخی از نوع‌های Rust باید پیش از پاس دادن به یک تابع variadic cast شوند، به دلیل قواعد پیچیدهٔ ABI که استاندارد C دیکته می‌کند. برای رفع خطا، مقدار را به نوعی که پیام خطا مشخص کرده است cast کنید (ممکن است لازم باشد آن را از std::os::raw import کنید).

    در این مورد، c_double هم‌اندازهٔ f64 است، بنابراین می‌توانیم مستقیماً از آن استفاده کنیم:

    # use std::os::raw::{c_char, c_int};
# extern "C" {
#     fn printf(format: *const c_char, ...) -> c_int;
# }

unsafe {
    printf("%f\n\0".as_ptr() as _, 0f64); // ok!
}
