راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود.

    متغیرهای static و const می‌توانند به متغیرهای const دیگر ارجاع دهند. اما یک متغیر const نمی‌تواند به یک متغیر static ارجاع دهد.

    نمونه کد اشتباه:

    static X: i32 = 42;
const Y: i32 = X;

    در این مثال، Y نمی‌تواند به X ارجاع دهد. برای رفع این مشکل، می‌توان مقدار را به‌صورت یک const استخراج کرد و سپس از آن استفاده نمود:

    const A: i32 = 42;
static X: i32 = A;
const Y: i32 = A;
