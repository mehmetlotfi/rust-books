    یک closure یا generator ساخته شده است که به نوع خودش ارجاع می‌دهد.

    نمونهٔ کد خطادار:

    fn fix<F>(f: &F)
  where F: Fn(&F)
{
    f(&f);
}

fn main() {
    fix(&|y| {
        // Here, when `x` is called, the parameter `y` is equal to `x`.
    });
}

    Rust اجازه نمی‌دهد یک closure مستقیماً به نوع خودش ارجاع دهد، چه از طریق یک آرگومان (مانند نمونهٔ بالا) و چه با گرفتن خودش از طریق محیطش. این محدودیت کمک می‌کند استنتاج closureها قابل مهار بماند.

    ساده‌ترین راه‌حل این است که closure خود را به یک تابع سطح بالا یا یک متد تبدیل کنید. در برخی موارد نیز می‌توانید با گرفتن یک شیء &Fn() یا یک اشاره‌گر fn() که به خودش اشاره دارد، کاری کنید که closure خودش را صدا بزند. این کار مجاز است، زیرا closure خودش را از طریق یک فراخوانی مجازی (virtual call) صدا می‌زند و در نتیجه مستقیماً به نوع خودش ارجاع نمی‌دهد.
