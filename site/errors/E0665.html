    صفت Default روی یک شمارش derive شده است بدون اینکه واریانت پیش‌فرض مشخص شود.

    نمونهٔ کد خطادار:

    #[derive(Default)]
enum Food {
    Sweet,
    Salty,
}

    صفت Default را به این دلیل ساده نمی‌توان روی یک شمارش derive کرد که کامپایلر نمی‌داند به‌طور پیش‌فرض کدام مقدار را انتخاب کند، در حالی که برای یک ساختار، تا زمانی که همهٔ فیلدهایش نیز صفت Default را پیاده‌سازی کرده باشند، این کار ممکن است.

    در حالتی که واریانت پیش‌فرض مورد نظر داده‌ای همراه ندارد، می‌توانید برای derive کردن آن، روی آن #[default] را بگذارید:

    #[derive(Default)]
enum Food {
    #[default]
    Sweet,
    Salty,
}

    در حالتی که واریانت پیش‌فرض داده‌ای همراه دارد، باید Default را به‌صورت دستی روی شمارش خود پیاده‌سازی کنید:

    enum Food {
    Sweet(i32),
    Salty,
}

impl Default for Food {
    fn default() -> Food {
        Food::Sweet(1)
    }
}
