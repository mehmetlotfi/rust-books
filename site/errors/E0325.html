راهنمای خطاهای کامپایلرCompiler Error Index

    یک نوع وابسته (associated type) پیاده‌سازی شده است در حالی که آیتم دیگری از صفت انتظار می‌رفت.

    نمونه کد خطادار:

    struct Bar;

trait Foo {
    const N : u32;
}

impl Foo for Bar {
    type N = u32;
    // error: item `N` is an associated type, which doesn't match its
    //        trait `<Bar as Foo>`
}

    لطفاً بررسی کنید که نام نوع وابسته اشتباه نوشته نشده باشد و پیاده‌سازی شما با تعریف صفت مطابقت داشته باشد. مثال:

    struct Bar;

trait Foo {
    type N;
}

impl Foo for Bar {
    type N = u32; // ok!
}

    یا:

    struct Bar;

trait Foo {
    const N : u32;
}

impl Foo for Bar {
    const N : u32 = 0; // ok!
}
