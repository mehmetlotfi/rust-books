راهنمای خطاهای کامپایلرCompiler Error Index

    یک قید آیتم وابسته (associated item constraint) در جایی غیرمنتظره نوشته شده است.

    نمونه کد دارای خطا:

    pub trait Foo {
    type A;
    fn boo(&self) -> <Self as Foo>::A;
}

struct Bar;

impl Foo for isize {
    type A = usize;
    fn boo(&self) -> usize { 42 }
}

fn baz<I>(x: &<I as Foo<A = Bar>>::A) {}
// error: associated item constraint are not allowed here

    برای رفع این خطا، لطفاً قیدهای آیتم وابسته را به اعلان پارامتر نوع منتقل کنید:

    # struct Bar;
# trait Foo { type A; }
fn baz<I: Foo<A=Bar>>(x: &<I as Foo>::A) {} // ok!

    یا به عبارت where:

    # struct Bar;
# trait Foo { type A; }
fn baz<I>(x: &<I as Foo>::A) where I: Foo<A=Bar> {}
    → E0228E0230 ←
