    تعریف یک تابع naked پشتیبانی‌نشده.

    مثال کدی که خطا می‌دهد:

    #[unsafe(naked)]
pub extern "C" fn f() -> u32 {
    42
}

    تابع naked باید با استفاده از یک بلوک اسمبلی واحد naked_asm! تعریف شود.

    اجرا هرگز نباید از انتهای کد اسمبلی عبور کند و ادامه یابد، بنابراین باید یا بازگردد یا واگرا (diverge) شود. بلوک asm همچنین می‌تواند از گزینه‌های att_syntax و raw استفاده کند، اما گزینه‌های دیگر مجاز نیستند.

    بلوک asm نباید هیچ عملوندی (operand) جز const و sym داشته باشد.
