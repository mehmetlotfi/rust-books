راهنمای خطاهای کامپایلرCompiler Error Index

    برخی از پارامترهای نوع نام یکسانی دارند.

    نمونه کد خطادار:

    fn f<T, T>(s: T, u: T) {} // error: the name `T` is already used for a generic
                          //        parameter in this item's generic parameters

    لطفاً بررسی کنید که نام هیچ‌یک از پارامترهای نوع اشتباه نوشته نشده باشد و پارامترهای هم‌نام را تغییر نام دهید. مثال:

    fn f<T, Y>(s: T, u: Y) {} // ok!

    پارامترهای نوع در یک آیتم وابسته (associated item) نیز نمی‌توانند پارامترهای آیتم دربرگیرنده را پنهان (shadow) کنند:

    trait Foo<T> {
    fn do_something(&self) -> T;
    fn do_something_else<T: Clone>(&self, bar: T);
}
