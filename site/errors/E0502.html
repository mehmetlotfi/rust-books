راهنمای خطاهای کامپایلرCompiler Error Index

    متغیری که پیش‌تر با یک نوع تغییرپذیری مشخص (تغییرپذیر یا تغییرناپذیر) قرض گرفته شده بود، دوباره با تغییرپذیری متفاوتی قرض گرفته شده است.

    نمونه کد خطادار:

    fn bar(x: &mut i32) {}
fn foo(a: &mut i32) {
    let y = &a; // a is borrowed as immutable.
    bar(a); // error: cannot borrow `*a` as mutable because `a` is also borrowed
            //        as immutable
    println!("{}", y);
}

    برای رفع این خطا مطمئن شوید که پیش از دسترسی به متغیر با تغییرپذیری متفاوت، هیچ ارجاع دیگری به آن وجود ندارد:

    fn bar(x: &mut i32) {}
fn foo(a: &mut i32) {
    bar(a);
    let y = &a; // ok!
    println!("{}", y);
}

    برای اطلاعات بیشتر درباره‌ی سامانه‌ی مالکیت Rust، بخش ارجاع‌ها و قرض‌گیری کتاب را ببینید.
