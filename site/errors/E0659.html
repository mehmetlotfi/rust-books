راهنمای خطاهای کامپایلرCompiler Error Index

    استفاده از یک آیتم مبهم است.

    نمونهٔ کد خطادار:

    pub mod moon {
    pub fn foo() {}
}

pub mod earth {
    pub fn foo() {}
}

mod collider {
    pub use crate::moon::*;
    pub use crate::earth::*;
}

fn main() {
    crate::collider::foo(); // ERROR: `foo` is ambiguous
}

    این خطا معمولاً زمانی ظاهر می‌شود که دو آیتم با نام یکسان در یک ماژول وارد (import) شوند. در اینجا، تابع‌های foo وارد شده و از ماژول collider دوباره صادر (reexport) می‌شوند و بنابراین هنگام استفاده از collider::foo() هر دو تابع با هم تداخل پیدا می‌کنند.

    برای حل این خطا، بهترین راه‌حل معمولاً این است که هنگام استفاده از آیتم، مسیر پیش از آن را نگه دارید. مثال:

    pub mod moon {
    pub fn foo() {}
}

pub mod earth {
    pub fn foo() {}
}

mod collider {
    pub use crate::moon;
    pub use crate::earth;
}

fn main() {
    crate::collider::moon::foo(); // ok!
    crate::collider::earth::foo(); // ok!
}
