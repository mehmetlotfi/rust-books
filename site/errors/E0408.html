راهنمای خطاهای کامپایلرCompiler Error Index

    یک الگوی «یا» (or) به‌کار رفته که در آن، متغیرهای مقیدشده در همه الگوها به‌طور یکسان مقید نشده‌اند.

    نمونه کد خطادار:

    match x {
    Some(y) | None => { /* use y */ } // error: variable `y` from pattern #1 is
                                      //        not bound in pattern #2
    _ => ()
}

    در اینجا y به محتوای Some مقید می‌شود و می‌توان آن را درون بلوک مربوط به بازوی match استفاده کرد. اما اگر x برابر None باشد، مشخص نکرده‌ایم که y چیست و بلوک از متغیری ناموجود استفاده خواهد کرد.

    برای رفع این خطا، یا آن را به چند بازوی match جداگانه تقسیم کنید:

    let x = Some(1);
match x {
    Some(y) => { /* use y */ }
    None => { /* ... */ }
}

    یا متغیر را در همه زیرالگوهای الگوی «یا» به فیلدی از همان نوع مقید کنید:

    let x = (0, 2);
match x {
    (0, y) | (y, 0) => { /* use y */}
    _ => {}
}

    در این مثال، اگر x با الگوی (0, _) مطابقت کند، فیلد دوم در y قرار می‌گیرد. اگر با (_, 0) مطابقت کند، فیلد اول در y قرار می‌گیرد؛ بنابراین در همه حالت‌ها y مقداری دارد.
