راهنمای خطاهای کامپایلرCompiler Error Index

    از نحو لیترال ساختار (structure-literal) برای ساختن آیتمی استفاده شده است که یک ساختار یا واریانت شمارش نیست.

    نمونه کد نادرست:

    type U32 = u32;
let t = U32 { value: 4 }; // error: expected struct, variant or union type,
                          // found builtin type `u32`

    برای رفع این مشکل، مطمئن شوید که نام درست نوشته شده و شکل صحیح مقداردهی اولیه به کار رفته است.

    برای مثال، کد بالا را می‌توان به این صورت اصلاح کرد:

    type U32 = u32;
let t: U32 = 4;

    یا:

    struct U32 { value: u32 }
let t = U32 { value: 4 };
