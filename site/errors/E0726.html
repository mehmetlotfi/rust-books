    طول عمر (lifetime) یک آرگومان در یک تابع async حذف شده بود (elided).

    نمونه کد خطادار:

    وقتی یک ساختار یا یک نوع با طول عمر مقید/اعلان می‌شود، برای کامپایلر Rust مهم است که هنگام استفاده، طول عمر آن نوع را بداند. هنگامی که طول عمر به‌صراحت ذکر نشده باشد و کامپایلر Rust نتواند طول عمر نوع شما را تعیین کند، خطای زیر رخ می‌دهد.

    use futures::executor::block_on;
struct Content<'a> {
    title: &'a str,
    body: &'a str,
}
async fn create(content: Content) { // error: implicit elided
                                    // lifetime not allowed here
    println!("title: {}", content.title);
    println!("body: {}", content.body);
}
let content = Content { title: "Rust", body: "is great!" };
let future = create(content);
block_on(future);

    طول عمر دلخواه پارامتر content را مشخص کنید یا طول عمر ناشناس را مانند content: Content<'_> به‌کار ببرید. طول عمر ناشناس به کامپایلر Rust می‌گوید که content فقط تا زمانی لازم است که تابع create اجرای خود را به پایان برساند.

    «حذف ضمنی» (implicit elision) یعنی حذف طول عمر پیشنهادی، که همان pub async fn create<'a>(content: Content<'a>) {} است، در این‌جا مجاز نیست، زیرا طول عمر content می‌تواند با بافتار فعلی متفاوت باشد:

    async fn create(content: Content<'_>) { // ok!
    println!("title: {}", content.title);
    println!("body: {}", content.body);
}

    درباره حذف طول عمر (lifetime elision) در این فصل بیشتر بدانید و فصلی درباره طول عمرها را این‌جا می‌توانید بیابید.
