راهنمای خطاهای کامپایلرCompiler Error Index

    یک دستور break همراه با آرگومان در حلقه‌ای غیر از loop به کار رفته است.

    نمونه کد دارای خطا:

    # let mut i = 1;
# fn satisfied(n: usize) -> bool { n % 23 == 0 }
let result = while true {
    if satisfied(i) {
        break 2 * i; // error: `break` with value from a `while` loop
    }
    i += 1;
};

    دستور break در حلقه‌های loop می‌تواند یک آرگومان بگیرد (که در صورت اجرای break، مقدار عبارت حلقه خواهد بود)، اما در حلقه‌های for، while و while let چنین امکانی وجود ندارد.

    مطمئن شوید که دستورهای break value; فقط در حلقه‌های loop به کار می‌روند:

    # let mut i = 1;
# fn satisfied(n: usize) -> bool { n % 23 == 0 }
let result = loop { // This is now a "loop" loop.
    if satisfied(i) {
        break 2 * i; // ok!
    }
    i += 1;
};
