راهنمای خطاهای کامپایلرCompiler Error Index

    آیتم‌های داخلی، پارامترهای جنریک آیتم‌هایی را که در آن‌ها قرار گرفته‌اند به ارث نمی‌برند.

    نمونه کد خطادار:

    fn foo<T>(x: T) {
    fn bar(y: T) { // T is defined in the "outer" function
        // ..
    }
    bar(x);
}

    این کد هم کار نمی‌کند:

    fn foo<T>(x: T) {
    type MaybeT = Option<T>;
    // ...
}

    یا این:

    fn foo<T>(x: T) {
    struct Foo {
        x: T,
    }
    // ...
}

    آیتم‌هایی که درون آیتم‌های دیگر تودرتو شده‌اند اساساً مانند آیتم‌های سطح بالا هستند، با این تفاوت که فقط از درون همان آیتمی که در آن قرار دارند قابل استفاده‌اند.

    چند راه‌حل برای این مشکل وجود دارد.

    اگر آیتم یک تابع است، می‌توانید از یک closure استفاده کنید:

    fn foo<T>(x: T) {
    let bar = |y: T| { // explicit type annotation may not be necessary
        // ..
    };
    bar(x);
}

    برای یک آیتم جنریک می‌توانید پارامترها را کپی کنید:

    fn foo<T>(x: T) {
    fn bar<T>(y: T) {
        // ..
    }
    bar(x);
}

    fn foo<T>(x: T) {
    type MaybeT<T> = Option<T>;
}

    حتماً قیدها (bounds) را هم کپی کنید:

    fn foo<T: Copy>(x: T) {
    fn bar<T: Copy>(y: T) {
        // ..
    }
    bar(x);
}

    fn foo<T: Copy>(x: T) {
    struct Foo<T: Copy> {
        x: T,
    }
}

    ممکن است این کار به راهنمایی‌های نوعی (type hint) بیشتری در بدنه تابع نیاز داشته باشد.

    اگر آیتم یک تابع درون یک impl است، تعریف یک تابع کمکی خصوصی ممکن است ساده‌تر باشد:

    # struct Foo<T>(T);
impl<T> Foo<T> {
    pub fn foo(&self, x: T) {
        self.bar(x);
    }

    fn bar(&self, y: T) {
        // ..
    }
}

    برای پیاده‌سازی‌های پیش‌فرض در صفت‌ها (trait)، راه‌حل تابع کمکی خصوصی کار نمی‌کند، اما closureها یا کپی کردن پارامترها همچنان باید کار کنند.
