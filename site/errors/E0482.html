راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود.

    طول عمر یک مقدار بازگشتی بیشتر از فراخوانی تابع عمر نمی‌کند.

    نمونه کد دارای خطا:

    fn prefix<'a>(
    words: impl Iterator<Item = &'a str>
) -> impl Iterator<Item = String> { // error!
    words.map(|v| format!("foo-{}", v))
}

    برای رفع این خطا، طول عمر مقدار بازگشتی را صریح کنید:

    fn prefix<'a>(
    words: impl Iterator<Item = &'a str> + 'a
) -> impl Iterator<Item = String> + 'a { // ok!
    words.map(|v| format!("foo-{}", v))
}

    قابلیت impl Trait در این مثال از یک محدودیت ضمنی طول عمر 'static در نوع بازگشتی استفاده می‌کند. با این حال، نوعی که Iterator ارسال‌شده به تابع را پیاده‌سازی می‌کند فقط به اندازه‌ی 'a عمر می‌کند که کافی نیست.

    راه‌حل شامل افزودن قید طول عمر هم به آرگومان تابع و هم به مقدار بازگشتی است تا اطمینان حاصل شود که مقادیر درون iterator هنگام خروج تابع از دامنه (scope) حذف (drop) نمی‌شوند.

    راه‌حل جایگزین این است که تضمین کنیم ارجاع‌های Item در iterator در تمام طول عمر برنامه زنده‌اند.

    fn prefix(
    words: impl Iterator<Item = &'static str>
) -> impl Iterator<Item = String> {  // ok!
    words.map(|v| format!("foo-{}", v))
}

    مشکل طول عمر مشابهی ممکن است هنگام بازگرداندن closureها نیز پیش آید:

    fn foo(
    x: &mut Vec<i32>
) -> impl FnMut(&mut Vec<i32>) -> &[i32] { // error!
    |y| {
        y.append(x);
        y
    }
}

    به‌طور مشابه، راه‌حل در اینجا استفاده از طول عمر صریح برای مقدار بازگشتی و انتقال مالکیت متغیر به closure است.

    fn foo<'a>(
    x: &'a mut Vec<i32>
) -> impl FnMut(&mut Vec<i32>) -> &[i32] + 'a { // ok!
    move |y| {
        y.append(x);
        y
    }
}

    برای درک بهتر نحوه‌ی برخورد با طول عمر در impl Trait، لطفاً به RFC 1951 مراجعه کنید.
