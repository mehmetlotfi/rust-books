    این خطا نشان می‌دهد که ساختار، شمارش یا واریانت شمارش را نمی‌توان از بیرون از crateِ تعریف‌کننده‌اش نمونه‌سازی کرد، زیرا با non_exhaustive علامت‌گذاری شده است و بنابراین ممکن است در آینده فیلدها یا واریانت‌های بیشتری به آن افزوده شود که می‌تواند اثرات جانبی نامطلوبی بر این کد بگذارد.

    نمونهٔ کد خطادار:

    #[non_exhaustive]
pub struct NormalStruct {
    pub first_field: u16,
    pub second_field: u16,
}

let ns = NormalStruct { first_field: 640, second_field: 480 }; // error!

    توصیه می‌شود در مستندات crate به دنبال تابع new یا معادل آن بگردید.
