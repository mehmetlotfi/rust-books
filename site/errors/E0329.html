راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود.

    تلاش شد از طریق یک پارامتر نوع جنریک یا Self به یک ثابت وابسته دسترسی پیدا شود. این کار هنوز پشتیبانی نمی‌شود. مثالی که باعث این خطا می‌شود در زیر آمده است:

    trait Foo {
    const BAR: f64;
}

struct MyStruct;

impl Foo for MyStruct {
    const BAR: f64 = 0f64;
}

fn get_bar_bad<F: Foo>(t: F) -> f64 {
    F::BAR
}

    در حال حاضر، مقدار BAR برای یک نوع خاص فقط از طریق نوع مشخص (concrete) قابل دسترسی است، همان‌طور که در زیر نشان داده شده است:

    trait Foo {
    const BAR: f64;
}

struct MyStruct;

impl Foo for MyStruct {
    const BAR: f64 = 0f64;
}

fn get_bar_good() -> f64 {
    <MyStruct as Foo>::BAR
}
