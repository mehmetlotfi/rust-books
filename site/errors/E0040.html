راهنمای خطاهای کامپایلرCompiler Error Index

    در Rust فراخوانی دستی destructorها مجاز نیست.

    نمونه کد نادرست:

    struct Foo {
    x: i32,
}

impl Drop for Foo {
    fn drop(&mut self) {
        println!("kaboom");
    }
}

fn main() {
    let mut x = Foo { x: -7 };
    x.drop(); // error: explicit use of destructor method
}

    انجام این کار غیرضروری است، زیرا drop هر بار که یک مقدار از محدوده (scope) خارج می‌شود به‌طور خودکار فراخوانی می‌شود. با این حال، اگر واقعاً لازم است مقداری را دستی رها کنید، می‌توانید از تابع std::mem::drop استفاده کنید:

    struct Foo {
    x: i32,
}
impl Drop for Foo {
    fn drop(&mut self) {
        println!("kaboom");
    }
}
fn main() {
    let mut x = Foo { x: -7 };
    drop(x); // ok!
}
