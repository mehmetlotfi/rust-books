راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود.

    سعی کرده‌اید نوعی را در جایی که انتظار یک صفت (trait) مشخص را دارد ارائه دهید، در حالی که آن نوع آن صفت را پیاده‌سازی نمی‌کند. این خطا معمولاً هنگام کار با نوع‌های مبتنی بر Fn رخ می‌دهد. کد دارای خطا:

    fn foo<F: Fn(usize)>(x: F) { }

fn main() {
    // type mismatch: ... implements the trait `core::ops::Fn<(String,)>`,
    // but the trait `core::ops::Fn<(usize,)>` is required
    // [E0281]
    foo(|y: String| { });
}

    مشکل در این مورد این است که foo طوری تعریف شده که یک Fn با یک آرگومان از نوع String می‌پذیرد، اما closure‌ای که سعی کردیم به آن بدهیم یک آرگومان از نوع usize می‌خواهد.
