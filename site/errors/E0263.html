راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود.

    یک طول عمر (lifetime) بیش از یک بار در یک حوزه اعلان شده است.

    کد دارای خطا:

    fn foo<'a, 'b, 'a>(x: &'a str, y: &'b str, z: &'a str) { // error!
}

    دو طول عمر نمی‌توانند نام یکسان داشته باشند. برای رفع این مثال، دومین 'a را به چیز دیگری تغییر دهید (برای مثال 'c):

    fn foo<'a, 'b, 'c>(x: &'a str, y: &'b str, z: &'c str) { // ok!
}
