راهنمای خطاهای کامپایلرCompiler Error Index

    پارامترهای متغیر (variadic) روی تابعی با ABI غیر از C به کار رفته‌اند.

    نمونه کد نادرست:

    extern "Rust" {
    fn foo(x: u8, ...); // error!
}

    Rust فقط برای تعامل‌پذیری با کد C در FFI خود از پارامترهای variadic پشتیبانی می‌کند. بنابراین پارامترهای variadic فقط با توابعی قابل استفاده‌اند که از ABI زبان C استفاده می‌کنند. برای اصلاح چنین کدی، آن‌ها را در یک بلوک extern “C” قرار دهید:

    extern "C" {
    fn foo (x: u8, ...);
}
