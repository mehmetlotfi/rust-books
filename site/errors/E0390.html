راهنمای خطاهای کامپایلرCompiler Error Index

    یک متد یا ثابت روی یک نوع اولیه (primitive) پیاده‌سازی شده است.

    نمونه کد خطادار:

    struct Foo {
    x: i32
}

impl *mut Foo {}
// error: cannot define inherent `impl` for primitive types

    این کار مجاز نیست، اما استفاده از یک صفت برای پیاده‌سازی متد یا ثابت راه‌حل خوبی است. مثال:

    struct Foo {
    x: i32
}

trait Bar {
    fn bar();
}

impl Bar for *mut Foo {
    fn bar() {} // ok!
}

    به‌جای تعریف یک پیاده‌سازی ذاتی (inherent) روی یک ارجاع، می‌توانید ارجاع را به درون پیاده‌سازی نیز منتقل کنید:

    struct Foo;

impl &Foo { // error: no nominal type found for inherent implementation
    fn bar(self, other: Self) {}
}

    تبدیل می‌شود به

    struct Foo;

impl Foo {
    fn bar(&self, other: &Self) {}
}
