راهنمای خطاهای کامپایلرCompiler Error Index

    تلاش برای یک cast ناسازگار انجام شده است.

    نمونهٔ کد دارای خطا:

    let x = &0u8; // Here, `x` is a `&u8`.
let y: u32 = x as u32; // error: casting `&u8` as `u32` is invalid

    هنگام cast کردن به یاد داشته باشید که فقط نوع‌های اولیه (primitive) را می‌توان به یکدیگر cast کرد. مثال:

    let x = &0u8;
let y: u32 = *x as u32; // We dereference it first and then cast it.

    برای اطلاعات بیشتر دربارهٔ castها، بخش Type cast را در کتاب مرجع (The Reference Book) ببینید.
