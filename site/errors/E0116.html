    یک پیاده‌سازی ذاتی (inherent) برای نوعی تعریف شده است که بیرون از crate فعلی قرار دارد.

    نمونه کدی که خطا می‌دهد:

    impl Vec<u8> { } // error

    پیاده‌سازی ذاتی را فقط برای نوعی می‌توانید تعریف کنید که در همان crate تعریف شده باشد. برای مثال، یک بلوک impl مانند بالا مجاز نیست، زیرا Vec در کتابخانه‌ی استاندارد تعریف شده است.

    برای رفع این مشکل، می‌توانید یکی از این کارها را انجام دهید:

    • صفتی تعریف کنید که توابع/نوع‌ها/ثابت‌های وابسته‌ی مورد نظر را داشته باشد و آن صفت را برای نوع مورد نظر پیاده‌سازی کنید
    • نوع جدیدی تعریف کنید که نوع مورد نظر را در خود بپیچد و پیاده‌سازی را روی نوع جدید تعریف کنید

    توجه کنید که استفاده از کلیدواژه‌ی type در اینجا کارساز نیست، چون type فقط یک نام مستعار برای نوع (type alias) معرفی می‌کند:

    type Bytes = Vec<u8>;

impl Bytes { } // error, same as above
