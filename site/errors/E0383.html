راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود.

    این خطا زمانی رخ می‌دهد که سعی شود ساختاری که در حال حاضر مقداردهی‌نشده است به‌طور جزئی دوباره مقداردهی شود.

    برای مثال، این وضعیت می‌تواند پس از انجام یک drop رخ دهد:

    struct Foo {
    a: u32,
}
impl Drop for Foo {
    fn drop(&mut self) { /* ... */ }
}

let mut x = Foo { a: 1 };
drop(x); // `x` is now uninitialized
x.a = 2; // error, partial reinitialization of uninitialized structure `t`

    این خطا را می‌توان با مقداردهی مجدد کامل ساختار مورد نظر برطرف کرد:

    struct Foo {
    a: u32,
}
impl Drop for Foo {
    fn drop(&mut self) { /* ... */ }
}

let mut x = Foo { a: 1 };
drop(x);
x = Foo { a: 2 };
