راهنمای خطاهای کامپایلرCompiler Error Index

    پارامتر self در یک متد دارای «نوع گیرنده» (receiver type) جنریک نامعتبر است.

    مثال کد خطادار:

    struct Foo;

impl Foo {
    fn foo<R: std::ops::Deref<Target=Self>>(self: R) {}
}

    یا به‌صورت جایگزین،

    struct Foo;

impl Foo {
    fn foo(self: impl std::ops::Deref<Target=Self>) {}
}

    متدها یک پارامتر اول ویژه به نام self می‌گیرند. معمول است که از self، &self یا &mut self استفاده شود، که به‌ترتیب شکر نحوی (syntactic sugar) برای self: Self، self: &Self و self: &mut Self هستند. اما می‌توان از انواع پیچیده‌تری برای پارامتر self نیز استفاده کرد، برای مثال std::rc::Rc<Self>. مجموعه انواع مجاز Self با استفاده از قابلیت nightly به نام Arbitrary self types قابل گسترش است. این قابلیت مجموعه انواع معتبر Self را به هر نوعی که std::ops::Deref<Target=Self> را پیاده‌سازی کند گسترش می‌دهد، مثلاً Rc<Self>، Box<Self> یا اشاره‌گرهای هوشمند خودتان که همین کار را انجام می‌دهند.

    با این حال، حتی با آن قابلیت نیز نوع self باید مشخص (concrete) باشد. انواع جنریک برای self مجاز نیستند. به‌طور مشخص، اگر نوع self یک پارامتر نوعی باشد که روی خود متد تعریف شده است، رد می‌شود.

    موارد زیر درست هستند:

    struct Foo;

impl Foo {
    fn foo(self) {}
    fn foo2(self: std::rc::Rc<Self>) {} // or some other similar
        // smart pointer if you enable arbitrary self types and
        // the pointer implements Deref<Target=Self>
}
