راهنمای خطاهای کامپایلرCompiler Error Index

    تلاش برای دسترسی به یک فیلد روی یک نوع اولیه (primitive) انجام شده است.

    نمونهٔ کد دارای خطا:

    let x: u32 = 0;
println!("{}", x.foo); // error: `{integer}` is a primitive type, therefore
                       //        doesn't have fields

    نوع‌های اولیه ابتدایی‌ترین نوع‌های موجود در Rust هستند و فیلد ندارند. برای دسترسی به داده از طریق فیلدهای نام‌دار از ساختارها استفاده می‌شود. مثال:

    // We declare struct called `Foo` containing two fields:
struct Foo {
    x: u32,
    y: i64,
}

// We create an instance of this struct:
let variable = Foo { x: 0, y: -12 };
// And we can now access its fields:
println!("x: {}, y: {}", variable.x, variable.y);

    برای اطلاعات بیشتر دربارهٔ نوع‌های اولیه و ساختارها، به کتاب (Book) نگاه کنید.
