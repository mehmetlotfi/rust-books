راهنمای خطاهای کامپایلرCompiler Error Index

    تلاش برای ایندکس کردن مقداری شده است که نوع آن صفت std::ops::Index را پیاده‌سازی نکرده است.

    نمونهٔ کد دارای خطا:

    0u8[2]; // error: cannot index into a value of type `u8`

    فقط مقادیری که نوعشان صفت std::ops::Index را پیاده‌سازی کرده باشد را می‌توان با کروشه ایندکس کرد. مثال:

    let v: Vec<u8> = vec![0, 1, 2, 3];

// The `Vec` type implements the `Index` trait so you can do:
println!("{}", v[2]);

    چندتایی‌ها (tuple) و ساختارها با نقطه (.) ایندکس می‌شوند، نه با کروشه ([])، و نام عناصر چندتایی همان موقعیت آن‌هاست: ignore(pseudo code) // this (pseudo code) expression is true for any tuple: tuple == (tuple.0, tuple.1, ...)

    // this (pseudo code) expression is true for any tuple:
tuple == (tuple.0, tuple.1, ...)
