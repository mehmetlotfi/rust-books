راهنمای خطاهای کامپایلرCompiler Error Index

    در پیاده‌سازی یک صفت (trait)، متدی تعریف شده که در صفت پیاده‌سازی‌شده وجود ندارد.

    نمونه کد خطادار:

    trait Foo {
    fn a();
}

struct Bar;

impl Foo for Bar {
    fn a() {}
    fn b() {} // error: method `b` is not a member of trait `Foo`
}

    لطفاً بررسی کنید که نام متد را اشتباه ننوشته باشید و از صفت درست استفاده کرده باشید. مثال اول:

    trait Foo {
    fn a();
    fn b();
}

struct Bar;

impl Foo for Bar {
    fn a() {}
    fn b() {} // ok!
}

    مثال دوم:

    trait Foo {
    fn a();
}

struct Bar;

impl Foo for Bar {
    fn a() {}
}

impl Bar {
    fn b() {}
}
