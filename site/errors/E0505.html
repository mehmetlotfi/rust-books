راهنمای خطاهای کامپایلرCompiler Error Index

    مقداری در حالی که هنوز قرض گرفته شده بود، به بیرون منتقل شده است.

    نمونه کد خطادار:

    struct Value {}

fn borrow(val: &Value) {}

fn eat(val: Value) {}

fn main() {
    let x = Value{};
    let _ref_to_val: &Value = &x;
    eat(x);
    borrow(_ref_to_val);
}

    در اینجا تابع eat مالکیت x را می‌گیرد. اما x را نمی‌توان منتقل کرد، زیرا قرضِ _ref_to_val باید تا زمان فراخوانی تابع borrow باقی بماند. برای رفع این مشکل می‌توانید چند کار انجام دهید:

    • سعی کنید از انتقال متغیر پرهیز کنید.
    • پیش از انتقال، قرض را آزاد کنید.
    • صفت Copy را برای آن نوع پیاده‌سازی کنید.

    مثال‌ها:

    struct Value {}

fn borrow(val: &Value) {}

fn eat(val: &Value) {}

fn main() {
    let x = Value{};

    let ref_to_val: &Value = &x;
    eat(&x); // pass by reference, if it's possible
    borrow(ref_to_val);
}

    یا:

    struct Value {}

fn borrow(val: &Value) {}

fn eat(val: Value) {}

fn main() {
    let x = Value{};

    let ref_to_val: &Value = &x;
    borrow(ref_to_val);
    // ref_to_val is no longer used.
    eat(x);
}

    یا:

    #[derive(Clone, Copy)] // implement Copy trait
struct Value {}

fn borrow(val: &Value) {}

fn eat(val: Value) {}

fn main() {
    let x = Value{};
    let ref_to_val: &Value = &x;
    eat(x); // it will be copied here.
    borrow(ref_to_val);
}

    برای اطلاعات بیشتر درباره‌ی سامانه‌ی مالکیت Rust، بخش ارجاع‌ها و قرض‌گیری کتاب را ببینید.
