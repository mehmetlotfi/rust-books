راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود.

    این خطا زمانی رخ می‌دهد که سعی شود داده‌ای که یک closure آن را به‌صورت تغییرناپذیر capture کرده، تغییر داده شود یا ارجاع تغییرپذیر به آن گرفته شود.

    نمونه کد خطادار:

    // Accepts a function or a closure that captures its environment immutably.
// Closures passed to foo will not be able to mutate their closed-over state.
fn foo<F: Fn()>(f: F) { }

// Attempts to mutate closed-over data. Error message reads:
// `cannot assign to data in a captured outer variable...`
fn mutable() {
    let mut x = 0u32;
    foo(|| x = 2);
}

// Attempts to take a mutable reference to closed-over data. Error message
// reads: `cannot borrow data mutably in a captured outer variable...`
fn mut_addr() {
    let mut x = 0u32;
    foo(|| { let y = &mut x; });
}

    مشکل اینجاست که foo طوری تعریف شده که پارامتری از نوع Fn می‌پذیرد. بنابراین closureهایی که به foo داده می‌شوند از نوع Fn استنتاج می‌شوند، یعنی محیط خود را به‌صورت تغییرناپذیر capture می‌کنند.

    اگر تعریف foo در اختیار شما باشد، ساده‌ترین راه‌حل capture کردن داده به‌صورت تغییرپذیر است. این کار با تعریف foo به‌گونه‌ای که به‌جای Fn، نوع FnMut را بپذیرد انجام می‌شود:

    fn foo<F: FnMut()>(f: F) { }

    یا می‌توانیم استفاده از انواع Cell و RefCell را برای دستیابی به تغییرپذیری درونی از طریق یک ارجاع مشترک در نظر بگیریم. تابع mutable در مثال ما را می‌توان به شکل زیر بازتعریف کرد:

    use std::cell::Cell;

fn foo<F: Fn()>(f: F) { }

fn mutable() {
    let x = Cell::new(0u32);
    foo(|| x.set(2));
}

    برای اطلاعات بیشتر می‌توانید مستندات API مربوط به Cell را بخوانید.
