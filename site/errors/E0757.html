راهنمای خطاهای کامپایلرCompiler Error Index

    به یک تابع هر دو attribute با نام‌های ffi_const و ffi_pure داده شده است.

    مثال کدی که خطا می‌دهد:

    #![feature(ffi_const, ffi_pure)]

extern "C" {
    #[unsafe(ffi_const)]
    #[unsafe(ffi_pure)]
    //~^ ERROR `#[ffi_const]` function cannot be `#[ffi_pure]`
    pub fn square(num: i32) -> i32;
}

    از آنجا که ffi_const تضمین‌های قوی‌تری نسبت به ffi_pure فراهم می‌کند، attribute با نام ffi_pure را حذف کنید:

    #![feature(ffi_const)]

extern "C" {
    #[unsafe(ffi_const)]
    pub fn square(num: i32) -> i32;
}

    درباره const و pure می‌توانید اطلاعات بیشتری را در مستندات GCC درباره attributeهای رایج توابع بیابید. کتاب ناپایدار Rust نیز اطلاعات بیشتری درباره ffi_const و ffi_pure دارد.
