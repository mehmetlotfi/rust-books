راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود

    افزونه (plugin) .. فقط با قالب rlib یافت شد، اما باید با قالب dylib در دسترس باشد.

    نمونه کد دارای خطا:

    rlib-plugin.rs

    #![crate_type = "rlib"]
#![feature(rustc_private)]

extern crate rustc_middle;
extern crate rustc_driver;

use rustc_driver::plugin::Registry;

#[no_mangle]
fn __rustc_plugin_registrar(_: &mut Registry) {}

    main.rs

    #![feature(plugin)]
#![plugin(rlib_plugin)] // error: plugin `rlib_plugin` only found in rlib
                        //        format, but must be available in dylib

fn main() {}

    کامپایلر یک رابط افزونه ارائه می‌دهد تا امکان تغییر فرایند کامپایل (افزودن lint و غیره) فراهم شود. افزونه‌ها باید در crateهای مخصوص به خود تعریف شوند (مشابه جداسازی proc-macro) و سپس کامپایل شده و به crate دیگری پیوند داده شوند. crateهای افزونه باید به قالب dylib که به‌صورت پویا پیوند می‌شود کامپایل شوند، نه قالب rlib که به‌صورت ایستا پیوند می‌شود. درباره انواع مختلف خروجی در این بخش از Rust reference بیشتر بخوانید.

    این خطا به‌سادگی با کامپایل مجدد crate افزونه در قالب dylib رفع می‌شود.
