راهنمای خطاهای کامپایلرCompiler Error Index

    یک عبارت union دقیقاً یک فیلد ندارد.

    مثال کدی که خطا می‌دهد:

    union Bird {
    pigeon: u8,
    turtledove: u16,
}

let bird = Bird {}; // error
let bird = Bird { pigeon: 0, turtledove: 1 }; // error

    ویژگی کلیدی unionها این است که همهٔ فیلدهای یک union فضای ذخیره‌سازی مشترکی دارند. در نتیجه، نوشتن در یک فیلد از union می‌تواند فیلدهای دیگر آن را بازنویسی کند و اندازهٔ union با اندازهٔ بزرگ‌ترین فیلد آن تعیین می‌شود.

    اطلاعات بیشتر دربارهٔ نوع‌های union را می‌توانید در Rust reference بیابید.

    مثال درست:

    union Bird {
    pigeon: u8,
    turtledove: u16,
}

let bird = Bird { pigeon: 0 }; // OK
