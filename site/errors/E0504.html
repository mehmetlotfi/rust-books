راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود.

    این خطا زمانی رخ می‌دهد که تلاش شود یک متغیر قرض‌گرفته‌شده به داخل یک closure منتقل شود.

    نمونه کد خطادار:

    struct FancyNum {
    num: u8,
}

fn main() {
    let fancy_num = FancyNum { num: 5 };
    let fancy_ref = &fancy_num;

    let x = move || {
        println!("child function: {}", fancy_num.num);
        // error: cannot move `fancy_num` into closure because it is borrowed
    };

    x();
    println!("main function: {}", fancy_ref.num);
}

    در اینجا fancy_num توسط fancy_ref قرض گرفته شده است و بنابراین نمی‌توان آن را به داخل closure با نام x منتقل کرد. راهی برای انتقال یک مقدار به داخل closure در زمانی که قرض گرفته شده وجود ندارد، زیرا این کار قرض را باطل می‌کند.

    اگر closure نمی‌تواند از مقدار منتقل‌شده بیشتر عمر کند، به‌جای انتقال از یک ارجاع استفاده کنید:

    struct FancyNum {
    num: u8,
}

fn main() {
    let fancy_num = FancyNum { num: 5 };
    let fancy_ref = &fancy_num;

    let x = move || {
        // fancy_ref is usable here because it doesn't move `fancy_num`
        println!("child function: {}", fancy_ref.num);
    };

    x();

    println!("main function: {}", fancy_num.num);
}

    اگر مقدار باید ابتدا قرض گرفته شود و سپس منتقل شود، سعی کنید طول عمر قرض را با یک بلوک محدود کنید:

    struct FancyNum {
    num: u8,
}

fn main() {
    let fancy_num = FancyNum { num: 5 };

    {
        let fancy_ref = &fancy_num;
        println!("main function: {}", fancy_ref.num);
        // `fancy_ref` goes out of scope here
    }

    let x = move || {
        // `fancy_num` can be moved now (no more references exist)
        println!("child function: {}", fancy_num.num);
    };

    x();
}

    اگر طول عمر یک ارجاع کافی نیست، مانند حالتی که از چند نخ استفاده می‌شود، استفاده از Arc را برای ساخت یک مقدار با شمارش ارجاع در نظر بگیرید:

    use std::sync::Arc;
use std::thread;

struct FancyNum {
    num: u8,
}

fn main() {
    let fancy_ref1 = Arc::new(FancyNum { num: 5 });
    let fancy_ref2 = fancy_ref1.clone();

    let x = thread::spawn(move || {
        // `fancy_ref1` can be moved and has a `'static` lifetime
        println!("child thread: {}", fancy_ref1.num);
    });

    x.join().expect("child thread should finish");
    println!("main thread: {}", fancy_ref2.num);
}
