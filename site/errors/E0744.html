    توجه: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود.

    یک عبارت پشتیبانی‌نشده درون یک بافتار const به کار رفته بود.

    نمونه کد خطادار:

    const _: i32 = {
    async { 0 }.await
};

    در حال حاضر، استفاده از .await درون const، static یا const fn ممنوع است.

    ممکن است در آینده این کار مجاز شود، اما پیاده‌سازی آن هنوز کامل نیست. مسئله پیگیری (tracking issue) مربوط به async در const fn را ببینید.
