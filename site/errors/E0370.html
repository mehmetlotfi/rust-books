راهنمای خطاهای کامپایلرCompiler Error Index

    مقدار بیشینه یک شمارش (enum) به‌دست آمده است، بنابراین نمی‌توان آن را به‌طور خودکار در مقدار بعدی شمارش قرار داد.

    نمونه کد خطادار:

    #[repr(i64)]
enum Foo {
    X = 0x7fffffffffffffff,
    Y, // error: enum discriminant overflowed on value after
       //        9223372036854775807: i64; set explicitly via
       //        Y = -9223372036854775808 if that is desired outcome
}

    برای رفع این مشکل، مقدار بعدی شمارش را به‌صورت دستی تعیین کنید یا گونه (variant) دارای مقدار بیشینه را در انتهای شمارش قرار دهید. مثال‌ها:

    #[repr(i64)]
enum Foo {
    X = 0x7fffffffffffffff,
    Y = 0, // ok!
}

    یا:

    #[repr(i64)]
enum Foo {
    Y = 0, // ok!
    X = 0x7fffffffffffffff,
}
