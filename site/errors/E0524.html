راهنمای خطاهای کامپایلرCompiler Error Index

    متغیری که به دسترسی یکتا (unique) نیاز دارد به‌طور هم‌زمان در بیش از یک closure استفاده می‌شود.

    نمونه کد خطادار:

    fn set(x: &mut isize) {
    *x += 4;
}

fn dragoooon(x: &mut isize) {
    let mut c1 = || set(x);
    let mut c2 = || set(x); // error!

    c2();
    c1();
}

    برای حل این مشکل چند راه‌حل وجود دارد. اول اینکه، آیا لازم است این متغیر هم‌زمان در بیش از یک closure استفاده شود؟ اگر چنین است، از انواع دارای شمارش مرجع مانند Rc (یا Arc اگر به‌صورت هم‌روند اجرا می‌شود) استفاده کنید:

    use std::rc::Rc;
use std::cell::RefCell;

fn set(x: &mut isize) {
    *x += 4;
}

fn dragoooon(x: &mut isize) {
    let x = Rc::new(RefCell::new(x));
    let y = Rc::clone(&x);
    let mut c1 = || { let mut x2 = x.borrow_mut(); set(&mut x2); };
    let mut c2 = || { let mut x2 = y.borrow_mut(); set(&mut x2); }; // ok!

    c2();
    c1();
}

    اگر نه، closureها را فقط یکی‌یکی اجرا کنید:

    fn set(x: &mut isize) {
    *x += 4;
}

fn dragoooon(x: &mut isize) {
    { // This block isn't necessary since non-lexical lifetimes, it's just to
      // make it more clear.
        let mut c1 = || set(&mut *x);
        c1();
    } // `c1` has been dropped here so we're free to use `x` again!
    let mut c2 = || set(&mut *x);
    c2();
}
