راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود

    یک طول عمر غیر 'static در یک const جنریک استفاده شده است. این کار در حال حاضر مجاز نیست.

    مثال کدی که خطا می‌دهد:

    #![feature(adt_const_params, unsized_const_params)]

fn function_with_str<'a, const STRING: &'a str>() {} // error!

    برای رفع این مشکل، طول عمر در const جنریک باید به 'static تغییر کند:

    #![feature(adt_const_params, unsized_const_params)]

fn function_with_str<const STRING: &'static str>() {} // ok!

    برای اطلاعات بیشتر، GitHub issue #74052 را ببینید.
