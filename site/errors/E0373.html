راهنمای خطاهای کامپایلرCompiler Error Index

    یک متغیر گرفته‌شده (captured) در یک closure ممکن است به اندازه کافی عمر نکند.

    نمونه کد خطادار:

    fn foo() -> Box<dyn Fn(u32) -> u32> {
    let x = 0u32;
    Box::new(|y| x + y)
}

    این خطا زمانی رخ می‌دهد که سعی شود از داده‌ای که closure آن را capture کرده استفاده شود، در حالی که ممکن است آن داده دیگر وجود نداشته باشد. این خطا معمولاً هنگام بازگرداندن یک closure دیده می‌شود، مانند نمونه کد بالا.

    توجه کنید که x روی stack توسط foo() تخصیص داده شده است. به‌طور پیش‌فرض، Rust داده‌های بسته‌شده (closed-over) را با ارجاع capture می‌کند. این یعنی پس از بازگشت foo()، دیگر x وجود ندارد. بنابراین تلاش برای دسترسی به x درون closure ناامن خواهد بود.

    موقعیت دیگری که ممکن است با این خطا روبه‌رو شوید، ایجاد نخ‌ها (threads) است:

    fn foo() {
    let x = 0u32;
    let y = 1u32;

    let thr = std::thread::spawn(|| {
        x + y
    });
}

    از آنجا که نخ جدید ما به‌صورت موازی اجرا می‌شود، ممکن است فریم stack حاوی x و y تا زمانی که بخواهیم از آن‌ها استفاده کنیم از بین رفته باشد. حتی اگر درون foo تابع thr.join() را فراخوانی کنیم (که تا پایان thr مسدود می‌شود و تضمین می‌کند فریم stack از بین نمی‌رود)، باز هم موفق نخواهیم شد: کامپایلر نمی‌تواند ثابت کند که این رفتار ایمن است و بنابراین اجازه نمی‌دهد.

    راه‌حل این مشکل معمولاً استفاده از یک closure از نوع move است. این رویکرد داده را به جای گرفتن ارجاع به آن، به درون closure منتقل (یا در صورت امکان کپی) می‌کند. برای مثال:

    fn foo() -> Box<dyn Fn(u32) -> u32> {
    let x = 0u32;
    Box::new(move |y| x + y)
}

    اکنون که closure نسخه مختص به خود از داده را دارد، جای نگرانی درباره ایمنی نیست.

    ممکن است هنگام استفاده از بلوک‌های async نیز با این خطا مواجه شوید:

    use std::future::Future;

async fn f() {
    let v = vec![1, 2, 3i32];
    spawn(async { //~ ERROR E0373
        println!("{:?}", v)
    });
}

fn spawn<F: Future + Send + 'static>(future: F) {
    unimplemented!()
}

    مشابه closureها، بلوک‌های async بلافاصله اجرا نمی‌شوند و ممکن است داده‌های بسته‌شده را با ارجاع capture کنند. برای اطلاعات بیشتر، https://rust-lang.github.io/async-book/03_async_await/01_chapter.html را ببینید.
