    یک توضیح مستندات (doc comment) پیدا شد که به هیچ چیزی متصل نیست.

    نمونه کد خطادار:

    trait Island {
    fn lost();

    /// I'm lost!
}

    یادآوری کوتاه: توضیح مستندات باید پیش از آیتمی قرار بگیرد که قرار است آن را مستند کند. بنابراین اگر می‌خواهید صفت Island را مستند کنید، باید توضیح مستندات را پیش از آن بگذارید، نه درون آن. این موضوع درباره‌ی متد lost هم صدق می‌کند: توضیح مستندات باید پیش از آن باشد:

    /// I'm THE island!
trait Island {
    /// I'm lost!
    fn lost();
}
