    این خطا زمانی رخ می‌دهد که یک قرض (borrow) در یک coroutine قابل‌جابه‌جایی (movable) از یک نقطهٔ yield عبور کند و همچنان زنده بماند.

    نمونه کد خطادار:

    # #![feature(coroutines, coroutine_trait, stmt_expr_attributes)]
# use std::ops::Coroutine;
# use std::pin::Pin;
let mut b = #[coroutine] || {
    let a = &String::new(); // <-- This borrow...
    yield (); // ...is still in scope here, when the yield occurs.
    println!("{}", a);
};
Pin::new(&mut b).resume(());

    coroutineها می‌توانند بدون نشانه باشند یا با static علامت‌گذاری شوند. اگر بدون نشانه باشند، coroutine «قابل‌جابه‌جایی» در نظر گرفته می‌شود. در حال حاضر، در یک coroutine قابل‌جابه‌جایی مجاز نیست yieldی رخ دهد که در آن لحظه یک قرض هنوز در حوزه (scope) باشد. برای رفع این خطا می‌توان coroutine را با static علامت‌گذاری کرد:

    # #![feature(coroutines, coroutine_trait, stmt_expr_attributes)]
# use std::ops::Coroutine;
# use std::pin::Pin;
let mut b = #[coroutine] static || { // <-- note the static keyword
    let a = &String::from("hello, world");
    yield ();
    println!("{}", a);
};
let mut b = std::pin::pin!(b);
b.as_mut().resume(());

    اگر coroutine باید قابل‌جابه‌جایی باقی بماند، مثلاً برای اینکه بدون پین کردن آن روی پشته یا در یک تخصیص حافظه به‌صورت Unpin استفاده شود، می‌توانیم مثال قبلی را به‌گونه‌ای دیگر هم رفع کنیم: قرض را حذف کنیم و نوع را فقط به‌صورت مقدار (by value) نگه داریم:

    # #![feature(coroutines, coroutine_trait, stmt_expr_attributes)]
# use std::ops::Coroutine;
# use std::pin::Pin;
let mut b = #[coroutine] || {
    let a = String::from("hello, world");
    yield ();
    println!("{}", a);
};
Pin::new(&mut b).resume(());

    البته این یک حالت بسیار ساده است. در حالت‌های پیچیده‌تر ممکن است بخواهیم بیش از یک ارجاع به مقداری که قرض گرفته شده داشته باشیم؛ در چنین مواردی چیزی شبیه نوع‌های Rc یا Arc می‌تواند مفید باشد.

    این خطا اغلب هنگام پیمایش (iteration) هم پیش می‌آید:

    # #![feature(coroutines, coroutine_trait, stmt_expr_attributes)]
# use std::ops::Coroutine;
# use std::pin::Pin;
let mut b = #[coroutine] || {
  let v = vec![1,2,3];
  for &x in &v { // <-- borrow of `v` is still in scope...
    yield x; // ...when this yield occurs.
  }
};
Pin::new(&mut b).resume(());

    چنین حالت‌هایی را گاهی می‌توان با پیمایش «به‌صورت مقدار» (یا استفاده از into_iter()) برای جلوگیری از قرض‌گیری رفع کرد:

    # #![feature(coroutines, coroutine_trait, stmt_expr_attributes)]
# use std::ops::Coroutine;
# use std::pin::Pin;
let mut b = #[coroutine] || {
  let v = vec![1,2,3];
  for x in v { // <-- Take ownership of the values instead!
    yield x; // <-- Now yield is OK.
  }
};
Pin::new(&mut b).resume(());

    اگر گرفتن مالکیت گزینهٔ مناسبی نیست، استفاده از اندیس‌ها هم می‌تواند جواب دهد:

    # #![feature(coroutines, coroutine_trait, stmt_expr_attributes)]
# use std::ops::Coroutine;
# use std::pin::Pin;
let mut b = #[coroutine] || {
  let v = vec![1,2,3];
  let len = v.len(); // (*)
  for i in 0..len {
    let x = v[i]; // (*)
    yield x; // <-- Now yield is OK.
  }
};
Pin::new(&mut b).resume(());

// (*) -- Unfortunately, these temporaries are currently required.
// See <https://github.com/rust-lang/rust/issues/43122>.
