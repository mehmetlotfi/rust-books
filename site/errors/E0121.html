راهنمای خطاهای کامپایلرCompiler Error Index

    مکان‌نگهدار نوع _ درون یک نوع در امضای یک آیتم به کار رفته است.

    نمونه کدی که خطا می‌دهد:

    fn foo() -> _ { 5 } // error

static BAR: _ = "test"; // error

    در این موارد باید نوع را به‌صراحت بنویسید:

    fn foo() -> i32 { 5 } // ok!

static BAR: &str = "test"; // ok!

    مکان‌نگهدار نوع _ را بیرون از امضای آیتم‌ها می‌توان به این شکل به کار برد:

    let x = "a4a".split('4')
    .collect::<Vec<_>>(); // No need to precise the Vec's generic type.
