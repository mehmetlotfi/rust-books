راهنمای خطاهای کامپایلرCompiler Error Index

    پارامتر طول عمر (lifetime) در تعریف یک تابع، در صورتی late-bound نامیده می‌شود که هر دو شرط زیر برقرار باشد:

    1. در نوع یک آرگومان ظاهر شود
    2. در یک قید نوع جنریک ظاهر نمی‌شود

    نمی‌توانید برای پارامترهای طول عمر late-bound آرگومان طول عمر مشخص کنید.

    مثال کد خطادار:

    fn foo<'a>(x: &'a str) -> &'a str { x }
let _ = foo::<'static>;

    نوع یک نمونه مشخص از یک تابع جنریک، روی پارامترهای طول عمر late-bound به‌صورت سراسری سورگذاری (universally quantified) می‌شود. دلیل این است که می‌خواهیم تابع برای هر طول عمری که به پارامتر طول عمر late-bound نسبت داده شود، صرف‌نظر از محل فراخوانی تابع، کار کند. در نتیجه، مشخص کردن آرگومان برای پارامترهای طول عمر late-bound معنایی ندارد، زیرا این پارامترها تا محل (یا محل‌های) فراخوانی تابع تعیین نمی‌شوند.

    برای رفع مشکل، طول عمر مشخص‌شده را حذف کنید:

    fn foo<'a>(x: &'a str) -> &'a str { x }
let _ = foo;

    اطلاعات بیشتر

    پارامترهای طول عمری که late-bound نیستند، early-bound نامیده می‌شوند. ممکن است این سردرگمی پیش بیاید که پارامترهای طول عمر late-bound و early-bound در تعریف تابع به یک شکل اعلان می‌شوند. هنگام اشاره به نوع اشاره‌گر تابع، سورگذاری سراسری روی پارامترهای طول عمر late-bound را می‌توان صریح کرد:

    trait BarTrait<'a> {}

struct Bar<'a> {
    s: &'a str
}

impl<'a> BarTrait<'a> for Bar<'a> {}

fn bar<'a, 'b, T>(x: &'a str, _t: T) -> &'a str
where T: BarTrait<'b>
{
    x
}

let bar_fn: for<'a> fn(&'a str, Bar<'static>) -> &'a str = bar; // OK
let bar_fn2 = bar::<'static, Bar>; // Not allowed
let bar_fn3 = bar::<Bar>; // OK

    در تعریف bar، پارامتر طول عمر 'a از نوع late-bound است، در حالی که 'b از نوع early-bound است. این موضوع در حاشیه‌نویسی نوع bar_fn منعکس شده است، جایی که 'a به‌صورت سراسری سورگذاری شده و 'b با یک طول عمر مشخص نمونه‌سازی شده است. وقتی پارامترهای طول عمر late-bound وجود دارند، مشخص کردن صریح آرگومان‌های طول عمر early-bound مجاز نیست (مانند bar_fn2، به issue #42868 مراجعه کنید)، هرچند انواعی که توسط پارامترهای early-bound مقید شده‌اند را می‌توان مشخص کرد (مانند bar_fn3).
