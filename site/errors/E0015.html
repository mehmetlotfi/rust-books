راهنمای خطاهای کامپایلرCompiler Error Index

    یک تابع غیر const در یک زمینهٔ const فراخوانی شده است.

    نمونه کد اشتباه:

    fn create_some() -> Option<u8> {
    Some(1)
}

// error: cannot call non-const function `create_some` in constants
const FOO: Option<u8> = create_some();

    همهٔ توابعی که در یک زمینهٔ const (ثابت یا عبارت static) استفاده می‌شوند باید با const علامت‌گذاری شده باشند.

    برای رفع این خطا، می‌توانید create_some را به‌عنوان یک تابع ثابت تعریف کنید:

    // declared as a `const` function:
const fn create_some() -> Option<u8> {
    Some(1)
}

const FOO: Option<u8> = create_some(); // no error!
