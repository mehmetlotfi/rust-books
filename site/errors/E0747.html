راهنمای خطاهای کامپایلرCompiler Error Index

    آرگومان‌های جنریک با همان ترتیبی که پارامترهای جنریک متناظر اعلان شده‌اند ارائه نشده‌اند، یا به‌جای ثابت (constant) یک نوع ارائه شده است.

    نمونه کد خطادار:

    struct S<'a, T>(&'a T);

type X = S<(), 'static>; // error: the type argument is provided before the
                         // lifetime argument

    ترتیب آرگومان‌ها باید طوری تغییر کند که با ترتیب اعلان پارامترها مطابقت داشته باشد، مانند زیر:

    struct S<'a, T>(&'a T);

type X = S<'static, ()>; // ok

    نمونه کد خطادار دیگر:

    struct Foo<const N: usize>;

fn foo() -> Foo<usize> {} // error: type provided when a constant was
                          // expected

    وقتی یک پارامتر جنریک ثابت اعلان شده باشد، باید یک عبارت ثابت ارائه شود، نه یک نوع، مانند زیر:

    struct Foo<const N: usize>;

fn foo() -> Foo<3> { Foo }
