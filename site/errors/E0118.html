    یک پیاده‌سازی ذاتی (inherent) برای چیزی تعریف شده است که ساختار، شمارش، union یا شیء صفت نیست.

    نمونه کدی که خطا می‌دهد:

    impl<T> T { // error: no nominal type found for inherent implementation
    fn get_state(&self) -> String {
        // ...
    }
}

    برای رفع این خطا، لطفاً یک صفت را روی این نوع پیاده‌سازی کنید یا آن را در یک ساختار بپیچید. مثال:

    // we create a trait here
trait LiveLongAndProsper {
    fn get_state(&self) -> String;
}

// and now you can implement it on T
impl<T> LiveLongAndProsper for T {
    fn get_state(&self) -> String {
        "He's dead, Jim!".to_owned()
    }
}

    یا می‌توانید یک newtype بسازید. newtype یک ساختار چندتایی (tuple-struct) است که نوع دیگری را در خود می‌پیچد. برای مثال، در struct NewType(Foo) نوع NewType یک newtype روی Foo است. مثال:

    struct TypeWrapper<T>(T);

impl<T> TypeWrapper<T> {
    fn get_state(&self) -> String {
        "Fascinating!".to_owned()
    }
}
