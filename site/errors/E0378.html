    صفت DispatchFromDyn روی چیزی پیاده‌سازی شده است که اشاره‌گر یا یک پوشش newtype پیرامون یک اشاره‌گر نیست.

    نمونه کد خطادار:

    #![feature(dispatch_from_dyn)]
use std::ops::DispatchFromDyn;

struct WrapperExtraField<T> {
    ptr: T,
    extra_stuff: i32,
}

impl<T, U> DispatchFromDyn<WrapperExtraField<U>> for WrapperExtraField<T>
where
    T: DispatchFromDyn<U>,
{}

    صفت DispatchFromDyn در حال حاضر فقط برای انواع اشاره‌گر داخلی و ساختارهایی قابل پیاده‌سازی است که پوشش newtype پیرامون آن‌ها هستند؛ یعنی ساختار باید فقط یک فیلد داشته باشد (به‌جز PhantomData) و آن فیلد خودش باید DispatchFromDyn را پیاده‌سازی کند.

    #![feature(dispatch_from_dyn, unsize)]
use std::{
    marker::Unsize,
    ops::DispatchFromDyn,
};

struct Ptr<T: ?Sized>(*const T);

impl<T: ?Sized, U: ?Sized> DispatchFromDyn<Ptr<U>> for Ptr<T>
where
    T: Unsize<U>,
{}

    مثال دیگر:

    #![feature(dispatch_from_dyn)]
use std::{
    ops::DispatchFromDyn,
    marker::PhantomData,
};

struct Wrapper<T> {
    ptr: T,
    _phantom: PhantomData<()>,
}

impl<T, U> DispatchFromDyn<Wrapper<U>> for Wrapper<T>
where
    T: DispatchFromDyn<U>,
{}
