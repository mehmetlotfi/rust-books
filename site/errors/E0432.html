    یک واردسازی (import) قابل تشخیص (resolve) نبود.

    نمونه کد خطادار:

    use something::Foo; // error: unresolved import `something::Foo`.

    در Rust 2015، مسیرها در دستورهای use نسبت به ریشه crate هستند. برای وارد کردن آیتم‌ها نسبت به ماژول فعلی و ماژول والد، به ترتیب از پیشوندهای self:: و super:: استفاده کنید.

    در Rust 2018 و بعد از آن، مسیرها در دستورهای use نسبت به ماژول فعلی هستند، مگر اینکه با نام یک crate یا با crate:: به‌صورت لفظی شروع شوند؛ در آن صورت از ریشه crate آغاز می‌شوند. مانند کد Rust 2015، پیشوندهای self:: و super:: به ترتیب به ماژول فعلی و ماژول والد اشاره می‌کنند.

    همچنین بررسی کنید که نام واردسازی را اشتباه ننوشته باشید و آن آیتم در ماژولی که از آن وارد می‌کنید وجود داشته باشد. مثال:

    use self::something::Foo; // Ok.

mod something {
    pub struct Foo;
}
# fn main() {}

    اگر سعی کرده‌اید از یک ماژول در یک crate خارجی استفاده کنید و از Rust 2015 بهره می‌برید، ممکن است اعلان extern crate را (که معمولاً در ریشه crate قرار می‌گیرد) فراموش کرده باشید:

    extern crate core; // Required to use the `core` crate in Rust 2015.

use core::any;
# fn main() {}

    از Rust 2018 به بعد، اعلان extern crate لازم نیست و می‌توانید به‌جای آن مستقیماً از use استفاده کنید:

    use core::any; // No extern crate required in Rust 2018.
# fn main() {}
