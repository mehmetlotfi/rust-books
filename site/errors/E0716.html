راهنمای خطاهای کامپایلرCompiler Error Index

    یک مقدار موقت (temporary) در حالی drop می‌شود که یک قرض هنوز در حال استفاده‌ی فعال است.

    نمونه کد خطادار:

    fn foo() -> i32 { 22 }
fn bar(x: &i32) -> &i32 { x }
let p = bar(&foo());
         // ------ creates a temporary
let q = *p;

    در اینجا عبارت &foo() عبارت foo() را قرض می‌گیرد. از آنجا که foo() فراخوانی یک تابع است و نام یک متغیر نیست، این کار یک مقدار موقت ایجاد می‌کند – آن مقدار موقت مقدار بازگشتی foo() را ذخیره می‌کند تا بتوان آن را قرض گرفت. می‌توانید تصور کنید که let p = bar(&foo()); معادل کد زیر است که از یک متغیر موقت صریح استفاده می‌کند.

    نمونه کد خطادار:

    # fn foo() -> i32 { 22 }
# fn bar(x: &i32) -> &i32 { x }
let p = {
  let tmp = foo(); // the temporary
  bar(&tmp) // error: `tmp` does not live long enough
}; // <-- tmp is freed as we exit this block
let q = p;

    هر زمان که یک مقدار موقت ایجاد می‌شود، طبق قواعد ثابتی به‌طور خودکار drop (آزاد) می‌شود. معمولاً مقدار موقت در پایان دستور دربرگیرنده drop می‌شود – در این مورد، پس از let p. این موضوع در مثال بالا با نشان دادن اینکه tmp هنگام خروج از بلوک آزاد می‌شود، توضیح داده شده است.

    برای رفع این مشکل باید یک متغیر محلی برای ذخیره‌ی مقدار بسازید، نه اینکه به یک مقدار موقت تکیه کنید. برای مثال، می‌توانید برنامه‌ی اصلی را به صورت زیر تغییر دهید:

    fn foo() -> i32 { 22 }
fn bar(x: &i32) -> &i32 { x }
let value = foo(); // dropped at the end of the enclosing block
let p = bar(&value);
let q = *p;

    با معرفی let value صریح، فضایی تخصیص می‌دهیم که تا پایان بلوک دربرگیرنده (زمانی که value از محدوده خارج می‌شود) باقی می‌ماند. وقتی &value را قرض می‌گیریم، یک متغیر محلی را قرض می‌گیریم که از قبل وجود دارد و بنابراین هیچ مقدار موقتی ایجاد نمی‌شود.

    مقادیر موقت همیشه در پایان دستور دربرگیرنده drop نمی‌شوند. در موارد ساده‌ای که عبارت & بلافاصله در یک متغیر ذخیره می‌شود، کامپایلر به‌طور خودکار طول عمر مقدار موقت را تا پایان بلوک دربرگیرنده تمدید می‌کند. بنابراین راه دیگر برای رفع برنامه‌ی اصلی این است که let tmp = &foo() بنویسید و نه let tmp = foo():

    fn foo() -> i32 { 22 }
fn bar(x: &i32) -> &i32 { x }
let value = &foo();
let p = bar(value);
let q = *p;

    در اینجا همچنان foo() را قرض می‌گیریم، اما چون قرض مستقیماً به یک متغیر تخصیص داده می‌شود، مقدار موقت تا پایان بلوک دربرگیرنده drop نخواهد شد. قواعد مشابهی زمانی اعمال می‌شود که مقادیر موقت در ساختارهای تجمیعی مانند tuple یا ساختار ذخیره می‌شوند:

    // Here, two temporaries are created, but
// as they are stored directly into `value`,
// they are not dropped until the end of the
// enclosing block.
fn foo() -> i32 { 22 }
let value = (&foo(), &foo());
