    traitهای تابع داخلی نسبت به یک چندتایی (tuple) از آرگومان‌های تابع جنریک هستند. اگر برای نشان‌دادن trait تابع به‌جای پرانتز (Fn(T) -> U) از نشانه‌گذاری کروشه‌زاویه‌ای (Fn<(T,), Output=U>) استفاده شود، پارامتر نوع باید یک tuple باشد. در غیر این صورت نشانه‌گذاری فراخوانی تابع قابل استفاده نیست و trait توسط closureها پیاده‌سازی نخواهد شد.

    محتمل‌ترین منشأ این خطا استفاده از نشانه‌گذاری کروشه‌زاویه‌ای بدون پیچیدن نوع آرگومان تابع در یک tuple است، برای مثال:

    #![feature(unboxed_closures)]

fn foo<F: Fn<i32>>(f: F) -> F::Output { f(3) }

    می‌توان آن را با اصلاح قید trait به این شکل رفع کرد:

    #![feature(unboxed_closures)]

fn foo<F: Fn<(i32,)>>(f: F) -> F::Output { f(3) }

    توجه کنید که (T,) همیشه نوع یک tuple تک‌عضوی را نشان می‌دهد که شامل عنصری از نوع T است. ویرگول برای رفع ابهام نحوی (syntactic) لازم است.
