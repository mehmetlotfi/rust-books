راهنمای خطاهای کامپایلرCompiler Error Index

    یک توضیح مستندات (documentation comment) پیدا شد که هیچ چیزی را مستند نمی‌کند.

    نمونه کد خطادار:

    fn main() {
    // The following doc comment will fail:
    /// This is a useless doc comment!
}

    توضیحات مستندات باید بلافاصله پیش از آیتم‌هایی مانند توابع، نوع‌ها، ماژول‌ها و غیره بیایند. مثال‌ها:

    /// I'm documenting the following struct:
struct Foo;

/// I'm documenting the following function:
fn foo() {}
