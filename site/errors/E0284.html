راهنمای خطاهای کامپایلرCompiler Error Index

    این خطا زمانی رخ می‌دهد که کامپایلر نتواند نوع بازگشتی تابع یا متدی را که نسبت به نوع بازگشتی جنریک است، بدون ابهام استنتاج کند؛ مانند متد collect برای Iteratorها.

    برای مثال:

    fn main() {
    let n: u32 = 1;
    let mut d: u64 = 2;
    d = d + n.into();
}

    در اینجا جمعی از d و n.into() داریم. بنابراین n.into() می‌تواند هر نوع T را برگرداند که u64: Add<T> برقرار باشد. از سوی دیگر، متد into می‌تواند هر نوعی را برگرداند که u32: Into<T> برای آن برقرار باشد.

    نویسنده این کد احتمالاً می‌خواهد into() یک u64 برگرداند، اما کامپایلر نمی‌تواند مطمئن باشد که نوع دیگری مانند T وجود ندارد که هم u32: Into<T> و هم u64: Add<T> برای آن برقرار باشد.

    برای رفع این خطا، برای عبارت میانی از یک نوع مشخص استفاده کنید:

    fn main() {
    let n: u32 = 1;
    let mut d: u64 = 2;
    let m: u64 = n.into();
    d = d + m;
}
