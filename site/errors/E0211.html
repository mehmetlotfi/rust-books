راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود.

    شما از تابع یا نوعی استفاده کرده‌اید که با الزامات محل استفاده‌اش سازگار نیست. نمونه کدهای دارای خطا:

    #![feature(intrinsics)]
#![allow(internal_features)]

#[rustc_intrinsic]
unsafe fn unreachable(); // error: intrinsic has wrong type

// or:

fn main() -> i32 { 0 }
// error: main function expects type: `fn() {main}`: expected (), found i32

// or:

let x = 1u8;
match x {
    0u8..=3i8 => (),
    // error: mismatched types in range: expected u8, found i8
    _ => ()
}

// or:

use std::rc::Rc;
struct Foo;

impl Foo {
    fn x(self: Rc<Foo>) {}
    // error: mismatched self type: expected `Foo`: expected struct
    //        `Foo`, found struct `alloc::rc::Rc`
}

    برای نمونه کد اول، تعریف تابع را بررسی کنید. مثال:

    #![feature(intrinsics)]
#![allow(internal_features)]

#[rustc_intrinsic]
unsafe fn unreachable() -> !; // ok!

    مورد دوم کمی خاص است: تابع main همیشه باید این تعریف را داشته باشد:

    fn main();

    این تابع هرگز پارامتر نمی‌گیرد و هرگز نوعی برنمی‌گرداند.

    برای مثال سوم، هنگام استفاده از match، همه الگوها باید همان نوعی را داشته باشند که روی آن match می‌کنید. مثال:

    let x = 1u8;

match x {
    0u8..=3u8 => (), // ok!
    _ => ()
}

    و در نهایت برای مثال آخر، فقط Box<Self>، &Self، Self یا &mut Self به‌عنوان پارامتر صریح self کار می‌کنند. مثال:

    struct Foo;

impl Foo {
    fn x(self: Box<Foo>) {} // ok!
}
