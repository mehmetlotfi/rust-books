راهنمای خطاهای کامپایلرCompiler Error Index

    نوع وابسته (associated type) برای یک شیء صفت مشخص نشده است.

    نمونه کدی که خطا می‌دهد:

    trait Trait {
    type Bar;
}

type Foo = dyn Trait; // error: the value of the associated type `Bar` (from
                      //        the trait `Trait`) must be specified

    شیءهای صفت باید همه‌ی نوع‌های وابسته‌ی خود را مشخص کنند. لطفاً بررسی کنید که همه‌ی نوع‌های وابسته‌ی صفت مشخص شده باشند و صفت درست به کار رفته باشد. مثال:

    trait Trait {
    type Bar;
}

type Foo = dyn Trait<Bar=i32>; // ok!
