راهنمای خطاهای کامپایلرCompiler Error Index

    تلاش برای cast به یک نوع بدون اندازهٔ مشخص (unsized) انجام شده است.

    نمونهٔ کد دارای خطا:

    let x = &[1_usize, 2] as [usize]; // error: cast to unsized type: `&[usize; 2]`
                                  //        as `[usize]`

    در Rust برخی نوع‌ها در زمان کامپایل اندازهٔ مشخصی ندارند. برای مثال، در یک نوع slice مانند [u32] تعداد عناصر در زمان کامپایل مشخص نیست و در نتیجه اندازهٔ کل قابل محاسبه نیست. بنابراین چنین نوع‌هایی را فقط از طریق یک ارجاع (مثلاً &T یا &mut T) یا نوع اشاره‌گر دیگری (مثلاً Box یا Rc) می‌توان کار کرد. به‌جای آن سعی کنید به یک ارجاع cast کنید:

    let x = &[1_usize, 2] as &[usize]; // ok!
