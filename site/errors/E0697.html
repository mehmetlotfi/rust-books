    یک closure به‌عنوان static استفاده شده است.

    نمونه کد خطادار:

    fn main() {
    static || {}; // used as `static`
}

    closureها را نمی‌توان به‌عنوان static استفاده کرد. آن‌ها محیط (environment) را «ذخیره» می‌کنند و به همین دلیل یک closure از نوع static فقط یک محیط static را ذخیره می‌کند که صرفاً از متغیرهایی با طول عمر static تشکیل می‌شود. با توجه به این، بهتر است از یک تابع واقعی استفاده شود. ساده‌ترین راه‌حل حذف کلیدواژه‌ی static است.
