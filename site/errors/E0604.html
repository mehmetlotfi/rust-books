    تلاش شده است نوعی غیر از u8 به char cast شود.

    نمونهٔ کد دارای خطا:

    0u32 as char; // error: only `u8` can be cast as `char`, not `u32`

    char یک Unicode Scalar Value است، یعنی یک مقدار صحیح از 0 تا 0xD7FF و از 0xE000 تا 0x10FFFF. (فاصلهٔ میان این دو بازه برای جفت‌های جانشین (surrogate pairs) است.) فقط u8 همیشه در این بازه‌ها جا می‌گیرد، بنابراین فقط u8 را می‌توان به char cast کرد.

    برای پذیرش مقادیر بزرگ‌تر از char::from_u32 استفاده کنید که معتبر بودن مقدار را بررسی می‌کند.

    assert_eq!(86u8 as char, 'V'); // ok!
assert_eq!(char::from_u32(0x3B1), Some('α')); // ok!
assert_eq!(char::from_u32(0xD800), None); // not a USV.

    برای اطلاعات بیشتر دربارهٔ castها، بخش Type cast را در کتاب مرجع (The Reference Book) ببینید.
