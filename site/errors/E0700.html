    نوع بازگشتی impl Trait پارامترهای طول عمری را capture می‌کند که در خود impl Trait ظاهر نمی‌شوند.

    نمونه کد خطادار:

    use std::cell::Cell;

trait Trait<'a> { }

impl<'a, 'b> Trait<'b> for Cell<&'a u32> { }

fn foo<'x, 'y>(x: Cell<&'x u32>) -> impl Trait<'y>
where 'x: 'y
{
    x
}

    در اینجا تابع foo مقداری از نوع Cell<&'x u32> برمی‌گرداند که به طول عمر 'x ارجاع دارد. اما نوع بازگشتی به‌صورت impl Trait<'y> تعریف شده است – این نشان می‌دهد که foo «نوعی را که Trait<'y> را پیاده‌سازی می‌کند» برمی‌گرداند، اما همچنین نشان می‌دهد که نوع بازگشتی فقط داده‌هایی را capture می‌کند که به طول عمر 'y ارجاع دارند. در این مورد، ما به داده‌ای با طول عمر 'x ارجاع می‌دهیم، پس این تابع خطا دارد.

    برای رفع این مشکل باید از نوع بازگشتی به طول عمر 'x ارجاع دهید. برای مثال، تغییر نوع بازگشتی به impl Trait<'y> + 'x کار می‌کند:

    use std::cell::Cell;

trait Trait<'a> { }

impl<'a,'b> Trait<'b> for Cell<&'a u32> { }

fn foo<'x, 'y>(x: Cell<&'x u32>) -> impl Trait<'y> + 'x
where 'x: 'y
{
    x
}
