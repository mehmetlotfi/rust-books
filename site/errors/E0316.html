راهنمای خطاهای کامپایلرCompiler Error Index

    یک شرط where شامل سور‌گذاری (quantification) تودرتو روی طول عمرها است.

    نمونه کد خطادار:

    trait Tr<'a, 'b> {}

fn foo<T>(t: T)
where
    for<'a> &'a T: for<'b> Tr<'a, 'b>, // error: nested quantification
{
}

    نحو Rust اجازه می‌دهد سورگذاری طول عمر در دو جای شرط‌های where انجام شود: سورگذاری فقط روی کران صفت (مانند Ty: for<'l> Trait<'l>) و سورگذاری روی کل شرط (مانند for<'l> &'l Ty: Trait<'l>). استفاده از هر دو در یک شرط به سورگذاری تودرتوی طول عمر منجر می‌شود که پشتیبانی نمی‌شود.

    مثال زیر کامپایل می‌شود، زیرا شرطی که سورگذاری تودرتو داشت طوری بازنویسی شده که فقط از یک for<> استفاده کند:

    trait Tr<'a, 'b> {}

fn foo<T>(t: T)
where
    for<'a, 'b> &'a T: Tr<'a, 'b>, // ok
{
}
