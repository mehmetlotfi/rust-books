    نوعی که تبدیل (coerce) می‌شود، بیشتر از مقداری که به آن تبدیل می‌شود عمر نمی‌کند.

    نمونه کد دارای خطا:

    #![feature(coerce_unsized)]
#![feature(unsize)]

use std::marker::Unsize;
use std::ops::CoerceUnsized;

// error: lifetime of the source pointer does not outlive lifetime bound of the
//        object type
impl<'a, 'b, T, S> CoerceUnsized<&'a T> for &'b S where S: Unsize<T> {}

    در حین یک coercion، «اشاره‌گر مبدأ» (نوعی که تبدیل می‌شود) بیشتر از «نوع شیء» (مقداری که به آن تبدیل می‌شود) عمر نکرد. در مثال بالا، 'b زیرنوع 'a نیست. این خطا در حال حاضر فقط با صفت ناپایدار CoerceUnsized رخ می‌دهد که امکان پیاده‌سازی coercionهای سفارشی برای انواع بدون اندازه (unsized) پشت یک اشاره‌گر هوشمند را فراهم می‌کند.
