راهنمای خطاهای کامپایلرCompiler Error Index

    چیزی غیر از یک ساختار، variant یا union در جایی استفاده شده است که یکی از آن‌ها انتظار می‌رفت.

    نمونه کد دارای خطا:

    mod mordor {}

let sauron = mordor { x: () }; // error!

enum Jak {
    Daxter { i: isize },
}

let eco = Jak::Daxter { i: 1 };
match eco {
    Jak { i } => {} // error!
}

    در تمام این خطاها، یک نوع مورد انتظار بود. برای مثال، در خطای اول، ما سعی کردیم ماژول mordor را نمونه‌سازی کنیم، که غیرممکن است. اگر می‌خواهید یک نوع درون یک ماژول را نمونه‌سازی کنید، می‌توانید به این صورت عمل کنید:

    mod mordor {
    pub struct TheRing {
        pub x: usize,
    }
}

let sauron = mordor::TheRing { x: 1 }; // ok!

    در خطای دوم، ما سعی کردیم شمارش Jak را مستقیماً الگو قرار دهیم، که ممکن نیست: فقط می‌توانید یکی از variantهای آن را الگو قرار دهید. برای این کار:

    enum Jak {
    Daxter { i: isize },
}

let eco = Jak::Daxter { i: 1 };
match eco {
    Jak::Daxter { i } => {} // ok!
}
