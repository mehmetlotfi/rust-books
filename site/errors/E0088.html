راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: کامپایلر دیگر این کد خطا را صادر نمی‌کند.

    شما آرگومان‌های طول عمر بیش از حد داده‌اید. نمونه کد دارای خطا:

    fn f() {}

fn main() {
    f::<'static>() // error: wrong number of lifetime arguments:
                   //        expected 0, found 1
}

    لطفاً بررسی کنید که تعداد درست آرگومان‌های طول عمر را داده‌اید. مثال:

    fn f() {}

fn main() {
    f() // ok!
}

    همچنین مهم است بدانید که کامپایلر Rust معمولاً می‌تواند طول عمر را خودش تشخیص دهد. مثال:

    struct Foo {
    value: String
}

impl Foo {
    // it can be written like this
    fn get_value<'a>(&'a self) -> &'a str { &self.value }
    // but the compiler works fine with this too:
    fn without_lifetime(&self) -> &str { &self.value }
}

fn main() {
    let f = Foo { value: "hello".to_owned() };

    println!("{}", f.get_value());
    println!("{}", f.without_lifetime());
}
