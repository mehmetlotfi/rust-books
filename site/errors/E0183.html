راهنمای خطاهای کامپایلرCompiler Error Index

    پیاده‌سازی دستی یک صفت از خانواده‌ی Fn*.

    نمونه کدی که خطا می‌دهد:

    struct MyClosure {
    foo: i32
}

impl FnOnce<()> for MyClosure {  // error
    type Output = ();
    extern "rust-call" fn call_once(self, args: ()) -> Self::Output {
        println!("{}", self.foo);
    }
}

    پیاده‌سازی دستی Fn، FnMut یا FnOnce ناپایدار (unstable) است و به #![feature(fn_traits, unboxed_closures)] نیاز دارد.

    #![feature(fn_traits, unboxed_closures)]

struct MyClosure {
    foo: i32
}

impl FnOnce<()> for MyClosure {  // ok!
    type Output = ();
    extern "rust-call" fn call_once(self, args: ()) -> Self::Output {
        println!("{}", self.foo);
    }
}

    آرگومان‌ها باید یک چندتایی (tuple) باشند که فهرست آرگومان‌ها را نشان می‌دهد. برای اطلاعات بیشتر، issue پیگیری را ببینید:
