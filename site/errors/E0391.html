    یک چرخه وابستگی نوع (type dependency cycle) پیش آمده است.

    نمونه کد خطادار:

    trait FirstTrait : SecondTrait {

}

trait SecondTrait : FirstTrait {

}

    مثال بالا شامل یک وابستگی دایره‌ای بین دو صفت است: FirstTrait به SecondTrait وابسته است که خودش به FirstTrait وابسته است.

    برای اطلاعات بیشتر، https://rustc-dev-guide.rust-lang.org/overview.html#queries و https://rustc-dev-guide.rust-lang.org/query.html را ببینید.
