راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود

    یک آرگومان ناشناخته به attribute با نام instruction_set داده شده است.

    مثال کدی که خطا می‌دهد:

    #![feature(isa_attribute)]

#[instruction_set(intel::x64)] // error: invalid argument
pub fn something() {}
fn main() {}

    attribute با نام instruction_set در حال حاضر فقط از دو آرگومان پشتیبانی می‌کند:

    • arm::a32
    • arm::t32

    هر آرگومان دیگری که به attribute با نام instruction_set داده شود این خطا را برمی‌گرداند. مثال:

    #![feature(isa_attribute)]

#[cfg_attr(target_arch="arm", instruction_set(arm::a32))] // ok!
pub fn something() {}
fn main() {}

    برای اطلاعات بیشتر، بخش attribute با نام instruction_set در Reference را ببینید.
