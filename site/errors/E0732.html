راهنمای خطاهای کامپایلرCompiler Error Index

    یک enum دارای discriminant باید #[repr(inttype)] را مشخص کند.

    نمونه کد خطادار:

    enum Enum { // error!
    Unit = 1,
    Tuple() = 2,
    Struct{} = 3,
}
# fn main() {}

    اگر یک enum گونه‌ای غیر واحد (non-unit) با discriminant داشته باشد، یا هم گونه‌های واحد (unit) با discriminant و هم گونه‌های غیر واحد داشته باشد، باید #[repr(inttype)] برای آن تعیین شود. این محدودیت تضمین می‌کند که راهی دقیق و مشخص برای استخراج discriminant یک گونه از روی یک مقدار وجود دارد؛ برای مثال:

    #[repr(u8)]
enum Enum {
    Unit = 3,
    Tuple(u16) = 2,
    Struct {
        a: u8,
        b: u16,
    } = 1,
}

fn discriminant(v : &Enum) -> u8 {
    unsafe { *(v as *const Enum as *const u8) }
}

fn main() {
    assert_eq!(3, discriminant(&Enum::Unit));
    assert_eq!(2, discriminant(&Enum::Tuple(5)));
    assert_eq!(1, discriminant(&Enum::Struct{a: 7, b: 11}));
}
