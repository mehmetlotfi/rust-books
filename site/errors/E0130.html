راهنمای خطاهای کامپایلرCompiler Error Index

    یک الگو به‌عنوان آرگومان در اعلان یک تابع خارجی (foreign function) تعریف شده است.

    نمونهٔ کد خطادار:

    extern "C" {
    fn foo((a, b): (u32, u32)); // error: patterns aren't allowed in foreign
                                //        function declarations
}

    برای رفع این خطا، آرگومان الگو را با یک آرگومان معمولی جایگزین کنید. مثال:

    struct SomeStruct {
    a: u32,
    b: u32,
}

extern "C" {
    fn foo(s: SomeStruct); // ok!
}

    یا:

    extern "C" {
    fn foo(a: (u32, u32)); // ok!
}
