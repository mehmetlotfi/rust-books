راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود.

    این خطا نشان می‌دهد که شاخهٔ عبارتِ متناظر با الگوی مشخص‌شده هرگز اجرا نخواهد شد، زیرا برای تمام مقادیر ممکنِ عبارتی که با آن تطبیق انجام می‌شود، یکی از الگوهای قبلی تطبیق می‌یابد.

    این یعنی شاید برخی از الگوهای قبلی بیش از حد کلی هستند، این الگو بیش از حد خاص است یا ترتیب نادرست است.

    برای مثال، بلوک match زیر شاخه‌های بیش از حد دارد:

    match Some(0) {
    Some(bar) => {/* ... */}
    x => {/* ... */} // This handles the `None` case
    _ => {/* ... */} // All possible cases have already been handled
}

    در بلوک‌های match الگوها به ترتیب تطبیق داده می‌شوند؛ بنابراین، برای مثال، قرار دادن یک شاخهٔ wildcard بالاتر از یک شاخهٔ خاص‌تر باعث بی‌اثر شدن شاخهٔ دوم می‌شود.

    از درستی ترتیب شاخه‌های match اطمینان حاصل کنید و شاخه‌های زائد را حذف کنید.
