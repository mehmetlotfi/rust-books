راهنمای خطاهای کامپایلرCompiler Error Index

    یک متد روی یک نوع عددی مبهم فراخوانی شده است.

    نمونه کد خطادار:

    2.0.neg(); // error!

    این خطا نشان می‌دهد که مقدار عددیِ مورد نظر برای متد وجود دارد، اما نوع مقدار عددی یا اتصال (binding) قابل تشخیص نبوده است.

    این خطا روی لیترال‌های عددی و روی اتصال‌های عددی‌ای رخ می‌دهد که نوع مشخص و مشخصی ندارند:

    let x = 2.0;
x.neg();  // same error as above

    به همین دلیل باید برای لیترال یا اتصال عددی یک نوع مشخص کنید:

    use std::ops::Neg;

let _ = 2.0_f32.neg(); // ok!
let x: f32 = 2.0;
let _ = x.neg(); // ok!
let _ = (2.0 as f32).neg(); // ok!
