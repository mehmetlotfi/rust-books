راهنمای خطاهای کامپایلرCompiler Error Index

    تلاش شده است به یک مقدار قرض‌گرفته‌شده مقدار جدید انتساب داده شود.

    نمونه کد خطادار:

    struct FancyNum {
    num: u8,
}

let mut fancy_num = FancyNum { num: 5 };
let fancy_ref = &fancy_num;
fancy_num = FancyNum { num: 6 };
// error: cannot assign to `fancy_num` because it is borrowed

println!("Num: {}, Ref: {}", fancy_num.num, fancy_ref.num);

    چون fancy_ref هنوز ارجاعی به fancy_num نگه می‌دارد، نمی‌توان مقدار جدیدی به fancy_num انتساب داد، زیرا این کار ارجاع را باطل می‌کند.

    به‌عنوان راه دیگر، می‌توانیم مقدار fancy_num را به یک fancy_num دوم منتقل کنیم:

    struct FancyNum {
    num: u8,
}

let mut fancy_num = FancyNum { num: 5 };
let moved_num = fancy_num;
fancy_num = FancyNum { num: 6 };

println!("Num: {}, Moved num: {}", fancy_num.num, moved_num.num);

    اگر مقدار باید قرض گرفته شود، سعی کنید طول عمر قرض را با یک بلوک محدود کنید:

    struct FancyNum {
    num: u8,
}

let mut fancy_num = FancyNum { num: 5 };

{
    let fancy_ref = &fancy_num;
    println!("Ref: {}", fancy_ref.num);
}

// Works because `fancy_ref` is no longer in scope
fancy_num = FancyNum { num: 6 };
println!("Num: {}", fancy_num.num);

    یا با انتقال ارجاع به داخل یک تابع:

    struct FancyNum {
    num: u8,
}

fn print_fancy_ref(fancy_ref: &FancyNum){
    println!("Ref: {}", fancy_ref.num);
}

let mut fancy_num = FancyNum { num: 5 };

print_fancy_ref(&fancy_num);

// Works because function borrow has ended
fancy_num = FancyNum { num: 6 };
println!("Num: {}", fancy_num.num);
