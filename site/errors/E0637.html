راهنمای خطاهای کامپایلرCompiler Error Index

    نام طول عمر '_ یا &T بدون نام صریح طول عمر در جایی غیرمجاز به کار رفته است.

    نمونهٔ کد خطادار:

    fn underscore_lifetime<'_>(str1: &'_ str, str2: &'_ str) -> &'_ str {
                     //^^ `'_` is a reserved lifetime name
    if str1.len() > str2.len() {
        str1
    } else {
        str2
    }
}

fn without_explicit_lifetime<T>()
where
    T: Iterator<Item = &u32>,
                     //^ `&` without an explicit lifetime name
{
}

fn without_hrtb<T>()
where
    T: Into<&u32>,
          //^ `&` without an explicit lifetime name
{
}

    نخست اینکه '_ را نمی‌توان در برخی جاها به‌عنوان شناسهٔ طول عمر به کار برد، زیرا برای طول عمر ناشناس (anonymous) رزرو شده است. دوم اینکه &T بدون نام صریح طول عمر نیز در برخی جاها مجاز نیست. برای رفع این مشکلات از یک حرف کوچک مانند 'a یا دنباله‌ای از حروف کوچک مانند 'foo استفاده کنید. برای اطلاعات بیشتر دربارهٔ شناسهٔ طول عمر به کتاب مراجعه کنید. برای اطلاعات بیشتر دربارهٔ استفاده از طول عمر ناشناس در Rust 2018 به نوشتهٔ وبلاگ Rust 2018 مراجعه کنید.

    نمونهٔ اصلاح‌شده:

    fn underscore_lifetime<'a>(str1: &'a str, str2: &'a str) -> &'a str {
    if str1.len() > str2.len() {
        str1
    } else {
        str2
    }
}

fn without_explicit_lifetime<'a, T>()
where
    T: Iterator<Item = &'a u32>,
{
}

fn without_hrtb<T>()
where
    T: for<'foo> Into<&'foo u32>,
{
}
