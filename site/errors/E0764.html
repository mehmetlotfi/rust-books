راهنمای خطاهای کامپایلرCompiler Error Index

    یک ارجاع تغییرپذیر در یک ثابت (constant) استفاده شده است.

    مثال کدی که خطا می‌دهد:

    fn main() {
    const OH_NO: &'static mut usize = &mut 1; // error!
}

    ارجاع‌های تغییرپذیر (&mut) فقط در توابع ثابت (constant functions) قابل استفاده‌اند، نه در static یا ثابت‌ها. این محدودیت برای جلوگیری از ساخت ثابت‌هایی وجود دارد که در مقدار نهایی‌شان یک ارجاع تغییرپذیر دارند. اگر ثابتی از نوع &mut i32 داشتید، می‌توانستید مقدار را از طریق آن ارجاع تغییر دهید و در نتیجه ثابت عملاً تغییرپذیر می‌شد.

    هرچند ممکن است در آینده طرحی ظریف‌تر وجود داشته باشد که ارجاع‌های تغییرپذیر را در صورتی که به مقدار نهایی «نشت» نکنند مجاز کند، فعلاً رویکردی محافظه‌کارانه‌تر انتخاب شده است. const fnها این مشکل را ندارند، زیرا borrow checker مانع از بازگرداندن ارجاع‌های تغییرپذیر جدید از const fn می‌شود.

    به یاد داشته باشید: نمی‌توانید درون یک ثابت یا static فراخوانی تابع انجام دهید. با این حال می‌توانید بی‌مشکل از آن در توابع ثابت استفاده کنید:

    const fn foo(x: usize) -> usize {
    let mut y = 1;
    let z = &mut y;
    *z += x;
    y
}

fn main() {
    const FOO: usize = foo(10); // ok!
}
