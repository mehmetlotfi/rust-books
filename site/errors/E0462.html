راهنمای خطاهای کامپایلرCompiler Error Index

    به‌جای rlib یا dylib، یک staticlib به نام .. یافت شد.

    این دو فایل را در نظر بگیرید:

    a.rs

    #![crate_type = "staticlib"]

fn foo() {}

    main.rs

    extern crate a;

fn main() {
    a::foo();
}

    crate a به‌صورت staticlib کامپایل شده است. staticlib کتابخانه‌ای وابسته به سیستم است که فقط برای پیوند با برنامه‌های غیر Rust (برنامه‌های C) در نظر گرفته شده است. توجه کنید که staticlibها همه وابستگی‌های بالادستی (core، std، سایر وابستگی‌های کاربر و غیره) را در خود دارند و به همین دلیل به‌طور قابل‌توجهی از dylibها بزرگ‌ترند: staticlib را برای پیوند با برنامه‌های C ترجیح دهید. درباره crate_typeهای مختلف در این بخش از Reference بیشتر بخوانید.

    این خطا را می‌توان به این روش‌ها رفع کرد:

    • استفاده از Cargo، مدیر بسته‌های Rust، که این مشکل را به‌طور خودکار برطرف می‌کند.
    • کامپایل مجدد crate به‌صورت rlib یا dylib؛ قالب‌هایی که برای پیوند‌دهی در Rust مناسب‌اند.
