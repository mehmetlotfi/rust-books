راهنمای خطاهای کامپایلرCompiler Error Index

    شما سعی کرده‌اید به نوعی که به آرگومان جنریک نیازی ندارد، یک آرگومان جنریک بدهید.

    نمونه کدی که خطا می‌دهد:

    type X = u32<i32>; // error: type arguments are not allowed for this type
type Y = bool<'static>; // error: lifetime parameters are not allowed on
                        //        this type

    بررسی کنید که آرگومان درست را به کار برده باشید و تعریف نیز درست باشد.

    مثال:

    type X = u32; // ok!
type Y = bool; // ok!

    توجه کنید که آرگومان‌های جنریک برای سازنده‌های واریانت شمارش (enum) بعد از واریانت می‌آیند، نه بعد از خود شمارش. برای مثال، باید Option::None::<u32> را بنویسید، نه Option::<u32>::None.
