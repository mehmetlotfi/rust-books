راهنمای خطاهای کامپایلرCompiler Error Index

    سازنده یک ساختار (struct) که فیلدهای خصوصی دارد فراخوانی شده است.

    نمونه کد دارای خطا:

    mod bar {
    pub struct Foo {
        pub a: isize,
        b: isize,
    }
}

let f = bar::Foo{ a: 0, b: 0 }; // error: field `b` of struct `bar::Foo`
                                //        is private

    برای رفع این خطا، مطمئن شوید که همه فیلدهای ساختار عمومی هستند، یا تابعی برای ساخت آسان نمونه پیاده‌سازی کنید. مثال‌ها:

    mod bar {
    pub struct Foo {
        pub a: isize,
        pub b: isize, // we set `b` field public
    }
}

let f = bar::Foo{ a: 0, b: 0 }; // ok!

    یا:

    mod bar {
    pub struct Foo {
        pub a: isize,
        b: isize, // still private
    }

    impl Foo {
        pub fn new() -> Foo { // we create a method to instantiate `Foo`
            Foo { a: 0, b: 0 }
        }
    }
}

let f = bar::Foo::new(); // ok!
