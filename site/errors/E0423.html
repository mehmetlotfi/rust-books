راهنمای خطاهای کامپایلرCompiler Error Index

    شناسه‌ای مانند نام یک تابع به کار رفته یا مقداری انتظار می‌رفته و شناسه وجود دارد، اما به فضای نام (namespace) دیگری تعلق دارد.

    نمونه کد خطادار:

    struct Foo { a: bool };

let f = Foo();
// error: expected function, tuple struct or tuple variant, found `Foo`
// `Foo` is a struct name, but this expression uses it like a function name

    لطفاً بررسی کنید که نام چیزی را که واقعاً می‌خواستید در اینجا استفاده کنید اشتباه ننوشته باشید. مثال:

    fn Foo() -> u32 { 0 }

let f = Foo(); // ok!

    فراموش کردن ! در انتهای فراخوانی ماکرو رایج است و این هم همین خطا را ایجاد می‌کند:

    println("");
// error: expected function, tuple struct or tuple variant,
// found macro `println`
// did you mean `println!(...)`? (notice the trailing `!`)

    حالت دیگری که این خطا صادر می‌شود زمانی است که مقداری انتظار می‌رود، اما چیز دیگری یافت می‌شود:

    pub mod a {
    pub const I: i32 = 1;
}

fn h1() -> i32 {
    a.I
    //~^ ERROR expected value, found module `a`
    // did you mean `a::I`?
}

    نوع‌های شمارشی (enum) که به‌عنوان مقدار استفاده می‌شوند

    نوع‌های شمارش خودشان نوع هستند و نمی‌توان آن‌ها را مستقیماً به‌عنوان مقدار به کار برد.

    fn main(){
    let x = Option::<i32>;
    //~^ ERROR expected value,found enum `Option`
}
