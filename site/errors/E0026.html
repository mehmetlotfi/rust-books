راهنمای خطاهای کامپایلرCompiler Error Index

    یک الگوی ساختار سعی کرده است فیلدی را از یک ساختار استخراج کند که وجود ندارد.

    نمونه کد نادرست:

    struct Thing {
    x: u32,
    y: u32,
}

let thing = Thing { x: 0, y: 0 };

match thing {
    Thing { x, z } => {} // error: `Thing::z` field doesn't exist
}

    اگر از الگوهای فیلد کوتاه‌شده استفاده می‌کنید اما می‌خواهید با نام دیگری به فیلد ساختار اشاره کنید، باید آن را به‌صراحت تغییر نام دهید. فیلدهای ساختار با نامی که پیش از دونقطه : می‌آید شناسایی می‌شوند؛ بنابراین الگوهای ساختار باید شبیه تعریف نوع ساختاری باشند که با آن تطبیق داده می‌شود.

    struct Thing {
    x: u32,
    y: u32,
}

let thing = Thing { x: 0, y: 0 };

match thing {
    Thing { x, y: z } => {} // we renamed `y` to `z`
}
