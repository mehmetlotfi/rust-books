راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود.

    یک شیء صفت (trait object) طول عمر مشخصی مانند '1 دارد، اما به شکلی استفاده شده که لازم است طول عمر 'static داشته باشد.

    مثال کدی که خطا می‌دهد:

    trait BooleanLike {}
trait Person {}

impl BooleanLike for bool {}

impl dyn Person {
    fn is_cool(&self) -> bool {
        // hey you, you're pretty cool
        true
    }
}

fn get_is_cool<'p>(person: &'p dyn Person) -> impl BooleanLike {
    // error: `person` has an anonymous lifetime `'p` but calling
    //        `print_cool_fn` introduces an implicit `'static` lifetime
    //        requirement
    person.is_cool()
}

    شیء صفت person در تابع get_is_cool، با اینکه پشت یک ارجاع با طول عمر 'p قرار دارد، طول عمر ضمنی مخصوص به خود را نیز دارد، یعنی '2.

    طول عمر '2 نمایانگر داده‌ای است که شیء صفت ممکن است در درون خود نگه دارد، برای مثال:

    trait MyTrait {}

struct MyStruct<'a>(&'a i32);

impl<'a> MyTrait for MyStruct<'a> {}

    در این سناریو، اگر شیء صفتی از نوع dyn MyTrait + '2 از روی MyStruct<'a> ساخته شود، 'a باید دست‌کم به اندازه '2 زنده بماند. این امر تضمین می‌کند که داده درونی شیء صفت از هر متد صفتی به‌صورت ایمن قابل دسترسی باشد. این قاعده برای هر طول عمری که هر ساختاری که به شیء صفت تبدیل می‌شود داشته باشد نیز برقرار است.

    در پیاده‌سازی برای dyn Person، طول عمر '2 که نمایانگر داده درونی است حذف شده بود، یعنی کامپایلر طول عمر 'static را استنباط کرده است. در نتیجه، کامپایلر متد is_cool در این پیاده‌سازی را به شکل زیر استنباط می‌کند:

    # trait Person {}
#
# impl dyn Person {
fn is_cool<'a>(self: &'a (dyn Person + 'static)) -> bool {unimplemented!()}
# }

    در حالی که تابع get_is_cool به این شکل استنباط می‌شود:

    # trait Person {}
# trait BooleanLike {}
#
fn get_is_cool<'p, R: BooleanLike>(person: &'p (dyn Person + 'p)) -> R {
    unimplemented!()
}

    و این ما را به هسته مشکل می‌رساند؛ انتساب نوع &'_ (dyn Person + '_) به نوع &'_ (dyn Person + 'static) ناممکن است.

    رفع آن به سادگی جنریک کردن روی طول عمر '2 است تا کامپایلر آن را 'static استنباط نکند:

    # trait Person {}
#
impl<'d> dyn Person + 'd {/* ... */}

// This works too, and is more elegant:
//impl dyn Person + '_ {/* ... */}

    برای اطلاعات بیشتر درباره طول عمر شیءهای صفت، مرجع Rust درباره کران‌های طول عمر شیء صفت را ببینید.
