    متغیرهای static که در بلوک‌های خارجی دارای attribute با نام #[linkage] هستند، باید یکی از انواع زیر را داشته باشند که در C معادل یک اشاره‌گر تهی‌پذیر (nullable) هستند:

    • *mut T یا *const T، که در آن T می‌تواند هر نوعی باشد.

    • یک نوع شمارش بدون attribute با نام #[repr] و با دو حالت (variant)، که یکی از حالت‌ها هیچ فیلدی ندارد و دیگری دقیقاً یک فیلد از یکی از انواع غیرتهی‌پذیر زیر دارد:

      • نوع ارجاع
      • نوع اشاره‌گر تابع

      حالت‌ها می‌توانند به هر ترتیبی ظاهر شوند.

    برای مثال، اعلان زیر نامعتبر است:

    #![feature(linkage)]

extern "C" {
    #[linkage = "extern_weak"]
    static foo: i8;
}

    اعلان‌های زیر معتبر هستند:

    #![feature(linkage)]

extern "C" {
    #[linkage = "extern_weak"]
    static foo: Option<unsafe extern "C" fn()>;

    #[linkage = "extern_weak"]
    static bar: Option<&'static i8>;

    #[linkage = "extern_weak"]
    static baz: *mut i8;
}
