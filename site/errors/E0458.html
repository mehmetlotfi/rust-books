راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود.

    یک «kind» ناشناخته برای attribute مربوط به link مشخص شده بود.

    نمونه کد دارای خطا:

    #[link(kind = "wonderful_unicorn")] extern "C" {}
// error: unknown kind: `wonderful_unicorn`

    لطفاً یک مقدار «kind» معتبر از میان موارد زیر مشخص کنید:

    • static
    • dylib
    • framework
    • raw-dylib
