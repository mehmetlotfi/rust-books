راهنمای خطاهای کامپایلرCompiler Error Index

    نسخه‌ای احتمالاً جدیدتر از crate .. یافت شد که .. به آن وابسته است.

    این فایل‌های دارای خطا را در نظر بگیرید:

    a1.rs

    #![crate_name = "a"]

pub fn foo<T>() {}

    a2.rs

    #![crate_name = "a"]

pub fn foo<T>() {
    println!("foo<T>()");
}

    b.rs

    #![crate_name = "b"]

extern crate a; // linked with `a1.rs`

pub fn foo() {
    a::foo::<isize>();
}

    main.rs

    extern crate a; // linked with `a2.rs`
extern crate b; // error: found possibly newer version of crate `a` which `b`
                //        depends on

fn main() {}

    گراف وابستگی این برنامه را می‌توان به صورت زیر نمایش داد:

        crate `main`
         |
         +-------------+
         |             |
         |             v
depends: |         crate `b`
 `a` v1  |             |
         |             | depends:
         |             |  `a` v2
         v             |
      crate `a` <------+

    crate main به crate a (نسخه 1) و crate b وابسته است که خود به crate a (نسخه 2) وابسته است؛ این ناهمخوانی نسخه‌ها قابل رفع نیست. این تفاوت نسخه‌ها معمولاً زمانی رخ می‌دهد که یک crate کامپایل و پیوند داده شود، سپس به‌روزرسانی شده و به crate دیگری پیوند بخورد. «نسخه» crate یک SVH (Strict Version Hash) است که به روشی وابسته به پیاده‌سازی محاسبه می‌شود. توجه کنید که این خطا فقط هنگام کامپایل و پیوند‌دهی مستقیم با rustc رخ می‌دهد؛ Cargo وابستگی‌ها را به‌طور خودکار حل می‌کند و از مدیریت وابستگی خود کامپایلر که باعث این مشکل می‌شود استفاده نمی‌کند.

    این خطا را می‌توان به این روش‌ها رفع کرد:

    • استفاده از Cargo، مدیر بسته‌های Rust، که این مشکل را به‌طور خودکار برطرف می‌کند.
    • کامپایل مجدد crate a تا هم crate b و هم main به نسخه‌ای یکسان وابسته باشند.
