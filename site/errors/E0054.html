راهنمای خطاهای کامپایلرCompiler Error Index

    تبدیل (cast) به نوع bool مجاز نیست.

    نمونه کد نادرست:

    let x = 5;

// Not allowed, won't compile
let x_is_nonzero = x as bool;

    اگر می‌خواهید یک نوع عددی را به bool تبدیل کنید، می‌توانید به‌جای آن آن را با صفر مقایسه کنید:

    let x = 5;

// Ok
let x_is_nonzero = x != 0;
