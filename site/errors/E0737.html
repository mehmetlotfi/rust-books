راهنمای خطاهای کامپایلرCompiler Error Index

    #[track_caller] ایجاب می‌کند توابع برای دریافت ضمنی محل فراخوان، ABI از نوع "Rust" داشته باشند. برای جزئیات این محدودیت و محدودیت‌های دیگر RFC 2091 را ببینید.

    نمونه کد خطادار:

    #[track_caller]
extern "C" fn foo() {}
    → E0736E0739 ←
