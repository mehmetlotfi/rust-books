راهنمای خطاهای کامپایلرCompiler Error Index

    تلاش برای دستیابی به یک نوع وابسته انجام شده است، اما نوع مبهم بود.

    نمونه کد دارای خطا:

    trait Trait { type X; }

fn main() {
    let foo: Trait::X;
}

    مشکل اینجاست که می‌خواهیم نوع وابسته X را از Trait بگیریم. متأسفانه نوع X تعریف نشده است، زیرا فقط در پیاده‌سازی‌های صفت مشخص (concrete) می‌شود. نسخه کارای این کد می‌تواند چنین باشد:

    trait Trait { type X; }

struct Struct;
impl Trait for Struct {
    type X = u32;
}

fn main() {
    let foo: <Struct as Trait>::X;
}

    این نحو مشخص می‌کند که نوع وابسته X را از پیاده‌سازی Trait برای Struct می‌خواهیم.

    به‌دلیل محدودیت‌های داخلی پیاده‌سازی فعلی کامپایلر، نمی‌توانیم به‌سادگی از Struct::X استفاده کنیم.
