راهنمای خطاهای کامپایلرCompiler Error Index

    یک impl منفی به‌صورت default impl تعریف شده بود.

    نمونه کد خطادار:

    # #![feature(negative_impls)]
# #![feature(specialization)]
trait MyTrait {
    type Foo;
}

default impl !MyTrait for u32 {} // error!
# fn main() {}

    impl منفی نمی‌تواند default impl باشد. default impl مقادیر پیش‌فرضی برای آیتم‌های درونش فراهم می‌کند تا impl های دیگر از آن‌ها استفاده کنند، در حالی که impl منفی اعلام می‌کند هیچ impl دیگری وجود ندارد. ترکیب این دو معنایی ندارد.
