راهنمای خطاهای کامپایلرCompiler Error Index

    یک meta-item نامعتبر درون یک attribute به کار رفته است.

    نمونه‌ی کد خطادار:

    #![feature(staged_api)]
#![allow(internal_features)]
#![stable(since = "1.0.0", feature = "test")]

#[deprecated(note)] // error!
#[unstable(feature = "deprecated_fn", issue = "123")]
fn deprecated() {}

#[unstable(feature = "unstable_struct", issue)] // error!
struct Unstable;

#[rustc_const_unstable(feature)] // error!
const fn unstable_fn() {}

#[stable(feature = "stable_struct", since)] // error!
struct Stable;

#[rustc_const_stable(feature)] // error!
const fn stable_fn() {}

    برای رفع مثال بالا می‌توانید این‌گونه بنویسید:

    #![feature(staged_api)]
#![allow(internal_features)]
#![stable(since = "1.0.0", feature = "test")]

#[deprecated(since = "1.39.0", note = "reason")] // ok!
#[unstable(feature = "deprecated_fn", issue = "123")]
fn deprecated() {}

#[unstable(feature = "unstable_struct", issue = "123")] // ok!
struct Unstable;

#[rustc_const_unstable(feature = "unstable_fn", issue = "124")] // ok!
const fn unstable_fn() {}

#[stable(feature = "stable_struct", since = "1.39.0")] // ok!
struct Stable;

#[stable(feature = "stable_fn", since = "1.39.0")]
#[rustc_const_stable(feature = "stable_fn", since = "1.39.0")] // ok!
const fn stable_fn() {}

    چند علت برای این خطا وجود دارد؛ ممکن است یک attribute انتظار داشته باشد فهرستی به آن بدهید، اما شما یک جفت name = value داده‌اید:

    // wrong, should be `#[repr(C)]`
#[repr = "C"]
struct Foo {}

    یا یک جفت name = value انتظار داشته، اما شما فهرست داده‌اید:

    // wrong, should be `note = "reason"`
#[deprecated(since = "1.0.0", note("reason"))]
struct Foo {}

    یا کلمه‌ای مشخص انتظار می‌رفته، اما کلمه‌ای غیرمنتظره داده‌اید:

    // should be `always` or `never`
#[inline(maybe_if_you_feel_like_it)]
fn foo() {}
