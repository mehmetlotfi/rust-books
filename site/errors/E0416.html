راهنمای خطاهای کامپایلرCompiler Error Index

    یک شناسه در یک الگو بیش از یک بار مقید شده است.

    نمونه کد خطادار:

    match (1, 2) {
    (x, x) => {} // error: identifier `x` is bound more than once in the
                 //        same pattern
}

    لطفاً بررسی کنید که نام شناسه‌ها را اشتباه ننوشته باشید. مثال:

    match (1, 2) {
    (x, y) => {} // ok!
}

    یا شاید منظور شما یکی کردن آن‌ها بوده است؟ از یک guard استفاده کنید:

    # let (A, B, C) = (1, 2, 3);
match (A, B, C) {
    (x, x2, see) if x == x2 => { /* A and B are equal, do one thing */ }
    (y, z, see) => { /* A and B not equal; do another thing */ }
}
    → E0415E0422 ←
