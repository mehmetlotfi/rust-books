راهنمای خطاهای کامپایلرCompiler Error Index

    این کد خطا نشان‌دهندهٔ ناسازگاری میان طول عمرهای ظاهرشده در امضای تابع (یعنی نوع پارامترها و نوع بازگشتی) و جریان داده‌ای است که در بدنهٔ تابع دیده می‌شود.

    نمونهٔ کد دارای خطا:

    fn foo<'a>(x: &'a i32, y: &i32) -> &'a i32 { // error: explicit lifetime
                                             //        required in the type of
                                             //        `y`
    if x > y { x } else { y }
}

    در کد بالا، تابع داده‌ای را برمی‌گرداند که از x یا y قرض گرفته شده است، اما annotation 'a نشان می‌دهد که فقط از x داده برمی‌گرداند. برای رفع خطا، امضا و بدنه باید با هم سازگار شوند. معمولاً این کار با به‌روزرسانی امضای تابع انجام می‌شود. بنابراین در اینجا نوع y را به &'a i32 تغییر می‌دهیم، به این صورت:

    fn foo<'a>(x: &'a i32, y: &'a i32) -> &'a i32 {
    if x > y { x } else { y }
}

    اکنون امضا نشان می‌دهد که تابع داده‌ای را که از x یا y قرض گرفته شده برمی‌گرداند. به‌عنوان جایگزین، می‌توانید بدنه را طوری تغییر دهید که از y داده‌ای برنگرداند:

    fn foo<'a>(x: &'a i32, y: &i32) -> &'a i32 {
    x
}
