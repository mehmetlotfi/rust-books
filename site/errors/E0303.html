راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود.

    زیرپیوندها (sub-bindings)، مانند ref x @ Some(ref y)، اکنون تحت #![feature(bindings_after_at)] مجاز هستند و بررسی می‌شوند تا اطمینان حاصل شود که ایمنی حافظه رعایت می‌شود.

    در برخی موارد ممکن است زیرپیوندها ایمنی حافظه را نقض کنند. به‌روزرسانی‌های borrow checker در نسخه‌ای آینده از Rust ممکن است این محدودیت را برطرف کنند، اما فعلاً الگوها باید بدون زیرپیوند بازنویسی شوند.

    قبل:

    match Some("hi".to_string()) {
    ref op_string_ref @ Some(s) => {},
    None => {},
}

    بعد:

    match Some("hi".to_string()) {
    Some(ref s) => {
        let op_string_ref = &Some(s);
        // ...
    },
    None => {},
}

    پیوند op_string_ref در هر دو حالت نوع &Option<&String> دارد.
