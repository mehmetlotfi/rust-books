راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود.

    عبارت‌های where باید از پارامترهای نوع جنریک استفاده کنند: در غیر این صورت به کار بردن آن‌ها معنایی ندارد. مثالی که این خطا را ایجاد می‌کند:

    trait Foo {
    fn bar(&self);
}

#[derive(Copy,Clone)]
struct Wrapper<T> {
    Wrapped: T
}

impl Foo for Wrapper<u32> where Wrapper<u32>: Clone {
    fn bar(&self) { }
}

    این استفاده از عبارت where عجیب است؛ کاربرد رایج‌تر چیزی شبیه به این است:

    trait Foo {
    fn bar(&self);
}

#[derive(Copy,Clone)]
struct Wrapper<T> {
    Wrapped: T
}
impl <T> Foo for Wrapper<T> where Wrapper<T>: Clone {
    fn bar(&self) { }
}

    در اینجا می‌گوییم این پیاده‌سازی روی Wrapper فقط وقتی وجود دارد که نوع پیچیده‌شده‌ی T صفت Clone را پیاده‌سازی کرده باشد. عبارت where مهم است، چون برخی نوع‌ها Clone را پیاده‌سازی نمی‌کنند و در نتیجه این متد را دریافت نخواهند کرد.

    اما در مثال خطادار ما، به یک نوع مشخص و واحد ارجاع می‌دهیم. چون به‌طور قطع می‌دانیم Wrapper<u32> صفت Clone را پیاده‌سازی می‌کند، دلیلی ندارد که آن را در یک عبارت where نیز مشخص کنیم.
