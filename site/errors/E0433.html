راهنمای خطاهای کامپایلرCompiler Error Index

    یک crate، ماژول یا نوع اعلام‌نشده به‌کار رفته است.

    نمونه کد خطادار:

    let map = HashMap::new();
// error: failed to resolve: use of undeclared type `HashMap`

    لطفاً بررسی کنید که نام نوع/ماژول را اشتباه ننوشته باشید یا وارد کردن (import) آن را فراموش نکرده باشید:

    use std::collections::HashMap; // HashMap has been imported.
let map: HashMap<u32, u32> = HashMap::new(); // So it can be used!

    اگر انتظار داشتید از نام یک crate استفاده کنید:

    use ferris_wheel::BigO;
// error: failed to resolve: use of undeclared module or unlinked crate

    مطمئن شوید که crate به‌عنوان وابستگی در Cargo.toml اضافه شده است.

    برای استفاده از یک ماژول از crate فعلی، پیشوند crate:: را به مسیر اضافه کنید.
