راهنمای خطاهای کامپایلرCompiler Error Index

    یک طول عمر فقط در اتصال نوع وابسته (associated type) وجود دارد و در نوع‌های ورودی صفت نیامده است.

    نمونه کد خطادار:

    fn bar<F>(t: F)
    // No type can satisfy this requirement, since `'a` does not
    // appear in any of the input types (here, `i32`):
    where F: for<'a> Fn(i32) -> Option<&'a i32>
{
}

fn main() { }

    برای رفع این مشکل، یا طول عمر را در ورودی‌ها به کار ببرید یا از 'static استفاده کنید. مثال:

    fn bar<F, G>(t: F, u: G)
    where F: for<'a> Fn(&'a i32) -> Option<&'a i32>,
          G: Fn(i32) -> Option<&'static i32>,
{
}

fn main() { }

    این خطا شامل استفاده از نوع‌های وابسته‌ای که پارامتر طول عمر دارند نیز می‌شود.

    trait Foo {
    type Assoc<'a>;
}

struct Bar<X, F>
where
    X: Foo,
    F: for<'a> Fn(X::Assoc<'a>) -> &'a i32
{
    x: X,
    f: F
}

    سناریوی اخیر به این دلیل با این خطا مواجه می‌شود که Foo::Assoc<'a> ممکن است توسط نوعی پیاده‌سازی شود که از پارامتر 'a استفاده نمی‌کند؛ بنابراین تضمینی وجود ندارد که X::Assoc<'a> واقعاً از 'a استفاده کند.

    برای رفع این مشکل می‌توانیم یک پارامتر ساختگی (dummy) پاس بدهیم:

    # trait Foo {
#     type Assoc<'a>;
# }
struct Bar<X, F>
where
    X: Foo,
    F: for<'a> Fn(X::Assoc<'a>, /* dummy */ &'a ()) -> &'a i32
{
    x: X,
    f: F
}

    نکته: مثال‌های بالا پیش‌تر (به‌اشتباه) توسط کامپایلر پذیرفته می‌شدند، اما بعدها این رفتار اصلاح شد. برای جزئیات بیشتر مسئله #33685 را ببینید.
