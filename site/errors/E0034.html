راهنمای خطاهای کامپایلرCompiler Error Index

    کامپایلر نمی‌داند کدام متد را فراخوانی کند، چون بیش از یک متد امضای یکسان دارند.

    نمونه کد نادرست:

    struct Test;

trait Trait1 {
    fn foo();
}

trait Trait2 {
    fn foo();
}

impl Trait1 for Test { fn foo() {} }
impl Trait2 for Test { fn foo() {} }

fn main() {
    Test::foo() // error, which foo() to call?
}

    برای پرهیز از این خطا باید فقط یکی از آن‌ها را نگه دارید و بقیه را حذف کنید. پس بیایید مثال خود را اصلاح کنیم:

    struct Test;

trait Trait1 {
    fn foo();
}

impl Trait1 for Test { fn foo() {} }

fn main() {
    Test::foo() // and now that's good!
}

    با این حال، راه‌حل بهتر این است که نوع و trait را به‌صورت کاملاً صریح نام ببرید:

    struct Test;

trait Trait1 {
    fn foo();
}

trait Trait2 {
    fn foo();
}

impl Trait1 for Test { fn foo() {} }
impl Trait2 for Test { fn foo() {} }

fn main() {
    <Test as Trait1>::foo()
}

    یک مثال آخر:

    trait F {
    fn m(&self);
}

trait G {
    fn m(&self);
}

struct X;

impl F for X { fn m(&self) { println!("I am F"); } }
impl G for X { fn m(&self) { println!("I am G"); } }

fn main() {
    let f = X;

    F::m(&f); // it displays "I am F"
    G::m(&f); // it displays "I am G"
}
