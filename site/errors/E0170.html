    یک اتصال الگو (pattern binding) از همان نام یکی از واریانت‌های یک نوع استفاده می‌کند.

    نمونه کدی که خطا می‌دهد:

    # #![deny(warnings)]
enum Method {
    GET,
    POST,
}

fn is_empty(s: Method) -> bool {
    match s {
        GET => true,
        _ => false
    }
}

fn main() {}

    واریانت‌های شمارش به‌طور پیش‌فرض با نام کامل (qualified) به کار می‌روند. برای مثال، با این نوع:

    enum Method {
    GET,
    POST,
}

    شما آن را این‌گونه تطبیق می‌دهید:

    enum Method {
    GET,
    POST,
}

let m = Method::GET;

match m {
    Method::GET => {},
    Method::POST => {},
}

    اگر نام‌ها را کامل ننویسید، کد به‌جای آن متغیرهای تازه‌ای با نام «GET» و «POST» را متصل (bind) می‌کند. این رفتار احتمالاً چیزی نیست که می‌خواهید، به همین دلیل rustc در این حالت هشدار می‌دهد.

    استفاده از نام‌های کامل روش خوبی است و بیشتر کدها با آن به‌خوبی کار می‌کنند. اما اگر نام‌های بدون پیشوند را ترجیح می‌دهید، می‌توانید واریانت‌ها را به دامنه وارد کنید:

    use Method::*;
enum Method { GET, POST }
# fn main() {}

    اگر می‌خواهید دیگران بتوانند واریانت‌ها را مستقیماً از ماژول شما وارد کنند، از pub use استفاده کنید:

    pub use Method::*;
pub enum Method { GET, POST }
# fn main() {}
