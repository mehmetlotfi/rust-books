راهنمای خطاهای کامپایلرCompiler Error Index

    یک مقدار قرض‌گرفته‌شده به بیرون منتقل شده است.

    نمونه کد خطادار:

    use std::cell::RefCell;

struct TheDarkKnight;

impl TheDarkKnight {
    fn nothing_is_true(self) {}
}

fn main() {
    let x = RefCell::new(TheDarkKnight);

    x.borrow().nothing_is_true(); // error: cannot move out of borrowed content
}

    در اینجا متد nothing_is_true مالکیت self را می‌گیرد. اما self را نمی‌توان منتقل کرد، زیرا .borrow() فقط یک &TheDarkKnight فراهم می‌کند که قرضی از محتوای متعلق به RefCell است. برای رفع این خطا سه انتخاب دارید:

    • سعی کنید از انتقال متغیر پرهیز کنید.
    • به‌گونه‌ای مالکیت را بازپس بگیرید.
    • صفت Copy را برای آن نوع پیاده‌سازی کنید.

    این وضعیت می‌تواند هنگام استفاده از نوعی که Fn یا FnMut را پیاده‌سازی می‌کند نیز پیش بیاید، زیرا هیچ‌یک اجازه انتقال از درون خود را نمی‌دهند (این‌ها معمولاً closureهایی را نشان می‌دهند که می‌توان بیش از یک بار فراخوانی کرد). بخش زیادی از متن زیر برای بدنه closureهای غیر FnOnce نیز به همان اندازه صدق می‌کند.

    مثال‌ها:

    use std::cell::RefCell;

struct TheDarkKnight;

impl TheDarkKnight {
    fn nothing_is_true(&self) {} // First case, we don't take ownership
}

fn main() {
    let x = RefCell::new(TheDarkKnight);

    x.borrow().nothing_is_true(); // ok!
}

    یا:

    use std::cell::RefCell;

struct TheDarkKnight;

impl TheDarkKnight {
    fn nothing_is_true(self) {}
}

fn main() {
    let x = RefCell::new(TheDarkKnight);
    let x = x.into_inner(); // we get back ownership

    x.nothing_is_true(); // ok!
}

    یا:

    use std::cell::RefCell;

#[derive(Clone, Copy)] // we implement the Copy trait
struct TheDarkKnight;

impl TheDarkKnight {
    fn nothing_is_true(self) {}
}

fn main() {
    let x = RefCell::new(TheDarkKnight);

    x.borrow().nothing_is_true(); // ok!
}

    انتقال یک عضو از درون یک ساختار که به‌صورت تغییرپذیر قرض گرفته شده نیز خطای E0507 را ایجاد می‌کند:

    struct TheDarkKnight;

impl TheDarkKnight {
    fn nothing_is_true(self) {}
}

struct Batcave {
    knight: TheDarkKnight
}

fn main() {
    let mut cave = Batcave {
        knight: TheDarkKnight
    };
    let borrowed = &mut cave;

    borrowed.knight.nothing_is_true(); // E0507
}

    این کار فقط در صورتی مجاز است که چیزی را جایش بگذارید. برای این منظور می‌توان از mem::replace استفاده کرد:

    # struct TheDarkKnight;
# impl TheDarkKnight { fn nothing_is_true(self) {} }
# struct Batcave { knight: TheDarkKnight }
use std::mem;

let mut cave = Batcave {
    knight: TheDarkKnight
};
let borrowed = &mut cave;

mem::replace(&mut borrowed.knight, TheDarkKnight).nothing_is_true(); // ok!

    برای اطلاعات بیشتر درباره‌ی سامانه‌ی مالکیت Rust، بخش ارجاع‌ها و قرض‌گیری کتاب را ببینید.
