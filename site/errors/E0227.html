راهنمای خطاهای کامپایلرCompiler Error Index

    این خطا نشان می‌دهد که کامپایلر نمی‌تواند تشخیص دهد که آیا در مجموعه قیدهای ناحیه (region) مشتق‌شده دقیقاً یک ناحیه یکتا وجود دارد یا نه.

    نمونه کد دارای خطا:

    trait Foo<'foo>: 'foo {}
trait Bar<'bar>: 'bar {}

trait FooBar<'foo, 'bar>: Foo<'foo> + Bar<'bar> {}

struct Baz<'foo, 'bar> {
    baz: dyn FooBar<'foo, 'bar>,
}

    در اینجا baz می‌تواند طول عمر 'foo یا 'bar را داشته باشد.

    برای رفع این خطا، یک طول عمر صریح فراهم کنید:

    trait Foo<'foo>: 'foo {}
trait Bar<'bar>: 'bar {}

trait FooBar<'foo, 'bar>: Foo<'foo> + Bar<'bar> {}

struct Baz<'foo, 'bar, 'baz>
where
    'baz: 'foo + 'bar,
{
    obj: dyn FooBar<'foo, 'bar> + 'baz,
}
    → E0226E0228 ←
