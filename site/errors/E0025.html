راهنمای خطاهای کامپایلرCompiler Error Index

    هر فیلد یک ساختار را فقط یک بار می‌توان در یک الگو به متغیر متصل کرد.

    نمونه کد نادرست:

    struct Foo {
    a: u8,
    b: u8,
}

fn main(){
    let x = Foo { a:1, b:2 };

    let Foo { a: x, a: y } = x;
    // error: field `a` bound multiple times in the pattern
}

    هر بار که نام یک فیلد ظاهر می‌شود، مقدار آن فیلد به یک متغیر متصل می‌شود؛ بنابراین برای رفع این خطا باید استفاده‌های تکراری از نام فیلد را حذف یا تغییر دهید. شاید نام فیلد دیگری را اشتباه نوشته‌اید؟ مثال:

    struct Foo {
    a: u8,
    b: u8,
}

fn main(){
    let x = Foo { a:1, b:2 };

    let Foo { a: x, b: y } = x; // ok!
}
