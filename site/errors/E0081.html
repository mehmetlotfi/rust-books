راهنمای خطاهای کامپایلرCompiler Error Index

    یک مقدار discriminant بیش از یک بار وجود دارد.

    نمونه کد دارای خطا:

    enum Enum {
    P = 3,
    X = 3, // error!
    Y = 5,
}

    discriminantهای شمارش برای تمایز دادن بین واریانت‌های شمارش که در حافظه ذخیره می‌شوند به کار می‌روند. این خطا نشان می‌دهد که یک مقدار برای دو یا چند واریانت استفاده شده است و تشخیص آن‌ها از یکدیگر را غیرممکن می‌کند.

    enum Enum {
    P,
    X = 3, // ok!
    Y = 5,
}

    توجه کنید که واریانت‌هایی که discriminant آن‌ها به‌صورت دستی مشخص نشده است، از بالا به پایین و از ۰ شماره‌گذاری می‌شوند، بنابراین ممکن است بین واریانت‌هایی که به‌ظاهر بی‌ارتباطند تداخل رخ دهد.

    enum Bad {
    X,
    Y = 0, // error!
}

    در این‌جا تا زمانی که به Y برسیم، discriminant مقدار ۰ از قبل به X اختصاص یافته است، بنابراین تداخل رخ می‌دهد.
