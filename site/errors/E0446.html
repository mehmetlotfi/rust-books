راهنمای خطاهای کامپایلرCompiler Error Index

    یک نوع یا صفت خصوصی در امضای یک نوع وابسته (associated type) عمومی به کار رفته است.

    نمونه کد دارای خطا:

    struct Bar;

pub trait PubTr {
    type Alias;
}

impl PubTr for u8 {
    type Alias = Bar; // error private type in public interface
}

fn main() {}

    دو راه برای رفع این خطا وجود دارد. راه اول این است که امضای نوع عمومی را فقط برای ماژولی عمومی کنید که به نوع خصوصی هم دسترسی دارد. این کار با استفاده از pub(crate) یا pub(in crate::my_mod::etc) انجام می‌شود. مثال:

    struct Bar;

pub(crate) trait PubTr { // only public to crate root
    type Alias;
}

impl PubTr for u8 {
    type Alias = Bar;
}

fn main() {}

    راه دوم برای رفع این خطا این است که نوع خصوصی را عمومی کنید. مثال:

    
pub struct Bar; // we set the Bar trait public

pub trait PubTr {
    type Alias;
}

impl PubTr for u8 {
    type Alias = Bar;
}

fn main() {}
