راهنمای خطاهای کامپایلرCompiler Error Index

    یک متغیر const زمان کامپایل به یک متغیر static از نوع thread-local ارجاع می‌دهد.

    نمونه کد خطادار:

    #![feature(thread_local)]

#[thread_local]
static X: usize = 12;

const Y: usize = 2 * X;

    متغیرهای static و const می‌توانند به متغیرهای const دیگر ارجاع دهند، اما یک متغیر const نمی‌تواند به یک متغیر static از نوع thread-local ارجاع دهد. در این مثال، Y نمی‌تواند به X ارجاع دهد. برای رفع این مشکل، می‌توان مقدار را به‌صورت یک const بیرون کشید و سپس از آن استفاده کرد:

    #![feature(thread_local)]

const C: usize = 12;

#[thread_local]
static X: usize = C;

const Y: usize = 2 * C;
