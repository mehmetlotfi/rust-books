راهنمای خطاهای کامپایلرCompiler Error Index

    یک صفت روی صفت دیگری پیاده‌سازی شده است که از قبل آن را به‌طور خودکار پیاده‌سازی می‌کرد.

    نمونه‌های کد خطادار:

    trait Foo { fn foo(&self) { } }
trait Bar: Foo { }
trait Baz: Bar { }

impl Bar for dyn Baz { } // error, `Baz` implements `Bar` by definition
impl Foo for dyn Baz { } // error, `Baz` implements `Bar` which implements `Foo`
impl Baz for dyn Baz { } // error, `Baz` (trivially) implements `Baz`

    این مورد مجاز است، زیرا Bar طبق تعریف Baz را پیاده‌سازی نمی‌کند:

    # trait Foo { fn foo(&self) { } }
# trait Bar: Foo { }
# trait Baz: Bar { }
impl Baz for dyn Bar { } // Note: This is OK

    هنگامی که Trait2 یک زیرصفت (subtrait) از Trait1 باشد (برای مثال وقتی Trait2 تعریفی مانند trait Trait2: Trait1 { ... } دارد)، پیاده‌سازی Trait1 برای Trait2 مجاز نیست. دلیلش این است که Trait2 طبق تعریف از قبل Trait1 را پیاده‌سازی می‌کند، بنابراین انجام این کار فایده‌ای ندارد.
