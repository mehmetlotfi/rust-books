راهنمای خطاهای کامپایلرCompiler Error Index

    قید طول عمر این نوع شیء را نمی‌توان از زمینه (context) استنباط کرد و باید صریحاً مشخص شود.

    نمونه کد دارای خطا:

    trait Trait { }

struct TwoBounds<'a, 'b, T: Sized + 'a + 'b> {
    x: &'a i32,
    y: &'b i32,
    z: T,
}

type Foo<'a, 'b> = TwoBounds<'a, 'b, dyn Trait>;

    وقتی یک شیء صفت (trait object) به‌عنوان آرگومان نوع یک نوع جنریک استفاده می‌شود، Rust در صورت مشخص نشدن طول عمر آن، سعی می‌کند آن را استنباط کند. اما وقتی نوع حاوی بیش از یک قید طول عمر داشته باشد، این کار ممکن نیست.

    مثال بالا را می‌توان یا با کاهش تعداد قیدهای طول عمر به یکی یا با صریح کردن طول عمر شیء صفت حل کرد، مانند زیر:

    trait Trait { }

struct TwoBounds<'a, 'b, T: Sized + 'a + 'b> {
    x: &'a i32,
    y: &'b i32,
    z: T,
}

type Foo<'a, 'b> = TwoBounds<'a, 'b, dyn Trait + 'b>;

    برای اطلاعات بیشتر، RFC 599 و اصلاحیه آن RFC 1156 را ببینید.
