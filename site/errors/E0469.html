    ماکرویی که برای وارد شدن فهرست شده بود پیدا نشد.

    نمونه کد دارای خطا:

    #[macro_use(drink, be_merry)] // error: imported macro not found
extern crate alloc;

fn main() {
    // ...
}

    یا ماکروی فهرست‌شده در crate واردشده وجود ندارد، یا از crate داده‌شده صادر (export) نمی‌شود.

    این ممکن است به‌دلیل یک غلط تایپی باشد. آیا نام ماکرو را اشتباه نوشته‌اید؟

    نام ماکروهایی را که برای وارد شدن فهرست کرده‌اید دوباره بررسی کنید و مطمئن شوید که crate موردنظر آن‌ها را صادر می‌کند.

    یک نسخه کارآمد چنین خواهد بود:

    // In some_crate crate:
#[macro_export]
macro_rules! eat {
    ...
}

#[macro_export]
macro_rules! drink {
    ...
}

// In your crate:
#[macro_use(eat, drink)]
extern crate some_crate; //ok!
