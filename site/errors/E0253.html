راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود.

    تلاش شده است نوعی که قابل وارد کردن نیست وارد شود. این اتفاق می‌تواند هنگام تلاش برای وارد کردن یک نوع از درون یک صفت (trait) رخ دهد.

    کد دارای خطا:

    #![feature(import_trait_associated_functions)]

mod foo {
    pub trait MyTrait {
        type SomeType;
    }
}

use foo::MyTrait::SomeType;
// error: `SomeType` is not directly importable

fn main() {}

    وارد کردن مستقیم نوع‌هایی که متعلق به یک صفت (trait) هستند نامعتبر است.
