راهنمای خطاهای کامپایلرCompiler Error Index

    اسمبلی درون‌خطی (asm!) روی این هدف پشتیبانی نمی‌شود.

    نمونه کد دارای خطا:

    // compile-flags: --target sparc64-unknown-linux-gnu
#![no_std]

use core::arch::asm;

fn main() {
    unsafe {
        asm!(""); // error: inline assembly is not supported on this target
    }
}

    کامپایلر Rust اسمبلی درون‌خطی را با ماکروی asm! (که پیش‌تر llvm_asm! بود) برای همه هدف‌ها پشتیبانی نمی‌کند. همه هدف‌های Tier 1 از این ماکرو پشتیبانی می‌کنند، اما پشتیبانی در میان هدف‌های Tier 2 و 3 تضمین نشده است (حتی زمانی که از std پشتیبانی می‌کنند). توجه کنید که این خطا به error[E0658]: inline assembly is not stable yet on this architecture مرتبط است، اما با آن متفاوت است، زیرا در E0472 پشتیبانی برنامه‌ریزی نشده و در دست انجام هم نیست.

    راه آسانی برای رفع این مشکل وجود ندارد، اما:

    • بررسی کنید که آیا واقعاً به اسمبلی درون‌خطی نیاز دارید، یا راه دیگری برای رسیدن به هدفتان وجود دارد (مثلاً intrinsicها و غیره).
    • در نظر بگیرید که اسمبلی خود را به‌صورت خارجی بنویسید، با آن پیوند دهید و از Rust آن را فراخوانی کنید.
    • در نظر بگیرید که در https://github.com/rust-lang/rust مشارکت کنید و به افزودن پشتیبانی از هدف خود کمک کنید!
