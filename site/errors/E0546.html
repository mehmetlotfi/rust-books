راهنمای خطاهای کامپایلرCompiler Error Index

    مقدار feature در یک attribute پایداری (stability attribute) وجود ندارد.

    نمونه‌ی کد خطادار:

    #![feature(staged_api)]
#![allow(internal_features)]
#![stable(since = "1.0.0", feature = "test")]

#[unstable(issue = "none")] // invalid
fn unstable_fn() {}

#[stable(since = "1.0.0")] // invalid
fn stable_fn() {}

    برای رفع این مشکل، باید فیلد feature را مشخص کنید. نمونه:

    #![feature(staged_api)]
#![allow(internal_features)]
#![stable(since = "1.0.0", feature = "test")]

#[unstable(feature = "unstable_fn", issue = "none")] // ok!
fn unstable_fn() {}

#[stable(feature = "stable_fn", since = "1.0.0")] // ok!
fn stable_fn() {}

    برای جزئیات بیشتر، پیوست How Rust is Made and “Nightly Rust” کتاب و بخش Stability attributes در Rustc Dev Guide را ببینید.
