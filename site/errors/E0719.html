راهنمای خطاهای کامپایلرCompiler Error Index

    یک آیتم وابسته (associated item) بیش از یک بار در یک شیء صفت مشخص شده است.

    نمونه کد خطادار:

    trait FooTrait {}
trait BarTrait {}

// error: associated type `Item` in trait `Iterator` is specified twice
type Foo = dyn Iterator<Item = u32, Item = u32>;

    برای رفع این مشکل، مشخص‌کننده‌ی تکراری را حذف کنید:

    مثال اصلاح‌شده:

    type Foo = dyn Iterator<Item = u32>; // ok!

    برای اطلاعات بیشتر درباره‌ی نوع‌های وابسته (associated type)، کتاب را ببینید. برای اطلاعات بیشتر درباره‌ی محدودیت‌های نوع وابسته، RFC 2289 را ببینید.
