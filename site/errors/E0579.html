راهنمای خطاهای کامپایلرCompiler Error Index

    حد پایین یک بازه کوچک‌تر از حد بالای آن نبود.

    نمونه کد خطادار:

    
fn main() {
    match 5u32 {
        // This range is ok, albeit pointless.
        1..2 => {}
        // This range is empty, and the compiler can tell.
        5..5 => {} // error!
    }
}

    هنگام تطبیق با یک بازه‌ی انحصاری، کامپایلر بررسی می‌کند که بازه تهی نباشد. الگوهای بازه‌ی انحصاری نقطه‌ی شروع را در بر می‌گیرند اما نقطه‌ی پایان را شامل نمی‌شوند؛ بنابراین این شرط معادل آن است که شروع بازه باید کوچک‌تر از پایان بازه باشد.
