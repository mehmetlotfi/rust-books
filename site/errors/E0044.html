راهنمای خطاهای کامپایلرCompiler Error Index

    نمی‌توانید از پارامترهای نوع یا ثابت روی آیتم‌های خارجی (foreign items) استفاده کنید.

    نمونه کد نادرست:

    extern "C" { fn some_func<T>(x: T); }

    برای رفع این مشکل، پارامتر جنریک را با تخصیص‌هایی (specializations) که نیاز دارید جایگزین کنید:

    extern "C" { fn some_func_i32(x: i32); }
extern "C" { fn some_func_i64(x: i64); }
