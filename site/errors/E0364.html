راهنمای خطاهای کامپایلرCompiler Error Index

    آیتم‌های خصوصی را نمی‌توان به‌طور عمومی دوباره صادر (re-export) کرد. این خطا نشان می‌دهد که سعی کرده‌اید نوع یا مقداری را pub use کنید که خودش عمومی نبوده است.

    نمونه کد خطادار:

    mod a {
    fn foo() {}

    mod a {
        pub use super::foo; // error!
    }
}

    راه‌حل این مشکل این است که مطمئن شوید آیتم‌هایی که دوباره صادر می‌کنید خودشان با pub علامت‌گذاری شده‌اند:

    mod a {
    pub fn foo() {} // ok!

    mod a {
        pub use super::foo;
    }
}

    برای اطلاعات بیشتر درباره‌ی این موضوع، بخش Use Declarations در Reference را ببینید.
