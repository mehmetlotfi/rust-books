راهنمای خطاهای کامپایلرCompiler Error Index

    فیلد یک ساختار یا یک واریانت شمارش ساختارگونه بیش از یک بار مشخص شده است.

    نمونه کد نادرست:

    struct Foo {
    x: i32,
}

fn main() {
    let x = Foo {
                x: 0,
                x: 0, // error: field `x` specified more than once
            };
}

    این خطا نشان می‌دهد که در تلاش برای ساخت یک ساختار یا واریانت شمارش ساختارگونه، یکی از فیلدها بیش از یک بار مشخص شده است. هر فیلد باید دقیقاً یک بار مشخص شود. مثال:

    struct Foo {
    x: i32,
}

fn main() {
    let x = Foo { x: 0 }; // ok!
}
