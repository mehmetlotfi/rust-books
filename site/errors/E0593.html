راهنمای خطاهای کامپایلرCompiler Error Index

    شما سعی کردید به یک نوع مبتنی بر Fn تعداد آرگومان‌هایی متفاوت از تعداد مورد انتظار بدهید.

    نمونهٔ کد دارای خطا:

    fn foo<F: Fn()>(x: F) { }

fn main() {
    // [E0593] closure takes 1 argument but 0 arguments are required
    foo(|y| { });
}

    باید دقیقاً به همان تعداد آرگومانی که نوع مبتنی بر Fn انتظار دارد، آرگومان ارائه کنید. بنابراین برای رفع مثال قبلی باید آرگومان y را حذف کنیم:

    fn foo<F: Fn()>(x: F) { }

fn main() {
    foo(|| { }); // ok!
}
