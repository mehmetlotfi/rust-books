راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود.

    شما یک ارجاع به یک static قابل‌تغییر ایجاد کرده‌اید.

    مثال کد خطادار:

    static mut X: i32 = 23;
fn work() {
  let _val = unsafe { X };
}
let x_ref = unsafe { &mut X };
work();
// The next line has Undefined Behavior!
// `x_ref` is a mutable reference and allows no aliases,
// but `work` has been reading the reference between
// the moment `x_ref` was created and when it was used.
// This violates the uniqueness of `x_ref`.
*x_ref = 42;

    ارجاع به یک static قابل‌تغییر طول عمر 'static دارد. این بسیار خطرناک است زیرا به‌راحتی ممکن است طول عمر آن ارجاع به‌طور ناخواسته با دسترسی‌های متعارض دیگر به همان static همپوشانی پیدا کند.

    ارجاع به staticهای قابل‌تغییر در ویرایش (edition) 2024 یک خطای سخت است.
