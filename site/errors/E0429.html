    توجه: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود.

    کلیدواژه self نمی‌تواند به‌تنهایی به‌عنوان آخرین بخش (segment) یک اعلان use ظاهر شود.

    نمونه کد خطادار:

    use std::fmt::self; // error: `self` imports are only allowed within a { } list

    برای استفاده از یک فضای نام (namespace) به‌همراه برخی از اعضای آن، می‌توان self را به‌عنوان بخشی از فهرست واردسازی‌های داخل آکولاد نوشت:

    use std::fmt::{self, Debug};

    اگر فقط می‌خواهید خود فضای نام را وارد کنید، مستقیماً این کار را انجام دهید:

    use std::fmt;
