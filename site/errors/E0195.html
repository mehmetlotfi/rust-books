راهنمای خطاهای کامپایلرCompiler Error Index

    پارامترهای طول عمر متد با تعریف صفت (trait) مطابقت ندارند.

    نمونه کد دارای خطا:

    trait Trait {
    fn bar<'a,'b:'a>(x: &'a str, y: &'b str);
}

struct Foo;

impl Trait for Foo {
    fn bar<'a,'b>(x: &'a str, y: &'b str) {
    // error: lifetime parameters or bounds on method `bar`
    // do not match the trait declaration
    }
}

    قید طول عمر 'b در پیاده‌سازی bar() با تعریف صفت مطابقت ندارد. مطمئن شوید که اعلان‌های طول عمر در تعریف صفت و در پیاده‌سازی دقیقاً یکسان هستند. مثال:

    trait Trait {
    fn t<'a,'b:'a>(x: &'a str, y: &'b str);
}

struct Foo;

impl Trait for Foo {
    fn t<'a,'b:'a>(x: &'a str, y: &'b str) { // ok!
    }
}
