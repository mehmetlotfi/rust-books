راهنمای خطاهای کامپایلرCompiler Error Index

    یک ارجاع طول عمر بیشتری از داده‌ای که به آن ارجاع می‌دهد دارد.

    نمونه کد دارای خطا:

    struct Foo<'a> {
    x: fn(&'a i32),
}

trait Trait<'a, 'b> {
    type Out;
}

impl<'a, 'b> Trait<'a, 'b> for usize {
    type Out = &'a Foo<'b>; // error!
}

    در اینجا مشکل این است که کامپایلر نمی‌تواند مطمئن باشد که طول عمر 'b بیشتر از 'a خواهد بود؛ در حالی که این امر برای اطمینان از اینکه Trait::Out همیشه ارجاعی به یک نوع موجود دارد الزامی است. بنابراین در این حالت فقط باید به کامپایلر بگوییم که 'b باید بیشتر از 'a عمر کند:

    struct Foo<'a> {
    x: fn(&'a i32),
}

trait Trait<'a, 'b> {
    type Out;
}

impl<'a, 'b: 'a> Trait<'a, 'b> for usize { // we added the lifetime enforcement
    type Out = &'a Foo<'b>; // it now works!
}
