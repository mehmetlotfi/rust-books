راهنمای خطاهای کامپایلرCompiler Error Index

    نمی‌توانید مقداری را وارد کنید که نامش با مقدار دیگری که در ماژول تعریف شده یکسان است.

    کد دارای خطا:

    use bar::foo; // error: an item named `foo` is already in scope

fn foo() {}

mod bar {
     pub fn foo() {}
}

fn main() {}

    برای رفع این خطا می‌توانید از نام مستعار استفاده کنید. مثال:

    use bar::foo as bar_foo; // ok!

fn foo() {}

mod bar {
     pub fn foo() {}
}

fn main() {}

    یا می‌توانید با استفاده از آیتم والد به آیتم مورد نظر ارجاع دهید:

    fn foo() {}

mod bar {
     pub fn foo() {}
}

fn main() {
    bar::foo(); // we get the item by referring to its parent
}
