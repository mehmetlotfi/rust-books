راهنمای خطاهای کامپایلرCompiler Error Index

    هدف ماکروی derive(CoercePointee) مشخصاتی دارد که برای یک استفاده معنادار قابل‌قبول نیستند.

    مثال‌های کد خطادار:

    داده هدف یک struct نیست.

    #![feature(coerce_pointee)]
use std::marker::CoercePointee;
#[derive(CoercePointee)]
enum NotStruct<'a, T: ?Sized> {
    Variant(&'a T),
}

    داده هدف چیدمانی دارد که شفاف (transparent) نیست، یا به عبارت دیگر repr(transparent) ندارد.

    #![feature(coerce_pointee)]
use std::marker::CoercePointee;
#[derive(CoercePointee)]
struct NotTransparent<'a, #[pointee] T: ?Sized> {
    ptr: &'a T,
}

    داده هدف هیچ فیلد داده‌ای ندارد.

    #![feature(coerce_pointee)]
use std::marker::CoercePointee;
#[derive(CoercePointee)]
#[repr(transparent)]
struct NoField<'a, #[pointee] T: ?Sized> {}

    داده هدف روی هیچ داده‌ای جنریک نیست، یا هیچ پارامتر نوع جنریکی ندارد.

    #![feature(coerce_pointee)]
use std::marker::CoercePointee;
#[derive(CoercePointee)]
#[repr(transparent)]
struct NoGeneric<'a>(&'a u8);

    داده هدف چند پارامتر نوع جنریک دارد، اما هیچ‌کدام به‌عنوان pointee برای coercion تعیین نشده است.

    #![feature(coerce_pointee)]
use std::marker::CoercePointee;
#[derive(CoercePointee)]
#[repr(transparent)]
struct AmbiguousPointee<'a, T1: ?Sized, T2: ?Sized> {
    a: (&'a T1, &'a T2),
}

    داده هدف چند پارامتر نوع جنریک دارد که به‌عنوان pointee برای coercion تعیین شده‌اند.

    #![feature(coerce_pointee)]
use std::marker::CoercePointee;
#[derive(CoercePointee)]
#[repr(transparent)]
struct TooManyPointees<
    'a,
    #[pointee] A: ?Sized,
    #[pointee] B: ?Sized>
((&'a A, &'a B));

    پارامتر نوعی که به‌عنوان pointee تعیین شده، با ?Sized علامت‌گذاری نشده است.

    #![feature(coerce_pointee)]
use std::marker::CoercePointee;
#[derive(CoercePointee)]
#[repr(transparent)]
struct NoMaybeSized<'a, #[pointee] T> {
    ptr: &'a T,
}

    در مجموع، ماکروی CoercePointee می‌طلبد که نوع، یک struct باشد که روی حداقل یک نوع یا بیشتر جنریک است و یکی از آن‌ها با #[pointee] علامت‌گذاری شده است، دست‌کم یک فیلد داده دارد و چیدمان repr(transparent) را به کار می‌برد. تنها نوع جنریک یا نوعی که با #[pointee] علامت‌گذاری شده است، باید با ?Sized نیز علامت‌گذاری شده باشد.
