راهنمای خطاهای کامپایلرCompiler Error Index

    یک نوع trait ارجاع‌زدایی (dereference) شده است.

    نمونه کد نادرست:

    # trait SomeTrait { fn method_one(&self){} fn method_two(&self){} }
# impl<T> SomeTrait for T {}
let trait_obj: &SomeTrait = &"some_value";

// This tries to implicitly dereference to create an unsized local variable.
let &invalid = trait_obj;

// You can call methods without binding to the value being pointed at.
trait_obj.method_one();
trait_obj.method_two();

    یک اشاره‌گر به نوع trait را نمی‌توان به‌طور ضمنی توسط یک الگو ارجاع‌زدایی کرد. هر trait یک نوع تعریف می‌کند، اما چون اندازه پیاده‌سازهای trait ثابت نیست، این نوع اندازه‌ای در زمان کامپایل ندارد. بنابراین همه دسترسی‌ها به انواع trait باید از طریق اشاره‌گر انجام شود. اگر با این خطا روبه‌رو شدید، سعی کنید از ارجاع‌زدایی اشاره‌گر پرهیز کنید.

    برای اطلاعات بیشتر درباره شیء صفت‌ها می‌توانید بخش اشیای صفت را در Reference بخوانید.
