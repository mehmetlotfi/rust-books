راهنمای خطاهای کامپایلرCompiler Error Index

    یک ارجاع ناهم‌تراز (unaligned) به فیلدی از یک struct یا union از نوع packed ایجاد شده است.

    attribute با نام #[repr(packed)] فاصله‌گذاری (padding) بین فیلدها را حذف می‌کند، که می‌تواند باعث شود فیلدها در آدرس‌های حافظه ناهم‌تراز ذخیره شوند. ایجاد ارجاع به چنین فیلدهایی تضمین‌های ایمنی حافظه Rust را نقض می‌کند و می‌تواند در کد بهینه‌شده به رفتار تعریف‌نشده منجر شود.

    مثال کد خطادار:

    #[repr(packed)]
pub struct Foo {
    field1: u64,
    field2: u8,
}

unsafe {
    let foo = Foo { field1: 0, field2: 0 };
    // Accessing the field directly is fine.
    let val = foo.field1;
    // A reference to a packed field causes a error.
    let val = &foo.field1; // ERROR
    // An implicit `&` is added in format strings, causing the same error.
    println!("{}", foo.field1); // ERROR
}

    ایجاد ارجاع به یک فیلد packed با ترازبندی ناکافی رفتار تعریف‌نشده است و بنابراین ممنوع است. استفاده از بلوک unsafe در این مورد هیچ تغییری ایجاد نمی‌کند. در عوض، کد باید از داده فیلد packed یک کپی بگیرد یا از اشاره‌گرهای خام و دسترسی‌های ناهم‌تراز استفاده کند.

    #[repr(packed)]
pub struct Foo {
    field1: u64,
    field2: u8,
}

unsafe {
    let foo = Foo { field1: 0, field2: 0 };

    // Instead of a reference, we can create a raw pointer...
    let ptr = std::ptr::addr_of!(foo.field1);
    // ... and then (crucially!) access it in an explicitly unaligned way.
    let val = unsafe { ptr.read_unaligned() };
    // This would *NOT* be correct:
    // let val = unsafe { *ptr }; // Undefined Behavior due to unaligned load!

    // For formatting, we can create a copy to avoid the direct reference.
    let copy = foo.field1;
    println!("{}", copy);

    // Creating a copy can be written in a single line with curly braces.
    // (This is equivalent to the two lines above.)
    println!("{}", { foo.field1 });

    // A reference to a field that will always be sufficiently aligned is safe:
    println!("{}", foo.field2);
}

    Unionها

    اگرچه ایجاد ارجاع به فیلد یک union به‌خودی‌خود unsafe است، در صورتی که فیلد ارجاع‌شده ترازبندی کافی نداشته باشد، باز هم این خطا ایجاد می‌شود. همان‌طور که برای فیلدهای ساختار عمل می‌کنید، از addr_of! و اشاره‌گرهای خام استفاده کنید.

    #[repr(packed)]
pub union Foo {
    field1: u64,
    field2: u8,
}

unsafe {
    let foo = Foo { field1: 0 };
    // Accessing the field directly is fine.
    let val = foo.field1;

    // A reference to a packed union field causes an error.
    let val = &foo.field1; // ERROR
}

    اطلاعات بیشتر

    توجه کنید که این خطا به‌طور خاص درباره ارجاع‌ها به فیلدهای packed است. دسترسی مستقیم و بر پایه مقدار به آن فیلدها اشکالی ندارد، زیرا در آن صورت کامپایلر اطلاعات کافی برای تولید نوع صحیح دسترسی را دارد.

    برای اطلاعات بیشتر به issue #82523 مراجعه کنید.
