راهنمای خطاهای کامپایلرCompiler Error Index

    یک ارجاع به یک متغیر محلی بازگردانده شده است.

    نمونه کد خطادار:

    fn get_dangling_reference() -> &'static i32 {
    let x = 0;
    &x
}

    use std::slice::Iter;
fn get_dangling_iterator<'a>() -> Iter<'a, i32> {
    let v = vec![1, 2, 3];
    v.iter()
}

    متغیرهای محلی، پارامترهای تابع و مقادیر موقت همگی پیش از پایان بدنهٔ تابع drop می‌شوند. ارجاعی (یا ساختاری شامل یک ارجاع) که به چنین مقدار drop‌شده‌ای بازگردانده شود، بلافاصله نامعتبر خواهد بود. بنابراین بازگرداندن چنین ارجاعی مجاز نیست.

    به‌جای ارجاع دادن به داده‌های محلی، مقداری را بازگردانید که مالکیت آن‌ها را به عهده می‌گیرد:

    use std::vec::IntoIter;

fn get_integer() -> i32 {
    let x = 0;
    x
}

fn get_owned_iterator() -> IntoIter<i32> {
    let v = vec![1, 2, 3];
    v.into_iter()
}
