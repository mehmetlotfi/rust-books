    کد unsafe خارج از یک بلوک unsafe به کار رفته است.

    نمونهٔ کد خطادار:

    unsafe fn f() { return; } // This is the unsafe code

fn main() {
    f(); // error: call to unsafe function requires unsafe function or block
}

    استفاده از قابلیت‌های unsafe بالقوه خطرناک است و بررسی‌های ایمنی آن را مجاز نمی‌دانند. نمونه‌ها:

    • مرجع‌زدایی (dereference) اشاره‌گرهای خام
    • فراخوانی تابع‌ها از طریق FFI
    • فراخوانی تابع‌هایی که با unsafe علامت‌گذاری شده‌اند

    با قرار دادن دستورهای unsafe درون یک بلوک unsafe می‌توان این بررسی‌های ایمنی را برای بخشی از کد تعدیل کرد. برای مثال:

    unsafe fn f() { return; }

fn main() {
    unsafe { f(); } // ok!
}

    برای جزئیات بیشتر، بخش unsafe کتاب را ببینید.

    کد unsafe در تابع‌ها

    در حال حاضر کد unsafe درون تابع‌های unsafe پذیرفته می‌شود، اما این رفتار در حال حذف تدریجی است و به‌جای آن، در اینجا نیز استفاده از بلوک‌های unsafe الزامی خواهد شد.

    unsafe fn f() { return; }

unsafe fn g() {
    f(); // Is accepted, but no longer recommended
    unsafe { f(); } // Recommended way to write this
}

    کنترل هشدار دربارهٔ این مورد بر عهدهٔ lint با نام unsafe_op_in_unsafe_fn است که در edition 2024 به‌طور پیش‌فرض warn و در editionهای قبلی به‌طور پیش‌فرض allow است.
