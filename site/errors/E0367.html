    تلاش شده است Drop برای یک تخصصی‌سازی از یک نوع جنریک پیاده‌سازی شود.

    نمونه کد خطادار:

    trait Foo {}

struct MyStruct<T> {
    t: T
}

impl<T: Foo> Drop for MyStruct<T> {
    fn drop(&mut self) {}
}

    این کد مجاز نیست: نمی‌توان Drop را فقط برای زیرمجموعه‌ای از پیاده‌سازی‌های یک نوع جنریک تخصصی کرد. برای اینکه این کد کار کند، MyStruct نیز باید الزام کند که T صفت Foo را پیاده‌سازی کند. گزینه دیگر این است که نوع جنریک را درون نوع دیگری بپیچید که به‌درستی تخصصی شده باشد:

    trait Foo{}

struct MyStruct<T> {
    t: T
}

struct MyStructWrapper<T: Foo> {
    t: MyStruct<T>
}

impl <T: Foo> Drop for MyStructWrapper<T> {
    fn drop(&mut self) {}
}
