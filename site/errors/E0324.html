راهنمای خطاهای کامپایلرCompiler Error Index

    یک متد پیاده‌سازی شده است در حالی که آیتم دیگری از صفت انتظار می‌رفت.

    نمونه کد خطادار:

    struct Bar;

trait Foo {
    const N : u32;

    fn M();
}

impl Foo for Bar {
    fn N() {}
    // error: item `N` is an associated method, which doesn't match its
    //        trait `<Bar as Foo>`
}

    برای رفع این خطا، لطفاً بررسی کنید که نام متد اشتباه نوشته نشده باشد و مطمئن شوید که واقعاً آیتم‌های صفت درست را پیاده‌سازی می‌کنید. مثال:

    struct Bar;

trait Foo {
    const N : u32;

    fn M();
}

impl Foo for Bar {
    const N : u32 = 0;

    fn M() {} // ok!
}
