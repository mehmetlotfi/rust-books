راهنمای خطاهای کامپایلرCompiler Error Index

    ماژول‌های خصوصی را نمی‌توان به‌صورت عمومی دوباره صادر (re-export) کرد. این خطا نشان می‌دهد که سعی کرده‌اید ماژولی را که خودش عمومی نیست با pub use صادر کنید.

    نمونه کد خطادار:

    mod foo {
    pub const X: u32 = 1;
}

pub use foo as foo2;

fn main() {}

    راه‌حل این مشکل این است که مطمئن شوید ماژولی که دوباره صادر می‌کنید، خودش با pub علامت‌گذاری شده است:

    pub mod foo {
    pub const X: u32 = 1;
}

pub use foo as foo2;

fn main() {}

    برای اطلاعات بیشتر درباره‌ی این موضوع، به بخش Use Declarations در مرجع (reference) مراجعه کنید.
