راهنمای خطاهای کامپایلرCompiler Error Index

    یک تابع وابسته‌ی صفت به‌صورت ایستا (static) تعریف شده است، اما پیاده‌سازیِ آن صفت همان تابع را به‌صورت متد اعلان کرده است (یعنی پارامتر self می‌گیرد).

    نمونه کدی که خطا می‌دهد:

    trait Foo {
    fn foo();
}

struct Bar;

impl Foo for Bar {
    // error, method `foo` has a `&self` declaration in the impl, but not in
    // the trait
    fn foo(&self) {}
}

    وقتی یک نوع تابع وابسته‌ی یک صفت را پیاده‌سازی می‌کند، باید از همان امضا استفاده کند. بنابراین در این مورد، چون Foo::foo هیچ آرگومانی نمی‌گیرد و چیزی برنمی‌گرداند، پیاده‌سازی آن روی Bar هم باید همین‌طور باشد:

    trait Foo {
    fn foo();
}

struct Bar;

impl Foo for Bar {
    fn foo() {} // ok!
}
