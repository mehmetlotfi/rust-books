راهنمای خطاهای کامپایلرCompiler Error Index

    نمی‌توان یک auto trait را از طریق تبدیل اشاره‌گر (pointer cast) به قیدهای نوع dyn Trait افزود.

    مثال کد خطادار:

    let ptr: *const dyn core::any::Any = &();
_ = ptr as *const (dyn core::any::Any + Send);

    افزودن یک auto trait می‌تواند vtable را نامعتبر کند و پس از آن به‌طور بالقوه در کد ایمن باعث رفتار تعریف‌نشده (UB) شود. برای مثال:

    use core::{mem::transmute, ptr::NonNull};

trait Trait {
    fn f(&self)
    where
        Self: Send;
}

impl Trait for NonNull<()> {
    fn f(&self) {
        unreachable!()
    }
}

fn main() {
    let unsend: &dyn Trait = &NonNull::dangling();
    let bad: &(dyn Trait + Send) = unsafe { transmute(unsend) };
    // This crashes, since the vtable for `NonNull as dyn Trait` does
    // not have an entry for `Trait::f`.
    bad.f();
}

    برای رفع این خطا می‌توانید به‌جای تبدیل اشاره‌گر از transmute استفاده کنید، اما پیش از فراخوانی یک متد روی شیء صفت (trait object) یا اجازه دادن به کد دیگر برای این کار، باید مطمئن شوید که vtable برای نوع اشاره‌گر معتبر است.
