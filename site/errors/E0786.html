راهنمای خطاهای کامپایلرCompiler Error Index

    یک فایل metadata نامعتبر بود.

    مثال کدی که خطا می‌دهد:

    use ::foo; // error: found invalid metadata files for crate `foo`

    هنگام بارگذاری crateها، هر crate باید یک فایل metadata معتبر داشته باشد. فایل‌های نامعتبر می‌توانند ناشی از خرابی سیستم فایل، خطای IO در حین خواندن فایل یا (به‌ندرت) یک باگ در خود کامپایلر باشند.

    حذف فایل و ساخت دوباره آن، یا گزارش یک باگ دربارهٔ کامپایلر را در نظر بگیرید.
