راهنمای خطاهای کامپایلرCompiler Error Index

    مقداری جابه‌جا (move) شده است که اندازه‌ی آن در زمان کامپایل معلوم نبوده است.

    نمونه کدی که خطا می‌دهد:

    trait Bar {
    fn f(self);
}

impl Bar for i32 {
    fn f(self) {}
}

fn main() {
    let b: Box<dyn Bar> = Box::new(0i32);
    b.f();
    // error: cannot move a value of type dyn Bar: the size of dyn Bar cannot
    //        be statically determined
}

    در Rust فقط وقتی می‌توانید یک مقدار را move کنید که اندازه‌ی آن در زمان کامپایل معلوم باشد.

    برای دور زدن این محدودیت، می‌توانید مقدار را پشت یک ارجاع «پنهان» کنید: یا &x یا &mut x. چون ارجاع اندازه‌ی ثابتی دارد، می‌توانید آن را مثل همیشه جابه‌جا کنید. مثال:

    trait Bar {
    fn f(&self);
}

impl Bar for i32 {
    fn f(&self) {}
}

fn main() {
    let b: Box<dyn Bar> = Box::new(0i32);
    b.f();
    // ok!
}
