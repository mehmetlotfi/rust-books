راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود.

    یک متد روی یک اشاره‌گر خام فراخوانی شده است که نوع درونی آن به‌طور کامل شناخته‌شده نبود.

    نمونه کد خطادار:

    # #![deny(warnings)]
# fn main() {
let foo = &1;
let bar = foo as *const _;
if bar.is_null() {
    // ...
}
# }

    در اینجا نوع bar معلوم نیست؛ می‌تواند اشاره‌گری به هر چیزی باشد. به‌جای آن، برای اشاره‌گر یک نوع مشخص کنید (ترجیحاً چیزی که با آنچه به آن اشاره می‌کنید سازگار باشد):

    let foo = &1;
let bar = foo as *const i32;
if bar.is_null() {
    // ...
}

    با اینکه is_null() روی هر اشاره‌گر خامی به‌عنوان متد وجود دارد، Rust این خطا را نشان می‌دهد زیرا Rust اجازه می‌دهد self نوع‌های دلخواه داشته باشد (پشت پرچم ویژگی arbitrary_self_types).

    این یعنی کسی می‌تواند چنین تابعی را تعریف کند:

    impl Foo {
    fn is_null(self: *const Self) -> bool {
        // do something else
    }
}

    و حالا وقتی .is_null() را روی یک اشاره‌گر خام به Foo فراخوانی می‌کنید، ابهام پیش می‌آید.

    با توجه به اینکه نوع اشاره‌گر را نمی‌دانیم و برای برخی نوع‌ها ابهام بالقوه وجود دارد، فراخوانی متدها روی اشاره‌گرهای خام را در صورتی که نوع ناشناخته باشد ممنوع می‌کنیم.
