راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود.

    در یک الگو، همهٔ مقادیری که صفت Copy را پیاده‌سازی نمی‌کنند باید به یک شکل متصل شوند. هدف در اینجا جلوگیری از اتصال هم‌زمان با انتقال (by-move) و با ارجاع (by-ref) است.

    این محدودیت ممکن است در نسخه‌ای آینده از Rust برداشته شود.

    نمونه کد اشتباه:

    #![feature(move_ref_pattern)]

struct X { x: (), }

let x = Some((X { x: () }, X { x: () }));
match x {
    Some((y, ref z)) => {}, // error: cannot bind by-move and by-ref in the
                            //        same pattern
    None => panic!()
}

    دو راه‌حل دارید:

    راه‌حل ۱: مقادیر الگو را به یک شکل متصل کنید.

    struct X { x: (), }

let x = Some((X { x: () }, X { x: () }));
match x {
    Some((ref y, ref z)) => {},
    // or Some((y, z)) => {}
    None => panic!()
}

    راه‌حل ۲: صفت Copy را برای ساختار X پیاده‌سازی کنید.

    با این حال، به یاد داشته باشید که راه‌حل اول ارجح است.

    #[derive(Clone, Copy)]
struct X { x: (), }

let x = Some((X { x: () }, X { x: () }));
match x {
    Some((y, ref z)) => {},
    None => panic!()
}
