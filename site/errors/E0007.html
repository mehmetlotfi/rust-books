راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود.

    این خطا نشان می‌دهد که اتصال‌ها (bindings) در یک شاخهٔ match مستلزم انتقال یک مقدار به بیش از یک مکان هستند و بدین‌ترتیب مالکیت یکتا را نقض می‌کنند. کدی مانند نمونهٔ زیر نامعتبر است، زیرا هم‌زمان لازم است کل Option<String> به متغیری به نام op_string منتقل شود و String درونی نیز به متغیری به نام s منتقل شود.

    نمونه کد اشتباه:

    #![feature(bindings_after_at)]

let x = Some("s".to_string());

match x {
    op_string @ Some(s) => {}, // error: use of moved value
    None => {},
}
