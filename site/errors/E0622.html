راهنمای خطاهای کامپایلرCompiler Error Index

    نکته: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود.

    یک intrinsic بدون اینکه تابع باشد اعلان شده است.

    نمونهٔ کد دارای خطا:

    #![feature(intrinsics)]
#![allow(internal_features)]

extern "C" {
    #[rustc_intrinsic]
    pub static atomic_singlethreadfence_seqcst: unsafe fn();
    // error: intrinsic must be a function
}

fn main() { unsafe { atomic_singlethreadfence_seqcst(); } }

    intrinsic تابعی است که در یک زبان برنامه‌نویسی مشخص برای استفاده در دسترس است و پیاده‌سازی آن به‌طور ویژه توسط کامپایلر مدیریت می‌شود. برای رفع این خطا، کافی است یک تابع تعریف کنید. مثال:

    #![feature(intrinsics)]
#![allow(internal_features)]

#[rustc_intrinsic]
pub unsafe fn atomic_singlethreadfence_seqcst(); // ok!

fn main() { unsafe { atomic_singlethreadfence_seqcst(); } }
