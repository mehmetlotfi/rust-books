راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: کامپایلر دیگر این کد خطا را صادر نمی‌کند.

    هنگام استفاده از attribute #[simd] روی یک ساختار تاپلی، همهٔ اجزای ساختار تاپلی باید از یک نوع مشخص و غیرجنریک باشند تا کامپایلر بتواند دربارهٔ نحوهٔ استفاده از SIMD با آن‌ها استدلال کند. اگر این نوع‌ها جنریک باشند، این خطا رخ می‌دهد.

    این کد باعث خطا می‌شود:

    #![feature(repr_simd)]

#[repr(simd)]
struct Bad<T>([T; 4]);

    اما این کد خطا نمی‌دهد:

    #![feature(repr_simd)]

#[repr(simd)]
struct Good([u32; 4]);
