راهنمای خطاهای کامپایلرCompiler Error Index

    ارزیابی یک مقدار ثابت با شکست مواجه شد.

    نمونه کد دارای خطا:

    enum Enum {
    X = (1 << 500),
    Y = (1 / 0),
}

    این خطا نشان می‌دهد که کامپایلر نتوانسته است یک عبارت ثابت را که باید ارزیابی می‌شد، به‌درستی ارزیابی کند. تقسیم بر ۰ یا ایجاد سرریز عدد صحیح دو راه برای ایجاد این خطا هستند.

    مطمئن شوید عبارت‌های داده‌شده می‌توانند به‌عنوان نوع عدد صحیح مورد نظر ارزیابی شوند.

    برای اطلاعات بیشتر دربارهٔ تعیین نوع‌های عدد صحیح سفارشی روی شمارش‌ها با استفاده از attribute repr، بخش Discriminants در Reference را ببینید.
