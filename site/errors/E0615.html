راهنمای خطاهای کامپایلرCompiler Error Index

    تلاش شده است به یک متد مانند یک فیلد دسترسی پیدا شود.

    نمونهٔ کد دارای خطا:

    struct Foo {
    x: u32,
}

impl Foo {
    fn method(&self) {}
}

let f = Foo { x: 0 };
f.method; // error: attempted to take value of method `method` on type `Foo`

    اگر می‌خواهید از یک متد استفاده کنید، بعد از آن () اضافه کنید:

    # struct Foo { x: u32 }
# impl Foo { fn method(&self) {} }
# let f = Foo { x: 0 };
f.method();

    اما اگر می‌خواستید به یک فیلد از ساختار دسترسی پیدا کنید، بررسی کنید که نام فیلد درست نوشته شده باشد. مثال:

    # struct Foo { x: u32 }
# impl Foo { fn method(&self) {} }
# let f = Foo { x: 0 };
println!("{}", f.x);
