راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود.

    در Rust 1.3 انتظار می‌رود که کران‌های پیش‌فرض طول عمر شیء (default object lifetime bounds) تغییر کنند، همان‌طور که در RFC 1156 توضیح داده شده است. این هشدار را دریافت می‌کنید چون کامپایلر تشخیص می‌دهد که ممکن است این تغییر در کد شما باعث خطای کامپایل شود. ممکن است، هرچند بعید است، که این یک هشدار اشتباه باشد.

    اصل تغییر این است که جایی که &'a Box<SomeTrait> پیش‌تر به‌طور پیش‌فرض &'a Box<SomeTrait+'a> بود، اکنون پیش‌فرض آن &'a Box<SomeTrait+'static> است (در اینجا SomeTrait نام یک نوع صفت است). توجه کنید که تنها انواعی که تحت تأثیر قرار می‌گیرند ارجاع‌هایی به box هستند، مانند &Box<SomeTrait> یا &[Box<SomeTrait>]. انواع رایج‌تر مانند &SomeTrait یا Box<SomeTrait> تحت تأثیر قرار نمی‌گیرند.

    برای خاموش کردن این هشدار، کد خود را طوری ویرایش کنید که از یک کران صریح استفاده کند. در بیشتر موارد، این یعنی باید امضای تابعی را که فراخوانی می‌کنید تغییر دهید. برای مثال، اگر خطا روی فراخوانی‌ای مانند foo(x) گزارش شود و foo به این شکل تعریف شده باشد:

    # trait SomeTrait {}
fn foo(arg: &Box<SomeTrait>) { /* ... */ }

    می‌توانید آن را به این تغییر دهید:

    # trait SomeTrait {}
fn foo<'a>(arg: &'a Box<SomeTrait+'a>) { /* ... */ }

    این به‌صراحت بیان می‌کند که انتظار دارید شیء صفت SomeTrait شامل ارجاع‌هایی باشد (با حداکثر طول عمر 'a).
