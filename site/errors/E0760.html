راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود.

    نوع بازگشتی async fn یا impl trait نمی‌تواند شامل یک projection یا Self باشد که به طول عمرهای یک scope والد ارجاع می‌دهد.

    مثال کدی که خطا می‌دهد:

    struct S<'a>(&'a i32);

impl<'a> S<'a> {
    async fn new(i: &'a i32) -> Self {
        S(&22)
    }
}

    برای رفع این خطا باید Self را به‌صورت صریح به S<'a> بنویسیم:

    struct S<'a>(&'a i32);

impl<'a> S<'a> {
    async fn new(i: &'a i32) -> S<'a> {
        S(&22)
    }
}

    این کار در آینده مجاز خواهد شد، اما پیاده‌سازی آن هنوز کامل نیست. درباره این محدودیت به issue-61949 مراجعه کنید.
