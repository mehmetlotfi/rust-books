راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: کامپایلر دیگر این کد خطا را صادر نمی‌کند.

    تعداد آرگومان‌های نوع داده‌شده به یک تابع کمتر از حد لازم بوده است. برای مثال:

    fn foo<T, U>() {}

fn main() {
    foo::<f64>(); // error: wrong number of type arguments: expected 2, found 1
}

    توجه کنید که اگر تابعی چند آرگومان نوع می‌گیرد اما می‌خواهید کامپایلر برخی از آن‌ها را استنتاج کند، می‌توانید از جایگزین‌های نوع (type placeholder) استفاده کنید:

    fn foo<T, U>(x: T) {}

fn main() {
    let x: bool = true;
    foo::<f64>(x);    // error: wrong number of type arguments:
                      //        expected 2, found 1
    foo::<_, f64>(x); // same as `foo::<bool, f64>(x)`
}
