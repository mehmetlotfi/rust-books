راهنمای خطاهای کامپایلرCompiler Error Index

    هنگام استفاده از attribute #[simd]، عنصر یک ساختار تاپلی از نوع ماشین (machine type) نیست.

    نمونه کد دارای خطا:

    #![feature(repr_simd)]

#[repr(simd)]
struct Bad([String; 2]); // error!

    هنگام استفاده از attribute #[simd] روی یک ساختار تاپلی، عناصر تاپل باید از نوع‌های ماشین باشند تا بتوان عملیات SIMD را روی آن‌ها اعمال کرد.

    نمونهٔ اصلاح‌شده:

    #![feature(repr_simd)]

#[repr(simd)]
struct Good([u32; 4]); // ok!
