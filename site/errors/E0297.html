راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود.

    الگوهایی که برای متصل کردن نام‌ها به کار می‌روند باید رد‌ناپذیر (irrefutable) باشند. یعنی باید تضمین کنند که در همه حالت‌ها یک نام استخراج می‌شود. به‌جای الگو‌دادن به متغیر حلقه، استفاده از match یا if let درون بدنه حلقه را در نظر بگیرید. برای مثال:

    let xs : Vec<Option<i32>> = vec![Some(1), None];

// This fails because `None` is not covered.
for Some(x) in xs {
    // ...
}

    به‌جای آن درون حلقه از match استفاده کنید:

    let xs : Vec<Option<i32>> = vec![Some(1), None];

for item in xs {
    match item {
        Some(x) => {},
        None => {},
    }
}

    یا از if let استفاده کنید:

    let xs : Vec<Option<i32>> = vec![Some(1), None];

for item in xs {
    if let Some(x) = item {
        // ...
    }
}
