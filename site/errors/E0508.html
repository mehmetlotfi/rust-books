    یک مقدار از یک آرایه با اندازهٔ ثابت و غیر copy به بیرون منتقل شده است.

    نمونه کد خطادار:

    struct NonCopy;

fn main() {
    let array = [NonCopy; 1];
    let _value = array[0]; // error: cannot move out of type `[NonCopy; 1]`,
                           //        a non-copy fixed-size array
}

    اولین عنصر از آرایه منتقل (move) شده است، اما این کار ممکن نیست زیرا NonCopy صفت Copy را پیاده‌سازی نمی‌کند.

    به‌جای انتقال عنصر، آن را قرض بگیرید:

    struct NonCopy;

fn main() {
    let array = [NonCopy; 1];
    let _value = &array[0]; // Borrowing is allowed, unlike moving.
}

    از طرف دیگر، اگر نوع شما Clone را پیاده‌سازی می‌کند و نیاز دارید مالک مقدار باشید، می‌توانید عنصر را قرض بگیرید و سپس آن را clone کنید:

    #[derive(Clone)]
struct NonCopy;

fn main() {
    let array = [NonCopy; 1];
    // Now you can clone the array element.
    let _value = array[0].clone();
}

    اگر واقعاً می‌خواهید مقدار را به بیرون منتقل کنید، می‌توانید با استفاده از یک الگوی آرایه‌ای تجزیه‌کننده (destructuring) آن را منتقل کنید:

    struct NonCopy;

fn main() {
    let array = [NonCopy; 1];
    // Destructuring the array
    let [_value] = array;
}
