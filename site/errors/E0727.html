    عبارت yield در یک بافتار async به کار رفته بود.

    نمونه کد خطادار:

    #![feature(coroutines, stmt_expr_attributes)]

fn main() {
    let coroutine = #[coroutine] || {
        async {
            yield;
        }
    };
}

    در این‌جا کلیدواژه yield درون یک بلوک async استفاده شده است، که هنوز پشتیبانی نمی‌شود.

    برای رفع این خطا، باید yield را از بلوک async بیرون ببرید:

    #![feature(coroutines, stmt_expr_attributes)]

fn main() {
    let coroutine = #[coroutine] || {
        yield;
    };
}
