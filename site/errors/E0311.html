راهنمای خطاهای کامپایلرCompiler Error Index

    این خطا زمانی رخ می‌دهد که یک کران outlives برآورده‌نشده شامل یک ناحیه‌ی حذف‌شده (elided region) و یک پارامتر نوع جنریک یا نوع وابسته باشد.

    نمونه کد خطادار:

    fn no_restriction<T>(x: &()) -> &() {
    with_restriction::<T>(x)
}

fn with_restriction<'a, T: 'a>(x: &'a ()) -> &'a () {
    x
}

    چرا این کد کامپایل نمی‌شود؟ نگاه به کران‌های طول عمری که کامپایلر به‌طور خودکار اضافه می‌کند کمک می‌کند. برای جزئیات بیشتر مستندات lifetime elision را ببینید.

    کامپایلر طول عمر x و نوع بازگشتی را در no_restriction() به یک طول عمر دلخواه 'anon حذف می‌کند. تنها اطلاعاتی که در اختیار کامپایلر است این است که 'anon در طول اجرای تابع معتبر است. هنگام فراخوانی with_restriction()، کامپایلر به‌دلیل کران T: 'a در with_restriction() الزام می‌کند که پارامتر نوع کاملاً نامرتبط T بیشتر از 'anon زنده بماند. این موضوع باعث خطا می‌شود، زیرا در no_restriction() هیچ الزامی وجود ندارد که T بیشتر از 'anon زنده بماند.

    اگر no_restriction() به‌جای &() از &T به‌عنوان آرگومان استفاده می‌کرد، کامپایلر یک کران ضمنی اضافه می‌کرد و این کد کامپایل می‌شد.

    این خطا را می‌توان با نام‌گذاری صریح طول عمر حذف‌شده‌ی x و سپس الزام صریح این‌که پارامتر جنریک T بیشتر از آن طول عمر زنده بماند، برطرف کرد:

    fn no_restriction<'a, T: 'a>(x: &'a ()) -> &'a () {
    with_restriction::<T>(x)
}

fn with_restriction<'a, T: 'a>(x: &'a ()) -> &'a () {
    x
}
