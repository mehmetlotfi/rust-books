راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود.

    در Rust محدودیت‌های مختلفی برای تبدیل (transmute) بین نوع‌ها وجود دارد؛ برای مثال، نوع‌هایی که transmute می‌شوند باید اندازهٔ یکسانی داشته باشند. برای اعمال همهٔ این محدودیت‌ها، کامپایلر باید نوع‌های دقیقی را که ممکن است transmute شوند بداند. وقتی پارامترهای نوع در میان باشند، این کار همیشه شدنی نیست.

    بنابراین، برای مثال، کد زیر مجاز نیست:

    use std::mem::transmute;

struct Foo<T>(Vec<T>);

fn foo<T>(x: Vec<T>) {
    // we are transmuting between Vec<T> and Foo<F> here
    let y: Foo<T> = unsafe { transmute(x) };
    // do something with y
}

    در این مورد خاص، احتمال زیادی وجود دارد که transmute بی‌خطر باشد (اما Rust این را تضمین نمی‌کند). با این حال، وقتی ترازبندی (alignment) و بهینه‌سازی‌های enum به میان می‌آید، بسیار محتمل است که اندازه‌ها بسته به نمونه‌سازی‌های مختلف پارامتر نوع با هم برابر باشند یا نباشند. بررسی این موضوع برای همهٔ نوع‌های ممکن شدنی نیست، بنابراین transmute() فقط نوع‌هایی را می‌پذیرد که هیچ پارامتر نوع نمونه‌سازی‌نشده‌ای ندارند.

    اگر به این کار نیاز دارید، احتمال زیادی وجود دارد که در حال انجام کاری نادرست باشید. به یاد داشته باشید که Rust چندان تضمینی درباره چیدمان (layout) ساختارهای مختلف نمی‌دهد (حتی دو ساختار با اعلان‌های یکسان ممکن است چیدمان‌های متفاوتی داشته باشند). اگر راه‌حلی وجود دارد که اصلاً transmute را کنار بگذارد، آن را امتحان کنید.

    اگر ممکن است، کد را به‌صورت دستی تک‌ریخت (monomorphize) کنید، یعنی تابع را برای هر نمونه‌سازی ممکن از نوع بنویسید. می‌توان با استفاده از صفت‌ها (traits) این کار را به‌صورت تمیز انجام داد، برای مثال:

    use std::mem::transmute;

struct Foo<T>(Vec<T>);

trait MyTransmutableType: Sized {
    fn transmute(_: Vec<Self>) -> Foo<Self>;
}

impl MyTransmutableType for u8 {
    fn transmute(x: Vec<u8>) -> Foo<u8> {
        unsafe { transmute(x) }
    }
}

impl MyTransmutableType for String {
    fn transmute(x: Vec<String>) -> Foo<String> {
        unsafe { transmute(x) }
    }
}

// ... more impls for the types you intend to transmute

fn foo<T: MyTransmutableType>(x: Vec<T>) {
    let y: Foo<T> = <T as MyTransmutableType>::transmute(x);
    // do something with y
}

    اندازهٔ هر impl در transmute مثل همیشه از نظر تطابق بررسی می‌شود و چون هیچ پارامتر نوع آزادی در کار نیست، این کد باید کامپایل شود مگر آنکه در یکی از impl‌ها عدم تطابق اندازه وجود داشته باشد.

    همچنین می‌توان transmute را به‌صورت دستی انجام داد:

    # use std::ptr;
# let v = Some("value");
# type SomeType = &'static [u8];
unsafe {
    ptr::read(&v as *const _ as *const SomeType) // `v` transmuted to `SomeType`
}
# ;

    توجه کنید که این کار (برخلاف transmute) مقدار v را move نمی‌کند و اگر می‌خواهید از فراخوانی destructorها جلوگیری کنید، ممکن است نیاز به فراخوانی mem::forget(v) داشته باشد.
