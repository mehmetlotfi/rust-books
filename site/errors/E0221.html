راهنمای خطاهای کامپایلرCompiler Error Index

    تلاش برای دستیابی به یک نوع وابسته انجام شده است، اما نوع مبهم بود.

    نمونه کد دارای خطا:

    trait T1 {}
trait T2 {}

trait Foo {
    type A: T1;
}

trait Bar : Foo {
    type A: T2;
    fn do_something() {
        let _: Self::A;
    }
}

    در این مثال، Foo یک نوع وابسته A تعریف می‌کند. Bar آن نوع را از Foo به ارث می‌برد و نوع وابسته دیگری با همین نام تعریف می‌کند. در نتیجه، وقتی می‌خواهیم از Self::A استفاده کنیم، مشخص نیست که منظور A تعریف‌شده در Foo است یا آن‌که در Bar تعریف شده است.

    برای دور زدن این مشکل دو راه وجود دارد. راه اول این است که نام یکی از نوع‌ها را تغییر دهیم. راه دیگر این است که نوع مورد نظر را با نحو زیر مشخص کنیم:

    trait T1 {}
trait T2 {}

trait Foo {
    type A: T1;
}

trait Bar : Foo {
    type A: T2;
    fn do_something() {
        let _: <Self as Bar>::A;
    }
}
