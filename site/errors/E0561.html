راهنمای خطاهای کامپایلرCompiler Error Index

    یک الگوی غیر-شناسه (non-ident) یا غیر-wildcard به‌عنوان پارامتر یک نوع اشاره‌گر تابع (function pointer) استفاده شده است.

    نمونه‌ی کد خطادار:

    type A1 = fn(mut param: u8); // error!
type A2 = fn(&param: u32); // error!

    هنگام استفاده از یک نام مستعار (alias) برای یک نوع تابع، برای مثال نمی‌توانید یک پارامتر را قابل‌تغییر (mutable) تعیین کنید.

    برای رفع مشکل، الگوها را حذف کنید (البته _ مجاز است). نمونه:

    type A1 = fn(param: u8); // ok!
type A2 = fn(_: u32); // ok!

    همچنین می‌توانید نام پارامتر را کاملاً حذف کنید:

    type A3 = fn(i16); // ok!
