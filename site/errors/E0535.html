راهنمای خطاهای کامپایلرCompiler Error Index

    نکته: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود

    دلیلش این است که این خطا بیش از حد مختص attribute به نام inline بود. برای سایر attributeها نیز تشخیص‌های مشابهی وجود دارد. نمونه‌ی این‌جا اکنون E0539 را صادر می‌کند.

    نمونه‌ی کد خطادار:

    #[inline(unknown)] // error: invalid argument
pub fn something() {}

fn main() {}

    attribute به نام inline تنها دو آرگومان را پشتیبانی می‌کند:

    • always
    • never

    هر آرگومان دیگری که به attribute به نام inline داده شود، این خطا را برمی‌گرداند. نمونه:

    #[inline(never)] // ok!
pub fn something() {}

fn main() {}

    برای اطلاعات بیشتر، بخش attribute به نام inline را در Reference ببینید.
