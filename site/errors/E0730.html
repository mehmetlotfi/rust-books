راهنمای خطاهای کامپایلرCompiler Error Index

    الگوی تطبیق (pattern matching) روی آرایه‌ای بدون طول ثابت انجام شده بود.

    برای رفع این خطا دو راه‌حل دارید:

    fn is_123<const N: usize>(x: [u32; N]) -> bool {
    match x {
        [1, 2, ..] => true, // error: cannot pattern-match on an
                            //        array without a fixed length
        _ => false
    }
}

    از آرایه‌ای با طول ثابت استفاده کنید.

    1. از یک slice استفاده کنید.
    2. از یک slice استفاده کنید.

    مثال با آرایه‌ای با طول ثابت:

    fn is_123(x: [u32; 3]) -> bool { // We use an array with a fixed size
    match x {
        [1, 2, ..] => true, // ok!
        _ => false
    }
}

    مثال با slice:

    fn is_123(x: &[u32]) -> bool { // We use a slice
    match x {
        [1, 2, ..] => true, // ok!
        _ => false
    }
}
