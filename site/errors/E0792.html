راهنمای خطاهای کامپایلرCompiler Error Index

    در یک type alias impl trait، نوع پنهان تنها زمانی می‌تواند مقداردهی شود که به‌صورت کاملاً جنریک (و در محدوده تعریف‌کننده‌اش) به کار رود. یعنی

    #![feature(type_alias_impl_trait)]

type Foo<T> = impl std::fmt::Debug;

#[define_opaque(Foo)]
fn foo() -> Foo<u32> {
    5u32
}

    پذیرفته نمی‌شود. اگر پذیرفته می‌شد، می‌شد شرایط ناایمنی مانند مورد زیر ساخت

    #![feature(type_alias_impl_trait)]

type Foo<T> = impl Default;

#[define_opaque(Foo)]
fn foo() -> Foo<u32> {
    5u32
}

fn main() {
    let x = Foo::<&'static mut String>::default();
}

    در عوض باید تابع را جنریک کنید:

    #![feature(type_alias_impl_trait)]

type Foo<T> = impl std::fmt::Debug;

#[define_opaque(Foo)]
fn foo<U>() -> Foo<U> {
    5u32
}

fn main() {}

    این یعنی صرف‌نظر از پارامتر جنریک foo، نوع پنهان همیشه u32 خواهد بود. اگر بخواهید پارامتر جنریک را به نوع پنهان پیوند دهید، این کار هم ممکن است:

    #![feature(type_alias_impl_trait)]

use std::fmt::Debug;

type Foo<T: Debug> = impl Debug;

#[define_opaque(Foo)]
fn foo<U: Debug>() -> Foo<U> {
    Vec::<U>::new()
}

fn main() {}
