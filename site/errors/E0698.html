راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود.

    هنگام استفاده از coroutineها (یا async) همه‌ی متغیرهای نوع باید مقید شوند تا بتوان یک coroutine ساخت.

    نمونه کد خطادار:

    async fn bar<T>() -> () {}

async fn foo() {
    bar().await; // error: cannot infer type for `T`
}

    در مثال بالا، کامپایلر نمی‌تواند T را تشخیص دهد. برای رفع این مشکل باید T را به یک نوع مشخص مانند String مقید کنید تا بتوان یک coroutine ساخت:

    async fn bar<T>() -> () {}

async fn foo() {
    bar::<String>().await;
    //   ^^^^^^^^ specify type explicitly
}
