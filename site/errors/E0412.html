راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود.

    نمونه‌های کد خطادار:

    impl Something {} // error: type name `Something` is not in scope

// or:

trait Foo {
    fn bar(N); // error: type name `N` is not in scope
}

// or:

fn foo(x: T) {} // type name `T` is not in scope

    برای رفع این خطا، لطفاً بررسی کنید که نام نوع را اشتباه ننوشته باشید و آن را تعریف کرده یا به حوزه (scope) وارد (import) کرده باشید. مثال‌ها:

    struct Something;

impl Something {} // ok!

// or:

trait Foo {
    type N;

    fn bar(_: Self::N); // ok!
}

// or:

fn foo<T>(x: T) {} // ok!

    حالت دیگری که باعث این خطا می‌شود زمانی است که یک نوع در ماژول والد وارد شده باشد. برای رفع آن می‌توانید از پیشنهاد کامپایلر پیروی کنید و File را مستقیماً استفاده کنید یا از use super::File; استفاده کنید که نوع‌ها را از فضای نام والد وارد می‌کند. نمونه‌ای که باعث این خطا می‌شود در ادامه آمده است:

    use std::fs::File;

mod foo {
    fn some_function(f: File) {}
}

    use std::fs::File;

mod foo {
    // either
    use super::File;
    // or
    // use std::fs::File;
    fn foo(f: File) {}
}
# fn main() {} // don't insert it for us; that'll break imports
