راهنمای خطاهای کامپایلرCompiler Error Index

    نکته: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود.

    گزاره‌ی cfg به نام not ناقص‌نوشته (malformed) بود.

    نمونه‌ی کد خطادار (با استفاده از cargo doc):

    #![feature(doc_cfg)]
#[doc(cfg(not()))]
pub fn main() {

}

    گزاره‌ی not یک الگوی cfg انتظار دارد. نمونه:

    #![feature(doc_cfg)]
#[doc(cfg(not(target_os = "linux")))] // ok!
pub fn main() {

}

    برای اطلاعات بیشتر درباره‌ی ماکروی cfg، بخش کامپایل شرطی را در Reference بخوانید.
