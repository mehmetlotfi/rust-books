راهنمای خطاهای کامپایلرCompiler Error Index

    هنگام پیاده‌سازی یک صفت (trait)، نوع وابسته‌ای به‌کار رفته که نامش با هیچ‌یک از نوع‌های وابسته صفت مطابقت ندارد.

    نمونه کد خطادار:

    trait Foo {}

impl Foo for i32 {
    type Bar = bool;
}

    پیاده‌سازی‌های صفت فقط می‌توانند نوع‌های وابسته‌ای را پیاده‌سازی کنند که عضو صفت موردنظر باشند.

    راه‌حل این مشکل حذف نوع وابسته اضافی است:

    trait Foo {}

impl Foo for i32 {}
