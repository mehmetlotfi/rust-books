راهنمای خطاهای کامپایلرCompiler Error Index

    نامی به‌کار رفته که قابل تشخیص (resolve) نیست.

    نمونه‌های کد خطادار:

    something_that_doesnt_exist::foo;
// error: unresolved name `something_that_doesnt_exist::foo`

// or:

trait Foo {
    fn bar() {
        Self; // error: unresolved name `Self`
    }
}

// or:

let x = unknown_variable;  // error: unresolved name `unknown_variable`

    لطفاً بررسی کنید که نام اشتباه نوشته نشده باشد و مطمئن شوید که شناسه موردنظر برای موقعیت داده‌شده معتبر است. مثال:

    enum something_that_does_exist {
    Foo,
}

    یا:

    mod something_that_does_exist {
    pub static foo : i32 = 0i32;
}

something_that_does_exist::foo; // ok!

    یا:

    let unknown_variable = 12u32;
let x = unknown_variable; // ok!

    اگر آیتم در ماژول فعلی تعریف نشده است، باید با یک دستور use وارد (import) شود، مانند:

    # mod foo { pub fn bar() {} }
# fn main() {
use foo::bar;
bar();
# }

    اگر آیتمی که وارد می‌کنید در هیچ‌یک از ماژول‌های والای ماژول فعلی تعریف نشده باشد، باید به‌صورت عمومی (public) نیز اعلام شود (مثلاً pub fn).
