    یک پیاده‌سازی ذاتی (inherent) به‌صورت unsafe علامت‌گذاری شده است.

    نمونه کد دارای خطا:

    struct Foo;

unsafe impl Foo { } // error!

    پیاده‌سازی‌های ذاتی (پیاده‌سازی‌هایی که صفتی را پیاده نمی‌کنند و فقط متدهای مرتبط با یک نوع را فراهم می‌کنند) همیشه ایمن هستند، زیرا هیچ صفت unsafeای را پیاده‌سازی نمی‌کنند. حذف کلیدواژه unsafe از پیاده‌سازی ذاتی این خطا را برطرف می‌کند.

    struct Foo;

impl Foo { } // ok!
