راهنمای خطاهای کامپایلرCompiler Error Index

    یک attribute بررسی lint توسط دستور forbid که به‌صورت attribute روی یک دامنه (scope) بیرونی، یا با گزینه -F در خط فرمان تنظیم شده بود، نادیده گرفته شد.

    نمونه کد دارای خطا:

    #![forbid(non_snake_case)]

#[allow(non_snake_case)]
fn main() {
    // error: allow(non_snake_case) incompatible with previous forbid
    let MyNumber = 2;
}

    تنظیم forbid مانند deny، هشدار متناظر کامپایلر را به یک خطای سخت تبدیل می‌کند. برخلاف deny، تنظیم forbid از بازنویسی شدن توسط attributeهای درونی جلوگیری می‌کند.

    اگر مطمئن هستید که می‌خواهید بررسی lint را بازنویسی کنید، می‌توانید forbid را به deny تغییر دهید (یا اگر forbid با گزینه خط فرمان داده شده بود، به‌جای -F از -D استفاده کنید) تا attribute درونی بررسی lint مجاز شود:

    #![deny(non_snake_case)]

#[allow(non_snake_case)]
fn main() {
    let MyNumber = 2; // ok!
}

    در غیر این صورت، کد را طوری ویرایش کنید که بررسی lint را پشت سر بگذارد و attributeی را که بازنویسی شده بود حذف کنید:

    #![forbid(non_snake_case)]

fn main() {
    let my_number = 2;
}
