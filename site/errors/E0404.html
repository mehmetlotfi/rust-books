راهنمای خطاهای کامپایلرCompiler Error Index

    نوعی که صفت (trait) نیست در جایی به کار رفته که انتظار صفت می‌رود، مانند یک قید (bound) یا impl.

    نمونه کد خطادار:

    struct Foo;
struct Bar;

impl Foo for Bar {} // error: `Foo` is not a trait
fn baz<T: Foo>(t: T) {} // error: `Foo` is not a trait

    نمونه کد خطادار دیگر:

    type Foo = Iterator<Item=String>;

fn bar<T: Foo>(t: T) {} // error: `Foo` is a type alias

    لطفاً بررسی کنید که نام صفت اشتباه نوشته نشده باشد یا شناسه درست استفاده شده باشد. مثال:

    trait Foo {
    // some functions
}
struct Bar;

impl Foo for Bar { // ok!
    // functions implementation
}

fn baz<T: Foo>(t: T) {} // ok!

    به‌عنوان جایگزین، می‌توانید یک صفت جدید با محدودیت‌های موردنظرتان به‌عنوان صفت والا (super trait) تعریف کنید:

    # trait Foo {}
# struct Bar;
# impl Foo for Bar {}
trait Qux: Foo {} // Anything that implements Qux also needs to implement Foo
fn baz<T: Qux>(t: T) {} // also ok!

    در نهایت، اگر از نسخه nightly استفاده می‌کنید و می‌خواهید به‌جای نام مستعار نوع (type alias) از نام مستعار صفت (trait alias) استفاده کنید، باید از #![feature(trait_alias)] استفاده کنید:

    #![feature(trait_alias)]
trait Foo = Iterator<Item=String>;

fn bar<T: Foo>(t: T) {} // ok!
