راهنمای خطاهای کامپایلرCompiler Error Index

    پارامتر self در یک متد دارای «نوع گیرنده» (receiver type) نامعتبر است.

    نمونه کد خطادار:

    struct Foo;
struct Bar;

trait Trait {
    fn foo(&self);
}

impl Trait for Foo {
    fn foo(self: &Bar) {}
}

    متدها یک پارامتر اول ویژه می‌گیرند که سه شکل دارد: self، &self و &mut self. این‌ها به‌ترتیب شکل‌های خلاصه‌نویسی‌شده‌ی self: Self، self: &Self و self: &mut Self هستند.

    # struct Foo;
trait Trait {
    fn foo(&self);
//         ^^^^^ `self` here is a reference to the receiver object
}

impl Trait for Foo {
    fn foo(&self) {}
//         ^^^^^ the receiver type is `&Foo`
}

    نوع Self به‌عنوان نام مستعاری برای نوعِ پیاده‌ساز فعلیِ صفت یا همان «نوع گیرنده» عمل می‌کند. علاوه بر Self، &Self و &mut Self که پیش‌تر گفته شد و انواع گیرنده‌ی معتبر هستند، موارد زیر نیز معتبرند: self: Box<Self>، self: Rc<Self>، self: Arc<Self> و self: Pin<P> (که در آن P یکی از انواع قبلی به‌جز Self است). توجه کنید که Self می‌تواند نوع پیاده‌ساز زیرین نیز باشد، مانند Foo در مثال زیر:

    # struct Foo;
# trait Trait {
#     fn foo(&self);
# }
impl Trait for Foo {
    fn foo(self: &Foo) {}
}

    کامپایلر هنگام استفاده از نوع گیرنده‌ی نامعتبر، این خطا را صادر می‌کند، مانند مثال زیر:

    # struct Foo;
# struct Bar;
# trait Trait {
#     fn foo(&self);
# }
impl Trait for Foo {
    fn foo(self: &Bar) {}
}

    قابلیت nightly با نام Arbitrary self types مجموعه‌ی انواع گیرنده‌ی پذیرفته‌شده را گسترش می‌دهد تا هر نوعی را که صفت Receiver را پیاده‌سازی می‌کند و می‌تواند زنجیره‌ی انواع Target خود را تا Self دنبال کند نیز شامل شود. یک پیاده‌سازی فراگیر (blanket implementation) از Receiver برای T: Deref وجود دارد، بنابراین هر نوعی که به Self ارجاع‌زدایی شود قابل استفاده است.

    #![feature(arbitrary_self_types)]

struct Foo;
struct Bar;

// Because you can dereference `Bar` into `Foo`...
impl std::ops::Deref for Bar {
    type Target = Foo;

    fn deref(&self) -> &Foo {
        &Foo
    }
}

impl Foo {
    fn foo(self: Bar) {}
//         ^^^^^^^^^ ...it can be used as the receiver type
}
