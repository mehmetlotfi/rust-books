    هنگام فراخوانی یک closure، تعداد نامعتبری آرگومان داده شده است.

    نمونه کد نادرست:

    let f = |x| x * 3;
let a = f();        // invalid, too few parameters
let b = f(4);       // this works!
let c = f(2, 3);    // invalid, too many parameters

    هنگام فراخوانی closureها یا سایر پیاده‌سازی‌های traitهای تابع یعنی Fn، FnMut یا FnOnce با نشانه‌گذاری فراخوانی، تعداد پارامترهای ارسال‌شده به تابع باید با تعریف آن مطابقت داشته باشد.

    با یک تابع جنریک نیز باید به‌طور مشابه رفتار شود:

    fn foo<F: Fn()>(f: F) {
    f(); // this is valid, but f(3) would not work
}
