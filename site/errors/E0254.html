راهنمای خطاهای کامپایلرCompiler Error Index

    تلاش شده است آیتمی وارد شود، در حالی که یک extern crate با همین نام پیش‌تر وارد شده است.

    کد دارای خطا:

    extern crate core;

mod foo {
    pub trait core {
        fn do_something();
    }
}

use foo::core;  // error: an extern crate named `core` has already
                //        been imported in this module

fn main() {}

    برای رفع این مشکل باید نام دست‌کم یکی از دو import را تغییر دهید. مثال:

    extern crate core as libcore; // ok!

mod foo {
    pub trait core {
        fn do_something();
    }
}

use foo::core;

fn main() {}
