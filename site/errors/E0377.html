راهنمای خطاهای کامپایلرCompiler Error Index

    CoerceUnsized یا DispatchFromDyn را فقط می‌توان بین ساختارهایی از یک نوع یکسان پیاده‌سازی کرد.

    نمونه کد خطادار:

    #![feature(coerce_unsized)]
use std::ops::CoerceUnsized;

pub struct Foo<T: ?Sized> {
    field_with_unsized_type: T,
}

pub struct Bar<T: ?Sized> {
    field_with_unsized_type: T,
}

// error: the trait `CoerceUnsized` may only be implemented for a coercion
//        between structures with the same definition
impl<T, U> CoerceUnsized<Bar<U>> for Foo<T> where T: CoerceUnsized<U> {}

    CoerceUnsized برای تبدیل ساختارهایی استفاده می‌شود که فیلدی دارند که می‌تواند بدون اندازه (unsized) شود، مانند یک MyBox<T> سفارشی که به MyBox<dyn Trait> تبدیل unsized می‌شود. DispatchFromDyn برای توزیع (dispatch) از MyBox<dyn Trait> به MyBox<Self> در یک صفت سازگار با dyn (dyn-compatible) به‌کار می‌رود.

    کامپایلر از تبدیل بین ساختارهایی با نوع‌های متفاوت پشتیبانی نمی‌کند؛ بنابراین یک پیاده‌سازی معتبر از CoerceUnsized یا DispatchFromDyn باید بین یک ساختار یکسان با پارامترهای جنریک متفاوت نوشته شود.

    توجه کنید که CoerceUnsized و DispatchFromDyn عمدتاً توسط اشاره‌گرهای هوشمند مانند Box، Rc و Arc استفاده می‌شوند تا بتوانند مشخص کنند که انواع unsized مورد اشاره خود را می‌توانند تبدیل کنند.
