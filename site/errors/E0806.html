راهنمای خطاهای کامپایلرCompiler Error Index

    یک آیتم قابل‌پیاده‌سازی از بیرون (externally implementable item) با اعلان خود سازگار نیست.

    مثال کد خطادار:

    #![feature(extern_item_impls)]

#[eii(foo)]
fn x();

#[foo]
fn y(a: u64) -> u64 {
//~^ ERROR E0806
    a
}


fn main() {}

    علت خطا در اینجا این است که y آیتم قابل‌پیاده‌سازی از بیرون به نام foo را پیاده‌سازی می‌کند. این کار تنها زمانی ممکن است که امضای پیاده‌سازی y با امضای اعلان foo یکسان باشد. بنابراین برای رفع آن، امضای y باید طوری تغییر کند که با امضای x مطابقت داشته باشد:

    #![feature(extern_item_impls)]

#[eii(foo)]
fn x();

#[foo]
fn y() {}


fn main() {}

    یکی از شایع‌ترین راه‌هایی که این خطا رخ می‌دهد، استفاده از امضای نادرست برای #[panic_handler] است. امضا توسط core ارائه می‌شود.

    #![no_std]

#[panic_handler]
fn on_panic() -> ! {
//~^ ERROR E0806

    loop {}
}

fn main() {}

    شکل درست:

    #![no_std]

#[panic_handler]
fn on_panic(info: &core::panic::PanicInfo<'_>) -> ! {
    loop {}
}

fn main() {}
    → E0805
