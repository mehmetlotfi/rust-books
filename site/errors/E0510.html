راهنمای خطاهای کامپایلرCompiler Error Index

    مقدار مورد تطبیق در یک guard مربوط به match مقداردهی شده است.

    نمونه کد خطادار:

    let mut x = Some(0);
match x {
    None => {}
    Some(_) if { x = None; false } => {} // error!
    Some(_) => {}
}

    هنگامی که روی یک متغیر match انجام می‌شود، نمی‌توان آن را در guardهای match تغییر داد، زیرا این کار می‌تواند باعث شود match جامع (exhaustive) نباشد.

    در اینجا اجرای x = None مقداری را که در حال تطبیق است تغییر می‌دهد و ما را مجبور می‌کند «به گذشته برگردیم» و به شاخهٔ None بازگردیم. برای رفع این مشکل، مقدار را در داخل شاخهٔ match تغییر دهید:

    let mut x = Some(0);
match x {
    None => {}
    Some(_) => {
        x = None; // ok!
    }
}
