راهنمای خطاهای کامپایلرCompiler Error Index

    این کد خطا داخلی کامپایلر است و با کد معمولی Rust صادر نمی‌شود.

    attribute داخلی rustc_allowed_through_unstable_modules باید روی آیتمی به کار رود که attribute با نام stable دارد.

    مثال کدی که خطا می‌دهد:

    // NOTE: both of these attributes are perma-unstable and should *never* be
//       used outside of the compiler and standard library.
#![feature(rustc_attrs)]
#![feature(staged_api)]
#![allow(internal_features)]

#![unstable(feature = "foo_module", reason = "...", issue = "123")]

#[rustc_allowed_through_unstable_modules(
    message = "deprecation message",
    module = "stable_module",
)]
// #[stable(feature = "foo", since = "1.0")]
struct Foo;
// ^^^ error: `rustc_allowed_through_unstable_modules` attribute must be
//            paired with a `stable` attribute

    معمولاً وقتی آیتمی با attribute با نام stable علامت‌گذاری می‌شود، ماژول‌هایی که آن آیتم را در بر گرفته‌اند نیز باید با attributeهای stable علامت‌گذاری شوند؛ در غیر این صورت آیتم عملاً (de facto) ناپایدار می‌شود. #[rustc_allowed_through_unstable_modules] راه‌حلی موقت است که به یک آیتم اجازه می‌دهد از ماژول‌های والد ناپایدار خود «فرار» کند. این خطا زمانی رخ می‌دهد که آیتمی با #[rustc_allowed_through_unstable_modules] علامت‌گذاری شده باشد اما attribute مکمل stable وجود نداشته باشد. برای نمونه‌ای از کاربرد #[rustc_allowed_through_unstable_modules]، به #99288 نگاه کنید.
