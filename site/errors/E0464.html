راهنمای خطاهای کامپایلرCompiler Error Index

    کامپایلر چند فایل کتابخانه با نام crate درخواست‌شده پیدا کرد.

    // aux-build:crateresolve-1.rs
// aux-build:crateresolve-2.rs
// aux-build:crateresolve-3.rs

extern crate crateresolve;
//~^ ERROR multiple candidates for `rlib` dependency `crateresolve` found

fn main() {}

    این خطا می‌تواند در چند حالت مختلف رخ دهد؛ برای مثال هنگام استفاده از extern crate یا ارسال گزینه‌های --extern بدون مسیر crate. همچنین ممکن است به‌دلیل مشکلات کش در پوشه ساخت (build) باشد که در آن صورت cargo clean می‌تواند کمک کند.

    در مثال بالا سه فایل کتابخانه متفاوت وجود دارد که همگی نام crate یکسانی تعریف می‌کنند. بدون ارائه مسیر کامل، کامپایلر راهی برای تشخیص اینکه کدام crate را باید به کار ببرد ندارد.
