راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود.

    در وضعیت داده‌شده نمی‌توان طول عمر را تعیین کرد.

    نمونه کد دارای خطا:

    fn transmute_lifetime<'a, 'b, T>(t: &'a (T,)) -> &'b T {
    match (&t,) { // error!
        ((u,),) => u,
    }
}

let y = Box::new((42,));
let x = transmute_lifetime(&y);

    در این کد، دو راه برای حل مشکل دارید:

    1. اطمینان حاصل کنید که 'a دست‌کم به اندازهٔ 'b زنده می‌ماند.
    2. برای مقادیر ورودی و خروجی از یک الزام طول عمر یکسان استفاده کنید.

    برای راه‌حل اول، می‌توانید 'a را با 'a: 'b جایگزین کنید:

    fn transmute_lifetime<'a: 'b, 'b, T>(t: &'a (T,)) -> &'b T {
    match (&t,) { // ok!
        ((u,),) => u,
    }
}

    در راه‌حل دوم، کافی است 'b را حذف کنید تا هر دو از 'a استفاده کنند:

    fn transmute_lifetime<'a, T>(t: &'a (T,)) -> &'a T {
    match (&t,) { // ok!
        ((u,),) => u,
    }
}
