راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود.

    async fnها هنوز در صفت‌ها (trait) در Rust پشتیبانی نمی‌شوند.

    نمونه کد خطادار:

    trait T {
    // Neither case is currently supported.
    async fn foo() {}
    async fn bar(&self) {}
}

    async fnها یک impl Future برمی‌گردانند، که دو مثال زیر را معادل می‌کند:

    async fn foo() -> User {
    unimplemented!()
}
// The async fn above gets desugared as follows:
fn foo(&self) -> impl Future<Output = User> + '_ {
    unimplemented!()
}

    اما وقتی پای پشتیبانی از این قابلیت در صفت‌ها در میان باشد، چند مشکل پیاده‌سازی وجود دارد. یکی از آن‌ها این است که بازگرداندن impl Trait در صفت‌ها پشتیبانی نمی‌شود، زیرا به پشتیبانی از Generic Associated Types نیاز دارد:

    impl MyDatabase {
    async fn get_user(&self) -> User {
        unimplemented!()
    }
}

impl MyDatabase {
    fn get_user(&self) -> impl Future<Output = User> + '_ {
        unimplemented!()
    }
}

    تا زمانی که این مشکلات حل شوند، می‌توانید از crate با نام async-trait استفاده کنید که با desugar کردن به «futureهای box‌شده» (Pin<Box<dyn Future + Send + 'async>>) امکان استفاده از async fn را در trait‌ها فراهم می‌کند.

    توجه کنید که استفاده از این متدهای صفت به ازای هر فراخوانی تابع منجر به یک تخصیص heap می‌شود. این هزینه برای اکثریت قریب به اتفاق برنامه‌ها قابل‌توجه نیست، اما هنگام تصمیم‌گیری برای استفاده از این قابلیت در API عمومی تابعی سطح پایین که انتظار می‌رود میلیون‌ها بار در ثانیه فراخوانی شود، باید در نظر گرفته شود.

    ممکن است بخواهید برای اطلاعات بیشتر به کتاب async سر بزنید.
