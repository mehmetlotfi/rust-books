راهنمای خطاهای کامپایلرCompiler Error Index

    تابع‌هایی که با cmse-nonsecure-call علامت‌گذاری شده‌اند، محدودیت‌هایی بر ورودی‌ها و خروجی‌های خود اعمال می‌کنند.

    • ورودی‌ها باید در 4 ثبات آرگومان 32 بیتی موجود جا شوند. ترازبندی مهم است.
    • خروجی‌ها یا باید در 4 بایت جا شوند، یا یک نوع بنیادی با اندازه 8 باشند (i64، u64، f64).
    • هیچ جنریکی در امضا نمی‌تواند به کار رود.

    برای اطلاعات بیشتر، aapcs32 شرکت arm را ببینید.

    مثال کد خطادار:

    #![feature(abi_cmse_nonsecure_call)]

#[no_mangle]
pub fn test(
    f: extern "cmse-nonsecure-call" fn(u32, u32, u32, u32, u32) -> u32,
) -> u32 {
    f(1, 2, 3, 4, 5)
}

    تراز (alignment) آرگومان‌ها رعایت می‌شود. در مثال زیر، padding درج می‌شود تا آرگومان u64 در ثبات‌های r2 و r3 ارسال شود. سپس برای آرگومان نهایی f32 جایی باقی نمی‌ماند

    #![feature(abi_cmse_nonsecure_call)]

#[no_mangle]
pub fn test(
    f: extern "cmse-nonsecure-call" fn(u32, u64, f32) -> u32,
) -> u32 {
    f(1, 2, 3.0)
}
