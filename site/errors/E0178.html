راهنمای خطاهای کامپایلرCompiler Error Index

    عملگر نوع + در یک بافت مبهم به کار رفته است.

    نمونه کدی که خطا می‌دهد:

    trait Foo {}

struct Bar<'a> {
    x: &'a Foo + 'a,     // error!
    y: &'a mut Foo + 'a, // error!
    z: fn() -> Foo + 'a, // error!
}

    در نوع‌ها، عملگر نوع + تقدم پایینی دارد، بنابراین اغلب لازم است از پرانتز استفاده کنید:

    trait Foo {}

struct Bar<'a> {
    x: &'a (Foo + 'a),     // ok!
    y: &'a mut (Foo + 'a), // ok!
    z: fn() -> (Foo + 'a), // ok!
}

    جزئیات بیشتر را در RFC 438 می‌توانید ببینید.
