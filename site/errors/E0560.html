راهنمای خطاهای کامپایلرCompiler Error Index

    یک فیلد ناشناخته در یک ساختار مشخص شده است.

    نمونه‌ی کد خطادار:

    struct Simba {
    mother: u32,
}

let s = Simba { mother: 1, father: 0 };
// error: structure `Simba` has no field named `father`

    بررسی کنید که نام فیلد را اشتباه ننوشته باشید یا اینکه آن فیلد وجود داشته باشد. نمونه:

    struct Simba {
    mother: u32,
    father: u32,
}

let s = Simba { mother: 1, father: 0 }; // ok!
