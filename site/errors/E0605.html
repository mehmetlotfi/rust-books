راهنمای خطاهای کامپایلرCompiler Error Index

    تلاش برای یک cast نامعتبر انجام شده است.

    نمونه‌های کد دارای خطا:

    let x = 0u8;
x as Vec<u8>; // error: non-primitive cast: `u8` as `std::vec::Vec<u8>`

// Another example

let v = core::ptr::null::<u8>(); // So here, `v` is a `*const u8`.
v as &u8; // error: non-primitive cast: `*const u8` as `&u8`

    فقط نوع‌های اولیه (primitive) را می‌توان به یکدیگر cast کرد. مثال‌ها:

    let x = 0u8;
x as u32; // ok!

let v = core::ptr::null::<u8>();
v as *const i8; // ok!

    برای اطلاعات بیشتر دربارهٔ castها، بخش Type cast را در کتاب مرجع (The Reference Book) ببینید.
