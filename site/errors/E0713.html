    این خطا زمانی رخ می‌دهد که تلاش شود حالتی فراتر از پایان طول عمر نوعی که صفت Drop را پیاده‌سازی می‌کند قرض گرفته شود.

    نمونه کد خطادار:

    pub struct S<'a> { data: &'a mut String }

impl<'a> Drop for S<'a> {
    fn drop(&mut self) { self.data.push_str("being dropped"); }
}

fn demo<'a>(s: S<'a>) -> &'a mut String { let p = &mut *s.data; p }

    در اینجا demo تلاش می‌کند داده‌ی رشته‌ای را که درون آرگومان s نگه‌داری می‌شود قرض بگیرد و سپس آن قرض را برگرداند. اما S به‌گونه‌ای تعریف شده که Drop را پیاده‌سازی می‌کند.

    ساختارهایی که صفت Drop را پیاده‌سازی می‌کنند یک destructor ضمنی دارند که هنگام خارج شدن از محدوده (scope) فراخوانی می‌شود. این destructor هنگام اجرا دسترسی انحصاری به فیلدهای ساختار دارد.

    این یعنی وقتی s به پایان demo می‌رسد، destructor آن دسترسی انحصاری به داده‌ی رشته‌ایِ قرض‌گرفته‌شده با &mut پیدا می‌کند. اجازه دادن به اینکه قرض دیگری از همان داده‌ی رشته‌ای (p) فراتر از drop شدن s وجود داشته باشد، نقض این اصل است که قرض‌های &mut دسترسی انحصاری و بدون alias به داده‌ی ارجاع‌شده‌ی خود دارند.

    این خطا را می‌توان با تغییر demo رفع کرد، به‌طوری که destructor در زمانی که داده‌ی رشته‌ای قرض گرفته شده اجرا نشود؛ برای مثال با دریافت S به‌صورت ارجاع:

    pub struct S<'a> { data: &'a mut String }

impl<'a> Drop for S<'a> {
    fn drop(&mut self) { self.data.push_str("being dropped"); }
}

fn demo<'a>(s: &'a mut S<'a>) -> &'a mut String { let p = &mut *(*s).data; p }

    توجه کنید که این روش به یک ارجاع به S با طول عمر 'a نیاز دارد. هیچ چیز کوتاه‌تر از 'a کافی نیست: طول عمر کوتاه‌تر به این معنا خواهد بود که پس از پایان اجرای demo، چیز دیگری (مانند destructor!) می‌تواند پس از پایان آن طول عمر کوتاه‌تر به s.data دسترسی پیدا کند، که دوباره دسترسی انحصاریِ قرض &mut را نقض می‌کند.
