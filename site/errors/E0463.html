راهنمای خطاهای کامپایلرCompiler Error Index

    یک crate اعلان شده است اما پیدا نمی‌شود.

    نمونه کد دارای خطا:

    extern crate foo; // error: can't find crate

    برای اینکه بتوانید از یک crate استفاده کنید، باید کد خود را به crate موردنظر پیوند دهید (مثلاً از طریق Cargo یا گزینه -L در rustc).

    دلایل رایج

    • crate اصلاً وجود ندارد. اگر از Cargo استفاده می‌کنید، آن را به [dependencies] در Cargo.toml اضافه کنید.
    • crate وجود دارد، اما با نامی متفاوت. اگر از Cargo استفاده می‌کنید، در [dependencies] در Cargo.toml به دنبال package = بگردید.

    دلایل رایج نبودن std یا core

    • شما برای هدفی کامپایل متقاطع (cross-compile) می‌کنید که std از پیش بسته‌بندی‌شده ندارد. یکی از این موارد را در نظر بگیرید:
      • افزودن نسخه از پیش کامپایل‌شده std با rustup target add
      • ساخت std از روی کد منبع با cargo build -Z build-std
      • استفاده از #![no_std] در ریشه crate تا اصلاً به std نیازی نداشته باشید.
    • شما در حال توسعه خود کامپایلر هستید و libstd را از روی کد منبع نساخته‌اید. معمولاً می‌توانید آن را با x.py build library/std بسازید. اطلاعات بیشتر درباره x.py در rustc-dev-guide موجود است.
