راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: کامپایلر دیگر این کد خطا را صادر نمی‌کند.

    شما نمی‌توانید یک ساختار (یا شمارش) Foo تعریف کنید که برای ساختن یک مقدار جدید Foo به یک نمونه از Foo نیاز داشته باشد. دلیلش این است که هیچ راهی وجود ندارد که نخستین نمونهٔ Foo ساخته شود تا نمونهٔ دیگری را مقداردهی اولیه کند!

    این‌جا مثالی از ساختاری که چنین مشکلی دارد آمده است:

    struct Foo { x: Box<Foo> } // error

    یک راه‌حل استفاده از Option است، مانند زیر:

    struct Foo { x: Option<Box<Foo>> }

    اکنون می‌توان دست‌کم یک نمونه از Foo ساخت: Foo { x: None }.
