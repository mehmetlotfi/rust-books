    یک عملگر انتساب روی عبارتی غیرمکانی (non-place) به کار رفته است.

    نمونه‌های کد نادرست:

    struct SomeStruct {
    x: i32,
    y: i32,
}

const SOME_CONST: i32 = 12;

fn some_other_func() {}

fn some_function() {
    SOME_CONST = 14; // error: a constant value cannot be changed!
    1 = 3; // error: 1 isn't a valid place!
    some_other_func() = 4; // error: we cannot assign value to a function!
    SomeStruct::x = 12; // error: SomeStruct a structure name but it is used
                        //        like a variable!
}

    سمت چپ یک عملگر انتساب باید یک عبارت مکانی (place expression) باشد. عبارت مکانی یک مکان حافظه را نشان می‌دهد و می‌تواند یک متغیر (با فضای نام اختیاری)، یک ارجاع‌زدایی، یک عبارت اندیس‌گذاری یا ارجاع به یک فیلد باشد.

    جزئیات بیشتر را می‌توانید در بخش عبارت‌ها در Reference بیابید.

    و اکنون چند مثال کارآمد ارائه می‌کنیم:

    struct SomeStruct {
    x: i32,
    y: i32,
}
let mut s = SomeStruct { x: 0, y: 0 };

s.x = 3; // that's good !

// ...

fn some_func(x: &mut i32) {
    *x = 12; // that's good !
}
