راهنمای خطاهای کامپایلرCompiler Error Index

    یک شمارش (enum) با راهنمای بازنمایی repr(transparent) صفر گونه (variant) یا بیش از یک گونه داشت.

    نمونه کد خطادار:

    #[repr(transparent)]
enum Status { // error: transparent enum needs exactly one variant, but has 2
    Errno(u32),
    Ok,
}

    از آن‌جا که شمارش‌های transparent هنگام اجرا دقیقاً مانند یکی از گونه‌های خود بازنمایی می‌شوند، آن گونه باید به‌طور یکتا مشخص باشد. اگر هیچ گونه‌ای وجود نداشته باشد یا چند گونه وجود داشته باشد، معلوم نیست شمارش چگونه باید بازنمایی شود.
