راهنمای خطاهای کامپایلرCompiler Error Index

    فقط صفت‌هایی که در crate فعلی تعریف شده‌اند را می‌توان برای نوع‌های دلخواه پیاده‌سازی کرد.

    نمونه کدی که خطا می‌دهد:

    impl Drop for u32 {}

    این خطا نشان‌دهنده‌ی نقض یکی از قواعد یتیم (orphan rules) در Rust برای پیاده‌سازی صفت‌ها است. این قاعده هر پیاده‌سازی از یک صفت خارجی (صفتی که در crate دیگری تعریف شده) را ممنوع می‌کند، هنگامی که

    • نوعی که صفت را پیاده‌سازی می‌کند خارجی باشد
    • همه‌ی پارامترهایی که به صفت داده می‌شوند (در صورت وجود) نیز خارجی باشند.

    برای پرهیز از این نوع خطا، مطمئن شوید که دست‌کم یک نوع محلی در impl به کار رفته باشد:

    pub struct Foo; // you define your type in your crate

impl Drop for Foo { // and you can implement the trait on it!
    // code of trait implementation here
#   fn drop(&mut self) { }
}

impl From<Foo> for i32 { // or you use a type from your crate as
                         // a type parameter
    fn from(i: Foo) -> i32 {
        0
    }
}

    یا به‌جای آن، یک صفت را به‌صورت محلی تعریف کنید و آن را پیاده‌سازی کنید:

    trait Bar {
    fn get(&self) -> usize;
}

impl Bar for u32 {
    fn get(&self) -> usize { 0 }
}

    برای اطلاع از طراحی قواعد یتیم، RFC 1023 را ببینید.
