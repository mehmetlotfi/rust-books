راهنمای خطاهای کامپایلرCompiler Error Index

    یک ثابت وابسته (associated const) پیاده‌سازی شده است در حالی که آیتم دیگری از صفت انتظار می‌رفت.

    نمونه کد خطادار:

    trait Foo {
    type N;
}

struct Bar;

impl Foo for Bar {
    const N : u32 = 0;
    // error: item `N` is an associated const, which doesn't match its
    //        trait `<Bar as Foo>`
}

    لطفاً بررسی کنید که نام ثابت وابسته اشتباه نوشته نشده باشد و صفت درست پیاده‌سازی شده باشد. مثال:

    struct Bar;

trait Foo {
    type N;
}

impl Foo for Bar {
    type N = u32; // ok!
}

    یا:

    struct Bar;

trait Foo {
    const N : u32;
}

impl Foo for Bar {
    const N : u32 = 0; // ok!
}
