راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود.

    تلاش برای پیاده‌سازی صفت Copy برای یک شمارش (enum) شکست خورد، زیرا یکی از واریانت‌ها Copy را پیاده‌سازی نمی‌کند. برای رفع این مشکل باید Copy را برای واریانت مورد نظر پیاده‌سازی کنید. توجه کنید که ممکن است این کار شدنی نباشد، مانند مثال زیر:

    enum Foo {
    Bar(Vec<u32>),
    Baz,
}

impl Copy for Foo { }

    این کد شکست می‌خورد، زیرا Vec<T> برای هیچ Tای Copy را پیاده‌سازی نمی‌کند.

    این هم مثال دیگری که با خطا مواجه می‌شود:

    #[derive(Copy)]
enum Foo<'a> {
    Bar(&'a mut bool),
    Baz,
}

    دلیل خطا این است که &mut T حتی وقتی T از نوع Copy باشد، Copy نیست (این با رفتار &T تفاوت دارد که همیشه Copy است).
