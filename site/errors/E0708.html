راهنمای خطاهای کامپایلرCompiler Error Index

    توجه: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود.

    closureهای async از نوع non-move که پارامتر دارند در حال حاضر پشتیبانی نمی‌شوند.

    نمونه کد خطادار:

    fn main() {
    let add_one = async |num: u8| {
        num + 1
    };
}

    async به‌صورت non-move در نسخه‌ی فعلی پشتیبانی نمی‌شود؛ می‌توانید با استفاده از move آن را با موفقیت به کار ببرید:

    fn main() {
    let add_one = async move |num: u8| { // ok!
        num + 1
    };
}
