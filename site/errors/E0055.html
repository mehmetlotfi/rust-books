راهنمای خطاهای کامپایلرCompiler Error Index

    هنگام فراخوانی یک متد، مقدار به‌طور خودکار به‌تعداد لازم ارجاع‌زدایی (dereference) می‌شود تا نوع مقدار با گیرنده (receiver) متد مطابقت پیدا کند. نکته این است که کامپایلر فقط تا حد محدودیت بازگشت (recursion limit) تلاش می‌کند ارجاع‌زدایی کند (این حد را می‌توان با attribute به نام recursion_limit تنظیم کرد).

    برای یک مثال تا حدی مصنوعی:

    #![recursion_limit="4"]

struct Foo;

impl Foo {
    fn foo(&self) {}
}

fn main() {
    let foo = Foo;
    let ref_foo = &&&&&Foo;

    // error, reached the recursion limit while auto-dereferencing `&&&&&Foo`
    ref_foo.foo();
}

    یک راه‌حل می‌تواند افزایش محدودیت بازگشت باشد. توجه کنید که ممکن است یک بازگشت بی‌پایان در ارجاع‌زدایی ایجاد شود؛ در این صورت تنها راه‌حل این است که به‌نحوی بازگشت را قطع کنید.
