راهنمای خطاهای کامپایلرCompiler Error Index

    تلاش شده است به/از یک اشاره‌گر با نوع نامشخص تبدیل (cast) انجام شود.

    نمونهٔ کد خطادار:

    let b = 0 as *const _; // error

    اگر اشاره‌گری به/از نوعی دیگر تبدیل می‌شود که قابل استنتاج نیست، باید اطلاعات نوع ارائه شود:

    // Creating a pointer from reference: type can be inferred
let a = &(String::from("Hello world!")) as *const _; // ok!

let b = 0 as *const i32; // ok!

let c: *const i32 = 0 as *const _; // ok!
