راهنمای خطاهای کامپایلرCompiler Error Index

    یک پارامتر نوع یا طول عمر تعریف شده است اما در عمل استفاده نشده است.

    نمونه کد خطادار:

    enum Foo<T> {
    Bar,
}

    اگر پارامتر نوع به‌اشتباه گنجانده شده باشد، این خطا را می‌توان به سادگی با حذف پارامتر نوع برطرف کرد، مانند زیر:

    enum Foo {
    Bar,
}

    از طرف دیگر، اگر پارامتر نوع عمداً درج شده است، باید از آن استفاده شود. یک راه‌حل ساده در زیر آمده است:

    enum Foo<T> {
    Bar(T),
}

    این خطا هنگام کار با کد unsafe نیز معمولاً دیده می‌شود. برای مثال، هنگام استفاده از اشاره‌گرهای خام ممکن است بخواهید طول عمری را مشخص کنید که داده مورد اشاره در طول آن معتبر است. تلاش اولیه (زیر) باعث این خطا می‌شود:

    struct Foo<'a, T> {
    x: *const T,
}

    می‌خواهیم این قید را بیان کنیم که Foo نباید بیشتر از 'a عمر کند، زیرا داده‌ای که T به آن اشاره می‌کند فقط در همان طول عمر معتبر است. مشکل این است که در عمل هیچ استفاده‌ای از 'a نشده است. می‌توان با افزودن یک نوع PhantomData به ساختار این مشکل را دور زد و از آن برای این استفاده کرد که به کامپایلر بگوییم طوری رفتار کند که انگار ساختار شامل یک ارجاع قرض‌گرفته‌شده &'a T است:

    use std::marker::PhantomData;

struct Foo<'a, T: 'a> {
    x: *const T,
    phantom: PhantomData<&'a T>
}

    از PhantomData همچنین می‌توان برای بیان اطلاعات درباره‌ی پارامترهای نوع استفاده‌نشده بهره گرفت.
