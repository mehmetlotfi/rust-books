راهنمای خطاهای کامپایلرCompiler Error Index

    بیش از یک قید طول عمر صریح روی یک شیء صفت (trait object) استفاده شده است.

    نمونه کد دارای خطا:

    trait Foo {}

type T<'a, 'b> = dyn Foo + 'a + 'b; // error: Trait object `arg` has two
                                    //        lifetime bound, 'a and 'b.

    در اینجا T یک شیء صفت با دو قید طول عمر صریح، ’a و ’b است.

    روی شیء صفت فقط یک قید طول عمر صریح مجاز است. برای رفع این خطا، حذف یکی از قیدهای طول عمر را در نظر بگیرید:

    trait Foo {}

type T<'a> = dyn Foo + 'a;
    → E0225E0227 ←
