راهنمای خطاهای کامپایلرCompiler Error Index

    یک بازه‌ی شامل‌شونده (inclusive range) بدون پایان به کار رفته است.

    نمونه کد خطادار:

    fn main() {
    let tmp = vec![0, 1, 2, 3, 4, 4, 3, 3, 2, 1];
    let x = &tmp[1..=]; // error: inclusive range was used with no end
}

    یک بازه‌ی شامل‌شونده برای آنکه پایان را شامل شود، به یک پایان نیاز دارد. اگر فقط به شروع نیاز دارید و پایانی لازم ندارید، از بازه‌ی غیرشامل‌شونده (با ..) استفاده کنید:

    fn main() {
    let tmp = vec![0, 1, 2, 3, 4, 4, 3, 3, 2, 1];
    let x = &tmp[1..]; // ok!
}

    یا برای بازه‌ی شامل‌شونده‌ی خود یک پایان مشخص کنید:

    fn main() {
    let tmp = vec![0, 1, 2, 3, 4, 4, 3, 3, 2, 1];
    let x = &tmp[1..=3]; // ok!
}
