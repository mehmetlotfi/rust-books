راهنمای خطاهای کامپایلرCompiler Error Index

    یک تابع از کلیدواژه‌ی continue به‌طور نادرست استفاده می‌کند.

    نمونه کد خطادار:

    fn continue_simple() {
    'b: {
        continue; // error!
    }
}
fn continue_labeled() {
    'b: {
        continue 'b; // error!
    }
}
fn continue_crossing() {
    loop {
        'b: {
            continue; // error!
        }
    }
}

    در اینجا از کلیدواژه‌ی continue به‌طور نادرست استفاده کرده‌ایم. همان‌طور که در بالا دیدیم، continue به یک بلوک برچسب‌دار اشاره می‌کند.

    برای رفع این مشکل باید از بلوک برچسب‌دار به‌درستی استفاده کنیم. برای مثال:

    fn continue_simple() {
    'b: loop {
        continue ; // ok!
    }
}
fn continue_labeled() {
    'b: loop {
        continue 'b; // ok!
    }
}
fn continue_crossing() {
    loop {
        'b: loop {
            continue; // ok!
        }
    }
}
