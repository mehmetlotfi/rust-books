راهنمای خطاهای کامپایلرCompiler Error Index

    یک کلیدواژه حلقه (break یا continue) درون یک closure ولی بیرون از هر حلقه‌ای به کار رفته است.

    کد دارای خطا:

    let w = || { break; }; // error: `break` inside of a closure

    کلیدواژه‌های break و continue درون closureها به‌طور معمول قابل استفاده‌اند، به شرطی که درون یک حلقه نیز قرار داشته باشند. برای متوقف کردن اجرای یک closure باید به‌جای آن‌ها از دستور return استفاده کنید. مثال:

    let w = || {
    for _ in 0..10 {
        break;
    }
};
