راهنمای خطاهای کامپایلرCompiler Error Index

    به یک مقدار غیرقابل‌تغییر (non-mutable) مقداری تخصیص داده شده است.

    نمونهٔ کد دارای خطا:

    struct SolarSystem {
    earth: i32,
}

let ss = SolarSystem { earth: 3 };
ss.earth = 2; // error!

    برای رفع این خطا، ss را با کلیدواژهٔ mut به‌صورت قابل‌تغییر تعریف کنید:

    struct SolarSystem {
    earth: i32,
}

let mut ss = SolarSystem { earth: 3 }; // declaring `ss` as mutable
ss.earth = 2; // ok!
