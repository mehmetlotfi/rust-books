راهنمای خطاهای کامپایلرCompiler Error Index

    یک الگو سعی کرده است تعداد نادرستی فیلد را از یک واریانت استخراج کند.

    نمونه کد نادرست:

    enum Fruit {
    Apple(String, String),
    Pear(u32),
}

let x = Fruit::Apple(String::new(), String::new());

match x {
    Fruit::Apple(a) => {}, // error!
    _ => {}
}

    الگویی که برای تطبیق با یک واریانت شمارش (enum) به کار می‌رود، باید برای هر فیلد آن واریانت یک زیرالگو ارائه کند.

    در اینجا واریانت Apple دو فیلد دارد و باید به این شکل تطبیق داده شود:

    enum Fruit {
    Apple(String, String),
    Pear(u32),
}

let x = Fruit::Apple(String::new(), String::new());

// Correct.
match x {
    Fruit::Apple(a, b) => {},
    _ => {}
}

    تطبیق با تعداد نادرست فیلد هیچ تفسیر معقولی ندارد:

    enum Fruit {
    Apple(String, String),
    Pear(u32),
}

let x = Fruit::Apple(String::new(), String::new());

// Incorrect.
match x {
    Fruit::Apple(a) => {},
    Fruit::Apple(a, b, c) => {},
}

    بررسی کنید که شمارش با چند فیلد تعریف شده است و مطمئن شوید الگوی شما همان تعداد را به کار می‌برد.
