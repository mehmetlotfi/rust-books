راهنمای خطاهای کامپایلرCompiler Error Index

    نکته: این کد خطا دیگر توسط کامپایلر صادر نمی‌شود

    دلیلش این است که این خطا بیش از حد مختص attribute به نام inline بود. برای سایر attributeها نیز تشخیص‌های مشابهی وجود دارد. نمونه‌ی این‌جا اکنون E0805 را صادر می‌کند.

    attribute به نام inline ناقص‌نوشته (malformed) بود.

    نمونه‌ی کد خطادار:

    #[inline()] // error: expected one argument
pub fn something() {}

fn main() {}

    نسخه‌ی پرانتزدار attribute به نام inline نیاز دارد که پارامتر مشخص شود:

    #[inline(always)]
fn something() {}

    یا:

    #[inline(never)]
fn something() {}

    به‌طور جایگزین، می‌توان از نسخه‌ی بدون پرانتز این attribute استفاده کرد تا به کامپایلر درباره‌ی امکان درون‌گذاری (inlining) اشاره شود:

    #[inline]
fn something() {}

    برای اطلاعات بیشتر، بخش attribute به نام inline را در Reference ببینید.
