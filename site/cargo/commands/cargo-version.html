    cargo-version(1)

    نام

    cargo-version — نمایش اطلاعات نسخه

    خلاصه

    cargo version [options]

    توضیحات

    نسخهٔ Cargo را نمایش می‌دهد.

    گزینه‌ها

    -v
    --verbose

    اطلاعات اضافی دربارهٔ نسخه را نمایش می‌دهد.

    مثال‌ها

    1. نسخه را نمایش دهید:

      cargo version

    2. نسخه از طریق پرچم‌ها نیز در دسترس است:

      cargo --version
cargo -V

    3. اطلاعات اضافی دربارهٔ نسخه را نمایش دهید:

      cargo -Vv
