    کار روی یک بستهٔ Cargo موجود

    اگر یک بستهٔ موجود را که از Cargo استفاده می‌کند دانلود کنید، شروع به کار با آن بسیار آسان است.

    ابتدا بسته را از جایی تهیه کنید. در این مثال، از regex استفاده می‌کنیم که از مخزن آن در GitHub کلون شده است:

    $ git clone https://github.com/rust-lang/regex.git
$ cd regex

    برای ساخت، از cargo build استفاده کنید:

    $ cargo build
   Compiling regex v1.5.0 (file:///path/to/package/regex)

    این دستور همهٔ وابستگی‌ها را دریافت می‌کند و سپس آن‌ها را به‌همراه خود بسته می‌سازد.
