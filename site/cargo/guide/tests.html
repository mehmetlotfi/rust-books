    آزمون‌ها

    Cargo می‌تواند آزمون‌های شما را با دستور cargo test اجرا کند. Cargo آزمون‌هایی را که باید اجرا شوند در دو جا جست‌وجو می‌کند: در هر یک از فایل‌های src شما و در آزمون‌های موجود در tests/. آزمون‌های فایل‌های src باید آزمون‌های واحد و آزمون‌های مستندات باشند. آزمون‌های tests/ باید از نوع آزمون‌های یکپارچه‌سازی باشند. به همین دلیل، لازم است crateهای خود را در فایل‌های tests import کنید.

    این هم مثالی از اجرای cargo test در بستهٔ ما که در حال حاضر آزمونی ندارد:

    $ cargo test
   Compiling regex v1.5.0 (https://github.com/rust-lang/regex.git#9f9f693)
   Compiling hello_world v0.1.0 (file:///path/to/package/hello_world)
     Running target/test/hello_world-9c2b65bbb79eabce

running 0 tests

test result: ok. 0 passed; 0 failed; 0 ignored; 0 measured; 0 filtered out

    اگر بستهٔ شما آزمون داشت، خروجی بیشتری با تعداد درست آزمون‌ها می‌دیدید.

    همچنین می‌توانید با دادن یک فیلتر، یک آزمون مشخص را اجرا کنید:

    $ cargo test foo

    این دستور هر آزمونی را که foo در نامش باشد اجرا می‌کند.

    cargo test بررسی‌های دیگری نیز انجام می‌دهد. هر مثالی را که اضافه کرده‌اید کامپایل می‌کند تا مطمئن شود هنوز کامپایل می‌شوند. همچنین آزمون‌های مستندات را اجرا می‌کند تا مطمئن شود نمونه‌کدهای موجود در کامنت‌های مستندات کامپایل می‌شوند. برای دید کلی دربارهٔ نوشتن و سازمان‌دهی آزمون‌ها، لطفاً راهنمای آزمون را در مستندات Rust ببینید. برای آشنایی بیشتر با سبک‌های مختلف آزمون در Cargo، هدف‌های Cargo: آزمون‌ها را ببینید.
