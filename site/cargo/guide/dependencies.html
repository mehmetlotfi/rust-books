کتاب CargoThe Cargo Book

    وابستگی‌ها

    crates.io، رجیستری بستهٔ مرکزی جامعهٔ Rust است که محلی برای کشف و دانلود بسته‌ها فراهم می‌کند. cargo به‌طور پیش‌فرض طوری پیکربندی شده است که بسته‌های درخواستی را از آنجا پیدا کند.

    برای وابسته شدن به کتابخانه‌ای که در crates.io میزبانی می‌شود، آن را به Cargo.toml خود اضافه کنید.

    افزودن یک وابستگی

    اگر Cargo.toml شما هنوز بخش [dependencies] ندارد، آن را اضافه کنید، سپس نام و نسخهٔ crate موردنظرتان را فهرست کنید. این مثال یک وابستگی به crate با نام time اضافه می‌کند:

    [dependencies]
time = "0.1.12"

    رشتهٔ نسخه یک الزام نسخه به سبک SemVer است. مستندات مشخص کردن وابستگی‌ها اطلاعات بیشتری دربارهٔ گزینه‌هایی که در اینجا دارید ارائه می‌دهد.

    اگر بخواهید وابستگی‌ای به crate با نام regex نیز اضافه کنید، لازم نیست برای هر crate فهرست‌شده [dependencies] را دوباره اضافه کنید. فایل Cargo.toml کامل شما با وابستگی به crateهای time و regex این‌گونه خواهد بود:

    [package]
name = "hello_world"
version = "0.1.0"
edition = "2024"

[dependencies]
time = "0.1.12"
regex = "0.1.41"

    دوباره cargo build را اجرا کنید؛ Cargo وابستگی‌های جدید و همهٔ وابستگی‌های آن‌ها را دریافت می‌کند، همه را کامپایل می‌کند و Cargo.lock را به‌روزرسانی می‌کند:

    $ cargo build
      Updating crates.io index
   Downloading memchr v0.1.5
   Downloading libc v0.1.10
   Downloading regex-syntax v0.2.1
   Downloading memchr v0.1.5
   Downloading aho-corasick v0.3.0
   Downloading regex v0.1.41
     Compiling memchr v0.1.5
     Compiling libc v0.1.10
     Compiling regex-syntax v0.2.1
     Compiling memchr v0.1.5
     Compiling aho-corasick v0.3.0
     Compiling regex v0.1.41
     Compiling hello_world v0.1.0 (file:///path/to/package/hello_world)

    Cargo.lock اطلاعات دقیق دربارهٔ اینکه کدام revision برای همهٔ این وابستگی‌ها استفاده شده است را در خود دارد.

    اکنون اگر regex به‌روز شود، شما همچنان با همان revision ساخت را انجام می‌دهید، تا زمانی که تصمیم بگیرید cargo update را اجرا کنید.

    اکنون می‌توانید از کتابخانهٔ regex در main.rs استفاده کنید.

    use regex::Regex;

fn main() {
    let re = Regex::new(r"^\d{4}-\d{2}-\d{2}$").unwrap();
    println!("Did our date match? {}", re.is_match("2014-01-01"));
}

    اجرای آن این خروجی را نشان می‌دهد:

    $ cargo run
   Running `target/hello_world`
Did our date match? true
