    کتاب Cargo

    Cargo مدیر بستهٔ زبان Rust است. Cargo وابستگی‌های بستهٔ Rust شما را دانلود می‌کند، بسته‌هایتان را کامپایل می‌کند، بسته‌های قابل توزیع می‌سازد و آن‌ها را در crates.io، رجیستری بسته جامعهٔ Rust، بارگذاری می‌کند. می‌توانید در این کتاب در GitHub مشارکت کنید.
