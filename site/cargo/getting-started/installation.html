    نصب Rust و Cargo

    ساده‌ترین راه برای دریافت Cargo این است که آخرین نسخهٔ stable زبان Rust را با استفاده از rustup نصب کنید. نصب Rust با rustup باعث نصب cargo نیز می‌شود.

    در سیستم‌های Linux و macOS این کار به شکل زیر انجام می‌شود:

    curl https://sh.rustup.rs -sSf | sh

    این دستور یک اسکریپت را دانلود می‌کند و نصب را آغاز می‌کند. اگر همه‌چیز خوب پیش برود، این پیام را می‌بینید:

    Rust is installed now. Great!

    در Windows، فایل rustup-init.exe را دانلود و اجرا کنید. این فایل نصب را در یک کنسول آغاز می‌کند و در صورت موفقیت، پیام بالا را نمایش می‌دهد.

    پس از آن می‌توانید با دستور rustup، کانال‌های beta یا nightly را نیز برای Rust و Cargo نصب کنید.

    برای گزینه‌ها و اطلاعات بیشتر دربارهٔ نصب، به صفحهٔ نصب در وب‌سایت Rust سر بزنید.
