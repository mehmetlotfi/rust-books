    اولین قدم‌ها با Cargo

    این بخش دید کلی و سریعی از ابزار خط فرمان cargo ارائه می‌دهد. در اینجا نشان می‌دهیم که Cargo چگونه می‌تواند یک بستهٔ جدید برایمان بسازد، crate درون آن بسته را کامپایل کند و برنامهٔ حاصل را اجرا کند.

    برای شروع یک بستهٔ جدید با Cargo، از cargo new استفاده کنید:

    $ cargo new hello_world

    Cargo به‌طور پیش‌فرض از --bin استفاده می‌کند تا یک برنامهٔ باینری بسازد. برای ساختن یک کتابخانه، به‌جای آن باید --lib را به کار ببریم.

    بیایید ببینیم Cargo برای ما چه چیزی تولید کرده است:

    $ cd hello_world
$ tree .
.
├── Cargo.toml
└── src
    └── main.rs

1 directory, 2 files

    این همهٔ آن چیزی است که برای شروع لازم داریم. ابتدا نگاهی به Cargo.toml بیندازیم:

    [package]
name = "hello_world"
version = "0.1.0"
edition = "2024"

[dependencies]

    این فایل یک manifest نام دارد و شامل همهٔ فرادادهٔ مورد نیاز Cargo برای کامپایل بستهٔ شماست.

    این هم محتوای src/main.rs:

    fn main() {
    println!("Hello, world!");
}

    Cargo یک برنامهٔ «hello world» برای ما تولید کرد که با نام binary crate نیز شناخته می‌شود. بیایید آن را کامپایل کنیم:

    $ cargo build
   Compiling hello_world v0.1.0 (file:///path/to/package/hello_world)

    و سپس اجرایش کنیم:

    $ ./target/debug/hello_world
Hello, world!

    همچنین می‌توانیم از cargo run استفاده کنیم تا کامپایل و اجرا را در یک مرحله انجام دهیم:

    $ cargo run
     Fresh hello_world v0.1.0 (file:///path/to/package/hello_world)
   Running `target/hello_world`
Hello, world!
