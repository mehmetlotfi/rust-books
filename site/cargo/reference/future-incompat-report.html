    گزارش ناسازگاری آینده

    Cargo در همهٔ وابستگی‌ها به دنبال هشدارهای «ناسازگاری آینده» می‌گردد. این‌ها هشدارهایی دربارهٔ تغییراتی هستند که ممکن است در آینده به خطای سخت تبدیل شوند و باعث شوند وابستگی در نسخه‌ای آتی از rustc دیگر ساخته نشود. اگر هشداری پیدا شود، یک اعلان کوتاه نمایش داده می‌شود که نشان می‌دهد هشدارها یافت شده‌اند و دستورالعمل نمایش گزارش کامل را ارائه می‌کند.

    برای مثال، ممکن است در پایان یک ساخت چیزی شبیه به این ببینید:

    warning: the following packages contain code that will be rejected by a future
         version of Rust: rental v0.5.5
note: to see what the problems were, use the option `--future-incompat-report`,
      or run `cargo report future-incompatibilities --id 1`

    گزارش کامل را می‌توان با دستور cargo report future-incompatibilities --id ID نمایش داد، یا با اجرای دوبارهٔ ساخت همراه با پرچم --future-incompat-report. سپس توسعه‌دهنده باید وابستگی‌های خود را به نسخه‌ای به‌روز کند که مشکل در آن رفع شده است، یا با توسعه‌دهندگان وابستگی‌ها همکاری کند تا به حل مشکل کمک کند.

    پیکربندی

    این قابلیت را می‌توان از طریق بخش [future-incompat-report] در .cargo/config.toml پیکربندی کرد. در حال حاضر گزینه‌های پشتیبانی‌شده این‌ها هستند:

    [future-incompat-report]
frequency = "always"

    مقادیر پشتیبانی‌شده برای frequency عبارت‌اند از "always" و "never"؛ این مقادیر کنترل می‌کنند که آیا در پایان cargo build / cargo check پیامی چاپ شود یا خیر.
