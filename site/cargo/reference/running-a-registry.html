    اجرای یک رجیستری

    یک رجیستری حداقلی را می‌توان با داشتن یک مخزن git که شامل یک ایندکس است و یک سرور که فایل‌های فشردهٔ .crate ساخته‌شده توسط cargo package را در خود دارد پیاده‌سازی کرد. کاربران نخواهند توانست با Cargo در آن منتشر کنند، اما این ممکن است برای محیط‌های بسته کافی باشد. قالب ایندکس در ایندکس رجیستری شرح داده شده است.

    یک رجیستری کامل که از انتشار پشتیبانی می‌کند، علاوه بر این به یک سرویس API وب نیاز دارد که با API مورد استفادهٔ Cargo سازگار باشد. API وب در API وب رجیستری شرح داده شده است.

    پروژه‌های تجاری و اجتماعی برای ساخت و اجرای یک رجیستری در دسترس‌اند. برای فهرستی از موارد موجود، https://github.com/rust-lang/cargo/wiki/Third-party-registries را ببینید.
