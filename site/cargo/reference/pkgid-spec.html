    مشخصه‌های شناسهٔ بسته

    زیردستورهای Cargo اغلب باید برای عملیات گوناگونی مانند به‌روزرسانی، پاک‌سازی، ساخت و غیره به یک بستهٔ مشخص در گراف وابستگی ارجاع دهند. برای حل این مسئله، Cargo از مشخصه‌های شناسهٔ بسته (Package ID Specifications) پشتیبانی می‌کند. مشخصه رشته‌ای است که برای ارجاع یکتا به یک بسته در میان گراف بسته‌ها به کار می‌رود.

    مشخصه ممکن است کاملاً مشخص (fully qualified) باشد، مانند registry+https://github.com/rust-lang/crates.io-index#regex@1.4.3، یا ممکن است مختصر باشد، مانند regex. تا زمانی که شکل مختصر بتواند یک بستهٔ واحد را در گراف وابستگی به‌طور یکتا مشخص کند، می‌توان از آن استفاده کرد. اگر ابهامی وجود داشته باشد، می‌توان قیدهای بیشتری اضافه کرد تا مشخصه یکتا شود. برای مثال، اگر دو نسخه از بستهٔ regex در گراف وجود داشته باشد، می‌توان با افزودن نسخه آن را یکتا کرد، مانند regex@1.4.3.

    مشخصه‌های شناسهٔ بسته‌ای که cargo خروجی می‌دهد، برای مثال در خروجی cargo metadata، کاملاً مشخص هستند.

    دستور زبان مشخصه

    دستور زبان صوری یک مشخصهٔ شناسهٔ بسته به این صورت است:

    spec := pkgname |
        [ kind "+" ] proto "://" hostname-and-path [ "?" query] [ "#" ( pkgname | semver ) ]
query = ( "branch" | "tag" | "rev" ) "=" ref
pkgname := name [ ("@" | ":" ) semver ]
semver := digits [ "." digits [ "." digits [ "-" prerelease ] [ "+" build ]]]

kind = "registry" | "git" | "path"
proto := "http" | "git" | "file" | ...

    در اینجا، کروشه نشان می‌دهد که محتوای داخل آن اختیاری است.

    از شکل URL می‌توان برای وابستگی‌های git یا برای تمایز بین بسته‌هایی که از منابع مختلف، مانند رجیستری‌های متفاوت، می‌آیند استفاده کرد.

    بسته‌های محلی روی فایل‌سیستم می‌توانند برای ارجاع از URLهای file:// استفاده کنند:

    مشخصهنامنسخه
    file:///path/to/my/project/foofoo*
    file:///path/to/my/project/foo#1.1.8foo1.1.8
    path+file:///path/to/my/project/foo#1.1.8foo1.1.8

    اختصار مشخصه‌ها

    هدف از این کار این است که هم نحوی مختصر و هم نحوی جامع برای ارجاع به بسته‌ها در گراف وابستگی فراهم شود. ارجاع‌های مبهم ممکن است به یک یا چند بسته اشاره کنند. بیشتر دستورها اگر بیش از یک بسته با همان مشخصه قابل ارجاع باشد، خطا تولید می‌کنند.
