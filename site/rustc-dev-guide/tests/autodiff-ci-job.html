    Autodiff CI job

    job با نام optional-test-x86_64-gnu-autodiff پوشش تست پیوسته را برای قابلیت آزمایشی autodiff و یکپارچگی آن با LLVM Enzyme فراهم می‌کند. این یک job از نوع auto اختیاری است، پس شکست آن مانع merge شدن یک pull request نمی‌شود.

    برای زمینهٔ بیشتر دربارهٔ این قابلیت، issue پیگیری autodiff و فصل درون‌ساز autodiff را ببینید.

    چه چیزی تست می‌شود

    این job این‌ها را بررسی می‌کند:

    • گسترش ماکرو و پیام‌های تشخیصی حالت‌های forward و reverse؛
    • تولید LLVM IR برای autodiff؛
    • اعمال feature gate با نام autodiff.

    اجرای job

    برای اجرای job در یک ساخت try، روی یک pull request کامنت بگذارید:

    @bors try jobs=optional-x86_64-gnu-autodiff

    برای اجرای محلی job، این دستور را از checkout مربوط به Rust اجرا کنید:

    $ cargo run --manifest-path src/ci/citool/Cargo.toml run-local optional-x86_64-gnu-autodiff

    برای اطلاعات بیشتر دربارهٔ اجرای محلی jobهای CI تست با Docker را ببینید.

    نقطهٔ تماس

    اگر پرسشی دارید یا برای شکستی در این job کمک می‌خواهید، topic جدیدی در کانال Zulip مربوط به autodiff باز کنید. برای شکست‌های مشکوک backend مربوط به Enzyme، راهنمای اشکال‌زدایی autodiff را ببینید.
