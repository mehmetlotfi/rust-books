راهنمای توسعهٔ rustcrustc Development Guide

    Ecosystem testing

    Rust یکپارچگی را با کد دنیای واقعی در اکوسیستم تست می‌کند تا رگرسیون‌ها را بگیرد و دربارهٔ تکامل زبان تصمیم‌های آگاهانه بگیرد.

    Testing methods

    Crater

    Crater ابزاری است که تست‌ها را روی هزاران پروژهٔ عمومی اجرا می‌کند. این ابزار زیرساخت جداگانهٔ خودش را برای اجرا دارد و به‌عنوان بخشی از CI اجرا نمی‌شود. برای جزئیات بیشتر فصل Crater را ببینید.

    cargotest

    cargotest ابزار کوچکی است که cargo test را روی چند پروژهٔ نمونه (مثل stylo، ripgrep، tokei و غیره) اجرا می‌کند. این به‌عنوان بخشی از CI اجرا می‌شود و تضمین می‌کند رگرسیون قابل‌توجهی وجود ندارد:

    ./x test src/tools/cargotest

    builderهای پروژه‌های بزرگ متن‌باز
