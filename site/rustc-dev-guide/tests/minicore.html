    تست کمکی minicore: استفاده از stubهای core

    tests/auxiliary/minicore.rs یک تست کمکی برای مجموعه‌های تست ui/codegen/assembly/mir-opt است. stubهای core را برای تست‌هایی فراهم می‌کند که باید برای هدف‌های cross-compile ساخته شوند اما نیاز/تمایلی به اجرا ندارند.

    لطفاً توجه کنید که minicore فقط برای آیتم‌های core در نظر گرفته شده، و صراحتاً نه برای آیتم‌های std یا alloc، چون آیتم‌های core برای طیف گسترده‌تری از تست‌ها کاربرد دارند.

    یک تست می‌تواند با مشخص‌کردن directive با نام //@ add-minicore از minicore استفاده کند. سپس تست را با #![feature(no_core)] + #![no_std] + #![no_core] علامت بزنید، و crate را با extern crate minicore (edition 2015) یا use minicore (edition 2018 به بعد) به تست وارد کنید.

    Implied compiler flags

    به‌دلیل ماهیت no_std + no_core این تست‌ها، //@ add-minicore به‌طور ضمنی لازم می‌کند تست با -C panic=abort ساخته شود. panicهای unwinding پشتیبانی نمی‌شوند.

    تست‌ها همچنین با -C force-unwind-tables=yes ساخته می‌شوند تا directiveهای CFI در تست‌های assembly حفظ شوند.

    خلاصه: //@ add-minicore دو پرچم کامپایلر را ضمنی می‌کند:

    1. -C panic=abort
    2. -C force-unwind-tables=yes

    افزودن stubهای بیشتر core

    اگر دیدید آیتمی از core در stub با نام minicore نیست، افزودن آن به تست کمکی را در نظر بگیرید اگر احتمالاً استفاده می‌شود یا از قبل بیش از یک تست به آن نیاز دارد.

    همگام‌ماندن با core

    آیتم‌های minicore باید با core به‌روز نگه داشته شوند. برای خروجی تشخیصی سازگار بین استفاده از core و minicore، هر attribute با نام diagnostic (مثل on_unimplemented) باید دقیقاً در minicore بازتولید شود.

    مثال تست codegen که از minicore استفاده می‌کند

    //@ add-minicore
//@ revisions: meow bark
//@[meow] compile-flags: --target=x86_64-unknown-linux-gnu
//@[meow] needs-llvm-components: x86
//@[bark] compile-flags: --target=wasm32-unknown-unknown
//@[bark] needs-llvm-components: webassembly

#![crate_type = "lib"]
#![feature(no_core)]
#![no_std]
#![no_core]

extern crate minicore;
use minicore::*;

struct Meow;
impl Copy for Meow {} // `Copy` here is provided by `minicore`

// CHECK-LABEL: meow
#[unsafe(no_mangle)]
fn meow() {}
