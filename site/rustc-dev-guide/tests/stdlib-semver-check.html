    بررسی شکستگی نسخه‌گذاری معنایی کتابخانهٔ استاندارد

    job با نام test-x86_64-gnu-stdlib-semver-check ابزار cargo-semver-checks (به اختصار c-s-c) را روی کتابخانهٔ استاندارد (core، alloc و std) اجرا می‌کند تا شکستگی‌های ناخواستهٔ احتمالی نسخه‌گذاری معنایی (semver) را بیابد. این کار را با تحلیل خروجی JSON مربوط به rustdoc (از مؤلفهٔ rust-docs-json) برای merge commit والد و commit فعلی که در حال merge شدن است انجام می‌دهد. هنگام اجرا، یکی از پنج حالت ممکن است رخ دهد:

    1. همه‌چیز درست پیش می‌رود، c-s-c هیچ شکستگی‌ای نمی‌یابد.
    2. The rustdoc JSON version was bumped recently, and c-s-c cannot handle it yet. This case will result in the test ending with a success, and printing a warning that c-s-c needs to be updated. Once c-s-c releases a version that supports the new JSON format, it should go to 1. again.
      • ما فعلاً آخرین نسخهٔ منتشرشدهٔ c-s-c را در این job نصب می‌کنیم، پس نسخهٔ آن نیازی به به‌روزرسانی دستی در مخزن rust-lang/rust ندارد.
    3. c-s-c شکستگی‌ای تشخیص می‌دهد، اما false positive است. در این مورد لطفاً false positive را به این topic در Zulip گزارش کنید، و stamp file را bump کنید.
    4. c-s-c شکستگی واقعی را تشخیص می‌دهد و به شما کمک کرده شکستگی ناخواسته را بیابید. آفرین! در این مورد لطفاً گزارش این موفقیت را به این topic در Zulip در نظر بگیرید.
    5. c-s-c شکستگی واقعی را تشخیص می‌دهد، اما می‌خواهید به هر حال land شود (شاید یک edge case است که FCP شده). در آن صورت stamp file را bump کنید.

    bump‌کردن stamp file مربوط به semver در stdlib

    اگر می‌خواهید CI برای PRای که c-s-c در آن شکستگی تشخیص می‌دهد (چه واقعی چه نه) بگذرد، باید فایل src/bootstrap/stdlib-semver-check-stamp را تغییر دهید. لطفاً شمارهٔ PR‌ای را که این فایل را در آن تغییر می‌دهید در انتهای فایل به‌روز کنید. این تضمین می‌کند تست صرف‌نظر از آنچه c-s-c تشخیص می‌دهد سبز می‌ماند.

    اجرای دستی بررسی

    می‌توانید بررسی semver را به‌صورت محلی با ./x test std-semver-check --set rust.stdlib-semver-baseline=${PARENT} اجرا کنید، که در آن PARENT commit SHAای است که می‌خواهید stdlib درون‌درختی را با آن مقایسه کنید. اگر آن را مشخص نکنید، bootstrap جدیدترین commit بالادستی را که در تاریخچهٔ git محلی شما بیابد انتخاب می‌کند.
