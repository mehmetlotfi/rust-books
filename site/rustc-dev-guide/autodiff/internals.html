    ماژول std::autodiff در Rust برنامه‌نویسی مشتق‌پذیر را ممکن می‌کند:

    #![feature(autodiff)]
use std::autodiff::*;

// f(x) = x * x, f'(x) = 2.0 * x
// bar therefore returns (x * x, 2.0 * x)
#[autodiff_reverse(bar, Active, Active)]
fn foo(x: f32) -> f32 { x * x }

fn main() {
    assert_eq!(bar(3.0, 1.0), (9.0, 6.0));
    assert_eq!(bar(4.0, 1.0), (16.0, 8.0));
}

    مستندات تفصیلی ماژول std::autodiff در std::autodiff در دسترس است.

    برنامه‌نویسی مشتق‌پذیر در حوزه‌های مختلفی مانند محاسبات عددی، مکانیک جامدات، شیمی محاسباتی، دینامیک سیالات یا برای آموزش شبکه‌های عصبی از طریق Backpropagation، حل‌کننده ODE، رندرینگ مشتق‌پذیر، محاسبات کوانتومی و شبیه‌سازی‌های اقلیمی استفاده می‌شود.

    std::autodiff در حال حاضر بر پایه Enzyme است، ابزاری مبتنی بر LLVM برای مشتق‌گیری خودکار. سه دلیل اصلی برای تکیه بر autodiff مبتنی بر کامپایلر وجود دارد:

    • سهولت استفاده: crateهای autodiff فعلی از برنامه‌های معمولی Rust پشتیبانی نمی‌کنند. آن‌ها یا یک DSL سفارشی را الزامی می‌کنند، یا استفاده از نوع‌های ارائه‌شده توسط کتابخانه را لازم دارند (به‌جای مثلاً برش‌ها یا آرایه‌ها)، یا به تابع‌های اسکالر محدودند. autodiff مبتنی بر کامپایلر به کاربران اجازه می‌دهد کد معمولی Rust بنویسند، از جمله آرایه‌ها، برش‌ها، ساختارها و شمارش‌های تعریف‌شده توسط کاربر، جریان کنترل و موارد دیگر.
    • کارایی: بیشتر رویکردهای autodiff موجود در Rust برای هر عملیات یک سربار ثابت دارند. این سربار را می‌توان به‌آسانی در کاربردهای ML که عملیات گران کمی روی تانسورهای بزرگ دارند مستهلک کرد. اما در کاربردهای حوزه HPC یا محاسبات علمی اغلب غیرقابل‌قبول است. با کار روی LLVM IR (بهینه‌شده)، autodiff مبتنی بر کامپایلر می‌تواند در آن موارد به کارایی به‌مراتب بهتری دست یابد.
    • ویژگی‌ها: با کار در چنین سطح پایینی و اشتراک پیاده‌سازی با دیگر زبان‌های مبتنی بر LLVM، می‌توانیم از حجم زیاد کاری که پیش‌تر در پروژه Enzyme انجام شده بهره ببریم. برای مثال، می‌توانیم از کد Rust که روتین‌های MPI یا کد GPU را فراخوانی می‌کند، از جمله کتابخانه‌هایی مانند CuBLAS، پشتیبانی کنیم.
