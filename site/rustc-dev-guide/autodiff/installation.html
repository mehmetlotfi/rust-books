راهنمای توسعهٔ rustcrustc Development Guide

    Installation

    بیشتر کاربران می‌توانند با نصب مؤلفه enzyme توسط rustup، std::autodiff را روی آخرین toolchain نوع nightly خود فعال کنند، به شرط آنکه از یکی از این پلتفرم‌ها استفاده کنند:

    • Linux: با x86_64-unknown-linux-gnu یا aarch64-unknown-linux-gnu
    • macOS: با aarch64-apple-darwin یا x86_64-apple-darwin
    • Windows: با x86_64-llvm-mingw یا aarch64-llvm-mingw

    اگر مشارکت‌کننده rustc/enzyme/autodiff هستید یا به پلتفرم دیگری نیاز دارید، می‌توانید rustc را به‌همراه autodiff از روی کد منبع بسازید. اگر برای هدف مورد نظر خود به کمک در فعال‌سازی ساخت‌های خودکار نیاز دارید، لطفاً یک issue باز کنید.

    راهنمای نصب

    اگر می‌خواهید std::autodiff را روی Linux، macOS یا Windows استفاده کنید و قصد ندارید PR به پروژه ارسال کنید، توصیه می‌کنیم فقط از نصب nightly موجود خود استفاده کنید و مؤلفه جاافتاده را دانلود کنید. لطفاً اجرا کنید:

    rustup +nightly component add enzyme

    نسخه‌های قدیمی‌تر rustup از این مؤلفه اطلاعی ندارند، بنابراین اگر به مشکل برخوردید، سعی کنید خود rustup را به‌روزرسانی کنید:

    rustup self update
rustup +nightly component add enzyme

    راهنمای نصب برای Nix

    در Nix می‌توانید یک toolchain نوع nightly برای Rust را به‌همراه مؤلفه Enzyme با استفاده از oxalica rust-overlay تعریف کنید.

    برای مثال:

    rust-bin.selectLatestNightlyWith (toolchain: toolchain.default.override {
  extensions = [ "enzyme" ];
})

    یا می‌توانید یک فایل toolchain بسازید که مؤلفه Enzyme را اعلام کند، مانند

    [toolchain]
channel = "nightly-2026-06-23"
components = [ "enzyme" ]

    و آن را در overlay مصرف کنید

    rust-bin.fromRustupToolchainFile ./rust-toolchain.toml

    دستورالعمل ساخت

    ابتدا باید مخزن Rust را clone و پیکربندی کنید. بسته به ترجیح خود، ممکن است بخواهید --enable-clang یا --enable-lld را نیز فعال کنید.

    git clone git@github.com:rust-lang/rust
cd rust
./configure --release-channel=nightly --enable-llvm-enzyme --enable-llvm-link-shared --enable-llvm-assertions --enable-ninja --enable-option-checking --disable-docs --set llvm.download-ci-llvm=false

    سپس می‌توانید rustc را با دستور زیر بسازید:

    ./x build --stage 1 library

    پس از آن، پیوند toolchain مربوط به rustc به شما اجازه می‌دهد آن را از طریق cargo استفاده کنید:

    rustup toolchain link enzyme build/host/stage1
rustup toolchain install nightly # enables -Z unstable-options

    سپس می‌توانید آزمون‌های ما را اجرا کنید:

    ./x test --stage 1 tests/codegen-llvm/autodiff
./x test --stage 1 tests/pretty/autodiff
./x test --stage 1 tests/ui/autodiff
./x test --stage 1 tests/run-make/autodiff
./x test --stage 1 tests/ui/feature-gates/feature-gate-autodiff.rs

    Autodiff هنوز آزمایشی است، بنابراین اگر می‌خواهید در پروژه‌های خودتان از آن استفاده کنید، باید lto="fat" را به Cargo.toml خود اضافه کنید و به‌جای cargo یا cargo +nightly از RUSTFLAGS="-Zautodiff=Enable" cargo +enzyme استفاده کنید.

    Compiler Explorer و ساخت‌های dist

    نمونه compiler explorer ما را می‌توان به شیوه‌ای مشابه به یک rustc جدیدتر به‌روز کرد. ابتدا یک نمونه docker آماده کنید.

    docker run -it ubuntu:22.04
export CC=clang CXX=clang++
apt update
apt install wget vim python3 git curl libssl-dev pkg-config lld ninja-build cmake clang build-essential

    سپس rustc را به شیوه‌ای کمی تغییریافته بسازید:

    git clone https://github.com/rust-lang/rust
cd rust
./configure --release-channel=nightly --enable-llvm-enzyme --enable-llvm-link-shared --enable-llvm-assertions --enable-ninja --enable-option-checking --disable-docs --set llvm.download-ci-llvm=false
./x dist

    سپس tarball را به میزبان خود کپی می‌کنیم. dockerid جدیدترین ورودی در خروجی docker ps -a است.

    docker cp <dockerid>:/rust/build/dist/rust-nightly-x86_64-unknown-linux-gnu.tar.gz rust-nightly-x86_64-unknown-linux-gnu.tar.gz

    پس از آن می‌توانیم یک تگ جدید (پیش‌انتشار) در مخزن EnzymeAD/rust ایجاد کنیم و یک PR روی مخزن EnzymeAD/enzyme-explorer بسازیم تا تگ را به‌روز کند. فراموش نکنید در PR از tgymnich بخواهید (ping) تا اسکریپت به‌روزرسانی خود را اجرا کند. توجه: ما باید EnzymeAD/rust را بایگانی کنیم و دستورالعمل‌های اینجا را به‌روز کنیم. explorer به‌زودی باید بتواند toolchain مربوط به rustc را از سرورهای رسمی rust دریافت کند.

    دستورالعمل ساخت خود Enzyme

    دنبال کردن دستورالعمل ساخت Rust در بالا، LLVMEnzyme، LLDEnzyme و ClangEnzyme را به‌همراه کامپایلر Rust می‌سازد. اگر فقط می‌خواهید از هر یک از آن‌ها استفاده کنید و تجربه‌ای با cmake ندارید، همین روش را توصیه می‌کنیم. با این حال، اگر ترجیح می‌دهید Enzyme را بدون Rust بسازید، این دستورالعمل‌ها ممکن است کمک کنند.

    git clone git@github.com:llvm/llvm-project
cd llvm-project
mkdir build
cd build
cmake -G Ninja ../llvm -DLLVM_TARGETS_TO_BUILD="host" -DLLVM_ENABLE_ASSERTIONS=ON -DLLVM_ENABLE_PROJECTS="clang;lld" -DLLVM_ENABLE_RUNTIMES="openmp" -DLLVM_ENABLE_PLUGINS=ON -DCMAKE_BUILD_TYPE=Release -DCMAKE_INSTALL_PREFIX=.
ninja
ninja install

    این یک ساخت کارآمد از LLVM به شما می‌دهد؛ اکنون می‌توانیم به ساخت Enzyme ادامه دهیم. از پوشه llvm-project خارج شوید و دستورهای زیر را اجرا کنید:

    git clone git@github.com:EnzymeAD/Enzyme
cd Enzyme/enzyme
mkdir build
cd build
cmake .. -G Ninja -DLLVM_DIR=<YourLocalPath>/llvm-project/build/lib/cmake/llvm/ -DLLVM_EXTERNAL_LIT=<YourLocalPath>/llvm-project/llvm/utils/lit/lit.py -DCMAKE_BUILD_TYPE=Release -DCMAKE_EXPORT_COMPILE_COMMANDS=YES -DBUILD_SHARED_LIBS=ON
ninja

    این Enzyme را می‌سازد و می‌توانید آن را در Enzyme/enzyme/build/lib/<LLD/Clang/LLVM/lib>Enzyme.so پیدا کنید. (پسوندها ممکن است بسته به سیستم‌عامل شما متفاوت باشند).
