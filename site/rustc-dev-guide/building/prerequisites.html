    سخت‌افزار

    برای ساخت به اتصال اینترنت نیاز دارید. فرایند bootstrap شامل به‌روزرسانی زیرماژول‌های git و دانلود یک کامپایلر beta است. لازم نیست اینترنت فوق‌العاده سریع باشد، اما سریع‌تر بودنش کمک می‌کند.

    نیازمندی‌های سخت‌افزاری سخت‌گیرانه‌ای وجود ندارد، اما ساخت کامپایلر از نظر محاسباتی پرهزینه است، بنابراین یک ماشین قوی‌تر کمک می‌کند، و من توصیه نمی‌کنم سعی کنید روی Raspberry Pi بسازید! موارد زیر را توصیه می‌کنیم.

    • بیش از ۳۰ گیگابایت فضای خالی دیسک. در غیر این صورت باید مدام کش‌های افزایشی را پاک کنید. فضای بیشتر بهتر است؛ کامپایلر کمی پرمصرف است و از این مشکل آگاهیم.
    • بیش از ۸ گیگابایت RAM
    • حداقل ۲ هسته. داشتن هسته‌های بیشتر واقعاً کمک می‌کند. ۱۰ یا ۲۰ یا بیشتر هم زیاد نیست!

    ماشین‌های قوی‌تر به ساخت‌های بسیار سریع‌تر منجر می‌شوند. اگر ماشین شما چندان قدرتمند نیست، یک راهبرد رایج این است که روی ماشین محلی فقط از ./x check استفاده کنید و بگذارید ساخت CI تغییرات شما را هنگام push کردن به شاخهٔ PR آزمایش کند.

    ساخت کامپایلر روی یک لپ‌تاپ با توان متوسط بیش از نیم ساعت طول می‌کشد. پیشنهاد می‌کنیم LLVM را از CI دانلود کنید تا لازم نباشد آن را از کد منبع بسازید (اینجا را ببینید).

    مانند cargo، سیستم ساخت از تا حد ممکن هسته‌های بیشتری استفاده می‌کند. گاهی این می‌تواند باعث شود حافظهٔ شما کم بیاید. می‌توانید با -j تعداد کارهای همزمان را تنظیم کنید. اگر یک ساخت کامل بیش از حدود ۴۵ دقیقه تا یک ساعت طول می‌کشد، احتمالاً بیشتر وقت صرف جابه‌جایی حافظه به swap و بازگرداندن آن می‌شود؛ سعی کنید از -j1 استفاده کنید.

    اگر فضای خالی دیسک زیادی ندارید، ممکن است بخواهید کامپایل افزایشی را خاموش کنید (اینجا را ببینید). این کار کامپایل را کندتر می‌کند (به‌ویژه پس از یک rebase)، اما مقدار زیادی فضا را از کش‌های افزایشی ذخیره می‌کند.
