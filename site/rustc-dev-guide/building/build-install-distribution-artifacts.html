راهنمای توسعهٔ rustcrustc Development Guide

    ساخت artifactهای توزیع

    ممکن است بخواهید کامپایلر را برای توزیع بسازید و بسته‌بندی کنید. برای این کار این دستور را اجرا کنید:

    ./x dist

    نصب از روی سورس

    ممکن است ترجیح دهید Rust (و ابزارهایی که در پیکربندی‌تان تنظیم شده‌اند) را با ساخت از روی سورس نصب کنید. در این صورت این دستور را اجرا کنید:

    ./x install

    توجه: اگر در حال آزمودن تغییری در کامپایلر هستید، شاید بخواهید کامپایلر را (با ./x build) بسازید و سپس یک toolchain بسازید، همان‌طور که اینجا توضیح داده شده است.

    برای نمونه، اگر toolchain ساخته‌شده «foo» نام داشته باشد، آن را با rustc +foo ... فراخوانی می‌کنید (که در آن … نشان‌دهنده بقیه آرگومان‌هاست).

    به جای نصب سراسری Rust (و ابزارهای فایل پیکربندی‌تان) می‌توانید متغیر محیطی DESTDIR را برای تغییر مسیر نصب تنظیم کنید. اگر می‌خواهید مسیرهای نصب را پویاتر تنظیم کنید، بهتر است برای این کار از گزینه‌های نصب در فایل پیکربندی استفاده کنید.
