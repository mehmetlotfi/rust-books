    Bootstrap کردن کامپایلر

    Bootstrapping فرایند استفاده از یک کامپایلر برای کامپایل کردن خودش است. دقیق‌تر بگوییم، یعنی استفاده از یک کامپایلر قدیمی‌تر برای کامپایل نسخه جدیدتر همان کامپایلر.

    این موضوع یک پارادوکس مرغ و تخم‌مرغی پدید می‌آورد: نخستین کامپایلر از کجا آمد؟ حتماً به زبانی دیگر نوشته شده بوده است. در مورد Rust، به زبان OCaml نوشته شده بود. اما مدت‌ها پیش کنار گذاشته شد و اکنون تنها راه ساخت یک نسخه مدرن rustc استفاده از نسخه‌ای کمی قدیمی‌تر است.

    سیستم ساخت bootstrap در Rust دقیقاً همین‌گونه کار می‌کند: نسخه beta فعلی rustc را دانلود می‌کند و سپس با آن کامپایلر جدید را کامپایل می‌کند.

    در این بخش ابتدا یک نمای کلی از کاری که Bootstrap انجام می‌دهد ارائه می‌کنیم و سپس مقدمه‌ای کلی بر چگونگی انجام آن توسط Bootstrap می‌آوریم.

    علاوه بر این، برای آشنایی با روش‌های اشکال‌زدایی، اشکال‌زدایی bootstrap را ببینید.
