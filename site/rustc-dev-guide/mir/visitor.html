    MIR visitor

    visitor مربوط به MIR ابزار مناسبی برای پیمایش MIR و جست‌وجوی چیزها یا اعمال تغییر در آن است. traitهای visitor در ماژول rustc_middle::mir::visit تعریف شده‌اند – دو تا از آن‌ها هست که با یک ماکرو تولید می‌شوند: Visitor (که روی &Mir عمل می‌کند و ارجاع‌های مشترک برمی‌گرداند) و MutVisitor (که روی &mut Mir عمل می‌کند و ارجاع‌های تغییرپذیر برمی‌گرداند).

    برای پیاده‌سازی visitor باید نوعی بسازید که visitor شما را نمایش دهد. معمولاً این نوع می‌خواهد به هر حالتی که هنگام پردازش MIR لازم دارید «آویزان بماند»:

    struct MyVisitor<...> {
    tcx: TyCtxt<'tcx>,
    ...
}

    و سپس trait با نام Visitor یا MutVisitor را برای آن نوع پیاده‌سازی می‌کنید:

    impl<'tcx> MutVisitor<'tcx> for MyVisitor {
    fn visit_foo(&mut self, ...) {
        ...
        self.super_foo(...);
    }
}

    همان‌طور که بالا نشان داده شد، درون impl می‌توانید هر یک از متدهای visit_foo (مثلاً visit_terminator) را بازنویسی کنید تا کدی بنویسید که هر وقت foo یافت شد اجرا شود. اگر می‌خواهید محتوای foo را به‌صورت بازگشتی پیمایش کنید، متد super_foo را فراخوانی می‌کنید. توجه کنید هرگز نمی‌خواهید super_foo را بازنویسی کنید.

    مثال بسیار ساده‌ای از visitor را می‌توان در LocalFinder یافت. با پیاده‌سازی متد visit_local، این visitor متغیرهای محلی‌ای را شناسایی می‌کند که می‌توانند کاندیدای بازترتیب‌دهی باشند.

    Traversal

    علاوه بر visitor، ماژول rustc_middle::mir::traversal توابع مفیدی برای پیمایش CFG مربوط به MIR به ترتیب‌های استاندارد مختلف دارد (مثل pre-order، reverse post-order و غیره).
