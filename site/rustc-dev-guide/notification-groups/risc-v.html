    RISC-V notification group

    برچسب GitHub: O-riscv
    دستور ping: @rustbot ping risc-v

    این فهرست برای درخواست کمک هم در تشخیص و تست مسائل مرتبط با RISC-V و هم پیشنهادهایی برای حل پرسش‌های جالب دربارهٔ پشتیبانی ما از RISC-V به‌کار می‌رود.

    این گروه یک کانال Zulip وابسته هم دارد (#t-compiler/risc-v) که افراد می‌توانند در آن پرسش مطرح کنند و دربارهٔ موضوعات مخصوص RISC-V بحث کنند.

    پس اگر علاقه‌مند به مشارکت هستید، لطفاً در گروه RISC-V ثبت‌نام کنید! برای این کار، یک PR روی مخزن rust-lang/team باز کنید. فقط این مثال را دنبال کنید، اما نام کاربری را به نام خودتان تغییر دهید!
