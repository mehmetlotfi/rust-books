    گروه اعلان هدف GPU

    برچسب GitHub: ندارد
    دستور ping: @rustbot ping gpu-target

    این گروه اعلان به مسائل مرتبط با لینکر و یکپارچگی آن‌ها درون کامپایلر می‌پردازد.

    این گروه یک stream در Zulip هم دارد (#t-compiler/gpgpu-backend) که افراد می‌توانند در آن پرسش مطرح کنند و دربارهٔ موضوعات و issueهای مرتبط با GPU بحث کنند.

    اگر علاقه‌مند به مشارکت هستید، با خیال راحت در این گروه ثبت‌نام کنید! برای این کار، یک PR روی مخزن rust-lang/team باز کنید و کاربر GitHub خود را به این فایل اضافه کنید.
