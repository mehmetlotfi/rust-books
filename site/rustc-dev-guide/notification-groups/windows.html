    Windows notification group

    برچسب GitHub: O-Windows
    دستور ping: @rustbot ping windows

    این فهرست برای درخواست کمک هم در تشخیص و تست مسائل مرتبط با Windows و هم پیشنهادهایی برای حل پرسش‌های جالب دربارهٔ پشتیبانی ما از Windows به‌کار می‌رود.

    این گروه یک کانال Zulip وابسته هم دارد (#t-compiler/windows) که افراد می‌توانند در آن پرسش مطرح کنند و دربارهٔ موضوعات مخصوص Windows بحث کنند.

    برای تصور بهتر از کاری که گروه انجام می‌دهد، در ادامه مثال‌هایی از انواع پرسش‌هایی آمده که برای تعیین بهترین مسیر اقدام از گروه مشورت می‌خواستیم:

    • از کدام نسخه‌های MinGW باید پشتیبانی کنیم؟
    • آیا باید نصب‌کنندهٔ GUI قدیمی InnoSetup را حذف کنیم؟ #72569
    • برای کتابخانه‌های استاتیک در Windows از چه نام‌هایی استفاده کنیم؟ #29520

    پس اگر علاقه‌مند به مشارکت هستید، لطفاً در گروه Windows ثبت‌نام کنید! برای این کار، یک PR روی مخزن rust-lang/team باز کنید. فقط این مثال را دنبال کنید، اما نام کاربری را به نام خودتان تغییر دهید!
