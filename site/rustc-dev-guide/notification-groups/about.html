    Notification groups

    گروه‌های اعلان (notification groups) راه آسانی برای کمک به rustc به شکل «تکه‌تکه» هستند، بدون تعهد به پروژه‌ای بزرگ‌تر. پیوستن به گروه‌های اعلان آسان است (فقط یک PR بفرستید!) و پیوستن هیچ تعهد خاصی به همراه ندارد.

    وقتی به یک گروه اعلان بپیوندید، به فهرستی اضافه می‌شوید که هر وقت issue جدیدی که با معیارهای گروه اعلان جور باشد پیدا شود در GitHub ping می‌گیرد. اگر علاقه داشتید می‌توانید issue را claim کنید و کار روی آن را شروع کنید.

    البته لازم نیست منتظر برچسب‌خوردن issueهای جدید باشید! اگر ترجیح می‌دهید، می‌توانید از برچسب GitHub مربوط به گروه اعلان برای جست‌وجوی issueهای موجود که هنوز claim نشده‌اند استفاده کنید.

    فهرست گروه‌های اعلان

    این فهرست گروه‌های اعلان است:

    چه issueهایی برای گروه‌های اعلان مناسب‌اند؟

    گروه‌های اعلان معمولاً برای باگ‌های منزوی ping می‌شوند، به‌ویژه آن‌هایی که اولویت متوسط دارند:

    • منظور از منزوی این است که انتظار نداریم برای رفع باگ بازآرایی بزرگ‌مقیاس لازم باشد.
    • منظور از اولویت متوسط این است که دوست داریم باگ رفع شود، اما آن‌قدر مشکل سوزانی نیست که همه‌چیز را رها کنیم و آن را رفع کنیم. خطر چنین باگ‌هایی البته این است که می‌توانند با گذشت زمان انباشته شوند، و نقش گروه اعلان تلاش برای جلوگیری از این است!

    پیوستن به یک گروه اعلان

    برای پیوستن به یک گروه اعلان، فقط باید PRای باز کنید که نام کاربری GitHub شما را به فایل مناسب در مخزن تیم Rust اضافه می‌کند. برای تصور دقیق و شناسایی فایلی که باید ویرایش شود «PRهای نمونه» زیر را ببینید.

    همچنین اگر هنوز عضو هیچ تیم Rust نیستید، علاوه بر افزودن نام خود به فایل، باید مخزن را checkout کنید و دستور زیر را اجرا کنید:

    cargo run add-person $your_user_name

    برچسب‌زدن یک issue برای گروه اعلان

    برای برچسب‌زدن یک issue به‌عنوان مناسب برای گروه اعلان، به rustbot دستور ping با نام گروه اعلان می‌دهید. برای مثال:

    @rustbot ping apple
@rustbot ping arm
@rustbot ping emscripten
@rustbot ping risc-v
@rustbot ping wasi
@rustbot ping wasm
@rustbot ping windows

    برای کوتاه‌تر و راحت‌تر به یاد ماندنی‌شدن برخی دستورها، نام‌های مستعاری هست که در فایل triagebot.toml تعریف شده‌اند. برای مثال، همهٔ این دستورها معادل‌اند و گروه Apple را ping می‌کنند:

    @rustbot ping apple
@rustbot ping macos
@rustbot ping ios

    به یاد داشته باشید این نام‌های مستعار برای راحتی انسان‌ها هستند. ممکن است تغییر کنند. اگر لازم است مطمئن شوید یک دستور همیشه معتبر خواهد بود، فراخوانی‌های کامل را به نام‌های مستعار ترجیح دهید.

    اما توجه کنید این فقط باید توسط اعضای تیم کامپایلر یا مشارکت‌کنندگان انجام شود، و معمولاً به‌عنوان بخشی از triage تیم کامپایلر انجام می‌شود.
