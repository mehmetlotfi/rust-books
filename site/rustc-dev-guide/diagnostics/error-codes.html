    کدهای خطا

    ما عموماً تلاش می‌کنیم به هر پیام خطا یک کد یکتا مانند E0123 اختصاص دهیم. این کدها در کامپایلر در فایل‌های diagnostics.rs که در هر crate قرار دارند تعریف می‌شوند و عمدتاً از ماکروها تشکیل شده‌اند. هر کد خطا یک توضیح (explanation) مرتبط دارد: کدهای خطای جدید باید آن را شامل شوند. توجه کنید که همه‌ی کدهای خطای تاریخی (که دیگر صادر نمی‌شوند) توضیح ندارند.

    توضیحات خطا

    توضیحات به زبان Markdown نوشته می‌شوند (برای جزئیات نحو، CommonMark Spec را ببینید)، و همه‌ی آن‌ها در crate به نام rustc_error_codes پیوند داده شده‌اند. لطفاً برای جزئیات نحوه‌ی قالب‌بندی و نوشتن توضیحات بلند کدهای خطا، RFC 1567 را بخوانید. از مارس 2026، تلاشی1 برای جایگزینی این RFC که تا حد زیادی منسوخ شده با یک استاندارد جدید و انعطاف‌پذیرتر در جریان است.

    توضیحات خطا باید پیام خطا را بسط دهند و جزئیاتی درباره‌ی چرا رخ دادن خطا ارائه کنند. کپی و پیست کردن یک راه‌حل سریع برای کاربران مفید نیست؛ توضیحات باید به کاربران کمک کنند بفهمند چرا کدشان توسط کامپایلر پذیرفته نمی‌شود. Rust به پیام‌های خطای مفید افتخار می‌کند و توضیحات بلند نیز از این قاعده مستثنا نیستند. با این حال، تا زمانی که توضیحات خطا بازنگری شوند1، نحوه‌ی دقیق نوشتن آن‌ها تا حدی باز است؛ مثل همیشه: از بازبین خود بپرسید یا در Zulip مربوط به Rust بپرسید.

    اختصاص یک کد جدید

    کدهای خطا در compiler/rustc_error_codes ذخیره می‌شوند.

    برای ایجاد یک خطای جدید، ابتدا باید کد آزاد بعدی را پیدا کنید. می‌توانید آن را با باز کردن rustc_error_codes/src/lib.rs و پایین رفتن تا انتهای اعلان ماکروی error_codes! پیدا کنید.

    در اینجا ممکن است ببینیم بالاترین کد خطای در حال استفاده E0805 است، پس احتمالاً E0806 را می‌خواهیم. برای اطمینان، rg E0806 را اجرا کنید و بررسی کنید؛ نباید هیچ ارجاعی ببینید.

    باید برای خطای خود یک توضیح بسط‌یافته بنویسید که در rustc_error_codes/src/error_codes/E0806.md قرار می‌گیرد. برای ثبت خطا، کد را (به ترتیب عددی درست) به ماکروی error_codes! اضافه کنید، به این صورت:

    macro_rules! error_codes {
...
0806,
}

    برای صادر کردن واقعی خطا می‌توانید از ماکروی struct_span_code_err! استفاده کنید:

    struct_span_code_err!(self.dcx(), // some path to the `DiagCtxt` here
                 span, // whatever span in the source you want
                 E0806, // your new error code
                 fluent::example::an_error_message)
    .emit() // actually issue the error

    اگر می‌خواهید یادداشت‌ها یا قطعه‌های دیگری اضافه کنید، می‌توانید پیش از فراخوانی .emit() متدهایی را صدا بزنید:

    struct_span_code_err!(...)
    .span_label(another_span, fluent::example::example_label)
    .span_note(another_span, fluent::example::separate_note)
    .emit()

    برای نمونه‌ای از یک PR که یک کد خطا اضافه می‌کند، #76143 را ببینید.

    اجرای doctestهای کد خطا

    برای آزمودن مثال‌های اضافه‌شده در rustc_error_codes/src/error_codes، مولد نمایه‌ی خطا (error index generator) را با دستور زیر اجرا کنید:

    ./x test ./src/tools/error_index_generator
