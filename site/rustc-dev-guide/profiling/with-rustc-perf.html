    پروفایل‌کردن با rustc-perf

    مجموعهٔ benchmark در Rust روشی جامع برای پروفایل‌کردن و benchmark‌کردن کامپایلر Rust فراهم می‌کند. دستورالعمل استفاده از این مجموعه را در راهنمای آن می‌یابید.

    اما استفادهٔ دستی از این مجموعه می‌تواند کمی دست‌وپاگیر باشد. برای آسان‌تر‌کردن این کار برای مشارکت‌کنندگان rustc، سامانهٔ ساخت کامپایلر (bootstrap) هم یکپارچگی داخلی با مجموعهٔ benchmark فراهم می‌کند، که مجموعه را دانلود و برایتان می‌سازد، toolchain محلی کامپایلر می‌سازد و اجازه می‌دهد آن را با رابط خط فرمان ساده‌شده پروفایل کنید.

    می‌توانید از دستور ./x perf <command> [options] برای استفاده از این یکپارچگی استفاده کنید.

    می‌توانید از پرچم‌های معمول bootstrap برای این دستور استفاده کنید، مثل --stage 1 یا --stage 2، مثلاً برای تغییر stage مربوط به sysroot ساخته‌شده. همچنین ممکن است پیکربندی bootstrap.toml برای پشتیبانی بهتر از پروفایل‌کردن مفید باشد، مثلاً تنظیم rust.debuginfo-level = 1 برای افزودن اطلاعات خط منبع به کامپایلر ساخته‌شده.

    x perf فعلاً این دستورها را پشتیبانی می‌کند:

    • benchmark <id>: کامپایلر را benchmark می‌کند و نتایج را زیر id داده‌شده ذخیره می‌کند.
    • compare <baseline> <modified>: نتایج benchmark دو کامپایلر را با دو id داده‌شده مقایسه می‌کند.
    • eprintln: فقط کامپایلر را اجرا می‌کند و خروجی stderr آن را می‌گیرد. توجه کنید که کامپایلر معمولاً هیچ چیزی در stderr چاپ نمی‌کند، پس ممکن است بخواهید برای گرفتن خروجی چند فراخوانی eprintln! اضافه کنید.
    • samply: کامپایلر را با پروفایلر نمونه‌بردار samply پروفایل می‌کند.
    • cachegrind: از Cachegrind برای تولید ردیابی شبیه‌سازی‌شدهٔ دقیقی از اجرای کامپایلر استفاده می‌کند.

    توضیح مفصل‌تری از پروفایلرها را در راهنمای rustc-perf می‌یابید.

    می‌توانید از گزینه‌های زیر برای دستور x perf استفاده کنید که مشابه گزینه‌های متناظر دستورهای profile_local و bench_local هستند که در مجموعه می‌توانید به‌کار ببرید:

    • --include: benchmarkهایی را که باید پروفایل/benchmark شوند انتخاب می‌کند.
    • --profiles: profileهایی (Check، Debug، Opt، Doc) را که باید پروفایل/benchmark شوند انتخاب می‌کند.
    • --scenarios: سناریوهایی (Full، IncrFull، IncrPatched، IncrUnchanged) را که باید پروفایل/benchmark شوند انتخاب می‌کند.

    مثال diff پروفایل برای crateهای خارجی

    ممکن است بخواهید برای crateهای خارجی یک diff محلی بین دو commit از کامپایلر تولید کنید. برای شروع، در مخزن rustc-perf، collector را که benchmarkهای کامپایلر Rust را اجرا می‌کند به این شکل بسازید.

    cargo build --release -p collector

    سپس collector را می‌توان با cargo اجرا کرد، با مشخص‌کردن فایل دودویی collector. این آرگومان‌های زیر را انتظار دارد:

    • <PROFILE>: انتخاب پروفایلر برای نحوهٔ اندازه‌گیری عملکرد. در این مثال از Cachegrind استفاده می‌کنیم.
    • <RUSTC>: نسخهٔ کامپایلر Rust برای benchmark، که به‌صورت commit SHA از rust-lang/rust مشخص می‌شود. آرگومان‌های اختیاری اجازهٔ اجرای profileها و سناریوها را همان‌طور که در بالا شرح داده شد می‌دهند. اطلاعات بیشتر دربارهٔ آرگومان‌های اجباری و اختیاری را در rustc-perf-readme-profilers می‌یابید.

    سپس، برای تولید diff پروفایل برای crate با نام serve_derive-1.0.136، برای دو commit به نام‌های <SHA1> و <SHA2> از مخزن rust-lang/rust، این را در مخزن rustc-perf اجرا کنید:

    cargo run --release --bin collector profile_local cachegrind +<SHA1> --rustc2 +<SHA2> --exact-match serde_derive-1.0.136 --profiles Check --scenarios IncrUnchanged
