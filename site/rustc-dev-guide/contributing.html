    گزارش باگ

    باگ‌ها هرچند ناخوشایندند، واقعیتِ نرم‌افزارند. ما نمی‌توانیم چیزی را که از آن خبر نداریم رفع کنیم، پس لطفاً گزارش‌دادن را دریغ نکنید. اگر مطمئن نیستید که چیزی باگ است یا نه، باز هم راحت یک issue باز کنید.

    اگر فکر می‌کنید گزارش عمومی باگ شما برای کاربران Rust خطر امنیتی دارد، لطفاً دستورالعمل‌های گزارش آسیب‌پذیری‌های امنیتی را دنبال کنید.

    اگر از کانال nightly استفاده می‌کنید، لطفاً پیش از ثبت باگ بررسی کنید که آیا باگ در آخرین toolchain هم وجود دارد. ممکن است قبلاً رفع شده باشد.

    اگر فرصت دارید، پیش از گزارش باگ لطفاً issueهای موجود را جست‌وجو کنید، چون ممکن است کس دیگری خطای شما را قبلاً گزارش کرده باشد. این روش همیشه جواب نمی‌دهد و گاهی دشوار است بدانید چه چیزی را جست‌وجو کنید، پس آن را یک امتیاز اضافه بدانید. اگر به‌طور اتفاقی گزارش تکراری ثبت کنید ایرادی ندارد.

    همچنین برای اینکه دیگرانی که با همین باگ روبه‌رو شده‌اند issue شما را پیدا کنند، بهتر است issue را با عنوانی توصیفی ثبت کنید که اطلاعاتی منحصر به آن باگ داشته باشد. این اطلاعات می‌تواند ویژگی زبان یا کامپایلر مورد استفاده، شرایطی که باگ را ایجاد می‌کند، یا بخشی از پیام خطا (در صورت وجود) باشد. مثالی از آن: “impossible case reached” on lifetime inference for impl Trait in return position.

    باز‌کردن issue به آسانی دنبال‌کردن این پیوند و پر‌کردن فیلدهای قالب مناسبی است که ارائه شده.

    سایر رویه‌ها

    سایر رویه‌های مشارکت در بخش‌هایی از راهنما که مسئول آن‌ها هستند مستند شده‌اند:

    • برای تغییرات معمول یا pull requestهای بزرگ و فراگیر، به تغییرات عادی کد، چرخهٔ عمر PR و راهنمای pull request مراجعه کنید.

    • برای ویژگی‌های جدید، تغییرات بزرگ و تغییرات ناسازگار، به پیاده‌سازی ویژگی‌های جدید زبان و رویه‌های تغییرات ناسازگار مراجعه کنید.

    • برای تغییرات حساس به کارایی، به آزمون کارایی مراجعه کنید.

    • برای مستندات کامپایلر، به مشارکت در مستندات مراجعه کنید.

    • برای بررسی و اولویت‌بندی issueها، به triage issueها مراجعه کنید.

    • برای راهنمایی دربارهٔ استفاده از LLMها، به اجرای LLMها مراجعه کنید.

    • برای تغییرات خود این راهنما، به نوشتن مستندات rustc-dev-guide مراجعه کنید.

    • برای وابستگی‌های خارجی، به استفاده از مخازن خارجی مراجعه کنید.

    • برای منابع بیشتر، به دربارهٔ این راهنما مراجعه کنید.
