راهنمای توسعهٔ rustcrustc Development Guide

    Feature gateها

    این فصل برای ارائهٔ راهنمایی پایه در افزودن، حذف و تغییر feature gateها در نظر گرفته شده است.

    برای اینکه ببینید rustc چگونه feature gateها را در خط لولهٔ کامپایلر اعمال و بررسی می‌کند، به بررسی Feature Gate مراجعه کنید.

    توجه کنید که این مطلب مخصوص feature gateهای زبان است؛ feature gateهای کتابخانه از سازوکاری متفاوت استفاده می‌کنند.

    افزودن یک feature gate

    برای دستورالعمل‌ها به بخش “Stability in code” در قسمت «پیاده‌سازی ویژگی‌های جدید» مراجعه کنید.

    حذف یک feature gate

    برای حذف یک feature gate، این مراحل را دنبال کنید:

    1. اعلان feature gate را در rustc_feature/src/unstable.rs حذف کنید. به این شکل خواهد بود:

      /// description of feature
(unstable, $feature_name, "$version", Some($tracking_issue_number))

    2. نسخهٔ اصلاح‌شده‌ای از اعلان feature gate را که همین الان حذف کردید به rustc_feature/src/removed.rs اضافه کنید:

      /// description of feature
(removed, $old_feature_name, "$version", Some($tracking_issue_number),
 Some("$why_it_was_removed"))

    تغییر نام یک feature gate

    برای تغییر نام یک feature gate، این مراحل را دنبال کنید (دو مرحلهٔ اول همان مراحلی است که هنگام حذف یک feature gate باید دنبال شود):

    1. اعلان قدیمی feature gate را در rustc_feature/src/unstable.rs حذف کنید. به این شکل خواهد بود:

      /// description of feature
(unstable, $old_feature_name, "$version", Some($tracking_issue_number))

    2. نسخهٔ اصلاح‌شده‌ای از اعلان قدیمی feature gate را که همین الان حذف کردید به rustc_feature/src/removed.rs اضافه کنید:

      /// description of feature
/// Renamed to `$new_feature_name`
(removed, $old_feature_name, "$version", Some($tracking_issue_number),
 Some("renamed to `$new_feature_name`"))

    3. یک اعلان feature gate با نام جدید به rustc_feature/src/unstable.rs اضافه کنید. باید بسیار شبیه اعلان قدیمی باشد:

      /// description of feature
(unstable, $new_feature_name, "$version", Some($tracking_issue_number))

    پایدارسازی یک ویژگی

    برای دستورالعمل‌ها به بخش “Updating the feature-gate listing” در فصل «Stabilizing Features» مراجعه کنید. علاوه بر به‌روزرسانی اعلان، مراحل اضافی دیگری هم لازم است انجام دهید!
