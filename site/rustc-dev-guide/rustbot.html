راهنمای توسعهٔ rustcrustc Development Guide

    Mastering @rustbot

    @rustbot (که triagebot هم شناخته می‌شود) یک ربات کمکی است که عمدتاً برای این به‌کار می‌رود که هر مشارکت‌کننده‌ای بتواند کارهایی را انجام دهد که معمولاً به عضویت در سازمان rust-lang در GitHub نیاز دارند. جالب‌ترین قابلیت‌های آن برای مشارکت‌کنندگان rustc اختصاص‌دادن issue و تغییر برچسب‌هاست.

    Issue claiming

    وقتی قصد دارید روی یک issue تخصیص‌نیافته کار کنید آن را claim کنید. تخصیص issue را ببینید.

    Issue relabeling

    تغییر برچسب‌های یک issue یا PR هم معمولاً مخصوص اعضای سازمان است. اما @rustbot به شما اجازه می‌دهد با چند محدودیت، خودتان برچسب یک issue را تغییر دهید. این بیشتر در دو مورد مفید است:

    کمک به triage کردن issueها: issue tracker در Rust در زمان نگارش بیش از ۵٬۰۰۰ issue باز دارد، پس برچسب‌ها قدرتمندترین ابزاری هستند که برای تمیز نگه‌داشتن آن داریم. لازم نیست ساعت‌ها در issue tracker صرف triage کنید، اما اگر issueای باز می‌کنید، اگر خودتان راحت هستید می‌توانید آن را برچسب‌گذاری کنید.

    به‌روزرسانی وضعیت یک PR: ما از «برچسب‌های وضعیت» برای نشان‌دادن وضعیت PRها استفاده می‌کنیم. برای مثال، اگر PR شما تعارض merge داشته باشد، به‌طور خودکار برچسب S-waiting-on-author می‌گیرد و ممکن است بازبین‌ها تا وقتی PR را rebase نکنید آن را بازبینی نکنند. وقتی branch خود را rebase کردید، باید برچسب‌ها را خودتان تغییر دهید تا برچسب S-waiting-on-author برداشته شود و S-waiting-on-review دوباره اضافه شود. در این مورد، دستور @rustbot این‌طور به نظر می‌رسد:

    @rustbot label -S-waiting-on-author +S-waiting-on-review

    نحو این دستور نسبتاً آزاد است، پس شکل‌های دیگری هم برای فراخوانی این دستور هست. میان‌برهایی هم برای به‌روزرسانی برچسب‌ها هست، برای مثال @rustbot ready همان کار دستور بالا را انجام می‌دهد. برای جزئیات بیشتر صفحهٔ مستندات برچسب‌گذاری و میان‌برها را ببینید.

    دستورهای دیگر

    اگر علاقه دارید ببینید @rustbot چه کارهایی از دستش برمی‌آید، مستندات آن را ببینید که به‌عنوان مرجع ربات در نظر گرفته شده و باید با هر ارتقای ربات به‌روز نگه داشته شود.

    @rustbot توسط تیم Release نگه‌داری می‌شود. اگر بازخوردی دربارهٔ دستورهای موجود یا پیشنهادی برای دستورهای جدید دارید، با خیال راحت در Zulip تماس بگیرید یا issueای در مخزن triagebot ثبت کنید.
