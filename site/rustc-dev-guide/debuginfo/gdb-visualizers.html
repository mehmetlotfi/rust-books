    GDB - ارائه‌دهنده‌های پایتون

    در ادامه پیوندهایی به بخش‌های مرتبط مستندات GDB آمده است

    • مروری بر نوشتن یک pretty printer
    • API مربوط به Pretty Printer (معادل SyntheticProvider در LLDB)
    • API مربوط به Value (معادل SBValue در LLDB)
    • API مربوط به Type (معادل SBType در LLDB)
    • API مربوط به Type Printing (معادل SyntheticProvider.get_type_name در LLDB)
