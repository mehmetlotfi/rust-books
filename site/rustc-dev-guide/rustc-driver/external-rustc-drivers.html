راهنمای توسعهٔ rustcrustc Development Guide

    External rustc_drivers

    rustc_private

    Overview

    قابلیت rustc_private به crateهای خارجی اجازه می‌دهد از درون‌ساز کامپایلر استفاده کنند.

    استفاده از rustc_private با toolchainهای رسمی

    هنگام استفاده از قابلیت rustc_private با toolchainهای رسمی Rust که از طریق rustup توزیع می‌شوند، باید دو مؤلفهٔ اضافی نصب کنید:

    1. rustc-dev: Provides compiler libraries
    2. llvm-tools: کتابخانه‌های LLVM لازم برای لینک را فراهم می‌کند

    Installation steps

    هر دو مؤلفه را با rustup نصب کنید:

    rustup component add rustc-dev llvm-tools

    Common error

    بدون مؤلفهٔ llvm-tools با خطاهای لینک مثل این روبه‌رو می‌شوید:

    error: linking with `cc` failed: exit status: 1
  |
  = note: rust-lld: error: unable to find library -lLLVM-{version}

    استفاده از rustc-private با toolchainهای سفارشی

    برای toolchainهای ساخته‌شده به‌صورت سفارشی یا محیط‌هایی که از rustup استفاده نمی‌کنند، معمولاً پیکربندی اضافی لازم است:

    Requirements

    • کتابخانه‌های LLVM باید در مسیرهای جست‌وجوی کتابخانهٔ سیستم شما در دسترس باشند
    • نسخهٔ LLVM باید با نسخه‌ای که برای ساخت toolchain Rust شما به‌کار رفته مطابقت داشته باشد

    Troubleshooting steps

    1. بررسی کنید LLVM نصب و در دسترس است
    2. مطمئن شوید مسیرهای کتابخانه تنظیم شده‌اند: 
      export LD_LIBRARY_PATH=/path/to/llvm/lib:$LD_LIBRARY_PATH
    3. مطمئن شوید نسخهٔ LLVM شما با toolchain Rust شما سازگار است

    پیکربندی rust-analyzer برای پروژه‌های خارج از درخت (out-of-tree)

    هنگام توسعهٔ پروژه‌های out-of-tree که از crateهای rustc_private استفاده می‌کنند، می‌توانید rust-analyzer را طوری پیکربندی کنید که این crateها را بشناسد.

    Configuration steps

    1. rust-analyzer.rustc.source را در تنظیمات ویرایشگر خود روی "discover" بگذارید.

      برای VS Code، این را به rust_analyzer_settings.json بیفزایید:

      {
    "rust-analyzer.rustc.source": "discover"
}

    2. این را به Cargo.toml هر crateای که از rustc_private استفاده می‌کند بیفزایید:

      [package.metadata.rust-analyzer]
rustc_private = true

    این پیکربندی به rust-analyzer اجازه می‌دهد crateهای rustc_private را در پروژه‌های out-of-tree درست بشناسد و پشتیبانی IDE ارائه دهد.

    گرفتن مستندات nightly برای rustc_private

    Latest nightly

    برای آخرین nightly، می‌توانید مؤلفهٔ rustc-docs را نصب کنید و مستقیماً در مرورگر باز کنید:

    rustup component add rustc-docs
rustup doc --rustc-docs

    نکته: مؤلفهٔ rustc-docs فقط برای toolchainهای nightly اخیر در دسترس است و ممکن است برای هر تاریخ nightly وجود نداشته باشد. اولین بار در PR #75560 (اوت 2020) معرفی شد.

    Older nightlies

    اگر به درون‌ساز کامپایلر از nightly قدیمی‌تری وابسته‌اید، ممکن است بخواهید به مستندات داخلی همان nightly مراجعه کنید. تنها راه این کار تولید محلی مستندات است. برای مثال، برای گرفتن مستندات nightly-2025-11-08:

    هش commit مربوط به Git آن nightly را بگیرید:

    rustup toolchain install nightly-2025-11-08
rustc +nightly-2025-11-08 --version --verbose

    خروجی شامل خطی با نام commit-hash است که نسخهٔ دقیق منبع را مشخص می‌کند. rust-lang/rust را روی همان commit checkout کنید، سپس گام‌های مستندات کامپایلر را دنبال کنید.
