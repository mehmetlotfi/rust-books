زبان برنامه‌نویسی RustThe Rust Programming Language

    سلام دنیا!

    حالا که Rust را نصب کرده‌اید، وقت نوشتن نخستین برنامه است. رسم یادگیری یک زبان جدید این است که برنامهٔ کوچکی بنویسیم که Hello, world! را روی صفحه چاپ کند؛ ما هم همین کار را می‌کنیم.

    نکته: این کتاب آشنایی پایه با خط فرمان را فرض می‌کند. Rust شما را به ویرایشگر یا ابزار خاصی محدود نمی‌کند. اگر IDE را ترجیح می‌دهید، از محیط دلخواهتان استفاده کنید. بسیاری از IDEها تا حدی از Rust پشتیبانی می‌کنند؛ جزئیات را در راهنمای همان IDE ببینید. تیم Rust نیز با rust-analyzer روی پشتیبانی باکیفیت از IDEها تمرکز دارد. اطلاعات بیشتر در پیوست D آمده است.

    آماده‌کردن پوشهٔ پروژه

    ابتدا پوشه‌ای برای نگه‌داری کد Rust بسازید. محل کد برای Rust اهمیتی ندارد، اما برای تمرین‌ها و پروژه‌های این کتاب پیشنهاد می‌کنیم پوشه‌ای به نام projects در پوشهٔ خانگی خود بسازید و همهٔ پروژه‌ها را آنجا نگه دارید.

    یک ترمینال باز کنید و دستورهای زیر را وارد کنید تا یک پوشهٔ projects و درون آن یک پوشه برای پروژهٔ «Hello, world!» ساخته شود.

    ترمینال را باز کنید. در لینوکس، macOS و PowerShell ویندوز این دستورها را وارد کنید:

    $ mkdir ~/projects
$ cd ~/projects
$ mkdir hello_world
$ cd hello_world

    برای CMD ویندوز این را وارد کنید:

    > mkdir "%USERPROFILE%\projects"
> cd /d "%USERPROFILE%\projects"
> mkdir hello_world
> cd hello_world

    مبانی یک برنامهٔ Rust

    فایل سورس تازه‌ای با نام main.rs بسازید. نام فایل‌های Rust همیشه به پسوند .rs ختم می‌شود. اگر نام فایل چند واژه دارد، طبق قرارداد آن‌ها را با زیرخط جدا کنید؛ برای نمونه hello_world.rs بهتر از helloworld.rs است.

    اکنون فایل main.rs را که همین الان ساخته‌اید باز کنید و کد لیستینگ ۱-۱ را در آن وارد کنید.

    فایل را ذخیره کنید و به ترمینال در پوشهٔ ~/projects/hello_world برگردید. در لینوکس یا macOS برنامه را این‌گونه کامپایل و اجرا کنید:

    $ rustc main.rs
$ ./main
Hello, world!

    در ویندوز به جای ./main از .\main استفاده کنید:

    > rustc main.rs
> .\main
Hello, world!

    در هر سیستم‌عاملی باید عبارت Hello, world! را در ترمینال ببینید. اگر این خروجی نمایش داده نشد، برای دریافت کمک به بخش رفع اشکال در راهنمای نصب برگردید.

    اگر Hello, world! چاپ شد، تبریک! شما رسماً یک برنامهٔ Rust نوشته‌اید. این یعنی شما یک برنامه‌نویس Rust هستید؛ خوش آمدید!

    کالبدشناسی یک برنامهٔ Rust

    برنامهٔ «سلام دنیا» را دقیق‌تر بررسی کنیم. نخستین بخش این است:

    fn main() {

}

    این خط‌ها تابعی به نام main تعریف می‌کنند. تابع main ویژه است: همیشه نخستین کدی است که در هر برنامهٔ اجرایی Rust اجرا می‌شود. در اینجا خط اول تابعی به نام main اعلان می‌کند که پارامتر ندارد و چیزی برنمی‌گرداند. اگر پارامتری وجود می‌داشت، داخل پرانتز (()) قرار می‌گرفت.

    بدنهٔ تابع میان {} قرار دارد. Rust برای بدنهٔ همهٔ تابع‌ها آکولاد می‌خواهد. روش رایج این است که آکولاد باز را با یک فاصله در همان خط تعریف تابع بنویسیم.

    نکته: اگر می‌خواهید در پروژه‌های Rust از یک سبک استاندارد پیروی کنید، می‌توانید از یک ابزار قالب‌بندی خودکار به نام rustfmt استفاده کنید تا کدتان را با سبکی مشخص قالب‌بندی کند (دربارهٔ rustfmt در پیوست D بیشتر می‌خوانید). تیم Rust این ابزار را، همان‌طور که rustc را، همراه توزیع استاندارد Rust قرار داده است، بنابراین باید از قبل روی رایانهٔ شما نصب شده باشد!

    بدنهٔ main این کد را در خود دارد:

    println!("Hello, world!");

    تمام کار برنامهٔ کوچک ما در همین خط انجام می‌شود: چاپ متن روی صفحه. سه نکتهٔ مهم در آن وجود دارد.

    نخست اینکه println! یک ماکروی Rust را فراخوانی می‌کند. اگر به‌جای آن یک تابع را فراخوانی می‌کرد، به‌صورت println (بدون !) نوشته می‌شد. ماکروهای Rust راهی برای نوشتن کدی هستند که کد تولید می‌کند تا نحو Rust را گسترش دهد، و در فصل ۲۰ با جزئیات بیشتری دربارهٔ آن‌ها صحبت خواهیم کرد. فعلاً فقط لازم است بدانید که استفاده از ! یعنی دارید یک ماکرو را به‌جای یک تابع معمولی فراخوانی می‌کنید و ماکروها همیشه از همان قواعد توابع پیروی نمی‌کنند.

    دوم، رشتهٔ "Hello, world!" را می‌بینید. آن را به‌عنوان آرگومان به println! می‌دهیم تا روی صفحه چاپ شود.

    سوم، خط با نقطه‌ویرگول (;) پایان می‌یابد. این علامت می‌گوید عبارت تمام شده و عبارت بعدی می‌تواند آغاز شود. بیشتر خط‌های کد Rust به نقطه‌ویرگول ختم می‌شوند.

    کامپایل و اجرا

    شما همین الان یک برنامهٔ تازه‌ساخته را اجرا کردید، پس بیایید هر مرحلهٔ این فرایند را بررسی کنیم.

    برنامهٔ تازه را اجرا کردید؛ حالا مرحله‌های این فرایند را جداگانه ببینیم. پیش از اجرای برنامهٔ Rust باید با کامپایلر و دستور rustc، همراه نام فایل سورس، آن را کامپایل کنید:

    $ rustc main.rs

    اگر پیش‌زمینهٔ C یا C++ دارید، شباهت این دستور با gcc یا clang را می‌بینید. پس از کامپایل موفق، Rust یک فایل اجرایی دودویی تولید می‌کند.

    در لینوکس، macOS و PowerShell ویندوز با ls فایل اجرایی را می‌بینید:

    $ ls
main  main.rs

    در لینوکس و macOS دو فایل می‌بینید. PowerShell ویندوز همان سه فایلی را نشان می‌دهد که در CMD دیده می‌شوند. در CMD این دستور را بزنید:

    > dir /B %= the /B option says to only show the file names =%
main.exe
main.pdb
main.rs

    خروجی شامل فایل سورس با پسوند .rs، فایل اجرایی (main.exe در ویندوز و main در دیگر سیستم‌ها) و در ویندوز فایل اطلاعات اشکال‌زدایی با پسوند .pdb است. حالا فایل اجرایی را اجرا کنید:

    $ ./main # or .\main on Windows

    اگر main.rs شما همان برنامهٔ «Hello, world!» باشد، این خط Hello, world! را در ترمینال شما چاپ می‌کند.

    اگر بیشتر با زبان‌های پویا مانند Ruby، Python یا JavaScript کار کرده‌اید، شاید به جدا بودن مرحلهٔ کامپایل و اجرا عادت نداشته باشید. Rust زبانی است که پیش از اجرا کامپایل می‌شود؛ یعنی می‌توانید برنامه را کامپایل کنید و فایل اجرایی را به فرد دیگری بدهید تا حتی بدون نصب Rust آن را اجرا کند. در مقابل، گیرندهٔ فایل .rb، .py یا .js باید پیاده‌سازی زبان مربوط را نصب داشته باشد؛ هرچند در آن زبان‌ها معمولاً یک دستور برای اجرای برنامه کافی است. طراحی زبان همیشه با بده‌بستان‌هایی همراه است.

    کامپایل مستقیم با rustc برای برنامه‌های ساده مناسب است، اما با بزرگ‌شدن پروژه لازم است گزینه‌ها را مدیریت و اشتراک کد را آسان کنید. در بخش بعد با Cargo آشنا می‌شویم؛ ابزاری که به نوشتن برنامه‌های واقعی Rust کمک می‌کند.
