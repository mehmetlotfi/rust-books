زبان برنامه‌نویسی RustThe Rust Programming Language

    ضمیمه د: ابزارهای مفید توسعه

    در این ضمیمه دربارهٔ چند ابزار مفید توسعه صحبت می‌کنیم که پروژهٔ Rust ارائه می‌دهد. به قالب‌بندی خودکار، راه‌های سریع برای اعمال اصلاحات هشدارها، یک linter و یکپارچه‌سازی با IDEها نگاهی می‌اندازیم.

    قالب‌بندی خودکار با rustfmt

    ابزار rustfmt کد شما را بر اساس سبک کدنویسی جامعه بازقالب‌بندی می‌کند. بسیاری از پروژه‌های مشارکتی از rustfmt استفاده می‌کنند تا از بحث دربارهٔ انتخاب سبک نوشتن Rust جلوگیری شود: همه کد خود را با همین ابزار قالب‌بندی می‌کنند.

    نصب‌های Rust به‌طور پیش‌فرض شامل rustfmt هستند، بنابراین باید برنامه‌های rustfmt و cargo-fmt از قبل روی سیستم شما وجود داشته باشند. این دو دستور شبیه rustc و cargo هستند، به این معنا که rustfmt کنترل دقیق‌تری می‌دهد و cargo-fmt با قراردادهای پروژه‌هایی که از Cargo استفاده می‌کنند آشناست. برای قالب‌بندی هر پروژهٔ Cargo، دستور زیر را وارد کنید:

    $ cargo fmt

    اجرای این دستور تمام کد Rust موجود در crate فعلی را بازقالب‌بندی می‌کند. این کار فقط باید سبک کد را تغییر دهد، نه معنای آن را. برای اطلاعات بیشتر دربارهٔ rustfmt به مستندات آن مراجعه کنید.

    اصلاح کد با rustfix

    ابزار rustfix همراه نصب‌های Rust ارائه می‌شود و می‌تواند هشدارهای کامپایلر را که راه روشنی برای رفع مشکل دارند و احتمالاً همان چیزی است که شما می‌خواهید، به‌طور خودکار اصلاح کند. احتمالاً قبلاً هشدارهای کامپایلر را دیده‌اید. برای مثال، این کد را در نظر بگیرید:

    نام فایل: src/main.rs

    fn main() {
    let mut x = 42;
    println!("{x}");
}

    در اینجا متغیر x را تغییرپذیر تعریف کرده‌ایم، اما هرگز آن را تغییر نمی‌دهیم. Rust دربارهٔ این موضوع به ما هشدار می‌دهد:

    $ cargo build
   Compiling myprogram v0.1.0 (file:///projects/myprogram)
warning: variable does not need to be mutable
 --> src/main.rs:2:9
  |
2 |     let mut x = 0;
  |         ----^
  |         |
  |         help: remove this `mut`
  |
  = note: `#[warn(unused_mut)]` on by default

    این هشدار پیشنهاد می‌کند کلیدواژهٔ mut را حذف کنیم. با اجرای دستور cargo fix می‌توانیم این پیشنهاد را با ابزار rustfix به‌طور خودکار اعمال کنیم:

    $ cargo fix
    Checking myprogram v0.1.0 (file:///projects/myprogram)
      Fixing src/main.rs (1 fix)
    Finished dev [unoptimized + debuginfo] target(s) in 0.59s

    وقتی دوباره به src/main.rs نگاه کنیم، می‌بینیم که cargo fix کد را تغییر داده است:

    نام فایل: src/main.rs

    fn main() {
    let x = 42;
    println!("{x}");
}

    اکنون متغیر x تغییرناپذیر است و هشدار دیگر نمایش داده نمی‌شود.

    همچنین می‌توانید از دستور cargo fix برای انتقال کد خود بین edition‌های مختلف Rust استفاده کنید. دربارهٔ edition‌ها در ضمیمهٔ ه توضیح داده شده است.

    lintهای بیشتر با Clippy

    ابزار Clippy مجموعه‌ای از lintها است که کد شما را تحلیل می‌کند تا بتوانید اشتباهات رایج را پیدا کنید و کد Rust خود را بهبود دهید. Clippy همراه نصب‌های استاندارد Rust ارائه می‌شود.

    برای اجرای lintهای Clippy روی هر پروژهٔ Cargo، دستور زیر را وارد کنید:

    $ cargo clippy

    برای مثال، فرض کنید برنامه‌ای می‌نویسید که از تقریبی از یک ثابت ریاضی مانند pi استفاده می‌کند، همان‌طور که این برنامه می‌کند:

    اجرای cargo clippy روی این پروژه به این خطا می‌انجامد:

    error: approximate value of `f{32, 64}::consts::PI` found
 --> src/main.rs:2:13
  |
2 |     let x = 3.1415;
  |             ^^^^^^
  |
  = note: `#[deny(clippy::approx_constant)]` on by default
  = help: consider using the constant directly
  = help: for further information visit https://rust-lang.github.io/rust-clippy/master/index.html#approx_constant

    این خطا به شما می‌گوید که Rust از قبل ثابت دقیق‌تری به نام PI تعریف کرده است و اگر به‌جای آن از این ثابت استفاده کنید، برنامه‌تان درست‌تر خواهد بود. سپس کد خود را طوری تغییر می‌دهید که از ثابت PI استفاده کند.

    یکپارچه‌سازی با IDE با استفاده از rust-analyzer

    برای کمک به یکپارچه‌سازی با IDE، جامعهٔ Rust استفاده از rust-analyzer را توصیه می‌کند. این ابزار مجموعه‌ای از ابزارهای کامپایلرمحور است که با Language Server Protocol کار می‌کند؛ پروتکلی که مشخص می‌کند IDEها و زبان‌های برنامه‌نویسی چگونه با یکدیگر ارتباط برقرار کنند. کلاینت‌های مختلفی می‌توانند از rust-analyzer استفاده کنند، مانند افزونهٔ Rust analyzer برای Visual Studio Code.

    برای دستورالعمل نصب، به صفحهٔ اصلی پروژهٔ rust-analyzer سر بزنید و سپس پشتیبانی از language server را در IDE خود نصب کنید. IDE شما قابلیت‌هایی مانند تکمیل خودکار، پرش به تعریف و نمایش خطاها به‌صورت درون‌خطی را به دست خواهد آورد.
