زبان برنامه‌نویسی RustThe Rust Programming Language

    نصب

    نخستین قدم، نصب Rust است. Rust را با rustup دریافت می‌کنیم؛ ابزاری خط فرمان برای مدیریت نسخه‌های Rust و ابزارهای وابسته. برای دانلود به اینترنت نیاز دارید.

    نکته: اگر به هر دلیل نمی‌خواهید از rustup استفاده کنید، گزینه‌های دیگر را در صفحهٔ روش‌های دیگر نصب Rust ببینید.

    مراحل زیر تازه‌ترین نسخهٔ پایدار کامپایلر Rust را نصب می‌کنند. تضمین پایداری Rust باعث می‌شود همهٔ نمونه‌های قابل‌کامپایل این کتاب با نسخه‌های جدیدتر نیز کامپایل شوند. ممکن است خروجی میان نسخه‌ها کمی تفاوت داشته باشد، چون پیام‌های خطا و هشدار Rust پیوسته بهتر می‌شوند. در نتیجه هر نسخهٔ پایدار و جدیدی که با این مراحل نصب کنید باید با محتوای کتاب درست کار کند.

    شیوهٔ نمایش دستورهای خط فرمان

    در این فصل و سراسر کتاب، دستورهای ترمینال را نشان می‌دهیم. خط‌هایی که باید در ترمینال وارد کنید با $ شروع می‌شوند. خود نویسهٔ $ را تایپ نکنید؛ این فقط اعلان خط فرمان است و آغاز هر دستور را نشان می‌دهد. خط‌هایی که با $ شروع نمی‌شوند معمولاً خروجی دستور قبلی‌اند. در نمونه‌های مخصوص PowerShell به جای $ از > استفاده می‌کنیم.

    نصب rustup در لینوکس یا macOS

    اگر از لینوکس یا macOS استفاده می‌کنید، ترمینال را باز کنید و دستور زیر را وارد کنید:

    $ curl --proto '=https' --tlsv1.2 https://sh.rustup.rs -sSf | sh

    این دستور یک اسکریپت را دریافت و نصب rustup را آغاز می‌کند؛ سپس rustup تازه‌ترین نسخهٔ پایدار Rust را نصب می‌کند. ممکن است رمز عبورتان خواسته شود. اگر نصب موفق باشد این خط را می‌بینید:

    Rust is installed now. Great!

    به یک linker نیز نیاز دارید؛ برنامه‌ای که Rust با آن خروجی‌های کامپایل‌شده را در یک فایل کنار هم قرار می‌دهد. به احتمال زیاد linker از قبل روی سیستم شما هست. اگر خطایی مربوط به linker دیدید، یک کامپایلر C نصب کنید که معمولاً linker را هم به همراه دارد. کامپایلر C از این جهت نیز مفید است که بعضی بسته‌های رایج Rust به کد C وابسته‌اند.

    در macOS می‌توانید با این دستور کامپایلر C را نصب کنید:

    $ xcode-select --install

    کاربران لینوکس معمولاً باید مطابق راهنمای توزیع خود GCC یا Clang را نصب کنند. برای نمونه در Ubuntu می‌توانید بستهٔ build-essential را نصب کنید.

    نصب rustup در ویندوز

    در ویندوز به صفحهٔ نصب Rust بروید و دستورالعمل نصب را دنبال کنید. در بخشی از فرایند از شما خواسته می‌شود Visual Studio را نصب کنید. این برنامه linker و کتابخانه‌های بومی لازم برای کامپایل را فراهم می‌کند. اگر در این مرحله به راهنمای بیشتری نیاز دارید، راهنمای نصب MSVC را ببینید.

    بقیهٔ کتاب از دستورهایی استفاده می‌کند که هم در cmd.exe و هم در PowerShell کار می‌کنند. هرجا تفاوتی وجود داشته باشد مشخص می‌کنیم کدام را به کار ببرید.

    عیب‌یابی

    برای اطمینان از نصب درست Rust، یک shell باز کنید و این خط را وارد کنید:

    $ rustc --version

    باید شمارهٔ نسخه، هش commit و تاریخ انتشار تازه‌ترین نسخهٔ پایدار را با قالب زیر ببینید:

    rustc x.y.z (abcabcabc yyyy-mm-dd)

    اگر این اطلاعات نمایش داده شد، Rust با موفقیت نصب شده است. در غیر این صورت، به روش زیر بررسی کنید که Rust در متغیر سیستمی %PATH% قرار داشته باشد.

    در CMD ویندوز:

    > echo %PATH%

    در PowerShell:

    > echo $env:Path

    در لینوکس و macOS:

    $ echo $PATH

    اگر همهٔ این‌ها درست است و Rust هنوز کار نمی‌کند، جاهای مختلفی وجود دارد که می‌توانید از آن‌ها کمک بگیرید. در صفحهٔ جامعه ببینید چگونه با Rustaceanهای دیگر (لقب خودمانی و کمی شوخ‌طبعانه‌ای که به خودمان داده‌ایم) در تماس باشید.

    به‌روزرسانی و حذف

    پس از نصب Rust با rustup، به‌روزرسانی به نسخه‌های تازه آسان است. در shell این دستور را اجرا کنید:

    $ rustup update

    برای حذف Rust و rustup، این دستور را اجرا کنید:

    $ rustup self uninstall

    خواندن مستندات محلی

    همراه نصب Rust یک نسخهٔ محلی از مستندات نیز نصب می‌شود تا بتوانید بدون اینترنت آن را بخوانید. با اجرای rustup doc مستندات محلی در مرورگر باز می‌شوند.

    هر زمان کتابخانهٔ استاندارد نوع یا تابعی در اختیارتان گذاشت و مطمئن نبودید چه کاری انجام می‌دهد یا چگونه باید از آن استفاده کنید، پاسخ را در مستندات رابط برنامه‌نویسی (API) پیدا کنید.

    استفاده از ویرایشگر متن و IDE

    این کتاب هیچ پیش‌فرضی دربارهٔ ابزاری که برای نوشتن کد Rust استفاده می‌کنید ندارد. تقریباً هر ویرایشگر متنی کار را راه می‌اندازد! بااین‌حال، بسیاری از ویرایشگرهای متن و محیط‌های توسعهٔ یکپارچه (IDE) پشتیبانی داخلی از Rust دارند. همیشه می‌توانید فهرست نسبتاً به‌روزی از بسیاری از ویرایشگرها و IDEها را در صفحهٔ ابزارها در وب‌سایت Rust پیدا کنید.

    کار آفلاین با این کتاب

    در چند نمونه از بسته‌هایی بیرون از کتابخانهٔ استاندارد استفاده می‌کنیم. برای اجرای این نمونه‌ها یا باید به اینترنت وصل باشید یا وابستگی‌ها را از قبل دریافت کرده باشید. برای دریافت پیشاپیش وابستگی‌ها، دستورهای زیر را اجرا کنید. در ادامه با cargo و کار هرکدام از این دستورها دقیق‌تر آشنا می‌شویم.

    $ cargo new get-dependencies
$ cd get-dependencies
$ cargo add rand@0.10.1 trpl@0.2.0

    این کار بسته‌ها را در cache نگه می‌دارد تا بعداً لازم نباشد دوباره آن‌ها را دریافت کنید. پس از اجرای دستورها، نیازی به نگه‌داشتن پوشهٔ get-dependencies ندارید. از این پس می‌توانید گزینهٔ --offline را به همهٔ دستورهای cargo در ادامهٔ کتاب بدهید تا به جای تلاش برای اتصال به شبکه، از نسخه‌های ذخیره‌شده استفاده کنند.
