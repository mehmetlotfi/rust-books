    نسخه‌های سبک Rust

    سبک پیش‌فرض Rust با گذشت زمان، همراه با خود Rust، تغییر می‌کند. با این حال، برای این‌که سبک کد موجود و کارهای CI که سبک کد را بررسی می‌کنند خراب نشوند، تغییرات در سبک پیش‌فرض Rust فقط در نسخه‌های سبک ظاهر می‌شوند.

    کدی که در یک نسخهٔ Rust مشخص نوشته می‌شود، به‌طور پیش‌فرض از نسخهٔ سبک متناظر آن استفاده می‌کند. برای این‌که مهاجرت سبک کد جدا از تغییرات معنایی بین نسخه‌های Rust آسان شود، ابزارهای قالب‌بندی مانند rustfmt اجازه می‌دهند نسخهٔ سبک به‌طور جداگانه از نسخهٔ Rust به‌روز شود.

    نسخهٔ فعلی راهنمای سبک، آخرین نسخهٔ سبک Rust را توصیف می‌کند. هر سبک گذشتهٔ متمایز، نسخهٔ بایگانی‌شدهٔ متناظری از راهنمای سبک دارد.

    توجه کنید که نسخه‌های بایگانی‌شدهٔ راهنمای سبک، قالب‌بندی سازه‌های جدیدتر Rust را که در زمان بایگانی آن نسخه وجود نداشتند مستند نمی‌کنند. با این حال، هر نسخهٔ سبک همچنان همهٔ سازه‌های معتبر آن نسخهٔ Rust را قالب‌بندی می‌کند؛ قالب‌بندی سازه‌های جدیدتر از اولین نسخهٔ سبک بعدی می‌آید که قواعد قالب‌بندی آن سازه را ارائه می‌دهد (بدون هیچ تغییر سیستماتیک یا سراسری از آن نسخهٔ سبک).

    همهٔ نسخه‌های Rust تغییرات متناظر در سبک Rust ندارند. برای مثال، Rust 2015، Rust 2018 و Rust 2021 همگی از یک نسخهٔ سبک استفاده می‌کنند.

    نسخهٔ سبک بعدی Rust

    • هرگز داخل فراخوانی تابع بدون آرگومان مانند func() یا لیترال یکه () خط را نشکنید.

    نسخهٔ سبک Rust 2024

    این راهنمای سبک نسخهٔ سبک Rust 2024 را توصیف می‌کند. نسخهٔ سبک Rust 2024 فعلاً فقط در نسخهٔ شبانه موجود است و ممکن است پیش از انتشار Rust 2024 تغییر کند.

    برای تاریخچهٔ کامل تغییرات نسخهٔ سبک Rust 2024، تاریخچهٔ git راهنمای سبک را ببینید. تغییرات مهم در نسخهٔ سبک Rust 2024 شامل این موارد است:

    • اصلاحات متفرقهٔ باگ‌های rustfmt.
    • استفاده از مرتب‌سازی نسخه‌ای (مرتب‌کردن x8، x16، x32، x64، x128 به همین ترتیب).
    • تغییر مرتب‌سازی «ASCIIbetical» به مرتب‌سازی آگاه از یونیکد با قاعدهٔ «غیرحروف‌کوچک قبل از حروف کوچک».

    نسخهٔ سبک Rust 2015/2018/2021
