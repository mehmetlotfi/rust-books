    دستورها

    دستورهای let

    بعد از : و در دو طرف = (در صورت وجود) یک فاصله بگذارید. قبل از سمی‌کالن فاصله نگذارید.

    // A comment.
let pattern: Type = expr;

let pattern;
let pattern: Type;
let pattern = expr;

    اگر ممکن است، اعلان را در یک خط قرار دهید. اگر این ممکن نیست و اعلان در دو خط جا می‌شود، بعد از = بشکنید. عبارت را با تورفتگی بلوکی بنویسید:

    let pattern: Type =
    expr;

    اگر خط اول هنوز در یک خط جا نمی‌شود، بعد از : بشکنید و از تورفتگی بلوکی استفاده کنید. اگر نوع حتی بعد از شکستن بعد از : هم به چند خط نیاز دارد، خط اول را در همان خطِ : قرار دهید، مشروط به قواعد ترکیب.

    let pattern:
    Type =
    expr;

    e.g,

    let Foo {
    f: abcd,
    g: qwer,
}: Foo<Bar> =
    Foo { f, g };

let (abcd,
    defg):
    Baz =
{ ... }

    اگر عبارت چند خط است، اگر خط اول عبارت در فضای باقی‌مانده جا شود، در همان خطِ = می‌ماند و بقیهٔ عبارت دیگر تورفتگی اضافی نمی‌گیرد. اگر خط اول جا نشود، عبارت در خط‌های بعدی و با تورفتگی بلوکی قرار می‌گیرد. اگر عبارت یک بلوک است و نوع یا الگو چند خط دارد، آکولاد بازکننده در خط جدید و بدون تورفتگی قرار می‌گیرد (این کار جداکنندهٔ داخل بلوک از نوع است)؛ در غیر این صورت آکولاد بازکننده بعد از = می‌آید.

    نمونه‌ها:

    let foo = Foo {
    f: abcd,
    g: qwer,
};

let foo =
    ALongName {
        f: abcd,
        g: qwer,
    };

let foo: Type = {
    an_expression();
    ...
};

let foo:
    ALongType =
{
    an_expression();
    ...
};

let Foo {
    f: abcd,
    g: qwer,
}: Foo<Bar> = Foo {
    f: blimblimblim,
    g: blamblamblam,
};

let Foo {
    f: abcd,
    g: qwer,
}: Foo<Bar> = foo(
    blimblimblim,
    blamblamblam,
);

    بلوک‌های else (دستورهای let-else)

    دستور let می‌تواند یک بخش else داشته باشد و در این صورت یک دستور let-else می‌شود. در این حالت همیشه همان قواعد قالب‌بندی دستورهای let دیگر را برای بخش‌های پیش از else (یعنی بخش let pattern: Type = initializer_expr) اعمال کنید.

    کل دستور let-else را در یک خط قرار دهید اگر همهٔ شرط‌های زیر برقرار باشند:

    • کل دستور کوتاه است
    • بلوک else فقط یک عبارت تک‌خطی و بدون دستور دارد
    • بلوک else هیچ کامنتی ندارد
    • بخش‌های دستور let پیش از بلوک else را می‌توان در یک خط قالب‌بندی کرد
    let Some(1) = opt else { return };

    در غیر این صورت، دستور let-else به شکستن خط نیاز دارد.

    اگر دستور let-else در چند خط شکسته می‌شود، هرگز بین else و { خط نشکنید، و همیشه قبل از } بشکنید.

    اگر بخش‌های دستور let که پیش از else هستند در یک خط قالب‌بندی می‌شوند، ولی دستور let-else کاملاً در یک خط جا نمی‌شود، else { را در همان خطی قرار دهید که عبارت مقداردهی اولیه در آن است، با یک فاصله بین آن‌ها، و سپس بعد از { بشکنید. آکولاد بسته } را هم‌سطح با let تورفتگی دهید و بلوک داخلی را یک مرحله بیشتر تورفتگی دهید.

    let Some(1) = opt else {
    return;
};

let Some(1) = opt else {
    // nope
    return
};

    اگر بخش‌های دستور let که پیش از else هستند در یک خط قالب‌بندی می‌شوند، ولی else { در همان خط جا نمی‌شود، قبل از else بشکنید.

        let Some(x) = some_really_really_really_really_really_really_really_really_really_long_name
    else {
        return;
    };

    اگر عبارت مقداردهی اولیه چند خطی است، کلیدواژهٔ else و آکولاد بازکنندهٔ بلوک (یعنی else {) را فقط در صورتی در همان خطِ پایان عبارت مقداردهی اولیه قرار دهید (با یک فاصله بین آن‌ها) که همهٔ شرط‌های زیر برقرار باشند:

    • عبارت مقداردهی اولیه با یک یا چند پرانتز بسته، کروشهٔ بسته و/یا آکولاد بسته تمام می‌شود
    • هیچ چیز دیگری در آن خط نیست
    • آن خط همان سطح تورفتگی کلیدواژهٔ let را دارد

    برای نمونه:

    let Some(x) = y.foo(
    "abc",
    fairly_long_identifier,
    "def",
    "123456",
    "string",
    "cheese",
) else {
    bar()
}

    در غیر این صورت، کلیدواژهٔ else و آکولاد بازکننده را در خط بعد از پایان عبارت مقداردهی اولیه قرار دهید، و کلیدواژهٔ else را هم‌سطح با let تورفتگی دهید.

    برای نمونه:

    fn main() {
    let Some(x) = abcdef()
        .foo(
            "abc",
            some_really_really_really_long_ident,
            "ident",
            "123456",
        )
        .bar()
        .baz()
        .qux("fffffffffffffffff")
    else {
        return
    };

    let Some(aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa) =
        bbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbb
    else {
        return;
    };

    let LongStructName(AnotherStruct {
        multi,
        line,
        pattern,
    }) = slice.as_ref()
    else {
        return;
    };

    let LongStructName(AnotherStruct {
        multi,
        line,
        pattern,
    }) = multi_line_function_call(
        arg1,
        arg2,
        arg3,
        arg4,
    ) else {
        return;
    };
}

    ماکروها در موقعیت دستور

    برای فراخوانی ماکرو در موقعیت دستور، از پرانتز یا کروشه به‌عنوان جداکننده استفاده کنید و آن را با سمی‌کالن تمام کنید. اطراف نام، !، جداکننده‌ها یا ; فاصله نگذارید.

    // A comment.
a_macro!(...);

    عبارت‌ها در موقعیت دستور

    بین عبارت و سمی‌کالن فاصله نگذارید.

    <expr>;

    همهٔ عبارت‌ها در موقعیت دستور را با سمی‌کالن تمام کنید، مگر این‌که با یک بلوک تمام شوند یا به‌عنوان مقدار یک بلوک به کار روند.

    E.g.,

    {
    an_expression();
    expr_as_value()
}

return foo();

loop {
    break;
}

    از سمی‌کالن استفاده کنید وقتی یک عبارت نوع void دارد، حتی اگر می‌توانست منتشر شود. برای نمونه:

    fn foo() { ... }

fn bar() {
    foo();
}
