راهنمای سبک RustRust Style Guide

    سایر توصیه‌های سبک

    عبارت‌ها

    تا جایی که ممکن است از ماهیت عبارت‌محور Rust استفاده کنید؛

    // use
let x = if y { 1 } else { 0 };
// not
let x;
if y {
    x = 1;
} else {
    x = 0;
}

    نام‌ها

    • نوع‌ها باید UpperCamelCase باشند،
    • متغیرهای شمارشی (enum variants) باید UpperCamelCase باشند،
    • فیلدهای struct باید snake_case باشند،
    • نام توابع و متدها باید snake_case باشد،
    • متغیرهای محلی باید snake_case باشند،
    • نام ماکروها باید snake_case باشد،
    • ثابت‌ها (const و staticهای تغییرناپذیر) باید SCREAMING_SNAKE_CASE باشند.
    • وقتی نامی به‌دلیل این‌که کلیدواژهٔ رزروشده است ممنوع است (مانند crate)، یا از شناسهٔ خام (r#crate) استفاده کنید یا زیرخط انتهایی (crate_) بگذارید. کلمه را غلط ننویسید (krate).
