    crateهای ارجاع‌شده در این کتاب

    • anyhow - نوع anyhow::Error را برای مدیریت آسان خطا فراهم می‌کند
    • assert_cmd - آزمون یکپارچگی ابزارهای CLI را ساده می‌کند
    • assert_fs - آماده‌سازی فایل‌های ورودی و آزمودن فایل‌های خروجی
    • clap-verbosity-flag - پرچم --verbose را به ابزارهای CLI مبتنی بر clap اضافه می‌کند
    • clap - تجزیه‌گر آرگومان‌های خط فرمان
    • confy - مدیریت پیکربندی بدون کد تکراری
    • crossbeam-channel - کانال‌های چندتولیدکننده و چندمصرف‌کننده برای تبادل پیام فراهم می‌کند
    • ctrlc - مدیریت‌کنندهٔ آسان ctrl-c
    • env_logger - لاگری را پیاده‌سازی می‌کند که با متغیرهای محیطی قابل پیکربندی است
    • exitcode - ثابت‌های کد خروج سیستم
    • human-panic - مدیریت‌کنندهٔ پیام panic
    • indicatif - نوارهای پیشرفت و نشانگرهای چرخان
    • log - لاگ‌گیری را مستقل از پیاده‌سازی فراهم می‌کند
    • predicates - توابع گزاره‌ای با مقدار بولی را پیاده‌سازی می‌کند
    • proptest - چارچوب آزمون مبتنی بر ویژگی (property testing)
    • serde_json - سریال‌سازی/ازسریال‌سازی به JSON
    • signal-hook - سیگنال‌های UNIX را مدیریت می‌کند
    • tokio - محیط اجرای ناهمگام
    • wasm-pack - ابزاری برای ساخت WebAssembly

    crateهای دیگر

    با توجه به چشم‌انداز دائماً در حال تغییر crateهای Rust، جای خوبی برای یافتن crateها فهرست crateهای lib.rs است، از جمله:

    • رابط خط فرمان
    • پیکربندی
    • رابط‌های پایگاه داده
    • رمزگذاری
    • سیستم فایل
    • کلاینت HTTP
    • سیستم‌عامل‌ها
