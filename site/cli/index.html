    برنامه‌های خط فرمان در Rust

    Rust زبانی سریع و کامپایل‌شدهٔ ایستا است که ابزارهای عالی و اکوسیستمی با رشد سریع دارد. همین ویژگی‌ها آن را برای نوشتن برنامه‌های خط فرمان بسیار مناسب می‌کند: این برنامه‌ها باید کوچک، قابل‌حمل و سریع باشند. برنامه‌های خط فرمان همچنین راه خوبی برای شروع یادگیری Rust یا معرفی Rust به تیم شما هستند!

    نوشتن برنامه‌ای با یک رابط خط فرمان (CLI) ساده تمرین بسیار خوبی برای مبتدی‌ای است که تازه با زبان آشنا شده است و می‌خواهد حس و حال آن را تجربه کند. با این حال، این موضوع جنبه‌های بسیاری دارد که اغلب تنها بعدتر آشکار می‌شوند.

    ساختار این کتاب به این شکل است: با یک آموزش کوتاه شروع می‌کنیم که در پایان آن به یک ابزار CLI کارا می‌رسید. با چند مفهوم اصلی Rust و نیز جنبه‌های اصلی برنامه‌های CLI آشنا می‌شوید. پس از آن، فصل‌هایی می‌آیند که دربارهٔ برخی از این جنبه‌ها با جزئیات بیشتری بحث می‌کنند.

    یک نکتهٔ آخر پیش از آنکه مستقیم سراغ برنامه‌های CLI برویم: اگر در این کتاب خطایی یافتید یا می‌خواهید در نوشتن محتوای بیشتر برای آن کمک کنید، می‌توانید منبع آن را در مخزن کتاب CLI پیدا کنید. خوشحال می‌شویم نظرات شما را بشنویم! متشکریم!
