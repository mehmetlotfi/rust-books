کتاب برنامه‌های خط فرمانCommand Line Applications in Rust

    نخستین پیاده‌سازی grrs

    پس از فصل قبل دربارهٔ آرگومان‌های خط فرمان، داده‌های ورودی خود را داریم و می‌توانیم نوشتن ابزار واقعی را شروع کنیم. تابع main ما در حال حاضر فقط این یک خط را دارد:

        let args = Cli::parse();

    می‌توانیم دستور println را که موقتاً آن‌جا گذاشته بودیم تا نشان دهیم برنامه‌مان مطابق انتظار کار می‌کند، حذف کنیم.

    بیایید با باز کردن فایلی که گرفته‌ایم شروع کنیم.

        let content = std::fs::read_to_string(&args.path).expect("could not read file");

    توجه: متد .expect را این‌جا می‌بینید؟ این یک تابع میان‌بر است که باعث می‌شود برنامه فوراً خارج شود وقتی مقدار (در این مورد، فایل ورودی) قابل خواندن نباشد. این روش چندان زیبا نیست، و در فصل بعدی دربارهٔ گزارش‌دهی بهتر خطا، خواهیم دید چگونه آن را بهبود دهیم.

    اکنون، بیایید روی خط‌ها پیمایش کنیم و هر خطی را که شامل الگوی ما است چاپ کنیم:

        for line in content.lines() {
        if line.contains(&args.pattern) {
            println!("{}", line);
        }
    }

    جمع‌بندی

    کد شما اکنون باید این‌گونه باشد:

    use clap::Parser;

/// Search for a pattern in a file and display the lines that contain it.
#[derive(Parser)]
struct Cli {
    /// The pattern to look for
    pattern: String,
    /// The path to the file to read
    path: std::path::PathBuf,
}

fn main() {
    let args = Cli::parse();
    let content = std::fs::read_to_string(&args.path).expect("could not read file");

    for line in content.lines() {
        if line.contains(&args.pattern) {
            println!("{}", line);
        }
    }
}

    آن را امتحان کنید: cargo run -- main src/main.rs اکنون باید کار کند!

    تمرین برای خواننده: این بهترین پیاده‌سازی نیست، چون کل فایل را در حافظه می‌خواند، مهم نیست فایل چقدر بزرگ باشد. راهی برای بهینه‌سازی آن پیدا کنید! (یک ایده می‌تواند استفاده از BufReader به‌جای read_to_string() باشد.)
