کتاب برنامه‌های خط فرمانCommand Line Applications in Rust

    راه‌اندازی پروژه

    اگر هنوز این کار را نکرده‌اید، Rust را روی رایانه‌تان نصب کنید (باید فقط چند دقیقه طول بکشد). پس از آن، یک ترمینال باز کنید و به پوشه‌ای بروید که می‌خواهید کد برنامه‌تان را در آن بگذارید.

    با اجرای cargo new grrs در پوشه‌ای که پروژه‌های برنامه‌نویسی خود را در آن نگه می‌دارید شروع کنید. اگر به پوشهٔ تازه‌ساخته‌شدهٔ grrs نگاه کنید، ساختار معمول یک پروژهٔ Rust را می‌بینید:

    • یک فایل Cargo.toml که فراداده‌های پروژهٔ ما را در خود دارد، از جمله فهرست وابستگی‌ها/کتابخانه‌های خارجی که استفاده می‌کنیم.
    • یک فایل src/main.rs که نقطهٔ ورود باینری (اصلی) ما است.

    اگر بتوانید در پوشهٔ grrs دستور cargo run را اجرا کنید و یک «Hello World» بگیرید، همه‌چیز آماده است.

    ممکن است چنین به نظر برسد

    $ cargo new grrs
     Created binary (application) `grrs` package
$ cd grrs/
$ cargo run
   Compiling grrs v0.1.0 (/Users/pascal/code/grrs)
    Finished dev [unoptimized + debuginfo] target(s) in 0.70s
     Running `target/debug/grrs`
Hello, world!
