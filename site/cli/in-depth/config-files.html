    استفاده از فایل‌های پیکربندی

    کار با پیکربندی‌ها می‌تواند آزاردهنده باشد، به‌ویژه اگر از چند سیستم‌عامل پشتیبانی کنید که هر کدام جای مخصوص خود را برای فایل‌های کوتاه‌مدت و بلندمدت دارند.

    برای این کار راه‌حل‌های متعددی وجود دارد که برخی سطح‌پایین‌تر از بقیه‌اند.

    ساده‌ترین crate برای این منظور confy است. نام برنامهٔ شما را می‌پرسد و از شما می‌خواهد ساختار پیکربندی را با یک struct (که Serialize و Deserialize باشد) مشخص کنید و بقیهٔ کارها را خودش انجام می‌دهد!

    #[derive(Debug, Serialize, Deserialize)]
struct MyConfig {
    name: String,
    comfy: bool,
    foo: i64,
}

fn main() -> Result<(), io::Error> {
    let cfg: MyConfig = confy::load("my_app")?;
    println!("{:#?}", cfg);
    Ok(())
}

    استفاده از آن فوق‌العاده آسان است، البته به بهای از دست دادن انعطاف‌پذیری در پیکربندی. اما اگر تنها یک پیکربندی ساده می‌خواهید، این crate ممکن است برای شما مناسب باشد!
