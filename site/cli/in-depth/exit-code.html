کتاب برنامه‌های خط فرمانCommand Line Applications in Rust

    کدهای خروج

    یک برنامه همیشه موفق نمی‌شود. و وقتی خطایی رخ می‌دهد، باید مطمئن شوید که اطلاعات لازم را به‌درستی اعلام می‌کنید. علاوه بر اطلاع‌رسانی خطاها به کاربر، در بیشتر سیستم‌ها وقتی یک فرایند به پایان می‌رسد، یک کد خروج نیز اعلام می‌کند (یک عدد صحیح بین ۰ تا ۲۵۵ با بیشتر پلتفرم‌ها سازگار است). باید تلاش کنید کد درست را متناسب با وضعیت برنامهٔ خود اعلام کنید. برای مثال، در حالت ایده‌آل که برنامهٔ شما موفق می‌شود، باید با 0 خارج شود.

    وقتی خطایی رخ می‌دهد، کار کمی پیچیده‌تر می‌شود. در عمل، بسیاری از ابزارها هنگام بروز یک شکست رایج با 1 خارج می‌شوند. در حال حاضر، Rust هنگامی که فرایند دچار panic شود، کد خروج 101 را تنظیم می‌کند. فراتر از این، افراد در برنامه‌های خود کارهای بسیار متفاوتی انجام داده‌اند.

    پس چه باید کرد؟ اکوسیستم BSD تعریفی مشترک برای کدهای خروج خود گردآوری کرده است (می‌توانید آن‌ها را اینجا ببینید). کتابخانهٔ Rust با نام exitcode همین کدها را آماده برای استفاده در برنامهٔ شما فراهم می‌کند. برای مقادیر ممکن، لطفاً مستندات API آن را ببینید.

    پس از افزودن وابستگی exitcode به Cargo.toml خود، می‌توانید آن را این‌گونه به کار ببرید:

    fn main() {
    // ...actual work...
    match result {
        Ok(_) => {
            println!("Done!");
            std::process::exit(exitcode::OK);
        }
        Err(CustomError::CantReadConfig(e)) => {
            eprintln!("Error: {}", e);
            std::process::exit(exitcode::CONFIG);
        }
        Err(e) => {
            eprintln!("Error: {}", e);
            std::process::exit(exitcode::DATAERR);
        }
    }
}
