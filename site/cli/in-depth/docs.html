کتاب برنامه‌های خط فرمانCommand Line Applications in Rust

    تولید مستندات برای برنامه‌های CLI شما

    مستندات برنامه‌های CLI معمولاً شامل بخش --help در خود فرمان و یک صفحهٔ راهنما (man) است.

    هر دو را می‌توان هنگام استفاده از clap و از طریق crate با نام clap_mangen به‌صورت خودکار تولید کرد.

    #[derive(Parser)]
pub struct Head {
    /// file to load
    pub file: PathBuf,
    /// how many lines to print
    #[arg(short = "n", default_value = "5")]
    pub count: usize,
}

    در مرحلهٔ دوم، باید از یک build.rs استفاده کنید تا فایل راهنما را هنگام کامپایل از روی تعریف برنامهٔ شما در کد تولید کند.

    چند نکته وجود دارد که باید در نظر داشت (مانند اینکه می‌خواهید باینری خود را چگونه بسته‌بندی کنید) اما فعلاً فایل man را به‌سادگی کنار پوشهٔ src قرار می‌دهیم.

    use clap::CommandFactory;

#[path="src/cli.rs"]
mod cli;

fn main() -> std::io::Result<()> {
    let out_dir = std::path::PathBuf::from(std::env::var_os("OUT_DIR").ok_or_else(|| std::io::ErrorKind::NotFound)?);
    let cmd = cli::Head::command();

    let man = clap_mangen::Man::new(cmd);
    let mut buffer: Vec<u8> = Default::default();
    man.render(&mut buffer)?;

    std::fs::write(out_dir.join("head.1"), buffer)?;

    Ok(())
}

    وقتی اکنون برنامهٔ خود را کامپایل کنید، یک فایل head.1 در پوشهٔ پروژهٔ شما ایجاد می‌شود.

    اگر آن را با man باز کنید، می‌توانید از مستندات رایگان خود لذت ببرید.
