    نوع‌های پوششی یک متد مخرب فراهم می‌کنند (C-FREE)

    هر نوع پوششی غیر Copy که HAL فراهم می‌کند باید یک متد free داشته باشد که پوشش را مصرف کند و دستگاه جانبی خام (و احتمالاً اشیای دیگر) را که از آن ساخته شده بود، پس بدهد.

    این متد باید در صورت لزوم دستگاه جانبی را خاموش و بازنشانی کند. فراخوانی new با دستگاه جانبی خامی که free برگردانده است نباید به‌خاطر وضعیت غیرمنتظرهٔ دستگاه جانبی شکست بخورد.

    اگر نوع HAL برای ساخته شدن به اشیای غیر Copy دیگری نیاز دارد (برای نمونه پایه‌های I/O)، هر یک از این اشیا نیز باید توسط free آزاد و برگردانده شود. در آن صورت free باید یک چندتایی (tuple) برگرداند.

    برای مثال:

    pub struct TIMER0;
pub struct Timer(TIMER0);

impl Timer {
    pub fn new(periph: TIMER0) -> Self {
        Self(periph)
    }

    pub fn free(self) -> TIMER0 {
        self.0
    }
}

    HALها crate دسترسی به ثبات‌های خود را دوباره صادر می‌کنند (C-REEXPORT-PAC)

    HALها را می‌توان بر پایهٔ PACهای تولیدشده با svd2rust یا بر پایهٔ crateهای دیگری نوشت که دسترسی خام به ثبات‌ها را فراهم می‌کنند. HALها باید همیشه crate دسترسی به ثبات‌هایی را که بر آن بنا شده‌اند در ریشهٔ crate خود دوباره صادر کنند.

    یک PAC باید با نام pac دوباره صادر شود، صرف‌نظر از نام واقعی crate، چون نام HAL باید از پیش روشن کند که چه PACای مورد دسترسی است.

    نوع‌ها صفت‌های embedded-hal را پیاده‌سازی می‌کنند (C-HAL-TRAITS)

    نوع‌هایی که HAL فراهم می‌کند باید همهٔ صفت‌های قابل‌اِعمالی را که crate به نام embedded-hal ارائه می‌دهد پیاده‌سازی کنند.
