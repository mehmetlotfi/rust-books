کتاب Rust نهفتهThe Embedded Rust Book

    ابزارها

    کار با ریزکنترلرها مستلزم استفاده از چند ابزار مختلف است؛ چون با معماری‌ای سروکار داریم که با معماری لپ‌تاپ شما فرق دارد و باید برنامه‌ها را روی یک دستگاه راه دور اجرا و اشکال‌زدایی کنیم.

    ما از همهٔ ابزارهای فهرست‌شده در زیر استفاده خواهیم کرد. هر جا حداقل نسخه‌ای ذکر نشده باشد، هر نسخهٔ جدیدی باید کار کند؛ اما نسخه‌هایی را که خودمان آزموده‌ایم فهرست کرده‌ایم.

    • Rust نسخهٔ 1.31، 1.31-beta یا یک toolchain جدیدتر، به‌علاوهٔ پشتیبانی از کامپایل برای ARM Cortex-M.
    • cargo-binutils ~0.1.4
    • qemu-system-arm. نسخهٔ آزموده‌شده: 3.0.0
    • OpenOCD نسخهٔ 0.8 یا بالاتر. نسخه‌های آزموده‌شده: v0.9.0 و v0.10.0
    • GDB همراه با پشتیبانی از ARM. نسخهٔ 7.12 یا جدیدتر به‌شدت توصیه می‌شود. نسخه‌های آزموده‌شده: 7.10، 7.11، 7.12 و 8.1
    • cargo-generate یا git. این ابزارها اختیاری‌اند، اما پیگیری کتاب را آسان‌تر می‌کنند.

    متن زیر توضیح می‌دهد چرا از این ابزارها استفاده می‌کنیم. دستورالعمل‌های نصب در صفحهٔ بعد آمده است.

    cargo-generate یا git

    برنامه‌های bare metal برنامه‌های Rust غیراستاندارد (no_std) هستند که برای اینکه چیدمان حافظهٔ برنامه درست از آب درآید، به چند تنظیم در فرایند پیوند (linking) نیاز دارند. این کار به چند فایل اضافی (مانند اسکریپت‌های پیوندگر) و تنظیمات (مانند پرچم‌های پیوندگر) احتیاج دارد. ما این‌ها را برایتان در یک الگوی آماده بسته‌بندی کرده‌ایم تا فقط لازم باشد اطلاعات ناقص (مانند نام پروژه و ویژگی‌های سخت‌افزار هدف شما) را وارد کنید.

    الگوی ما با cargo-generate سازگار است؛ این ابزار یک زیردستور Cargo برای ساخت پروژه‌های جدید Cargo از روی الگوهاست. همچنین می‌توانید الگو را با git، curl، wget یا مرورگر وب خود دانلود کنید.

    cargo-binutils

    cargo-binutils مجموعه‌ای از زیردستورهای Cargo است که استفاده از ابزارهای LLVM همراه با toolchain زبان Rust را آسان می‌کند. این ابزارها شامل نسخه‌های LLVM از objdump، nm و size هستند و برای بررسی فایل‌های باینری به کار می‌روند.

    مزیت استفاده از این ابزارها به‌جای GNU binutils این است که (الف) نصب ابزارهای LLVM صرف‌نظر از سیستم‌عامل شما با همان یک دستور انجام می‌شود (rustup component add llvm-tools) و (ب) ابزارهایی مثل objdump از همهٔ معماری‌هایی که rustc پشتیبانی می‌کند – از ARM تا x86_64 – پشتیبانی می‌کنند، چون هر دو از یک backend مشترک LLVM استفاده می‌کنند.

    qemu-system-arm

    QEMU یک شبیه‌ساز است. در اینجا از نوعی از آن استفاده می‌کنیم که می‌تواند سیستم‌های ARM را به‌طور کامل شبیه‌سازی کند. از QEMU برای اجرای برنامه‌های توکار روی میزبان استفاده می‌کنیم. به لطف آن می‌توانید بخش‌هایی از این کتاب را حتی بدون داشتن هیچ سخت‌افزاری دنبال کنید!

    ابزارهای اشکال‌زدایی Rust توکار

    مرور کلی

    اشکال‌زدایی سیستم‌های توکار در Rust به ابزارهای تخصصی نیاز دارد: نرم‌افزاری برای مدیریت فرایند اشکال‌زدایی، اشکال‌زداهایی (debugger) برای بررسی و کنترل اجرای برنامه، و پروب‌های سخت‌افزاری برای برقراری تعامل میان میزبان و دستگاه توکار. این سند ابزارهای نرم‌افزاری ضروری مانند Probe-rs و OpenOCD را که فرایند اشکال‌زدایی را ساده می‌کنند و پشتیبانی می‌کنند، در کنار اشکال‌زداهای شاخصی مانند GDB و افزونهٔ Probe-rs برای Visual Studio Code معرفی می‌کند. افزون بر این، پروب‌های سخت‌افزاری کلیدی مانند Rusty-probe، ST-Link، J-Link و MCU-Link را که برای اشکال‌زدایی و برنامه‌ریزی مؤثر دستگاه‌های توکار نقش اساسی دارند، پوشش می‌دهد.

    نرم‌افزارهایی که ابزارهای اشکال‌زدایی را هدایت می‌کنند

    Probe-rs

    Probe-rs نرم‌افزاری مدرن و Rust‌محور است که برای کار با اشکال‌زداها در سیستم‌های توکار طراحی شده است. برخلاف OpenOCD، Probe-rs با تأکید بر سادگی ساخته شده و هدفش کاهش بار پیکربندی‌ای است که اغلب در دیگر راه‌حل‌های اشکال‌زدایی دیده می‌شود. این نرم‌افزار از پروب‌ها و هدف‌های گوناگون پشتیبانی می‌کند و رابطی سطح بالا برای تعامل با سخت‌افزار توکار فراهم می‌آورد. Probe-rs مستقیماً با ابزارهای Rust یکپارچه می‌شود و از طریق افزونهٔ خود با Visual Studio Code نیز یکپارچه می‌شود و به توسعه‌دهندگان امکان می‌دهد جریان کاری اشکال‌زدایی خود را روان‌تر کنند.

    OpenOCD (Open On-Chip Debugger)

    OpenOCD ابزاری متن‌باز برای اشکال‌زدایی، آزمایش و برنامه‌ریزی سیستم‌های توکار است. این ابزار رابطی میان سیستم میزبان و سخت‌افزار توکار فراهم می‌کند و از لایه‌های انتقال گوناگونی مانند JTAG و SWD (Serial Wire Debug) پشتیبانی می‌کند. OpenOCD با GDB که یک اشکال‌زداست یکپارچه می‌شود. OpenOCD پشتیبانی گسترده، مستندات فراوان و جامعه‌ای بزرگ دارد، اما ممکن است پیکربندی پیچیده‌ای لازم داشته باشد، به‌ویژه برای راه‌اندازی‌های توکار سفارشی.

    اشکال‌زداها

    اشکال‌زدا به توسعه‌دهندگان اجازه می‌دهد اجرای یک برنامه را بررسی و کنترل کنند تا خطاها یا باگ‌ها را بیابند و برطرف کنند. این ابزار امکاناتی مانند تعیین نقطهٔ توقف (breakpoint)، پیمایش کد خط‌به‌خط و بررسی مقادیر متغیرها و وضعیت حافظه را فراهم می‌کند. اشکال‌زداها برای توسعه و نگهداری دقیق نرم‌افزار ضروری‌اند و به توسعه‌دهندگان کمک می‌کنند مطمئن شوند کدشان در شرایط گوناگون همان‌طور که انتظار می‌رود رفتار می‌کند.

    اشکال‌زداها می‌دانند چگونه:

    • با ثبات‌های نگاشت‌شده در حافظه تعامل کنند.
    • نقطهٔ توقف و نقطهٔ پایش (watchpoint) تعیین کنند.
    • ثبات‌های نگاشت‌شده در حافظه را بخوانند و در آن‌ها بنویسند.
    • تشخیص دهند که ریزکنترلر به‌خاطر یک رویداد اشکال‌زدایی متوقف شده است.
    • پس از مواجهه با یک رویداد اشکال‌زدایی، اجرای ریزکنترلر را ادامه دهند.
    • حافظهٔ FLASH ریزکنترلر را پاک کنند و در آن بنویسند.

    افزونهٔ Probe-rs برای Visual Studio Code

    Probe-rs یک افزونه برای Visual Studio Code دارد که تجربه‌ای روان از اشکال‌زدایی را بدون نیاز به راه‌اندازی گسترده فراهم می‌کند. از طریق این اتصال، توسعه‌دهندگان می‌توانند از ویژگی‌های ویژهٔ Rust مانند چاپ زیبا (pretty printing) و پیام‌های خطای مفصل استفاده کنند و مطمئن باشند فرایند اشکال‌زدایی‌شان با اکوسیستم Rust هماهنگ است.

    TRACE32

    TRACE32 یک راه‌حل حرفه‌ای اشکال‌زدایی و ردیابی برای سیستم‌های توکار است که شرکت Lauterbach آن را توسعه داده است. این ابزار از طیف گسترده‌ای از معماری‌های پردازنده از جمله ARM و RISC-V پشتیبانی می‌کند و از طریق JTAG، SWD و انواع رابط‌های ردیابی به سخت‌افزار هدف متصل می‌شود. TRACE32 قابلیت‌های پیشرفتهٔ اشکال‌زدایی مانند اشکال‌زدایی چندهسته‌ای، نقاط توقف پیچیده و تحلیل ردیابی بلادرنگ را فراهم می‌کند. این ابزار با اطلاعات اشکال‌زدایی استاندارد ELF/DWARF کار می‌کند و به همین دلیل با باینری‌های Rust که با toolchain‌های متداول ساخته شده‌اند سازگار است.

    GDB (GNU Debugger)

    GDB ابزار اشکال‌زدایی همه‌کاره‌ای است که به توسعه‌دهندگان اجازه می‌دهد وضعیت برنامه‌ها را هنگام اجرا یا پس از از کار افتادنشان بررسی کنند. برای Rust توکار، GDB از طریق OpenOCD یا دیگر سرورهای اشکال‌زدایی به سیستم هدف متصل می‌شود تا با کد توکار تعامل کند. GDB بسیار قابل پیکربندی است و از قابلیت‌هایی مانند اشکال‌زدایی از راه دور، بازرسی متغیرها و نقاط توقف شرطی پشتیبانی می‌کند. این ابزار روی پلتفرم‌های گوناگون قابل استفاده است و برای نیازهای اشکال‌زدایی ویژهٔ Rust، مانند چاپ زیبا و یکپارچگی با IDE‌ها، پشتیبانی گسترده‌ای دارد.

    پروب‌ها

    پروب سخت‌افزاری دستگاهی است که در توسعه و اشکال‌زدایی سیستم‌های توکار برای تسهیل ارتباط میان رایانهٔ میزبان و دستگاه توکار هدف به کار می‌رود. این دستگاه معمولاً از پروتکل‌هایی مانند JTAG یا SWD پشتیبانی می‌کند و به این ترتیب می‌تواند ریزکنترلر یا ریزپردازندهٔ سیستم توکار را برنامه‌ریزی، اشکال‌زدایی و تحلیل کند. پروب‌های سخت‌افزاری برای تعیین نقطهٔ توقف، پیمایش کد و بررسی حافظه و ثبات‌های پردازنده برای توسعه‌دهندگان حیاتی‌اند و عملاً امکان تشخیص و رفع مشکلات را به‌صورت بلادرنگ فراهم می‌کنند.

    Rusty-probe

    Rusty-probe یک پروب اشکال‌زدایی سخت‌افزاری مبتنی بر USB و متن‌باز است که برای کار با probe-rs طراحی شده است. ترکیب Rusty-Probe و probe-rs راه‌حلی آسان برای استفاده و مقرون‌به‌صرفه برای توسعه‌دهندگانی فراهم می‌کند که روی برنامه‌های Rust توکار کار می‌کنند.

    ST-Link

    ST-Link پروب محبوب اشکال‌زدایی و برنامه‌ریزی است که STMicroelectronics عمدتاً برای سری‌های ریزکنترلر STM32 و STM8 خود توسعه داده است. این پروب هم اشکال‌زدایی و هم برنامه‌ریزی را از طریق رابط‌های JTAG یا SWD (Serial Wire Debug) پشتیبانی می‌کند. ST-Link به دلیل پشتیبانی مستقیم از طیف گستردهٔ بردهای توسعهٔ STMicroelectronics و یکپارچگی با IDE‌های اصلی بسیار رایج است و برای توسعه‌دهندگانی که با ریزکنترلرهای STM کار می‌کنند انتخابی راحت است.

    J-Link

    J-Link که SEGGER Microcontroller آن را توسعه داده، اشکال‌زدای قدرتمند و همه‌کاره‌ای است که از طیف گسترده‌ای از هسته‌های CPU و دستگاه‌ها فراتر از ARM، مانند RISC-V، پشتیبانی می‌کند. J-Link که به کارایی و قابلیت اطمینان بالا شهرت دارد، از رابط‌های ارتباطی گوناگون از جمله JTAG، SWD و رابط‌های fine-pitch JTAG پشتیبانی می‌کند. قابلیت‌های پیشرفته‌ای مانند نقاط توقف نامحدود در حافظهٔ فلش و سازگاری با مجموعهٔ بزرگی از محیط‌های توسعه آن را محبوب کرده است.

    MCU-Link

    MCU-Link پروب اشکال‌زدایی‌ای است که نقش برنامه‌ریز (programmer) را هم ایفا می‌کند و شرکت NXP Semiconductors آن را عرضه کرده است. این پروب از انواع ریزکنترلرهای ARM Cortex پشتیبانی می‌کند و به‌خوبی با ابزارهای توسعه‌ای مانند MCUXpresso IDE کار می‌کند. MCU-Link به‌ویژه به دلیل تنوع کاربرد و قیمت مناسب شاخص است و گزینه‌ای در دسترس برای علاقه‌مندان، مدرسان و توسعه‌دهندگان حرفه‌ای به شمار می‌رود.
