کتاب Rust نهفتهThe Embedded Rust Book

    مقدمه

    به کتاب Rust توکار (The Embedded Rust Book) خوش آمدید: کتابی مقدماتی دربارهٔ استفاده از زبان برنامه‌نویسی Rust روی سیستم‌های توکار «Bare Metal»، مانند ریزکنترلرها.

    Rust توکار برای چه کسانی است

    Rust توکار برای همهٔ کسانی است که می‌خواهند برنامه‌نویسی توکار انجام دهند و در عین حال از مفاهیم سطح بالاتر و تضمین‌های ایمنی‌ای که زبان Rust فراهم می‌کند بهره ببرند. (همچنین ببینید: Rust برای چه کسانی است)

    دامنه

    اهداف این کتاب عبارت‌اند از:

    • آشنا کردن توسعه‌دهندگان با توسعهٔ Rust توکار و رساندنشان به سطح لازم؛ یعنی چگونگی راه‌اندازی یک محیط توسعه.

    • به اشتراک گذاشتن بهترین روش‌های کنونی استفاده از Rust برای توسعهٔ توکار؛ یعنی چگونه از قابلیت‌های زبان Rust به بهترین شکل استفاده کنیم تا نرم‌افزار توکار درست‌تری بنویسیم.

    • در برخی موارد، نقش یک کتاب آشپزی (cookbook) را داشته باشد؛ مثلاً: چگونه C و Rust را در یک پروژهٔ واحد با هم ترکیب کنم؟

    این کتاب سعی می‌کند تا حد ممکن عمومی باشد، اما برای آسان‌تر شدن کار هم خوانندگان و هم نویسندگان، در همهٔ مثال‌هایش از معماری ARM Cortex-M استفاده می‌کند. با این حال، کتاب فرض نمی‌کند که خواننده با این معماری خاص آشنا باشد و جزئیات مختص به این معماری را در جای لازم توضیح می‌دهد.

    این کتاب برای چه کسانی است

    این کتاب مخاطبانی را در نظر دارد که یا پیشینه‌ای در زمینهٔ سیستم‌های توکار دارند یا پیشینه‌ای در Rust، با این حال باور داریم هر کسی که دربارهٔ برنامه‌نویسی Rust توکار کنجکاو است می‌تواند از این کتاب چیزی بیاموزد. برای کسانی که هیچ دانش پیشینی ندارند، پیشنهاد می‌کنیم بخش «مفروضات و پیش‌نیازها» را بخوانند و دانسته‌های ناقص خود را تکمیل کنند تا از کتاب بیشتر بهره ببرند و تجربهٔ خواندن بهتری داشته باشند. می‌توانید بخش «منابع دیگر» را ببینید تا منابعی دربارهٔ موضوع‌هایی بیابید که شاید بخواهید آن‌ها را مرور کنید.

    مفروضات و پیش‌نیازها

    • با استفاده از زبان برنامه‌نویسی Rust راحت هستید و برنامه‌های Rust را روی یک محیط دسکتاپ نوشته، اجرا و اشکال‌زدایی کرده‌اید. همچنین باید با اصطلاحات و الگوهای رایج ویرایش 2018 آشنا باشید، چون این کتاب Rust 2018 را هدف گرفته است.
    • با توسعه و اشکال‌زدایی سیستم‌های توکار در زبان دیگری مانند C، C++ یا Ada راحت هستید و با مفاهیمی مانند موارد زیر آشنایید:
      • کامپایل متقاطع (Cross Compilation)
      • پیرامونی‌های نگاشت‌شده به حافظه
      • وقفه‌ها
      • رابط‌های رایج مانند I2C، SPI، Serial و غیره.

    چگونه از این کتاب استفاده کنیم

    این کتاب عموماً فرض می‌کند که آن را از ابتدا تا انتها می‌خوانید. فصل‌های بعدی بر مفاهیم فصل‌های قبلی بنا می‌شوند، و فصل‌های قبلی ممکن است وارد جزئیات یک موضوع نشوند و آن را در فصلی بعدی دوباره مرور کنند.

    این کتاب برای بیشتر مثال‌های خود از برد توسعهٔ STM32F3DISCOVERY ساخت STMicroelectronics استفاده می‌کند. این برد بر پایهٔ معماری ARM Cortex-M است، و هرچند قابلیت‌های پایه در بیشتر CPUهای مبتنی بر این معماری یکسان است، پیرامونی‌ها و دیگر جزئیات پیاده‌سازی ریزکنترلرها از یک سازنده به سازندهٔ دیگر متفاوت است، و اغلب حتی میان خانواده‌های ریزکنترلر یک سازندهٔ واحد هم فرق می‌کند.

    به همین دلیل پیشنهاد می‌کنیم برای دنبال کردن مثال‌های این کتاب، برد توسعهٔ STM32F3DISCOVERY را تهیه کنید.
