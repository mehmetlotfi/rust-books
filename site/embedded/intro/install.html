    نصب ابزارها

    این صفحه دستورالعمل‌های نصب چند ابزار را که به سیستم‌عامل وابسته نیستند در بر دارد:

    toolchain زبان Rust

    rustup را با پیروی از دستورالعمل‌های https://rustup.rs نصب کنید.

    توجه مطمئن شوید نسخهٔ کامپایلرتان برابر یا جدیدتر از 1.31 باشد. دستور rustc -V باید تاریخی جدیدتر از تاریخ نشان‌داده‌شده در زیر برگرداند.

    $ rustc -V
rustc 1.31.1 (b6c32da9b 2018-12-18)

    برای صرفه‌جویی در پهنای باند و فضای دیسک، نصب پیش‌فرض فقط از کامپایل بومی (native) پشتیبانی می‌کند. برای افزودن پشتیبانی از کامپایل متقابل برای معماری‌های ARM Cortex-M، یکی از هدف‌های کامپایل زیر را انتخاب کنید. برای برد STM32F3DISCOVERY که در مثال‌های این کتاب به کار رفته، از هدف thumbv7em-none-eabihf استفاده کنید. بهترین Cortex-M را برای خودتان بیابید.

    Cortex-M0، M0+ و M1 (معماری ARMv6-M):

    rustup target add thumbv6m-none-eabi

    Cortex-M3 (معماری ARMv7-M):

    rustup target add thumbv7m-none-eabi

    Cortex-M4 و M7 بدون ممیز شناور سخت‌افزاری (معماری ARMv7E-M):

    rustup target add thumbv7em-none-eabi

    Cortex-M4F و M7F با ممیز شناور سخت‌افزاری (معماری ARMv7E-M):

    rustup target add thumbv7em-none-eabihf

    Cortex-M23 (معماری ARMv8-M):

    rustup target add thumbv8m.base-none-eabi

    Cortex-M33 و M35P (معماری ARMv8-M):

    rustup target add thumbv8m.main-none-eabi

    Cortex-M33F و M35PF با ممیز شناور سخت‌افزاری (معماری ARMv8-M):

    rustup target add thumbv8m.main-none-eabihf

    cargo-binutils

    cargo install cargo-binutils

rustup component add llvm-tools

    ویندوز: پیش‌نیاز آن نصب بودن C++ Build Tools برای Visual Studio 2019 است. https://visualstudio.microsoft.com/thank-you-downloading-visual-studio/?sku=BuildTools&rel=16

    cargo-generate

    بعداً از این ابزار برای تولید یک پروژه از روی یک الگو استفاده خواهیم کرد.

    cargo install cargo-generate

    نکته: در برخی توزیع‌های لینوکس (مثلاً Ubuntu) ممکن است پیش از نصب cargo-generate لازم باشد بسته‌های libssl-dev و pkg-config را نصب کنید.
