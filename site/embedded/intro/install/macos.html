    macOS

    همهٔ ابزارها را می‌توان با Homebrew یا MacPorts نصب کرد:

    نصب ابزارها با Homebrew

    $ # GDB
$ brew install arm-none-eabi-gdb

$ # OpenOCD
$ brew install openocd

$ # QEMU
$ brew install qemu

    توجه اگر OpenOCD از کار افتاد، ممکن است لازم باشد آخرین نسخه را با این دستور نصب کنید:

    $ brew install --HEAD openocd

    نصب ابزارها با MacPorts

    $ # GDB
$ sudo port install arm-none-eabi-gcc

$ # OpenOCD
$ sudo port install openocd

$ # QEMU
$ sudo port install qemu

    همین بود! به بخش بعد بروید.
