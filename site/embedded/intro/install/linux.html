    لینوکس

    در اینجا دستورهای نصب برای چند توزیع لینوکس آمده است.

    بسته‌ها

    • Ubuntu 18.04 یا جدیدتر / Debian stretch یا جدیدتر

    توجه gdb-multiarch دستور GDB‌ای است که برای اشکال‌زدایی برنامه‌های ARM Cortex-M از آن استفاده می‌کنید

    sudo apt install gdb-multiarch openocd qemu-system-arm
    • Ubuntu 14.04 و 16.04

    توجه arm-none-eabi-gdb دستور GDB‌ای است که برای اشکال‌زدایی برنامه‌های ARM Cortex-M از آن استفاده می‌کنید

    sudo apt install gdb-arm-none-eabi openocd qemu-system-arm
    • Fedora 27 یا جدیدتر
    sudo dnf install gdb openocd qemu-system-arm
    • Arch Linux

    توجه arm-none-eabi-gdb دستور GDB‌ای است که برای اشکال‌زدایی برنامه‌های ARM Cortex-M از آن استفاده می‌کنید

    sudo pacman -S arm-none-eabi-gdb qemu-system-arm openocd

    قواعد udev

    این قاعده به شما اجازه می‌دهد بدون دسترسی root از OpenOCD همراه با برد Discovery استفاده کنید.

    فایل /etc/udev/rules.d/70-st-link.rules را با محتوای نشان‌داده‌شده در زیر ایجاد کنید.

    # STM32F3DISCOVERY rev A/B - ST-LINK/V2
ATTRS{idVendor}=="0483", ATTRS{idProduct}=="3748", TAG+="uaccess"

# STM32F3DISCOVERY rev C+ - ST-LINK/V2-1
ATTRS{idVendor}=="0483", ATTRS{idProduct}=="374b", TAG+="uaccess"

    سپس همهٔ قواعد udev را با دستور زیر دوباره بارگذاری کنید:

    sudo udevadm control --reload-rules

    اگر برد به لپ‌تاپتان وصل بود، آن را جدا کنید و دوباره وصل کنید.

    می‌توانید با اجرای این دستور مجوزهای دسترسی را بررسی کنید:

    lsusb

    که باید چیزی شبیه این نشان دهد

    (..)
Bus 001 Device 018: ID 0483:374b STMicroelectronics ST-LINK/V2.1
(..)

    شمارهٔ bus و device را یادداشت کنید. با این شماره‌ها مسیری مانند /dev/bus/usb/<bus>/<device> بسازید. سپس از این مسیر به این شکل استفاده کنید:

    ls -l /dev/bus/usb/001/018

    crw-------+ 1 root root 189, 17 Sep 13 12:34 /dev/bus/usb/001/018

    getfacl /dev/bus/usb/001/018 | grep user

    user::rw-
user:you:rw-

    علامت + که به انتهای مجوزهای دسترسی افزوده شده وجود یک مجوز گسترش‌یافته (extended permission) را نشان می‌دهد. دستور getfacl می‌گوید کاربر you می‌تواند از این دستگاه استفاده کند.

    اکنون به بخش بعد بروید.
