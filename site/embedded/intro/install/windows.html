    ویندوز

    arm-none-eabi-gdb

    ARM برای ویندوز نصاب‌های .exe ارائه می‌دهد. یکی را از اینجا بگیرید و دستورالعمل‌ها را دنبال کنید. درست پیش از پایان فرایند نصب، گزینهٔ «Add path to environment variable» را تیک بزنید/انتخاب کنید. سپس بررسی کنید که ابزارها در %PATH% شما باشند:

    $ arm-none-eabi-gdb -v
GNU gdb (GNU Tools for Arm Embedded Processors 7-2018-q2-update) 8.1.0.20180315-git
(..)

    OpenOCD

    نسخهٔ باینری رسمی‌ای از OpenOCD برای ویندوز وجود ندارد، اما اگر حوصلهٔ کامپایل کردن آن را ندارید، پروژهٔ xPack یک توزیع باینری اینجا ارائه می‌کند. دستورالعمل‌های نصب ارائه‌شده را دنبال کنید. سپس متغیر محیطی %PATH% را به‌روز کنید تا مسیری را که فایل‌های باینری در آن نصب شده‌اند در بر بگیرد. (C:\Users\USERNAME\AppData\Roaming\xPacks\@xpack-dev-tools\openocd\0.10.0-13.1\.content\bin\، اگر از نصب آسان استفاده کرده باشید)

    با دستور زیر بررسی کنید که OpenOCD در %PATH% شما هست:

    $ openocd -v
Open On-Chip Debugger 0.10.0
(..)

    QEMU

    QEMU را از وب‌سایت رسمی بگیرید.

    درایور USB برای ST-LINK

    باید این درایور USB را هم نصب کنید وگرنه OpenOCD کار نخواهد کرد. دستورالعمل‌های نصاب را دنبال کنید و مطمئن شوید نسخهٔ درست (32 بیتی یا 64 بیتی) درایور را نصب می‌کنید.
