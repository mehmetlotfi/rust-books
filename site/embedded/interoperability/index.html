    قابلیت همکاری

    قابلیت همکاری میان کد Rust و کد C همواره به تبدیل داده میان این دو زبان وابسته است. برای این منظور، در stdlib یک ماژول اختصاصی به نام std::ffi وجود دارد.

    std::ffi تعریف نوع‌ها را برای نوع‌های اولیهٔ C، مانند char، int و long، فراهم می‌کند. همچنین ابزارهایی برای تبدیل نوع‌های پیچیده‌تر مانند رشته‌ها ارائه می‌دهد و هم &str و هم String را به نوع‌های C نگاشت می‌کند که کار با آن‌ها آسان‌تر و ایمن‌تر است.

    از Rust 1.30 به بعد، قابلیت‌های std::ffi بسته به اینکه تخصیص حافظه در کار باشد یا نه، در core::ffi یا alloc::ffi در دسترس هستند. crate به نام cty و crate به نام cstr_core نیز قابلیت‌های مشابهی ارائه می‌دهند.

    یک مقدار از نوع اولیهٔ C را می‌توان به‌جای نوع متناظر در Rust به کار برد و برعکس، چون نوع اول صرفاً یک نام مستعار (type alias) برای نوع دوم است. برای مثال، کد زیر روی پلتفرم‌هایی کامپایل می‌شود که unsigned int در آن‌ها 32 بیتی است.

    fn foo(num: u32) {
    let c_num: c_uint = num;
    let r_num: u32 = c_num;
}
