    وقفه‌ها

    وقفه‌ها از جنبه‌های مختلفی با استثناها تفاوت دارند، اما نحوهٔ کار و استفاده‌شان تا حد زیادی شبیه است و کنترلر وقفهٔ واحدی هم آن‌ها را مدیریت می‌کند. استثناها را معماری Cortex-M تعریف می‌کند، اما وقفه‌ها همواره پیاده‌سازی‌هایی مختص سازنده (و اغلب حتی مختص تراشه) هستند، چه در نام‌گذاری و چه در عملکرد.

    وقفه‌ها انعطاف زیادی در اختیار می‌گذارند که هنگام استفادهٔ پیشرفته از آن‌ها باید مدنظر قرار گیرد. ما این کاربردها را در این کتاب پوشش نمی‌دهیم، اما خوب است نکات زیر را به خاطر داشته باشید:

    • وقفه‌ها اولویت‌های قابل‌برنامه‌ریزی دارند که ترتیب اجرای کنترل‌گرهایشان را تعیین می‌کند
    • وقفه‌ها می‌توانند تودرتو شوند و پیش‌دستی کنند؛ یعنی اجرای یک کنترل‌گر وقفه ممکن است با وقفهٔ دیگری که اولویت بالاتری دارد قطع شود
    • به‌طور کلی، دلیلی که باعث فعال شدن وقفه شده است باید پاک شود تا کنترل‌گر وقفه بی‌پایان دوباره فراخوانی نشود

    گام‌های کلی مقداردهی اولیه در زمان اجرا همیشه یکسان است:

    • دستگاه(های) جانبی را طوری تنظیم کنید که در زمان‌های دلخواه درخواست وقفه تولید کنند
    • اولویت دلخواه کنترل‌گر وقفه را در کنترلر وقفه تنظیم کنید
    • کنترل‌گر وقفه را در کنترلر وقفه فعال کنید

    مشابه استثناها، crate با نام cortex-m-rt هم یک attribute به نام interrupt برای تعریف کنترل‌گرهای وقفه فراهم می‌کند. با این حال، این attribute فقط زمانی در دسترس است که feature با نام device فعال باشد. به بیان دیگر، قرار نیست این attribute مستقیماً استفاده شود؛ چنین کاری به خطای کامپایل می‌انجامد.

    در عوض، باید از نسخهٔ صادرشدهٔ مجدد (re-exported) attribute با نام interrupt استفاده کنید که crate دستگاه فراهم می‌کند (معمولاً با svd2rust تولید می‌شود). این کار تضمین می‌کند که کامپایلر می‌تواند بررسی کند وقفهٔ موردنظر واقعاً روی دستگاه هدف وجود دارد. فهرست وقفه‌های موجود، و جایگاه آن‌ها در جدول بردار وقفه، معمولاً به‌طور خودکار از یک فایل SVD توسط svd2rust تولید می‌شود.

    use lm3s6965::interrupt; // Re-exported attribute from the device crate

// Interrupt handler for the Timer2 interrupt
#[interrupt]
fn TIMER2A() {
    // ..
    // Clear reason for the generated interrupt request
}

    کنترل‌گرهای وقفه، مانند کنترل‌گرهای استثنا، شبیه تابع‌های معمولی‌اند (جز اینکه آرگومان ندارند). با این حال، به‌دلیل قراردادهای فراخوانی ویژه، بخش‌های دیگر firmware نمی‌توانند آن‌ها را مستقیماً فراخوانی کنند. اما می‌توان در نرم‌افزار درخواست وقفه تولید کرد تا انحراف به کنترل‌گر وقفه فعال شود.

    مانند کنترل‌گرهای استثنا، می‌توان داخل کنترل‌گرهای وقفه نیز متغیرهای static mut تعریف کرد تا حالت برنامه به‌صورت امن نگه داشته شود.

    #[interrupt]
fn TIMER2A() {
    static mut COUNT: u32 = 0;

    // `COUNT` has type `&mut u32` and it's safe to use
    *COUNT += 1;
}
