    تبدیل نوع‌ها (Type Conversions)

    در پایان روز، همه‌چیز فقط انبوهی از بیت‌ها در جایی است، و سیستم‌های نوع صرفاً برای کمک به ما در استفاده‌ی درست از آن بیت‌ها وجود دارند. دو مشکل رایج در نوع‌دهی به بیت‌ها وجود دارد: نیاز به بازتفسیر همان بیت‌ها به‌عنوان یک نوع دیگر، و نیاز به تغییر بیت‌ها برای داشتن معنای معادل در یک نوع دیگر. از آنجا که Rust تشویق می‌کند ویژگی‌های مهم در سیستم نوع کدگذاری شوند، این مشکلات فوق‌العاده فراگیرند. به همین دلیل Rust چند راه برای حل آن‌ها در اختیار شما می‌گذارد.

    ابتدا به راه‌هایی نگاه می‌کنیم که Safe Rust برای بازتفسیر مقادیر در اختیار شما می‌گذارد. ساده‌ترین راه این است که یک مقدار را به اجزای سازنده‌اش تجزیه کنید و سپس از آن‌ها نوع جدیدی بسازید. مثلاً

    struct Foo {
    x: u32,
    y: u16,
}

struct Bar {
    a: u32,
    b: u16,
}

fn reinterpret(foo: Foo) -> Bar {
    let Foo { x, y } = foo;
    Bar { a: x, b: y }
}

    اما این در بهترین حالت آزاردهنده است. برای تبدیل‌های رایج، Rust جایگزین‌های راحت‌تری فراهم می‌کند.
