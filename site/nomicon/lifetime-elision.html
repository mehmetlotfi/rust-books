    حذف طول عمر (Lifetime Elision)

    برای راحت‌تر کردن الگوهای رایج، Rust اجازه می‌دهد طول عمرها در امضای توابع حذف (elide) شوند.

    یک موقعیت طول عمر هر جایی است که بتوانید در یک نوع طول عمر بنویسید:

    &'a T
&'a mut T
T<'a>

    موقعیت‌های طول عمر می‌توانند «ورودی» یا «خروجی» باشند:

    • برای تعریف‌های fn، نوع‌های fn و صفت‌های Fn، FnMut و FnOnce، ورودی به نوع آرگومان‌های صوری اشاره دارد، در حالی که خروجی به نوع نتیجه اشاره دارد. پس fn foo(s: &str) -> (&str, &str) یک طول عمر را در موقعیت ورودی و دو طول عمر را در موقعیت خروجی حذف کرده است. توجه کنید که موقعیت‌های ورودیِ تعریف یک متد fn شامل طول عمرهایی که در سرآیند impl آن متد می‌آیند نمی‌شود (و برای یک متد پیش‌فرض، طول عمرهایی که در سرآیند صفت می‌آیند را هم شامل نمی‌شود).

    • برای سرآیندهای impl، همهٔ نوع‌ها ورودی هستند. پس impl Trait<&T> for Struct<&T> دو طول عمر را در موقعیت ورودی حذف کرده است، در حالی که impl Struct<&T> یکی را حذف کرده است.

    قواعد حذف به این شرح است:

    • هر طول عمر حذف‌شده در موقعیت ورودی به یک پارامتر طول عمر متمایز تبدیل می‌شود.

    • اگر دقیقاً یک موقعیت طول عمر ورودی وجود داشته باشد (حذف‌شده یا نه)، آن طول عمر به همهٔ طول عمرهای حذف‌شدهٔ خروجی اختصاص می‌یابد.

    • اگر چند موقعیت طول عمر ورودی وجود داشته باشد، اما یکی از آن‌ها &self یا &mut self باشد، طول عمر self به همهٔ طول عمرهای حذف‌شدهٔ خروجی اختصاص می‌یابد.

    • در غیر این صورت، حذف یک طول عمر خروجی خطا است.

    مثال‌ها:

    fn print(s: &str);                                      // elided
fn print<'a>(s: &'a str);                               // expanded

fn debug(lvl: usize, s: &str);                          // elided
fn debug<'a>(lvl: usize, s: &'a str);                   // expanded

fn substr(s: &str, until: usize) -> &str;               // elided
fn substr<'a>(s: &'a str, until: usize) -> &'a str;     // expanded

fn get_str() -> &str;                                   // ILLEGAL

fn frob(s: &str, t: &str) -> &str;                      // ILLEGAL

fn get_mut(&mut self) -> &mut T;                        // elided
fn get_mut<'a>(&'a mut self) -> &'a mut T;              // expanded

fn args<T: ToCStr>(&mut self, args: &[T]) -> &mut Command                  // elided
fn args<'a, 'b, T: ToCStr>(&'a mut self, args: &'b [T]) -> &'a mut Command // expanded

fn new(buf: &mut [u8]) -> BufWriter;                    // elided
fn new(buf: &mut [u8]) -> BufWriter<'_>;                // elided (with `rust_2018_idioms`)
fn new<'a>(buf: &'a mut [u8]) -> BufWriter<'a>          // expanded
