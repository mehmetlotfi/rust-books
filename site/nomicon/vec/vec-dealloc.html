    آزادسازی حافظه

    در مرحلهٔ بعد باید Drop را پیاده‌سازی کنیم تا حجم عظیمی از منابع را نشت ندهیم. ساده‌ترین راه این است که pop را صدا بزنیم تا None بدهد، و سپس بافرمان را آزاد کنیم. توجه کنید که اگر T: !Drop باشد، صدا زدن pop لازم نیست. در تئوری می‌توانیم از Rust بپرسیم که آیا T به needs_drop نیاز دارد یا نه و فراخوانی‌های pop را حذف کنیم. اما در عمل LLVM در حذف کدهای ساده و بدون اثر جانبی از این دست واقعاً خوب است، پس مگر اینکه متوجه شوید حذف نمی‌شود (که در این مورد حذف می‌شود)، به زحمتش نمی‌ارزد.

    وقتی self.cap == 0 است نباید alloc::dealloc را صدا بزنیم، چون در این حالت در واقع هیچ حافظه‌ای تخصیص نداده‌ایم.

    impl<T> Drop for Vec<T> {
    fn drop(&mut self) {
        if self.cap != 0 {
            while let Some(_) = self.pop() { }
            let layout = Layout::array::<T>(self.cap).unwrap();
            unsafe {
                alloc::dealloc(self.ptr.as_ptr() as *mut u8, layout);
            }
        }
    }
}
