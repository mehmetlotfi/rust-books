    Push و Pop

    بسیار خب. می‌توانیم مقداردهی اولیه کنیم. می‌توانیم تخصیص بدهیم. بیایید واقعاً مقداری قابلیت پیاده‌سازی کنیم! با push شروع می‌کنیم. تنها کاری که باید بکند این است که بررسی کند پر هستیم یا نه تا رشد کند، بی‌قیدوشرط در اندیس بعدی بنویسد، و سپس طولمان را یک واحد افزایش دهد.

    برای انجام نوشتن باید مراقب باشیم حافظه‌ای را که می‌خواهیم در آن بنویسیم ارزیابی (evaluate) نکنیم. در بدترین حالت، حافظه‌ای است که واقعاً مقداردهی‌نشده و مستقیم از تخصیص‌دهنده آمده. در بهترین حالت، بیت‌های یک مقدار قدیمی است که pop کرده‌ایم. در هر دو صورت، نمی‌توانیم به‌سادگی به آن حافظه اندیس بزنیم و آن را ارجاع‌زدایی کنیم، چون این کار حافظه را به‌عنوان یک نمونهٔ معتبر از T ارزیابی می‌کند. بدتر اینکه foo[idx] = x سعی می‌کند روی مقدار قدیمی foo[idx] تابع drop را صدا بزند!

    روش درست انجام این کار با ptr::write است، که صرفاً کورکورانه آدرس هدف را با بیت‌های مقداری که ما می‌دهیم بازنویسی می‌کند. هیچ ارزیابی‌ای در کار نیست.

    برای push، اگر len قدیمی (پیش از صدا زده شدن push) برابر ۰ باشد، می‌خواهیم در اندیس صفرم بنویسیم. پس باید به‌اندازهٔ len قدیمی offset بدهیم.

    pub fn push(&mut self, elem: T) {
    if self.len == self.cap { self.grow(); }

    unsafe {
        ptr::write(self.ptr.as_ptr().add(self.len), elem);
    }

    // Can't fail, we'll OOM first.
    self.len += 1;
}

    آسان بود! pop چطور؟ هرچند این بار اندیسی که می‌خواهیم به آن دسترسی پیدا کنیم مقداردهی اولیه شده است، Rust به ما اجازه نمی‌دهد صرفاً مکان حافظه را ارجاع‌زدایی کنیم تا مقدار را بیرون بکشیم، چون این کار حافظه را مقداردهی‌نشده رها می‌کند! برای این کار به ptr::read نیاز داریم، که فقط بیت‌ها را از آدرس هدف بیرون کپی می‌کند و آن را به‌عنوان مقداری از نوع T تفسیر می‌کند. این کار حافظهٔ این آدرس را از نظر منطقی مقداردهی‌نشده باقی می‌گذارد، حتی با اینکه در واقع یک نمونهٔ کاملاً سالم از T آنجا هست.

    برای pop، اگر مثلاً len قدیمی ۱ باشد، می‌خواهیم از اندیس صفرم بخوانیم. پس باید به‌اندازهٔ len جدید offset بدهیم.

    pub fn pop(&mut self) -> Option<T> {
    if self.len == 0 {
        None
    } else {
        self.len -= 1;
        unsafe {
            Some(ptr::read(self.ptr.as_ptr().add(self.len)))
        }
    }
}
