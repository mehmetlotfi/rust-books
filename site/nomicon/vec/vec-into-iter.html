    IntoIter

    بیایید به نوشتن iterator‌ها بپردازیم. iter و iter_mut به لطف جادوی Deref از قبل برای ما نوشته شده‌اند. با این حال دو iterator جالب هست که Vec ارائه می‌دهد و slice‌ها نمی‌توانند: into_iter و drain.

    IntoIter، Vec را به‌صورت by-value مصرف می‌کند و در نتیجه می‌تواند عناصرش را به‌صورت by-value تولید کند. برای فعال کردن این امکان، IntoIter باید کنترل تخصیص حافظهٔ Vec را به دست بگیرد.

    IntoIter باید DoubleEnded هم باشد تا خواندن از هر دو سر ممکن شود. خواندن از انتها را می‌توان صرفاً با صدا زدن pop پیاده‌سازی کرد، اما خواندن از ابتدا سخت‌تر است. می‌توانستیم remove(0) را صدا بزنیم اما این کار به‌طرز دیوانه‌واری گران است. در عوض می‌خواهیم فقط از ptr::read استفاده کنیم تا مقدارها را از هر یک از دو سر Vec بیرون کپی کنیم، بدون اینکه اصلاً بافر را تغییر دهیم.

    برای این کار از یک ایدیوم بسیار رایج C برای پیمایش آرایه استفاده می‌کنیم. دو اشاره‌گر می‌سازیم؛ یکی که به ابتدای آرایه اشاره می‌کند و یکی که به یک عنصر بعد از انتها. وقتی از یک سر عنصری می‌خواهیم، مقداری را که اشاره‌گر آن سر به آن اشاره می‌کند می‌خوانیم و اشاره‌گر را یک خانه جابه‌جا می‌کنیم. وقتی دو اشاره‌گر برابر شدند، می‌دانیم کار تمام شده است.

    توجه کنید که ترتیب خواندن و offset دادن برای next و next_back برعکس است. برای next_back اشاره‌گر همیشه بعد از عنصری است که می‌خواهد بعداً بخواند، در حالی که برای next اشاره‌گر همیشه روی عنصری است که می‌خواهد بعداً بخواند. برای اینکه ببینید چرا چنین است، حالتی را در نظر بگیرید که همهٔ عناصر به‌جز یکی تولید شده‌اند.

    آرایه این شکلی است:

              S  E
[X, X, X, O, X, X, X]

    اگر E مستقیماً به عنصری اشاره می‌کرد که می‌خواهد بعداً تولید کند، قابل‌تشخیص از حالتی که دیگر عنصری برای تولید نمانده نبود.

    هرچند در طول پیمایش اصلاً به آن اهمیتی نمی‌دهیم، باید اطلاعات تخصیص Vec را هم نگه داریم تا پس از drop شدن IntoIter بتوانیم آن را آزاد کنیم.

    پس از struct زیر استفاده خواهیم کرد:

    pub struct IntoIter<T> {
    buf: NonNull<T>,
    cap: usize,
    start: *const T,
    end: *const T,
}

    و این همان چیزی است که برای مقداردهی اولیه به آن می‌رسیم:

    impl<T> IntoIterator for Vec<T> {
    type Item = T;
    type IntoIter = IntoIter<T>;
    fn into_iter(self) -> IntoIter<T> {
        // Make sure not to drop Vec since that would free the buffer
        let vec = ManuallyDrop::new(self);

        // Can't destructure Vec since it's Drop
        let ptr = vec.ptr;
        let cap = vec.cap;
        let len = vec.len;

        IntoIter {
            buf: ptr,
            cap,
            start: ptr.as_ptr(),
            end: if cap == 0 {
                // can't offset off this pointer, it's not allocated!
                ptr.as_ptr()
            } else {
                unsafe { ptr.as_ptr().add(len) }
            },
        }
    }
}

    و برای مقداردهی اولیه به این می‌رسیم:

    impl<T> Iterator for IntoIter<T> {
    type Item = T;
    fn next(&mut self) -> Option<T> {
        if self.start == self.end {
            None
        } else {
            unsafe {
                let result = ptr::read(self.start);
                self.start = self.start.offset(1);
                Some(result)
            }
        }
    }

    fn size_hint(&self) -> (usize, Option<usize>) {
        let len = (self.end as usize - self.start as usize)
                  / mem::size_of::<T>();
        (len, Some(len))
    }
}

    پیمایش رو به جلو این‌گونه است:

    impl<T> DoubleEndedIterator for IntoIter<T> {
    fn next_back(&mut self) -> Option<T> {
        if self.start == self.end {
            None
        } else {
            unsafe {
                self.end = self.end.offset(-1);
                Some(ptr::read(self.end))
            }
        }
    }
}

    چون IntoIter مالکیت تخصیص خود را به دست می‌گیرد، باید Drop را پیاده‌سازی کند تا آن را آزاد کند. با این حال، می‌خواهد Drop را برای drop کردن عناصری که تولید نشده‌اند و در آن باقی مانده‌اند نیز پیاده‌سازی کند.

    impl<T> Drop for IntoIter<T> {
    fn drop(&mut self) {
        if self.cap != 0 {
            // drop any remaining elements
            for _ in &mut *self {}
            let layout = Layout::array::<T>(self.cap).unwrap();
            unsafe {
                alloc::dealloc(self.buf.as_ptr() as *mut u8, layout);
            }
        }
    }
}
