    Deref

    بسیار خب! یک پشتهٔ حداقلی آبرومند پیاده‌سازی کرده‌ایم. می‌توانیم push کنیم، می‌توانیم pop کنیم و می‌توانیم بعد از خودمان پاکسازی کنیم. با این حال، مجموعهٔ درهم‌برهمی از قابلیت‌ها هست که منطقاً می‌خواهیم داشته باشیم. به‌طور خاص، ما یک آرایهٔ درست‌وحسابی داریم، اما هیچ‌کدام از قابلیت‌های slice را نداریم. حل این مسئله در واقع کاملاً آسان است: می‌توانیم Deref<Target=[T]> را پیاده‌سازی کنیم. این کار به‌طور جادویی باعث می‌شود Vec ما در هر جور شرایطی به slice تبدیل شود (coerce) و مثل یک slice رفتار کند.

    تنها چیزی که لازم داریم slice::from_raw_parts است. این تابع slice‌های خالی را برای ما به‌درستی مدیریت می‌کند. بعداً وقتی پشتیبانی از نوع‌های با اندازهٔ صفر را راه‌اندازی کنیم، برای آن‌ها هم بدون هیچ دردسری کار خواهد کرد.

    use std::ops::Deref;

impl<T> Deref for Vec<T> {
    type Target = [T];
    fn deref(&self) -> &[T] {
        unsafe {
            std::slice::from_raw_parts(self.ptr.as_ptr(), self.len)
        }
    }
}

    و بیایید DerefMut را هم پیاده کنیم:

    use std::ops::DerefMut;

impl<T> DerefMut for Vec<T> {
    fn deref_mut(&mut self) -> &mut [T] {
        unsafe {
            std::slice::from_raw_parts_mut(self.ptr.as_ptr(), self.len)
        }
    }
}

    حالا len، first، last، اندیس‌گذاری، برش‌دهی (slicing)، مرتب‌سازی، iter، iter_mut و همهٔ امکانات جانبی دیگری را که slice ارائه می‌دهد داریم. عالی!
