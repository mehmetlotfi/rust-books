    کران‌های صفت با رتبهٔ بالاتر (HRTB)

    صفت‌های Fn در Rust کمی جادویی هستند. برای مثال، می‌توانیم کد زیر را بنویسیم:

    struct Closure<F> {
    data: (u8, u16),
    func: F,
}

impl<F> Closure<F>
    where F: Fn(&(u8, u16)) -> &u8,
{
    fn call(&self) -> &u8 {
        (self.func)(&self.data)
    }
}

fn do_it(data: &(u8, u16)) -> &u8 { &data.0 }

fn main() {
    let clo = Closure { data: (0, 1), func: do_it };
    println!("{}", clo.call());
}

    اگر بخواهیم این کد را به همان شیوه‌ای که در بخش طول عمر انجام دادیم ساده‌لوحانه از قند نحوی (desugar) درآوریم، به مشکل برمی‌خوریم:

    // NOTE: `&'b data.0` and `'x: {` is not valid syntax!
struct Closure<F> {
    data: (u8, u16),
    func: F,
}

impl<F> Closure<F>
    // where F: Fn(&'??? (u8, u16)) -> &'??? u8,
{
    fn call<'a>(&'a self) -> &'a u8 {
        (self.func)(&self.data)
    }
}

fn do_it<'b>(data: &'b (u8, u16)) -> &'b u8 { &'b data.0 }

fn main() {
    'x: {
        let clo = Closure { data: (0, 1), func: do_it };
        println!("{}", clo.call());
    }
}

    چطور باید طول عمرها را روی کران صفتِ F بیان کنیم؟ باید در آنجا یک طول عمر بدهیم، اما طول عمری که برایمان اهمیت دارد تا زمانی که وارد بدنهٔ call نشویم نامی ندارد! همچنین این یک طول عمر ثابت نیست؛ call با هر طول عمری که &self در آن نقطه داشته باشد کار می‌کند.

    این کار به جادوی کران‌های صفت با رتبهٔ بالاتر (HRTB) نیاز دارد. روش desugar کردن آن به این صورت است:

    where for<'a> F: Fn(&'a (u8, u16)) -> &'a u8,

    یا به شکل دیگر:

    where F: for<'a> Fn(&'a (u8, u16)) -> &'a u8,

    (در اینجا Fn(a, b, c) -> d خودش فقط قند نحوی برای صفت واقعیِ ناپایدار Fn است.)

    for<'a> را می‌توان «برای همهٔ انتخاب‌های 'a» خواند، و در اصل یک فهرست نامتناهی از کران‌های صفت تولید می‌کند که F باید آن‌ها را برآورده کند. شدید است. جاهای زیادی بیرون از صفت‌های Fn نیست که با HRTBها روبه‌رو شویم، و حتی برای آن‌ها هم برای حالت‌های رایج قند نحوی جادویی خوبی داریم.

    در مجموع، می‌توانیم کد اصلی را صریح‌تر این‌گونه بازنویسی کنیم:

    struct Closure<F> {
    data: (u8, u16),
    func: F,
}

impl<F> Closure<F>
    where for<'a> F: Fn(&'a (u8, u16)) -> &'a u8,
{
    fn call(&self) -> &u8 {
        (self.func)(&self.data)
    }
}

fn do_it(data: &(u8, u16)) -> &u8 { &data.0 }

fn main() {
    let clo = Closure { data: (0, 1), func: do_it };
    println!("{}", clo.call());
}
