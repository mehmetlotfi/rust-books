    dead_code

    کامپایلر یک lint به نام dead_code دارد که دربارهٔ توابع استفاده‌نشده هشدار می‌دهد. با یک ویژگی می‌توان این lint را غیرفعال کرد.

    fn used_function() {}

// `#[allow(dead_code)]` is an attribute that disables the `dead_code` lint
#[allow(dead_code)]
fn unused_function() {}

fn noisy_unused_function() {}
// FIXME ^ Add an attribute to suppress the warning

fn main() {
    used_function();
}

    در برنامه‌های واقعی باید کد مرده را حذف کنید. در این مثال‌ها به‌دلیل ماهیت تعاملی آن‌ها، در بعضی بخش‌ها کد مرده را مجاز می‌کنیم.
