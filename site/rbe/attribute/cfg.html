Rust با مثالRust By Example

    cfg

    بررسی شرطی پیکربندی با دو عملگر متفاوت امکان‌پذیر است:

    • ویژگی cfg: نگارش #[cfg(...)] در جایگاه ویژگی؛
    • ماکروی cfg!: نگارش cfg!(...) در عبارت‌های بولی.

    اولی کامپایل شرطی را فعال می‌کند و دومی بر اساس شرط به مقدار true یا false ارزیابی می‌شود تا بررسی در زمان اجرا ممکن باشد. نگارش آرگومان‌های هر دو یکسان است.

    برخلاف #[cfg]، ماکروی cfg! هیچ کدی را حذف نمی‌کند و فقط به درست یا نادرست ارزیابی می‌شود. برای نمونه، وقتی شرط یک عبارت if/else با cfg! نوشته شده باشد، همهٔ بلوک‌ها باید معتبر باشند؛ فارغ از اینکه cfg! چه مقداری تولید می‌کند.

    // This function only gets compiled if the target OS is linux
#[cfg(target_os = "linux")]
fn are_you_on_linux() {
    println!("You are running linux!");
}

// And this function only gets compiled if the target OS is *not* linux
#[cfg(not(target_os = "linux"))]
fn are_you_on_linux() {
    println!("You are *not* running linux!");
}

fn main() {
    are_you_on_linux();

    println!("Are you sure?");
    if cfg!(target_os = "linux") {
        println!("Yes. It's definitely linux!");
    } else {
        println!("Yes. It's definitely *not* linux!");
    }
}
