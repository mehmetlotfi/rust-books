    کریت‌ها

    با ویژگی crate_type می‌توان به کامپایلر گفت کریت فایل اجرایی است یا کتابخانه، و حتی نوع کتابخانه را تعیین کرد. ویژگی crate_name نیز برای تنظیم نام کریت به کار می‌رود.

    بااین‌حال توجه به این نکته مهم است که ویژگی‌های crate_type و crate_name هنگام استفاده از Cargo، مدیر بستهٔ راست، هیچ اثری ندارند. چون Cargo در بیشتر پروژه‌های راست استفاده می‌شود، این یعنی کاربردهای واقعی crate_type و crate_name نسبتاً محدود است.

    // This crate is a library
#![crate_type = "lib"]
// The library is named "rary"
#![crate_name = "rary"]

pub fn public_function() {
    println!("called rary's `public_function()`");
}

fn private_function() {
    println!("called rary's `private_function()`");
}

pub fn indirect_access() {
    print!("called rary's `indirect_access()`, that\n> ");

    private_function();
}

    هنگام استفاده از ویژگی crate_type دیگر نیازی نیست پرچم --crate-type را به rustc بدهیم.

    $ rustc lib.rs
$ ls lib*
library.rlib
