    وابستگی‌های توسعه

    گاهی وابستگی‌ای را فقط برای آزمون‌ها (یا مثال‌ها و بنچمارک‌ها) لازم داریم. چنین وابستگی‌هایی در بخش [dev-dependencies] فایل Cargo.toml افزوده می‌شوند و به بسته‌های دیگری که به این بسته وابسته‌اند منتقل نخواهند شد.

    یکی از نمونه‌ها pretty_assertions است که ماکروهای استاندارد assert_eq! و assert_ne! را برای نمایش تفاوت‌های رنگی گسترش می‌دهد. فایل Cargo.toml:

    # standard crate data is left out
[dev-dependencies]
pretty_assertions = "1"

    فایل src/lib.rs:

    pub fn add(a: i32, b: i32) -> i32 {
    a + b
}

#[cfg(test)]
mod tests {
    use super::*;
    use pretty_assertions::assert_eq; // crate for test-only use. Cannot be used in non-test code.

    #[test]
    fn test_add() {
        assert_eq!(add(2, 3), 5);
    }
}
