Rust با مثالRust By Example

    قالب‌بندی

    دیدیم که قالب‌بندی با یک رشتهٔ قالب مشخص می‌شود:

    • format!("{}", foo) -> "3735928559"
    • format!("0x{:X}", foo) -> "0xDEADBEEF"
    • format!("0o{:o}", foo) -> "0o33653337357"

    یک متغیر یکسان (foo) را می‌توان بسته به نوع آرگومان به شکل‌های متفاوتی قالب‌بندی کرد: X، o یا بدون تعیین نوع.

    این قابلیت به کمک صفت‌ها پیاده‌سازی شده و برای هر نوع آرگومان یک صفت وجود دارد. پرکاربردترین صفت قالب‌بندی Display است که مواردی مانند {} را مدیریت می‌کند؛ یعنی زمانی که نوع آرگومان مشخص نشده است.

    use std::fmt::{self, Formatter, Display};

struct City {
    name: &'static str,
    // Latitude
    lat: f32,
    // Longitude
    lon: f32,
}

impl Display for City {
    // `f` is a buffer, and this method must write the formatted string into it.
    fn fmt(&self, f: &mut Formatter) -> fmt::Result {
        let lat_c = if self.lat >= 0.0 { 'N' } else { 'S' };
        let lon_c = if self.lon >= 0.0 { 'E' } else { 'W' };

        // `write!` is like `format!`, but it will write the formatted string
        // into a buffer (the first argument).
        write!(f, "{}: {:.3}°{} {:.3}°{}",
               self.name, self.lat.abs(), lat_c, self.lon.abs(), lon_c)
    }
}

#[derive(Debug)]
struct Color {
    red: u8,
    green: u8,
    blue: u8,
}

fn main() {
    for city in [
        City { name: "Dublin", lat: 53.347778, lon: -6.259722 },
        City { name: "Oslo", lat: 59.95, lon: 10.75 },
        City { name: "Vancouver", lat: 49.25, lon: -123.1 },
    ] {
        println!("{}", city);
    }
    for color in [
        Color { red: 128, green: 255, blue: 90 },
        Color { red: 0, green: 3, blue: 254 },
        Color { red: 0, green: 0, blue: 0 },
    ] {
        // Switch this to use {} once you've added an implementation
        // for fmt::Display.
        println!("{:?}", color);
    }
}

    فهرست کامل صفت‌های قالب‌بندی و نوع آرگومان مربوط به هرکدام را می‌توانید در مستندات std::fmt ببینید.

    تمرین

    برای ساختار Color در مثال بالا، صفت fmt::Display را طوری پیاده‌سازی کنید که خروجی زیر نمایش داده شود:

    RGB (128, 255, 90) 0x80FF5A
RGB (0, 3, 254) 0x0003FE
RGB (0, 0, 0) 0x000000

    اگر گیر کردید، این دو نکته می‌توانند کمک کنند:

    • شاید لازم باشد هر رنگ را بیش از یک بار فهرست کنید.
    • با :0>2 می‌توانید مقدار را تا عرض ۲ با صفر پُر کنید. برای اعداد مبنای شانزده نیز می‌توان از :02X استفاده کرد.

    امتیاز اضافی:

    • اگر می‌خواهید از همین حالا تبدیل نوع را هم امتحان کنید، فرمول محاسبهٔ یک رنگ در فضای رنگی RGB چنین است: RGB = (R * 65_536) + (G * 256) + B که در آن R is RED, G is GREEN, and B is BLUE. یک عدد صحیح ۸ بیتی بدون علامت (u8) فقط می‌تواند مقادیر تا ۲۵۵ را نگه دارد. برای تبدیل u8 به u32 می‌توانید بنویسید: variable_name as u32.
