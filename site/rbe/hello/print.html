    چاپ قالب‌بندی‌شده

    چاپ توسط مجموعه‌ای از macros انجام می‌شود که در std::fmt تعریف شده‌اند و برخی از آن‌ها عبارت‌اند از:

    • format!: متن قالب‌بندی‌شده را در یک String می‌نویسد.
    • print!: مانند format! است، اما متن را در خروجی استاندارد کنسول (io::stdout) چاپ می‌کند.
    • println!: مانند print! است، با این تفاوت که در پایان یک خط جدید اضافه می‌کند.
    • eprint!: مانند print! است، اما متن را در خروجی خطای استاندارد (io::stderr) چاپ می‌کند.
    • eprintln!: مانند eprint! است، با این تفاوت که در پایان یک خط جدید اضافه می‌کند.

    همهٔ این ماکروها متن را به یک شیوه تجزیه می‌کنند. مزیت دیگر راست این است که درستی قالب‌بندی را هنگام کامپایل بررسی می‌کند.

    fn main() {
    // In general, the `{}` will be automatically replaced with any
    // arguments. These will be stringified.
    println!("{} days", 31);

    // Positional arguments can be used. Specifying an integer inside `{}`
    // determines which additional argument will be replaced. Arguments start
    // at 0 immediately after the format string.
    println!("{0}, this is {1}. {1}, this is {0}", "Alice", "Bob");

    // As can named arguments.
    println!("{subject} {verb} {object}",
             object="the lazy dog",
             subject="the quick brown fox",
             verb="jumps over");

    // Different formatting can be invoked by specifying the format character
    // after a `:`.
    println!("Base 10:               {}",   69420); // 69420
    println!("Base 2 (binary):       {:b}", 69420); // 10000111100101100
    println!("Base 8 (octal):        {:o}", 69420); // 207454
    println!("Base 16 (hexadecimal): {:x}", 69420); // 10f2c

    // You can right-justify text with a specified width. This will
    // output "    1". (Four white spaces and a "1", for a total width of 5.)
    println!("{number:>5}", number=1);

    // You can pad numbers with extra zeroes,
    println!("{number:0>5}", number=1); // 00001
    // and left-adjust by flipping the sign. This will output "10000".
    println!("{number:0<5}", number=1); // 10000

    // You can use named arguments in the format specifier by appending a `$`.
    println!("{number:0>width$}", number=1, width=5);

    // Rust even checks to make sure the correct number of arguments are used.
    println!("My name is {0}, {1} {0}", "Bond");
    // FIXME ^ Add the missing argument: "James"

    // Only types that implement fmt::Display can be formatted with `{}`. User-
    // defined types do not implement fmt::Display by default.

    #[allow(dead_code)] // disable `dead_code` which warn against unused module
    struct Structure(i32);

    // This will not compile because `Structure` does not implement
    // fmt::Display.
    // println!("This struct `{}` won't print...", Structure(3));
    // TODO ^ Try uncommenting this line

    // For Rust 1.58 and above, you can directly capture the argument from a
    // surrounding variable. Just like the above, this will output
    // "    1", 4 white spaces and a "1".
    let number: f64 = 1.0;
    let width: usize = 5;
    println!("{number:>width$}");
}

    std::fmt شامل traits متعددی است که نحوهٔ نمایش متن را کنترل می‌کنند. شکل پایهٔ دو مورد مهم از آن‌ها در ادامه فهرست شده است:

    • fmt::Debug: از نشانهٔ {:?} استفاده می‌کند و متن را با هدف اشکال‌زدایی قالب‌بندی می‌کند.
    • fmt::Display: از نشانهٔ {} استفاده می‌کند و متن را به شکلی خواناتر و مناسب کاربر قالب‌بندی می‌کند.

    در این مثال از fmt::Display استفاده کردیم، زیرا کتابخانهٔ استاندارد پیاده‌سازی آن را برای این نوع‌ها فراهم کرده است. چاپ نوع‌های سفارشی به چند مرحلهٔ بیشتر نیاز دارد.

    پیاده‌سازی صفت fmt::Display به‌طور خودکار صفت ToString را پیاده‌سازی می‌کند که به ما امکان می‌دهد نوع را به String تبدیل کنیم.

    در خط ۴۳، عبارت #[allow(dead_code)] یک ویژگی است که فقط بر جزء بعد از خود اثر می‌گذارد.

    تمرین‌ها

    • مشکل کد بالا را با توجه به FIXME برطرف کنید تا بدون خطا اجرا شود.
    • خطی را که برای قالب‌بندی ساختار Structure نوشته شده از حالت توضیح خارج کنید (TODO را ببینید).
    • یک فراخوانی println! اضافه کنید که با کنترل تعداد رقم‌های اعشار، عبارت Pi is roughly 3.142 را چاپ کند. برای این تمرین، مقدار تقریبی پی را let pi = 3.141592 در نظر بگیرید. راهنما: برای تنظیم تعداد رقم‌های اعشار می‌توانید مستندات std::fmt را بررسی کنید.
