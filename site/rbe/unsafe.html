Rust با مثالRust By Example

    عملیات ناامن (Unsafe)

    برای شروع این بخش، از مستندات رسمی نقل می‌کنیم: «باید تلاش کرد مقدار کد unsafe در یک پایگاه کد کمینه شود.» با در نظر گرفتن این نکته، شروع کنیم! حاشیه‌نویسی‌های unsafe در Rust برای دور زدن حفاظت‌هایی به‌کار می‌روند که کامپایلر برقرار کرده است؛ به‌طور مشخص، چهار کاربرد اصلی برای unsafe وجود دارد:

    • ارجاع‌زدایی اشاره‌گرهای خام
    • فراخوانی توابع یا متدهای unsafe (از جمله تابعی از طریق FFI؛ فصل پیشین را ببینید)
    • دسترسی به متغیرهای ایستای تغییرپذیر یا تغییر آن‌ها
    • پیاده‌سازی صفات ناامن
    • دسترسی به اعضای union

    اشاره‌گرهای خام

    اشاره‌گرهای خام * و ارجاع‌های &T رفتاری مشابه دارند، اما ارجاع‌ها به کمک بررسی‌کنندهٔ قرض تضمین می‌کنند به دادهٔ معتبر اشاره کنند و همیشه امن‌اند. ارجاع‌زدایی اشاره‌گر خام تنها در بلوک unsafe ممکن است.

    fn main() {
    let raw_p: *const u32 = &10;

    unsafe {
        assert!(*raw_p == 10);
    }
}

    فراخوانی توابع ناامن

    برخی توابع را می‌توان unsafe اعلان کرد، یعنی تضمین درستی به‌جای کامپایلر بر عهدهٔ برنامه‌نویس است. یک نمونه std::slice::from_raw_parts است که با دریافت اشاره‌گری به عنصر اول و یک طول، یک slice می‌سازد.

    use std::slice;

fn main() {
    let some_vector = vec![1, 2, 3, 4];

    let pointer = some_vector.as_ptr();
    let length = some_vector.len();

    unsafe {
        let my_slice: &[u32] = slice::from_raw_parts(pointer, length);

        assert_eq!(some_vector.as_slice(), my_slice);
    }
}

    در slice::from_raw_parts یکی از فرض‌هایی که حتماً باید برقرار بماند این است که اشاره‌گر به حافظهٔ معتبر با نوع درست اشاره کند. نقض این ناورداها رفتار برنامه را تعریف‌نشده می‌کند و نتیجه قابل پیش‌بینی نیست.

    اعضای Union

    اعضای union در حافظه هم‌پوشانی دارند؛ بنابراین تغییر یک عضو، مقدار همهٔ اعضا را تغییر می‌دهد. وقتی نوع دادهٔ لازم در زمان اجرا معلوم نیست می‌توان از آن‌ها استفاده کرد. چون Rust enumهای امن دارد، هدف اصلی union تعامل با کد C است. دسترسی و تغییر اعضای union فقط در Rust ناامن مجاز است.

    union MyFirstUnion {
    float: f32,
    integer: u32
}

fn main() {
    // Creating an object of a union type doesn't require Unsafe Rust.
    let mut u = MyFirstUnion { float: 123.45 };
    
    // Reading and changing u.float or u.integer is only allowed in Unsafe Rust.
    unsafe {
        assert_eq!(u.float, 123.45);
        println!("u.float = 123.45, but u.integer = {}", u.integer);

        u.integer = 42;
        assert_eq!(u.integer, 42);
        println!("u.integer = 42, but u.float = {}", u.float);
    }
}
