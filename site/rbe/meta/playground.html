Rust با مثالRust By Example

    محیط آزمایش (Playground)

    Rust Playground راهی برای آزمایش کد Rust از طریق رابط وب است.

    استفاده همراه mdbook

    در mdbook می‌توانید مثال‌های کد را قابل اجرا و ویرایش کنید.

    fn main() {
    println!("Hello World!");
}

    این کار به خواننده اجازه می‌دهد نمونه‌کد را اجرا و نیز ویرایش کند. نکتهٔ اصلی افزودن واژهٔ editable با یک ویرگول به حصار کد است.

    ```rust,editable
//...place your code here
```

    اگر می‌خواهید mdbook هنگام ساخت و آزمون از کد بگذرد، ignore را اضافه کنید.

    ```rust,editable,ignore
//...place your code here
```

    استفاده همراه مستندات

    شاید در برخی مستندات رسمی Rust دکمهٔ «Run» را دیده باشید که نمونه‌کد را در زبانه‌ای تازه در Playground باز می‌کند. این قابلیت با ویژگی #[doc] به نام html_playground_url فعال می‌شود.

    #![doc(html_playground_url = "https://play.rust-lang.org/")]
//! ```
//! println!("Hello World");
//! ```
