Rust با مثالRust By Example

    مستندسازی

    با cargo doc مستندات را در target/doc بسازید؛ cargo doc --open آن را خودکار در مرورگر باز می‌کند.

    برای اجرای همهٔ آزمون‌ها، از جمله آزمون مستندات، cargo test و فقط برای آزمون مستندات cargo test --doc را اجرا کنید.

    این فرمان‌ها در صورت نیاز rustdoc (و rustc) را به‌درستی فراخوانی می‌کنند.

    توضیحات مستندات

    توضیحات مستندات برای پروژه‌های بزرگ بسیار سودمندند. هنگام اجرای rustdoc همین توضیحات به مستندات کامپایل می‌شوند. با /// مشخص می‌شوند و از Markdown پشتیبانی می‌کنند.

    #![crate_name = "doc"]

/// A human being is represented here
pub struct Person {
    /// A person must have a name, no matter how much Juliet may hate it
    name: String,
}

impl Person {
    /// Creates a person with the given name.
    ///
    /// # Examples
    ///
    /// ```
    /// // You can have rust code between fences inside the comments
    /// // If you pass --test to `rustdoc`, it will even test it for you!
    /// use doc::Person;
    /// let person = Person::new("name");
    /// ```
    pub fn new(name: &str) -> Person {
        Person {
            name: name.to_string(),
        }
    }

    /// Gives a friendly hello!
    ///
    /// Says "Hello, [name](Person::name)" to the `Person` it is called on.
    pub fn hello(&self) {
        println!("Hello, {}!", self.name);
    }
}

fn main() {
    let john = Person::new("John");

    john.hello();
}

    برای اجرای آزمون‌ها، ابتدا کد را به‌صورت کتابخانه بسازید و سپس محل کتابخانه را به rustdoc بگویید تا آن را به هر برنامهٔ doctest پیوند دهد:

    $ rustc doc.rs --crate-type lib
$ rustdoc --test --extern doc="libdoc.rlib" doc.rs

    ویژگی‌های مستندات

    در ادامه چند نمونه از رایج‌ترین ویژگی‌های #[doc] در rustdoc آمده است.

    inline

    مستندات را به‌جای پیوند به صفحه‌ای جدا، درجا قرار می‌دهد.

    #[doc(inline)]
pub use bar::Bar;

/// bar docs
pub mod bar {
    /// the docs for Bar
    pub struct Bar;
}

    no_inline

    از پیوند دادن به صفحه‌ای جدا یا هر جای دیگر جلوگیری می‌کند.

    // Example from libcore/prelude
#[doc(no_inline)]
pub use crate::mem::drop;

    hidden

    به rustdoc می‌گوید این مورد را در مستندات نیاورد:

    // Example from the futures-rs library
#[doc(hidden)]
pub use self::async_await::*;

    جامعه به‌طور گسترده از rustdoc استفاده می‌کند و مستندات کتابخانهٔ std نیز با آن تولید می‌شود.
