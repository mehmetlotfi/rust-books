    آرگومان‌های برنامه

    کتابخانهٔ استاندارد

    با std::env::args می‌توان به آرگومان‌های خط فرمان دسترسی یافت. این تابع تکرارگری برمی‌گرداند که برای هر آرگومان یک String تولید می‌کند:

    use std::env;

fn main() {
    let args: Vec<String> = env::args().collect();

    // The first argument is the path that was used to call the program.
    println!("My path is {}.", args[0]);

    // The rest of the arguments are the passed command line parameters.
    // Call the program like this:
    //   $ ./args arg1 arg2
    println!("I got {:?} arguments: {:?}.", args.len() - 1, &args[1..]);
}
    $ ./args 1 2 3
My path is ./args.
I got 3 arguments: ["1", "2", "3"].

    Crateها

    علاوه بر این، crateهای بسیاری وجود دارند که هنگام ساخت برنامه‌های خط فرمان قابلیت‌های بیشتری فراهم می‌کنند. یکی از محبوب‌ترین crateها برای آرگومان‌های خط فرمان clap است.
