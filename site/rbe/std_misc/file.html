    ورودی/خروجی فایل

    ساختار File یک فایل بازشده را نمایش می‌دهد (توصیف‌گر فایل را در خود می‌پیچد) و امکان خواندن و/یا نوشتن فایل زیربنایی را می‌دهد.

    چون در ورودی/خروجی فایل خطاهای زیادی ممکن است رخ دهد، همهٔ متدهای File نوع io::Result<T> را برمی‌گردانند که نام مستعار Result<T, io::Error> است.

    این کار شکست همهٔ عملیات I/O را صریح می‌کند؛ بنابراین برنامه‌نویس تمام مسیرهای شکست را می‌بیند و به مدیریت پیش‌دستانهٔ آن‌ها تشویق می‌شود.
