    مسیر (Path)

    نوع Path مسیر فایل‌ها را در سامانهٔ فایل نمایش می‌دهد. در همهٔ سکوها یک std::path::Path واحد وجود دارد که معنا و جداکننده‌های ویژهٔ هر سکو را انتزاع می‌کند. هنگام نیاز آن را با use std::path::Path; وارد محدوده کنید.

    می‌توان Path را از OsStr ساخت. این نوع چندین متد برای دریافت اطلاعات فایل یا پوشهٔ مقصد دارد.

    Path تغییرناپذیر است. نسخهٔ مالک Path، یعنی PathBuf، است. رابطهٔ Path و PathBuf شبیه رابطهٔ str و String است: یک PathBuf را می‌توان درجا تغییر داد و می‌توان آن را به Path ارجاع‌زدایی کرد.

    توجه کنید که Path درون خود نه به‌صورت رشتهٔ UTF-8، بلکه به‌صورت یک OsString ذخیره می‌شود. بنابراین تبدیل یک Path به &str رایگان نیست و ممکن است شکست بخورد (یک Option برگردانده می‌شود). با این حال، می‌توان با into_os_string و as_os_str به‌ترتیب یک Path را آزادانه به OsString یا &OsStr تبدیل کرد.

    use std::path::Path;

fn main() {
    // Create a `Path` from an `&'static str`
    let path = Path::new(".");

    // The `display` method returns a `Display`able structure
    let _display = path.display();

    // `join` merges a path with a byte container using the OS specific
    // separator, and returns a `PathBuf`
    let mut new_path = path.join("a").join("b");

    // `push` extends the `PathBuf` with a `&Path`
    new_path.push("c");
    new_path.push("myfile.tar.gz");

    // `set_file_name` updates the file name of the `PathBuf`
    new_path.set_file_name("package.tgz");

    // Convert the `PathBuf` into a string slice
    match new_path.to_str() {
        None => panic!("new path is not a valid UTF-8 sequence"),
        Some(s) => println!("new path is {}", s),
    }
}
