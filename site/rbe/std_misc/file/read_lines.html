Rust با مثالRust By Example

    read_lines

    رویکردی ساده‌انگارانه

    این می‌تواند نخستین تلاش معقول یک تازه‌کار برای خواندن خط‌های فایل باشد.

    use std::fs::read_to_string;

fn read_lines(filename: &str) -> Vec<String> {
    let mut result = Vec::new();

    for line in read_to_string(filename).unwrap().lines() {
        result.push(line.to_string())
    }

    result
}

    چون متد lines() تکرارگری روی خط‌های فایل برمی‌گرداند، می‌توانیم همان‌جا نگاشت را انجام دهیم و نتیجه‌ها را گردآوری کنیم تا عبارتی کوتاه‌تر و روان‌تر داشته باشیم.

    use std::fs::read_to_string;

fn read_lines(filename: &str) -> Vec<String> {
    read_to_string(filename)
        .unwrap()  // panic on possible file-reading errors
        .lines()  // split the string into an iterator of string slices
        .map(String::from)  // make each slice into a string
        .collect()  // gather them together into a vector
}

    توجه کنید در هر دو مثال باید ارجاع &str بازگردانده‌شده از lines() را به نوع مالک String تبدیل کنیم؛ به‌ترتیب با .to_string() و String::from.

    رویکردی کارآمدتر

    اینجا مالکیت File بازشده را به ساختار BufReader می‌دهیم. BufReader برای کاهش تخصیص‌های میانی از بافر داخلی استفاده می‌کند.

    همچنین read_lines را تغییر می‌دهیم تا به‌جای تخصیص یک String تازه برای هر خط، تکرارگر برگرداند.

    use std::fs::File;
use std::io::{self, BufRead};
use std::path::Path;

fn main() {
    // File hosts.txt must exist in the current path
    if let Ok(lines) = read_lines("./hosts.txt") {
        // Consumes the iterator, returns an (Optional) String
        for line in lines.map_while(Result::ok) {
            println!("{}", line);
        }
    }
}

// The output is wrapped in a Result to allow matching on errors.
// Returns an Iterator to the Reader of the lines of the file.
fn read_lines<P>(filename: P) -> io::Result<io::Lines<io::BufReader<File>>>
where P: AsRef<Path>, {
    let file = File::open(filename)?;
    Ok(io::BufReader::new(file).lines())
}

    اجرای برنامه، خط‌ها را جداگانه چاپ می‌کند.

    $ echo -e "127.0.0.1\n192.168.0.1\n" > hosts.txt
$ rustc read_lines.rs && ./read_lines
127.0.0.1
192.168.0.1

    (چون File::open آرگومان عمومی AsRef<Path> می‌خواهد، متد عمومی read_lines() را با همان قید و کلیدواژهٔ where تعریف می‌کنیم.)

    این فرایند از ساخت یک String شامل تمام محتوای فایل کارآمدتر است؛ ساخت چنین رشته‌ای به‌ویژه برای فایل‌های بزرگ مشکل کارایی ایجاد می‌کند.
