    بستارها

    بستارها توابعی هستند که می‌توانند محیط پیرامون خود را در اختیار بگیرند. برای نمونه، بستار زیر متغیر x را می‌گیرد:

    |val| val + x

    نگارش و قابلیت‌های بستارها استفادهٔ سریع و درجا از آن‌ها را بسیار آسان می‌کند. فراخوانی بستار دقیقاً مانند فراخوانی تابع است؛ با این تفاوت که نوع ورودی و خروجی می‌تواند استنباط شود و نام متغیرهای ورودی باید مشخص باشد.

    دیگر ویژگی‌های بستارها عبارت‌اند از:

    • استفاده از || به‌جای () پیرامون متغیرهای ورودی؛
    • اختیاری‌بودن آکولادهای {} برای عبارت تک‌خطی و الزامی‌بودن آن‌ها در سایر موارد؛
    • امکان در اختیار گرفتن متغیرهای محیط بیرونی.
    fn main() {
    let outer_var = 42;

    // A regular function can't refer to variables in the enclosing environment
    //fn function(i: i32) -> i32 { i + outer_var }
    // TODO: uncomment the line above and see the compiler error. The compiler
    // suggests that we define a closure instead.

    // Closures are anonymous, here we are binding them to references.
    // Annotation is identical to function annotation but is optional
    // as are the `{}` wrapping the body. These nameless functions
    // are assigned to appropriately named variables.
    let closure_annotated = |i: i32| -> i32 { i + outer_var };
    let closure_inferred  = |i     |          i + outer_var  ;

    // Call the closures.
    println!("closure_annotated: {}", closure_annotated(1));
    println!("closure_inferred: {}", closure_inferred(1));
    // Once closure's type has been inferred, it cannot be inferred again with another type.
    //println!("cannot reuse closure_inferred with another type: {}", closure_inferred(42i64));
    // TODO: uncomment the line above and see the compiler error.

    // A closure taking no arguments which returns an `i32`.
    // The return type is inferred.
    let one = || 1;
    println!("closure returning one: {}", one());

}
