Rust با مثالRust By Example

    توابع واگرا

    توابع واگرا هرگز بازنمی‌گردند. این توابع با ! مشخص می‌شوند که یک نوع تهی است.

    fn foo() -> ! {
    panic!("This call never returns.");
}

    برخلاف همهٔ نوع‌های دیگر، نمی‌توان نمونه‌ای از این نوع ساخت، زیرا مجموعهٔ مقادیر ممکن آن تهی است. توجه کنید که این نوع با () تفاوت دارد؛ نوع () دقیقاً یک مقدار ممکن دارد.

    برای نمونه، تابع زیر به‌طور معمول بازمی‌گردد، هرچند مقدار بازگشتی آن اطلاعاتی ندارد.

    fn some_fn() {
    ()
}

fn main() {
    let _a: () = some_fn();
    println!("This function returns and you can see this line.");
}

    در مقابل، تابع زیر هرگز کنترل را به فراخواننده بازنمی‌گرداند.

    #![feature(never_type)]

fn main() {
    let x: ! = panic!("This call never returns.");
    println!("You will never see this line!");
}

    ممکن است این مفهوم انتزاعی به نظر برسد، اما در عمل بسیار مفید و اغلب کاربردی است. مزیت اصلی این نوع آن است که می‌تواند به هر نوع دیگری تبدیل شود؛ بنابراین در موقعیت‌هایی که نوع دقیق لازم است، مانند شاخه‌های match، انعطاف زیادی فراهم می‌کند. این انعطاف اجازه می‌دهد کدی مانند نمونهٔ زیر بنویسیم:

    fn main() {
    fn sum_odd_numbers(up_to: u32) -> u32 {
        let mut acc = 0;
        for i in 0..up_to {
            // Notice that the return type of this match expression must be u32
            // because of the type of the "addition" variable.
            let addition: u32 = match i%2 == 1 {
                // The "i" variable is of type u32, which is perfectly fine.
                true => i,
                // On the other hand, the "continue" expression does not return
                // u32, but it is still fine, because it never returns and therefore
                // does not violate the type requirements of the match expression.
                false => continue,
            };
            acc += addition;
        }
        acc
    }
    println!("Sum of odd numbers up to 9 (excluding): {}", sum_odd_numbers(9));
}

    این نوع همچنین نوع بازگشتی توابعی است که برای همیشه در حلقه می‌مانند، مانند سرورهای شبکه با loop {}، یا توابعی که فرایند را خاتمه می‌دهند، مانند exit().
