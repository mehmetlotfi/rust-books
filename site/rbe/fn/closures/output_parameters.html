    به‌عنوان پارامتر خروجی

    وقتی بستارها می‌توانند پارامتر ورودی باشند، باید بتوان آن‌ها را به‌عنوان خروجی نیز بازگرداند. بااین‌حال نوع ناشناس بستار بنا بر تعریف ناشناخته است؛ بنابراین برای بازگرداندن آن باید از impl Trait استفاده کنیم.

    صفت‌های معتبر برای بازگرداندن یک بستار عبارت‌اند از:

    • Fn
    • FnMut
    • FnOnce

    افزون بر این باید از کلیدواژهٔ move استفاده شود تا همهٔ متغیرها با مقدار گرفته شوند. دلیلش این است که مقادیر گرفته‌شده با ارجاع، به‌محض خروج از تابع از بین می‌روند و ارجاع‌های نامعتبری در بستار باقی می‌گذارند.

    fn create_fn() -> impl Fn() {
    let text = "Fn".to_owned();

    move || println!("This is a: {}", text)
}

fn create_fnmut() -> impl FnMut() {
    let text = "FnMut".to_owned();

    move || println!("This is a: {}", text)
}

fn create_fnonce() -> impl FnOnce() {
    let text = "FnOnce".to_owned();

    move || println!("This is a: {}", text)
}

fn main() {
    let fn_plain = create_fn();
    let mut fn_mut = create_fnmut();
    let fn_once = create_fnonce();

    fn_plain();
    fn_mut();
    fn_once();
}
