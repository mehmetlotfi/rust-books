Rust با مثالRust By Example

    ناشناس‌بودن نوع

    بستارها متغیرهای محدودهٔ پیرامون را به‌شکلی مختصر در اختیار می‌گیرند. آیا این کار پیامدی دارد؟ قطعاً. توجه کنید که استفاده از بستار به‌عنوان پارامتر تابع به جنریک‌ها نیاز دارد؛ این نیاز از شیوهٔ تعریف بستارها ناشی می‌شود:

    // `F` must be generic.
fn apply<F>(f: F) where
    F: FnOnce() {
    f();
}

    هنگام تعریف یک بستار (closure)، کامپایلر به‌طور ضمنی یک ساختار ناشناس جدید می‌سازد تا متغیرهای گرفته‌شده را درون آن نگه دارد و در همان حال، عملکرد را از طریق یکی از traits یعنی Fn، FnMut یا FnOnce برای این نوع ناشناخته پیاده‌سازی می‌کند. این نوع به متغیری اختصاص می‌یابد که تا زمان فراخوانی نگه داشته می‌شود.

    از آنجا که این نوع جدید از نوعی ناشناخته است، هر استفاده‌ای از آن در یک تابع به جنریک‌ها نیاز دارد. بااین‌حال یک پارامتر نوع بدون قید <T> همچنان مبهم است و مجاز نخواهد بود. بنابراین مقید‌کردن آن با یکی از traits یعنی Fn، FnMut یا FnOnce (که آن را پیاده‌سازی می‌کند) برای مشخص‌کردن نوع آن کافی است.

    // `F` must implement `Fn` for a closure which takes no
// inputs and returns nothing - exactly what is required
// for `print`.
fn apply<F>(f: F) where
    F: Fn() {
    f();
}

fn main() {
    let x = 7;

    // Capture `x` into an anonymous type and implement
    // `Fn` for it. Store it in `print`.
    let print = || println!("{}", x);

    apply(print);
}
