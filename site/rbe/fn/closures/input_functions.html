    توابع به‌عنوان ورودی

    از آنجا که بستارها می‌توانند آرگومان باشند، شاید بپرسید آیا دربارهٔ توابع نیز همین‌طور است؟ بله. اگر تابعی اعلان کنید که یک بستار را به‌عنوان پارامتر می‌گیرد، هر تابعی که قید صفت آن بستار را برآورده کند می‌تواند به‌عنوان پارامتر ارسال شود.

    // Define a function which takes a generic `F` argument
// bounded by `Fn`, and calls it
fn call_me<F: Fn()>(f: F) {
    f();
}

// Define a wrapper function satisfying the `Fn` bound
fn function() {
    println!("I'm a function!");
}

fn main() {
    // Define a closure satisfying the `Fn` bound
    let closure = || println!("I'm a closure!");

    call_me(closure);
    call_me(function);
}

    به‌عنوان نکته‌ای اضافی، Fn، FnMut و FnOnce که traits هستند، تعیین می‌کنند که بستار چگونه متغیرها را از دامنهٔ پیرامون خود می‌گیرد.
