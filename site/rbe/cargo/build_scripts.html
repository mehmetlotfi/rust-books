Rust با مثالRust By Example

    اسکریپت‌های ساخت

    گاهی ساخت معمولی با cargo کافی نیست. شاید کریت شما پیش از آنکه cargo بتواند آن را با موفقیت کامپایل کند به پیش‌نیازهایی مانند تولید کد یا کامپایل مقداری کد بومی نیاز داشته باشد. برای حل این مشکل، اسکریپت‌های ساخت (build scripts) را داریم که Cargo می‌تواند اجرا کند.

    برای افزودن اسکریپت ساخت به بسته می‌توان آن را در Cargo.toml به شکل زیر مشخص کرد:

    [package]
...
build = "build.rs"

    در غیر این صورت Cargo به‌طور پیش‌فرض در پوشهٔ پروژه به‌دنبال فایل build.rs می‌گردد.

    شیوهٔ استفاده از اسکریپت ساخت

    اسکریپت ساخت صرفاً یک فایل راست دیگر است که پیش از کامپایل هر بخش دیگری از بسته، کامپایل و اجرا می‌شود. بنابراین می‌توان از آن برای آماده‌کردن پیش‌نیازهای کریت استفاده کرد.

    Cargo ورودی‌های اسکریپت را از طریق متغیرهای محیطی مشخص‌شده در اینجا در اختیار آن می‌گذارد تا بتوان از آن‌ها استفاده کرد.

    اسکریپت خروجی خود را از طریق stdout ارائه می‌کند. همهٔ خط‌های چاپ‌شده در target/debug/build/<pkg>/output نوشته می‌شوند. خط‌هایی که با cargo: آغاز شوند مستقیماً به‌وسیلهٔ Cargo تفسیر می‌شوند و می‌توانند پارامترهای کامپایل بسته را تعیین کنند.

    برای مشخصات بیشتر و مثال‌ها، مشخصات Cargo را مطالعه کنید.
