    آزمون‌ها

    آزمون بخش جدایی‌ناپذیر هر نرم‌افزار است. راست به‌صورت کامل از آزمون واحد و یکپارچگی پشتیبانی می‌کند؛ این فصل از کتاب زبان برنامه‌نویسی راست را ببینید.

    در فصل‌های آزمون یاد می‌گیریم چگونه آزمون‌های واحد و یکپارچگی بنویسیم. برای سازمان‌دهی، آزمون‌های واحد را در همان ماژول مورد آزمون و آزمون‌های یکپارچگی را در پوشهٔ جداگانهٔ tests/ قرار می‌دهیم:

    foo
├── Cargo.toml
├── src
│   └── main.rs
│   └── lib.rs
└── tests
    ├── my_test.rs
    └── my_other_test.rs

    هر فایل در پوشهٔ tests یک آزمون یکپارچگی جداگانه است؛ یعنی کتابخانه را چنان می‌آزماید که گویی از یک کریت وابسته فراخوانی شده است.

    فصل آزمون سه شیوهٔ متفاوت آزمون را با جزئیات توضیح می‌دهد: واحد، مستندات و یکپارچگی.

    cargo راهی ساده برای اجرای همهٔ آزمون‌ها در اختیار شما می‌گذارد:

    $ cargo test

    باید خروجی‌ای شبیه این ببینید:

    $ cargo test
   Compiling blah v0.1.0 (file:///nobackup/blah)
    Finished dev [unoptimized + debuginfo] target(s) in 0.89 secs
     Running target/debug/deps/blah-d3b32b97275ec472

running 4 tests
test test_bar ... ok
test test_baz ... ok
test test_foo_bar ... ok
test test_foo ... ok

test result: ok. 4 passed; 0 failed; 0 ignored; 0 measured; 0 filtered out

    همچنین می‌توانید فقط آزمون‌هایی را اجرا کنید که نامشان با یک الگو سازگار است:

    $ cargo test test_foo

    $ cargo test test_foo
   Compiling blah v0.1.0 (file:///nobackup/blah)
    Finished dev [unoptimized + debuginfo] target(s) in 0.35 secs
     Running target/debug/deps/blah-d3b32b97275ec472

running 2 tests

test test_foo_bar ... ok

    یک نکتهٔ احتیاطی: Cargo ممکن است چند آزمون را هم‌زمان اجرا کند؛ بنابراین مطمئن شوید آزمون‌ها با یکدیگر وارد وضعیت رقابتی نمی‌شوند.

    یکی از نمونه‌های مشکل‌ساز هم‌زمانی زمانی است که دو آزمون در یک فایل خروجی می‌نویسند، مانند مثال زیر:

    #[cfg(test)]
mod tests {
    // Import the necessary modules
    use std::fs::OpenOptions;
    use std::io::Write;

    // This test writes to a file
    #[test]
    fn test_file() {
        // Opens the file ferris.txt or creates one if it doesn't exist.
        let mut file = OpenOptions::new()
            .append(true)
            .create(true)
            .open("ferris.txt")
            .expect("Failed to open ferris.txt");

        // Print "Ferris" 5 times.
        for _ in 0..5 {
            file.write_all("Ferris\n".as_bytes())
                .expect("Could not write to ferris.txt");
        }
    }

    // This test tries to write to the same file
    #[test]
    fn test_file_also() {
        // Opens the file ferris.txt or creates one if it doesn't exist.
        let mut file = OpenOptions::new()
            .append(true)
            .create(true)
            .open("ferris.txt")
            .expect("Failed to open ferris.txt");

        // Print "Corro" 5 times.
        for _ in 0..5 {
            file.write_all("Corro\n".as_bytes())
                .expect("Could not write to ferris.txt");
        }
    }
}

    با اینکه هدف رسیدن به خروجی زیر است:

    $ cat ferris.txt

Corro
Corro

Corro

    $ cargo test test_file && cat ferris.txt
