    جنریک‌ها

    جنریک‌ها موضوع تعمیم نوع‌ها و قابلیت‌ها به حالت‌های گسترده‌تر هستند. این کار از راه‌های گوناگون تکرار کد را کاهش می‌دهد، اما گاهی نگارش نسبتاً پیچیده‌ای می‌طلبد. در کد جنریک باید با دقت مشخص کنیم نوع جنریک برای کدام نوع‌ها معتبر است. ساده‌ترین و رایج‌ترین کاربرد جنریک‌ها، پارامترهای نوع هستند.

    پارامتر نوع با استفاده از علامت‌های زاویه‌دار و نام‌گذاری CamelCase به‌صورت جنریک مشخص می‌شود: <Aaa, Bbb, ...>. پارامتر نوع جنریک معمولاً با <T> نمایش داده می‌شود. در راست، واژهٔ «جنریک» هر چیزی را نیز توصیف می‌کند که یک یا چند پارامتر نوع جنریک <T> بپذیرد. نوعی که به‌عنوان پارامتر نوع جنریک مشخص شده باشد جنریک است و باقی نوع‌ها مشخص یا غیرجنریک هستند.

    برای نمونه، تعریف تابع جنریک foo که آرگومانی از نوع دلخواه T می‌گیرد:

    fn foo<T>(arg: T) { ... }

    چون T با <T> به‌عنوان پارامتر نوع جنریک معرفی شده، هنگام استفاده در (arg: T) جنریک محسوب می‌شود؛ حتی اگر T پیش‌تر به‌عنوان یک struct تعریف شده باشد.

    مثال زیر بخشی از این نگارش را در عمل نشان می‌دهد:

    // A concrete type `A`.
struct A;

// In defining the type `Single`, the first use of `A` is not preceded by `<A>`.
// Therefore, `Single` is a concrete type, and `A` is defined as above.
struct Single(A);
//            ^ Here is `Single`s first use of the type `A`.

// Here, `<T>` precedes the first use of `T`, so `SingleGen` is a generic type.
// Because the type parameter `T` is generic, it could be anything, including
// the concrete type `A` defined at the top.
struct SingleGen<T>(T);

fn main() {
    // `Single` is concrete and explicitly takes `A`.
    let _s = Single(A);

    // Create a variable `_char` of type `SingleGen<char>`
    // and give it the value `SingleGen('a')`.
    // Here, `SingleGen` has a type parameter explicitly specified.
    let _char: SingleGen<char> = SingleGen('a');

    // `SingleGen` can also have a type parameter implicitly specified:
    let _t    = SingleGen(A); // Uses `A` defined at the top.
    let _i32  = SingleGen(6); // Uses `i32`.
    let _char = SingleGen('a'); // Uses `char`.
}
