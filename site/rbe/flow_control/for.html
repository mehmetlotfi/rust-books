    حلقه‌های for

    for و بازه (range)

    ساختار for in برای پیمایش یک Iterator به کار می‌رود. یکی از ساده‌ترین راه‌های ساخت تکرارگر، استفاده از نگارش بازهٔ a..b است. این بازه مقادیر را از a، به‌صورت شامل، تا b، به‌صورت غیرشامل، و با گام‌های یک‌تایی تولید می‌کند.

    بیایید این بار FizzBuzz را به‌جای while با for بنویسیم.

    fn main() {
    // `n` will take the values: 1, 2, ..., 100 in each iteration
    for n in 1..101 {
        if n % 15 == 0 {
            println!("fizzbuzz");
        } else if n % 3 == 0 {
            println!("fizz");
        } else if n % 5 == 0 {
            println!("buzz");
        } else {
            println!("{}", n);
        }
    }
}

    برای ساخت بازه‌ای که هر دو انتهای آن شامل باشند، می‌توان از a..=b استفاده کرد. نمونهٔ بالا را می‌توان چنین نوشت:

    fn main() {
    // `n` will take the values: 1, 2, ..., 100 in each iteration
    for n in 1..=100 {
        if n % 15 == 0 {
            println!("fizzbuzz");
        } else if n % 3 == 0 {
            println!("fizz");
        } else if n % 5 == 0 {
            println!("buzz");
        } else {
            println!("{}", n);
        }
    }
}

    به یاد داشته باشید که اگر a>b باشد، کد کامپایل می‌شود اما بدنهٔ حلقه هرگز اجرا نخواهد شد.

    for i in 10..1 {
    println!("fizzbuzz");
}

    برای شمارش معکوس، باید به‌جای آن از .rev() استفاده کنید

    for i in (1..10).rev() {
    println!("fizzbuzz");
}

    for و تکرارگرها

    ساختار for in به چند روش می‌تواند با یک Iterator کار کند. همان‌طور که در بخش صفت Iterator گفته شد، حلقهٔ for به‌طور پیش‌فرض تابع into_iter را روی مجموعه اعمال می‌کند؛ اما این تنها راه تبدیل مجموعه به تکرارگر نیست.

    توابع into_iter، iter و iter_mut هرکدام با ارائهٔ نمایی متفاوت از داده‌های درون مجموعه، تبدیل مجموعه به تکرارگر را به شیوه‌ای متفاوت انجام می‌دهند.

    • iter — در هر تکرار، هر عنصر مجموعه را قرض می‌گیرد؛ بنابراین مجموعه دست‌نخورده باقی می‌ماند و پس از حلقه نیز قابل استفاده است.
    fn main() {
    let names = vec!["Bob", "Frank", "Ferris"];

    for name in names.iter() {
        match name {
            &"Ferris" => println!("There is a rustacean among us!"),
            // TODO ^ Try deleting the & and matching just "Ferris"
            _ => println!("Hello {}", name),
        }
    }

    println!("names: {:?}", names);
}
    • into_iter — مجموعه را مصرف می‌کند تا در هر تکرار خود داده در اختیار حلقه قرار بگیرد. پس از مصرف مجموعه دیگر نمی‌توان از آن استفاده کرد، زیرا به داخل حلقه «منتقل» شده است.
    fn main() {
    let names = vec!["Bob", "Frank", "Ferris"];

    for name in names.into_iter() {
        match name {
            "Ferris" => println!("There is a rustacean among us!"),
            _ => println!("Hello {}", name),
        }
    }

    // `names` has been 'moved' and can no longer be used.
    // Try uncommenting the line below to see the compiler error:
    // println!("names: {:?}", names);
}
    • iter_mut — هر عنصر مجموعه را به‌صورت تغییرپذیر قرض می‌گیرد و اجازه می‌دهد مجموعه در همان محل تغییر کند.
    fn main() {
    let mut names = vec!["Bob", "Frank", "Ferris"];

    for name in names.iter_mut() {
        *name = match name {
            &mut "Ferris" => "There is a rustacean among us!",
            _ => "Hello",
        }
    }

    println!("names: {:?}", names);
}

    در قطعه‌کدهای بالا به نوع شاخهٔ match توجه کنید؛ تفاوت اصلی میان انواع پیمایش همین‌جاست. تفاوت نوع نیز طبیعتاً عملیات قابل انجام را تغییر می‌دهد.
