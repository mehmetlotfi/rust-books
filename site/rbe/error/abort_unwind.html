    abort و unwind

    بخش قبل سازوکار panic را نشان داد. بر اساس تنظیم panic می‌توان مسیرهای متفاوت کد را به‌صورت شرطی کامپایل کرد. مقادیر فعلی unwind و abort هستند.

    با ادامهٔ مثال لیموناد، راهبرد panic را صریحاً به‌کار می‌بریم تا خطوط متفاوت کد اجرا شوند.

    fn drink(beverage: &str) {
    // You shouldn't drink too much sugary beverages.
    if beverage == "lemonade" {
        if cfg!(panic = "abort") {
            println!("This is not your party. Run!!!!");
        } else {
            println!("Spit it out!!!!");
        }
    } else {
        println!("Some refreshing {} is all I need.", beverage);
    }
}

fn main() {
    drink("water");
    drink("lemonade");
}

    مثال بعد بر بازنویسی drink() و استفادهٔ صریح از کلیدواژهٔ unwind تمرکز دارد.

    #[cfg(panic = "unwind")]
fn ah() {
    println!("Spit it out!!!!");
}

#[cfg(not(panic = "unwind"))]
fn ah() {
    println!("This is not your party. Run!!!!");
}

fn drink(beverage: &str) {
    if beverage == "lemonade" {
        ah();
    } else {
        println!("Some refreshing {} is all I need.", beverage);
    }
}

fn main() {
    drink("water");
    drink("lemonade");
}

    راهبرد panic را می‌توان از خط فرمان روی abort یا unwind تنظیم کرد.

    rustc  lemonade.rs -C panic=abort
