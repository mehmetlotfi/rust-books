    Result

    Result نسخه‌ای غنی‌تر از Option است که به‌جای نبود احتمالی، خطای احتمالی را توصیف می‌کند.

    یعنی Result<T, E> یکی از دو نتیجه را دارد:

    • Ok(T): عنصری از نوع T پیدا شد.
    • Err(E): خطایی با عنصر E رخ داد.

    طبق قرارداد، نتیجهٔ مورد انتظار Ok و نتیجهٔ غیرمنتظره Err است.

    مانند Option، نوع Result نیز متدهای بسیاری دارد. برای مثال unwrap() یا عنصر T را می‌دهد یا panic می‌کند. برای مدیریت حالت‌ها، ترکیب‌گرهای بسیاری میان Result و Option وجود دارد که با هم همپوشانی دارند.

    در کار با Rust احتمالاً با متدهایی مانند parse() روبه‌رو می‌شوید که Result برمی‌گردانند. تبدیل رشته به نوع دیگر همیشه ممکن نیست؛ پس parse() با یک Result احتمال شکست را نشان می‌دهد.

    ببینیم وقتی رشته‌ای را با parse() هم با موفقیت و هم بدون موفقیت تجزیه می‌کنیم چه رخ می‌دهد:

    fn multiply(first_number_str: &str, second_number_str: &str) -> i32 {
    // Let's try using `unwrap()` to get the number out. Will it bite us?
    let first_number = first_number_str.parse::<i32>().unwrap();
    let second_number = second_number_str.parse::<i32>().unwrap();
    first_number * second_number
}

fn main() {
    let twenty = multiply("10", "2");
    println!("double is {}", twenty);

    let tt = multiply("t", "2");
    println!("double is {}", tt);
}

    در حالت ناموفق، parse() خطایی برای ما باقی می‌گذارد تا unwrap() روی آن panic کند. افزون بر این، panic برنامهٔ ما را خاتمه می‌دهد و پیام خطای ناخوشایندی نشان می‌دهد.

    برای بهترشدن پیام خطا باید نوع بازگشتی را دقیق‌تر مشخص و خطا را صریحاً مدیریت کنیم.

    استفاده از Result در main

    اگر صریحاً مشخص شود، Result می‌تواند نوع بازگشتی تابع main نیز باشد. معمولاً main چنین شکلی دارد:

    fn main() {
    println!("Hello World!");
}

    بااین‌حال main نیز می‌تواند نوع بازگشتی Result داشته باشد. اگر درون تابع main خطایی رخ دهد، یک کد خطا برمی‌گرداند و نمایش اشکال‌زدایی (debug) خطا را (با استفاده از صفت Debug) چاپ می‌کند. مثال زیر چنین سناریویی را نشان می‌دهد و به جنبه‌هایی اشاره می‌کند که در بخش بعد آمده است.

    use std::num::ParseIntError;

fn main() -> Result<(), ParseIntError> {
    let number_str = "10";
    let number = match number_str.parse::<i32>() {
        Ok(number)  => number,
        Err(e) => return Err(e),
    };
    println!("{}", number);
    Ok(())
}
