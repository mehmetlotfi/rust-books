    Arc

    وقتی میان نخ‌ها به مالکیت مشترک نیاز داریم، می‌توان از Arc (شمارش ارجاع اتمی) استفاده کرد. این ساختار با پیاده‌سازی Clone اشاره‌گر ارجاع دیگری به محل مقدار روی هیپ می‌سازد و شمارنده را افزایش می‌دهد. از آنجا که مالکیت بین نخ‌ها مشترک است، با خارج‌شدن آخرین اشاره‌گر از محدوده، مقدار نیز کنار گذاشته می‌شود.

    use std::time::Duration;
use std::sync::Arc;
use std::thread;

fn main() {
    // This variable declaration is where its value is specified.
    let apple = Arc::new("the same apple");

    for _ in 0..10 {
        // Here there is no value specification as it is a pointer to a
        // reference in the memory heap.
        let apple = Arc::clone(&apple);

        thread::spawn(move || {
            // As Arc was used, threads can be spawned using the value allocated
            // in the Arc variable pointer's location.
            println!("{:?}", apple);
        });
    }

    // Make sure all Arc instances are printed from spawned threads.
    thread::sleep(Duration::from_secs(1));
}
