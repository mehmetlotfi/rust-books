    نوع‌های کلید جایگزین و سفارشی

    هر نوعی که صفات Eq و Hash را پیاده‌سازی کند می‌تواند کلید HashMap باشد؛ از جمله:

    • bool (چندان مفید نیست، چون فقط دو کلید ممکن دارد)
    • int، uint و همهٔ گونه‌های آن‌ها
    • String و &str (نکتهٔ حرفه‌ای: می‌توانید یک HashMap با کلید String داشته باشید و .get() را با یک &str فراخوانی کنید)

    توجه کنید که f32 و f64 صفت Hash را پیاده‌سازی نمی‌کنند؛ احتمالاً چون خطاهای دقت ممیز شناور استفاده از آن‌ها را به‌عنوان کلید بسیار خطاپذیر می‌کند.

    همهٔ کلاس‌های مجموعه (collection)، Eq و Hash را پیاده‌سازی می‌کنند، به شرطی که نوع درون آن‌ها نیز به‌ترتیب Eq و Hash را پیاده‌سازی کند. برای مثال، اگر T صفت Hash را پیاده‌سازی کند، Vec<T> نیز Hash را پیاده‌سازی می‌کند.

    با یک خط می‌توانید Eq و Hash را برای نوع سفارشی پیاده‌سازی کنید: #[derive(PartialEq, Eq, Hash)]

    کامپایلر بقیهٔ کار را انجام می‌دهد. برای کنترل بیشتر می‌توانید Eq و/یا Hash را خودتان پیاده‌سازی کنید. این راهنما وارد جزئیات پیاده‌سازی Hash نمی‌شود.

    برای تجربهٔ استفاده از struct در HashMap، یک سامانهٔ ورود کاربر بسیار ساده می‌سازیم:

    use std::collections::HashMap;

// Eq requires that you derive PartialEq on the type.
#[derive(PartialEq, Eq, Hash)]
struct Account<'a>{
    username: &'a str,
    password: &'a str,
}

struct AccountInfo<'a>{
    name: &'a str,
    email: &'a str,
}

type Accounts<'a> = HashMap<Account<'a>, AccountInfo<'a>>;

fn try_logon<'a>(accounts: &Accounts<'a>,
        username: &'a str, password: &'a str){
    println!("Username: {}", username);
    println!("Password: {}", password);
    println!("Attempting logon...");

    let logon = Account {
        username,
        password,
    };

    match accounts.get(&logon) {
        Some(account_info) => {
            println!("Successful logon!");
            println!("Name: {}", account_info.name);
            println!("Email: {}", account_info.email);
        },
        _ => println!("Login failed!"),
    }
}

fn main(){
    let mut accounts: Accounts = HashMap::new();

    let account = Account {
        username: "j.everyman",
        password: "password123",
    };

    let account_info = AccountInfo {
        name: "John Everyman",
        email: "j.everyman@email.com",
    };

    accounts.insert(account, account_info);

    try_logon(&accounts, "j.everyman", "psasword123");

    try_logon(&accounts, "j.everyman", "password123");
}
