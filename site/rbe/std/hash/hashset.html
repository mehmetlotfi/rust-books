    HashSet

    HashSet را HashMapای در نظر بگیرید که فقط کلیدهایش مهم‌اند (HashSet<T> در واقع پوششی روی HashMap<T, ()> است).

    شاید بپرسید: «فایده‌اش چیست؟ می‌توانم کلیدها را در Vec نگه دارم.»

    ویژگی منحصربه‌فرد HashSet تضمین نبود عناصر تکراری است. هر مجموعه‌ای باید این قرارداد را رعایت کند و HashSet تنها یکی از پیاده‌سازی‌هاست. (BTreeSet را نیز ببینید.)

    اگر مقداری را وارد کنید که از قبل در HashSet وجود دارد (مقدار تازه با قبلی برابر است و هش یکسانی دارند)، مقدار تازه جای قبلی را می‌گیرد.

    این ویژگی وقتی از هر چیز فقط یک نمونه می‌خواهید یا می‌خواهید وجود قبلی چیزی را بدانید، بسیار مفید است.

    اما مجموعه‌ها کارهای بیشتری انجام می‌دهند.

    مجموعه‌ها (sets) چهار عملیات اصلی دارند (همهٔ فراخوانی‌های زیر یک تکرارگر برمی‌گردانند):

    • union: همهٔ عناصر یکتای دو مجموعه.

    • difference: عناصر موجود در مجموعهٔ نخست و ناموجود در دومی.

    • intersection: عناصری که در هر دو مجموعه‌اند.

    • symmetric_difference: عناصری که در یکی از دو مجموعه‌اند، اما در هر دو نیستند.

    همهٔ این عملیات را در مثال زیر امتحان کنید:

    use std::collections::HashSet;

fn main() {
    let mut a: HashSet<i32> = vec![1i32, 2, 3].into_iter().collect();
    let mut b: HashSet<i32> = vec![2i32, 3, 4].into_iter().collect();

    assert!(a.insert(4));
    assert!(a.contains(&4));

    // `HashSet::insert()` returns false if
    // there was a value already present.
    assert!(b.insert(4), "Value 4 is already in set B!");
    // FIXME ^ Comment out this line

    b.insert(5);

    // If a collection's element type implements `Debug`,
    // then the collection implements `Debug`.
    // It usually prints its elements in the format `[elem1, elem2, ...]`
    println!("A: {:?}", a);
    println!("B: {:?}", b);

    // Print [1, 2, 3, 4, 5] in arbitrary order
    println!("Union: {:?}", a.union(&b).collect::<Vec<&i32>>());

    // This should print [1]
    println!("Difference: {:?}", a.difference(&b).collect::<Vec<&i32>>());

    // Print [2, 3, 4] in arbitrary order.
    println!("Intersection: {:?}", a.intersection(&b).collect::<Vec<&i32>>());

    // Print [1, 5]
    println!("Symmetric Difference: {:?}",
             a.symmetric_difference(&b).collect::<Vec<&i32>>());
}

    (مثال‌ها از مستندات اقتباس شده‌اند.)
