Rust با مثالRust By Example

    Rc

    وقتی به مالکیت چندگانه نیاز باشد، می‌توان از Rc (شمارش ارجاع، Reference Counting) استفاده کرد. Rc تعداد ارجاع‌ها را، که برابر با تعداد مالکان مقدار درون Rc است، پیگیری می‌کند.

    شمار ارجاع یک Rc با هر بار کلون‌شدن Rc یک واحد افزایش می‌یابد و هر بار که یکی از Rcهای کلون‌شده از دامنه خارج و drop شود، یک واحد کاهش می‌یابد. وقتی شمار ارجاع یک Rc به صفر برسد (یعنی هیچ مالکی باقی نمانده است)، هم خود Rc و هم مقدار درون آن drop می‌شوند.

    شبیه‌سازی Rc هرگز کپی عمیق انجام نمی‌دهد؛ فقط اشاره‌گر دیگری به مقدار می‌سازد و شمارنده را افزایش می‌دهد.

    use std::rc::Rc;

fn main() {
    let rc_examples = "Rc examples".to_string();
    {
        println!("--- rc_a is created ---");

        let rc_a: Rc<String> = Rc::new(rc_examples);
        println!("Reference Count of rc_a: {}", Rc::strong_count(&rc_a));

        {
            println!("--- rc_a is cloned to rc_b ---");

            let rc_b: Rc<String> = Rc::clone(&rc_a);
            println!("Reference Count of rc_b: {}", Rc::strong_count(&rc_b));
            println!("Reference Count of rc_a: {}", Rc::strong_count(&rc_a));

            // Two `Rc`s are equal if their inner values are equal
            println!("rc_a and rc_b are equal: {}", rc_a.eq(&rc_b));

            // We can use methods of a value directly
            println!("Length of the value inside rc_a: {}", rc_a.len());
            println!("Value of rc_b: {}", rc_b);

            println!("--- rc_b is dropped out of scope ---");
        }

        println!("Reference Count of rc_a: {}", Rc::strong_count(&rc_a));

        println!("--- rc_a is dropped out of scope ---");
    }

    // Error! `rc_examples` already moved into `rc_a`
    // And when `rc_a` is dropped, `rc_examples` is dropped together
    // println!("rc_examples: {}", rc_examples);
    // TODO ^ Try uncommenting this line
}
