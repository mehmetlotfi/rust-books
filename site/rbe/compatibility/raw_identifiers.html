    شناسه‌های خام (Raw identifiers)

    Rust مانند بسیاری از زبان‌های برنامه‌نویسی مفهوم «واژه‌های کلیدی» را دارد. این شناسه‌ها برای زبان معنای ویژه‌ای دارند و نمی‌توانید آن‌ها را به‌عنوان نام متغیر، تابع یا موارد مشابه به‌کار ببرید. شناسه‌های خام اجازه می‌دهند واژه‌های کلیدی را در جاهایی استفاده کنید که معمولاً مجاز نیستند. این ویژگی به‌ویژه هنگامی مفید است که Rust واژهٔ کلیدی تازه‌ای معرفی کند و کتابخانه‌ای نوشته‌شده با ویرایش قدیمی‌تر، متغیر یا تابعی هم‌نام آن داشته باشد.

    برای مثال، crateای به نام foo را در نظر بگیرید که با ویرایش ۲۰۱۵ Rust کامپایل شده و تابعی به نام try صادر می‌کند. این واژه در ویرایش ۲۰۱۸ برای قابلیتی تازه رزرو شده است؛ پس بدون شناسهٔ خام راهی برای نام بردن از تابع نداریم.

    extern crate foo;

fn main() {
    foo::try();
}

    این خطا را دریافت می‌کنید:

    error: expected identifier, found keyword `try`
 --> src/main.rs:4:4
  |
4 | foo::try();
  |      ^^^ expected identifier, found keyword

    با یک شناسهٔ خام می‌توانید آن را چنین بنویسید:

    extern crate foo;

fn main() {
    foo::r#try();
}
