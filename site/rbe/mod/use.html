Rust با مثالRust By Example

    اعلان use

    با اعلان use می‌توان یک مسیر کامل را برای دسترسی آسان‌تر به نامی تازه متصل کرد. معمولاً به این شکل استفاده می‌شود:

    use crate::deeply::nested::{
    my_first_function,
    my_second_function,
    AndATraitType
};

fn main() {
    my_first_function();
}

    با کلیدواژهٔ as می‌توان موارد واردشده را به نامی متفاوت متصل کرد:

    // Bind the `deeply::nested::function` path to `other_function`.
use deeply::nested::function as other_function;

fn function() {
    println!("called `function()`");
}

mod deeply {
    pub mod nested {
        pub fn function() {
            println!("called `deeply::nested::function()`");
        }
    }
}

fn main() {
    // Easier access to `deeply::nested::function`
    other_function();

    println!("Entering block");
    {
        // This is equivalent to `use deeply::nested::function as function`.
        // This `function()` will shadow the outer one.
        use crate::deeply::nested::function;

        // `use` bindings have a local scope. In this case, the
        // shadowing of `function()` is only in this block.
        function();

        println!("Leaving block");
    }

    function();
}

    همچنین می‌توان با pub use یک جزء را از ماژول دوباره صادر کرد تا از طریق رابط عمومی ماژول در دسترس باشد:

    mod deeply {
    pub mod nested {
        pub fn function() {
            println!("called `deeply::nested::function()`");
        }
    }
}

mod cool {
    pub use crate::deeply::nested::function;
}

fn main() {
    cool::function();
}
