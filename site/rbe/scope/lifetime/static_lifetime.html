Rust با مثالRust By Example

    ایستا (Static)

    راست چند نام رزروشده برای طول عمر دارد که یکی از آن‌ها 'static است. ممکن است آن را در دو موقعیت ببینید:

    // A reference with 'static lifetime:
let s: &'static str = "hello world";

// 'static as part of a trait bound:
fn generic<T>(x: T) where T: 'static {}

    این دو کاربرد به هم مرتبط‌اند اما تفاوت ظریفی دارند و هنگام یادگیری راست معمولاً باعث سردرگمی می‌شوند. برای هر موقعیت چند مثال می‌بینیم.

    طول عمر ارجاع

    وقتی 'static طول عمر یک ارجاع باشد، نشان می‌دهد دادهٔ مورد اشاره تا پایان باقی‌ماندهٔ اجرای برنامه زنده است. این طول عمر همچنان می‌تواند به طول عمری کوتاه‌تر تبدیل شود.

    دو راه رایج برای ساخت متغیر با طول عمر 'static وجود دارد که هر دو در حافظهٔ فقط‌خواندنی فایل اجرایی ذخیره می‌شوند:

    • ساخت ثابت با اعلان static؛
    • یک لفظ string با نوع &'static str بسازید.

    برای مشاهدهٔ هر روش، مثال زیر را ببینید:

    // Make a constant with `'static` lifetime.
static NUM: i32 = 18;

// Returns a reference to `NUM` where its `'static`
// lifetime is coerced to that of the input argument.
fn coerce_static<'a>(_: &'a i32) -> &'a i32 {
    &NUM
}

fn main() {
    {
        // Make a `string` literal and print it:
        let static_string = "I'm in read-only memory";
        println!("static_string: {}", static_string);

        // When `static_string` goes out of scope, the reference
        // can no longer be used, but the data remains in the binary.
    }

    {
        // Make an integer to use for `coerce_static`:
        let lifetime_num = 9;

        // Coerce `NUM` to lifetime of `lifetime_num`:
        let coerced_static = coerce_static(&lifetime_num);

        println!("coerced_static: {}", coerced_static);
    }

    println!("NUM: {} stays accessible!", NUM);
}

    چون ارجاع‌های 'static فقط باید برای باقی‌ماندهٔ عمر برنامه معتبر باشند، می‌توان آن‌ها را هنگام اجرای برنامه ساخت. برای نمایش این موضوع، مثال زیر از Box::leak برای ساخت پویای ارجاع‌های 'static استفاده می‌کند. در این حالت ارجاع از آغاز برنامه زنده نبوده و فقط از نقطهٔ نشت به بعد معتبر است.

    extern crate rand;
use rand::Fill;

fn random_vec() -> &'static [u64; 100] {
    let mut rng = rand::rng();
    let mut boxed = Box::new([0; 100]);
    boxed.fill(&mut rng);
    Box::leak(boxed)
}

fn main() {
    let first: &'static [u64; 100] = random_vec();
    let second: &'static [u64; 100] = random_vec();
    assert_ne!(first, second)
}

    قید صفت

    به‌عنوان قید صفت (trait bound)، به این معناست که نوع هیچ ارجاع غیرایستایی (non-static) در خود ندارد. برای مثال، دریافت‌کننده می‌تواند تا هر زمان که بخواهد نوع را نگه دارد و تا وقتی آن را drop نکرده، هرگز نامعتبر نمی‌شود.

    نکتهٔ مهم این است که هر دادهٔ تحت مالکیت همواره قید طول عمر 'static را برآورده می‌کند، اما ارجاع به آن داده معمولاً چنین نیست:

    use std::fmt::Debug;

fn print_it(input: impl Debug + 'static) {
    println!("'static value passed in is: {:?}", input);
}

fn main() {
    // i is owned and contains no references, thus it's 'static:
    let i = 5;
    print_it(i);

    // oops, &i only has the lifetime defined by the scope of
    // main(), so it's not 'static:
    print_it(&i);
}
