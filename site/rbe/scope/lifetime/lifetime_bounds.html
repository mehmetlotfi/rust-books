Rust با مثالRust By Example

    قیدها

    همان‌طور که نوع‌های جنریک می‌توانند مقید شوند، طول عمرها که خود جنریک‌اند نیز از قید استفاده می‌کنند. نویسهٔ : در اینجا معنای کمی متفاوت دارد، اما + همان معنا را حفظ می‌کند. عبارت‌های زیر چنین خوانده می‌شوند:

    1. T: 'a: همهٔ ارجاع‌های موجود در T باید بیشتر از طول عمر 'a زنده بمانند.
    2. T: Trait + 'a: نوع T باید صفت Trait را پیاده‌سازی کند و همهٔ ارجاع‌های درون T باید بیشتر از 'a عمر کنند.

    مثال زیر کاربرد این نگارش را پس از کلیدواژهٔ where نشان می‌دهد:

    use std::fmt::Debug; // Trait to bound with.

#[derive(Debug)]
struct Ref<'a, T: 'a>(&'a T);
// `Ref` contains a reference to a generic type `T` that has
// some lifetime `'a` unknown by `Ref`. `T` is bounded such that any
// *references* in `T` must outlive `'a`. Additionally, the lifetime
// of `Ref` may not exceed `'a`.

// A generic function which prints using the `Debug` trait.
fn print<T>(t: T) where
    T: Debug {
    println!("`print`: t is {:?}", t);
}

// Here a reference to `T` is taken where `T` implements
// `Debug` and all *references* in `T` outlive `'a`. In
// addition, `'a` must outlive the function.
fn print_ref<'a, T>(t: &'a T) where
    T: Debug + 'a {
    println!("`print_ref`: t is {:?}", t);
}

fn main() {
    let x = 7;
    let ref_x = Ref(&x);

    print_ref(&ref_x);
    print(ref_x);
}
