    طول عمرها

    طول عمر سازه‌ای است که کامپایلر، یا دقیق‌تر بگوییم بررسی‌کنندهٔ قرض، برای اطمینان از اعتبار همهٔ قرض‌ها استفاده می‌کند. طول عمر متغیر با ساخته‌شدن آن آغاز و با نابودی‌اش پایان می‌یابد. طول عمر و محدوده اغلب کنار هم مطرح می‌شوند، اما یکسان نیستند.

    برای نمونه حالتی را در نظر بگیرید که متغیری را با & قرض می‌گیریم. طول عمر قرض با محل اعلان آن تعیین می‌شود؛ پس تا زمانی معتبر است که پیش از نابودی قرض‌دهنده پایان یابد. در مقابل، محدودهٔ قرض با محل استفاده از ارجاع تعیین می‌شود.

    در مثال زیر و ادامهٔ این بخش می‌بینیم طول عمرها چه ارتباطی با محدوده‌ها دارند و چه تفاوتی میان آن‌هاست.

    // Lifetimes are annotated below with lines denoting the creation
// and destruction of each variable.
// `i` has the longest lifetime because its scope entirely encloses
// both `borrow1` and `borrow2`. The duration of `borrow1` compared
// to `borrow2` is irrelevant since they are disjoint.
fn main() {
    let i = 3; // Lifetime for `i` starts. ────────────────┐
    //                                                     │
    { //                                                   │
        let borrow1 = &i; // `borrow1` lifetime starts. ──┐│
        //                                                ││
        println!("borrow1: {}", borrow1); //              ││
    } // `borrow1` ends. ─────────────────────────────────┘│
    //                                                     │
    //                                                     │
    { //                                                   │
        let borrow2 = &i; // `borrow2` lifetime starts. ──┐│
        //                                                ││
        println!("borrow2: {}", borrow2); //              ││
    } // `borrow2` ends. ─────────────────────────────────┘│
    //                                                     │
}   // Lifetime ends. ─────────────────────────────────────┘

    توجه کنید هنوز هیچ نام یا نوعی به طول عمرها اختصاص نداده‌ایم. همان‌طور که خواهیم دید، این موضوع کاربرد طول عمرها را محدود می‌کند.
