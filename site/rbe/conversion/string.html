    تبدیل به رشته و برعکس

    تبدیل هر نوعی به String به سادگی پیاده‌سازی صفت ToString برای آن نوع است. بااین‌حال به‌جای انجام مستقیم این کار، بهتر است صفت fmt::Display را پیاده‌سازی کنید؛ این صفت ToString را به‌طور خودکار فراهم می‌کند و همان‌طور که در بخش print! بحث شد، امکان چاپ نوع را نیز می‌دهد.

    use std::fmt;

struct Circle {
    radius: i32
}

impl fmt::Display for Circle {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        write!(f, "Circle of radius {}", self.radius)
    }
}

fn main() {
    let circle = Circle { radius: 6 };
    println!("{}", circle.to_string());
}

    تجزیهٔ یک رشته

    تبدیل رشته‌ها به نوع‌های گوناگون مفید است، اما یکی از رایج‌ترین عملیات روی رشته‌ها تبدیل رشته به عدد است. روش متداول برای این کار استفاده از تابع parse است و اینکه یا کاری کنیم نوع استنباط شود یا نوعی را که باید تجزیه شود با نگارش «turbofish» مشخص کنیم. هر دو روش در مثال زیر نشان داده شده‌اند.

    تا زمانی که صفت FromStr برای نوع موردنظر پیاده‌سازی شده باشد، این روش رشته را به همان نوع تبدیل می‌کند. کتابخانهٔ استاندارد این صفت را برای نوع‌های بسیاری پیاده‌سازی کرده است.

    fn main() {
    let parsed: i32 = "5".parse().unwrap();
    let turbo_parsed = "10".parse::<i32>().unwrap();

    let sum = parsed + turbo_parsed;
    println!("Sum: {:?}", sum);
}

    برای داشتن این قابلیت روی یک نوع تعریف‌شده به‌دست کاربر، کافی است صفت FromStr را برای آن نوع پیاده‌سازی کنید.

    use std::num::ParseIntError;
use std::str::FromStr;

#[derive(Debug)]
struct Circle {
    radius: i32,
}

impl FromStr for Circle {
    type Err = ParseIntError;
    fn from_str(s: &str) -> Result<Self, Self::Err> {
        match s.trim().parse() {
            Ok(num) => Ok(Circle{ radius: num }),
            Err(e) => Err(e),
        }
    }
}

fn main() {
    let radius = "    3 ";
    let circle: Circle = radius.parse().unwrap();
    println!("{:?}", circle);
}
