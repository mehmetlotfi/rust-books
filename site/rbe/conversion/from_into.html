    From و Into

    صفت‌های From و Into ذاتاً به یکدیگر پیوسته‌اند و این در واقع بخشی از پیاده‌سازی آن است. اگر بتوانید نوع A را از نوع B تبدیل کنید، باور اینکه باید بتوانیم نوع B را به نوع A تبدیل کنیم دشوار نیست.

    From

    صفت From به یک نوع اجازه می‌دهد تعریف کند چگونه از نوعی دیگر ساخته شود و در نتیجه سازوکاری بسیار ساده برای تبدیل میان نوع‌های مختلف فراهم می‌آورد. کتابخانهٔ استاندارد پیاده‌سازی‌های فراوانی از این صفت برای تبدیل نوع‌های اولیه و رایج دارد.

    برای نمونه، به‌سادگی می‌توان یک str را به String تبدیل کرد:

    let my_str = "hello";
let my_string = String::from(my_str);

    برای تعریف تبدیل نوع سفارشی خودمان نیز می‌توانیم به همین شکل عمل کنیم.

    use std::convert::From;

#[derive(Debug)]
struct Number {
    value: i32,
}

impl From<i32> for Number {
    fn from(item: i32) -> Self {
        Number { value: item }
    }
}

fn main() {
    let num = Number::from(30);
    println!("My number is {:?}", num);
}

    Into

    صفت Into صرفاً نقطهٔ مقابل صفت From است. این صفت تعریف می‌کند چگونه یک نوع به نوعی دیگر تبدیل شود.

    هنگام فراخوانی into() معمولاً باید نوع نتیجه را مشخص کنیم، زیرا کامپایلر در بیشتر موارد نمی‌تواند آن را تشخیص دهد.

    use std::convert::Into;

#[derive(Debug)]
struct Number {
    value: i32,
}

impl Into<Number> for i32 {
    fn into(self) -> Number {
        Number { value: self }
    }
}

fn main() {
    let int = 5;
    // Try removing the type annotation
    let num: Number = int.into();
    println!("My number is {:?}", num);
}

    From و Into مکمل یکدیگرند

    From و Into به‌گونه‌ای طراحی شده‌اند که مکمل یکدیگر باشند؛ بنابراین لازم نیست هر دو صفت را پیاده‌سازی کنیم. اگر From را برای نوع خود پیاده‌سازی کرده باشید، Into در صورت نیاز همان را فراخوانی می‌کند. توجه کنید که عکس این موضوع درست نیست: پیاده‌سازی Into برای یک نوع، پیاده‌سازی From را به‌طور خودکار در اختیار آن قرار نمی‌دهد.

    use std::convert::From;

#[derive(Debug)]
struct Number {
    value: i32,
}

// Define `From`
impl From<i32> for Number {
    fn from(item: i32) -> Self {
        Number { value: item }
    }
}

fn main() {
    let int = 5;
    // use `Into`
    let num: Number = int.into();
    println!("My number is {:?}", num);
}
