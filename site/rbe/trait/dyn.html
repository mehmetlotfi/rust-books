    بازگرداندن صفت‌ها با dyn

    کامپایلر راست باید بداند نوع بازگشتی هر تابع چه مقدار فضا نیاز دارد؛ بنابراین همهٔ توابع باید نوع مشخصی بازگردانند. برخلاف بعضی زبان‌ها، اگر صفتی مانند Animal داشته باشید نمی‌توانید تابعی بنویسید که خود Animal را بازگرداند، زیرا پیاده‌سازی‌های مختلف آن اندازه‌های متفاوتی در حافظه دارند.

    راه‌حل ساده‌ای وجود دارد. به‌جای بازگرداندن مستقیم شیء صفت، تابع یک Box بازمی‌گرداند که یک Animal را در خود دارد. box ارجاعی به حافظهٔ هیپ است. چون اندازهٔ ارجاع به‌صورت ایستا مشخص است و کامپایلر تضمین می‌کند به Animal موجود در هیپ اشاره دارد، می‌توان صفت را از تابع بازگرداند.

    راست هنگام تخصیص حافظه روی هیپ تا حد ممکن صریح عمل می‌کند. پس اگر تابع به این روش اشاره‌گری به صفت روی هیپ بازگرداند، باید نوع بازگشتی را با کلیدواژهٔ dyn بنویسید؛ مانند Box<dyn Animal>.

    struct Sheep {}
struct Cow {}

trait Animal {
    // Instance method signature
    fn noise(&self) -> &'static str;
}

// Implement the `Animal` trait for `Sheep`.
impl Animal for Sheep {
    fn noise(&self) -> &'static str {
        "baaaaah!"
    }
}

// Implement the `Animal` trait for `Cow`.
impl Animal for Cow {
    fn noise(&self) -> &'static str {
        "moooooo!"
    }
}

// Returns some struct that implements Animal, but we don't know which one at compile time.
fn random_animal(random_number: f64) -> Box<dyn Animal> {
    if random_number < 0.5 {
        Box::new(Sheep {})
    } else {
        Box::new(Cow {})
    }
}

fn main() {
    let random_number = 0.234;
    let animal = random_animal(random_number);
    println!("You've randomly chosen an animal, and it says {}", animal.noise());
}
