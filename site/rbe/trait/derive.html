    اشتقاق

    کامپایلر می‌تواند با ویژگی #[derive] پیاده‌سازی پایهٔ برخی صفت‌ها را فراهم کند. اگر رفتار پیچیده‌تری نیاز باشد، همچنان می‌توان آن‌ها را دستی پیاده‌سازی کرد.

    صفت‌های قابل اشتقاق عبارت‌اند از:

    • traitهای مقایسه: Eq، PartialEq، Ord، PartialOrd.
    • Clone برای ساخت T از &T با کپی؛
    • Copy برای دادن معنای کپی به‌جای انتقال به نوع؛
    • Hash برای محاسبهٔ هش از &T؛
    • Default برای ساخت نمونهٔ خالی یک نوع داده؛
    • Debug برای قالب‌بندی مقدار با {:?}.
    // `Centimeters`, a tuple struct that can be compared
#[derive(PartialEq, PartialOrd)]
struct Centimeters(f64);

// `Inches`, a tuple struct that can be printed
#[derive(Debug)]
struct Inches(i32);

impl Inches {
    fn to_centimeters(&self) -> Centimeters {
        let &Inches(inches) = self;

        Centimeters(inches as f64 * 2.54)
    }
}

// `Seconds`, a tuple struct with no additional attributes
struct Seconds(i32);

fn main() {
    let _one_second = Seconds(1);

    println!("One foot equals {:?}", foot);

        if foot.to_centimeters() < meter {
            "smaller"
        } else {
            "bigger"
        };

    println!("One foot is {} than one meter.", cmp);
}
