Rust با مثالRust By Example

    impl Trait

    از impl Trait می‌توان در دو جایگاه استفاده کرد:

    1. به‌عنوان نوع آرگومان
    2. به‌عنوان نوع بازگشتی

    به‌عنوان نوع آرگومان

    اگر تابع شما نسبت به یک صفت عمومی است، اما نوع دقیق برایتان اهمیتی ندارد، می‌توانید با به‌کار بردن impl Trait به‌عنوان نوع آرگومان، اعلان تابع را ساده‌تر کنید.

    برای نمونه، کد زیر را در نظر بگیرید:

    fn parse_csv_document<R: std::io::BufRead>(src: R) -> std::io::Result<Vec<Vec<String>>> {
    src.lines()
        .map(|line| {
            // For each line in the source
            line.map(|line| {
                // If the line was read successfully, process it, if not, return the error
                line.split(',') // Split the line separated by commas
                    .map(|entry| String::from(entry.trim())) // Remove leading and trailing whitespace
                    .collect() // Collect all strings in a row into a Vec<String>
            })
        })
        .collect() // Collect all lines into a Vec<Vec<String>>
}

    تابع parse_csv_document عمومی است و می‌تواند هر نوعی را که BufRead را پیاده‌سازی کرده، مانند BufReader<File> یا [u8]، دریافت کند. اما نوع دقیق R اهمیتی ندارد و R فقط برای اعلان نوع src استفاده شده است؛ بنابراین تابع را می‌توان به شکل زیر نیز نوشت:

    fn parse_csv_document(src: impl std::io::BufRead) -> std::io::Result<Vec<Vec<String>>> {
    src.lines()
        .map(|line| {
            // For each line in the source
            line.map(|line| {
                // If the line was read successfully, process it, if not, return the error
                line.split(',') // Split the line separated by commas
                    .map(|entry| String::from(entry.trim())) // Remove leading and trailing whitespace
                    .collect() // Collect all strings in a row into a Vec<String>
            })
        })
        .collect() // Collect all lines into a Vec<Vec<String>>
}

    توجه کنید که استفاده از impl Trait به‌عنوان نوع آرگومان یعنی دیگر نمی‌توانید گونهٔ تابع مورد استفاده را صریحاً مشخص کنید؛ برای مثال، parse_csv_document::<std::io::Empty>(std::io::empty()) در نمونهٔ دوم کار نمی‌کند.

    به‌عنوان نوع بازگشتی

    اگر تابع شما نوعی را برمی‌گرداند که MyTrait را پیاده‌سازی می‌کند، می‌توانید نوع بازگشتی آن را به‌صورت -> impl MyTrait بنویسید. این کار می‌تواند امضای نوع‌ها را بسیار ساده‌تر کند!

    use std::iter;
use std::vec::IntoIter;

// This function combines two `Vec<i32>` and returns an iterator over it.
// Look how complicated its return type is!
fn combine_vecs_explicit_return_type(
    v: Vec<i32>,
    u: Vec<i32>,
) -> iter::Cycle<iter::Chain<IntoIter<i32>, IntoIter<i32>>> {
    v.into_iter().chain(u.into_iter()).cycle()
}

// This is the exact same function, but its return type uses `impl Trait`.
// Look how much simpler it is!
fn combine_vecs(
    v: Vec<i32>,
    u: Vec<i32>,
) -> impl Iterator<Item=i32> {
    v.into_iter().chain(u.into_iter()).cycle()
}

fn main() {
    let v1 = vec![1, 2, 3];
    let v2 = vec![4, 5];
    let mut v3 = combine_vecs(v1, v2);
    assert_eq!(Some(1), v3.next());
    assert_eq!(Some(2), v3.next());
    assert_eq!(Some(3), v3.next());
    assert_eq!(Some(4), v3.next());
    assert_eq!(Some(5), v3.next());
    println!("all done");
}

    مهم‌تر از آن، بعضی نوع‌های Rust را اصلاً نمی‌توان به‌طور صریح نوشت. برای مثال، هر بستار نوع عینی و بی‌نام خودش را دارد. پیش از نحو impl Trait، برای برگرداندن یک بستار ناچار بودید روی هیپ حافظه تخصیص دهید؛ اما اکنون می‌توانید همه‌چیز را به‌صورت ایستا انجام دهید:

    // Returns a function that adds `y` to its input
fn make_adder_function(y: i32) -> impl Fn(i32) -> i32 {
    let closure = move |x: i32| { x + y };
    closure
}

fn main() {
    let plus_one = make_adder_function(1);
    assert_eq!(plus_one(2), 3);
}

    همچنین می‌توانید با impl Trait تکرارگری را برگردانید که از بستارهای map یا filter استفاده می‌کند. این ویژگی کار با map و filter را آسان‌تر می‌کند. چون نوع بستارها نام ندارند، وقتی تابع تکرارگری شامل بستارها را برمی‌گرداند نمی‌توانید نوع بازگشتی صریحی برای آن بنویسید؛ اما با impl Trait این کار به‌آسانی ممکن است:

    fn double_positives<'a>(numbers: &'a Vec<i32>) -> impl Iterator<Item = i32> + 'a {
    numbers
        .iter()
        .filter(|x| x > &&0)
        .map(|x| x * 2)
}

fn main() {
    let singles = vec![-3, -2, 2, 3];
    let doubles = double_positives(&singles);
    assert_eq!(doubles.collect::<Vec<i32>>(), vec![4, 6]);
}
