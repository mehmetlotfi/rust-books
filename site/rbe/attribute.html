    ویژگی‌ها

    ویژگی نوعی فراداده است که به ماژول، کریت یا یک جزء اعمال می‌شود. از این فراداده می‌توان برای موارد زیر استفاده کرد:

    • کامپایل شرطی کد؛
    • تنظیم نام، نسخه و نوع کریت، اعم از اجرایی یا کتابخانه؛
    • غیرفعال‌کردن lintها (هشدارها)
    • فعال‌کردن قابلیت‌های کامپایلر مانند ماکروها و واردکردن سراسری؛
    • پیوند با یک کتابخانهٔ خارجی؛
    • علامت‌گذاری توابع به‌عنوان آزمون واحد؛
    • علامت‌گذاری توابعی که بخشی از سنجش کارایی هستند؛
    • ماکروهای شبیه ویژگی

    ویژگی‌ها به شکل #[outer_attribute] یا #![inner_attribute] نوشته می‌شوند و تفاوتشان در محدوده‌ای است که بر آن اثر می‌گذارند.

    • #[outer_attribute] روی جزء بلافاصله پس از خود اعمال می‌شود. تابع، اعلان ماژول، ثابت، ساختار و شمارش نمونه‌هایی از اجزا هستند. در مثال زیر ویژگی #[derive(Debug)] روی ساختار Rectangle اعمال شده است:

      #[derive(Debug)]
struct Rectangle {
    width: u32,
    height: u32,
}

    • #![inner_attribute] روی جزء دربرگیرنده، که معمولاً ماژول یا کریت است، اعمال می‌شود. به بیان دیگر، این ویژگی کل محدوده‌ای را که در آن قرار گرفته پوشش می‌دهد. در مثال زیر، اگر #![allow(unused_variables)] در main.rs باشد، روی کل کریت اعمال می‌شود:

      #![allow(unused_variables)]

fn main() {
    let x = 3; // This would normally warn about an unused variable.
}

    ویژگی‌ها می‌توانند آرگومان‌هایی با نگارش‌های گوناگون بگیرند:

    • #[attribute = "value"]
    • #[attribute(key = "value")]
    • #[attribute(value)]

    ویژگی‌ها می‌توانند چند مقدار داشته باشند و در چند خط نوشته شوند:

    #[attribute(value, value2)]


#[attribute(value, value2, value3,
            value4, value5)]
