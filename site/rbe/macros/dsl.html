Rust با مثالRust By Example

    زبان‌های دامنه‌محور (DSL)

    DSL یک «زبان» کوچک است که درون ماکروی Rust جای می‌گیرد. چون سامانهٔ ماکرو آن را به ساختارهای معمول Rust گسترش می‌دهد، کاملاً کد معتبر Rust است، اما ظاهر یک زبان کوچک را دارد. به این ترتیب می‌توانید برای کارکردی ویژه، نحوی فشرده یا شهودی تعریف کنید (البته در محدوده‌ای مشخص).

    فرض کنید می‌خواهیم API کوچکی برای ماشین‌حساب بسازیم؛ عبارتی به آن می‌دهیم و نتیجه در کنسول چاپ می‌شود.

    macro_rules! calculate {
    (eval $e:expr) => {
        {
            let val: usize = $e; // Force types to be unsigned integers
            println!("{} = {}", stringify!{$e}, val);
        }
    };
}

fn main() {
    calculate! {
        eval 1 + 2 // hehehe `eval` is _not_ a Rust keyword!
    }

    calculate! {
        eval (1 + 2) * (3 / 4)
    }
}

    خروجی:

    1 + 2 = 3
(1 + 2) * (3 / 4) = 0

    این نمونه بسیار ساده بود، اما رابط‌های بسیار پیچیده‌تری مانند lazy_static یا clap نیز ساخته شده‌اند.

    همچنین به دو جفت آکولاد در ماکرو توجه کنید. جفت بیرونی، در کنار () یا []، بخشی از نحو macro_rules! است.
