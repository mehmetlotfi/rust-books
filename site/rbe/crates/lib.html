Rust با مثالRust By Example

    ساخت کتابخانه

    بیایید کتابخانه‌ای بسازیم و سپس ببینیم چگونه می‌توان آن را به کریتی دیگر پیوند داد.

    در فایل rary.rs:

    pub fn public_function() {
    println!("called rary's `public_function()`");
}

fn private_function() {
    println!("called rary's `private_function()`");
}

pub fn indirect_access() {
    print!("called rary's `indirect_access()`, that\n> ");

    private_function();
}
    $ rustc --crate-type=lib rary.rs
$ ls lib*
library.rlib

    نام کتابخانه‌ها با پیشوند lib آغاز می‌شود و به‌طور پیش‌فرض از نام فایل کریت گرفته می‌شود. می‌توان این نام را با گزینهٔ --crate-name در rustc یا با ویژگی crate_name تغییر داد.
