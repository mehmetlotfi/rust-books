Rust با مثالRust By Example

    macro_rules!

    Rust سامانهٔ ماکروی قدرتمندی برای فرابرنامه‌نویسی فراهم می‌کند. همان‌طور که در فصل‌های پیش دیدید، ماکروها شبیه تابع‌اند، با این تفاوت که نامشان به علامت ! ختم می‌شود. ماکرو به‌جای ایجاد یک فراخوانی تابع، به کد منبعی گسترش می‌یابد که همراه با بقیهٔ برنامه کامپایل می‌شود. برخلاف ماکروهای C و بعضی زبان‌های دیگر، ماکروهای Rust به درخت نحو انتزاعی گسترش می‌یابند، نه اینکه صرفاً رشته‌ها را پیش‌پردازش کنند؛ در نتیجه با خطاهای غیرمنتظرهٔ تقدم عملگرها روبه‌رو نمی‌شوید.

    ماکروها را می‌توان با ماکروی macro_rules! ساخت.

    // This is a simple macro named `say_hello`.
macro_rules! say_hello {
    // `()` indicates that the macro takes no argument.
    () => {
        // The macro will expand into the contents of this block.
        println!("Hello!")
    };
}

fn main() {
    // This call will expand into `println!("Hello!")`
    say_hello!()
}

    پس ماکروها چه فایده‌ای دارند؟

    1. خودتان را تکرار نکنید. در بسیاری از موارد به کارکردی مشابه در چند جای مختلف، اما برای نوع‌های متفاوت نیاز دارید. نوشتن ماکرو اغلب راه خوبی برای جلوگیری از تکرار کد است. (بعداً بیشتر می‌خوانیم.)

    2. زبان‌های دامنه‌محور. ماکروها اجازه می‌دهند برای هدفی مشخص، نحو ویژه‌ای تعریف کنید. (بعداً بیشتر می‌خوانیم.)

    3. رابط‌های با تعداد آرگومان متغیر. گاهی می‌خواهید رابطی تعریف کنید که شمار متغیری آرگومان بگیرد. نمونهٔ آن println! است که بسته به رشتهٔ قالب، هر تعداد آرگومان می‌پذیرد. (بعداً بیشتر می‌خوانیم.)
