    بندهای where

    می‌توان قید را به‌جای نخستین اشاره به نوع، با یک بند where درست پیش از آکولاد باز { بیان کرد. افزون بر این، بندهای where می‌توانند قید را روی هر نوعی اعمال کنند، نه فقط پارامترهای نوع.

    چند مورد کاربردی برای بند where:

    • وقتی جداکردن نوع‌های جنریک و قیدها خواناتر است:
    impl <A: TraitB + TraitC, D: TraitE + TraitF> MyTrait<A, D> for YourType {}

// Expressing bounds with a `where` clause
impl <A, D> MyTrait<A, D> for YourType where
    A: TraitB + TraitC,
    D: TraitE + TraitF {}
    • وقتی بند where از نگارش معمولی گویاتر است. impl در مثال زیر بدون بند where مستقیماً قابل بیان نیست:
    use std::fmt::Debug;

trait PrintInOption {
    fn print_in_option(self);
}

// Because we would otherwise have to express this as `T: Debug` or
// use another method of indirect approach, this requires a `where` clause:
impl<T> PrintInOption for T where
    Option<T>: Debug {
    // We want `Option<T>: Debug` as our bound because that is what's
    // being printed. Doing otherwise would be using the wrong bound.
    fn print_in_option(self) {
        println!("{:?}", Some(self));
    }
}

fn main() {
    let vec = vec![1, 2, 3];

    vec.print_in_option();
}
