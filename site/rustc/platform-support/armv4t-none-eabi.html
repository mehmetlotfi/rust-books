    armv4t-none-eabi / thumbv4t-none-eabi

    • Tier: 3
    • پشتیبانی از کتابخانه: core و alloc (bare-metal، #![no_std])

    این دو هدف بخشی از گروه هدف arm-none-eabi هستند و همهٔ اطلاعات آنجا دربارهٔ آن‌ها نیز صدق می‌کند.

    هر دوی این اهداف را از جمله روی Game Boy Advance (GBA) می‌توان به کار برد. روی GBA معمولاً باید برای بهترین کارایی کلی از هدف thumb استفاده کرد. توجه کنید که این معماری فقط از مجموعه دستورالعمل قدیمی Thumb-1 پشتیبانی می‌کند و از مجموعه دستورالعمل بعدی Thumb-2 پشتیبانی نمی‌کند.

    نگهدارندگان هدف

    @Lokathor @corwinkuiper

    آزمون

    این یک هدف cross-compile است که برای آزمون باید آن را شبیه‌سازی (emulate) کنید.

    این هدف مستقل از دستگاه است و شبیه‌ساز دقیقی که لازم دارید به دستگاه مشخصی که می‌خواهید کدتان روی آن اجرا شود بستگی دارد.

    • هنگام ساخت برای GBA می‌توان از mgba-test-runner استفاده کرد تا مجموعهٔ عادی آزمون‌های Rust درون شبیه‌ساز mgba اجرا شود.
