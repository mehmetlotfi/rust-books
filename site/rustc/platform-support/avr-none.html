    avr-none

    مجموعه‌ای از ریزکنترلرهای Atmel: ATmega8، ATmega328p و غیره.

    سطح: 3

    نگهدارندگان هدف

    @Patryk27

    الزامات

    این هدف فقط به‌صورت متقاطع کامپایل می‌شود؛ میزبان‌های x86-64 Linux، x86-64 macOS و aarch64 macOS تأیید شده‌اند که کار می‌کنند، اما در اصل هر ماشینی که بتواند rustc و avr-gcc را اجرا کند باید مناسب باشد.

    کامپایل برای این هدف مستلزم نصب بودن avr-gcc است، زیرا چند intrinsic (مانند ضرب ۳۲ بیتی) به libgcc وابسته‌اند و هنوز نمی‌توان آن‌ها را از طریق compiler-builtins فراهم کرد. این محدودیتی است که امیدواریم در آینده برطرف کنیم.

    همچنین باید فایل .cargo/config را تنظیم کنید - برای جزئیات پایین‌تر را ببینید.

    ساخت هدف

    Rust با پشتیبانی فعال‌شده از AVR ارائه می‌شود؛ لازم نیست کامپایلر را دوباره بسازید.

    ساخت برنامه‌های Rust

    avr-gcc را نصب کنید:

    # Ubuntu:
$ sudo apt-get install gcc-avr

# Mac:
$ brew tap osx-cross/avr && brew install avr-gcc

# NixOS (takes a couple of minutes, since it's not provided through Hydra):
$ nix shell nixpkgs#pkgsCross.avr.buildPackages.gcc11

    … فایل .cargo/config را برای پروژهٔ خود تنظیم کنید:

    [build]
target = "avr-none"
rustflags = ["-C", "target-cpu=atmega328p"]

[unstable]
build-std = ["core"]

    … و سپس به‌سادگی اجرا کنید:

    $ cargo build --release

    فایل دودویی نهایی در ./target/avr-none/release/your-project.elf قرار می‌گیرد.

    توجه کنید که چون AVRها تعداد ثبات، ROM و RAM نسبتاً اندکی دارند، توصیه می‌شود همیشه از --release استفاده کنید تا فضا تمام نشود.

    همچنین توجه کنید که تعیین -C target-cpu1 الزامی است - در اینجا فهرستی از گونه‌های ممکن آمده است:

    https://github.com/llvm/llvm-project/blob/d5a6124259b55789bc49489632efa7c168a4f6cb/clang/lib/Basic/Targets/AVR.cpp#L48

    توجه کنید که دستگاه‌های بدون SRAM پشتیبانی نمی‌شوند، درست مانند کامپایل برنامه‌های C/C++ با avr-gcc یا Clang.

    آزمون

    می‌توانید از simavr برای شبیه‌سازی firmware حاصل روی ماشین خود استفاده کنید:

    $ simavr -m atmega328p ./target/avr-none/release/your-project.elf

    از طرف دیگر، اگر می‌خواهید چند #[test] واقعی بنویسید، می‌توانید از avr-tester استفاده کنید.

    1. برای این هدف، crateهایی که مقدار -C target-cpu متفاوتی دارند با یکدیگر سازگار برای پیوند نیستند. به همین دلیل، کامپایلر اطمینان می‌دهد که همهٔ crateهایی که با هم پیوند می‌شوند با target-cpu یکسانی کامپایل شده باشند. هنگام استفاده از دستورهای rustc برای ساخت باید این موضوع را در نظر گرفت. این موضوع برای Cargo اهمیت کمتری دارد، زیرا Cargo معمولاً برای همهٔ crateهای یک ساخت از target-cpu یکسانی استفاده می‌کند. ↩
