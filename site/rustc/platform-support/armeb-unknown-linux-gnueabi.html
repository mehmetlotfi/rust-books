    armeb-unknown-linux-gnueabi

    Tier: 3

    هدفی برای cross-compile کردن برنامه‌های Linux در حالت کاربر (user-mode) که معماری Arm BE8 را هدف می‌گیرند.

    برای اطلاعاتی که برای همهٔ اهداف Arm Linux صدق می‌کند، arm-linux را ببینید.

    نمای کلی

    معماری BE8 همان جریان کد با ترتیب little-endian را که سیستم‌های Arm مرسوم little-endian به کار می‌برند حفظ می‌کند، اما دسترسی‌های داده به‌صورت big-endian هستند. BE8 عمدتاً در برنامه‌های شبکه‌ای با کارایی بالا به کار می‌رود، جایی که توانایی خواندن بسته‌ها (packet) در «ترتیب بایت شبکه» (Network Byte Order) بومی آن‌ها مهم است (بسیاری از پروتکل‌های شبکه داده‌ها را در قالب سیمی خود با ترتیب بایت big-endian منتقل می‌کنند).

    تاریخچه

    معماری BE8 از Armv6 به بعد معماری big-endian پیش‌فرض Arm است. پیشینِ آن که برای دستگاه‌های Armv4 و Armv5 به کار می‌رفت BE32 بود. در معماری Armv6، ترتیب بایت (endianness) را می‌توان از طریق ثبات‌های سیستمی پیکربندی کرد. با این حال، BE32 از Armv7 به بعد کنار گذاشته شد.

    نگهدارندگان هدف

    @WorksButNotTested

    الزامات

    این هدف cross-compile می‌شود. این هدف به روال عادی از std پشتیبانی می‌کند (در واقع فقط تغییرات اندکی نسبت به پیکربندی استاندارد Arm لازم است).

    تعریف هدف

    تعریف هدف را می‌توانید اینجا ببینید. به‌ویژه باید توجه داشت که features مشخص می‌کند این هدف برای هستهٔ Armv8 ساخته شده است، هرچند احتمالاً می‌توان آن را در صورت نیاز تغییر داد.

    ساخت هدف

    چون این هدف Tier 3 است، Rust هنوز مصنوعات (artifact) از پیش کامپایل‌شده‌ای برای آن ارائه نمی‌کند.

    بنابراین می‌توانید با افزودن این هدف به فهرست target در bootstrap.toml، Rust را با پشتیبانی از آن بسازید؛ نمونه‌ای از پیکربندی در ادامه آمده است. انتظار می‌رود کاربر از قبل یک زنجیرابزار کامپایلر GNU کارا داشته باشد و مسیرها را متناسب با آن به‌روز کند.

    [llvm]
download-ci-llvm = false
optimize = true
ninja = true
targets = "ARM;X86"
clang = false

[build]
target = ["x86_64-unknown-linux-gnu", "armeb-unknown-linux-gnueabi"]
docs = false
docs-minification = false
compiler-docs = false
[install]
prefix = "/home/user/x-tools/rust/"

[rust]
debug-logging=true
backtrace = true
incremental = true

[target.x86_64-unknown-linux-gnu]

[dist]

[target.armeb-unknown-linux-gnueabi]
cc = "/home/user/x-tools/armeb-unknown-linux-gnueabi/bin/armeb-unknown-linux-gnueabi-gcc"
cxx = "/home/user/x-tools/armeb-unknown-linux-gnueabi/bin/armeb-unknown-linux-gnueabi-g++"
ar = "/home/user/x-tools/armeb-unknown-linux-gnueabi/bin/armeb-unknown-linux-gnueabi-ar"
ranlib = "/home/user/x-tools/armeb-unknown-linux-gnueabi/bin/armeb-unknown-linux-gnueabi-ranlib"
linker = "/home/user/x-tools/armeb-unknown-linux-gnueabi/bin/armeb-unknown-linux-gnueabi-gcc"
llvm-config = "/home/user/x-tools/clang/bin/llvm-config"
llvm-filecheck = "/home/user/x-tools/clang/bin/FileCheck"

    ساخت برنامه‌های Rust

    برای ساخت برای هدف BE8، فایل .cargo/config زیر درون هر دایرکتوری پروژه لازم است:

    [build]
target = "armeb-unknown-linux-gnueabi"

[target.armeb-unknown-linux-gnueabi]
linker = "armeb-unknown-linux-gnueabi-gcc"

    توجه کنید که انتظار می‌رود کاربر یک لینکر مناسب از زنجیرابزار GNU داشته باشد.

    → arm*-unknown-linux-*armv5te-unknown-linux-gnueabi ←
