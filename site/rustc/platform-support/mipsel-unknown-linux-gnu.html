    mipsel-unknown-linux-gnu

    سطح (Tier): ۳

    MIPS ۳۲ بیتی little-endian برای لینوکس با `glibc.

    نگهدارندگان هدف

    @LukasWoodtli

    الزامات

    این هدف روی لینوکس از std پشتیبانی می‌کند. ابزارهای میزبان پشتیبانی می‌شوند اما آزمایش نشده‌اند.

    ساخت هدف

    برای cross compilation باید کامپایلر C از GNU برای معماری mipsel نصب شده باشد. روی Ubuntu بسته‌های gcc-mipsel-linux-gnu و g++-mipsel-linux-gnu را نصب کنید.

    mipsel-unknown-linux-gnu را به فهرست target در config.toml اضافه کنید.

    ساخت برنامه‌های Rust

    Rust مصنوعات (artifact) از پیش کامپایل‌شده‌ای برای این هدف ارائه نمی‌کند. برای کامپایل برای این هدف، باید Rust را با فعال بودن این هدف بسازید (به «ساخت هدف» در بالا مراجعه کنید).
