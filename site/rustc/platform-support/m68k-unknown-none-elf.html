    m68k-unknown-none-elf

    سطح (Tier): ۳

    Motorola 680x0 به‌صورت bare metal

    نگهدارندگان هدف

    @knickish

    الزامات

    این هدف برای cross-compilation به یک محیط ساخت m68k نیاز دارد که روی Debian، سیستم‌های مبتنی بر Debian، openSUSE و توزیع‌های دیگر در دسترس است. در حال حاضر به لینکر gnu نیاز است، چون lld از معماری m68k پشتیبانی نمی‌کند.

    روی سیستم‌های مبتنی بر Debian نصب یک cross-compiler از نوع g++ برای معماری m68k کافی است؛ این کار وابستگی‌های دیگر، مانند بسته توسعه cross برای glibc، را به‌طور خودکار نصب می‌کند:

    apt install g++-m68k-linux-gnu

    فایل‌های دودویی را می‌توان با شبیه‌سازی QEMU user اجرا کرد. روی سیستم‌های مبتنی بر Debian، نصب بسته qemu-user-static برای اجرای فایل‌های دودویی ایستای ساده کافی است:

    # apt install qemu-user-static

    ساخت

    برای ساخت core و alloc برای این هدف دست‌کم به نسخه 19.1.5 از llvm نیاز است.

    کامپایل متقاطع

    این هدف را می‌توان از یک توزیع استاندارد Debian یا مبتنی بر Debian، openSUSE یا هر توزیع دیگری که یک cross-toolchain پایه برای m68k در اختیار دارد cross-compile کرد.

    آزمون

    در حال حاضر پشتیبانی‌ای برای اجرای مجموعه آزمون‌های rustc روی این هدف وجود ندارد.

    ساخت برنامه‌های Rust

    فایل .cargo/config.toml پیشنهادی:

    [unstable]
build-std = ["panic_abort", "core", "alloc"]

[target.m68k-unknown-none-elf]
# as we're building for ELF, the m68k-linux linker should be adequate
linker = "m68k-linux-gnu-ld"

# the mold linker also supports m68k, remove the above line and uncomment the
# following ones to use that instead
# linker = "clang"
# rustflags = ["-C", "link-arg=-fuse-ld=/path/to/mold/binary"]

    برنامه‌های Rust را می‌توان با دستور زیر برای این هدف ساخت:

    cargo build --target m68k-unknown-none-elf

    برنامه‌های بسیار ساده را می‌توان با برنامه qemu-m68k-static اجرا کرد:

    qemu-m68k-static your-code

    برای برنامه‌های پیچیده‌تر، برای آزمایش به یک سیستم m68k بومی (یا شبیه‌سازی‌شده) نیاز است.

    → m68k-unknown-linux-gnumips64-openwrt-linux-musl ←
