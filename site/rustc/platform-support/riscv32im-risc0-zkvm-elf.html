    riscv32im-risc0-zkvm-elf

    سطح (Tier): ۳

    ماشین مجازی دانش‌صفر (zkVM) شرکت RISC Zero که مجموعه دستورهای RV32IM را پیاده‌سازی می‌کند.

    نگهدارندگان هدف

    @flaub @jbruestle

    پیش‌زمینه

    این هدف یک محیط اجرایی است برای تولید اثبات اجرای یک فایل دودویی ELF از نوع RISC-V و هر خروجی‌ای که توسعه‌دهنده فایل دودویی بخواهد به‌صورت عمومی نمایش دهد. برای این کار، هدف فایل ELF را اجرا می‌کند تا یک رسید (receipt) حاوی خروجی محاسبه به‌همراه یک مهر رمزنگاری‌شده تولید کند. این رسید قابل راستی‌آزمایی است تا از یکپارچگی محاسبه و نتیجه آن اطمینان حاصل شود. این هدف فقط به‌صورت نرم‌افزاری پیاده‌سازی شده است؛ هیچ پیاده‌سازی سخت‌افزاری ندارد.

    ما یک افزونهٔ cargo به نام cargo-risczero داریم که به کاربران اجازه می‌دهد قالب‌های پروژه تولید کنند، ابزارهایی برای تجربهٔ کاربری بهتر نصب کنند، فایل دودویی را با استفاده از یک محیط docker بسازند و برنامه‌ها را آزمون کنند.

    الزامات

    این هدف فقط از cross compilation پشتیبانی می‌کند و ابزار میزبان ندارد. این هدف از alloc با یک allocator پیش‌فرض پشتیبانی می‌کند و پشتیبانی آزمایشی از std دارد. این هدف انتظار دارد فایل‌های دودویی در قالب ELF باشند.

    محیط اجرایی این هدف تک‌نخی و غیرانحصاری (non-preemptive) است و از هیچ دستور ممتازی و همچنین دسترسی‌های ناتراز پشتیبانی نمی‌کند. در زمان نگارش، این ماشین مجازی ۱۹۲ مگابایت حافظه دارد و متن/داده، heap و پشته باید در بازه آدرس 0x400 تا 0x0C000000 قرار بگیرند. خود فایل‌های دودویی هیچ سیستم‌عاملی را انتظار ندارند و می‌توان آن‌ها را به‌صورت اجرا روی bare-metal در نظر گرفت. این هدف از #[target_feature(...)] یا مقدارهای -C target-feature= استفاده نمی‌کند.

    فراخوانی extern "C" روی این هدف از قرارداد فراخوانی C استفاده می‌کند که در مشخصات RISC-V تشریح شده است.

    ساخت برای zkVM

    می‌توان برنامه‌های zkVM را با افزودن این هدف به فهرست target در bootstrap.toml ساخت. با این حال، توصیه می‌کنیم برنامه‌ها را در قالب آغازین تولیدشده توسط ابزار cargo-risczero و crate با نام risc0-build بسازید. این crate هنگام فراخوانی rustc از -C "link-arg=-Ttext= استفاده می‌کند تا متن را در مکان مناسب نگاشت کند و همچنین متغیرهایی تولید کند که فایل ELF و یک شناسه یکتای وابسته به آن را نمایش می‌دهند. قالب آغازین به توسعه‌دهندگان فراخوانی‌های سیستمی‌ای ارائه می‌دهد که برای محاسبات دانش‌صفر مفیدند، مانند نوشتن در خروجی عمومی، هش‌کردن با sha256 و ضرب اعداد صحیح بزرگ.

    ساخت برنامه‌های Rust

    Rust هنوز artifactهای از پیش کامپایل‌شده برای این هدف ارائه نمی‌دهد. برای کامپایل برای این هدف، باید Rust را با فعال‌بودن این هدف بسازید (بخش «ساخت هدف» را در بالا ببینید). استفاده از build-std را توصیه نمی‌کنیم، چون در گذشته هنگام ساخت core روی قالب آغازین خود با مشکل مواجه شده‌ایم. راه‌حل جایگزین دانلود toolchain مربوط به risc0 با اجرای cargo risczero install است.

    آزمون

    نکته: این هدف به‌صورت یک شبیه‌ساز نرم‌افزاری به نام zkVM پیاده‌سازی شده است و هیچ پیاده‌سازی سخت‌افزاری برای آن وجود ندارد.

    عملی‌ترین راه برای آزمون برنامه هدف استفاده از قالب آغازین ماست که با دستور cargo risczero new تولید می‌شود. این قالب یک کد نمونه «host» و «guest» تولید می‌کند. کد guest برای این هدف (که RV32IM است) کامپایل می‌شود، در حالی که کد «host» برای اجرا روی ماشین برنامه‌نویس کامپایل می‌شود که یا توزیعی از Linux دارد یا macOS. برنامه host مسئول اجرای فایل دودویی guest روی zkVM و بازیابی خروجی عمومی آن است.

    این هدف در حال حاضر از اجرای مجموعه آزمون‌های Rust پشتیبانی نمی‌کند.

    toolchainهای cross-compilation و کد C

    کد C سازگار را می‌توان با هر کامپایلری که هدف RV32IM دارد برای این هدف ساخت. روی clang و لینکر ld.lld می‌توان آن را با -march=rv32im و -mabi=ilp32، همراه با پرچم ویژگی‌های llvm یعنی features=+m و هدف llvm یعنی riscv32-unknown-none تولید کرد.
