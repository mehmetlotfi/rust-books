    aarch64-unknown-teeos

    سطح: 3

    هدفی برای سیستم‌عامل TEEOS.

    TEEOS یک سیستم‌عامل کوچک است که در TrustZone برای برنامه‌های مورد اعتماد/امنیتی اجرا می‌شود. هستهٔ TEEOS ریزهستهٔ HongMeng/ChCore است. libc برای TEEOS بخشی از musl است. این سیستم بسیار کوچک است، به‌طوری که برای برنامه‌ها در TEEOS شبکه، stdin و سیستم فایل وجود ندارد.

    برخی اختصارات:

    اختصارعبارت کاملتوضیح
    TEEمحیط اجرای مورداعتماد (Trusted Execution Environment)ARM TrustZone سیستم را به دو دنیا/حالت تقسیم می‌کند – دنیا/حالت امن و دنیا/حالت عادی. TEE در دنیا/حالت امن قرار دارد.
    REEمحیط اجرای غنی (Rich Execution Environment)دنیای عادی. برای مثال، Linux در تلفن‌های Android در سمت REE قرار دارد.
    TAبرنامهٔ مورداعتماد (Trusted Application)برنامه‌ای که روی سیستم سمت TEE اجرا می‌شود.
    CAبرنامهٔ کلاینت (Client Application)فرایندی که روی سیستم سمت REE اجرا می‌شود.

    TEEOS در حال تبدیل‌شدن به متن‌باز است. اطلاعات بیشتر

    راه‌اندازی

    ما از OpenHarmony SDK برای TEEOS استفاده می‌کنیم.

    OpenHarmony SDK در حال حاضر مستقیماً از کامپایل Rust پشتیبانی نمی‌کند، بنابراین مقداری راه‌اندازی لازم است.

    ابتدا باید OpenHarmony SDK را از این صفحه دریافت کنید. نسخهٔ OpenHarmony مورد نظر خود را انتخاب کنید و «Public SDK package for the standard system» را دانلود کنید.

    اسکریپت‌های shell زیر را که Clang موجود در OpenHarmony SDK را wrap می‌کنند ایجاد کنید:

    aarch64-unknown-teeos-clang.sh

    #!/bin/sh
exec /path/to/ohos-sdk/linux/native/llvm/bin/clang \
  -target aarch64-linux-gnu \
  "$@"

    aarch64-unknown-teeos-clang++.sh

    #!/bin/sh
exec /path/to/ohos-sdk/linux/native/llvm/bin/clang++ \
  -target aarch64-linux-gnu \
  "$@"

    ساخت هدف

    برای ساخت یک toolchain مربوط به Rust، یک فایل bootstrap.toml با محتوای زیر ایجاد کنید:

    profile = "compiler"
change-id = 115898

[build]
sanitizers = true
profiler = true
target = ["x86_64-unknown-linux-gnu", "aarch64-unknown-teeos"]
submodules = false
compiler-docs = false
extended = true

[install]
bindir = "bin"
libdir = "lib"

[target.aarch64-unknown-teeos]
cc = "/path/to/scripts/aarch64-unknown-teeos-clang.sh"
cxx = "/path/to/scripts/aarch64-unknown-teeos-clang.sh"
linker = "/path/to/scripts/aarch64-unknown-teeos-clang.sh"
ar = "/path/to/ohos-sdk/linux/native/llvm/bin/llvm-ar"
ranlib = "/path/to/ohos-sdk/linux/native/llvm/bin/llvm-ranlib"
llvm-config = "/path/to/ohos-sdk/linux/native/llvm/bin/llvm-config"

    note: You need to insert "/usr/include/x86_64-linux-gnu/" into environment variable: $C_INCLUDE_PATH
 if some header files like bits/xxx.h not found.
note: You can install gcc-aarch64-linux-gnu,g++-aarch64-linux-gnu if some files like crti.o not found.
note: You may need to install libc6-dev-i386 libc6-dev if "gnu/stubs-32.h" not found.

    ساخت برنامه‌های Rust

    Rust هنوز مصنوعات از پیش کامپایل‌شده‌ای برای این هدف ارائه نمی‌کند. برای کامپایل برای این هدف، یا باید Rust را با فعال‌بودن هدف بسازید (بخش «ساخت هدف» در بالا را ببینید)، یا با استفاده از build-std یا روشی مشابه، نسخهٔ خودتان از core را بسازید.

    باید پیوندگر مورد استفاده را در ~/.cargo/config پیکربندی کنید:

    [target.aarch64-unknown-teeos]
linker = "/path/to/aarch64-unknown-teeos-clang.sh" # or aarch64-linux-gnu-ld
