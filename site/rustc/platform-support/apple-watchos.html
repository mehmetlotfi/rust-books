کتاب rustcThe rustc Book

    *-apple-watchos

    اهداف watchOS اپل.

    سطح: 2 (بدون ابزارهای میزبان)

    • aarch64-apple-watchos: Apple WatchOS روی ARM64.
    • aarch64-apple-watchos-sim: شبیه‌ساز Apple WatchOS روی ARM64.

    سطح: 3

    • x86_64-apple-watchos-sim: شبیه‌ساز Apple WatchOS روی x86 ۶۴ بیتی.
    • arm64_32-apple-watchos: Apple WatchOS روی Arm 64_32.
    • armv7k-apple-watchos: Apple WatchOS روی Armv7k.

    نگهدارندگان هدف

    @deg4uss3r @vladimir-ea @leohowell @madsmtm

    الزامات

    این اهداف به‌صورت متقاطع کامپایل می‌شوند و به watchOS SDK متناظر (WatchOS.sdk یا WatchSimulator.sdk) نیاز دارند که Xcode ارائه می‌کند. برای ساخت اهداف ARM64 به Xcode 12 یا بالاتر نیاز است.

    مسیر SDK را می‌توان با متغیر محیطی رایج SDKROOT به rustc داد، یا هنگام کامپایل روی macOS میزبان تقریباً با همان منطقِ xcrun --sdk watchos --show-sdk-path استنباط می‌شود.

    نسخهٔ سیستم‌عامل

    حداقل نسخهٔ پشتیبانی‌شده watchOS 5.0 است.

    این نسخه را می‌توان برای هر فایل دودویی با تغییر هدف استقرار بالاتر برد. rustc متغیرهای محیطی رایجی را که Xcode برای این کار استفاده می‌کند رعایت می‌کند؛ در این مورد WATCHOS_DEPLOYMENT_TARGET.

    ساخت هدف

    اهداف سطح 2 از طریق rustup توزیع می‌شوند و می‌توان آن‌ها را با یکی از دستورهای زیر نصب کرد:

    $ rustup target add aarch64-apple-watchos
$ rustup target add aarch64-apple-watchos-sim

    برای نحوهٔ ساخت اهداف سطح 3، دستورالعمل‌های iOS را ببینید.
