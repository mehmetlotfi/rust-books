    *-apple-visionos

    اهداف visionOS / xrOS اپل.

    سطح: 2 (بدون ابزارهای میزبان)

    • aarch64-apple-visionos: Apple visionOS روی arm64.
    • aarch64-apple-visionos-sim: شبیه‌ساز Apple visionOS روی arm64.

    نگهدارندگان هدف

    @agg23 @madsmtm

    الزامات

    این اهداف به‌صورت متقاطع کامپایل می‌شوند و به visionOS SDK متناظر (XROS.sdk یا XRSimulator.sdk) نیاز دارند که Xcode 15 یا جدیدتر ارائه می‌کند.

    مسیر SDK را می‌توان با متغیر محیطی رایج SDKROOT به rustc داد، یا هنگام کامپایل روی macOS میزبان تقریباً با همان منطقِ xcrun --sdk xros --show-sdk-path استنباط می‌شود.

    نسخهٔ سیستم‌عامل

    حداقل نسخهٔ پشتیبانی‌شده visionOS 1.0 است.

    این نسخه را می‌توان برای هر فایل دودویی با تغییر هدف استقرار بالاتر برد. rustc متغیرهای محیطی رایجی را که Xcode برای این کار استفاده می‌کند رعایت می‌کند؛ در این مورد XROS_DEPLOYMENT_TARGET.

    ساخت هدف

    این اهداف از طریق rustup توزیع می‌شوند و می‌توان آن‌ها را با یکی از دستورهای زیر نصب کرد:

    $ rustup target add aarch64-apple-visionos
$ rustup target add aarch64-apple-visionos-sim
