    hexagon-unknown-linux-musl

    سطح (Tier): ۳

    هدفی برای cross-compile کردن برنامه‌های حالت کاربر لینوکس که معماری Hexagon DSP را هدف قرار می‌دهند.

    هدفتوضیحات
    hexagon-unknown-linux-muslلینوکس ۳۲ بیتی Hexagon

    نگهدارندگان هدف

    @androm3da @quic-mliebel

    الزامات

    این هدف cross-compile می‌شود. این هدف از std پشتیبانی می‌کند. به‌طور پیش‌فرض، کدی که با این هدف تولید می‌شود باید روی سخت‌افزار Hexagon DSP اجرا شود.

    • -Ctarget-cpu=hexagonv73 پشتیبانی از دستورهای تعریف‌شده تا Hexagon V73 را اضافه می‌کند.

    فایل‌های دودویی را می‌توان با شبیه‌سازی user در QEMU اجرا کرد. در سیستم‌های مبتنی بر Debian، نصب بسته qemu-user-static برای اجرای فایل‌های دودویی ایستای ساده کافی است:

    # apt install qemu-user-static
# qemu-hexagon-static ./hello

    برای ساخت برنامه‌های لینوکس با Rust، به لینکری نیاز دارید که بتواند hexagon را هدف قرار دهد. می‌توانید از clang/lld در toolchain مربوط به hexagon که منحصراً از مخازن متن‌باز عمومی ساخته شده است استفاده کنید.

    کتابخانه C نیز در همان toolchain گنجانده شده است و هنگام ساخت فایل‌های اجرایی لینک‌شده به‌صورت پویا می‌توان از آن استفاده کرد.

    # /opt/clang+llvm-VERSION-cross-hexagon-unknown-linux-musl/x86_64-linux-gnu/bin/qemu-hexagon -L /opt/clang+llvm-VERSION-cross-hexagon-unknown-linux-musl/x86_64-linux-gnu/target/hexagon-unknown-linux-musl/usr/ ./hello

    لینک کردن

    این هدف از hexagon-unknown-linux-musl-clang به‌عنوان لینکر پیش‌فرض استفاده می‌کند. این لینکر از toolchain متن‌باز hexagon در مسیرهایی مانند /opt/clang+llvm-21.1.8-cross-hexagon-unknown-linux-musl/x86_64-linux-gnu/bin/hexagon-unknown-linux-musl-clang در دسترس است.

    لینکرهای جایگزین عبارت‌اند از:

    • eld، که همراه toolchain متن‌باز hexagon و Hexagon SDK ارائه می‌شود
    • با تعیین -C linker=rust-lld می‌توان از rust-lld استفاده کرد

    ساخت هدف

    چون این هدف در Tier 3 است، Rust هنوز artifactهای از پیش کامپایل‌شده برای این هدف ارائه نمی‌دهد.

    بنابراین می‌توانید Rust را با پشتیبانی از این هدف بسازید؛ برای این کار آن را به فهرست target در bootstrap.toml اضافه کنید. نمونه‌ای از پیکربندی در ادامه آمده است.

    [build]
target = ["hexagon-unknown-linux-musl"]

[target.hexagon-unknown-linux-musl]

cc = "hexagon-unknown-linux-musl-clang"
cxx = "hexagon-unknown-linux-musl-clang++"
linker = "hexagon-unknown-linux-musl-clang"
ar = "hexagon-unknown-linux-musl-ar"
ranlib = "hexagon-unknown-linux-musl-ranlib"
musl-root = "/opt/clang+llvm-VERSION-cross-hexagon-unknown-linux-musl/x86_64-linux-gnu/target/hexagon-unknown-linux-musl/usr"
llvm-libunwind = 'in-tree'
qemu-rootfs = "/opt/clang+llvm-VERSION-cross-hexagon-unknown-linux-musl/x86_64-linux-gnu/target/hexagon-unknown-linux-musl/usr"

    آزمون

    در حال حاضر هیچ پشتیبانی‌ای برای اجرای مجموعه آزمون‌های rustc روی این هدف وجود ندارد.

    ساخت برنامه‌های Rust

    toolchain متن‌باز hexagon را از https://github.com/quic/toolchain_for_hexagon/releases دانلود و نصب کنید.

    برای ساخت برای هدف Hexagon Linux، فایل .cargo/config زیر در هر دایرکتوری پروژه لازم است:

    [build]
target = "hexagon-unknown-linux-musl"

[target.hexagon-unknown-linux-musl]
linker = "hexagon-unknown-linux-musl-clang"
ar = "hexagon-unknown-linux-musl-ar"
runner = "qemu-hexagon -L /opt/clang+llvm-VERSION-cross-hexagon-unknown-linux-musl/x86_64-linux-gnu/target/hexagon-unknown-linux-musl/usr"

    مقدار “runner” را در .cargo/config ویرایش کنید تا به مسیر کتابخانه C مربوط به toolchain شما اشاره کند.

    ...
runner = "qemu-hexagon -L /path/to/my/inst/clang+llvm-VERSION-cross-hexagon-unknown-linux-musl/x86_64-linux-gnu/target/hexagon-unknown-linux-musl/usr"
...

    برنامه Rust خود را با داشتن qemu-hexagon در PATH بسازید و اجرا کنید:

    export PATH=/path/to/my/inst/clang+llvm-VERSION-cross-hexagon-unknown-linux-musl/x86_64-linux-gnu/bin/:$PATH
cargo run -Zbuild-std -Zbuild-std-features=llvm-libunwind
