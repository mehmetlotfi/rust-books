    *-windows-gnullvm

    اهداف ویندوزی مشابه *-windows-gnu اما با استفاده از Universal C Runtime (UCRT) به‌عنوان زمان‌اجرا و ابزارها/کتابخانه‌های مختلف LLVM به‌جای GCC/Binutils.

    سطح: 2 (با ابزارهای میزبان)

    سه‌تایی‌های هدف در دسترس تا اینجا:

    • aarch64-pc-windows-gnullvm
    • x86_64-pc-windows-gnullvm

    سطح: 2 (بدون ابزارهای میزبان)

    سه‌تایی‌های هدف در دسترس تا اینجا:

    • i686-pc-windows-gnullvm

    الزامات

    ساخت این اهداف به یک toolchain زبان C مبتنی بر LLVM نیاز دارد، برای مثال llvm-mingw یا MSYS2 با محیط CLANG*، به‌همراه در دسترس بودن کتابخانهٔ استاتیک libunwind.

    باینری‌های این هدف از نظر الزامات و قابلیت‌ها باید دست‌کم هم‌تراز با *-windows-gnu باشند، به‌جز حالت ضمنی خودبسنده (self-contained) که در بخش زیر توضیح داده شده است.

    این اهداف برای extern "C" از قرارداد فراخوانی ویندوز پیروی می‌کنند.

    مانند هر هدف ویندوزی دیگر، باینری‌های تولیدشده در قالب PE هستند.

    ساخت هدف

    هم ساخت بومی و هم cross-compilation پشتیبانی می‌شوند و مشابه سایر اهداف Rust عمل می‌کنند.

    ساخت برنامه‌های Rust

    Rust برای این اهداف هم std و هم ابزارهای میزبان ارائه می‌کند. این امکان را می‌دهد که از آن‌ها هم به‌عنوان میزبان و هم به‌عنوان هدف استفاده شود.

    وقتی به‌عنوان میزبان استفاده شود و برنامه‌های Rust خالص ساخته شوند، به هیچ toolchain اضافی زبان C نیازی نیست. تنها الزامات، نصب مؤلفهٔ rust-mingw و تنظیم rust-lld به‌عنوان لینکر است. در غیر این صورت باید toolchain زبان C که پیش‌تر ذکر شد را نصب کنید. هنوز در صورت نبود toolchain زبان C بازگشت (fallback) خودکار به rust-lld وجود ندارد، اما ممکن است در آینده افزوده شود.

    آزمون

    باینری‌های تولیدشده روی ویندوز و روی لینوکس با Wine با سخت‌افزار بومی به‌خوبی کار می‌کنند. آزمون AArch64 روی x86_64 مسئله‌ساز است و نیازمند راه‌اندازی یک سیستم کامل AArch64 با QEMU است.

    بیشتر مجموعهٔ آزمون x86_64 با موفقیت اجرا می‌شود، اما چون روی CI اجرا نمی‌شود، انتظار می‌رود در طول زمان شکست‌های مختلفی رخ دهد.

    toolchainهای cross-compilation و کد C

    کد C سازگار را می‌توان با اهداف aarch64-pc-windows-gnu، i686-pc-windows-gnullvm و x86_64-pc-windows-gnu از Clang ساخت، مادامی که از toolchainهای زبان C مبتنی بر LLVM استفاده شود. این‌ها عبارت‌اند از:

    • llvm-mingw
    • MSYS2 با محیط CLANG*
