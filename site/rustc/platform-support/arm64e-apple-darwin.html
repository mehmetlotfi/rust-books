    arm64e-apple-darwin

    Tier: ۳ (همراه با ابزارهای میزبان)

    ARM64e macOS (نسخهٔ 11.0 به بعد، یعنی Big Sur و جدیدتر)

    نگهدارندگان هدف

    @arttet

    الزامات

    هدفی برای macOS روی تراشه‌های Apple سری M نسل‌های اخیر.

    برای الزامات عمومی macOS به مستندات *-apple-darwin مراجعه کنید.

    ساخت هدف

    می‌توانید با افزودن این هدف به فهرست target در bootstrap.toml، Rust را با پشتیبانی از آن بسازید:

    [build]
target = ["arm64e-apple-darwin"]

    ساخت برنامه‌های Rust

    Rust هنوز مصنوعات (artifact) از پیش کامپایل‌شده‌ای برای این هدف ارائه نمی‌کند. برای کامپایل به این هدف، باید Rust را با فعال بودن این هدف بسازید (بخش ساخت هدف را در بالا ببینید).

    آزمون

    این هدف از اجرای فایل‌های باینری روی پلتفرم‌های macOS با معماری arm64e پشتیبانی می‌کند.

    زنجیرابزارهای cross-compilation و کد C

    این هدف‌ها از کد C پشتیبانی می‌کنند. برای ساخت کد C سازگار، باید از XCode با همان کامپایلر و پرچم‌ها استفاده کنید.
