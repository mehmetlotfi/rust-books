کتاب rustcThe rustc Book

    riscv32imac-unknown-xous-elf

    سطح (Tier): ۳

    Xous یک ریزهسته (microkernel) و سیستم‌عاملی پیام‌محور است که دستگاه‌هایی مانند Precursor و Betrusted را به حرکت درمی‌آورد. این سیستم‌عامل به‌طور کامل با Rust نوشته شده است، بنابراین برای کامپایل برنامه‌ها برای Xous به هیچ نرم‌افزار اضافه‌ای نیاز نیست.

    نگهدارندگان هدف

    @xobs

    الزامات

    ساخت خود هدف به یک کامپایلر RISC-V نیاز دارد که cc-rs از آن پشتیبانی کند. برای مثال می‌توانید از toolchain آماده xPack استفاده کنید.

    cross-compile کردن برنامه‌ها به هیچ نرم‌افزار اضافه‌ای فراتر از toolchain نیاز ندارد. نسخه‌های آماده toolchain از Betrusted در دسترس هستند.

    ساخت هدف

    با فعال کردن این هدف در ساخت rustc می‌توان آن را ساخت.

    [build]
target = ["riscv32imac-unknown-xous-elf"]

    مطمئن شوید کامپایلر C شما در $PATH قرار دارد، سپس آن را به bootstrap.toml اضافه کنید:

    [target.riscv32imac-unknown-xous-elf]
cc = "riscv-none-elf-gcc"
ar = "riscv-none-elf-ar"

    ساخت برنامه‌های Rust

    Rust هنوز artifactهای از پیش کامپایل‌شده برای این هدف ارائه نمی‌دهد. برای کامپایل برای این هدف، باید یکی از کارهای زیر را انجام دهید:

    • Rust را با فعال‌بودن این هدف بسازید (بخش «ساخت هدف» را در بالا ببینید)
    • با استفاده از build-std یا روشی مشابه، نسخه خودتان از core را بسازید
    • یک toolchain آماده را از Betrusted دانلود کنید

    کامپایل متقاطع

    این هدف را می‌توان از هر میزبانی cross-compile کرد.
