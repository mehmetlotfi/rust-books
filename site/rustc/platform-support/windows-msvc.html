    *-pc-windows-msvc

    اهداف ویندوزی MSVC.

    سطح 1 با ابزارهای میزبان:

    • aarch64-pc-windows-msvc: ویندوز روی ARM64.
    • x86_64-pc-windows-msvc: ویندوز روی x86 64 بیتی.

    سطح 1 بدون ابزارهای میزبان:

    • i686-pc-windows-msvc: ویندوز روی x86 32 بیتی.

    نگهدارندگان هدف

    الزامات

    نسخهٔ سیستم‌عامل

    برای نصب‌های کلاینت، Windows 10 یا بالاتر لازم است و برای نصب‌های سرور، Windows Server 2016 یا بالاتر.

    ابزارهای میزبان

    حداقل نسخهٔ پشتیبانی‌شدهٔ Visual Studio نسخهٔ 2017 است، اما این پشتیبانی به‌طور فعال در CI آزمون نمی‌شود. به‌شدت توصیه می‌شود از آخرین نسخهٔ VS (در حال حاضر VS 2026) استفاده کنید.

    فقط اهداف 64 بیتی *-pc-windows-msvc از ابزارهای میزبان پشتیبانی می‌کنند.

    جزئیات پلتفرم

    این اهداف کتابخانهٔ استاندارد Rust را به‌طور کامل پیاده‌سازی می‌کنند.

    قرارداد فراخوانی extern "C" با قرارداد فراخوانی پیش‌فرض مایکروسافت برای معماری مورد نظر مطابقت دارد: __cdecl روی i686، x64 روی x86_64 و ARM64 روی aarch64.

    اهداف *-windows-msvc باینری‌های PE/COFF همراه با اطلاعات اشکال‌زدایی CodeView تولید می‌کنند که قالب‌های بومی مورد استفاده در ویندوز هستند.

    ساخت برنامه‌های Rust

    این اهداف از طریق rustup توزیع می‌شوند و می‌توان آن‌ها را با rustup component add [--toolchain {name}] {target} نصب کرد.

    برای مثال، افزودن هدف x86 32 بیتی به toolchain با نام nightly:

    rustup component add --toolchain nightly i686-pc-windows-msvc

    یا افزودن هدف ARM64 به toolchain فعال:

    rustup component add aarch64-pc-windows-msvc

    آزمون

    برای آزمون و اجرای این هدف هیچ الزام ویژه‌ای وجود ندارد.

    toolchainهای cross-compilation و کد C

    cross-compilation معماری‌محور از یک میزبان ویندوزی به پلتفرم ویندوزی متفاوت، به‌صورت بومی توسط toolchain MSVC پشتیبانی می‌شود، مشروط بر این‌که هنگام استفاده از VS Installer مؤلفه‌های مناسب انتخاب شده باشند.

    cross-compilation از یک میزبان غیرویندوزی به یک هدف *-windows-msvc ممکن است شدنی باشد اما پشتیبانی نمی‌شود.
