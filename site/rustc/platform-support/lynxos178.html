    *-lynxos178-*

    سطح (Tier): ۳

    اهدافی برای سیستم‌عامل LynxOS-178.

    LynxOS-178 یک RTOS تجاری است که برای سامانه‌های بی‌درنگ حیاتی از نظر ایمنی طراحی شده است. این سیستم‌عامل توسط Lynx Software Technologies به‌عنوان بخشی از مجموعه محصول MOSA.ic توسعه داده می‌شود.

    سه‌گانه‌های (triple) هدف موجود:

    • x86_64-lynx-lynxos178

    نگهدارندگان هدف

    @rfatykhov-lynx

    الزامات

    برای ساخت برنامه‌های Rust برای LynxOS-178، ابتدا باید LYNX MOSA.ic روی ماشین ساخت نصب شده باشد.

    این هدف فقط از cross-compilation پشتیبانی می‌کند، آن هم از همان میزبان‌هایی که Lynx CDK از آن‌ها پشتیبانی می‌کند.

    در حال حاضر فقط برنامه‌های no_std پشتیبانی می‌شوند. کار برای پشتیبانی از std در حال انجام است.

    ساخت هدف

    می‌توانید Rust را با پشتیبانی از x86_64-lynx-lynxos178 بسازید؛ برای این کار آن را به فهرست target در config.toml اضافه کنید و سپس ./x build --target x86_64-lynx-lynxos178 compiler را اجرا کنید.

    ساخت برنامه‌های Rust

    Rust هنوز artifactهای از پیش کامپایل‌شده برای این هدف ارائه نمی‌دهد. برای کامپایل برای این هدف، باید Rust را با فعال‌بودن این هدف بسازید (بخش «ساخت هدف» را در بالا ببینید).

    پیش از اجرای cargo، باید با اجرای source setup.sh از دایرکتوری los178، محیط را برای ساخت فایل‌های دودویی LynxOS-178 پیکربندی کنید.

    اگر برنامه/crateهای شما شامل ماکروهای رویه‌ای (procedural macro) باشند، Rust باید بتواند فایل‌های دودویی را برای میزبان نیز بسازد. با source کردن setup.sh، gcc میزبان پنهان می‌شود. برای مقابله با این مسئله، موارد زیر را به .cargo/config.toml پروژه خود اضافه کنید:

    [target.x86_64-unknown-linux-gnu]
linker = "lynx-host-gcc"

    (در صورت لزوم، سه‌گانه هدف میزبان خود را جایگزین x86_64-unknown-linux-gnu کنید.)

    برای اینکه cargo به فایل دودویی درست rustc اشاره کند، متغیر محیطی RUSTC را تنظیم کنید.

    کتابخانه core باید قابل استفاده باشد. می‌توانید با ساخت آن به‌عنوان بخشی از پروژه خود امتحان کنید:

    cargo +nightly build -Z build-std=core --target x86_64-lynx-lynxos178

    آزمون

    فایل‌های دودویی ساخته‌شده با Rust را می‌توان روی سیستم فایل یک نمونه LynxOS-178 قرار داد و در آنجا اجرا کرد. فایل‌های دودویی Rust معمولاً بزرگ‌اند، بنابراین ممکن است لازم باشد ابتدا آن‌ها را strip کنید.

    می‌توان مجموعه آزمون‌های Rust را با فراهم کردن یک test runner اجرا کرد که فایل دودویی آزمون را می‌گیرد و آن را روی LynxOS-178 اجرا می‌کند. با این حال، بیشتر (همه؟) آزمون‌ها بدون پشتیبانی از std اجرا نمی‌شوند، که هنوز پشتیبانی نمی‌شود.
