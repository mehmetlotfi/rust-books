    hexagon-unknown-qurt

    سطح (Tier): ۳

    Rust برای Hexagon QuRT (سیستم‌عامل بی‌درنگ شرکت Qualcomm).

    هدفتوضیحات
    hexagon-unknown-qurtHexagon ۳۲ بیتی QuRT

    نگهدارندگان هدف

    @androm3da

    الزامات

    این هدف cross-compile می‌شود. از std پشتیبانی می‌شود. این هدف از کتابخانه استاندارد و runtime مربوط به QuRT استفاده می‌کند.

    به‌طور پیش‌فرض، کدی که با این هدف تولید می‌شود باید روی سخت‌افزار Hexagon DSP که سیستم‌عامل بی‌درنگ QuRT را اجرا می‌کند، اجرا شود.

    • -Ctarget-cpu=hexagonv69 معماری Hexagon V69 را هدف می‌گیرد (پیش‌فرض)
    • -Ctarget-cpu=hexagonv73 پشتیبانی از دستورهای تعریف‌شده تا Hexagon V73 را اضافه می‌کند

    توابعی که با extern "C" علامت‌گذاری شده‌اند از قرارداد فراخوانی معماری Hexagon استفاده می‌کنند.

    این هدف به‌طور پیش‌فرض فایل‌های دودویی ELF مستقل از موقعیت (position-independent) تولید می‌کند و به همین دلیل هم برای تصاویر ایستا و هم برای shared objectهای پویا مناسب است.

    برای ساخت برنامه‌ها برای این هدف، Hexagon SDK لازم است.

    لینک کردن

    این هدف از hexagon-clang در Hexagon SDK به‌عنوان لینکر پیش‌فرض استفاده می‌کند. این لینکر در مسیرهایی مانند /opt/Hexagon_SDK/6.4.0.2/tools/HEXAGON_Tools/19.0.04/Tools/bin/hexagon-clang در دسترس است.

    لینکرهای جایگزین عبارت‌اند از:

    • eld، که هم همراه toolchain متن‌باز hexagon و هم همراه Hexagon SDK ارائه می‌شود
    • با تعیین -C linker=rust-lld می‌توان از rust-lld استفاده کرد

    ساخت هدف

    می‌توانید Rust را با پشتیبانی از این هدف بسازید؛ برای این کار آن را به فهرست target در bootstrap.toml اضافه کنید:

    [build]
build-stage = 1
host = ["<target for your host>"]
target = ["<target for your host>", "hexagon-unknown-qurt"]

[target.hexagon-unknown-qurt]
cc = "hexagon-clang"
cxx = "hexagon-clang++"
ranlib = "llvm-ranlib"
ar = "llvm-ar"
llvm-libunwind = 'in-tree'

    <target for your host> را با x86_64-unknown-linux-gnu یا هر مقدار مناسب دیگر برای ماشین میزبان خود جایگزین کنید.

    ساخت برنامه‌های Rust

    Rust هنوز artifactهای از پیش کامپایل‌شده برای این هدف ارائه نمی‌دهد. برای کامپایل برای این هدف، یا باید Rust را با فعال‌بودن این هدف بسازید (بخش «ساخت هدف» را در بالا ببینید)، یا با استفاده از build-std یا روشی مشابه، نسخه خودتان از core را بسازید.

    هدف‌گیری تصویر ایستا (Static Image)

    برای فایل‌های اجرایی ایستا که مستقیماً روی QuRT اجرا می‌شوند، از پیکربندی پیش‌فرض هدف همراه با پرچم‌های اضافی لینکر استفاده کنید:

    # Build a static executable for QuRT
cargo rustc --target hexagon-unknown-qurt -- \
    -C link-args="-static -nostdlib" \
    -C link-args="-L/opt/Hexagon_SDK/6.3.0.0/rtos/qurt/computev69/lib" \
    -C link-args="-lqurt -lc"

    این رویکرد برای موارد زیر مناسب است:

    • برنامه‌های مستقل QuRT
    • سرویس‌های سطح سیستم
    • کد مقداردهی اولیه در زمان بوت
    • برنامه‌هایی که به چیدمان حافظه قطعی نیاز دارند

    هدف‌گیری shared object قابل بارگذاری توسط کاربر

    برای کتابخانه‌های مشترکی که برنامه‌های QuRT می‌توانند به‌صورت پویا بارگذاری‌شان کنند:

    # Build a shared object for QuRT
cargo rustc --target hexagon-unknown-qurt \
    --crate-type=cdylib -- \
    -C link-args="-shared -fPIC" \
    -C link-args="-L/opt/Hexagon_SDK/6.3.0.0/rtos/qurt/computev69/lib"

    این رویکرد برای موارد زیر مناسب است:

    • معماری‌های مبتنی بر پلاگین
    • ماژول‌های قابل بارگذاری در زمان اجرا
    • کتابخانه‌های مشترک بین چند برنامه
    • کدی که باید بدون راه‌اندازی مجدد سیستم به‌روزرسانی شود

    گزینه‌های پیکربندی

    این هدف را می‌توان برای کاربردهای مختلف سفارشی کرد:

    برای تصاویر ایستا

    # In .cargo/config.toml
[target.hexagon-unknown-qurt]
rustflags = [
    "-C", "link-args=-static",
    "-C", "link-args=-nostdlib",
    "-C", "target-feature=-small-data"
]

    برای Shared Objectها

    # In .cargo/config.toml
[target.hexagon-unknown-qurt]
rustflags = [
    "-C", "link-args=-shared",
    "-C", "link-args=-fPIC",
    "-C", "relocation-model=pic"
]

    آزمون

    از آنجا که hexagon-unknown-qurt به محیط runtime مربوط به QuRT نیاز دارد، آزمون به یکی از موارد زیر نیاز دارد:

    • سخت‌افزار Hexagon همراه با QuRT
    • hexagon-sim
    • QEMU (qemu-system-hexagon)

    toolchainهای cross-compilation و کد C

    این هدف به toolchain اختصاصی Hexagon SDK برای تعامل با C نیاز دارد:

    • مسیر نمونه SDK: /opt/Hexagon_SDK/6.3.0.0/
    • Toolchain: از hexagon-clang در Hexagon SDK استفاده کنید
    • کتابخانه‌ها: در صورت نیاز، با کتابخانه‌های سیستمی QuRT لینک کنید

    نمونهٔ تعامل با C

    // lib.rs
#![no_std]
extern crate std;

#[unsafe(no_mangle)]
pub extern "C" fn rust_function() -> i32 {
    // Your Rust code here
    42
}

fn main() {
    // Example usage
    let result = rust_function();
    assert_eq!(result, 42);
}
    // wrapper.c
extern int rust_function(void);

int main() {
    return rust_function();
}

    این هدف هم از لینک ایستا برای برنامه‌های مستقل و هم از لینک پویا برای معماری‌های ماژولار پشتیبانی می‌کند، و همین آن را برای سناریوهای مختلف استقرار QuRT انعطاف‌پذیر می‌سازد.
