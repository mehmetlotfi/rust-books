    mipsisa*r6*-unknown-linux-gnu*

    سطح (Tier): ۳

    MIPS Release 6، یا به‌اختصار MIPS R6، جدیدترین نسخه از معماری مجموعه دستورها (ISA) برای MIPS است.

    MIPS R6 ماهیتی آزمایشی دارد، چون هنوز سخت‌افزار واقعی برای آن وجود ندارد. با این حال شبیه‌سازی Qemu در دسترس است و دو توزیع لینوکس برای اهداف توسعه و ارزیابی نگهداری می‌شوند. این مستندات پشتیبانی Rust از اهداف MIPS R6 را با الگوی mipsisa*r6*-unknown-linux-gnu* شرح می‌دهد.

    نام هدف از این قالب پیروی می‌کند: <machine>-<vendor>-<os><abi_suffix>، که در آن <machine> خانواده/مدل CPU را مشخص می‌کند، <vendor> فروشنده را و <os> نام سیستم‌عامل را. <abi_suffix> ABI پایه (32/n32/64/o64) را نشان می‌دهد.

    پسوند ABIتوضیحات
    abi64از ABI ۶۴ بیتی (64) استفاده می‌کند
    abin32از ABI نوع n32 استفاده می‌کند
    ندارداز ABI ۳۲ بیتی (32) (فرضی) استفاده می‌کند

    الزامات

    toolchain زبان C/C++

    برای یکی از اهداف MIPS R6 به یک toolchain از GNU نیاز است. AOSC OS محیط‌های ساخت بومی و cross-compiling کارآمدی فراهم می‌کند. همچنین می‌توانید toolchain خودتان را، متشکل از نسخه‌های جدید GCC و Binutils، فراهم کنید.

    کتابخانه‌های هدف

    برای انجام لینک پویا (dynamic linking) به مجموعه حداقلی از کتابخانه‌ها نیاز است:

    • GNU glibc
    • OpenSSL
    • Zlib
    • هدرهای Linux API

    این مجموعه کتابخانه‌ها باید نصب شوند تا یک sysroot حداقلی برای هدف تشکیل دهند.

    برای AOSC OS می‌توانید چنین sysroot ای را با دستورهای زیر نصب کنید:

    cd /tmp

# linux+api, glibc, and file system structure are included in the toolchain.
sudo apt install gcc+cross-mips64r6el binutils+cross-mips64r6el

# Download and extract required libraries.
wget https://repo.aosc.io/debs/pool/stable/main/z/zlib_1.2.13-0_mips64r6el.deb -O zlib.deb
wget https://repo.aosc.io/debs/pool/stable/main/o/openssl_1.1.1q-1_mips64r6el.deb -O openssl.deb

# Extract them to your desired location.
for i in zlib openssl ; do
    sudo dpkg-deb -vx $i.deb /var/ab/cross-root/mips64r6el
done

# Workaround a possible ld bug when using -Wl,-Bdynamic.
sudo sed -i 's|/usr|=/usr|g' /var/ab/cross-root/mips64r6el/usr/lib/libc.so

    برای توزیع‌های دیگر می‌توانید آن‌ها را به‌صورت دستی بسازید.

    ساخت

    روند زیر فرایند ساخت را برای هدف MIPS64 R6 با ABI ۶۴ بیتی (64) (mipsisa64r6el-unknown-linux-gnuabi64) شرح می‌دهد.

    پیش‌نیاز: غیرفعال کردن debuginfo

    یک باگ در LLVM باعث می‌شود اگر تولید debug یا debug info فعال باشد rustc از کار بیفتد (crash کند). برای غیرفعال کردن آن باید bootstrap.toml را ویرایش کنید:

    [rust]
debug = false
debug-info-level = 0

    پیش‌نیاز: فعال کردن backend مبتنی بر libc در rustix

    crate با نام rustix ممکن است سعی کند خودش را با اسمبلی MIPS R2 لینک کند که به خطای لینک می‌انجامد. برای جلوگیری از این مشکل می‌توانید با تنظیم RUSTFLAGS مربوط، rustix را مجبور کنید از backend جایگزین libc خود استفاده کند:

    export RUSTFLAGS="--cfg rustix_use_libc"

    این کار هنگام ساخت هشدارهایی ایجاد می‌کند، چون -D warnings به‌طور پیش‌فرض فعال است. با ویرایش bootstrap.toml و افزودن موارد زیر، -D warnings را غیرفعال کنید:

    [rust]
deny-warnings = false

    پیش‌نیاز: فراهم کردن OpenSSL

    از آنجا که این هدف در سطح ۳ است، openssl_sys برای آن کتابخانه OpenSSL همراه (vendored) ندارد. برای لینک کردن cargo باید یک کتابخانه OpenSSL از پیش ساخته‌شده فراهم کنید. چون یک sysroot از پیش پیکربندی‌شده داریم، می‌توانیم مستقیماً به آن اشاره کنیم:

    export MIPSISA64R6EL_UNKNOWN_LINUX_GNUABI64_OPENSSL_NO_VENDOR=y
export MIPSISA64R6EL_UNKNOWN_LINUX_GNUABI64_OPENSSL_DIR="/var/ab/cross-root/mips64r6el/usr"

    روی Debian ممکن است لازم باشد مسیر کتابخانه و مسیر include را جداگانه تعیین کنید:

    export MIPSISA64R6EL_UNKNOWN_LINUX_GNUABI64_OPENSSL_NO_VENDOR=y
export MIPSISA64R6EL_UNKNOWN_LINUX_GNUABI64_OPENSSL_LIB_DIR="/usr/lib/mipsisa64r6el-linux-gnuabi64/"
export MIPSISA64R6EL_UNKNOWN_LINUX_GNUABI64_OPENSSL_INCLUDE_DIR="/usr/include"

    اجرای x.py

    [build]
target = ["mipsisa64r6el-unknown-linux-gnuabi64"]

    مطمئن شوید که mipsisa64r6el-unknown-linux-gnuabi64-gcc در مسیر جست‌وجوی فایل‌های اجرایی شما ($PATH) در دسترس است.

    به‌طور جایگزین، می‌توانید مسیر همه فایل‌های اجرایی لازم toolchain را در bootstrap.toml مشخص کنید:

    [target.mipsisa64r6el-unknown-linux-gnuabi64]
# Adjust the paths below to point to your toolchain installation prefix.
cc = "/toolchain_prefix/bin/mipsisa64r6el-unknown-linux-gnuabi64-gcc"
cxx = "/toolchain_prefix/bin/mipsisa64r6el-unknown-linux-gnuabi64-g++"
ar = "/toolchain_prefix/bin/mipsisa64r6el-unknown-linux-gnuabi64-gcc-ar"
ranlib = "/toolchain_prefix/bin/mipsisa64r6el-unknown-linux-gnuabi64-ranlib"
linker = "/toolchain_prefix/bin/mipsisa64r6el-unknown-linux-gnuabi64-gcc"

    یا می‌توانید cross compiler toolchain خود را با یک متغیر محیطی مشخص کنید:

    export CROSS_COMPILE="/opt/abcross/mips64r6el/bin/mipsisa64r6el-aosc-linux-gnuabi64-"

    در پایان، اسکریپت ساخت را اجرا کنید:

    ./x.py build

    ساخت برنامه‌های Rust

    برای ساخت برنامه‌های Rust برای اهداف MIPS R6، برای مثال هدف mipsisa64r6el-unknown-linux-gnuabi64:

    cargo build --target mipsisa64r6el-unknown-linux-gnuabi64

    آزمون

    برای آزمایش یک فایل دودویی cross-compile‌شده روی سیستم ساخت خود، شبیه‌ساز کاربر Qemu را که از معماری MIPS R6 پشتیبانی می‌کند (qemu-user-mipsel یا qemu-user-mips64el) نصب کنید. برای اجرای برنامه، کتابخانه‌های زمان اجرای GCC (libgcc_s) مربوط به معماری هدف باید در sysroot هدف موجود باشند.

    env \
    CARGO_TARGET_MIPSISA64R6EL_UNKNOWN_LINUX_GNUABI64_LINKER="/opt/abcross/mips64r6el/bin/mipsisa64r6el-aosc-linux-gnuabi64-gcc" \
    CARGO_TARGET_MIPSISA64R6EL_UNKNOWN_LINUX_GNUABI64_RUNNER="qemu-mips64el-static -L /var/ab/cross-root/mips64r6el" \
    cargo run --release \
        --target mipsisa64r6el-unknown-linux-gnuabi64

    نکته‌هایی برای ساخت برنامه‌های Rust برای MIPS R6

    • تا زمانی که راه‌حل نهایی ارائه نشده است، لطفاً مطمئن شوید راه‌حل‌های موقت یادشده برای crate با نام rustix و برای LLVM همیشه اعمال شده‌اند. این کار با تنظیم متغیرهای محیطی مربوط و ویرایش Cargo.toml پیش از ساخت انجام می‌شود.
