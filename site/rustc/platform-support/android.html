    *-linux-android و *-linux-androideabi

    سطح: 2

    Android یک سیستم‌عامل موبایل است که بر پایهٔ هستهٔ Linux ساخته شده است.

    نگهدارندگان هدف

    @chriswailes @jfgoog @maurer @pirama-arumuga-nainar

    الزامات

    این هدف به‌صورت متقاطع از یک محیط میزبان کامپایل می‌شود. توسعه را می‌توان از درخت منبع یا با استفاده از Android NDK انجام داد.

    اهداف Android از std پشتیبانی می‌کنند. فایل‌های دودویی تولیدشده از قالب فایل ELF استفاده می‌کنند.

    سیاست به‌روزرسانی NDK/API

    Rust از جدیدترین Android Native Development Kit (NDK) با پشتیبانی بلندمدت (LTS) پشتیبانی خواهد کرد. به‌طور پیش‌فرض Rust از همهٔ سطوح API پشتیبانی‌شده توسط NDK پشتیبانی می‌کند، اما در صورت لزوم ممکن است حداقل سطح API بالاتری لازم باشد.

    ساخت هدف

    برای ساخت فایل‌های دودویی Rust برای Android، به یک نسخه از جدیدترین ویرایش LTS از Android NDK نیاز دارید. اهداف Android پشتیبانی‌شده عبارت‌اند از:

    • aarch64-linux-android
    • arm-linux-androideabi
    • armv7-linux-androideabi
    • i686-linux-android
    • thumbv7neon-linux-androideabi
    • x86_64-linux-android

    هدف riscv64-linux-android به‌عنوان یک هدف سطح ۳ پشتیبانی می‌شود.

    فهرست همهٔ اهداف پشتیبانی‌شده را می‌توان اینجا یافت

    نکات معماری

    riscv64-linux-android

    در حال حاضر هدف riscv64-linux-android به ویژگی‌ها/افزونه‌های معماری زیر نیاز دارد:

    • a (عملیات اتمی)
    • d (ممیز شناور با دقت مضاعف)
    • c (مجموعه دستورهای فشرده)
    • f (ممیز شناور با دقت ساده)
    • m (ضرب و تقسیم)
    • v (برداری)
    • Zba (دستورهای محاسبهٔ آدرس)
    • Zbb (دستورهای پایه)
    • Zbs (دستورهای تک‌بیتی)
