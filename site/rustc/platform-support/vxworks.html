    *-wrs-vxworks

    Tier: 3

    هدف‌هایی برای سیستم‌عامل VxWorks.

    سه‌گانه‌های هدف موجود:

    • x86_64-wrs-vxworks
    • aarch64-wrs-vxworks
    • i686-wrs-vxworks
    • armv7-wrs-vxworks-eabihf
    • powerpc-wrs-vxworks
    • powerpc64-wrs-vxworks

    • riscv32-wrs-vxworks
    • riscv64-wrs-vxworks

    @biabbas @hax0kartik

    الزامات

    نسخهٔ سیستم‌عامل

    حداقل نسخهٔ پشتیبانی‌شده VxWorks 7 است.

    محیط

    WIND_RELEASE_ID

    در محیط ساخت VxWorks، متغیر محیطی WIND_RELEASE_ID نسخهٔ انتشار VxWorks مورد استفاده برای ساخت را نشان می‌دهد. از WIND_RELEASE_ID می‌توان برای کامپایل شرطی قابلیت‌ها/کد یا مدیریت رفتار مخصوص هر نسخه استفاده کرد.

    ساخت

    Rust برای هر هدف را می‌توان با پیکربندی vsb مخصوص همان هدف کامپایل متقابل کرد. پشتیبانی از Std اضافه شده است اما هنوز به‌طور کامل آزموده نشده است.

    ساخت هدف

    می‌توانید با افزودن هدف‌ها به فهرست target در bootstrap.toml، Rust را با پشتیبانی از آن‌ها بسازید. علاوه بر این، باید workbench و wr-cc پیکربندی و فعال شده باشند.

    [build]
build-stage = 1
target = [
    "<HOST_TARGET>",
    "x86_64-wrs-vxworks",
    "aarch64-wrs-vxworks",
    "i686-wrs-vxworks",
    "armv7-wrs-vxworks-eabihf",
    "powerpc-wrs-vxworks",
    "powerpc64-wrs-vxworks",
    "powerpc-wrs-vxworks-spe",
]

    ساخت برنامه‌های Rust

    Rust هنوز آرتیفکت‌های از پیش کامپایل‌شده‌ای برای VxWorks ارائه نمی‌کند.

    ساده‌ترین راه برای ساخت و آزمودن برنامه‌ها برای VxWorks، استفاده از rustc و cargo همراه در VxWorks workbench و پیروی از راهنمای رسمی windriver است.

    زنجیرهٔ ابزار کامپایل متقابل و کد C

    این هدف از کد C پشتیبانی می‌کند. زنجیرهٔ ابزارهای C از پیش کامپایل‌شده را می‌توان در VxWorks workbench ارائه‌شده یافت.
