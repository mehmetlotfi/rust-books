    riscv32{e,em,emc}-unknown-none-elf

    سطح (Tier): ۳

    هدف bare-metal برای پردازنده‌های RISC-V با ISAهای RV32E، RV32EM و RV32EMC.

    نگهدارندگان هدف

    @hegza

    الزامات

    این هدف cross-compile می‌شود و از لینک ایستا استفاده می‌کند. هیچ toolchain خارجی لازم نیست و لینکر پیش‌فرض rust-lld کار می‌کند، اما باید یک اسکریپت لینکر مشخص کنید.

    ساخت هدف

    این هدف همراه Rust ارائه می‌شود و با rustup قابل نصب است.

    آزمون

    این یک هدف cross-compile شده از نوع no-std است که باید یا در یک شبیه‌ساز اجرا شود یا روی سخت‌افزار مناسب برنامه‌ریزی شود. اجرای مجموعه آزمون‌های Rust روی این هدف ممکن نیست.

    toolchainهای cross-compilation و کد C

    این هدف از کد C پشتیبانی می‌کند. اگر با C یا C++ لینک متقابل انجام می‌دهید، ممکن است لازم باشد به‌جای rust-lld از riscv32-unknown-elf-gcc به‌عنوان لینکر استفاده کنید.
