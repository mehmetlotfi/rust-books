    *-apple-ios

    اهداف iOS / iPadOS اپل.

    سطح: 2 (بدون ابزارهای میزبان)

    • aarch64-apple-ios: Apple iOS روی ARM64.
    • aarch64-apple-ios-sim: شبیه‌ساز Apple iOS روی ARM64.
    • x86_64-apple-ios: شبیه‌ساز Apple iOS روی x86 ۶۴ بیتی.

    سطح: 3

    • armv7s-apple-ios: Apple iOS روی Armv7-A.
    • i386-apple-ios: شبیه‌ساز Apple iOS روی x86 ۳۲ بیتی.

    نگهدارندگان هدف

    @badboy @deg4uss3r @madsmtm

    الزامات

    این اهداف به‌صورت متقاطع کامپایل می‌شوند و به iOS SDK متناظر (iPhoneOS.sdk یا iPhoneSimulator.sdk) نیاز دارند که Xcode ارائه می‌کند. برای ساخت اهداف ARM64 به Xcode 12 یا بالاتر نیاز است.

    مسیر SDK را می‌توان با متغیر محیطی رایج SDKROOT به rustc داد، یا هنگام کامپایل روی macOS میزبان تقریباً با همان منطقِ xcrun --sdk iphoneos --show-sdk-path استنباط می‌شود.

    نسخهٔ سیستم‌عامل

    حداقل نسخهٔ پشتیبانی‌شده iOS 10.0 است.

    این نسخه را می‌توان برای هر فایل دودویی با تغییر هدف استقرار بالاتر برد. rustc متغیرهای محیطی رایجی را که Xcode برای این کار استفاده می‌کند رعایت می‌کند؛ در این مورد IPHONEOS_DEPLOYMENT_TARGET.

    ساخت هدف

    اهداف سطح 2 از طریق rustup توزیع می‌شوند و می‌توان آن‌ها را با یکی از دستورهای زیر نصب کرد:

    $ rustup target add aarch64-apple-ios
$ rustup target add aarch64-apple-ios-sim
$ rustup target add x86_64-apple-ios

    اهداف سطح 3 را می‌توان با فعال کردن آن‌ها برای ساخت rustc در bootstrap.toml ساخت، مثلاً با افزودن:

    [build]
target = ["armv7s-apple-ios", "i386-apple-ios"]

    استفاده از -Zbuild-std ناپایدار با Cargo نایتلی نیز ممکن است کار کند.

    ساخت برنامه‌های Rust

    اگر rustc با پشتیبانی از این اهداف ساخته شده باشد، می‌توان برنامه‌های Rust را با تعیین --target برای آن‌ها ساخت. برای مثال:

    $ rustc --target aarch64-apple-ios your-code.rs

    یا اگر از Cargo و -Zbuild-std استفاده می‌کنید:

    $ cargo +nightly build -Zbuild-std --target armv7s-apple-ios

    می‌توان گونه‌های شبیه‌ساز را با cfg به‌صورت target_env = "sim" (یا target_abi = "sim" پیش از Rust 1.91.0) از گونه‌هایی که روی دستگاه واقعی اجرا می‌شوند تشخیص داد.

    if cfg!(all(target_vendor = "apple", target_env = "sim")) {
    // Do something on the iOS/tvOS/visionOS/watchOS Simulator.
} else {
    // Everything else, like Windows and non-Simulator iOS.
}

    این مشابه TARGET_OS_SIMULATOR در کد C است.

    آزمون

    اجرا و آزمون کد شما طبیعتاً به یک دستگاه واقعی که iOS اجرا می‌کند یا محیط شبیه‌ساز معادل Xcode نیاز دارد. ابزارهای متعددی در اکوسیستم برای اجرای یک پروژهٔ Cargo روی یکی از این‌ها وجود دارد. یکی از این ابزارها cargo-dinghy است. madsmtm/objc2#459 فهرست جامع‌تری دارد.

    برای دستورالعمل اجرای مجموعه آزمون کتابخانهٔ استاندارد، آزمون روی شبیه‌سازها در rustc-dev-guide را نیز ببینید.
