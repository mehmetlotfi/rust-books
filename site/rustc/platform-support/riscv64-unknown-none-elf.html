    riscv64{im,imac,gc}-unknown-none-elf

    سطح (Tier): ۲

    هدف bare-metal برای پردازنده‌های RISC-V با ISAهای RV64IMAC و RV64GC.

    سطح (Tier): ۳

    هدف bare-metal برای پردازنده‌های RISC-V با ISA از نوع RV64IM.

    نگهدارندگان هدف

    • گروه کاری Rust Embedded، تیم RISC-V

    الزامات

    این هدف cross-compile می‌شود و از لینک ایستا استفاده می‌کند. این هدف از core و alloc پشتیبانی می‌کند، اما از std نه.

    از آنجا که ISA از نوع RV64IM افزونه «A» (اتمی) را ندارد، عملیات اتمی با استفاده از قابلیت +forced-atomics شبیه‌سازی می‌شوند.

    هیچ toolchain خارجی لازم نیست و پیوندگر پیش‌فرض rust-lld کار می‌کند، اما باید یک اسکریپت پیوندگر مشخص کنید. crate با نام riscv-rt اسکریپت‌های پیوندگر مناسب را فراهم می‌کند. مخزن riscv-rust-quickstart نمونه‌هایی از پروژه‌های bare-metal برای RISC-V را نشان می‌دهد.

    ساخت هدف

    می‌توانید Rust را با پشتیبانی از این هدف بسازید؛ برای این کار آن را به فهرست target در bootstrap.toml اضافه کنید:

    [build]
target = ["riscv64im-unknown-none-elf"]

    یا می‌توانید از پرچم -Z build-std استفاده کنید تا کتابخانه استاندارد در صورت نیاز ساخته شود:

    cargo build -Z build-std=core,alloc --target riscv64im-unknown-none-elf

    ساخت برنامه‌های Rust

    Rust هنوز artifactهای از پیش کامپایل‌شده برای این هدف ارائه نمی‌دهد. برای کامپایل برای این هدف (بخش «ساخت هدف» را در بالا ببینید)

    آزمون

    این یک هدف cross-compile شده از نوع no-std است که باید یا در یک شبیه‌ساز اجرا شود یا روی سخت‌افزار مناسب برنامه‌ریزی شود. اجرای مجموعه آزمون‌های Rust روی این هدف ممکن نیست.

    toolchainهای cross-compilation و کد C

    این هدف از کد C پشتیبانی می‌کند. اگر با C یا C++ لینک متقابل انجام می‌دهید، ممکن است لازم باشد به‌جای rust-lld از riscv64-unknown-elf-gcc به‌عنوان لینکر استفاده کنید. روی هدف‌های riscv64im* که افزونهٔ a را ندارند، ممکن است به پرچم‌های -march=rv64im -mabi=lp64 نیاز باشد.
