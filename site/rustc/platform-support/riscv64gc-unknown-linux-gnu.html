    riscv64gc-unknown-linux-gnu

    سطح (Tier): ۲ (همراه با ابزارهای میزبان)

    هدف RISC-V برای Linux با glibc که از مجموعه دستورهای پایه RV64I همراه با مجموعه افزونه‌های G و همچنین افزونه C استفاده می‌کند.

    نگهدارندگان هدف

    @kito-cheng @michaelmaitland @robin-randhawa-sifive @topperc

    الزامات

    این هدف به موارد زیر نیاز دارد:

    • هستهٔ Linux نسخهٔ 4.20 یا بالاتر
    • glibc نسخهٔ 2.17 یا بالاتر

    ساخت هدف

    این هدف از طریق rustup توزیع می‌شود و جز این به پیکربندی خاصی نیاز ندارد.

    اگر به هر دلیلی لازم است Rust خودتان را بسازید، می‌توانید هدف را در bootstrap.toml فعال کنید. برای مثال:

    [build]
target = ["riscv64gc-unknown-linux-gnu"]

    ساخت برنامه‌های Rust

    روی میزبان riscv64gc-unknown-linux-gnu، هدف riscv64gc-unknown-linux-gnu باید به‌طور خودکار نصب شود و به‌صورت پیش‌فرض مورد استفاده قرار بگیرد.

    روی همه میزبان‌های دیگر، هدف را اضافه کنید:

    rustup target add riscv64gc-unknown-linux-gnu

    سپس crateها را با دستور زیر cross-compile کنید:

    cargo build --target riscv64gc-unknown-linux-gnu

    آزمون

    برای آزمون و اجرای این هدف هیچ الزام خاصی وجود ندارد. برای آزمون ساخت‌های cross روی میزبان، لطفاً به بخش «toolchainهای cross-compilation و کد C» در ادامه مراجعه کنید.

    toolchainهای cross-compilation و کد C

    یک toolchain برای RISC-V را می‌توان برای Windows/Mac/Linux از مخزن riscv-gnu-toolchain به دست آورد. فایل‌های دودویی از طریق embecosm در دسترس‌اند و ممکن است از مدیر بسته سیستم‌عامل شما هم قابل دریافت باشند.

    روی Ubuntu می‌توان یک toolchain برای RISC-V را با دستور زیر نصب کرد:

    apt install gcc-riscv64-linux-gnu g++-riscv64-linux-gnu libc6-dev-riscv64-cross

    بسته به سیستم شما، ممکن است لازم باشد هدف را طوری پیکربندی کنید که از لینکر GNU GCC استفاده کند. برای استفاده از آن، موارد زیر را به .cargo/config.toml خود اضافه کنید:

    [target.riscv64gc-unknown-linux-gnu]
linker = "riscv64-linux-gnu-gcc"

    اگر toolchain با نام riscv64-linux-gnu-* در PATH شما نیست، ممکن است لازم باشد تنظیمات بیشتری را پیکربندی کنید:

    [target.riscv64gc-unknown-linux-gnu]
# Adjust the paths to point at your toolchain
cc = "/TOOLCHAIN_PATH/bin/riscv64-linux-gnu-gcc"
cxx = "/TOOLCHAIN_PATH/bin/riscv64-linux-gnu-g++"
ar = "/TOOLCHAIN_PATH/bin/riscv64-linux-gnu-ar"
ranlib = "/TOOLCHAIN_PATH/bin/riscv64-linux-gnu-ranlib"
linker = "/TOOLCHAIN_PATH/bin/riscv64-linux-gnu-gcc"

    برای آزمون فایل‌های دودویی cross-compile شده روی میزبانی که RISC-V نیست، می‌توانید از qemu استفاده کنید. روی Ubuntu می‌توان یک شبیه‌ساز RISC-V را با دستور زیر به دست آورد:

    apt install qemu-system-riscv64

    سپس در .cargo/config.toml مقدار runner را تنظیم کنید:

    [target.riscv64gc-unknown-linux-gnu]
runner = "qemu-riscv64-static -L /usr/riscv64-linux-gnu -cpu rv64"

    روی Mac و Linux همچنین می‌توان از lima برای شبیه‌سازی RISC-V استفاده کرد، به روشی مشابه WSL2 در Windows:

    limactl start template://riscv
limactl shell riscv

    با استفاده از Docker (همراه با BuildKit) می‌توان از ایمیج riscv64/ubuntu برای ساخت یا اجرای فایل‌های دودویی riscv64gc-unknown-linux-gnu استفاده کرد.

    docker run --platform linux/riscv64 -ti --rm --mount "type=bind,src=$(pwd),dst=/checkout" riscv64/ubuntu bash
