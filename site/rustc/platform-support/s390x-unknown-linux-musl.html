    s390x-unknown-linux-musl

    سطح (Tier): ۳

    اهداف معماری IBM z/Architecture ‏(s390x)، از جمله IBM Z و LinuxONE، که Linux روی آن‌ها اجرا می‌شود.

    نگهدارندگان هدف

    @uweigand @Gelbpunkt

    الزامات

    این هدف به موارد زیر نیاز دارد:

    • هستهٔ Linux نسخهٔ 3.2 یا بالاتر
    • musl نسخهٔ 1.2.5 یا بالاتر

    کدی که این هدف تولید می‌کند از ISA مربوط به z/Architecture استفاده می‌کند، با فرض حداقل سطح معماری z10 (ویرایش هشتم «اصول عملکرد z/Architecture»)، و با ABI از نوع ELF برای s390x سازگار است.

    مواد مرجع:

    • اصول عملکرد z/Architecture (Principles of Operation)
    • رابط دودویی برنامه کاربردی ELF برای z/Architecture

    ساخت هدف

    چون این هدف در سطح ۳ (Tier 3) قرار دارد، Rust هنوز artifactهای از پیش کامپایل‌شده‌ای برای آن ارائه نمی‌دهد.

    بنابراین می‌توانید Rust را با پشتیبانی از این هدف بسازید؛ برای این کار آن را به فهرست هدف‌ها در bootstrap.toml اضافه کنید. نمونه‌ای از پیکربندی در ادامه آمده است.

    [build]
target = ["s390x-unknown-linux-musl"]

    ساخت برنامه‌های Rust

    Rust هنوز artifactهای از پیش کامپایل‌شده برای این هدف ارائه نمی‌دهد. برای کامپایل برای این هدف، ابتدا باید Rust را با فعال‌بودن این هدف بسازید (بخش «ساخت هدف» را در بالا ببینید).

    آزمون

    برای آزمون و اجرای این هدف هیچ الزام خاصی وجود ندارد. برای آزمون ساخت‌های cross روی میزبان، لطفاً به بخش «toolchainهای cross-compilation و کد C» در ادامه مراجعه کنید.

    toolchainهای cross-compilation و کد C

    کد Rust که با این هدف ساخته شده باشد با کد C که با GCC یا Clang و با سه‌گانه هدف s390x-unknown-linux-musl کامپایل شده سازگار است (چه به‌صورت بومی و چه با cross-compilation).

    بسته به سیستم شما، ممکن است لازم باشد هدف را طوری پیکربندی کنید که از لینکر GNU GCC استفاده کند. برای استفاده از آن، موارد زیر را به .cargo/config.toml خود اضافه کنید:

    [target.s390x-unknown-linux-musl]
linker = "s390x-linux-musl-gcc"

    اگر toolchain با نام s390x-linux-musl-* در PATH شما نیست، ممکن است لازم باشد تنظیمات بیشتری را پیکربندی کنید:

    [target.s390x-unknown-linux-musl]
# Adjust the paths to point at your toolchain
cc = "/TOOLCHAIN_PATH/bin/s390x-linux-musl-gcc"
cxx = "/TOOLCHAIN_PATH/bin/s390x-linux-musl-g++"
ar = "/TOOLCHAIN_PATH/bin/s390x-linux-musl-ar"
ranlib = "/TOOLCHAIN_PATH/bin/s390x-linux-musl-ranlib"
linker = "/TOOLCHAIN_PATH/bin/s390x-linux-musl-gcc"

    برای آزمون فایل‌های دودویی cross-compile شده روی میزبانی که s390x نیست، می‌توانید از qemu استفاده کنید.

    → s390x-unknown-linux-gnus390x-unknown-none-softfloat ←
