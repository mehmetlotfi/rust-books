    riscv64gc-unknown-linux-musl

    سطح (Tier): ۲ (همراه با ابزارهای میزبان)

    هدف RISC-V برای Linux با musl libc که از مجموعه دستورهای پایه RV64I همراه با مجموعه افزونه‌های G و همچنین افزونه C استفاده می‌کند.

    نگهدارندگان هدف

    @Amanieu @kraj

    الزامات

    این هدف به موارد زیر نیاز دارد:

    • هستهٔ Linux نسخهٔ 4.20 یا بالاتر
    • musl libc نسخهٔ 1.2.5 یا بالاتر

    ساخت هدف

    این هدف از طریق rustup توزیع می‌شود و جز این به پیکربندی خاصی نیاز ندارد.

    اگر لازم است Rust خودتان را بسازید، می‌توانید اهداف را در bootstrap.toml فعال کنید. برای مثال:

    [build]
target = ["riscv64gc-unknown-linux-musl"]

    ساخت برنامه‌های Rust

    روی میزبان riscv64gc-unknown-linux-musl، هدف riscv64gc-unknown-linux-musl باید به‌طور خودکار نصب شود و به‌صورت پیش‌فرض مورد استفاده قرار بگیرد.

    روی همه میزبان‌های دیگر، هدف را اضافه کنید:

    rustup target add riscv64gc-unknown-linux-musl

    سپس crateها را با دستور زیر cross-compile کنید:

    cargo build --target riscv64gc-unknown-linux-musl

    آزمون

    این هدف را می‌توان مانند همیشه با x.py روی یک میزبان RISC-V یا از طریق شبیه‌سازی QEMU آزمون کرد.
