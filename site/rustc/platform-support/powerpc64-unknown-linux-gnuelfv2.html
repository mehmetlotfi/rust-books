    powerpc64-unknown-linux-gnuelfv2

    Tier: 3

    هدفی برای برنامه‌های لینوکس PowerPC 64 بیتی با ترتیب big endian که از ABI نوع ELFv2 و کتابخانهٔ C گنو (GNU) استفاده می‌کنند.

    نگهدارندگان هدف

    @Gelbpunkt

    الزامات

    ساخت خود هدف به یک کامپایلر PowerPC 64 بیتی با ترتیب big endian نیاز دارد که از ABI نوع ELFv2 استفاده کند و cc-rs از آن پشتیبانی کند.

    ساخت هدف

    هدف را می‌توان با فعال‌کردن آن در ساخت rustc ساخت.

    [build]
target = ["powerpc64-unknown-linux-gnuelfv2"]

    مطمئن شوید کامپایلر C شما در $PATH قرار دارد، سپس آن را به bootstrap.toml اضافه کنید:

    [target.powerpc64-unknown-linux-gnuelfv2]
cc = "powerpc64-linux-gnu-gcc"
cxx = "powerpc64-linux-gnu-g++"
ar = "powerpc64-linux-gnu-ar"
linker = "powerpc64-linux-gnu-gcc"

    ساخت برنامه‌های Rust

    Rust هنوز آرتیفکت‌های از پیش کامپایل‌شده‌ای برای این هدف ارائه نمی‌کند. برای کامپایل برای این هدف، ابتدا باید Rust را با فعال‌بودن این هدف بسازید (بخش «ساخت هدف» بالا را ببینید).

    کامپایل متقابل

    این هدف را می‌توان از هر میزبانی کامپایل متقابل کرد.

    آزمون

    این هدف را می‌توان به‌طور معمول با x.py روی یک میزبان PowerPC 64 بیتی با ترتیب big endian یا از طریق شبیه‌سازی QEMU آزمود.
