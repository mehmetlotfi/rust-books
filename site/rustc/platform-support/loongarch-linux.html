    loongarch*-unknown-linux-*

    سطح (Tier): ۲ (همراه با ابزارهای میزبان)

    اهداف Linux برای LoongArch. LoongArch یک ISA از نوع RISC است که شرکت Loongson Technology Corporation Limited آن را توسعه داده است.

    هدفتوضیحات
    loongarch64-unknown-linux-gnuLoongArch64 لینوکس، ABI نوع LP64D (هسته 5.19، glibc 2.36)، نیازمند LSX
    loongarch64-unknown-linux-muslLoongArch64 لینوکس، ABI نوع LP64D (هسته 5.19، musl 1.2.5)، نیازمند LSX

    این اهداف هم از ساخت بومی و هم از cross-build پشتیبانی می‌کنند و پشتیبانی کامل از std دارند.

    مواد مرجع:

    • دفترچه‌های ISA مربوط به LoongArch
    • رابط دودویی برنامه (Application Binary Interface) برای معماری LoongArch™

    نگهدارندگان هدف

    الزامات

    نسخه سیستم‌عامل

    حداقل نسخه پشتیبانی‌شده لینوکس 5.19 است.

    برخی توزیع‌های لینوکس، که بیشتر تجاری هستند، ممکن است هسته‌های لینوکس fork‌شده‌ای ارائه دهند که برای پورت‌های LoongArch خود شماره نسخه‌ای کمتر از 5.19 دارند. چنین هسته‌هایی ممکن است همچنان وصله (patch) شوند تا با UAPI لینوکس 5.19 بالادستی سازگار باشند و در نتیجه از اهداف شرح‌داده‌شده در این سند پشتیبانی کنند، اما همیشه چنین نیست. نصب‌کننده rustup یک بررسی برای این مورد دارد و اگر ناسازگاری تشخیص داده شود متوقف می‌شود.

    toolchain میزبان

    این اهداف به یک toolchain نسبتاً به‌روز LoongArch روی میزبان نیاز دارند. در حال حاضر مؤلفه‌های زیر توسط CI مربوط به Rust برای ساخت این هدف استفاده می‌شوند و نسخه‌ها را می‌توان حداقل نیازمندی دانست:

    • GNU Binutils 2.45
    • GCC 15.x
    • glibc 2.36
    • linux-headers 5.19

    از این میان، glibc و linux-headers در قدیمی‌ترین نسخه‌هایی هستند که پشتیبانی mainline از LoongArch را دارند، بنابراین استفاده از نسخه‌های قدیمی‌تر آن‌ها ممکن نیست. نسخه‌های قدیمی‌تر Binutils و GCC نیز کار نخواهند کرد، چون از جمله به دلیل نبود پشتیبانی از انواع جدیدتر relocation در ELF برای LoongArch و قابلیت‌های دیگر.

    toolchainهای جدید LLVM/Clang ممکن است بتوانند این اهداف را بسازند، اما در حال حاضر به‌طور فعال آزمایش نمی‌شوند.

    ویژگی‌های CPU

    این اهداف به ویژگی‌های ممیز شناور دقت دوگانه و LSX (LoongArch SIMD Extension) نیاز دارند.

    ساخت

    این اهداف از طریق rustup توزیع می‌شوند و در غیر این صورت به پیکربندی خاصی نیاز ندارند.

    با این حال، اگر به هر دلیلی نیاز دارید Rust خودتان را بسازید، می‌توانید این اهداف را به‌سادگی در bootstrap.toml فعال کنید. برای مثال:

    [build]
target = ["loongarch64-unknown-linux-gnu"]

    مطمئن شوید که فایل‌های دودویی toolchain مربوط به LoongArch از طریق $PATH در دسترس هستند. به‌طور جایگزین، می‌توانید مسیرها را صریحاً در bootstrap.toml پیکربندی کنید:

    [target.loongarch64-unknown-linux-gnu]
# Adjust the paths to point at your toolchain
# Suppose the toolchain is placed at /TOOLCHAIN_PATH, and the cross prefix is
# "loongarch64-unknown-linux-gnu-":
cc = "/TOOLCHAIN_PATH/bin/loongarch64-unknown-linux-gnu-gcc"
cxx = "/TOOLCHAIN_PATH/bin/loongarch64-unknown-linux-gnu-g++"
ar = "/TOOLCHAIN_PATH/bin/loongarch64-unknown-linux-gnu-ar"
ranlib = "/TOOLCHAIN_PATH/bin/loongarch64-unknown-linux-gnu-ranlib"
linker = "/TOOLCHAIN_PATH/bin/loongarch64-unknown-linux-gnu-gcc"

    کامپایل متقاطع

    این هدف را می‌توان روی میزبان x86_64-unknown-linux-gnu cross-compile کرد. احتمالاً میزبان‌های دیگر هم کار می‌کنند، اما به‌طور فعال آزمایش نمی‌شوند.

    به لطف شبیه‌سازی linux-user در QEMU، می‌توانید cross build را مستقیماً روی میزبان آزمایش کنید. نمونه‌ای در ادامه آمده است:

    # Suppose the cross toolchain is placed at $TOOLCHAIN_PATH, with a cross prefix
# of "loongarch64-unknown-linux-gnu-".
export CC_loongarch64_unknown_linux_gnu="$TOOLCHAIN_PATH"/bin/loongarch64-unknown-linux-gnu-gcc
export CXX_loongarch64_unknown_linux_gnu="$TOOLCHAIN_PATH"/bin/loongarch64-unknown-linux-gnu-g++
export AR_loongarch64_unknown_linux_gnu="$TOOLCHAIN_PATH"/bin/loongarch64-unknown-linux-gnu-gcc-ar
export CARGO_TARGET_LOONGARCH64_UNKNOWN_LINUX_GNU_LINKER="$TOOLCHAIN_PATH"/bin/loongarch64-unknown-linux-gnu-gcc

# Point qemu-loongarch64 to the LoongArch sysroot.
# Suppose the sysroot is located at "sysroot" below the toolchain root:
export CARGO_TARGET_LOONGARCH64_UNKNOWN_LINUX_GNU_RUNNER="qemu-loongarch64 -L $TOOLCHAIN_PATH/sysroot"
# Or alternatively, if binfmt_misc is set up for running LoongArch binaries
# transparently:
export QEMU_LD_PREFIX="$TOOLCHAIN_PATH"/sysroot

cargo run --target loongarch64-unknown-linux-gnu --release

    آزمون

    برای آزمون و اجرای این اهداف هیچ نیازمندی خاصی وجود ندارد. برای آزمایش cross buildها روی میزبان، لطفاً به بخش «Cross-compilation» در بالا مراجعه کنید.

    ساخت برنامه‌های Rust

    چون این اهداف از طریق rustup در دسترس هستند، ساخت برنامه‌های Rust برای آن‌ها بسیار آسان است: مانند معماری‌های دیگر. توجه کنید که برای لینک کردن، یا اگر می‌خواهید کد C را همراه با Rust کامپایل کنید (مثلاً برای crateهای Rust که وابستگی C دارند)، به یک toolchain سی/سی‌پلاس‌پلاس برای LoongArch نیاز دارید.

    rustup target add loongarch64-unknown-linux-gnu
cargo build --target loongarch64-unknown-linux-gnu

    دسترس‌پذیری artifactهای از پیش ساخته‌شده از طریق rustup به شرح زیر است:

    • loongarch64-unknown-linux-gnu: از Rust 1.71؛
    • loongarch64-unknown-linux-musl: از Rust 1.81.
