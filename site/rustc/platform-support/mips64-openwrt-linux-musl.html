    mips64-openwrt-linux-musl

    سطح (Tier): ۳

    نگهدارندگان هدف

    @Itus-Shield

    الزامات

    این هدف cross-compile می‌شود. از std پشتیبانی نمی‌شود. تخصیص‌دهنده (allocator) پیش‌فرضی وجود ندارد، اما با فراهم کردن یک allocator می‌توان از alloc استفاده کرد.

    به‌طور پیش‌فرض کد Rust تولیدشده برای این هدف از -msoft-float استفاده می‌کند و به‌صورت پویا لینک می‌شود.

    این هدف فایل‌های دودویی را در قالب ELF تولید می‌کند.

    ساخت هدف

    این هدف صرفاً درون سیستم ساخت OpenWrt و از طریق بسته HOST با نام rust-lang ساخته می‌شود.

    ساخت برنامه‌های Rust

    Rust هنوز مصنوعات (artifact) از پیش کامپایل‌شده‌ای برای این هدف ارائه نمی‌کند. برای کامپایل برای این هدف، باید Rust را با فعال بودن این هدف بسازید (به «ساخت هدف» در بالا مراجعه کنید).

    آزمون

    از آنجا که mips64-openwrt-linux-musl از محیط‌های متنوعی پشتیبانی می‌کند و از std پشتیبانی نمی‌کند، این هدف در حال حاضر از اجرای مجموعه آزمون‌های Rust پشتیبانی نمی‌کند.
