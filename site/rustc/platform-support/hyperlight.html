    *-unknown-hyperlight

    Tier: ۳

    این اهداف برای ساخت فایل‌های اجرایی guest برای راهکار sandbox‌سازی Hyperlight استفاده می‌شوند.

    نگهدارندگان هدف

    • @syntactically
    • @yoshuawuyts

    الزامات

    این اهداف فقط برای کامپایل متقاطع قابل استفاده‌اند. آن‌ها نباید به چیز خاصی به‌عنوان ابزار میزبان نیاز داشته باشند، اما روش معمول استفاده از آن‌ها از طریق ابزار cargo-hyperlight است.

    اهداف Hyperlight هیچ پشتیبانی‌ای از std ندارند، اما از alloc به‌طور کامل پشتیبانی می‌کنند.

    این اهداف روی aarch64 معماری ARMv8.1-A (همراه با Neon) و روی x86_64 مجموعه‌دستور SSE2 را فرض می‌کنند که کتابخانه‌های هستهٔ Hyperlight به آن‌ها نیاز دارند. انتظار می‌رود این اهداف فقط با نسخه‌های جدید Hyperlight کار کنند.

    Hyperlight برای extern "C" از قرارداد فراخوانی رسمی hardfloat هر معماری استفاده می‌کند.

    فایل‌های دودویی guest در Hyperlight از قالب فایل ELF استفاده می‌کنند.

    ساخت هدف

    این اهداف را می‌توان با افزودن آن‌ها به فهرست target در bootstrap.toml ساخت.

    [build]
build-stage = 1
target = [
    "<HOST_TARGET>",
    "<ARCH>-unknown-hyperlight",
]

[target.<ARCH>-unknown-hyperlight]
no-std = true

    ساخت برنامه‌های Rust

    Rust هنوز مصنوعات از پیش کامپایل‌شده‌ای برای این هدف عرضه نمی‌کند. برای کامپایل برای این هدف، یا باید Rust را با فعال بودن این هدف بسازید (بخش «ساخت هدف» در بالا را ببینید)، یا با استفاده از build-std یا روشی مشابه نسخهٔ خودتان از core را بسازید. هنگام استفاده از cargo-hyperlight، این ابزار این کار را به‌طور خودکار مدیریت می‌کند.

    آزمون

    فایل‌های دودویی ساخته‌شده برای این هدف باید از crate با نام hyperlight-guest-bin استفاده کنند. سپس یک فایل دودویی مشخص را می‌توان توسط یک فرایند میزبان که از hyperlight-host استفاده می‌کند و با آن بر سر یک رابط میزبان/guest توافق دارد بارگذاری کرد. برای جزئیات بیشتر دربارهٔ مدل برنامه‌نویسی و نحوهٔ نوشتن یک میزبان، به این crateها و مستندات Hyperlight در وب‌سایت و مخزن آن مراجعه کنید.

    toolchainهای کامپایل متقاطع و کد C

    این هدف از کد C پشتیبانی می‌کند، از طریق cargo-hyperlight که امکان می‌دهد یک toolchain زبان C با نام <arch>-unknown-none را در قالبی بپیچد که بتواند برای Hyperlight بسازد.
