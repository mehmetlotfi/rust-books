    i686-unknown-hurd-gnu و x86_64-unknown-hurd-gnu

    سطح (Tier): ۳

    [GNU/Hurd] جایگزین پروژه GNU برای هسته یونیکس است.

    نگهدارندگان هدف

    @sthibaul

    الزامات

    این هدف از ابزارهای میزبان (host tools) پشتیبانی می‌کند.

    هدف GNU/Hurd از std پشتیبانی می‌کند و از قالب استاندارد فایل ELF استفاده می‌کند.

    ساخت هدف

    این هدف را می‌توان با افزودن i686-unknown-hurd-gnu و x86_64-unknown-hurd-gnu به‌عنوان هدف در فهرست rustc ساخت.

    ساخت برنامه‌های Rust

    Rust هنوز artifactهای از پیش کامپایل‌شده برای این هدف ارائه نمی‌دهد. برای کامپایل برای این هدف، یا باید Rust را با فعال‌بودن این هدف بسازید (بخش «ساخت هدف» را در بالا ببینید)، یا با استفاده از build-std یا روشی مشابه، نسخه خودتان از core را بسازید.

    آزمون

    آزمون‌ها را می‌توان مانند یک برنامه معمولی اجرا کرد.

    toolchainهای cross-compilation و کد C

    این هدف از کد C پشتیبانی می‌کند؛ toolchain مربوط به GNU این هدف را i686-unknown-gnu و x86_64-unknown-gnu می‌نامد.
