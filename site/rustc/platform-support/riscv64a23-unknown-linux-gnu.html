    riscv64a23-unknown-linux-gnu

    سطح (Tier): ۲ (بدون ابزارهای میزبان)

    هدف RISC-V که از پروفایل RVA23 تصویب‌شده استفاده می‌کند. این هدف به‌طور پیش‌فرض همه قابلیت‌های اجباری rva23u64 را فعال می‌کند.

    نگهدارندگان هدف

    @ZhongyaoChen @CaiWeiran

    الزامات

    این هدف را می‌توان روی پلتفرم زیر با موفقیت ساخت: ubuntu 24.04 (نسخه هسته Linux برابر 6.8.0، glibc 2.39).

    پلتفرم‌های دیگر ممکن است کار کنند، اما آزمایش نشده‌اند. اگر با مشکلی مواجه شدید، لطفاً با ما تماس بگیرید.

    ساخت هدف

    اهداف سطح ۲ از طریق rustup توزیع می‌شوند. هدف را با دستور زیر نصب کنید:

    rustup target add riscv64a23-unknown-linux-gnu

    ساخت برنامه‌های Rust

    crateها را به‌صورت متقاطع و با دستور زیر کامپایل کنید:

    cargo build --target=riscv64a23-unknown-linux-gnu

    برای cross-compilation ممکن است لازم باشد لینکر مناسب را نصب کنید:

    # Ubuntu/Debian
sudo apt-get install gcc-riscv64-linux-gnu

# Then set the linker
RUSTFLAGS="-C linker=riscv64-linux-gnu-gcc" cargo build --target=riscv64a23-unknown-linux-gnu
    → riscv64gc-unknown-linux-musls390x-unknown-linux-gnu ←
