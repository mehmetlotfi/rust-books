    aarch64-unknown-trusty و armv7-unknown-trusty

    Tier: 3

    Trusty یک سیستم‌عامل امن است که یک محیط اجرای مورد اعتماد (Trusted Execution Environment یا TEE) برای Android فراهم می‌کند.

    نگهدارندگان هدف

    @randomPoison @ahomescu

    الزامات

    این هدف‌ها کامپایل متقابل می‌شوند. هیچ الزام ویژه‌ای برای میزبان ندارند.

    اهداف Trusty پشتیبانی جزئی از کتابخانهٔ استاندارد دارند: alloc به‌طور کامل پشتیبانی می‌شود و std پشتیبانی محدودی دارد که مواردی مانند دسترسی به سیستم فایل، ورودی/خروجی شبکه و ایجاد فرایند/نخ را شامل نمی‌شود. توصیف‌گرهای فایل (file descriptor) برای مقاصد IPC پشتیبانی می‌شوند.

    Trusty از قالب فایل ELF استفاده می‌کند.

    ساخت هدف

    این هدف‌ها را می‌توان با فعال‌کردن آن‌ها در ساخت rustc ساخت، برای مثال:

    [build]
build-stage = 1
target = ["aarch64-unknown-trusty", "armv7-unknown-trusty"]

    ساخت برنامه‌های Rust

    در حال حاضر هیچ روش پشتیبانی‌شده‌ای برای ساخت یک برنامهٔ Trusty با Cargo وجود ندارد. می‌توانید دستورالعمل‌های ساخت Trusty را دنبال کنید تا هستهٔ Trusty را همراه با هر برنامهٔ Rust که در پروژه تنظیم شده باشد بسازید.

    آزمون

    برای اطلاع از نحوهٔ ساخت کد Rust در پروژهٔ اصلی Trusty، دستورالعمل‌های ساخت Trusty را ببینید. پروژهٔ اصلی همچنین شامل زیرساختی برای آزمودن برنامه‌های Rust درون یک شبیه‌ساز QEMU است.

    زنجیرهٔ ابزار کامپایل متقابل و کد C

    برای اطلاع از نحوهٔ ساخت کد C در Trusty، دستورالعمل‌های ساخت Trusty را ببینید.
