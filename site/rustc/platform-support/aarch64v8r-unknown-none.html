    aarch64v8r-unknown-none و aarch64v8r-unknown-none-softfloat

    • سطح: 3
    • پشتیبانی کتابخانه: core و alloc (بدون سیستم‌عامل، #![no_std])

    هدف bare-metal برای CPUهای خانوادهٔ معماری Armv8-R که در حالت AArch64 اجرا می‌شوند. پردازنده‌های این خانواده شامل Arm Cortex-R82 هستند.

    برای CPUهای Armv8-R که در حالت AArch32 اجرا می‌شوند (مانند Arm Cortex-R52)، به‌جای این صفحه armv8r-none-eabihf را ببینید.

    نگهدارندگان هدف

    • تیم Arm در گروه کاری Rust Embedded Devices
    • arm-maintainers (rust@arm.com)
      • برای اطلاع‌رسانی به ما از @rustbot ping arm-maintainers استفاده کنید

    گزینه‌های CPU هدف و ویژگی‌های هدف

    برخلاف پردازنده‌های AArch64 نسخهٔ v8-A، همهٔ پردازنده‌های AArch64 نسخهٔ v8-R دارای FPU نیستند (یعنی همهٔ پردازنده‌های Armv8-R AArch64 افزونهٔ اختیاری FEAT_FP در Armv8 را پیاده‌سازی نمی‌کنند). اگر FPU ندارید، یا FPU دارید اما به هر حال می‌خواهید از ABI نرم‌افزاری ممیز شناور (soft-float) استفاده کنید، باید از هدف aarch64v8r-unknown-none-softfloat استفاده کنید. اگر می‌خواهید از قرارداد فراخوانی استاندارد hard-float در Arm AArch64 استفاده کنید و FPU دارید، می‌توانید از هدف aarch64v8r-unknown-none استفاده کنید.

    هنگام استفاده از هدف aarch64v8r-unknown-none، حداقل ویژگی‌های ممیز شناور مفروض، ویژگی‌های Advanced SIMD هستند (FEAT_AdvSIMD یا +neon) که پیاده‌سازی آن با نام تجاری Arm NEON شناخته می‌شود.

    اگر پردازندهٔ شما مجموعهٔ دیگری از ویژگی‌های ممیز شناور را نسبت به انتظارات پیش‌فرض پشتیبانی می‌کند، باید آن‌ها را نیز با -C target-feature=(+/-) به‌دلخواه فعال یا غیرفعال کنید. با این حال توجه کنید که در حال حاضر Rust از ساخت اهداف hard-float AArch64 با غیرفعال‌بودن پشتیبانی Advanced SIMD پشتیبانی نمی‌کند. همچنین می‌توان با گزینهٔ -Ctarget-cpu به Rust (یا LLVM) گفت که مدل مشخصی از پردازندهٔ Arm دارید. انجام این کار ممکن است مجموعهٔ پیش‌فرض ویژگی‌های هدفِ فعال را تغییر دهد.

    الزامات

    این اهداف به‌صورت متقاطع کامپایل می‌شوند و از پیوند ایستا استفاده می‌کنند.

    به‌طور پیش‌فرض از پیوندگر lld همراه Rust استفاده می‌شود؛ با این حال ممکن است بخواهید به‌جای آن از پیوندگر GNU استفاده کنید. این پیوندگر را برای Windows/Mac/Linux می‌توان از وب‌سایت توسعه‌دهندگان Arm یا احتمالاً از مدیر بستهٔ سیستم‌عامل خود دریافت کرد. برای استفاده از آن، موارد زیر را به .cargo/config.toml خود اضافه کنید:

    [target.aarch64-unknown-none]
linker = "aarch64-none-elf-ld"

    همچنین می‌توان با تعیین aarch64-none-elf-gcc به‌عنوان پیوندگر، از پیوندگر GNU استفاده کرد. این کار هنگام استفاده از بهینه‌سازی زمان پیوند (LTO) در GCC لازم است.

    این اهداف اسکریپت پیوندگر ارائه نمی‌کنند، بنابراین باید بسته به دستگاه مشخصی که استفاده می‌کنید، اسکریپت خودتان را بیاورید. برای اینکه پیوندگر هنگام پیوند از your_script.ld استفاده کند، -Clink-arg=-Tyour_script.ld را به‌عنوان آرگومان rustc بدهید.

    toolchainهای کامپایل متقاطع و کد C

    این هدف از کد C که با triple هدف aarch64-none-elf و یک پرچم -march یا -mcpu مناسب کامپایل شده باشد پشتیبانی می‌کند.
