    armv7-unknown-linux-uclibceabi

    Tier: 3

    این هدف از CPU‌های Armv7-A با ممیز شناور نرم‌افزاری (softfloat) پشتیبانی می‌کند و از کتابخانهٔ استاندارد uclibc-ng استفاده می‌کند. این پیکربندی در بسیاری از روترهای خانگی رایج است (مثلاً Netgear R7000، Asus RT-AC68U).

    برای اطلاعاتی که برای همهٔ اهداف Arm Linux صدق می‌کند، arm-linux را ببینید.

    نگهدارندگان هدف

    @lancethepants

    الزامات

    این هدف cross-compile می‌شود و به یک زنجیرابزار متقاطع (cross toolchain) نیاز دارد.

    این هدف از ابزارهای میزبان (host tools) و std پشتیبانی می‌کند.

    ساخت هدف

    باید یک زنجیرابزار متقاطع 'C' را دانلود یا بسازید که Armv7-A softfloat را هدف بگیرد و از کتابخانهٔ استاندارد uclibc-ng استفاده کند. اگر سخت‌افزار هدف شما چیزی مانند یک روتر یا دستگاه نهفته است، به یاد داشته باشید که SDK‌های ارائه‌شده توسط سازنده برای این دسته از CPU‌ها ممکن است قدیمی باشند و احتمالاً برای bootstrap کردن rust مناسب نباشند.

    اینجا نمونه‌ای از یک زنجیرابزار هست که با buildroot ساخته شده است. این زنجیرابزار از مؤلفه‌های مدرن، و هدرهای هستهٔ قدیمی‌تر و در نتیجه فراگیر (2.6.36.4) استفاده می‌کند و در پروژه‌ای به نام Tomatoware به کار می‌رود. این زنجیرابزار وصله (patch) شده تا sysroot آن در /mmc قرار گیرد (مثلاً /mmc/bin، /mmc/lib، /mmc/include). این در سناریوهایی مفید است که سیستم فایل ریشه فقط‌خواندنی است اما می‌توانید حافظهٔ خارجی حاوی برنامه‌های کاربر را متصل کنید. Tomatoware نمونه‌ای از این است که حتی اجازه می‌دهد کامپایلرها و ابزارهای توسعه‌دهنده را به‌صورت بومی روی دستگاه هدف اجرا کنید.

    با استفاده از زنجیرابزار Tomatoware می‌توان این هدف را برای cross-compilation و کامپایل بومی (ابزارهای میزبان) با پروژهٔ

    rust-bootstrap-armv7-unknown-linux-uclibceabi.

    اگر از زنجیرابزار خودتان استفاده می‌کنید، این یک پیکربندی نمونه است.

    [build]
build-stage = 2
target = ["armv7-unknown-linux-uclibceabi"]

[target.armv7-unknown-linux-uclibceabi]
cc = "/path/to/arm-unknown-linux-uclibcgnueabi-gcc"
cxx = "/path/to/arm-unknown-linux-uclibcgnueabi-g++"
ar = "path/to/arm-unknown-linux-uclibcgnueabi-ar"
ranlib = "path/to/arm-unknown-linux-uclibcgnueabi-ranlib"
linker = "/path/to/arm-unknown-linux-uclibcgnueabi-gcc"

    ساخت برنامه‌های Rust

    موارد زیر فرض می‌کنند از زنجیرابزار و محیط Tomatoware استفاده می‌کنید. اگر از زنجیرابزار خودتان استفاده می‌کنید، آن را متناسب تغییر دهید.

    کامپایل بومی

    چون این هدف از ابزارهای میزبان پشتیبانی می‌کند، می‌توانید برنامه‌های rust را مستقیماً روی دستگاه هدف خود به‌صورت بومی بسازید. این کار می‌تواند راحت باشد، چون پیچیدگی‌های cross-compile را حذف می‌کند و می‌توانید فایل‌های باینری خود را بلافاصله آزمایش و مستقر کنید. یک ایراد آن این است که کامپایل روی CPU Armv7-A شما احتمالاً بسیار کندتر از cross-compile روی ماشین x86 شماست.

    برای راه‌اندازی کامپایل بومی:

    • Tomatoware را با استفاده از آخرین نسخهٔ nightly که اینجا یافت می‌شود روی دستگاه خود دانلود کنید.
    • tar zxvf arm-soft-mmc.tgz -C /mmc را اجرا کنید تا استخراج شود
    • /mmc/bin:/mmc:sbin/ را به PATH خود اضافه کنید، یا source /mmc/etc/profile را اجرا کنید
    • apt update && apt install rust

    اگر با پروژهٔ بالا خودتان rust را bootstrap کنید، یک فایل .deb ایجاد می‌شود که سپس می‌توانید آن را با دستور زیر نصب کنید

    dpkg -i rust_1.xx.x-x_arm.deb

    پس از انجام این مراحل می‌توانید در یک محیط بومی از rust به‌طور عادی استفاده کنید.

    کامپایل متقاطع

    برای cross compile کردن باید:

    • زنجیرابزار متقاطع rust را با rust-bootstrap-armv7-unknown-linux-uclibceabi یا زنجیرابزاری که خودتان ساخته‌اید بسازید.

    • زنجیرابزار ساخته‌شدهٔ خود را با دستور زیر پیوند دهید

      rustup toolchain link stage2 \
${HOME}/rust-bootstrap-armv7-unknown-linux-uclibceabi/src/rust/rust/build/x86_64-unknown-linux-gnu/stage2

    • ساخت با:

      CC_armv7_unknown_linux_uclibceabi=/opt/tomatoware/arm-soft-mmc/bin/arm-linux-gcc \
CXX_armv7_unknown_linux_uclibceabi=/opt/tomatoware/arm-soft-mmc/bin/arm-linux-g++ \
AR_armv7_unknown_linux_uclibceabi=/opt/tomatoware/arm-soft-mmc/bin/arm-linux-ar \
CFLAGS_armv7_unknown_linux_uclibceabi="-march=armv7-a -mtune=cortex-a9" \
CXXFLAGS_armv7_unknown_linux_uclibceabi="-march=armv7-a -mtune=cortex-a9" \
CARGO_TARGET_ARMV7_UNKNOWN_LINUX_UCLIBCEABI_LINKER=/opt/tomatoware/arm-soft-mmc/bin/arm-linux-gcc \
CARGO_TARGET_ARMV7_UNKNOWN_LINUX_UCLIBCEABI_RUSTFLAGS='-Clink-arg=-s -Clink-arg=-Wl,--dynamic-linker=/mmc/lib/ld-uClibc.so.1 -Clink-arg=-Wl,-rpath,/mmc/lib' \
cargo +stage2 \
build \
--target armv7-unknown-linux-uclibceabi \
--release

    • فایل باینری را به دستگاه هدف خود کپی کنید و اجرا کنید.

    متغیرهای محیطی CC، CXX، AR، CFLAGS و CXXFLAGS را مشخص می‌کنیم چون گاهی یک پروژه یا زیرپروژه به استفاده از زنجیرابزار متقاطع 'C' شما نیاز دارد. از آنجا که Tomatoware یک sysroot تغییریافته دارد، مکان dynamic-linker و rpath را نیز از طریق RUSTFLAGS ارسال می‌کنیم.

    آزمون با QEMU

    برای آزمایش یک فایل باینری cross-compile‌شده روی سیستم ساخت خود، دستورالعمل‌های Cross Compilation را دنبال کنید، qemu-arm-static را نصب کنید و با دستور زیر اجرا کنید.

    CC_armv7_unknown_linux_uclibceabi=/opt/tomatoware/arm-soft-mmc/bin/arm-linux-gcc \
CXX_armv7_unknown_linux_uclibceabi=/opt/tomatoware/arm-soft-mmc/bin/arm-linux-g++ \
AR_armv7_unknown_linux_uclibceabi=/opt/tomatoware/arm-soft-mmc/bin/arm-linux-ar \
CFLAGS_armv7_unknown_linux_uclibceabi="-march=armv7-a -mtune=cortex-a9" \
CXXFLAGS_armv7_unknown_linux_uclibceabi="-march=armv7-a -mtune=cortex-a9" \
CARGO_TARGET_ARMV7_UNKNOWN_LINUX_UCLIBCEABI_LINKER=/opt/tomatoware/arm-soft-mmc/bin/arm-linux-gcc \
CARGO_TARGET_ARMV7_UNKNOWN_LINUX_UCLIBCEABI_RUNNER="qemu-arm-static -L /opt/tomatoware/arm-soft-mmc/arm-tomatoware-linux-uclibcgnueabi/sysroot/" \
cargo +stage2 \
run \
--target armv7-unknown-linux-uclibceabi \
--release

    اجرا در chroot

    همچنین می‌توان در یک محیط chroot ساخت. این روشی راحت برای کار بدون نیاز به دسترسی به سخت‌افزار هدف است.

    برای ساخت chroot:

    • sudo debootstrap --arch armel bullseye $HOME/debian
    • sudo chroot $HOME/debian/ /bin/bash
    • mount proc /proc -t proc
    • mount -t sysfs /sys sys/
    • export PATH=/mmc/bin:/mmc/sbin:$PATH

    از اینجا می‌توانید محیط خود را راه‌اندازی کنید (مثلاً افزودن کاربر، نصب wget).

    • Tomatoware را با استفاده از آخرین نسخهٔ nightly که اینجا یافت می‌شود در محیط chroot دانلود کنید.
    • tar zxvf arm-soft-mmc.tgz -C /mmc را اجرا کنید تا استخراج شود
    • /mmc/bin:/mmc:sbin/ را به PATH خود اضافه کنید، یا source /mmc/etc/profile را اجرا کنید
    • sudo /mmc/bin/apt update && sudo /mmc/bin/apt install rust

    پس از انجام این مراحل می‌توانید در یک محیط chroot از rust به‌طور عادی استفاده کنید.

    به یاد داشته باشید که هنگام استفاده از sudo، PATH کاربر root ممکن است با PATH کاربر شما متفاوت باشد.
