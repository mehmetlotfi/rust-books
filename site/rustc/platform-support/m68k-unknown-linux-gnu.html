    m68k-unknown-linux-gnu

    سطح (Tier): ۳

    لینوکس برای Motorola 680x0

    نگهدارندگان هدف

    @glaubitz @ricky26

    الزامات

    این هدف برای cross-compilation به یک محیط ساخت Linux/m68k نیاز دارد که روی Debian و سیستم‌های مبتنی بر Debian، openSUSE و توزیع‌های دیگر در دسترس است.

    روی Debian نصب یک cross-compiler از نوع g++ برای معماری m68k کافی است؛ این کار وابستگی‌های دیگر، مانند بسته توسعه cross برای glibc، را به‌طور خودکار نصب می‌کند:

    # apt install g++-m68k-linux-gnu

    فایل‌های دودویی را می‌توان با شبیه‌سازی QEMU user اجرا کرد. روی سیستم‌های مبتنی بر Debian، نصب بسته qemu-user-static برای اجرای فایل‌های دودویی ایستای ساده کافی است:

    # apt install qemu-user-static

    برای اجرای برنامه‌های پیچیده‌تر باید با کمک دستور debootstrap یک chroot از Debian/m68k راه‌اندازی کرد:

    # apt install debootstrap debian-ports-archive-keyring
# debootstrap --keyring=/usr/share/keyrings/debian-ports-archive-keyring.gpg --arch=m68k unstable debian-68k http://ftp.ports.debian.org/debian-ports

    سپس به لطف شبیه‌سازی QEMU user می‌توان با دستور معمولی chroot به‌راحتی وارد این chroot شد:

    # chroot /path/to/debian-68k

    برای شروع ساخت بومی، که در حال حاضر آزمایش نشده است، می‌توان یک سیستم بومی Debian/m68k را یا روی سخت‌افزار واقعی مانند سیستم‌های Commodore Amiga یا Atari مبتنی بر 68k، یا در محیط‌های شبیه‌سازی‌شده مانند QEMU نسخه 4.2 یا جدیدتر یا ARAnyM نصب کرد.

    تصاویر ISO برای نصب را تیم Debian Ports فراهم کرده است و می‌توان آن‌ها را از سرور تصاویر CD دبیان به نشانی زیر به دست آورد:

    https://cdimage.debian.org/cdimage/ports/12.0/m68k/

    مستندات Debian/m68k در ویکی Debian به نشانی زیر در دسترس است:

    https://wiki.debian.org/M68k

    پشتیبانی از طریق فهرست پستی debian-68k در دسترس است:

    https://lists.debian.org/debian-68k/

    یا از طریق کانال IRC با نام #debian-68k در شبکه OFTC.

    ساخت

    codegen این هدف باید به‌طور پیش‌فرض ساخته شود. با این حال core و std در حال حاضر در دسترس نیستند، اما روی آن‌ها کار می‌شود و در آینده نزدیک باید در دسترس قرار بگیرند.

    کامپایل متقاطع

    این هدف را می‌توان از یک توزیع استاندارد Debian یا مبتنی بر Debian، openSUSE یا هر توزیع دیگری که یک cross-toolchain پایه برای m68k در اختیار دارد cross-compile کرد.

    آزمون

    در حال حاضر پشتیبانی‌ای برای اجرای مجموعه آزمون‌های rustc روی این هدف وجود ندارد.

    ساخت برنامه‌های Rust

    برنامه‌های Rust را می‌توان برای این هدف ساخت:

    rustc --target m68k-unknown-linux-gnu your-code.rs

    برنامه‌های بسیار ساده را می‌توان با برنامه qemu-m68k-static اجرا کرد:

    $ qemu-m68k-static your-code

    برای برنامه‌های پیچیده‌تر، برای آزمایش به یک chroot یا یک سیستم Debian/m68k بومی (یا شبیه‌سازی‌شده) نیاز است.
