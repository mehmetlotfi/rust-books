    powerpc64-sony-ps3

    Tier: 3

    هدفی برای Sony PlayStation 3 (که به‌اختصار «PS3» گفته می‌شود)، برای PowerPC Processor Element (PPU) از Cell Broadband Engine Architecture (CBEA).

    نگهدارندگان هدف

    • @ZephyrCodesStuff (توسعه‌دهنده و نگهدارندهٔ اصلی)
    • @RipleyTom (نگهدارندهٔ پشتیبان)

    الزامات

    این هدف یک پلتفرم PowerPC64 ELFv1 با ترتیب بایت big-endian (همان PPE در Cell Broadband Engine) است و فقط برای استفاده روی سیستم‌های Sony PlayStation 3 و تحت سیستم‌عامل رسمی آن، «CellOS»، در نظر گرفته شده است.

    پیوندده باید از PowerPC64 ELFv1 با ترتیب Big-Endian پشتیبانی کند: پیوندده‌ای که توصیه و آزمایش شده mold است. lld در LLVM جابه‌جایی‌های (relocation) فراخوانی ELFv1 را در محیط‌های freestanding با no_std به‌درستی مدیریت نمی‌کند و به همین دلیل ناسازگار است. (ببینید: rust-lang/rust#85589، llvm/llvm-project#27630)

    باینری‌های حاصل پس از پیوند نیاز به وصله‌زنی (patch) بیشتری دارند تا با سیستم‌عامل PlayStation 3 سازگار شوند و قابل بوت باشند. یک ابزار وصله‌زن متن‌باز اینجا در دسترس است. به‌طور کلی، یک وصله‌زن باید این کارها را انجام دهد:

    • بازنویسی OS/ABI در ELF به 0x66 (ELFOSABI_CELLLV2)
    • حذف هر هدر GNU/Linux
    • افزودن پرچم‌ها، بخش‌ها (.sys_proc_param و .sys_proc_prx_param) و هدرهای مخصوص Sony
    • افزودن «stub»ها برای کتابخانه‌های پیوند پویای SPRX شرکت Sony، با افزودن یک بخش (.lib.stub) تا CellOS بتواند آن‌ها را پیوند دهد
    • وصله‌زنی توصیف‌گرهای تابع OPD (در بخش .opd)

    نکته: ممکن است این فهرست برای همهٔ موارد استفاده جامع نباشد، اما برای تولید یک باینری قابل اجرا کافی است. تولید یک کتابخانهٔ پویای PRX ممکن است به مراحل بیشتر یا متفاوتی نیاز داشته باشد.

    این هدف به‌طور کامل پشتیبانی می‌کند از:

    • قابلیت‌های core در Rust
    • قابلیت alloc در Rust، چون هستهٔ CellOS Lv2 تخصیص حافظهٔ مجازی (sys_memory_allocate) را فراهم می‌کند که می‌توان روی آن یک تخصیص‌دهندهٔ heap (مانند talc) پیاده‌سازی کرد.
    • افزونه‌های برداری SIMD با نام AltiVec / VMX (که LLVM از طریق +altivec به‌صورت بومی پشتیبانی می‌کند)

    ساخت هدف

    اگر rustc با فعال‌بودن این هدف ساخته شود، برای ساخت آرتیفکت‌های میزبان کامپایلر به‌طور الزامی هیچ زنجیرهٔ ابزار کامپایل متقابل C خارجی لازم نیست، اما mold باید برای انجام پیوند روی سیستم میزبان نصب شده باشد.

    استفاده از lld به‌عنوان پیوندده بعید است، تا زمانی که پشتیبانی از ELFv1 در lld پیاده‌سازی شود.

    ساخت برنامه‌های Rust

    چون این هدف در Tier 3 قرار دارد، آرتیفکت‌های از پیش کامپایل‌شدهٔ کتابخانهٔ استاندارد (core، alloc) از طریق rustup توزیع نمی‌شوند. برنامه‌ها باید با یک زنجیرهٔ ابزار nightly همراه با مؤلفهٔ rust-src و -Z build-std ساخته شوند.

    یک SDK آمادهٔ توسعه برای Rust به‌صورت متن‌باز اینجا وجود دارد و با مجوز MIT OR Apache-2.0 منتشر شده است.

    فایل .cargo/config.toml پروژهٔ خود را پیکربندی کنید:

    [target.powerpc64-sony-ps3]
linker = "mold"
rustflags = [
    "-C", "relocation-model=static",
    "-C", "code-model=small",
    "-C", "target-feature=+altivec",
]

    پیش‌نیازها:

    • یک کامپایلر Rust نسخهٔ nightly همراه با مؤلفهٔ rust-src
    • پیوندده mold
    • ابزار پس از پیوند moldier
    • (اختیاری) make_fself یا scetool برای تبدیل خروجی .ELF به یک EBOOT.BIN رمزگذاری‌شده/امضاشده برای اجرا روی سخت‌افزار واقعی.

    فرایند ساخت:

    # Compile the binary
cargo +nightly build \
    --target powerpc64-sony-ps3 \
    -Z build-std=core,alloc \
    --release

# Patch the linked executable
moldier patch target/powerpc64-sony-ps3/release/my_program.ELF

# (Optional) Sign the binary for official hardware
make_fself "target/powerpc64-sony-ps3/release/my_program.ELF" "target/powerpc64-sony-ps3/release/my_program.BIN"

    آزمون

    این هدف اجرای باینری‌ها (پس از وصله‌زنی) را، هم روی سخت‌افزار رسمی و هم روی شبیه‌سازهای متن‌باز، به‌طور کامل پشتیبانی می‌کند.

    چون firmware رسمی سیستم اجرای کد امضانشده را ممنوع می‌کند، برای اجرای باینری‌ها ابتدا باید سیستم jailbreak شود. این کار اختیاری نیست.

    شبیه‌سازها هیچ الزامی دربارهٔ امضای کد ندارند، بنابراین آزمون روی شبیه‌سازها ساده است.

    اشکال‌زدایی کاملاً ممکن است، یا از طریق APIهای debug firmware روی سخت‌افزار رسمی، یا روی شبیه‌سازها از طریق اشکال‌زداهای یکپارچهٔ آن‌ها یا یک سرور GDB که شبیه‌ساز فراهم می‌کند.
