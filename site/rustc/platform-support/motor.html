    x86_64-unknown-motor

    سطح (Tier): ۳

    Motor OS یک سیستم‌عامل جدید برای محیط‌های مجازی‌سازی‌شده است.

    نگهدارندگان هدف

    @lasiotus

    الزامات

    این هدف cross-compile می‌شود. برای میزبان هیچ پیش‌نیاز خاصی وجود ندارد.

    Motor OS از قالب فایل ELF استفاده می‌کند.

    ساخت toolchain هدف

    toolchain هدف Motor OS را می‌توان با x.py ساخت:

    فایل bootstrap:

    [build]
host = ["x86_64-unknown-linux-gnu"]
target = ["x86_64-unknown-linux-gnu", "x86_64-unknown-motor"]

    دستور ساخت:

    ./x.py build --stage 2 clippy library

    ساخت برنامه‌های Rust

    مثال Hello Motor OS را ببینید.

    آزمون

    فایل‌های دودویی Rust که به‌صورت متقاطع کامپایل شده‌اند و مصنوعات (artifact) آزمون را می‌توان در ماشین‌های مجازی Motor OS اجرا کرد، همان‌طور که در مستند ساخت و مثال Hello Motor OS شرح داده شده است.

    toolchainهای cross-compilation و کد C

    کد C را می‌توان به‌عنوان بخشی از پروژه‌های cargo در Rust کامپایل کرد. با این حال پشتیبانی از libc وجود ندارد.
