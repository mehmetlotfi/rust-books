    aarch64-unknown-illumos و x86_64-unknown-illumos

    سطح (Tier): ۲/۳

    illumos یک سیستم‌عامل یونیکس است که قابلیت‌های نسل بعدی را برای توزیع‌های پایین‌دستی فراهم می‌کند، از جمله اشکال‌زدایی پیشرفته سیستم، سیستم فایل نسل بعدی، شبکه و گزینه‌های مجازی‌سازی.

    نگهدارندگان هدف

    @jclulow @pfmooney

    الزامات

    این هدف از ابزارهای میزبان (host tools) پشتیبانی می‌کند.

    هدف illumos از std پشتیبانی می‌کند و از قالب استاندارد فایل ELF استفاده می‌کند.

    x86_64-unknown-illumos یک هدف سطح ۲ همراه با ابزارهای میزبان است. aarch64-unknown-illumos یک هدف سطح ۳ است.

    ساخت هدف

    این اهداف را می‌توان با افزودن aarch64-unknown-illumos و x86_64-unknown-illumos به‌عنوان هدف در فهرست rustc ساخت.

    ساخت برنامه‌های Rust

    Rust برای هدف x86_64-unknown-illumos artifactهای از پیش کامپایل‌شده ارائه می‌دهد. Rust برای aarch64-unknown-illumos artifactهای از پیش کامپایل‌شده ارائه نمی‌دهد؛ ساخت این هدف یا به همان روشی که در بالا نشان داده شد لازم است یا با استفاده از -Zbuild-std.

    آزمون

    آزمون‌ها را می‌توان مانند یک برنامه معمولی اجرا کرد.

    toolchainهای cross-compilation و کد C

    این هدف از کد C پشتیبانی می‌کند.

    پروژه illumos artifactهای sysroot از پیش ساخته‌شده را در دسترس قرار می‌دهد که می‌توان برای cross-compilation از آن‌ها استفاده کرد. فایل‌های دودویی رسمی Rust با استفاده از این artifactها cross-compile می‌شوند.
