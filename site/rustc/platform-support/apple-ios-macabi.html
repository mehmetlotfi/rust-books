کتاب rustcThe rustc Book

    *-apple-ios-macabi

    اهداف Mac Catalyst اپل.

    سطح: 2 (بدون ابزارهای میزبان)

    • aarch64-apple-ios-macabi: Mac Catalyst روی ARM64.
    • x86_64-apple-ios-macabi: Mac Catalyst روی x86 ۶۴ بیتی.

    نگهدارندگان هدف

    @badboy @BlackHoleFox @madsmtm

    الزامات

    این اهداف به‌صورت متقاطع کامپایل می‌شوند و به macOS SDK متناظر (MacOSX.sdk) نیاز دارند که شامل سرایندهای ./System/iOSSupport است تا امکان پیوند با سرایندهای مخصوص iOS فراهم شود؛ این SDK از Xcode 11 یا بالاتر ارائه می‌شود.

    مسیر SDK را می‌توان با متغیر محیطی رایج SDKROOT به rustc داد، یا هنگام کامپایل روی macOS میزبان تقریباً با همان منطقِ xcrun --sdk macosx --show-sdk-path استنباط می‌شود.

    نسخهٔ سیستم‌عامل

    حداقل نسخهٔ پشتیبانی‌شده iOS 13.1 روی x86 و 14.0 روی Aarch64 است.

    این نسخه را می‌توان برای هر فایل دودویی با تغییر هدف استقرار بالاتر برد. rustc متغیرهای محیطی رایجی را که Xcode برای این کار استفاده می‌کند رعایت می‌کند؛ در این مورد IPHONEOS_DEPLOYMENT_TARGET.

    ساخت هدف

    این اهداف از طریق rustup توزیع می‌شوند و می‌توان آن‌ها را با یکی از دستورهای زیر نصب کرد:

    $ rustup target add aarch64-apple-ios-macabi
$ rustup target add x86_64-apple-ios-macabi

    Sanitizerها

    به دلیل پشتیبانی ضعیف CMake از Mac Catalyst، runtimeهای sanitizer در حال حاضر در دسترس نیستند؛ #129069 را ببینید.

    ساخت برنامه‌های Rust

    اگر rustc با پشتیبانی از این اهداف ساخته شده باشد، می‌توان برنامه‌های Rust را با تعیین --target برای آن‌ها ساخت. برای مثال:

    $ rustc --target aarch64-apple-ios-macabi your-code.rs

    می‌توان این هدف را با cfg به‌صورت target_env = "macabi" (یا target_abi = "macabi" پیش از Rust 1.91.0) از اهداف iOS تشخیص داد.

    if cfg!(target_env = "macabi") {
    // Do something only on Mac Catalyst.
}

    این مشابه TARGET_OS_MACCATALYST در کد C است.

    آزمون

    فایل‌های دودویی Mac Catalyst را می‌توان مستقیماً روی macOS 10.15 Catalina یا جدیدتر اجرا کرد.

    فایل‌های دودویی x86 را می‌توان با استفاده از Rosetta روی Apple Silicon اجرا کرد.

    توجه کنید که استفاده از برخی قابلیت‌های UIKit مستلزم بسته‌بندی (bundle) فایل دودویی است.
