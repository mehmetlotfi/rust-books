کتاب rustcThe rustc Book

    *-l4re-uclibc

    سطح (Tier): ۳

    L4Re یک سیستم‌عامل و hypervisor متن‌باز مبتنی بر ریزهسته (microkernel) است.

    سه‌گانه‌های (triplet) هدف موجود تا کنون:

    • x86_64-unknown-l4re-uclibc
    • aarch64-unknown-l4re-uclibc

    نگهدارندگان هدف

    • Marius Melzer (@farao)

    الزامات

    اهداف L4Re از یک محیط میزبان، که معمولاً لینوکس است، cross-compile می‌شوند. برای گزینه‌های راه‌اندازی L4Re، Getting Started را ببینید.

    سورس L4Re را می‌توانید در مخازن Github پیدا کنید.

    ساخت toolchain مربوط به Rust برای L4Re

    یک یا چند هدف L4Re از اهداف بالا را پیکربندی کنید و سه‌گانه میزبان را هم در config.toml اضافه کنید و Rust را مطابق مستندات بسازید. toolchain را با کپی کردن build/host/stage2/ در یک مکان دلخواه آماده کنید.

    برای هر هدف، با اجرای make sysroot در دایرکتوری ساخت L4Re یک دایرکتوری sysroot برای L4Re بسازید. محتوای sysroot/usr/lib/ را در دایرکتوری self-contained مربوط به هدف متناظر در درخت دایرکتوری toolchain مربوط به Rust کپی کنید.

    از rustup برای نصب محلی toolchain مربوط به Rust برای L4Re استفاده کنید:

    rustup toolchain link l4re <path-to-toolchain>

    اکنون از toolchain از طریق cargo (یا مستقیماً rustc) که با rustup نصب شده است استفاده کنید:

    cargo +l4re build --target <l4re-triple>

    یا

    rustc +l4re --target <l4re-triple> <rs-file>

    اسکریپت ساخت

    https://github.com/l4re/rust-l4re-toolchain/ یک اسکریپت wrapper برای ساخت L4Re و rustc برای arm64 و x86-64 دارد، همچنین برنامه‌های آزمایشی کوچکی برای راستی‌آزمایی در QEMU که نشان می‌دهند فایل‌های دودویی قابل اجرا تولید می‌شوند.

    اجرای برنامه‌های Rust روی L4Re

    می‌توانید یک برنامه L4Re که با Rust نوشته شده است را درست مانند هر فایل دودویی L4Re دیگری که خارج از سامانه ساخت L4Re ساخته شده باشد اجرا کنید. یک گزینه خوب این است که یک تصویر (image) L4Re بسازید، فایل دودویی برنامه را به آن تصویر اضافه کنید و آن را از طریق اسکریپت ned اجرا کنید. سپس می‌توان تصویر را روی سخت‌افزار گذاشت یا روی Qemu اجرا کرد.

    برای اطلاعات بیشتر l4re.org را ببینید.
