    *-win7-windows-msvc

    سطح: 3

    اهداف ویندوزی که به پشتیبانی از Windows 7 ادامه می‌دهند.

    سه‌تایی‌های هدف (target triple):

    • i686-win7-windows-msvc
    • x86_64-win7-windows-msvc

    نگهدارندگان هدف

    @roblabla

    الزامات

    این هدف از همهٔ بخش‌های core، alloc، std و test پشتیبانی می‌کند. این هدف هر شب به‌طور خودکار روی زیرساخت خصوصی میزبانی‌شده توسط نگهدارنده آزمون می‌شود. ابزارهای میزبان (host tools) نیز ممکن است کار کنند، هرچند تضمینی وجود ندارد. آخرین نسخهٔ شناخته‌شده از rustc با ابزارهای میزبان (x86_64) که با موفقیت ساخته شده، 1.91.0 است.

    این اهداف برای extern “C” از قرارداد فراخوانی ویندوز پیروی می‌کنند.

    مانند هر هدف ویندوزی دیگر، باینری‌های تولیدشده در قالب PE هستند.

    ساخت هدف

    می‌توانید Rust را با پشتیبانی از این اهداف بسازید، به این صورت که آن‌ها را به فهرست هدف در bootstrap.toml اضافه کنید:

    [build]
build-stage = 1
target = ["x86_64-win7-windows-msvc"]

    ساخت برنامه‌های Rust

    Rust برای این هدف artifactهای از پیش کامپایل‌شده ارائه نمی‌کند. برای کامپایل به این هدف، باید یا Rust را با فعال بودن این هدف بسازید (به «ساخت هدف» در بالا مراجعه کنید)، یا با استفاده از build-std یا روشی مشابه نسخهٔ خودتان را بسازید.

    آزمون

    باینری‌های تولیدشده روی ویندوز یا Wine با سخت‌افزار بومی به‌خوبی کار می‌کنند. آزمون از راه دور با استفاده از remote-test-server که این‌جا توضیح داده شده، امکان‌پذیر است.

    toolchainهای cross-compilation و کد C

    کد C سازگار را می‌توان یا با cl.exe از MSVC یا با clang-cl از LLVM ساخت.

    cross-compilation با استفاده از clang-cl/lld-link امکان‌پذیر است. این کار همچنین به Windows SDK نیاز دارد که می‌توان آن را با xwin تهیه کرد.

    • clang-cl و lld-link را روی دستگاه خود نصب کنید و مطمئن شوید که در $PATH شما قرار دارند.

    • xwin را نصب کنید: cargo install --locked xwin

    • با xwin ابزار Windows SDK را نصب کنید: xwin splat --output winsdk

    • یک اسکریپت xwin-lld-link با محتوای زیر بسازید:

      #!/usr/bin/env bash
set -e
XWIN=/path/to/winsdk
lld-link "$@" /libpath:$XWIN/crt/lib/x86_64 /libpath:$XWIN/sdk/lib/um/x86_64 /libpath:$XWIN/sdk/lib/ucrt/x86_64

    • یک اسکریپت xwin-clang-cl با محتوای زیر بسازید:

      #!/usr/bin/env bash
set -e
XWIN=/path/to/winsdk
clang-cl /imsvc "$XWIN/crt/include" /imsvc "$XWIN/sdk/include/ucrt" /imsvc "$XWIN/sdk/include/um" /imsvc "$XWIN/sdk/include/shared" --target="x86_64-pc-windows-msvc" "$@"

    • در bootstrap.toml خود این خطوط را اضافه کنید:

      [target.x86_64-win7-windows-msvc]
linker = "path/to/xwin-lld-link"
cc = "path/to/xwin-clang-cl"

    اکنون باید بتوانید کتابخانهٔ استاندارد Rust (std) و هر برنامهٔ Rust را cross-compile کنید.
