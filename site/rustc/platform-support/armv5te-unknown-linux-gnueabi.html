کتاب rustcThe rustc Book

    armv5te-unknown-linux-gnueabi

    Tier: 2

    این هدف از برنامه‌های Linux با glibc روی CPU‌های ARMv5TE بدون واحد ممیز شناور پشتیبانی می‌کند.

    برای اطلاعاتی که برای همهٔ اهداف Arm Linux صدق می‌کند، arm-linux را ببینید.

    نگهدارندگان هدف

    در حال حاضر هیچ نگه‌دارندهٔ هدفی به‌طور رسمی مستند نشده است.

    الزامات

    این هدف فقط برای cross-compilation است. ابزارهای میزبان (host tools) پشتیبانی نمی‌شوند. std به‌طور کامل پشتیبانی می‌شود.

    ساخت هدف

    چون این هدف tier 2 است، مصنوعات (artifact) آن از rustup در دسترس هستند.

    ساخت برنامه‌های Rust

    برای ساخت برنامه‌های Rust ممکن است بخواهید GCC را به‌عنوان لینکر در .cargo/config.toml به‌صورت زیر مشخص کنید:

    [target.armv5te-unknown-linux-gnueabi]
linker = "arm-linux-gnueabi-gcc"
