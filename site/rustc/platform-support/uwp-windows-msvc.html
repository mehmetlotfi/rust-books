    x86_64-uwp-windows-msvc، i686-uwp-windows-msvc، thumbv7a-uwp-windows-msvc و aarch64-uwp-windows-msvc

    Tier: 3

    هدف‌های ویندوز برای برنامه‌های Universal Windows Platform (UWP) با استفاده از زنجیرهٔ ابزار MSVC.

    نگهدارندگان هدف

    @bdbai

    الزامات

    این هدف‌ها با پشتیبانی از std کامپایل متقابل می‌شوند. الزامات میزبان و قالب باینری مانند هدف‌های متناظر غیر UWP است (یعنی x86_64-pc-windows-msvc، i686-pc-windows-msvc، thumbv7a-pc-windows-msvc و aarch64-pc-windows-msvc).

    ساخت هدف‌ها

    این هدف‌ها را می‌توان با فعال‌کردن آن‌ها در ساخت rustc ساخت، برای مثال:

    [build]
build-stage = 1
target = ["x86_64-uwp-windows-msvc", "aarch64-uwp-windows-msvc"]

    ساخت برنامه‌های Rust

    Rust هنوز آرتیفکت‌های از پیش کامپایل‌شده‌ای برای این هدف‌ها ارائه نمی‌کند. برای کامپایل برای این هدف‌ها، یا باید Rust را با فعال‌بودن این هدف‌ها بسازید (بخش «ساخت هدف‌ها» بالا را ببینید)، یا با استفاده از build-std یا روشی مشابه، نسخهٔ خودتان از std را بسازید.

    نمونه‌ای از ساخت یک پروژهٔ Rust برای x64 UWP با استفاده از build-std:

    cargo build -Z build-std=std,panic_abort --target x86_64-uwp-windows-msvc

    آزمون

    در حال حاضر پشتیبانی‌ای برای اجرای مجموعه آزمون rustc روی این هدف وجود ندارد.

    زنجیرهٔ ابزار کامپایل متقابل و کد C

    به‌طور کلی، هدف زنجیرهٔ ابزار باید با هدف‌های متناظر غیر UWP مطابقت داشته باشد. توجه کنید که همهٔ APIهای Win32 در UWP به یک شکل رفتار نمی‌کنند و برخی در AppContainer محدود شده‌اند یا اصلاً در دسترس نیستند. اگر کد C در حال کامپایل از APIهای محدودشده یا در دسترس‌نبوده استفاده می‌کند، جایگزین‌های مجاز را به کار ببرید یا مجموعه‌ویژگی‌های مشخصی را غیرفعال کنید تا از آن‌ها استفاده نشود.
