    armv7-sony-vita-newlibeabihf

    Tier: 3

    این tier از پردازندهٔ ARM Cortex A9 که روی کنسول PlayStation Vita اجرا می‌شود پشتیبانی می‌کند.

    پشتیبانی Rust از این هدف وابسته به Sony نیست، و از هیچ SDK رسمی Sony مشتق نشده و با آن به کار نمی‌رود.

    نگهدارندگان هدف

    @nikarh @pheki @zetanumbers

    الزامات

    این هدف cross-compile می‌شود و نصب زنجیرابزار VITASDK روی سیستم شما لازم است. پیوند پویا (dynamic linking) پشتیبانی نمی‌شود.

    crate‌های #![no_std] را می‌توان با استفاده از build-std برای ساخت core، و در صورت لزوم alloc و panic_abort ساخت.

    std به‌صورت جزئی پشتیبانی می‌شود، اما بیشتر کار می‌کند. برخی API‌ها پیاده‌سازی نشده‌اند و صرفاً خطا برمی‌گردانند، مانند std::process.

    این هدف به‌طور پیش‌فرض فایل‌های باینری را در قالب ELF با thumb ISA تولید می‌کند.

    فایل‌های باینری با arm-vita-eabi-gcc که زنجیرابزار VITASDK فراهم می‌کند پیوند داده می‌شوند.

    ساخت هدف

    Rust مصنوعات (artifact) از پیش کامپایل‌شده‌ای برای این هدف ارائه نمی‌کند. می‌توانید از پرچم build-std برای ساخت فایل‌های باینری ELF همراه با std استفاده کنید:

    cargo build -Z build-std=std,panic_abort --target=armv7-sony-vita-newlibeabihf --release

    ساخت برنامه‌های Rust

    روش پیشنهادی برای ساخت مصنوعاتی که بتوان آن‌ها را روی PlayStation Vita نصب و اجرا کرد، استفاده از ابزار cargo-vita است. این ابزار از build-std و زنجیرابزار VITASDK برای ساخت مصنوعات قابل اجرا روی Vita استفاده می‌کند.

    برای نصب این ابزار دستور زیر را اجرا کنید:

    cargo install --locked cargo-vita

    زنجیرابزار VITASDK باید نصب شده باشد و متغیر محیطی VITASDK باید روی مسیر آن تنظیم شود، مثلاً:

    export VITASDK=/opt/vitasdk

    بخش زیر را به Cargo.toml پروژهٔ خود اضافه کنید:

    [package.metadata.vita]
# A unique 9 character alphanumeric identifier of the app.
title_id = "RUSTAPP01"
# A title that will be used for the app. Optional, name will be used if not defined
title_name = "My application"

    برای ساخت یک VPK همراه با ELF در پروفایل release، دستور زیر را اجرا کنید:

    cargo vita build vpk --release

    پس از ساخت یک فایل *.vpk می‌توان آن را روی PlayStation Vita بارگذاری و نصب کرد، یا با شبیه‌ساز Vita3K به کار برد.

    آزمون

    اجراکنندهٔ آزمون پیش‌فرض Rust پشتیبانی می‌شود و آزمون‌ها را می‌توان با ابزار cargo-vita به یک elf کامپایل کرد و در یک فایل *.vpk بسته‌بندی نمود. فیلتر کردن آزمون‌ها در حال حاضر پشتیبانی نمی‌شود، زیرا ارسال آرگومان‌های خط فرمان به فایل اجرایی روی Vita پشتیبانی نمی‌شود، بنابراین اجراکننده همیشه همهٔ آزمون‌ها را اجرا می‌کند.

    مجموعه آزمون Rust برای library/std هنوز پشتیبانی نمی‌شود.

    کامپایل متقاطع

    این هدف را می‌توان از x86_64 روی سیستم‌های Windows، MacOS یا Linux به‌صورت cross-compile ساخت. میزبان‌های دیگر برای cross-compilation پشتیبانی نمی‌شوند.
