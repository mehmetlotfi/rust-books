    الزامات

    دریافت یک toolchain برای C

    تهیهٔ یک toolchain زبان C

    کامپایل Rust برای این هدف روی میزبان‌های x86_64 لینوکس آزمایش شده است. انواع دیگر میزبان آزمایش نشده‌اند، اما اگر toolchain کامپایل متقاطع مناسبی برایشان پیدا کنید، ممکن است کار کنند.

    اگر هنوز toolchain مناسبی ندارید، می‌توانید آن را از اینجا دانلود کنید و در یک دایرکتوری از حالت فشرده خارج کنید.

    پیکربندی Rust

    این هدف را می‌توان با فعال کردن آن برای ساخت rustc و قرار دادن موارد زیر در bootstrap.toml ساخت:

    [build]
target = ["x86_64-unknown-linux-gnu", "csky-unknown-linux-gnuabiv2", "csky-unknown-linux-gnuabiv2hf"]
stage = 2

[target.csky-unknown-linux-gnuabiv2]
# ADJUST THIS PATH TO POINT AT YOUR TOOLCHAIN
cc = "${TOOLCHAIN_PATH}/bin/csky-linux-gnuabiv2-gcc"

[target.csky-unknown-linux-gnuabiv2hf]
# ADJUST THIS PATH TO POINT AT YOUR TOOLCHAIN
cc = "${TOOLCHAIN_PATH}/bin/csky-linux-gnuabiv2-gcc"

    ساخت

    # in rust dir
./x.py build --stage 2

    ساخت و اجرای برنامه‌های Rust

    برای آزمودن فایل‌های دودویی کامپایل‌متقاطع‌شده روی یک سیستم x86_64 می‌توانید از qemu-cskyv2 استفاده کنید. این کار با ترجمهٔ پویای دودویی و ترجمهٔ پویای فراخوانی سیستمی، از نیاز به شبیه‌سازی کامل یک سیستم ARM جلوگیری می‌کند. به شما امکان می‌دهد برنامه‌های CSKY را مستقیماً روی کرنل x86_64 خود اجرا کنید. بسیار راحت است!

    برای استفاده:

    • qemu-cskyv2 را نصب کنید (اگر هنوز qemu ندارید، می‌توانید آن را از اینجا دانلود کنید و در یک دایرکتوری از حالت فشرده خارج کنید.)
    • toolchain ساخته‌شدهٔ خود را به این صورت پیوند دهید:
      • rustup toolchain link stage2 ${RUST}/build/x86_64-unknown-linux-gnu/stage2
    • یک برنامهٔ آزمایشی بسازید
    cargo new hello_world
cd hello_world
    • بسازید و اجرا کنید
    CARGO_TARGET_CSKY_UNKNOWN_LINUX_GNUABIV2_RUNNER=${QEMU_PATH}/bin/qemu-cskyv2 -L ${TOOLCHAIN_PATH}/csky-linux-gnuabiv2/libc \
CARGO_TARGET_CSKY_UNKNOWN_LINUX_GNUABIV2_LINKER=${TOOLCHAIN_PATH}/bin/csky-linux-gnuabiv2-gcc \
RUSTFLAGS="-C target-feature=+crt-static" \
cargo +stage2 run --target csky-unknown-linux-gnuabiv2

    توجه: برنامهٔ پیوندشده به‌صورت پویا ممکن است با qemu-cskyv2 اجرا نشود، اما روی هدف اصلی قابل اجرا است.
