    armv7r-none-eabi* و thumbv7r-none-eabi*

    • Tier: 2
    • پشتیبانی از کتابخانه: core و alloc (bare-metal، #![no_std])

    هدف bare-metal برای CPU‌های خانوادهٔ معماری Armv7-R که هم از A32 (Arm) ISA و هم از T32 (Thumb) ISA پشتیبانی می‌کنند.

    اهداف armv7r-none-eabi* به‌طور پیش‌فرض از حالت A32 (Arm) استفاده می‌کنند و اهداف thumbv7r-none-eabi* به‌طور پیش‌فرض از حالت T32 (Thumb).

    پردازنده‌های این خانواده شامل موارد زیر هستند:

    • Arm Cortex-R4
    • Arm Cortex-R5
    • Arm Cortex-R7
    • Arm Cortex-R8

    برای اطلاعاتی که برای همهٔ اهداف arm-none-eabi صدق می‌کند، به‌ویژه تفاوت بین ABI‌های eabi و eabihf، arm-none-eabi را ببینید.

    الزامات

    هنگام استفاده از اهداف hardfloat (یعنی -eabibf)، حداقل ویژگی‌های ممیز شناوری که فرض می‌شود ویژگی‌های vfpv3-d16 است که شامل دقت یگانه و مضاعف با 16 ثبات دقت مضاعف می‌شود. برای جزئیات بیشتر دربارهٔ گونه‌های ممکن FPU، VFP در پردازنده‌های Cortex-R را ببینید.

    اگر پردازندهٔ شما از مجموعه‌ای از ویژگی‌های ممیز شناور پشتیبانی می‌کند که با انتظارات پیش‌فرض vfpv3-d16 متفاوت است (مثلاً اگر فقط از دقت یگانه پشتیبانی می‌کند و از دقت مضاعف نه)، آن ویژگی‌ها را نیز باید در صورت نیاز با -C target-feature=(+/-) (یا با استفاده از یک هدف JSON سفارشی) فعال یا غیرفعال کنید. اگر ویژگی‌ها را حذف می‌کنید، باید کتابخانهٔ استاندارد Rust را نیز از روی کد منبع دوباره کامپایل کنید (مثلاً با -Zbuild-std=core).

    برای جزئیات نحوهٔ استفاده از این پرچم‌ها، مستندات Arm bare-metal را ببینید.
