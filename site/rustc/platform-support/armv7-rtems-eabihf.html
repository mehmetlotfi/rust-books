    armv7-rtems-eabihf

    Tier: 3

    اهداف ARM برای سیستم‌عامل بی‌درنگ RTEMS که از کامپایلر متقاطع (cross-compiler) gcc مربوط به RTEMS برای پیوند با کتابخانه‌های یک Board Support Package (BSP) مشخص استفاده می‌کنند.

    نگهدارندگان هدف

    @thesummer

    الزامات

    این هدف از ابزارهای میزبان (host tools) پشتیبانی نمی‌کند. فقط cross-compilation ممکن است. زنجیرابزار cross-compiler را می‌توان با پیروی از دستورالعمل‌های نصب مستندات RTEMS به دست آورد. علاوه بر cross-compiler، یک BSP کامپایل‌شده برای بردی که با این معماری سازگار است نیز باید روی میزبان در دسترس باشد. تاکنون BSP با نام xilinx_zynq_a9_qemu از RTEMS 6 آزمایش شده است.

    پشتیبانی از std وجود دارد، اما هنوز به‌طور کامل آزمایش نشده است. از آن در نرم‌افزار پروازی استفاده نکنید!

    این هدف برای extern "C" از قرارداد فراخوانی EABI پیروی می‌کند.

    فایل‌های باینری حاصل در قالب ELF هستند.

    ساخت هدف

    این هدف را می‌توان با کامپایلر استاندارد Rust ساخت.

    ساخت برنامه‌های Rust

    Rust هنوز مصنوعات (artifact) از پیش کامپایل‌شده‌ای برای این هدف ارائه نمی‌کند. برای کامپایل به این هدف، یا باید Rust را با فعال بودن این هدف بسازید (بخش «ساخت هدف» را در بالا ببینید)، یا با استفاده از build-std یا مشابه آن نسخهٔ خودتان از core را بسازید.

    برای ساخت یک فایل اجرایی RTEMS لازم است یک پیکربندی پایهٔ RTEMS (به زبان C) نیز کامپایل شده باشد تا با آن پیوند داده شود، چون این پیکربندی سیستم‌عامل را تنظیم می‌کند. نمونه‌ای از آن را می‌توانید در crate با نام rtems-sys ببینید که می‌توان آن را به‌عنوان وابستگی به برنامهٔ خود افزود.

    آزمون

    فایل‌های باینری حاصل روی هدف شبیه‌سازی‌شده به‌خوبی اجرا می‌شوند (احتمالاً روی Zedboard واقعی یا مشابه آن نیز). برای مثال، روی qemu می‌توان فایل باینری را با دستور زیر اجرا کرد:

    qemu-system-arm -no-reboot -serial null -serial mon:stdio -net none -nographic -M xilinx-zynq-a9 -m 512M -kernel <binary file>

    اجرای پایهٔ مجموعهٔ اجرای آزمون‌های واحد به نظر کار می‌کند. با این حال، اجرای مجموعه آزمون Rust روی سخت‌افزار (شبیه‌سازی‌شده) هنوز آزمایش نشده است.

    زنجیرابزارهای cross-compilation و کد C

    کد C سازگار را می‌توان با زنجیرابزار cross-compiler مربوط به RTEMS یعنی arm-rtems6-gcc ساخت. برای اطلاعات بیشتر دربارهٔ نحوهٔ ساخت زنجیرابزار، خود RTEMS و برنامه‌های RTEMS، لطفاً مستندات RTEMS را ببینید.
