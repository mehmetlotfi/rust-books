    riscv32{i,im,ima,imc,imfc,imac,imafc}-unknown-none-elf

    سطح (Tier): ۲

    هدف bare-metal برای پردازنده‌های RISC-V با ISAهای RV32I، RV32IM، RV32IMC، RV32IMAFC و RV32IMAC.

    سطح (Tier): ۳

    هدف bare-metal برای پردازنده‌های RISC-V با ISAهای RV32IMA و RV32IMFC.

    هدف riscv32imfc-unknown-none-elf هسته‌های RV32IMFC را پوشش می‌دهد که ممیز شناور تک‌دقت سخت‌افزاری دارند (افزونه F با ABI از نوع ilp32f) اما افزونه اتمی (A) را ندارند. مانند riscv32imc-unknown-none-elf، این هدف با +forced-atomics ساخته می‌شود: بارگیری/ذخیره‌های اتمی به بارگیری/ذخیره‌های ساده تبدیل می‌شوند (که روی یک hart درست است) و دستورهای lr/sc/amo* هرگز تولید نمی‌شوند؛ بنابراین روی هسته‌ای که افزونه A ندارد trap رخ نمی‌دهد. مقایسه‌وتعویض (compare-and-swap) و سایر عملیات اتمی خواندن-تغییر-نوشتن غیرفعال هستند (atomic_cas = false)؛ crateهای پایین‌دستی که به آن‌ها نیاز دارند از یک polyfill مبتنی بر critical-section استفاده می‌کنند (مثلاً portable-atomic).

    الزامات

    این هدف به‌صورت متقاطع کامپایل می‌شود و از پیوند ایستا استفاده می‌کند. هیچ toolchain خارجی لازم نیست و پیوندگر پیش‌فرض rust-lld کار می‌کند، اما باید یک اسکریپت پیوندگر مشخص کنید. crate با نام riscv-rt یک اسکریپت مناسب را فراهم می‌کند. مخزن riscv-rust-quickstart نمونه‌ای از یک پروژهٔ RV32 را نشان می‌دهد.

    ساخت هدف

    این هدف همراه Rust ارائه می‌شود و با rustup قابل نصب است.

    آزمون

    این یک هدف cross-compile شده از نوع no-std است که باید یا در یک شبیه‌ساز اجرا شود یا روی سخت‌افزار مناسب برنامه‌ریزی شود. اجرای مجموعه آزمون‌های Rust روی این هدف ممکن نیست.

    toolchainهای cross-compilation و کد C

    این هدف از کد C پشتیبانی می‌کند. اگر با C یا C++ لینک متقابل انجام می‌دهید، ممکن است لازم باشد به‌جای rust-lld از riscv32-unknown-elf-gcc به‌عنوان لینکر استفاده کنید.
