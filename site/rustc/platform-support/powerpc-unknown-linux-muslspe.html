    powerpc-unknown-linux-muslspe

    Tier: 3

    این هدف بسیار شبیه هدف‌های موجودی مانند powerpc-unknown-linux-musl و powerpc-unknown-linux-gnuspe است. این یکی پشتیبانی PowerPC SPE را برای musl دارد. متأسفانه آخرین نسخهٔ gcc که از PowerPC SPE پشتیبانی می‌کند 8.4.0 است.

    برای اطلاعات دربارهٔ PowerPC SPE، مستندات پشتیبانی پلتفرم powerpc-unknown-linux-gnuspe را هم ببینید.

    نگهدارندگان هدف

    @BKPepe

    الزامات

    این هدف کامپایل متقابل می‌شود. از std پشتیبانی نمی‌شود. تخصیص‌دهندهٔ پیش‌فرضی وجود ندارد، اما با فراهم‌کردن یک تخصیص‌دهنده می‌توان از alloc استفاده کرد.

    این هدف باینری‌هایی با قالب ELF تولید می‌کند.

    ساخت هدف

    این هدف در سامانهٔ ساخت OpenWrt برای روترهای CZ.NIC Turris 1.x با Freescale P2020 آزمایش و استفاده شده است.

    ساخت برنامه‌های Rust

    Rust هنوز آرتیفکت‌های از پیش کامپایل‌شده‌ای برای این هدف ارائه نمی‌کند. برای کامپایل برای این هدف، یا باید Rust را با فعال‌بودن این هدف بسازید (بخش «ساخت هدف» بالا را ببینید)، یا با استفاده از build-std یا روشی مشابه، نسخهٔ خودتان از core را بسازید.

    آزمون

    این هدف کامپایل متقابل می‌شود و از اجرای مجموعه آزمون rustc پشتیبانی نمی‌شود.
