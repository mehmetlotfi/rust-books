    *-unikraft-linux-musl

    Tier: 3

    هدف‌هایی برای کیت توسعهٔ Unikernel با نام Unikraft (همراه با musl).

    سه‌گانه‌های هدف موجود تاکنون:

    • x86_64-unikraft-linux-musl

    نگهدارندگان هدف

    @mkroening

    الزامات

    این هدف‌ها فقط از کامپایل متقابل پشتیبانی می‌کنند. این هدف‌ها از std پشتیبانی می‌کنند.

    Unikraft وانمود می‌کند که دقیقاً مانند لینوکس رفتار می‌کند. اینکه چه مقدار از آن قابلیت‌ها در دسترس باشد، به پیکربندی هر unikernel بستگی دارد. برای مثال، پیکربندی پایهٔ Unikraft + musl به‌صورت پیش‌فرض از poll یا شبکه پشتیبانی نمی‌کند. آن قابلیت‌ها به‌ترتیب نیازمند فعال‌کردن LIBPOSIX_EVENT یا lwIP هستند.

    هدف‌های Unikraft از قرارداد فراخوانی extern "C" لینوکس پیروی می‌کنند.

    برای این هدف‌ها، rustc مرحلهٔ نهایی پیوند را انجام نمی‌دهد. در عوض، سامانهٔ ساخت Unikraft تصویر نهایی Unikernel را برای پلتفرم انتخاب‌شده (مثلاً KVM، فضای کاربر لینوکس و Xen) تولید می‌کند.

    ساخت هدف‌ها

    می‌توانید با افزودن این هدف به فهرست target در bootstrap.toml، Rust را با پشتیبانی از آن بسازید:

    [build]
build-stage = 1
target = ["x86_64-unikraft-linux-musl"]

    ساخت برنامه‌های Rust

    Rust هنوز آرتیفکت‌های از پیش کامپایل‌شده‌ای برای این هدف‌ها ارائه نمی‌کند. برای کامپایل برای این هدف‌ها، یا باید Rust را با فعال‌بودن این هدف‌ها بسازید (بخش «ساخت هدف‌ها» بالا را ببینید)، یا با استفاده از build-std یا روشی مشابه، نسخهٔ خودتان از core را بسازید.

    پیوند به یک shim از KraftKit نیاز دارد. برای اطلاعات بیشتر unikraft/kraftkit#612 را ببینید.

    آزمون

    این هدف‌ها اجرای باینری‌ها را به‌شکل تصویرهای unikernel پشتیبانی می‌کنند. نحوهٔ اجرای تصویر unikernel به پلتفرم مشخص بستگی دارد (مثلاً KVM، فضای کاربر لینوکس و Xen). این هدف‌ها از اجرای مجموعه آزمون Rust پشتیبانی نمی‌کنند.

    زنجیرهٔ ابزار کامپایل متقابل و کد C

    این هدف‌ها از کد C پشتیبانی می‌کنند. برای ساخت کد C سازگار، باید از همان کامپایلر و پرچم‌هایی استفاده کنید که سامانهٔ ساخت Unikraft برای پیکربندی خاص شما به کار می‌برد. ساده‌ترین راه برای این کار، ساخت کد C با سامانهٔ ساخت Unikraft هنگام ساخت تصویر unikernel شماست.
