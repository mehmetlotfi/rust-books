    *-unknown-hermit

    سطح (Tier): ۳

    هدف unikernel به نام Hermit به شما امکان می‌دهد برنامه‌هایتان را به تصاویر unikernel مستقل و تخصصی کامپایل کنید که می‌توانند در ماشین‌های مجازی کوچک اجرا شوند.

    سه‌گانه‌های (triplet) هدف موجود تا کنون:

    • x86_64-unknown-hermit
    • aarch64-unknown-hermit
    • aarch64_be-unknown-hermit
    • riscv64gc-unknown-hermit

    نگهدارندگان هدف

    @stlankes @mkroening

    الزامات

    این اهداف فقط از cross-compilation پشتیبانی می‌کنند. این اهداف از std پشتیبانی می‌کنند.

    هنگام ساخت فایل‌های دودویی برای این هدف، unikernel مربوط به Hermit از ابتدا ساخته می‌شود. توسعه‌دهنده برنامه خودش هدف را تخصصی می‌کند و انتظارات متناظر را تعیین می‌کند.

    اهداف Hermit از قرارداد فراخوانی extern "C" لینوکس پیروی می‌کنند.

    فایل‌های دودویی Hermit قالب ELF دارند.

    ساخت هدف

    می‌توانید Rust را با پشتیبانی از این اهداف بسازید؛ برای این کار آن‌ها را به فهرست target در bootstrap.toml اضافه کنید. برای اجرای اسکریپت‌های ساخت Hermit باید هدف میزبان خود را نیز فعال کنید. اسکریپت‌های ساخت به llvm-tools وابسته‌اند و فایل‌های دودویی با rust-lld لینک می‌شوند، بنابراین آن‌ها نیز باید فعال باشند.

    [build]
build-stage = 1
target = [
    "<HOST_TARGET>",
    "x86_64-unknown-hermit",
    "aarch64-unknown-hermit",
    "aarch64_be-unknown-hermit",
    "riscv64gc-unknown-hermit",
]

[rust]
lld = true
llvm-tools = true

    ساخت برنامه‌های Rust

    Rust هنوز artifactهای از پیش کامپایل‌شده برای این اهداف ارائه نمی‌دهد. برای کامپایل برای این اهداف، یا باید Rust را با فعال‌بودن این اهداف بسازید (بخش «ساخت هدف» را در بالا ببینید)، یا با استفاده از build-std یا روشی مشابه، نسخه خودتان از core را بسازید.

    از آنجا که همهٔ برنامه‌های Hermit به‌صورت unikernel هستند، ساخت یک برنامهٔ Rust مستلزم گنجاندن کد سیستم‌عامل نیز هست. راهنمای انجام این کار در قالب آغازین ما، hermit-rs-template، ارائه شده است.

    آزمون

    این اهداف از اجرای فایل‌های دودویی به شکل تصاویر unikernel مستقل پشتیبانی می‌کنند. این تصاویر را می‌توان با loader مربوط به Hermit یا با hypervisor آن (Uhyve) اجرا کرد (chainload). از QEMU می‌توان برای بوت کردن فایل‌های دودویی Hermit با استفاده از loader روی هر معماری استفاده کرد. این اهداف از اجرای مجموعه آزمون‌های Rust پشتیبانی نمی‌کنند.

    toolchainهای cross-compilation و کد C

    این اهداف هنوز از استفاده هم‌زمان کد C و کد Rust پشتیبانی نمی‌کنند.
