    i686-apple-darwin

    macOS شرکت Apple روی x86 ۳۲ بیتی.

    نگهدارندگان هدف

    @thomcc @madsmtm

    الزامات

    برای پیش‌نیازهای عمومی macOS، مستندات *-apple-darwin را ببینید.

    ساخت هدف

    به SDK مربوط به macOS 10.13 نیاز دارید که همراه Xcode 9 عرضه می‌شود. مکان SDK را می‌توان با متغیر محیطی رایج SDKROOT به rustc داد.

    پس از آن، می‌توانید Rust را با پشتیبانی از این هدف بسازید؛ برای این کار آن را به فهرست target در bootstrap.toml اضافه کنید:

    [build]
target = ["i686-apple-darwin"]

    استفاده از -Zbuild-std ناپایدار با یک Cargo نسخه nightly نیز ممکن است کار کند.

    ساخت برنامه‌های Rust

    Rust دیگر artifactهای از پیش کامپایل‌شده برای این هدف ارائه نمی‌دهد. برای کامپایل برای این هدف، یا باید Rust را با فعال‌بودن این هدف بسازید (بخش «ساخت هدف» را در بالا ببینید)، یا با استفاده از build-std یا روشی مشابه، نسخه خودتان را بسازید.

    آزمون

    اجرای این هدف به یک Macbook اینتلی نیاز دارد که macOS 10.14 یا قدیمی‌تر را اجرا کند، زیرا نسخه‌های جدیدتر پشتیبانی از اجرای فایل‌های دودویی ۳۲ بیتی را حذف کرده‌اند.
