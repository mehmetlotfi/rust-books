    x86_64-unknown-linux-none

    Tier: 3

    باینری مستقل (freestanding) x86-64 برای linux بدون وابستگی به libc.

    نگهدارندگان target

    @rosymati

    الزامات

    این target به‌صورت متقابل کامپایل می‌شود و از هر میزبانی قابل ساخت است.

    این target از ابزارهای میزبان، std یا alloc پشتیبانی نمی‌کند.

    یکی از انگیزه‌های اصلی این target نوشتن یک لینکر پویا و libc به زبان Rust است. به همین دلیل، این target به‌طور پیش‌فرض کد مستقل از موقعیت و فایل‌های اجرایی مستقل از موقعیت (PIE) تولید می‌کند. باینری‌های PIE در زمان اجرا به جابه‌جایی (relocation) نیاز دارند. این کار معمولاً توسط لینکر پویا یا libc انجام می‌شود. می‌توانید با -Crelocation-model=static یک باینری وابسته به موقعیت بسازید که در زمان اجرا به relocation نیاز ندارد.

    ساخت target

    این target را می‌توان با فعال‌کردن آن در ساخت rustc ساخت:

    [build]
build-stage = 1
target = ["x86_64-unknown-linux-none"]

    ساخت برنامه‌های Rust

    Rust هنوز artifactهای از پیش کامپایل‌شده برای این target ارائه نمی‌کند. برای کامپایل برای این target، یا باید Rust را با فعال‌بودن target بسازید (بخش «ساخت target» بالا را ببینید)، یا با استفاده از build-std یا روشی مشابه نسخهٔ خودتان از core را بسازید.
