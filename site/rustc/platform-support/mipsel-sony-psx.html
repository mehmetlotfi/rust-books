    mipsel-sony-psx

    سطح (Tier): ۳

    Sony PlayStation 1 (psx)

    توسعه‌دهنده تعیین‌شده

    @ayrtonm

    الزامات

    این هدف cross-compile می‌شود. برای میزبان هیچ پیش‌نیاز خاصی ندارد.

    ساخت

    با فعال کردن این هدف در ساخت rustc می‌توان آن را ساخت:

    [build]
build-stage = 1
target = ["mipsel-sony-psx"]

    کامپایل متقاطع

    این هدف را می‌توان از هر میزبانی cross-compile کرد.

    آزمون

    در حال حاضر پشتیبانی‌ای برای اجرای مجموعه آزمون‌های rustc روی این هدف وجود ندارد.

    ساخت برنامه‌های Rust

    از آنجا که این هدف در سطح ۳ است، Rust مصنوعات (artifact) از پیش کامپایل‌شده‌ای برای آن ارائه نمی‌کند.

    کافی است از قابلیت (feature) نایتلی build-std در cargo برای ساخت کتابخانه‌های core و alloc استفاده کنید:

    cargo build -Zbuild-std=core,alloc --target mipsel-sony-psx

    دستور بالا یک فایل ELF تولید می‌کند. برای تولید فایل‌های دودویی با قالب PSEXE که شبیه‌سازها اجرا می‌کنند، می‌توانید از cargo-psx استفاده کنید:

    cargo psx build

    یا از -Clink-arg=--oformat=binary برای تولید یک فایل دودویی تخت (flat) استفاده کنید.

    → mips64-unknown-linux-muslabi64mipsel-unknown-linux-gnu ←
