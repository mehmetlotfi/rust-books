    x86_64-unknown-linux-gnutsan

    Tier: 2

    هدفی که x86_64-unknown-linux-gnu را بازتاب می‌دهد و ThreadSanitizer به‌طور پیش‌فرض در آن فعال است. هدف از این target امکان ارائهٔ کتابخانه‌های استاندارد دارای ابزارگذاری TSAN از طریق rustup است تا بتوان بدون نیاز به قابلیت‌های nightly (build-std) به یک باینری کاملاً ابزارگذاری‌شده رسید. پس از پایدار شدن build-std، دیگر به این target نیازی نخواهد بود و حذف خواهد شد.

    نگهدارندگان target

    • @jakos-sec
    • @1c3t3a
    • @rust-lang/project-exploit-mitigations

    الزامات

    این target فقط برای کامپایل متقابل (cross-compilation) است. ابزارهای میزبان پشتیبانی نمی‌شوند، زیرا نیازی به ابزارگذاری ابزارهای میزبان با TSAN نیست. std به‌طور کامل پشتیبانی می‌شود.

    در سایر جنبه‌ها این target معادل x86_64-unknown-linux-gnu است.

    ساخت target

    این target را می‌توان با فعال‌کردن آن در ساخت rustc ساخت:

    [build]
target = ["x86_64-unknown-linux-gnutsan"]

    ساخت برنامه‌های Rust

    برنامه‌های Rust را می‌توان با افزودن این target از طریق rustup کامپایل کرد:

    $ rustup target add x86_64-unknown-linux-gnutsan

    و سپس با این target کامپایل کرد:

    $ rustc foo.rs --target x86_64-unknown-linux-gnutsan

    آزمون

    باینری‌های ایجادشده بدون هیچ پیش‌نیاز خارجی روی Linux اجرا می‌شوند.

    ابزارهای cross-compilation و کد C

    این target از کد C پشتیبانی می‌کند و باید از همان toolchain target مربوط به x86_64-unknown-linux-gnu استفاده کند.

    → x86_64-unknown-linux-gnumsanxtensa-*-none-elf ←
