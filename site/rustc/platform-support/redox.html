    *-unknown-redox

    سطح (Tier): ۲/۳

    اهدافی برای سیستم‌عامل Redox OS.

    سه‌گانه‌های (triplet) هدف موجود تا این لحظه:

    • x86_64-unknown-redox (سطح ۲)
    • aarch64-unknown-redox (سطح ۳)
    • i586-unknown-redox (سطح ۳)
    • riscv64gc-unknown-redox (سطح ۳)

    نگهدارندگان هدف

    @jackpot51

    الزامات

    این اهداف به‌صورت بومی کامپایل می‌شوند و امکان cross-compile هم دارند. Std به‌طور کامل پشتیبانی می‌شود.

    انتظار می‌رود این اهداف فقط با آخرین نسخه Redox OS کار کنند، زیرا ABI هنوز پایدار نیست.

    extern "C" از قرارداد فراخوانی رسمی معماری مربوطه استفاده می‌کند.

    فایل‌های دودویی Redox OS از ELF به‌عنوان قالب فایل استفاده می‌کنند.

    ساخت هدف

    می‌توانید Rust را با پشتیبانی از این اهداف بسازید؛ برای این کار آن‌ها را به فهرست target در bootstrap.toml اضافه کنید. افزون بر این، باید یک نسخه از relibc در مسیر جست‌وجوی لینکر وجود داشته باشد.

    [build]
build-stage = 1
target = [
    "<HOST_TARGET>",
    "x86_64-unknown-redox",
    "aarch64-unknown-redox",
    "i586-unknown-redox",
    "riscv64gc-unknown-redox",
]

    ساخت برنامه‌های Rust و آزمون

    Rust هنوز artifactهای از پیش کامپایل‌شده‌ای برای Redox OS ارائه نمی‌دهد، به‌جز برای x86_64-unknown-redox.

    ساده‌ترین راه برای ساخت و آزمون برنامه‌ها برای Redox OS استفاده از redoxer است؛ این ابزار toolchain لازم برای ساخت را راه‌اندازی می‌کند و برنامه‌ها را درون یک ماشین مجازی Redox OS با QEMU اجرا می‌کند.

    toolchainهای cross-compilation و کد C

    این هدف از کد C پشتیبانی می‌کند. toolchainهای C از پیش کامپایل‌شده را می‌توانید در https://static.redox-os.org/toolchain/ بیابید.
