    x86_64-fortanix-unknown-sgx

    سطح: 2

    enclaveهای امن با استفاده از Intel Software Guard Extensions (SGX) بر پایهٔ ABI تعریف‌شده توسط Fortanix برای Enclave Development Platform (EDP).

    نگهدارندگان هدف

    @jethrogb @raoulstrackx @aditijannu

    مخاطبان بیشتر:

    تیم EDP در Fortanix.

    الزامات

    این هدف از std با یک allocator پیش‌فرض پشتیبانی می‌کند. فقط cross compilation پشتیبانی می‌شود.

    باینری‌ها از همهٔ CPUهایی که Intel SGX را دارند پشتیبانی می‌کنند. فقط حالت 64 بیتی پشتیبانی می‌شود.

    همهٔ ویژگی‌های std پشتیبانی نمی‌شوند؛ برای جزئیات به Using Rust’s std مراجعه کنید.

    قرارداد فراخوانی extern "C" همان System V AMD64 ABI است.

    ABI پشتیبانی‌شده fortanix-sgx-abi است.

    خروجی کامپایلر ELF است، اما قالب بومی این پلتفرم قالب SGX stream (SGXS) است. به یک مبدل مانند ftxsgx-elf2sgxs نیاز است.

    برنامه‌ها در قالب SGXS که با Fortanix SGX ABI سازگارند را می‌توان با هر runner سازگار، مانند ftxsgx-runner، اجرا کرد.

    برای توصیه‌هایی دربارهٔ راه‌اندازی یک محیط توسعه و اجرا، راهنمای نصب EDP را ببینید.

    ساخت هدف

    به‌عنوان یک هدف سطح 2، این هدف توسط پروژهٔ Rust ساخته می‌شود.

    می‌توانید bootstrap را به این شکل پیکربندی کنید:

    [build]
build-stage = 1
target = ["x86_64-fortanix-unknown-sgx"]

    ساخت برنامه‌های Rust

    جریان‌های ساخت استاندارد با cargo یا rustc باید کار کنند.

    آزمون

    مجموعهٔ آزمون Rust و همچنین آزمون‌های واحد و یکپارچگی سفارشی، در صورتی که یک cargo runner به‌درستی پیکربندی شده باشد، روی سخت‌افزاری که Intel SGX در آن فعال است اجرا می‌شوند؛ بخش الزامات را ببینید.

    toolchainهای cross-compilation و کد C

    کد C به‌طور کلی پشتیبانی نمی‌شود، چون libc وجود ندارد. کد C که برای x86-64 در حالت freestanding با استفاده از System V AMD64 ABI کامپایل شده باشد ممکن است کار کند. crate با نام rs-libc شامل زیرمجموعه‌ای از libc است که شناخته شده با این هدف کار می‌کند.
