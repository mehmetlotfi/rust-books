    x86_64-pc-cygwin

    سطح: 3

    اهداف ویندوزی که از Cygwin پشتیبانی می‌کنند. اهداف *-cygwin به‌عنوان هدف بومی برای برنامه‌ها در نظر گرفته نشده‌اند؛ توسعه‌دهنده‌ای که برنامه‌های ویندوزی می‌نویسد باید به‌جای آن‌ها از اهداف *-pc-windows-* استفاده کند که ویندوز بومی هستند.

    Cygwin صرفاً به‌عنوان یک لایهٔ شبیه‌سازی برای برنامه‌های مخصوص یونیکس در نظر گرفته شده که از اهداف بومی ویندوز پشتیبانی نمی‌کنند.

    نگهدارندگان هدف

    @Berrysoft

    الزامات

    این هدف به‌صورت cross compile ساخته می‌شود. به x86_64-pc-cygwin-gcc به‌عنوان لینکر نیاز دارد.

    مقدار target_os این هدف cygwin است و از نوع unix است.

    ساخت هدف

    برای cross-compilation به LLVM نسخهٔ 20.1.0-rc1 یا بالاتر نیاز دارید. در حال حاضر ساخت بومی روی Cygwin وجود ندارد. issue پیگیری برای ابزارهای میزبان روی Cygwin #137819 است.

    ساخت برنامه‌های Rust

    Rust هنوز artifactهای از پیش کامپایل‌شده برای این هدف ارائه نمی‌کند. برای کامپایل به این هدف، باید یا Rust را با فعال بودن این هدف بسازید (به «ساخت هدف» در بالا مراجعه کنید)، یا با استفاده از build-std یا روشی مشابه نسخهٔ خودتان از core را بسازید.
