    نگهدارندگان هدف

    ⚠️ این اهداف هیچ نگهدارنده‌ای ندارند و به‌درستی نگهداری نمی‌شوند. ⚠️

    اگر از این هدف استفاده می‌کنید، ثبت‌نام برای تبدیل شدن به نگهدارندهٔ هدف را در نظر بگیرید. برای جزئیات به سیاست سطح‌بندی اهداف (target tier policy) مراجعه کنید. بدون نگهدارنده، ممکن است این اهداف در آینده تنزل سطح پیدا کنند.

    الزامات

    این اهداف از std و ابزارهای میزبان پشتیبانی می‌کنند.

    برخلاف همتاهای MSVC خود، اهداف windows-gnu از cross-compilation پشتیبانی می‌کنند و از هر گونه پیامد مجوزدهی MSVC به دورند.

    آن‌ها برای extern "C" از قرارداد فراخوانی ویندوز پیروی می‌کنند.

    مانند هر هدف ویندوزی دیگر، باینری‌های تولیدشده در قالب PE هستند.

    toolchain زبان C

    این اهداف با استفاده از یک toolchain نسبتاً مدرن زبان C ساخته و آزمون می‌شوند، و باید آن را قدیمی‌ترین نسخهٔ پشتیبانی‌شده در نظر گرفت:

    • GNU Binutils 2.44
    • GCC 14.2
    • mingw-w64 12.0.0
    • کتابخانهٔ MSVCRT به‌عنوان پیش‌فرض
    • Libgcc با مدیریت استثنای DWARF-2 برای i686 و SEH برای x86_64

    استفاده از ابزارهای قدیمی‌تر (به‌ویژه Binutils) ممکن است به‌درستی کار نکند، به‌دلیل تعداد مشکلاتی که نسخه‌های قدیمی‌تر Binutils را آزار می‌دهند. نسخه‌های پشتیبانی‌شدهٔ toolchain ممکن است تغییر کنند.

    ساخت برنامه‌های Rust

    Rust یک کتابخانهٔ std از پیش کامپایل‌شده برای این اهداف ارائه می‌کند. این یعنی در صورت نصب بودن toolchain مناسب زبان C، می‌توان به‌سادگی از سایر میزبان‌ها برای این اهداف کامپایل و cross-compile کرد.
