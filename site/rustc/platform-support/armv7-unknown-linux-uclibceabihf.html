کتاب rustcThe rustc Book

    armv7-unknown-linux-uclibceabihf

    Tier: 3

    این tier از پردازندهٔ Armv7-A که هستهٔ Linux و کتابخانهٔ استاندارد uClibc-ng را اجرا می‌کند پشتیبانی می‌کند. پشتیبانی کامل از rust و کتابخانهٔ استاندارد rust را فراهم می‌کند.

    برای اطلاعاتی که برای همهٔ اهداف Arm Linux صدق می‌کند، arm-linux را ببینید.

    نگهدارندگان هدف

    @skrap

    الزامات

    این هدف cross-compile می‌شود و به یک زنجیرابزار متقاطع (cross toolchain) نیاز دارد. می‌توانید زنجیرابزارهای مناسب از پیش ساخته‌شده را در bootlin پیدا کنید یا خودتان از طریق buildroot یکی بسازید.

    ساخت

    دریافت زنجیرابزار C

    کامپایل rust برای این هدف روی میزبان‌های linux با معماری x86_64 آزمایش شده است. انواع دیگر میزبان آزمایش نشده‌اند، اما اگر زنجیرابزار cross-compilation مناسبی برایشان پیدا کنید ممکن است کار کنند.

    اگر هنوز زنجیرابزار مناسبی ندارید، یکی را از اینجا دانلود کنید و آن را در یک دایرکتوری باز کنید.

    پیکربندی rust

    این هدف را می‌توان با فعال کردن آن در ساخت rustc و قرار دادن موارد زیر در bootstrap.toml ساخت:

    [build]
target = ["armv7-unknown-linux-uclibceabihf"]
build-stage = 2

[target.armv7-unknown-linux-uclibceabihf]
# ADJUST THIS PATH TO POINT AT YOUR TOOLCHAIN
cc = "/TOOLCHAIN_PATH/bin/arm-buildroot-linux-uclibcgnueabihf-gcc"

    ساخت

    # in rust dir
./x.py build --stage 2

    ساخت و اجرای برنامه‌های Rust

    برای آزمایش فایل‌های باینری cross-compile‌شده روی یک سیستم x86_64 می‌توانید از برنامهٔ شبیه‌سازی فضای کاربر یعنی qemu-arm استفاده کنید. این برنامه با ترجمهٔ پویای باینری و ترجمهٔ پویای فراخوانی سیستمی، از شبیه‌سازی کامل یک سیستم ARM جلوگیری می‌کند. به شما اجازه می‌دهد برنامه‌های ARM را مستقیماً روی هستهٔ x86_64 خود اجرا کنید. بسیار راحت است!

    برای استفاده:

    • qemu-arm را مطابق توزیع خود نصب کنید.
    • زنجیرابزار ساخته‌شدهٔ خود را از این طریق پیوند دهید:
      • rustup toolchain link stage2 ${RUST}/build/x86_64-unknown-linux-gnu/stage2
    • یک برنامهٔ آزمایشی ایجاد کنید
    cargo new hello_world
cd hello_world
    • بسازید و اجرا کنید
    CARGO_TARGET_ARMV7_UNKNOWN_LINUX_UCLIBCEABIHF_RUNNER="qemu-arm -L ${TOOLCHAIN}/arm-buildroot-linux-uclibcgnueabihf/sysroot/" \
CARGO_TARGET_ARMV7_UNKNOWN_LINUX_UCLIBCEABIHF_LINKER=${TOOLCHAIN}/bin/arm-buildroot-linux-uclibcgnueabihf-gcc \
cargo +stage2 run --target armv7-unknown-linux-uclibceabihf
