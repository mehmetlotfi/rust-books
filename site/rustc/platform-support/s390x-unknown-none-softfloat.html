    s390x-unknown-none-softfloat

    سطح (Tier): ۲

    کد IBM z/Architecture ‏(s390x) در قالب ELF برای هسته‌ها و موارد مشابه.

    نگهدارندگان هدف

    @uweigand @cuviper

    الزامات

    این هدف فقط برای توسعه هسته روی s390x در نظر گرفته شده است. این هدف cross-compile می‌شود. از std پشتیبانی نمی‌شود. هیچ allocator پیش‌فرضی وجود ندارد، اما با فراهم کردن یک allocator می‌توان از alloc استفاده کرد.

    این هدف وجود FPU را فرض نمی‌کند و از هیچ ثبات غیر GPR استفاده نمی‌کند. این ویژگی اجازه می‌دهد کد تولیدشده در محیط‌هایی اجرا شود، مانند هسته‌ها، که ممکن است نیاز داشته باشند از چنین ثبات‌هایی استفاده نکنند یا درباره استفاده از آن‌ها ملاحظات ویژه‌ای داشته باشند (مثلاً ذخیره و بازیابی آن‌ها برای جلوگیری از خراب شدن کد فضای کاربر که از همان ثبات‌ها استفاده می‌کند). می‌توانید تولید کد را از طریق گزینه‌های codegen به‌نام -C target-feature= در rustc، یا از طریق سازوکار #[target_feature] در کد Rust، طوری تغییر دهید که از ویژگی‌های اضافی CPU استفاده کند.

    به‌طور پیش‌فرض، کدی که با هدف soft-float تولید می‌شود باید روی هر Z System از Z10 به بعد اجرا شود. فعال کردن ویژگی‌های اضافی هدف یا تغییر -Ctarget-cpu ممکن است ISA موردنیاز را از سطح پایه z10 بالاتر ببرد.

    extern "C" از ABI پایدار استفاده نمی‌کند و ممکن است میان نسخه‌های کامپایلر یا بک‌اند codegen تغییر کند.

    این هدف فقط فایل‌های شیء (object) را در قالب ELF تولید می‌کند. هر قالب جایگزین یا ملاحظات ویژه برای چیدمان فایل دودویی به گزینه‌های لینکر یا اسکریپت‌های لینکر نیاز خواهد داشت.

    • اصول عملکرد z/Architecture (Principles of Operation)

    ساخت هدف

    می‌توانید Rust را با پشتیبانی از این هدف بسازید؛ برای این کار آن را به فهرست target در bootstrap.toml اضافه کنید:

    [build]
target = ["s390x-unknown-none-softfloat"]

    ساخت برنامه‌های Rust

    این هدف برای ساخت فایل‌های دودویی مستقل در نظر گرفته نشده است. فقط باید آن را همراه با toolchain ساخت هسته به کار ببرید.

    آزمون

    از آنجا که کد تولیدشده با این هدف همیشه قرار است بخشی از هسته باشد، الزام اضافه‌ای برای آزمون وجود ندارد.

    اگر می‌خواهید آزمون بومی انجام دهید اما ماشین s390x اختصاصی خودتان را ندارید، چند راه برای دسترسی به چنین ماشینی وجود دارد:

    • IBM LinuxONE Community Cloud یک پورتال سلف‌سرویس ارائه می‌کند که در آن می‌توانید نمونه‌های ماشین مجازی s390x بسازید. این نمونه‌ها برای استفاده موقت در نظر گرفته شده‌اند (حداکثر ۱۲۰ روز).

    • IBM LinuxONE Open Source Cloud دسترسی دائمی به ماشین‌های s390x فراهم می‌کند. این کار به تأیید IBM نیاز دارد که معمولاً اگر قصد داشته باشید از ماشین برای کار روی یک پروژه متن‌باز مرتبط با اکوسیستم IBM Z استفاده کنید، داده می‌شود - کامپایلر Rust قطعاً شرایط لازم را دارد.
