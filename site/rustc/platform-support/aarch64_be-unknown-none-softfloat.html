    aarch64_be-unknown-none-softfloat

    سطح: 3

    هدفی برای فایل‌های دودویی ARM64 با big-endian در حالت freestanding/bare-metal و با قالب ELF: میان‌افزار، کرنل و مانند آن.

    نگهدارندگان هدف

    @Gelbpunkt

    الزامات

    این هدف به‌صورت متقاطع کامپایل می‌شود. از std پشتیبانی نمی‌شود. تخصیص‌دهندهٔ پیش‌فرض وجود ندارد، اما با فراهم‌کردن یک تخصیص‌دهنده می‌توان از alloc استفاده کرد.

    این هدف وجود FPU را فرض نمی‌کند و از هیچ ثبات غیر GPR استفاده نمی‌کند. این امر به کد تولیدشده اجازه می‌دهد در محیط‌هایی مانند کرنل‌ها اجرا شود که ممکن است نیاز داشته باشند از چنین ثبات‌هایی دوری کنند یا ملاحظات ویژه‌ای در استفاده از آن‌ها داشته باشند (مثلاً ذخیره و بازیابی آن‌ها برای جلوگیری از خراب‌شدن کد فضای کاربر که از همان ثبات‌ها استفاده می‌کند). می‌توانید با گزینه‌های codegen به نام -C target-feature= در rustc یا با سازوکار #[target_feature] در کد Rust، تولید کد را برای استفاده از ویژگی‌های اضافی CPU تغییر دهید.

    به‌طور پیش‌فرض، کدی که با هدف soft-float تولید می‌شود باید روی هر سخت‌افزار ARM64 با big-endian اجرا شود؛ فعال‌کردن ویژگی‌های هدف اضافی ممکن است این خط پایه را بالا ببرد.

    extern "C" از قرارداد فراخوانی استاندارد معماری استفاده می‌کند.

    این اهداف فایل‌های دودویی با قالب ELF تولید می‌کنند. هر قالب جایگزین یا ملاحظات ویژه برای چیدمان فایل دودویی به گزینه‌های پیوندگر یا اسکریپت‌های پیوندگر نیاز دارد.

    ساخت هدف

    می‌توانید با افزودن این هدف به فهرست target در bootstrap.toml، Rust را با پشتیبانی از آن بسازید:

    [build]
target = ["aarch64_be-unknown-none-softfloat"]

    ساخت برنامه‌های Rust

    Rust هنوز مصنوعات از پیش کامپایل‌شده‌ای برای این هدف ارائه نمی‌کند. برای کامپایل برای این هدف، ابتدا باید Rust را با فعال‌بودن هدف بسازید (بخش «ساخت هدف» در بالا را ببینید).

    کامپایل متقاطع

    برای ساخت‌های متقاطع، به یک toolchain مناسب C/C++ برای ARM64 نیاز دارید که برای پیوند استفاده شود، یا اگر می‌خواهید کد C را همراه با Rust کامپایل کنید (مثلاً برای crateهای Rust که وابستگی C دارند).

    Rust ممکن است بتواند از یک toolchain از نوع aarch64_be-unknown-linux-{gnu,musl}- با پرچم‌های مستقل مناسب برای ساخت این هدف استفاده کند (بسته به مفروضات آن toolchain، در ادامه ببینید)، یا ممکن است بخواهید از یک toolchain جداگانهٔ aarch64_be-unknown-none-softfloat استفاده کنید.

    روی برخی میزبان‌های ARM64 که از فایل‌های دودویی ELF استفاده می‌کنند، ممکن است بتوانید از toolchain C میزبان استفاده کنید، به شرطی که مفروضاتی دربارهٔ محیط میزبان وارد نکند که با انتظارات یک محیط مستقل مطابقت نداشته باشد. در غیر این صورت، ممکن است برای توسعهٔ مستقل/freestanding به یک toolchain جداگانه نیاز داشته باشید، درست مانند کامپایل متقاطع از یک پلتفرم غیر ARM64.

    آزمون

    از آنجا که این هدف از محیط‌های متنوعی پشتیبانی می‌کند و از std پشتیبانی نمی‌کند، اجرای مجموعه‌آزمون Rust را پشتیبانی نمی‌کند.
