    آشفته‌سازی نماد (Symbol Mangling)

    آشفته‌سازی نام نماد توسط rustc برای رمزگذاری یک نام یکتا برای نمادهایی به کار می‌رود که هنگام تولید کد استفاده می‌شوند. لینکر از نام‌های رمزگذاری‌شده برای مرتبط‌کردن نام با چیزی که به آن اشاره می‌کند استفاده می‌کند.

    روش آشفته‌سازی نام‌ها را می‌توان با گزینهٔ -C symbol-mangling-version کنترل کرد.

    کنترل به‌ازای هر آیتم

    ویژگی #[no_mangle] را می‌توان روی آیتم‌ها به کار برد تا آشفته‌سازی نام آن آیتم غیرفعال شود.

    ویژگی #[export_name] را می‌توان برای تعیین نام دقیقی که برای یک تابع یا static به کار می‌رود استفاده کرد.

    آیتم‌های فهرست‌شده در یک بلوک extern برای ارجاع به آیتم از شناسهٔ آیتم بدون آشفته‌سازی استفاده می‌کنند. ویژگی #[link_name] را می‌توان برای تغییر آن نام به کار برد.

    ماژول‌های import در WebAssembly

    در targetهای WebAssembly، آیتم‌های خارجی در بلوک‌های extern می‌توانند از یک نام import یکسان بدون تعارض استفاده کنند، به شرط آنکه مقادیر #[link(wasm_import_module = "...")] متفاوتی داشته باشند.

    رمزگشایی

    ممکن است در برخی موقعیت‌ها لازم باشد نام‌های رمزگذاری‌شده رمزگشایی شوند. برای مثال، اشکال‌زداها و سایر ابزارها ممکن است لازم باشد نام را از حالت آشفته خارج کنند تا برای کاربر خواناتر باشد. نسخه‌های جدید gdb و lldb پشتیبانی داخلی از رمزگشایی شناسه‌های Rust دارند. در موقعیت‌هایی که لازم است خودتان رمزگشایی کنید، می‌توان از crate با نام rustc-demangle برای رمزگشایی برنامه‌نویسی‌شدهٔ نام‌ها استفاده کرد. rustfilt ابزاری خط فرمان است که می‌تواند نام‌ها را رمزگشایی کند.

    نمونه‌ای از اجرای rustfilt:

    $ rustfilt _RNvCskwGfYPst2Cb_3foo16example_function
foo::example_function

    نسخه‌های آشفته‌سازی

    در حال حاضر یک نسخهٔ پایدار از طرح آشفته‌سازی وجود دارد - v0. در ساخت‌های nightly، rustc از بازگشت به طرح آشفته‌سازی legacy با استفاده از -C symbol-mangling-version پشتیبانی می‌کند. طرح آشفته‌سازی v0 در فصل قالب نماد v0 توضیح داده شده است.
