    Jobserver

    rustc در داخل خود می‌تواند از موازی‌سازی بهره ببرد. اگر یک jobserver در GNU Make از طریق متغیر محیطی MAKEFLAGS به rustc داده شود، rustc با سیستم ساختی که آن را فراخوانی کرده هماهنگ می‌شود. پرچم‌های دیگر نیز ممکن است اثر داشته باشند، مانند CARGO_MAKEFLAGS. اگر jobserver داده نشود، rustc خودش تعداد کارهایی (jobs) را که باید استفاده شوند انتخاب می‌کند.

    از Rust 1.76.0 به بعد، اگر به نظر برسد که یک jobserver در دسترس است اما rustc نمی‌تواند به آن دسترسی پیدا کند، هشدار می‌دهد؛ برای مثال:

    $ echo 'fn main() {}' | MAKEFLAGS=--jobserver-auth=3,4 rustc -
warning: failed to connect to jobserver from environment variable `MAKEFLAGS="--jobserver-auth=3,4"`: cannot open file descriptor 3 from the jobserver environment variable value: Bad file descriptor (os error 9)
  |
  = note: the build environment is likely misconfigured

    یکپارچه‌سازی با سیستم‌های ساخت

    زیربخش‌های زیر شامل توصیه‌هایی دربارهٔ نحوهٔ یکپارچه‌سازی rustc با سیستم‌های ساخت هستند تا jobserver به‌درستی مدیریت شود.

    GNU Make

    هنگام فراخوانی rustc از GNU Make، توصیه می‌شود همهٔ فراخوانی‌های rustc در Makefile به‌صورت بازگشتی (recursive) علامت‌گذاری شوند (با افزودن نشانگر + به ابتدای خط فرمان) تا GNU Make برای آن‌ها jobserver را فعال کند. برای مثال:

    x:
	+@echo 'fn main() {}' | rustc -

    به‌طور خاص، GNU Make نسخهٔ 4.3 (نسخه‌ای که تا سال 2024 به‌طور گسترده استفاده می‌شد) حتی زمانی که jobserver برای فرایند فرزند در دسترس قرار نگرفته باشد نیز یک jobserver ساده از نوع pipe را در MAKEFLAGS ارسال می‌کند، و این به نوبهٔ خود به این معناست که rustc دربارهٔ آن هشدار می‌دهد. برای مثال، اگر نشانگر + از مثال بالا حذف شود و GNU Make با دستوری مانند make -j2 اجرا شود، هشدار یادشده نمایش داده خواهد شد.

    برای فراخوانی‌های rustc درون $(shell ...) در یک Make بازگشتی، می‌توان jobserver را با پاک کردن متغیر MAKEFLAGS به‌صورت دستی غیرفعال کرد، برای مثال:

    S := $(shell MAKEFLAGS= rustc --print sysroot)

x:
	@$(MAKE) y

y:
	@echo $(S)

    CMake

    CMake نسخهٔ 3.28 از گزینهٔ JOB_SERVER_AWARE در دستور add_custom_target خود پشتیبانی می‌کند، برای مثال:

    cmake_minimum_required(VERSION 3.28)
project(x)
add_custom_target(x
    JOB_SERVER_AWARE TRUE
    COMMAND echo 'fn main() {}' | rustc -
)

    برای نسخه‌های قدیمی‌تر، هنگام استفاده از CMake با مولد Makefile، یک راه‌حل جایگزین این است که $(MAKE) را جایی در فرمان قرار دهید تا GNU Make آن را یک فراخوانی بازگشتی Make در نظر بگیرد، برای مثال:

    cmake_minimum_required(VERSION 3.22)
project(x)
add_custom_target(x
    COMMAND DUMMY_VARIABLE=$(MAKE) echo 'fn main() {}' | rustc -
)
