    ویژگی‌های مخصوص Cargo - بررسی پیکربندی‌های شرطی

    این سند برای خلاصه‌کردن مهم‌ترین شیوه‌هایی است که Cargo با lint به نام unexpected_cfgs و پرچم --check-cfg تعامل می‌کند. برای جزئیات هر مورد، به مستندات --check-cfg و کتاب Cargo مراجعه کنید.

    فهرست کامل cfgهای شناخته‌شده (یا همان درون‌ساخت‌ها) را می‌توانید در بررسی پیکربندی‌های شرطی / نام‌ها و مقادیر شناخته‌شده بیابید.

    ویژگی Cargo (Cargo feature)

    برای جزئیات بیشتر، بخش [features] در کتاب Cargo را ببینید.

    Cargo با جدول [features] سازوکاری برای بیان کامپایل شرطی و وابستگی‌های اختیاری فراهم می‌کند. Cargo به‌طور خودکار cfgهای متناظر با هر feature را به‌عنوان مورد انتظار اعلام می‌کند.

    Cargo.toml:

    [features]
serde = ["dep:serde"]
my_feature = []

    check-cfg در جدول [lints.rust]

    برای جزئیات بیشتر، بخش [lints] در کتاب Cargo را ببینید.

    هنگام استفاده از یک پیکربندی سفارشی که به‌صورت ایستا شناخته می‌شود (یعنی به build-script وابسته نیست)، Cargo پیکربندی lint سفارشی check-cfg را در [lints.rust.unexpected_cfgs] فراهم می‌کند.

    این پیکربندی را می‌توان برای تعیین آرگومان‌های ایستای سفارشی --check-cfg به کار برد و بیشتر زمانی مفید است که فهرست cfgهای مورد انتظار از پیش معلوم باشد.

    Cargo.toml:

    [lints.rust]
unexpected_cfgs = { level = "warn", check-cfg = ['cfg(has_foo)'] }

    cargo::rustc-check-cfg برای build.rs/build-script

    برای جزئیات بیشتر، بخش cargo::rustc-check-cfg در کتاب Cargo را ببینید.

    هنگام تنظیم یک پیکربندی سفارشی با cargo::rustc-cfg، Cargo دستور متناظر آن را فراهم می‌کند: cargo::rustc-check-cfg برای اعلام انتظار پیکربندی‌های سفارشی.

    build.rs:

    fn main() {
    println!("cargo::rustc-check-cfg=cfg(has_foo)");
    //        ^^^^^^^^^^^^^^^^^^^^^^ new with Cargo 1.80
    if has_foo() {
        println!("cargo::rustc-cfg=has_foo");
    }
}
