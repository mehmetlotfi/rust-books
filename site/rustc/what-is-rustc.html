    rustc چیست؟

    به «کتاب rustc» خوش آمدید! rustc کامپایلر زبان برنامه‌نویسی Rust است که توسط خود پروژه ارائه می‌شود. کامپایلرها کد منبع شما را می‌گیرند و کد دودویی تولید می‌کنند، چه به‌صورت کتابخانه و چه فایل اجرایی.

    بیشتر برنامه‌نویسان Rust مستقیماً rustc را فراخوانی نمی‌کنند، بلکه این کار را از طریق Cargo انجام می‌دهند. با این حال همهٔ این‌ها در خدمت rustc است! اگر می‌خواهید ببینید Cargo چگونه rustc را فراخوانی می‌کند، می‌توانید این را اجرا کنید

    $ cargo build --verbose

    و هر فراخوانی rustc را چاپ می‌کند. این کتاب می‌تواند به شما کمک کند بفهمید هر یک از این گزینه‌ها چه می‌کند. علاوه بر این، اگرچه بیشتر Rustaceanها از Cargo استفاده می‌کنند، همه چنین نیستند: گاهی rustc را در سیستم‌های ساخت دیگر ادغام می‌کنند. این کتاب باید راهنمایی برای همهٔ گزینه‌هایی باشد که برای این کار نیاز دارید.

    استفادهٔ پایه

    فرض کنید یک برنامهٔ کوچک hello world در فایلی به نام hello.rs دارید:

    fn main() {
    println!("Hello, world!");
}

    برای تبدیل این کد منبع به یک فایل اجرایی، می‌توانید از rustc استفاده کنید:

    $ rustc hello.rs
$ ./hello # on a *NIX
$ .\hello.exe # on Windows

    توجه کنید که ما همیشه فقط ریشهٔ crate را به rustc می‌دهیم، نه همهٔ فایل‌هایی که می‌خواهیم کامپایل کنیم. برای مثال، اگر یک main.rs داشتیم که این‌گونه بود:

    mod foo;

fn main() {
    foo::hello();
}

    و یک foo.rs که این را داشت:

    pub fn hello() {
    println!("Hello, world!");
}

    برای کامپایل این، این دستور را اجرا می‌کنیم:

    $ rustc main.rs

    نیازی نیست دربارهٔ foo.rs به rustc بگوییم؛ دستورهای mod هر چیزی را که لازم دارد به آن می‌دهند. این با شیوهٔ استفاده از کامپایلر C تفاوت دارد، که در آن کامپایلر را روی هر فایل فراخوانی می‌کنید و سپس همه‌چیز را به هم لینک می‌کنید. به بیان دیگر، crate یک واحد ترجمه است، نه یک ماژول خاص.
