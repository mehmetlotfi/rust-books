    گزینه‌های چاپ

    همهٔ این گزینه‌ها از طریق پرچم --print به rustc داده می‌شوند.

    این گزینه‌ها اطلاعات گوناگونی دربارهٔ کامپایلر چاپ می‌کنند. می‌توان چند گزینه را مشخص کرد و اطلاعات به همان ترتیبی که گزینه‌ها مشخص شده‌اند چاپ می‌شود.

    مشخص‌کردن یک گزینه معمولاً مرحلهٔ --emit را غیرفعال می‌کند و فقط اطلاعات درخواست‌شده را چاپ می‌کند.

    برای هر نوع اطلاعات درخواست‌شده می‌توان به‌صورت اختیاری یک مسیر فایل با قالب --print KIND=PATH مشخص کرد، درست مانند --emit. وقتی مسیری مشخص شود، اطلاعات به‌جای stdout در آن مسیر نوشته می‌شود.

    crate-name

    نام crate.

    معمولاً یا از attribute #![crate_name = "..."]، پرچم --crate-name یا نام فایل به دست می‌آید.

    مثال:

    $ rustc --print crate-name --crate-name my_crate a.rs
my_crate

    file-names

    نام فایل‌هایی که نوع خروجی link ایجاد می‌کند.

    sysroot

    مسیر مطلق sysroot.

    مثال (با rustup و toolchain نسخهٔ stable):

    $ rustc --print sysroot a.rs
/home/[REDACTED]/.rustup/toolchains/stable-x86_64-unknown-linux-gnu

    target-libdir

    مسیر libdir هدف.

    مثال (با rustup و toolchain نسخهٔ stable):

    $ rustc --print target-libdir a.rs
/home/[REDACTED]/.rustup/toolchains/beta-x86_64-unknown-linux-gnu/lib/rustlib/x86_64-unknown-linux-gnu/lib

    host-tuple

    رشتهٔ target-tuple کامپایلر میزبان.

    مثال:

    $ rustc --print host-tuple a.rs
x86_64-unknown-linux-gnu

    مثال با پرچم --target:

    $ rustc --print host-tuple --target "armv7-unknown-linux-gnueabihf" a.rs
x86_64-unknown-linux-gnu

    cfg

    فهرست مقادیر cfg. برای اطلاعات بیشتر دربارهٔ مقادیر cfg، کامپایل شرطی را ببینید.

    مثال (برای x86_64-unknown-linux-gnu):

    $ rustc --print cfg a.rs
debug_assertions
panic="unwind"
target_abi=""
target_arch="x86_64"
target_endian="little"
target_env="gnu"
target_family="unix"
target_feature="fxsr"
target_feature="sse"
target_feature="sse2"
target_has_atomic="16"
target_has_atomic="32"
target_has_atomic="64"
target_has_atomic="8"
target_has_atomic="ptr"
target_os="linux"
target_pointer_width="64"
target_vendor="unknown"
unix

    target-list

    فهرست هدف‌های شناخته‌شده. هدف را می‌توان با پرچم --target انتخاب کرد.

    target-cpus

    فهرست مقادیر CPU موجود برای هدف فعلی. CPU هدف را می‌توان با پرچم -C target-cpu=val انتخاب کرد.

    target-features

    فهرست featureهای هدف موجود برای هدف فعلی.

    featureهای هدف را می‌توان با پرچم unsafe به نام -C target-feature=val فعال کرد.

    برای جزئیات بیشتر، مشکلات شناخته‌شده را ببینید.

    relocation-models

    فهرست مدل‌های جابه‌جایی (relocation). مدل‌های جابه‌جایی را می‌توان با پرچم -C relocation-model=val انتخاب کرد.

    مثال:

    $ rustc --print relocation-models a.rs
Available relocation models:
    static
    pic
    pie
    dynamic-no-pic
    ropi
    rwpi
    ropi-rwpi
    default

    code-models

    فهرست مدل‌های کد. مدل‌های کد را می‌توان با پرچم -C code-model=val انتخاب کرد.

    مثال:

    $ rustc --print code-models a.rs
Available code models:
    tiny
    small
    kernel
    medium
    large

    tls-models

    فهرست مدل‌های Thread Local Storage پشتیبانی‌شده. مدل را می‌توان با پرچم -Z tls-model=val انتخاب کرد.

    مثال:

    $ rustc --print tls-models a.rs
Available TLS models:
    global-dynamic
    local-dynamic
    initial-exec
    local-exec
    emulated

    native-static-libs

    این گزینه ممکن است هنگام ایجاد یک crate از نوع staticlib به کار رود.

    اگر این تنها پرچم باشد، یک کامپایل کامل انجام می‌دهد و یک یادداشت تشخیصی شامل می‌شود که پرچم‌های پیونددهنده را برای پیوند با کتابخانهٔ ایستای حاصل نشان می‌دهد.

    یادداشت با متن native-static-libs: شروع می‌شود تا استخراج خروجی آسان‌تر شود.

    مثال:

    $ rustc --print native-static-libs --crate-type staticlib a.rs
note: link against the following native artifacts when linking against this static library. The order and any duplication can be significant on some platforms.

note: native-static-libs: -lgcc_s -lutil [REDACTED] -lpthread -lm -ldl -lc

    link-args

    این پرچم مرحلهٔ --emit را غیرفعال نمی‌کند. این می‌تواند هنگام اشکال‌زدایی گزینه‌های پیونددهنده مفید باشد.

    هنگام پیوند، این پرچم باعث می‌شود rustc فراخوانی کامل پیونددهنده را به شکل قابل‌خواندن برای انسان چاپ کند. قالب دقیق این خروجی اشکال‌زدایی تضمین پایداری ندارد، جز اینکه شامل فایل اجرایی پیونددهنده و متن هر آرگومان خط فرمانی خواهد بود که به پیونددهنده داده شده است.

    deployment-target

    هدف استقرار (deployment target) (یا حداقل نسخهٔ سیستم‌عامل) که در حال حاضر برای هدف پلتفرم اپل انتخاب شده است.

    این مقدار را می‌توان در کنار یک ساخت Rust برای مؤلفه‌های دیگری که به این اطلاعات نیاز دارند، مانند کامپایلرهای C، به کار برد یا به آن‌ها منتقل کرد. اگر هیچ متغیر *_DEPLOYMENT_TARGET در محیط وجود نداشته باشد، حداقل هدف استقرار پشتیبانی‌شده توسط rustc را برمی‌گرداند، و در غیر این صورت مقدار تجزیه‌شدهٔ آن متغیر را برمی‌گرداند.
