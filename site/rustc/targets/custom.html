    targetهای سفارشی

    اگر می‌خواهید برای targetای بسازید که هنوز توسط rustc پشتیبانی نمی‌شود، می‌توانید از یک «مشخصات target سفارشی» (custom target specification) برای تعریف target استفاده کنید. این فایل‌های مشخصات target با فرمت JSON هستند. برای دیدن JSON مربوط به target میزبان می‌توانید این را اجرا کنید:

    rustc +nightly -Z unstable-options --print target-spec-json

    برای دیدن آن برای target دیگری، پرچم --target را اضافه کنید:

    rustc +nightly -Z unstable-options --target=wasm32-unknown-unknown --print target-spec-json

    برای استفاده از یک target سفارشی، قابلیت build-std (ناپایدار) در cargo را ببینید.

    ویژگی‌های JSON مربوط به target پایدار نیستند و ممکن است تغییر کنند. هنگام استفاده از targetهای سفارشی همیشه نسخهٔ کامپایلر خود را ثابت (pin) کنید!

    طرح‌واره JSON

    rustc یک طرح‌واره (schema) JSON برای مشخصات JSON مربوط به target سفارشی فراهم می‌کند. چون این طرح‌واره ممکن است تغییر کند، همیشه باید از طرح‌وارهٔ همان نسخه‌ای از rustc استفاده کنید که target را به آن می‌دهید.

    آن را می‌توان در etc/target-spec-json-schema.json در sysroot (rustc --print sysroot) پیدا کرد یا با rustc +nightly -Zunstable-options --print target-spec-json-schema چاپ کرد. وجود و نام این طرح‌واره، درست مانند ویژگی‌های مشخصات JSON، پایدار نیست و ممکن است تغییر کند.

    مسیر جست‌وجوی target سفارشی

    وقتی گزینهٔ --target=TARGET به rustc داده می‌شود (که در آن TARGET هر رشته‌ای است)، از منطق زیر استفاده می‌کند:

    1. اگر TARGET نام یک target داخلی است، از آن استفاده کن
    2. اگر TARGET مسیر یک فایل است، آن فایل را به‌عنوان target از نوع json بخوان
    3. در غیر این صورت، فهرست دایرکتوری‌های جداشده با دونقطه موجود در متغیر محیطی RUST_TARGET_PATH را از چپ به راست برای فایلی به نام TARGET.json جست‌وجو کن.

    این مراحل به ترتیب امتحان می‌شوند، بنابراین اگر برای یک target چند تفسیر بالقوه معتبر وجود داشته باشد، هر کدام که زودتر پیدا شود اولویت دارد. اگر هیچ‌یک از این روش‌ها target را پیدا نکند، خطا صادر می‌شود.
