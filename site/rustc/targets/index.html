    targetها

    rustc به‌طور پیش‌فرض یک کامپایلر متقابل (cross-compiler) است. این یعنی می‌توانید از هر کامپایلری برای ساخت برای هر معماری استفاده کنید. فهرست targetها معماری‌های ممکنی است که می‌توانید برای آن‌ها بسازید. برای فهرست تفصیلی targetها صفحهٔ پشتیبانی از پلتفرم را ببینید، یا targetهای داخلی را برای دستورالعمل مشاهدهٔ آنچه برای نسخهٔ شما از rustc در دسترس است.

    برای دیدن همهٔ گزینه‌هایی که می‌توانید برای یک target تنظیم کنید، مستندات اینجا را ببینید.

    برای کامپایل به یک target مشخص، از پرچم --target استفاده کنید:

    $ rustc src/main.rs --target=wasm32-unknown-unknown

    قابلیت‌های target

    x86 و ARMv8 دو معماری پرکاربرد CPU هستند. مجموعه دستورالعمل‌های آن‌ها پایهٔ مشترکی را در بیشتر CPUها شکل می‌دهد. با این حال، برخی CPUها این مجموعه را با مجموعه دستورالعمل‌های سفارشی گسترش می‌دهند، مانند برداری (AVX)، دست‌کاری بیتی (BMI) یا رمزنگاری (AES).

    توسعه‌دهندگانی که می‌دانند کد کامپایل‌شدهٔ آن‌ها روی کدام CPUها اجرا خواهد شد، می‌توانند مجموعه دستورالعمل‌های مختص CPU را از طریق پرچم -C target-feature=val اضافه (یا حذف) کنند.

    لطفاً توجه کنید که این پرچم عموماً ناایمن (unsafe) تلقی می‌شود. جزئیات بیشتر را می‌توانید در این بخش بیابید.
