    طول عمرهای خام

    خلاصه

    • 'r#ident_or_keyword اکنون به‌عنوان یک طول عمر مجاز است، که امکان استفاده از کلیدواژه‌هایی مانند 'r#fn را فراهم می‌کند.

    جزئیات

    طول عمرهای خام در ویرایش 2021 معرفی شدند تا امکان مهاجرت به ویرایش‌های جدیدتری را که کلیدواژه‌های جدید معرفی می‌کنند پشتیبانی کنند. این مشابه شناسه‌های خام است که همین قابلیت را برای شناسه‌ها فراهم می‌کنند. برای مثال، ویرایش 2024 کلیدواژهٔ gen را معرفی کرد. از آنجا که طول عمرها نمی‌توانند کلیدواژه باشند، این موضوع باعث می‌شد کدی که از طول عمر 'gen استفاده می‌کند کامپایل نشود. طول عمرهای خام به lint مهاجرت اجازه می‌دهند آن طول عمرها را به 'r#gen تغییر دهد که کلیدواژه‌ها را مجاز می‌داند.

    در ویرایش‌های پیش از 2021، طول عمرهای خام به‌صورت توکن‌های جداگانه تجزیه می‌شوند. برای مثال 'r#foo به‌صورت سه توکن تجزیه می‌شود: 'r، # و foo.

    مهاجرت

    به‌عنوان بخشی از ویرایش ۲۰۲۱، یک lint مهاجرت با نام rust_2021_prefixes_incompatible_syntax اضافه شده است تا به مهاجرت خودکار کدهای Rust 2018 به Rust 2021 کمک کند.

    برای مهاجرت کد خود به سازگاری با ویرایش Rust 2021، این دستور را اجرا کنید:

    cargo fix --edition

    اگر بخواهید یا نیاز داشته باشید کد خود را به‌صورت دستی مهاجرت دهید، این کار نسبتاً ساده است.

    فرض کنید ماکرویی دارید که این‌گونه تعریف شده است:

    macro_rules! my_macro {
    ($a:tt $b:tt $c:tt) => {};
}

    در Rust 2015 و 2018 مجاز است که این ماکرو بدون فاصله بین توکن‌ها به این صورت فراخوانی شود:

    my_macro!('r#foo);

    در ویرایش 2021، این اکنون به‌صورت یک توکن واحد تجزیه می‌شود. برای فراخوانی این ماکرو، باید پیش از شناسه یک فاصله اضافه کنید، به این صورت:

    my_macro!('r# foo);
