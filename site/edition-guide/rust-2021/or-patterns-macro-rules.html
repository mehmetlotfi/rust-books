    الگوهای or در macro-rules

    خلاصه

    • نحوهٔ کار الگوها در ماکروهای macro_rules اندکی تغییر می‌کند:
      • $_:pat در macro_rules اکنون با استفاده از | نیز مطابقت پیدا می‌کند؛ مثلاً A | B.
      • $_:pat_param جدید مانند $_:pat پیشین رفتار می‌کند؛ یعنی با | (در سطح بالا) مطابقت پیدا نمی‌کند.
      • $_:pat_param در همهٔ ویرایش‌ها در دسترس است.

    جزئیات

    از Rust 1.53.0 به بعد، الگوها گسترش یافته‌اند تا از | در هر جایی از درون الگو پشتیبانی کنند. این کار به شما امکان می‌دهد به‌جای Some(1) | Some(2) بنویسید Some(1 | 2). از آنجا که این کار پیش‌تر به‌سادگی مجاز نبود، این یک تغییر ناسازگار نیست.

    با این حال، این تغییر بر ماکروهای macro_rules نیز تأثیر می‌گذارد. چنین ماکروهایی می‌توانند با استفاده از مشخص‌کنندهٔ قطعهٔ :pat الگوها را بپذیرند. در حال حاضر، :pat با | در سطح بالا مطابقت پیدا نمی‌کند، زیرا پیش از Rust 1.53 همهٔ الگوها (در همهٔ سطوح تودرتو) نمی‌توانستند شامل | باشند. ماکروهایی که الگوهایی مانند A | B را می‌پذیرند، مانند matches!()، از چیزی شبیه $($_:pat)|+ استفاده می‌کنند.

    چون این کار می‌توانست ماکروهای موجود را خراب کند، معنای :pat در Rust 1.53.0 برای شمول | تغییر نکرد. در عوض، این تغییر در Rust 2021 رخ می‌دهد. در ویرایش جدید، مشخص‌کنندهٔ قطعهٔ :pat با A | B مطابقت پیدا خواهد کرد.

    قطعه‌های $_:pat در Rust 2021 نمی‌توانند بلافاصله با یک | صریح دنبال شوند. از آنجا که گاهی هنوز می‌خواهیم قطعه‌های الگو را که با | دنبال می‌شوند مطابقت دهیم، مشخص‌کنندهٔ قطعهٔ :pat_param اضافه شده است تا رفتار قدیمی‌تر حفظ شود.

    مهم است به یاد داشته باشید که ویرایش‌ها برای هر crate تعیین می‌شوند، بنابراین تنها ویرایش مرتبط، ویرایش همان crate است که ماکرو در آن تعریف شده است. ویرایش crate که ماکرو در آن استفاده می‌شود بر نحوهٔ کار ماکرو تأثیری ندارد.

    مهاجرت

    یک lint با نام rust_2021_incompatible_or_patterns هر زمان که استفاده‌ای از $_:pat وجود داشته باشد که در Rust 2021 معنایش تغییر می‌کند فعال می‌شود.

    می‌توانید کد خود را به‌طور خودکار طوری مهاجرت دهید که با ویرایش Rust 2021 سازگار شود، یا مطمئن شوید که از قبل سازگار است، با اجرای:

    cargo fix --edition

    اگر ماکرویی دارید که به مطابقت نداشتن $_:pat با استفادهٔ سطح بالای | در الگوها وابسته است، باید هر وقوع $_:pat را به $_:pat_param تغییر دهید.

    برای مثال:

    macro_rules! my_macro { 
	($x:pat | $y:pat) => {
		// TODO: implementation
	} 
}

// This macro works in Rust 2018 since `$x:pat` does not match against `|`:
my_macro!(1 | 2);

// In Rust 2021 however, the `$_:pat` fragment matches `|` and is not allowed
// to be followed by a `|`. To make sure this macro still works in Rust 2021
// change the macro to the following:
macro_rules! my_macro { 
	($x:pat_param | $y:pat) => { // <- this line is different
		// TODO: implementation
	} 
}
