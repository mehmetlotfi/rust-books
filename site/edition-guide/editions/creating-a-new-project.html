راهنمای ویرایش‌های RustThe Edition Guide

    ایجاد یک پروژهٔ جدید

    پروژه‌ای که با Cargo ساخته می‌شود به‌طور پیش‌فرض طوری پیکربندی می‌شود که از آخرین ویرایش استفاده کند:

    $ cargo new foo
    Creating binary (application) `foo` package
note: see more `Cargo.toml` keys and their definitions at https://doc.rust-lang.org/cargo/reference/manifest.html
$ cat foo/Cargo.toml
[package]
name = "foo"
version = "0.1.0"
edition = "2024"

[dependencies]

    تنظیم edition = "2024" بستهٔ شما را طوری پیکربندی می‌کند که با ویرایش Rust 2024 ساخته شود. به پیکربندی دیگری نیاز نیست!

    می‌توانید از گزینهٔ --edition <YEAR> در cargo new استفاده کنید تا پروژه را با یک ویرایش مشخص بسازید. برای مثال، ساخت یک پروژهٔ جدید برای استفاده از ویرایش Rust 2018 را می‌توان این‌گونه انجام داد:

    $ cargo new --edition 2018 foo
    Creating binary (application) `foo` package
note: see more `Cargo.toml` keys and their definitions at https://doc.rust-lang.org/cargo/reference/manifest.html
$ cat foo/Cargo.toml
[package]
name = "foo"
version = "0.1.0"
edition = "2018"

[dependencies]

    نگران استفادهٔ تصادفی از یک سال نامعتبر برای ویرایش نباشید؛ دستور cargo new مقدار سال نامعتبر برای ویرایش را نمی‌پذیرد:

    $ cargo new --edition 2019 foo
error: invalid value '2019' for '--edition <YEAR>'
  [possible values: 2015, 2018, 2021, 2024]

  tip: a similar value exists: '2021'

For more information, try '--help'.

    می‌توانید مقدار کلید edition را با ویرایش ساده‌ی فایل Cargo.toml تغییر دهید. برای مثال، برای اینکه بستهٔ شما با ویرایش Rust 2015 ساخته شود، باید کلید را مانند مثال زیر تنظیم کنید:

    [package]
name = "foo"
version = "0.1.0"
edition = "2015"

[dependencies]
