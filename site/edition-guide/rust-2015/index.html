راهنمای ویرایش‌های RustThe Edition Guide

    Rust 2015

    موضوع اصلی Rust 2015 «پایداری» است. این ویرایش با انتشار نسخهٔ 1.0 آغاز شد و «ویرایش پیش‌فرض» است. سیستم ویرایش‌ها در اواخر سال 2017 طراحی شد، اما Rust 1.0 در ماه مه 2015 منتشر شده بود. به همین دلیل، به‌منظور حفظ سازگاری با نسخه‌های قبلی، وقتی ویرایش خاصی را مشخص نمی‌کنید، 2015 همان ویرایشی است که دریافت می‌کنید.

    «پایداری» موضوع اصلی Rust 2015 است، چون 1.0 تغییر بزرگی در توسعهٔ Rust به شمار می‌آمد. پیش از Rust 1.0، زبان Rust هر روز تغییر می‌کرد. این موضوع نوشتن نرم‌افزارهای بزرگ با Rust را بسیار دشوار می‌کرد و یادگیری آن را نیز سخت می‌ساخت. با انتشار Rust 1.0 و Rust 2015، ما متعهد شدیم که سازگاری با نسخه‌های قبلی را حفظ کنیم و پایه‌ای محکم فراهم آوریم تا مردم بتوانند پروژه‌های خود را روی آن بسازند.

    از آنجا که این ویرایش پیش‌فرض است، راهی برای انتقال کد شما به Rust 2015 وجود ندارد؛ این ویرایش صرفاً هست. شما از 2015 دور می‌شوید، اما هرگز واقعاً به سمت 2015 نمی‌روید. به همین دلیل، چیز دیگری دربارهٔ آن برای گفتن نیست!
