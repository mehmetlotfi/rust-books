    Rustfmt: رفع مشکلات قالب‌بندی

    خلاصه

    • رفع مشکلات در سناریوهای مختلف قالب‌بندی.

    جزئیات

    ویرایش سبک 2024 چندین رفع مشکل را برای سناریوهای مختلف قالب‌بندی معرفی می‌کند.

    کامنت‌های انتهایی نامرتبط بعد از آیتم‌ها یا در انتهای بلوک‌ها دیگر هم‌تراز نمی‌شوند

    پیش‌تر rustfmt فرض می‌کرد کامنتی که در خطِ بعد از یک آیتمِ دارای کامنت انتهایی قرار دارد باید طوری تورفتگی بگیرد که با آن کامنت انتهایی هم‌تراز شود. این رفتار تغییر کرده است و اکنون آن کامنت‌ها تورفتگی نمی‌گیرند.

    تورفتگی جنریک‌ها در بلوک‌های impl اصلاح شد

    جنریک‌ها در آیتم‌های impl تورفتگی بیش‌ازحد داشتند.

    ویرایش سبک 2021:

    impl<
        Target: FromEvent<A> + FromEvent<B>,
        A: Widget2<Ctx = C>,
        B: Widget2<Ctx = C>,
        C: for<'a> CtxFamily<'a>,
    > Widget2 for WidgetEventLifter<Target, A, B>
{
    type Ctx = C;
    type Event = Vec<Target>;
}

    ویرایش سبک 2024:

    impl<
    Target: FromEvent<A> + FromEvent<B>,
    A: Widget2<Ctx = C>,
    B: Widget2<Ctx = C>,
    C: for<'a> CtxFamily<'a>,
> Widget2 for WidgetEventLifter<Target, A, B>
{
    type Ctx = C;
    type Event = Vec<Target>;
}

    استفاده از تورفتگی صحیح هنگام قالب‌بندی یک fn پیچیده

    در برخی موارد، امضای یک fn پیچیده می‌توانست تورفتگی غیرمعمولی پیدا کند که اکنون رفع شده است.

    اجتناب از فاصلهٔ اضافی در عبارت اندیس‌گذاری tuple تو در تو

    عبارت‌های اندیس‌گذاری tuple تو در تو به‌اشتباه یک فاصلهٔ اضافی داشتند.

    ویرایش سبک 2021:

    fn main() {
    let _ = ((1,),).0 .0;
}

    ویرایش سبک 2024:

    fn main() {
    let _ = ((1,),).0.0;
}

    پایان دادن return/break/continue درون یک بلوک در match با نقطه‌ویرگول

    در یک return، break یا continue که درون یک بلوک در شاخهٔ match قرار داشت، به‌اشتباه نقطه‌ویرگول وجود نداشت.

    ویرایش سبک 2021:

    fn foo() {
    match 0 {
        0 => {
            return AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA
        }
        _ => "",
    };
}

    ویرایش سبک 2024:

    fn foo() {
    match 0 {
        0 => {
            return AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA;
        }
        _ => "",
    };
}

    الگوهای طولانی آرایه و slice اکنون شکسته می‌شوند

    الگوهای طولانی آرایه و slice به‌درستی شکسته نمی‌شدند.

    ویرایش سبک 2021:

    fn main() {
    let [aaaaaaaaaaaaaaaaaaaaaaaaaa, bbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbb, cccccccccccccccccccccccccc, ddddddddddddddddddddddddd] =
        panic!();
}

    ویرایش سبک 2024:

    fn main() {
    let [
        aaaaaaaaaaaaaaaaaaaaaaaaaa,
        bbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbb,
        cccccccccccccccccccccccccc,
        ddddddddddddddddddddddddd,

    قالب‌بندی آخرین دستور عبارتی به‌صورت یک عبارت

    آخرین دستور در یک بلوک که یک عبارت است اکنون به‌صورت یک عبارت قالب‌بندی می‌شود.

    ویرایش سبک 2021:

    fn main() {
    let toto = || {
        if true {
            42
        } else {
            24
        }
    };

    {
        T
    }
}

    ویرایش سبک 2024:

    fn main() {
    let toto = || {
        if true { 42 } else { 24 }
    };

    { T }
}

    قالب‌بندی یکسان برای فراخوانی تابع و ماکرو

    برخی از قالب‌بندی‌ها اکنون در فراخوانی ماکرو همان‌طور است که در فراخوانی تابع است.

    ویرایش سبک 2021:

    fn main() {
    macro_call!(HAYSTACK
        .par_iter()
        .find_any(|&&x| x[0] % 1000 == 999)
        .is_some());

    fn_call(
        HAYSTACK
            .par_iter()
            .find_any(|&&x| x[0] % 1000 == 999)
            .is_some(),
    );
}

    ویرایش سبک 2024:

    fn main() {
    macro_call!(
        HAYSTACK
            .par_iter()
            .find_any(|&&x| x[0] % 1000 == 999)
            .is_some()
    );

    fn_call(
        HAYSTACK
            .par_iter()
            .find_any(|&&x| x[0] % 1000 == 999)
            .is_some(),

    اجبار closureهای بلوکی برای closureهایی با بدنهٔ تک‌حلقه‌ای

    closureهایی که فقط یک حلقه دارند اکنون به‌صورت یک عبارت بلوکی قالب‌بندی می‌شوند.

    ویرایش سبک 2021:

    fn main() {
    thread::spawn(|| loop {
        println!("iteration");
    });
}

    ویرایش سبک 2024:

    fn main() {
    thread::spawn(|| {
        loop {
            println!("iteration");
        }
    });
}

    خطوط خالی در عبارت‌های where اکنون حذف می‌شوند

    خطوط خالی در یک عبارت where اکنون حذف می‌شوند.

    ویرایش سبک 2021:

    fn foo<T>(_: T)
where
    T: std::fmt::Debug,

    T: std::fmt::Display,
{
}

    ویرایش سبک 2024:

    fn foo<T>(_: T)
where
    T: std::fmt::Debug,
    T: std::fmt::Display,

    اصلاح قالب‌بندی دستور let-else دارای attribute

    اگر یک دستور let-else دارای attribute بود، بند else باعث می‌شد بخش else به‌اشتباه به‌طور جداگانه شکسته شود.

    ویرایش سبک 2021:

    fn main() {
    #[cfg(target_os = "linux")]
    let x = 42
    else {
        todo!()
    };

    // This is the same without an attribute.
    let x = 42 else { todo!() };
}

    ویرایش سبک 2024:

    fn main() {
    #[cfg(target_os = "linux")]
    let x = 42 else { todo!() };

    // This is the same without an attribute.
    let x = 42 else { todo!() };
}

    خطای off-by-one در format_macro_matchers

    هنگام استفاده از قابلیت format_macro_matchers، matcher در عرض ستونی شکسته می‌شد که یک واحد اختلاف داشت.

    ویرایش سبک 2021:

    macro_rules! test {
    ($aasdfghj:expr, $qwertyuiop:expr, $zxcvbnmasdfghjkl:expr, $aeiouaeiouaeio:expr, $add:expr) => {{
        return;
    }};
}

    ویرایش سبک 2024:

    macro_rules! test {

        $aasdfghj:expr, $qwertyuiop:expr, $zxcvbnmasdfghjkl:expr, $aeiouaeiouaeio:expr, $add:expr
    ) => {{
        return;
    }};

    رفع شکست در حالتی که => در کامنتِ بعد از => در match وجود دارد

    در برخی شرایط، اگر یک کامنت بعد از => در یک عبارت match خودش شامل => بود، قالب‌بندی به‌درستی انجام نمی‌شد.

    ویرایش سبک 2021:

    fn main() {
    match a {
        _ =>
        // comment with =>
                {
            println!("A")
        }
    }
}

    ویرایش سبک 2024:

    fn main() {
    match a {
        _ =>
        // comment with =>
        {
            println!("A")
        }
    }
}

    تورفتگی نادرست چند attribute درونی در یک عبارت match

    چند attribute درونی در یک عبارت match به‌اشتباه تورفتگی می‌گرفتند.

    ویرایش سبک 2021:

    pub fn main() {
    match a {
        #![attr1]
    #![attr2]
        _ => None,
    }
}

    ویرایش سبک 2024:

    pub fn main() {
    match a {
        #![attr1]
        #![attr2]
        _ => None,
    }
}
