    مشخص‌کننده‌های قطعهٔ ماکرو

    خلاصه

    • مشخص‌کنندهٔ قطعهٔ expr (fragment specifier) اکنون از عبارت‌های const و _ نیز پشتیبانی می‌کند.
    • مشخص‌کنندهٔ قطعهٔ expr_2021 برای سازگاری با گذشته اضافه شده است.

    جزئیات

    هنگامی که نحو جدیدی به Rust اضافه می‌شود، گاهی مشخص‌کننده‌های قطعهٔ موجود در macro_rules اجازه ندارند با نحو جدید تطبیق پیدا کنند تا سازگاری با گذشته حفظ شود. پشتیبانی از نحو جدید در مشخص‌کننده‌های قدیمی گاهی به ویرایش بعدی موکول می‌شود که فرصتی برای به‌روزرسانی آن‌ها فراهم می‌کند.

    دقیقاً همین اتفاق برای عبارت‌های const که در 1.79 اضافه شدند و عبارت‌های _ که در 1.59 اضافه شدند رخ داد. در ویرایش ۲۰۲۱ و پیش از آن، مشخص‌کنندهٔ قطعهٔ expr با این عبارت‌ها تطبیق پیدا نمی‌کند. دلیلش این است که ممکن است سناریویی مانند این داشته باشید:

    macro_rules! example {
    ($e:expr) => { println!("first rule"); };
    (const $e:expr) => { println!("second rule"); };
}

fn main() {
    example!(const { 1 + 1 });
}

    در اینجا، در ویرایش 2021، ماکرو با قاعدهٔ دوم تطبیق پیدا می‌کند. اگر ویرایش‌های قبلی expr را طوری تغییر می‌دادند که با عبارت‌های const تازه معرفی‌شده تطبیق پیدا کند، با قاعدهٔ اول تطبیق پیدا می‌کرد که یک تغییر ناسازگار (breaking change) بود.

    در ویرایش 2024، مشخص‌کننده‌های expr اکنون با عبارت‌های const و _ نیز تطبیق پیدا می‌کنند. برای پشتیبانی از رفتار قدیمی، مشخص‌کنندهٔ قطعهٔ expr_2021 اضافه شده است که با عبارت‌های جدید تطبیق پیدا نمی‌کند.

    مهاجرت

    lint با نام edition_2024_expr_fragment_specifier همهٔ استفاده‌های مشخص‌کنندهٔ expr را به expr_2021 تغییر می‌دهد تا رفتار ماکروهای موجود تغییر نکند. این lint بخشی از گروه lint با نام rust-2024-compatibility است که در مهاجرت خودکار ویرایش گنجانده شده است. برای مهاجرت کد خود به سازگاری با ویرایش Rust 2024، این دستور را اجرا کنید:

    cargo fix --edition

    در بیشتر موارد، احتمالاً می‌خواهید مشخص‌کنندهٔ expr را نگه دارید تا از عبارت‌های جدید پشتیبانی شود. باید ماکروی خود را بررسی کنید تا ببینید آیا قاعده‌های دیگری وجود دارند که در غیر این صورت با const یا _ تطبیق پیدا کنند و مشخص کنید که تداخلی وجود دارد یا نه. اگر رفتار جدید را می‌خواهید، فقط هر تغییری را که lint اعمال کرده است برگردانید.

    همچنین می‌توانید lint را به‌صورت دستی فعال کنید تا ماکروهایی را که ممکن است لازم باشد مشخص‌کنندهٔ expr در آن‌ها به‌روزرسانی شود پیدا کنید.

    // Add this to the root of your crate to do a manual migration.
#![warn(edition_2024_expr_fragment_specifier)]
