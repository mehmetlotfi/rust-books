    Cargo: بازنویسی default-features به‌ارث‌رسیده

    خلاصه

    • از Rust 1.99 به بعد، default-features روی یک وابستگی به‌ارث‌رسیده در یک بستهٔ ویرایش 2024، مقدار تعیین‌شده در [workspace.dependencies] را بازنویسی می‌کند.

    جزئیات

    ارث‌بری workspace به شما امکان می‌دهد وابستگی‌ها را در یک مکان (workspace) مشخص کنید و سپس از درون یک بسته به آن وابستگی‌های workspace ارجاع دهید.

    در ویرایش‌های قبل از 2024، وقتی وابستگی workspace مقدار default-features = true را مشخص کرده باشد (یا default-features را مشخص نکرده باشد)، default-features = false نادیده گرفته می‌شود. رفتار اولیهٔ ویرایش 2024 در Rust 1.85 تا 1.98 این ترکیب را رد می‌کرد. از Rust 1.99 به بعد، تنظیم default-features در یک بستهٔ ویرایش 2024 تنظیم workspace را بازنویسی می‌کند.

    برای مثال، با یک workspace که این را مشخص می‌کند:

    [workspace.dependencies]
regex = "1.10.4"

    مورد زیر featureهای پیش‌فرض regex را غیرفعال می‌کند:

    [package]
name = "foo"
version = "1.0.0"
edition = "2024"

[dependencies]
regex = { workspace = true, default-features = false }

    فقط حواستان باشد که اگر چند عضو workspace را هم‌زمان بسازید، featureها یکپارچه می‌شوند، به‌طوری که اگر یک عضو default-features = true را تنظیم کند (که در صورت تعیین نشدن صریح، مقدار پیش‌فرض است)، featureهای پیش‌فرض برای همهٔ اعضایی که از آن وابستگی استفاده می‌کنند فعال خواهند شد.

    مهاجرت

    هنگام استفاده از cargo fix --edition، Cargo در این وضعیت default-features = false را به‌طور خودکار حذف می‌کند. بدون این اصلاح، تغییر به ویرایش 2024 در Rust 1.85 تا 1.98 خطا تولید می‌کرد و در Rust 1.99 یا جدیدتر featureهای پیش‌فرض را غیرفعال می‌کرد.

    اگر می‌خواهید از رفتار جدید استفاده کنید، پس از تغییر به ویرایش 2024 این تنظیم را دوباره اضافه کنید. اگر ترجیح می‌دهید ضمن حفظ رفتار پیشین به‌صورت دستی مهاجرت کنید، مدخل‌های متناظر را حذف کنید. ویرایش‌های قبلی باید چیزی شبیه این نمایش دهند:

    warning: /home/project/Cargo.toml: `default-features` is ignored for regex,
since `default-features` was not specified for `workspace.dependencies.regex`;
overriding workspace `default-features` to false requires Rust 1.99+
and the 2024 edition
