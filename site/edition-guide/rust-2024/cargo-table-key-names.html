    Cargo: یکپارچگی نام جدول‌ها و کلیدها

    خلاصه

    • چند نام جدول و کلید در Cargo.toml که پیش‌تر دو روش برای مشخص کردن یک چیز یکسان وجود داشت، حذف شده‌اند.
      • [project] حذف شد؛ به‌جای آن از [package] استفاده کنید.
      • default_features حذف شد؛ به‌جای آن از default-features استفاده کنید.
      • crate_type حذف شد؛ به‌جای آن از crate-type استفاده کنید.
      • proc_macro حذف شد؛ به‌جای آن از proc-macro استفاده کنید.
      • dev_dependencies حذف شد؛ به‌جای آن از dev-dependencies استفاده کنید.
      • build_dependencies حذف شد؛ به‌جای آن از build-dependencies استفاده کنید.

    جزئیات

    چند نام جدول و کلید در ویرایش 2024 دیگر مجاز نیستند. دو روش برای مشخص کردن این جدول‌ها یا کلیدها وجود داشت، و این تغییر کمک می‌کند فقط یک روش برای مشخص کردن آن‌ها باشد.

    برخی از آن‌ها نتیجهٔ تغییر تصمیم‌ها در طول زمان بودند و برخی دیگر محصول جانبی ناخواستهٔ پیاده‌سازی. برای پرهیز از سردرگمی و اعمال یک سبک واحد در مشخص کردن این جدول‌ها و کلیدها، اکنون فقط یک شکل مجاز است.

    برای مثال:

    [dev_dependencies]
rand = { version = "0.8.5", default_features = false }

    باید به این تغییر کند:

    [dev-dependencies]
rand = { version = "0.8.5", default-features = false }

    توجه کنید که زیرخط‌ها در dev_dependencies و default_features به خط تیره تغییر یافتند.

    مهاجرت

    هنگام استفاده از cargo fix --edition، Cargo فایل Cargo.toml شما را به‌طور خودکار به‌روزرسانی می‌کند تا از نام‌های ترجیحی جدول‌ها و کلیدها استفاده کند.

    اگر ترجیح می‌دهید Cargo.toml خود را به‌صورت دستی به‌روزرسانی کنید، حتماً فهرست بالا را مرور کنید و مطمئن شوید فقط از شکل‌های جدید استفاده شده است.
