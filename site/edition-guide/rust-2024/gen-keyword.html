    کلیدواژهٔ gen

    خلاصه

    • gen یک کلیدواژهٔ رزروشده است.

    جزئیات

    کلیدواژهٔ gen به‌عنوان بخشی از RFC #3513 رزرو شده است تا «بلوک‌های gen» در نسخه‌ای از Rust در آینده معرفی شوند. بلوک‌های gen راهی فراهم می‌کنند تا نوشتن انواع خاصی از iteratorها آسان‌تر شود. رزرو کردن این کلیدواژه از همین حالا، پایدارسازی بلوک‌های gen را پیش از ویرایش بعدی آسان‌تر می‌کند.

    مهاجرت

    معرفی کلیدواژهٔ gen می‌تواند برای هر شناسه‌ای که از قبل gen نام دارد مشکل ایجاد کند. برای مثال، هر متغیر یا تابعی با نام gen با کلیدواژهٔ جدید تداخل پیدا می‌کند. برای غلبه بر این مشکل، Rust از پیشوند r# برای یک شناسهٔ خام پشتیبانی می‌کند که به شناسه‌ها اجازه می‌دهد با کلیدواژه‌ها همپوشانی داشته باشند.

    lint با نام keyword_idents_2024 هر شناسه‌ای به نام gen را به‌طور خودکار به r#gen تغییر می‌دهد تا کد در هر دو ویرایش همچنان کار کند. این lint بخشی از گروه lint با نام rust-2024-compatibility است که هنگام اجرای cargo fix --edition به‌طور خودکار اعمال می‌شود. برای مهاجرت کد خود به سازگاری با ویرایش Rust 2024، این دستور را اجرا کنید:

    cargo fix --edition

    برای مثال، این کد را تغییر می‌دهد:

    fn gen() {
    println!("generating!");
}

fn main() {
    gen();
}

    به این شکل تبدیل می‌شود:

    fn r#gen() {
    println!("generating!");
}

fn main() {
    r#gen();
}

    یا می‌توانید lint را به‌صورت دستی فعال کنید تا جاهایی را که شناسه‌های gen باید به r#gen تغییر کنند پیدا کنید:

    // Add this to the root of your crate to do a manual migration.
#![warn(keyword_idents_2024)]
