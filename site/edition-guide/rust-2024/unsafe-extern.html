    بلوک‌های extern از نوع unsafe

    خلاصه

    • بلوک‌های extern اکنون باید با کلیدواژهٔ unsafe علامت‌گذاری شوند.

    جزئیات

    Rust 1.82 در همهٔ ویرایش‌ها این امکان را اضافه کرد که بلوک‌های extern با کلیدواژهٔ unsafe علامت‌گذاری شوند.1 افزودن کلیدواژهٔ unsafe به تأکید بر این نکته کمک می‌کند که درست بودن امضاها بر عهدهٔ نویسندهٔ بلوک extern است. اگر امضاها درست نباشند، ممکن است به رفتار تعریف‌نشده منجر شود.

    نحو یک بلوک extern از نوع unsafe به این شکل است:

    unsafe extern "C" {
    // sqrt (from libm) may be called with any `f64`
    pub safe fn sqrt(x: f64) -> f64;

    // strlen (from libc) requires a valid pointer,
    // so we mark it as being an unsafe fn
    pub unsafe fn strlen(p: *const std::ffi::c_char) -> usize;

    // this function doesn't say safe or unsafe, so it defaults to unsafe
    pub fn free(p: *mut core::ffi::c_void);

    pub safe static IMPORTANT_BYTES: [u8; 256];
}

    علاوه بر اینکه می‌توانید یک بلوک extern را unsafe علامت‌گذاری کنید، می‌توانید مشخص کنید که هر آیتم درون بلوک extern به‌تنهایی safe است یا unsafe. آیتم‌های علامت‌گذاری‌شده با safe را می‌توان بدون بلوک unsafe به کار برد.

    از ویرایش 2024 به بعد، گنجاندن کلیدواژهٔ unsafe روی بلوک extern الزامی است. هدف این است که کاملاً روشن شود الزامات ایمنی‌ای وجود دارند که تعریف‌های extern باید آن‌ها را رعایت کنند.

    مهاجرت

    lint با نام missing_unsafe_on_extern می‌تواند بلوک‌های extern را با افزودن کلیدواژهٔ unsafe به‌روزرسانی کند. این lint بخشی از گروه lint با نام rust-2024-compatibility است که در مهاجرت خودکار ویرایش گنجانده شده است. برای اینکه کد خود را با ویرایش Rust 2024 سازگار کنید، این دستور را اجرا کنید:

    cargo fix --edition

    فقط توجه داشته باشید که این مهاجرت خودکار نمی‌تواند بررسی کند که امضاهای درون بلوک extern درست هستند. همچنان مسئولیت بازبینی دستی تعریف آن‌ها بر عهدهٔ خود شماست.

    به‌جای آن، می‌توانید lint را به‌صورت دستی فعال کنید تا جاهایی را که بلوک‌های unsafe در آن‌ها باید به‌روزرسانی شوند پیدا کنید.

    // Add this to the root of your crate to do a manual migration.
#![warn(missing_unsafe_on_extern)]
