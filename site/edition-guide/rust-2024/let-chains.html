    زنجیره‌های let در if و while

    خلاصه

    • امکان زنجیر کردن عبارت‌های let در عملوند شرط if و while فراهم می‌شود.

    جزئیات

    از ویرایش 2024 به بعد، زنجیر کردن عبارت‌های let درون عملوندهای شرط if و while مجاز است، که منظور از زنجیر کردن، زنجیره‌های && است. عبارت‌های let همچنان باید در سطح بالا ظاهر شوند، بنابراین if (let Some(hi) = foo || let Some(hi) = bar) مجاز نیست.

    پیش از 2024، let باید بلافاصله بعد از if یا while می‌آمد و شکل خاص if let یا while let را تشکیل می‌داد. اکنون if و while زنجیره‌هایی از یک یا چند عبارت let را می‌پذیرند که ممکن است با عبارت‌هایی از نوع bool ترکیب شده باشند.

    fn sum_first_two(nums: &[u8]) -> Option<u8> {
    let mut iter = nums.iter();
    if let Some(first) = iter.next()
        && let Some(second) = iter.next()
    {
        first.checked_add(*second)
    } else {
        None
    }
}

    این قابلیت به‌دلیل نیاز به بازتعریف دامنهٔ if let که یکی از تغییرات ویرایش 2024 است، به ویرایش وابسته شده است.

    مهاجرت

    گذر به ویرایش 2024 به‌خاطر این قابلیت به هیچ مهاجرتی نیاز ندارد، زیرا این قابلیت مجموعهٔ برنامه‌های مجاز Rust را به‌طور واقعی گسترش می‌دهد.
