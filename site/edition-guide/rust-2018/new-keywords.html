    کلیدواژه‌های جدید

    خلاصه

    • dyn یک کلیدواژهٔ سخت‌گیرانه (strict) است؛ در ویرایش 2015 یک کلیدواژهٔ ضعیف (weak) است.
    • async و await کلیدواژه‌های سخت‌گیرانه هستند.
    • try یک کلیدواژهٔ رزروشده است.

    انگیزه

    dyn Trait برای شیءهای صفت

    قابلیت dyn Trait سینتکس جدید برای استفاده از شیءهای صفت (trait objects) است. به طور خلاصه:

    • Box<Trait> به Box<dyn Trait> تبدیل می‌شود
    • &Trait و &mut Trait به &dyn Trait و &mut dyn Trait تبدیل می‌شوند

    و به همین ترتیب. در کد:

    trait Trait {}

impl Trait for i32 {}

// old
fn function1() -> Box<Trait> {
unimplemented!()
}

// new
fn function2() -> Box<dyn Trait> {
unimplemented!()
}

    همین!

    چرا؟

    استفاده از نام صفت به‌تنهایی برای شیءهای صفت تصمیم بدی از آب درآمد. سینتکس فعلی اغلب مبهم و گیج‌کننده است، حتی برای افراد باتجربه، و قابلیتی را ترجیح می‌دهد که نسبت به جایگزین‌هایش بیشتر استفاده نمی‌شود، گاهی کندتر است، و اغلب در جایی که جایگزین‌هایش قابل استفاده‌اند، اصلاً نمی‌توان از آن استفاده کرد.

    علاوه بر این، با آمدن impl Trait، مقایسهٔ «impl Trait در برابر dyn Trait» بسیار متقارن‌تر و در نتیجه کمی زیباتر از «impl Trait در برابر Trait» است. impl Trait در اینجا توضیح داده شده است.

    بنابراین در ویرایش جدید، هرجا به یک شیء صفت نیاز دارید، باید dyn Trait را به Trait به‌تنهایی ترجیح دهید.
