    تغییرات Cargo

    خلاصه

    • اگر در فایل مانیفست Cargo.toml یک تعریف هدف وجود داشته باشد، دیگر به‌طور خودکار کشف خودکار هدف‌های دیگر را غیرفعال نمی‌کند.
    • مسیرهای هدف به شکل src/{target_name}.rs دیگر برای هدف‌هایی که فیلد path در آن‌ها تنظیم نشده است استنباط نمی‌شوند.
    • اجرای cargo install برای پوشهٔ جاری دیگر مجاز نیست؛ برای نصب بستهٔ جاری باید cargo install --path . را مشخص کنید.
