    پارامترهای بی‌نام تابع‌های صفت منسوخ شدند

    خلاصه

    • وقتی تابع بدنه دارد، پارامترهای تابع trait می‌توانند از هر الگوی ردناپذیر (irrefutable) استفاده کنند.

    جزئیات

    مطابق با RFC شمارهٔ #1685، پارامترها در اعلان متدهای صفت دیگر نمی‌توانند بی‌نام باشند.

    برای مثال، در ویرایش 2015 این کد مجاز بود:

    trait Foo {
    fn foo(&self, u8);
}

    در ویرایش 2018، همهٔ پارامترها باید یک نام آرگومان داشته باشند (حتی اگر فقط _ باشد):

    trait Foo {
    fn foo(&self, baz: u8);
}
