    رشته‌ها

    Rust دو نوع رشته دارد: برش رشته (&str) و رشتهٔ دارای مالک (String). ما قصد نداریم تعیین کنیم کِی باید از کدام استفاده کنید، اما نشان می‌دهیم چگونه آن‌ها را شناسایی و ایجاد کنید و چگونه از آن‌ها استفاده کنید.
