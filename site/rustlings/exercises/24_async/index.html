    Async

    برنامه‌نویسی ناهمگام (asynchronous) مدلی است که در آن وظایف به یک runtime سپرده می‌شوند که آن‌ها را به‌طور همزمان اجرا می‌کند. این مدل به‌ویژه برای برنامه‌هایی کارآمد است که در آن‌ها عملیات‌های IO مستقل زیادی انجام می‌شود، مثلاً وب‌سرورها.

    Rust اجزای اولیهٔ لازم برای برنامه‌نویسی ناهمگام را در خود زبان فراهم می‌کند. با این حال، کتابخانهٔ استاندارد Rust شامل runtime نیست. برای این تمرین‌ها از runtime رایج به نام tokio استفاده می‌کنیم.
