    Optionها

    نوع Option یک مقدار اختیاری را نشان می‌دهد: هر Option یا Some است و مقداری دارد، یا None است و مقداری ندارد. نوع‌های Option در کد Rust بسیار رایج‌اند، زیرا کاربردهای متعددی دارند:

    • مقادیر اولیه
    • مقدار بازگشتی برای توابعی که روی کل دامنهٔ ورودی خود تعریف نشده‌اند (توابع جزئی)
    • مقدار بازگشتی برای گزارش خطاهای ساده، که در آن هنگام بروز خطا None برگردانده می‌شود
    • فیلدهای اختیاری ساختار
    • فیلدهای ساختار که می‌توان آن‌ها را قرض داد یا «برداشت» (take)
    • آرگومان‌های اختیاری تابع
    • اشاره‌گرهای تهی‌پذیر (nullable)
    • جابه‌جا کردن مقدارها برای خروج از موقعیت‌های دشوار
