    صفت‌ها

    صفت (trait) مجموعه‌ای از متدهاست.

    نوع‌های داده می‌توانند صفت‌ها را پیاده‌سازی کنند. برای این کار، متدهایی که صفت را تشکیل می‌دهند برای آن نوع داده تعریف می‌شوند. برای مثال، نوع داده String صفت From<&str> را پیاده‌سازی می‌کند. این به کاربر اجازه می‌دهد String::from("hello") بنویسد.

    به این ترتیب، صفت‌ها تا حدی شبیه interfaceهای جاوا و کلاس‌های انتزاعی C++ هستند.

    برخی از صفت‌های رایج دیگر Rust عبارت‌اند از:

    • Clone (متد clone)
    • Display (که نمایش قالب‌بندی‌شده از طریق {} را ممکن می‌کند)
    • Debug (که نمایش قالب‌بندی‌شده از طریق {:?} را ممکن می‌کند)

    از آنجا که صفت‌ها رفتار مشترک بین نوع‌های داده را نشان می‌دهند، هنگام نوشتن جنریک‌ها مفیدند.
