    پیکربندی Clippy

    توجه: فایل پیکربندی ناپایدار است و ممکن است در آینده منسوخ شود.

    برخی lintها را می‌توان در یک فایل TOML با نام clippy.toml یا .clippy.toml پیکربندی کرد. جست‌وجو برای این فایل از نخستین پوشه‌ای آغاز می‌شود که بر اساس ترتیب اولویت زیر تعریف شده باشد:

    1. پوشه‌ای که متغیر محیطی CLIPPY_CONF_DIR مشخص می‌کند، یا
    2. پوشه‌ای که متغیر محیطی CARGO_MANIFEST_DIR مشخص می‌کند، یا
    3. پوشهٔ جاری.

    اگر پوشهٔ انتخاب‌شده فایل پیکربندی نداشته باشد، Clippy در درخت پوشه‌ها به سمت بالا حرکت می‌کند و تک‌تک پوشه‌های والد را جست‌وجو می‌کند تا فایلی پیدا کند یا به ریشهٔ سیستم فایل برسد.

    این فایل شامل نگاشت ساده‌ای به شکل variable = value است، برای مثال:

    avoid-breaking-exported-api = false
disallowed-names = ["toto", "tata", "titi"]

    جدول پیکربندی‌ها همهٔ مقادیر پیکربندی، مقدار پیش‌فرض آن‌ها و فهرست lintهایی را که تحت تأثیر آن‌ها قرار می‌گیرند در خود دارد. هر lint قابل پیکربندی نیز اطلاعاتی دربارهٔ این مقادیر ارائه می‌دهد.

    برای پیکربندی‌هایی که از نوع فهرست هستند و مقدار پیش‌فرض دارند، مانند disallowed-names، می‌توانید از مقدار ویژهٔ ".." استفاده کنید تا مقادیر پیش‌فرض به‌جای آنکه جایگزین شوند، گسترش یابند.

    # default of disallowed-names is ["foo", "baz", "quux"]
disallowed-names = ["bar", ".."] # -> ["bar", "foo", "baz", "quux"]

    برای غیرفعال کردن پیام «for further information visit lint-link» می‌توانید متغیر محیطی CLIPPY_DISABLE_DOCS_LINKS را تعریف کنید.

    مجاز یا ممنوع کردن lintها

    attributeها در کد

    می‌توانید با افزودن attributeها به کد خود، lintهای Clippy را در حالت allow/warn/deny قرار دهید:

    • کل مجموعهٔ lintهایی که به‌طور پیش‌فرض در حالت warn هستند، با استفاده از گروه lint ‏clippy (#![allow(clippy::all)])

    • همهٔ lintها، با استفاده از هر دو گروه lint ‏clippy و clippy::pedantic (#![warn(clippy::all, clippy::pedantic)]). توجه کنید که clippy::pedantic شامل چند lint بسیار سخت‌گیر است که مستعد هشدار اشتباه هستند.

    • فقط برخی lintها (#![deny(clippy::single_match, clippy::box_vec)] و مانند آن)

    • allow/warn/deny را می‌توان با #[allow(...)] و مانند آن به یک تابع یا ماژول منفرد محدود کرد.

    توجه: allow یعنی lint برای کد شما نادیده گرفته شود. با warn، lint فقط یک هشدار صادر می‌کند، در حالی که با deny وقتی lint در کد شما فعال شود یک خطا صادر می‌کند. خطا باعث می‌شود Clippy با یک کد خطا خارج شود و به همین دلیل بیشتر در اسکریپت‌هایی که در CI/CD استفاده می‌شوند مفید است.

    پرچم‌های خط فرمان

    اگر نمی‌خواهید سطح lintها را در کد بیاورید، می‌توانید هنگام اجرا با ارسال پرچم‌های اضافی به Clippy، lintها را به‌صورت سراسری فعال یا غیرفعال کنید:

    برای مجاز کردن lint_name این دستور را اجرا کنید:

    cargo clippy -- -A clippy::lint_name

    و برای دریافت هشدار از lint_name این دستور را اجرا کنید:

    cargo clippy -- -W clippy::lint_name

    این روش با گروه‌های lint هم کار می‌کند. برای مثال می‌توانید Clippy را با فعال بودن هشدار برای همهٔ lintهای pedantic اجرا کنید:

    cargo clippy -- -W clippy::pedantic

    اگر فقط به برخی lintها اهمیت می‌دهید، می‌توانید همهٔ بقیه را مجاز کنید و سپس صراحتاً فقط برای lintهای مورد علاقه‌تان هشدار فعال کنید:

    cargo clippy -- -A clippy::all -W clippy::useless_format -W clippy::...

    بخش lints در Cargo.toml

    سرانجام، می‌توان lintها را با استفاده از بخش lints در فایل Cargo.toml مجاز یا ممنوع کرد:

    برای ممنوع کردن clippy::enum_glob_use، موارد زیر را در Cargo.toml قرار دهید:

    [lints.clippy]
enum_glob_use = "deny"

    برای جزئیات و گزینه‌های بیشتر، به مستندات Cargo مراجعه کنید.

    تعیین حداقل نسخهٔ پشتیبانی‌شدهٔ Rust

    پروژه‌هایی که قصد دارند از نسخه‌های قدیمی Rust پشتیبانی کنند، می‌توانند با تعیین حداقل نسخهٔ پشتیبانی‌شدهٔ Rust (MSRV) در فایل پیکربندی Clippy، lintهای مربوط به قابلیت‌های جدیدتر را غیرفعال کنند.

    msrv = "1.30.0"

    MSRV را می‌توان به شکل یک attribute نیز مشخص کرد، مانند زیر.

    #![feature(custom_inner_attributes)]
#![clippy::msrv = "1.30.0"]

fn main() {
    ...
}

    هنگام تعیین MSRV می‌توانید نسخهٔ patch را هم حذف کنید، بنابراین msrv = 1.30 معادل msrv = 1.30.0 است.

    توجه: برخی lintها رفتار خود را بسته به MSRV پیکربندی‌شده تغییر می‌دهند. در برخی موارد، Clippy ممکن است یک lint را به‌کلی ساکت کند تا APIها یا نحوی را پیشنهاد ندهد که برای MSRV پیکربندی‌شده در دسترس نیستند. در موارد دیگر، Clippy ممکن است lint را صادر کند اما یک پیشنهاد قدیمی‌تر و سازگار را انتخاب کند.

    توجه: custom_inner_attributes یک قابلیت ناپایدار است، بنابراین باید به‌طور صریح فعال شود.

    lintهایی که این گزینهٔ پیکربندی را تشخیص می‌دهند را اینجا می‌توانید پیدا کنید.

    غیرفعال کردن ارزیابی بخشی از کد

    توجه: این روش فقط باید در مواردی به کار رود که راه‌حل‌های دیگر، مانند #[allow(clippy::all)]، کافی نیستند.

    بسیار به‌ندرت ممکن است بخواهید Clippy را از ارزیابی بخش‌های مشخصی از کد به‌کلی بازدارید. این کار با کامپایل شرطی و بررسی اینکه cfg ‏clippy تنظیم نشده باشد امکان‌پذیر است. ممکن است لازم باشد یک stub فراهم کنید تا کد کامپایل شود:

    #[cfg(not(clippy))]
include!(concat!(env!("OUT_DIR"), "/my_big_function-generated.rs"));

#[cfg(clippy)]
fn my_big_function(_input: &str) -> Option<MyStruct> {
    None
}
