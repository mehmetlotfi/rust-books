کتاب ClippyThe Clippy Book

    attributeها برای نویسندگان crate

    در برخی موارد می‌توان پوشش Clippy را به کتابخانه‌های شخص ثالث هم گسترش داد. برای این کار، Clippy چند attribute فراهم می‌کند که می‌توان آن‌ها را روی آیتم‌های crate شخص ثالث به کار برد.

    #[clippy::format_args]

    از Clippy نسخهٔ v1.85 در دسترس است

    این attribute را می‌توان به ماکرویی افزود که از نحو format!، println! یا مشابه آن‌ها پشتیبانی می‌کند. این attribute به Clippy اعلام می‌کند که ماکرو یک ماکروی قالب‌بندی است و آرگومان‌های آن باید مانند آرگومان‌های format! بررسی شوند. هر lint که برای یک فراخوانی format! اعمال می‌شود، برای فراخوانی این ماکرو نیز اعمال خواهد شد. ماکرو می‌تواند پیش از رشتهٔ قالب آرگومان‌های اضافی داشته باشد که نادیده گرفته می‌شوند.

    مثال

    /// A macro that prints a message if a condition is true.
#[macro_export]
#[clippy::format_args]
macro_rules! print_if {
    ($condition:expr, $($args:tt)+) => {{
        if $condition {
            println!($($args)+)
        }
    }};
}

    #[clippy::has_significant_drop]

    از Clippy نسخهٔ v1.60 در دسترس است

    attribute ‏clippy::has_significant_drop را می‌توان به نوع‌هایی افزود که پیاده‌سازی Drop آن‌ها اثر جانبی مهمی دارد، مانند آزاد کردن قفل یک mutex؛ در این حالت مهم است که کاربران بتوانند طول عمر آن‌ها را دقیق درک کنند. وقتی در یک فراخوانی تابع، مقدار موقتی در scrutinee یک match بازگردانده می‌شود، طول عمر آن تا پایان بلوک match ادامه می‌یابد که ممکن است غافلگیرکننده باشد.

    مثال

    #[clippy::has_significant_drop]
struct CounterWrapper<'a> {
    counter: &'a Counter,
}

impl<'a> Drop for CounterWrapper<'a> {
    fn drop(&mut self) {
        self.counter.i.fetch_sub(1, Ordering::Relaxed);
    }
}
