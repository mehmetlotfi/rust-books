کتاب ClippyThe Clippy Book

    نصب

    اگر برای نصب و مدیریت toolchainهای Rust از rustup استفاده می‌کنید، Clippy معمولاً از پیش نصب شده است. در این صورت می‌توانید از این فصل بگذرید و به فصل استفاده بروید.

    Note

    توجه: اگر هنگام نصب یک toolchain از Rust، پروفایل minimal را به کار برده باشید، Clippy به‌طور خودکار نصب نمی‌شود.

    استفاده از Rustup

    اگر Clippy برای یک toolchain نصب نشده باشد، می‌توان آن را با دستور زیر نصب کرد

    $ rustup component add clippy [--toolchain=<name>]

    از روی سورس

    به فصل مبانی در راهنمای توسعه‌دهندگان Clippy نگاهی بیندازید تا دستورالعمل‌های گام‌به‌گام ساخت و نصب Clippy از روی سورس را بیابید.
