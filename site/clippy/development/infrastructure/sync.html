    همگام‌سازی تغییرات بین Clippy و rust-lang/rust

    Clippy در حال حاضر با یک نسخهٔ nightly پین‌شده ساخته می‌شود.

    در مخزن rust-lang/rust، که rustc در آن قرار دارد، یک نسخهٔ کپی از Clippy وجود دارد که توسعه‌دهندگان کامپایلر هر از چند گاهی آن را تغییر می‌دهند تا با تغییرات API ناپایدار کامپایلر سازگار شود.

    ما باید این تغییرات را به‌طور دوره‌ای به همین مخزن بازگردانیم، و تغییراتی که در این فاصله در همین مخزن انجام شده‌اند نیز باید به مخزن rust-lang/rust همگام شوند.

    برای جلوگیری از شلوغ شدن صف PRهای rust-lang/rust، اگر تغییر فوری‌ای وجود نداشته باشد، این همگام‌سازی دوطرفه به‌صورت دو هفته یک‌بار انجام می‌شود. این کار از روز انتشار نسخهٔ stable زبان Rust شروع می‌شود و پس از آن هر دو هفته تکرار می‌شود. به این ترتیب تضمین می‌کنیم که این مخزن همیشه با آخرین API کامپایلر به‌روز باشد و هر قابلیت Clippy پیش از رسیدن به beta، دو هفته در nightly در دسترس باشد. برای مرجع، نخستین همگام‌سازی با این رویه در تاریخ 2020-08-27 انجام شد.

    این فرایند در بخش‌های بعدی به‌تفصیل شرح داده شده است. برای اطلاعات کلی دربارهٔ subtreeها در مخزن Rust، راهنمای توسعهٔ rustc را ببینید.

    وصله‌کردن git-subtree برای کار با مخازن بزرگ

    در حال حاضر باگی در git-subtree وجود دارد که مانع از کار درست آن با مخزن rust-lang/rust می‌شود. یک PR باز برای رفع آن وجود دارد، اما راکد مانده است. پیش از ادامهٔ مراحل زیر، باید این اصلاح را به‌صورت دستی روی نسخهٔ محلی git-subtree اعمال کنیم.

    می‌توانید نسخهٔ وصله‌شدهٔ git-subtree را از اینجا دریافت کنید. این فایل را در مسیر /usr/lib/git-core قرار دهید (و از فایل قبلی نسخهٔ پشتیبان بگیرید) و مطمئن شوید مجوزهای مناسب را دارد:

    sudo cp --backup /path/to/patched/git-subtree.sh /usr/lib/git-core/git-subtree
sudo chmod --reference=/usr/lib/git-core/git-subtree~ /usr/lib/git-core/git-subtree
sudo chown --reference=/usr/lib/git-core/git-subtree~ /usr/lib/git-core/git-subtree

    Note

    نکته: بار اول که git subtree push را اجرا می‌کنید، باید یک کش ساخته شود. این کار شامل مرور یک‌بارهٔ کل تاریخچهٔ Clippy است. برای این کار باید محدودیت stack را افزایش دهید، که با ulimit -s 60000 انجام می‌شود. دستور ulimit را حتماً از همان نشستی اجرا کنید که git subtree را در آن فراخوانی می‌کنید.

    Note

    نکته: اگر کاربر Debian هستید، dash پوستهٔ پیش‌فرضی است که به‌جای sh برای اسکریپت‌ها استفاده می‌شود. این پوسته یک محدودیت بازگشت (recursion) ثابت برابر 1,000 دارد. برای اینکه این فرایند کار کند، باید اسکریپت را مجبور کنید به‌جای آن از bash استفاده کند. می‌توانید این کار را با ویرایش خط اول اسکریپت git-subtree و تغییر sh به bash انجام دهید.

    Note

    نکته: بخش‌های زیر فرض می‌کنند که remoteها را مطابق دستورالعمل تعریف remoteها تنظیم کرده‌اید.

    انجام همگام‌سازی از rust-lang/rust به Clippy

    در ادامه نسخهٔ خلاصهٔ فرایند همگام‌سازی آمده است (همهٔ دستورهای زیر باید داخل دایرکتوری rust اجرا شوند):

    1. مخزن rust-lang/rust را کلون کنید یا مطمئن شوید که به‌روز است.
    2. commit مربوط به آخرین nightly موجود را checkout کنید. می‌توانید آن را با rustup check به دست آورید.
    3. تغییرات نسخهٔ کپی‌شدهٔ Clippy در rust را به fork خود از Clippy همگام کنید: 
      # Be sure to either use a net-new branch, e.g. `rustup`, or delete the branch beforehand
# because changes cannot be fast forwarded and you have to run this command again.
git subtree push -P src/tools/clippy clippy-local rustup

    Note

    نکته: در بیشتر موارد باید در مخزن rust-clippy یک merge commit بسازید (این کار باید در مخزن Clippy انجام شود، نه در نسخهٔ کپی‌شدهٔ Clippy): bash git fetch upstream # assuming upstream is the rust-lang/rust remote git switch rustup git merge upstream/main --no-ff نکته: این یکی از معدود مواردی است که وجود merge commit در یک PR مجاز است.

    git fetch upstream  # assuming upstream is the rust-lang/rust remote
git switch rustup
git merge upstream/main --no-ff

    این یکی از معدود مواردی است که در آن‌ها وجود یک merge commit در یک PR مجاز است.

    1. نسخهٔ nightly را در مخزن Clippy با اجرای این دستورها به‌روز کنید: 
      cargo dev sync update_nightly
git commit -m "Bump nightly version -> YYYY-MM-DD" rust-toolchain.toml clippy_utils/README.md
    2. یک PR به rust-lang/rust-clippy باز کنید و منتظر بمانید تا merge شود (برای تسریع فرایند، تیم @rust-lang/clippy را در PR خود mention کنید و/یا از آن‌ها در stream مربوط به Zulip بپرسید.)

    انجام همگام‌سازی از Clippy به rust-lang/rust

    همهٔ دستورهای زیر باید داخل دایرکتوری rust اجرا شوند.

    1. مطمئن شوید که آخرین main از rust-lang/rust را checkout کرده‌اید.
    2. شاخهٔ master مخزن rust-lang/rust-clippy را به نسخهٔ کپی‌شدهٔ Clippy همگام کنید: bash git switch -c clippy-subtree-update git subtree pull -P src/tools/clippy clippy-upstream master 
      git switch -c clippy-subtree-update
git subtree pull -P src/tools/clippy clippy-upstream master
    3. یک PR به rust-lang/rust باز کنید.
