    Note

    توجه: این سند احتمالاً فقط در صورتی به کار شما می‌آید که عضو تیم Clippy باشید.

    Clippy همراه با انتشارهای stable زبان Rust منتشر می‌شود. تاریخ این انتشارها را می‌توانید در Rust Forge بیابید. این سند گام‌های لازم برای ایجاد یک انتشار Clippy را توضیح می‌دهد.

    تعریف remoteها

    شاید بخواهید remote با نام upstream را برای پروژهٔ Clippy تعریف کنید تا گام‌های بعدی ساده‌تر شوند. با این حال، این کار اختیاری است و می‌توانید به جای upstream از نشانی کامل استفاده کنید.

    git remote add upstream git@github.com:rust-lang/rust-clippy

    افزایش نسخه

    وقتی باید یک انتشار انجام شود، اگر نسخه‌ها در Cargo.toml درست نباشند، cargo test شکست می‌خورد. در طول آن همگام‌سازی، نسخه‌ها باید افزایش یابند. این کار با اجرای دستور زیر انجام می‌شود:

    cargo dev release bump_version

    این دستور شمارهٔ نسخهٔ هر فایل Cargo.toml مرتبط را افزایش می‌دهد. پس از آن، فایل‌های به‌روزشده را فقط با دستور زیر کامیت کنید:

    git commit -m "Bump Clippy version -> 0.1.XY" **/*Cargo.toml

    XY باید با نسخهٔ متناظر جایگزین شود

    یافتن کامیت Clippy

    هم برای به‌روزرسانی شاخهٔ beta و هم شاخهٔ stable، گام نخست یافتن کامیت آخرین همگام‌سازی Clippy است که در شاخهٔ مربوط Rust انجام شده است.

    اجرای دستورهای زیر در مخزن Rust کامیت مربوط به <branch> مشخص‌شده را به دست می‌دهد:

    git switch <branch>
SHA=$(git log --oneline -- src/tools/clippy/ | grep -o "Merge commit '[a-f0-9]*' into .*" | head -1 | sed -e "s/Merge commit '\([a-f0-9]*\)' into .*/\1/g")

    که در آن <branch> یکی از stable، beta یا master است.

    به‌روزرسانی شاخهٔ beta

    پس از به دست آوردن کامیت شاخهٔ beta، می‌توان شاخهٔ beta را در مخزن Clippy به‌روزرسانی کرد.

    git checkout beta
git reset --hard $SHA
git push upstream beta

    به‌روزرسانی شاخهٔ stable

    پس از به دست آوردن کامیت شاخهٔ stable، می‌توان شاخهٔ stable را در مخزن Clippy به‌روزرسانی کرد.

    git checkout stable
git reset --hard $SHA
git push upstream stable

    تگ کردن کامیت stable

    پس از به‌روزرسانی شاخهٔ stable، کامیت HEAD را تگ کنید و آن را به مخزن Clippy push کنید.

    git tag rust-1.XX.0               # XX should be exchanged with the corresponding version
git push upstream rust-1.XX.0     # `upstream` is the `rust-lang/rust-clippy` remote

    پس از این، انتشار باید در صفحهٔ تگ‌های Clippy در دسترس باشد.

    انتشار clippy_utils

    crate با نام clippy_utils بدون هیچ تضمین پایداری در crates.io منتشر می‌شود. برای این کار، پس از انجام همگام‌سازی و انتشار، به شاخهٔ upstream/master برگردید و clippy_utils را منتشر کنید:

    Note

    توجه: PR مربوط به Rustup که نسخهٔ nightly و نسخهٔ Clippy را افزایش می‌دهد باید پیش از انجام این کار ادغام شده باشد.

    git switch master && git pull upstream master
cargo publish --manifest-path clippy_utils/Cargo.toml

    به‌روزرسانی CHANGELOG.md

    برای این کار، سند نحوهٔ به‌روزرسانی changelog را ببینید.

    اگر وقت ندارید یک به‌روزرسانی کامل changelog را فوراً انجام دهید، فقط بخش‌های زیر را به‌روزرسانی کنید:

    • (beta) را از نسخهٔ stable جدید حذف کنید:

      ## Rust 1.XX (beta) -> ## Rust 1.XX

    • خط تاریخ انتشار نسخهٔ stable جدید را به‌روزرسانی کنید:

      Current beta, release 20YY-MM-DD -> Current stable, released 20YY-MM-DD

    • خط تاریخ انتشار نسخهٔ stable قبلی را به‌روزرسانی کنید:

      Current stable, released 20YY-MM-DD -> Released 20YY-MM-DD
