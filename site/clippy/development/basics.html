    دریافت کد

    نخست مطمئن شوید آخرین نسخهٔ Clippy را دریافت کرده‌اید. اگر این نخستین بار است که روی Clippy کار می‌کنید، یک fork از مخزن بسازید و سپس آن را با دستور زیر clone کنید:

    git clone git@github.com:<your-username>/rust-clippy

    اگر پیش‌تر Clippy را clone کرده‌اید، آن را به آخرین نسخه به‌روز کنید:

    # If the upstream remote has not been added yet
git remote add upstream https://github.com/rust-lang/rust-clippy
# upstream has to be the remote of the rust-lang/rust-clippy repo
git fetch upstream
# make sure that you are on the master branch
git checkout master
# rebase your master branch on the upstream master
git rebase upstream/master
# push to the master branch of your fork
git push

    ساخت و آزمایش

    می‌توانید Clippy را مانند هر پروژهٔ Rust دیگری بسازید و آزمایش کنید:

    cargo build  # builds Clippy
cargo test   # tests Clippy

    از آنجا که مجموعه آزمون‌های Clippy بسیار بزرگ است، چند دستور وجود دارد که فقط زیرمجموعه‌ای از آزمون‌های Clippy را اجرا می‌کنند:

    # only run UI tests
cargo uitest
# only run UI tests starting with `test_`
TESTNAME="test_" cargo uitest
# only run dogfood tests
cargo dev dogfood

    اگر خروجی یک آزمون UI با خروجی مورد انتظار تفاوت داشته باشد، می‌توانید فایل مرجع را با دستور زیر به‌روز کنید:

    cargo bless

    برای مثال، اگر یک غلط املایی را در پیام خطای یک lint اصلاح کنید یا یک فایل آزمون را برای افزودن یک مورد آزمون تغییر دهید، این کار لازم است.

    Note

    توجه: این دستور ممکن است فایل‌های بیشتری از آنچه مدنظر داشتید به‌روز کند. در آن صورت فقط فایل‌هایی را commit کنید که می‌خواستید به‌روز شوند.

    cargo dev

    Clippy چند ابزار توسعه دارد تا کار روی Clippy راحت‌تر شود. این ابزارها از طریق دستور cargo dev در دسترس هستند. ابزارهای موجود در زیر فهرست شده‌اند. برای دریافت اطلاعات بیشتر دربارهٔ این دستورها، کافی است آن‌ها را با --help فراخوانی کنید.

    # formats the whole Clippy codebase and all tests
cargo dev fmt
# register or update lint names/groups/...
cargo dev update_lints
# create a new lint and register it
cargo dev new_lint
# deprecate a lint and attempt to remove code relating to it
cargo dev deprecate
# automatically formatting all code before each commit
cargo dev setup git-hook
# (experimental) Setup Clippy to work with RustRover
cargo dev setup intellij
# runs the `dogfood` tests
cargo dev dogfood

    اطلاعات بیشتر دربارهٔ نحوهٔ استفاده و دلایل فرمان intellij.

    lintcheck

    دستور cargo lintcheck ‏Clippy را روی مجموعه‌ای ثابت از crateها می‌سازد و اجرا می‌کند و گزارشی از نتایج تولید می‌کند. می‌توانید با git diff گزارش به‌روزشده را با نسخهٔ قبلی‌اش مقایسه کنید و ببینید lint شما چه تأثیری روی مجموعه‌ای کوچک از crateها داشته است. اگر lint جدیدی اضافه می‌کنید، لطفاً هشدارهای حاصل را بررسی کنید و مطمئن شوید هشدار اشتباهی وجود ندارد و پیشنهادها معتبر هستند.

    برای جزئیات بیشتر به README این ابزار مراجعه کنید.

    دربارهٔ PRها

    ما از سیاست عدم استفاده از merge-commit در rustc پیروی می‌کنیم. به https://rustc-dev-guide.rust-lang.org/contributing.html#opening-a-pr مراجعه کنید.

    پیش از باز کردن pull request خود بدانید که ما یک سیاست دربارهٔ LLM داریم. سیاست LLM را ببینید.

    اختصارهای رایج

    اختصارمعنا
    UBرفتار تعریف‌نشده (Undefined Behavior)
    FPهشدار اشتباه (False Positive)
    FNشناسایی‌نشدن مورد واقعی (False Negative)
    ICEخطای داخلی کامپایلر (Internal Compiler Error)
    ASTدرخت نحو انتزاعی (Abstract Syntax Tree)
    MIRبازنمایی میانی سطح متوسط (Mid-Level Intermediate Representation)
    HIRبازنمایی میانی سطح بالا (High-Level Intermediate Representation)
    TCXبافت نوع (Type context)

    این فهرستی مختصر از اختصارهایی است که ممکن است هنگام توسعهٔ Clippy پیش بیایند. فهرست عمومی و جامع‌تر را می‌توانید در واژه‌نامهٔ rustc-dev-guide بیابید. اگر اختصار یا معنایی برایتان روشن نیست، همیشه در پرسیدن راحت باشید.

    نصب از روی سورس

    اگر روی Clippy کار می‌کنید و می‌خواهید آن را از سورس نصب کنید، مراحل زیر را انجام دهید:

    از ریشهٔ پروژهٔ Clippy، دستور زیر را اجرا کنید تا فایل‌های باینری Clippy ساخته شوند و در پوشهٔ toolchain کپی شوند. این کار به‌طور پیش‌فرض یک toolchain جدید با نام clippy ایجاد می‌کند؛ برای گزینه‌های دیگر cargo dev setup toolchain --help را ببینید.

    cargo dev setup toolchain

    اکنون می‌توانید در هر پروژه‌ای با استفاده از toolchain جدید، cargo +clippy clippy را اجرا کنید.

    cd my-project
cargo +clippy clippy

    …یا clippy-driver

    clippy-driver +clippy <filename>

    اگر دیگر به این toolchain نیازی ندارید، می‌توانید آن را با rustup حذف کنید:

    rustup toolchain uninstall clippy

    هرگز با cargo install --path . --force نصب نکنید، زیرا این کار proxyهای rustup را بازنویسی می‌کند. یعنی ~/.cargo/bin/cargo-clippy و ~/.cargo/bin/clippy-driver باید hard link یا soft link به ~/.cargo/bin/rustup باشند. می‌توانید با اجرای rustup update این موارد را ترمیم کنید.
